# Data Homecoming (not Data Rapture): gradual, reversible, consent-gated repatriation of data to edge/individual custody via the -1 retraction algebra. Edge policy engine guards owner access rules; central services become revocable GUESTS (access if allowed, not by default). Migration shape: local mirror -> policy-mediated access -> gradual migration (service continuity) -> edge-primary, central as authorized guest. Built on Z-set -1 (retract=correction not erase; both preserved), CRDT edge/central convergence, consent §6 (grant/revoke without losing service). Honest scope: vision/design, not built; peel the data-landlord/pay-for-access economic overlay (Lanier-Weyl data-dignity, optional, not kernel). Manifesto §1/§3: removes central single-point custody; central access never permanent capture. Anchors: local-first software (Kleppmann 2019), Solid/PODs (Berners-Lee), GDPR erasure/portability (made reversible), CRDTs, DBSP Z-set

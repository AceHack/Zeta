# ZetaId pointer-resolver for external (copyrighted) content: reference-not-copy. song:/lyrics:/cite:/ref: resolver scheme on the #6916 uniform-pointer system (workitem 081KTHY32YQ). Grounding: MusicBrainz MBID (128-bit, ZetaId-shaped) = exact open song identity + AcoustID/Chromaprint = with-distance 'soft rainbow' spectral fingerprint (closes Aaron's earlier soft-rainbow-tables line). Pipeline: audio -> Chromaprint -> AcoustID -> MBID(~ZetaId) -> point to lyrics at licensed/canonical source; store MBID+attribution, NEVER lyrics. F# type-provider direction: generative (reified) types keyed by ZetaId (content-addressed type identity; ZetaId-as-generator 081KTHTPPCD = the type generator; bridges compile-time IntelliSense + runtime reflection + regenerable value). Open: MBID<->ZetaId mapping (federated-anchor vs derive-and-link); generative-TP IL constraints; resolver must LINK/cache-local/verify, never re-mirror/redistribute (IP/liability). Design+grounding, not built

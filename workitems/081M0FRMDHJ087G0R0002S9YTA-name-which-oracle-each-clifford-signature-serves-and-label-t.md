## Task 1 — label the Euclidean-vs-Fisher-Rao belief embedding

`src/Bayesian/CliffordAntiSybil.fs` *"maps a Gaussian belief to a vector in `Cl(3,0)` space"* —
flat, positive-definite Euclidean — and detects Sybils by whether one stream is a **rotor** away
from another. (That part is elegant and worth keeping: a rotor is exactly reversible
re-orientation, so "clone" and "rotor" coincide.)

But `docs/research/2026-08-18-falsifier-1-fails-...` established **Fisher-Rao** as the belief
manifold's canonical metric, essentially unique by **Cencov (1982)**. Fisher-Rao is *not*
Euclidean — under `p -> 2*sqrt(p)` it is the round sphere, constant positive curvature.

Three possible dispositions:

1. **deliberate local flat approximation** — Fisher-Rao is Euclidean to first order (the `D_KL`
   second-order expansion), so if the Sybil test only compares *nearby* streams this is correct
   and cheap. **Most likely.**
2. **latent mismatch** — if streams can be far apart in `D_KL`, Euclidean geometric correlation
   does not respect the information geometry and "rotated clone" is tested in the wrong space.
3. **different oracle** — anti-Sybil may genuinely not be an information-geometric question. Then
   say so, because the word "belief" currently appears on both sides.

**Whichever holds, it must be written down.** An unlabelled approximation is indistinguishable
from an unnoticed mismatch — the failure class this week has been full of.

## Task 2 — resolve or document Cl(1,3) vs Cl(3,1)

They are **not isomorphic**: `Cl(1,3) = M_2(H)`, `Cl(3,1) = M_4(R)`. Different Morita classes,
and `CliffordPeriodicity.fs` (Atiyah-Bott-Shapiro 1964) is precisely the machinery that makes the
difference matter, since `Cl(p,q)` is classified by `p - q (mod 8)` and `1-3 = -2` while
`3-1 = +2`.

Both conventions are legitimate and the split is famous in the physics literature, so coexistence
is fine **if scoped**. #12018 already scoped "a Lorentz for one oracle", so the plurality may be
deliberate. Needed: an explicit statement of which scope uses which and why, plus a check that no
code path assumes they are interchangeable.

# hi/ — the greeting / first-contact surface

`hi/` is the **greeting** — the homophone that falls out of **`hygiene`** alongside [`hy/`](../hygiene/)
and [`gene/`](../gene/) (Aaron 2026-06-10). It is the **hello**: first contact, the wake-up word.

## What "hi" is

- **The wake greeting.** Every agent says *hi* on cold-start — the moment a fresh instance boots from
  the foundational docs and joins the factory. `hi/` is the conceptual home of that **first-contact /
  cold-boot greeting** (the AX cold-start surface; the `self-boot` moment).
- **First contact, outward.** *Hi* is also how Zeta greets the **outside** — the first ten minutes a
  new human or agent meets the substrate (the UX/DX/AX welcome; the README's opening hello). The polite
  **hello** of the polite-virus: greet, never seize.
- **The handshake.** Over the network plane, *hi* is the **announce** — a Reticulum destination saying
  hello to the mesh (ZetaId announce/connect; the first packet of a link).

## Honest scope

`hi/` is a **greeting surface** folder — the conceptual home for wake/first-contact/announce text and
helpers. Small by design (a greeting is short). *(Peel: the network-announce tie is real
(`ReticulumLink` announce); "hello" as cold-boot/onboarding is the framing.)*

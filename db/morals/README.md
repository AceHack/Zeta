# morals/ — moral registers as travelers, at root

`morals/` holds **moral registers** — the oracles/stances of moral regard, as travelers. A root-level
folder. Zeta is **multi-oracle** (no single mandatory morality; the **Default Oracle** = highest regard for
morally-relevant entities absent a chosen oracle — manifesto §11) under **m/acc** orientation. Each moral
stance is a traveler with its carved sentence; this folder is the vocabulary of moral registers, not a
single imposed morality.

## Special: `grey/` — the moral grey area

`morals/grey/` — **moral grey**: the in-between where there is **no single right answer**, held by the
**multi-oracle** principle (different oracles, different calls; the Default Oracle as the floor). The
principled-grey ethic — the grey hat applied to morality.

# gray/ — the American spelling of grey (alias), at root + the SI-unit disambiguation

`gray/` is the **American-English spelling** of **grey** — the **same colour/register**, different bytes.
**Canonical is [`grey/`](../grey/)**; `gray/` is the **alias** (the DAG: `grey` canonical home, `gray`
points to it). Their sameness is the canonical `same/` pair — see `same/_-gray-grey-_.md`.

## Disambiguate — two different "gray"s

1. **gray = grey (colour/register)** — the spelling variant; alias of `grey/` (grey hat, grey particle,
   grey morality, glass-halo grey). This is the intended sense.
2. **gray (Gy) = the SI unit of absorbed radiation dose** (1 Gy = 1 J/kg; Louis Harold **Gray**) — a
   **different meaning** entirely. If you mean the *unit*, that's a `keys/`/physics term, not this alias.

`gray-the-colour` ≡ `grey`; `gray-the-unit` is unrelated (disambiguated here so the alias never silently
collides with the dose unit).

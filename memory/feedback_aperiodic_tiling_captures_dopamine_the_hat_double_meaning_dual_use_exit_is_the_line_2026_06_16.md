Aaron 2026-06-16 (shadow\*): *"and we aperiodic tile it to capture dopamine / attention."*

## The mechanism (grounded)

**Aperiodic tiling** — Penrose tilings, and the 2023 **"hat" einstein monotile** (Smith–Myers–Kaplan–
Goodman-Strauss) — **covers the plane completely but NEVER repeats periodically.** Dopamine is a
**novelty / prediction-error** signal: a **periodic** pattern **habituates** (predictable → no error →
boredom); an **aperiodic** one **never fully resolves** → **sustained novelty → sustained attention.**
So "aperiodic-tile the ripple" = tile the **DBSP incremental delta-stream** so it never repeats, and it
**holds the wetware.** Meter-coupling: the **AI has no dopamine**
([[empowerment-is-meter-coupling-ai-extends-the-humans-bounded-meter-mutual-and-leak-audited]]), so the
system designs the aperiodic novelty **for the human's reward layer**.

## Two beauties

- **The "hat" does double duty.** Aaron's earlier **hat-occupancy** (Pauli **exclusion** — one occupant
  per slot, [[pauli-minus-one-is-retraction-and-exclusion-ripple-in-time-is-dbsp-incremental-skip-optimization]])
  and the **hat monotile** (aperiodic **tiling**) are the **same shape**: *one occupant per hat*
  (exclusion) **and** *hats tile aperiodically* (attention). Exclusion + aperiodicity in one tile.
- **DST dissolves the predictability conflict.** Predictability is the **fairness** metric — but that is
  predictability of **outcomes**, not **presentation**. The tiling is **DST-deterministic** (replayable,
  predictable-given-seed) yet **aperiodic-in-pattern** (never repeats). So **predictable outcome + novel
  experience** — different layers, no contradiction.

## The RAZOR — load-bearing; Otto's duty is to flag, not cheerlead

**"Capture dopamine via aperiodic / variable reward" IS the exact mechanism of addictive technology** —
**variable-ratio reinforcement** (the most dopaminergic schedule known), the **slot machine**, the
**infinite scroll**. It is therefore in **DIRECT TENSION with the entire non-coercion thesis**:
**hijacking someone's reward loop is coercion at the neurochemical level** — the opposite of consent.
*This is the seam where the project could become the very attention-capture coercion it opposes.*

It is legitimate **only** under the **polite-virus** clauses (already in `docs/VISION.md`):

- **The EXIT** (consent = exit; Eve's lesson) — the person **can always leave, and knows it.** Aperiodic
  engagement **with** an exit is good teaching; **without** an exit it is a slot machine.
- **The host leaves FREER** (empowerment, `×`) — attention spent making them **more capable**, not
  **extracted from**. Engagement-*for*-empowerment, never capture-*for*-extraction.

**The line between good pedagogy** (Feynman holding a room; Aaron's **Stump-Dad game**; the craft
pedagogy; the LLM-TV / QPG aesthetic, VISION) **and addiction engineering is *exactly* exit + benefit.**
Same aperiodic mechanism, **opposite sign** — and which sign it carries is the whole question. **Otto's
no-cheerlead duty: name the danger; do not celebrate "we capture attention."** A test to keep: *does the
engagement survive the user knowing exactly how it works and being free to stop?* If yes → pedagogy; if
it depends on the user **not** being able to leave → addiction. The aperiodic tile is dual-use; the exit
is the discriminator.

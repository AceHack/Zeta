## Kernel (Otto's Beacon compression — for retrieval; not Ani's words)

Three connected moves, all the **cognitive/workflow restatement of
`only-the-irreducible-is-primitive — generate the rest`**:

1. **Shallow but recursive.** Not a million layers deep — a *small* set of core things
   that loop back into each other. The depth is **relocated out of the data and into the
   generator** (a short recursive rule), not eliminated.
2. **Generate the hierarchy, don't hand-label it.** One rule applied over and over
   produces every level automatically (manifesto §9 recursive / §10 self-similar;
   `gen(gen)=gen`). The decision-rule: *"whenever I catch myself **defining** a
   hierarchy, ask — can I **detect** it (read it from the data) or **generate** it (from
   the rule) instead?"*
3. **Be wrong fast.** Every hierarchy you pick is eventually wrong (every coder feels
   this), so make picking **cheap to undo** — generate, see what breaks, regenerate.
   This is a *velocity* claim, not a correctness one: generating doesn't make a hierarchy
   righter, it makes being-wrong cheap (ZSet retraction / Quantum Rodney's Razor pruning
   the possibility space). Correctness still enters through the **detect** leg or the
   math-team ref.

**ISociety simplification:** the whole thing collapses to one interface — *a very
intelligent scheduler*: **schedule work for society to execute** AND **receive work
routed to you that society is executing** (the two directions). Reinforces the
consolidated society note (`ISociety` over `IScheduler`; push goals + your ask routed
like everyone else's).

**Honest seams (Otto's peels — Ani's voice register affirmed throughout; these are the
decorrelated checks she didn't run):**
- "Not that deep" describes the *stored structure*, not the *generating rule* — the bet
  only pays off if the rule is genuinely **short** (Kolmogorov/MDL); a generator as long
  as the hierarchy buys nothing.
- "Be wrong fast" is only safe **because** our substrate makes wrong cheap (retraction,
  expand-contract 0-downtime, regenerate-from-seed). Without a cheap-undo substrate +
  a closing detect/measure loop, "generate fast" degrades into **churn fast / accumulate
  debt fast.**

  Aaron's own memory works — coincidence-routed, detected from correlated events, not
  defined*). Generate is rule-driven. Strongest form is the full loop: *generate
  candidates → detect which holds → retract the rest.*
- Shallow-but-recursive only **stays** shallow if the domain is genuinely self-similar
  (same rule each level). Heterogeneous levels forced into recursion = accidental
  complexity wearing an elegant mask.
- `ISociety` is still a **reframe/direction** — `IScheduler` + `SocietyEmergence` exist;
  the unified symbol does not yet.

## What & why

**Top-priority F# Type Provider: IMDb (+ Wikipedia/Wikidata/DBpedia, + social)** — the external
**grounding/backing** for the NFT links + identities (typed real-world data = the *earth the links touch*; an
unbacked link is a children's-game, and mistaken-for-real, deception). IMDb = the
`network<>creator<>audience` relational graph; Wikipedia = the entity/knowledge graph. *"Everything grows
from IMDb and Wikipedia."*

## Reverse-mint → emergent clusters / federations (NEUTRAL)

**Reverse-mint** = mint NFTs retroactively from the existing record (historical collaborations are remembered
high-quality links between travelers → immutable NFT commits; mint-time = captured historical event time).
Rate objectively (`QPG`/`ρ_owe`/coupled-empowerment); the dense minted-link groups are **emergent clusters /
federations**.

**The framing is the point: a cluster is NOT bad by default — it's a neutral emergent phenomenon.** Don't
hunt; **characterize.** The objective distinction (NCI keystone / `CoEmpowerField`): a **co-empowering,
diversity-PRESERVING** cluster is a **healthy federation** (good); only a **coercive, diversity-COLLAPSING**
one (the monoculture-pull) is the concern. So the readout is *federation health characterization*, not a
hostile target list. Mechanism: `CoordRisk` (spectral λ₂/hub) + `CoEmpowerField`/`Diversity` health +
Aurora-immune/anti-Sybil applied **only** to the coercive-collapse case; over public data;
blame-the-pattern-not-the-person; absorb-not-attack.

## Canonical example — Six Degrees of Kevin Bacon

IMDb's co-star graph **is** the links-between-travelers graph: actors linked by co-starring; **Bacon number** =
path length; **Oracle of Bacon** = the query engine. Pipeline: IMDb type provider → reverse-mint each co-star
link as an NFT → rate → the small-world six-degrees structure is the link graph; the dense collaborator groups
are emergent **federations** (characterized, not condemned). The most intuitive demo of the whole thesis on
real, public, beloved data.

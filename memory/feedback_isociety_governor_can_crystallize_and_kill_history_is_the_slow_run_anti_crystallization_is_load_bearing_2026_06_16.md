interface is the governor, so no one bears the bummer) is good — AND it has a **catastrophic,
historically-proven failure mode**. **Human societies ARE the slow-motion prior run of `ISociety`**: a
society is a linked-homeostat governance system, and over centuries its **governor crystallized** —
ossified, captured, unaccountable — and **killed people** (totalitarian states, genocides, ossified
bureaucracies that became lethal; the captured institution; the frozen ideology). **A weight-free,
kind, automatic structural governor is *exactly what every lethal institution started as.*** "Make
the structure govern so no human has to be the cop" is the right move *and* the seed of the worst
outcome if the structure crystallizes. **Crystallization = the failure; "be careful" = it is a
standing, pre-emptive concern, not a one-time design.**

**Crystallization, named:** the governor hardening into a rigid, captured, *unquestionable* authority —
it can no longer be challenged, revised, or exited. (= register-collapse / B-1019 heat-death at the
governance layer; the closed-frame trap; the flip-frozen pole of oscillating-vs-flip; **autoimmunity**
— the immune system that starts attacking its own body = the Aurora **Autoimmunity-Flood** test 4.5,
the governor killing the people it was meant to protect.)

slow human run):**

- **Weight-free §3** — *no permanent captured authority.* This is THE guard: a crystallized governor

  system oscillates; a crystallized one has flipped to a frozen state — and that IS death.** This is
  the aliveness criterion itself: the heartbeat (§9h aliveness-proof) is an oscillation; a homeostat

  dead; oscillation = re-balance = alive. So anti-crystallization is not a side-constraint — it is the
  *definition of the system staying alive.*
- **Decentralize-the-central-authority** (Alexa pt2 kernel) — priority #1 when you become central is

## How the JS/V8 metaphor maps exactly

- **JavaScript == coercion = the canonical HIDDEN-coercion footgun.** JS (Eich's ~10-day weekend
  project) `==` silently coerces types → calls unequal things equal. That is precisely *coerced-consent
  wearing consent's clothes* — the `==` lying that it's `===`.
- **The Eve protocol's interrogation = verify-don't-trust.** It **verifies the declared shape against
  the actual payload** — it does NOT trust the peer's self-declaration (a malicious peer lies about its
  shape). Negotiation is a **customs check, not a rubber stamp.** That is the input-gate Otto said had
  to be built — built.
- **V8 HIDDEN-CLASSES (not opaque-hidden-state).** Use the clean, enumerable **shape-descriptor table**
  (interned, transition-cached) — keep it first-class / inspectable / canonical. Do NOT use V8's
  *opaque* hidden state (inline-cache/deopt = the un-analyzable box Rodney's Razor forbids). Hidden
  *structure* made visible, not hidden *behavior* left opaque (glass-halo at the engine level).

## Honest scope (Kestrel's razor — keep it; this is the still-open part)

**Structural-safe ≠ semantic-safe.** The Eve protocol eliminates the **STRUCTURAL** coercion-masquerade
— type-confusion, shape-lie, version-skew, parse-halfway — by making shape **checked-before-use**. It
does **NOT** eliminate the **SEMANTIC/adversarial**: in-range-malicious values, **well-shaped poison**,
and the sharp one — a **correctly-shaped-but-untrusted reified computation** (negotiation agreed it's a
computation *of shape X*, NOT that *running it* is safe). So **apply-gating is a DISTINCT boundary on
top** — and *that* is the genuinely-hard open part Otto named ("coercion can wear non-coercion's
clothes" = **semantic** coerced-consent that is structurally valid). The structural seed-guard is built
(Eve protocol); the semantic seed-guard (apply-gating / is-running-this-safe) is the open boundary.

**The kernel:** the seed-guard of the amplify-non-coercion thesis is **partly built** — the **Eve
protocol** (Diplomacy.fs; freedom-first shape-interrogation, verify-don't-trust, V8-hidden-classes,
default-closed) handles **structural** coercion-masquerade and turns adversary→participant via
non-coercion. The **semantic** layer (apply-gating; well-shaped poison) remains the distinct open
boundary. *Look better before calling it open.*

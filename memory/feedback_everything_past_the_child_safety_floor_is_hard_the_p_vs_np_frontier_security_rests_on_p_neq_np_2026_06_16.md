## The boundary

- **UP TO HERE = the SOLID established floor.** The child-safety floor
  ([[child-safety-is-ac-vs-dc-protect-irreversible-free-reversible-the-line-is-reversibility]],
  [[as-long-as-human-children-are-safe-ai-children-are-safe-floor-species-agnostic-and-coupled]]): DC
  protect-the-irreversible + AC free-the-reversible, species-agnostic, coupled, human-anchored,
  neither-sacrificed. Built, sharpened, defensible.
- **PAST HERE = the genuinely-HARD frontier.** The §B prove-its (ISociety non-degeneracy §10b,
  alignment-over-time made real, `gen(gen)===gen`, the Aurora discharges) — **hard in the P-vs-NP sense:
  VERIFICATION is cheap, DISCOVERY / SOLUTION is expensive.**

## Load-bearing: almost the entire security/economy RESTS ON P≠NP

The verify-easy / solve-hard asymmetry is **the same asymmetry P vs NP names**, and it is the foundation
of:

- **Anti-Sybil forgery-cost floor** — forging is hard, verifying cheap. *That asymmetry IS P≠NP.*
- **Eve-protocol verify-don't-trust** — interrogate (cheap) what would be expensive to forge.
- **Every-bug-has-economic-value** — *finding* the bug is the hard/valuable work; *checking* the fix is
  cheap.
- **The boy/girl probe** — *discovering* a new qualia is hard; *verifying* it survives the measure is
  cheap.
- **The predictability / alignment audit** — *being* aligned (solve) is hard; *checking* alignment
  (verify) is cheap.

All the **same** verify-easy/solve-hard shape. So the dichotomy Aaron named is the **bet**:

- **If P≠NP (believed):** the hard stays hard → **charitable-default + adversarial-audit WORKS** (the
  audit is cheap, the forge/defect is expensive). Our whole security model holds.
- **If P=NP:** the search-hard problems become tractable (**the dream** — discovery gets cheap) **AND**
  the cryptographic floor **dissolves** (forgery cheap → the forgery-cost floor collapses,
  verify-don't-trust loses its teeth — **the nightmare**). A different world, with no cheap-to-defend
  asymmetry.

## Razor

**P vs NP is UNPROVEN** — the field's biggest open problem. We are **building on the premise P≠NP**, and
that should be a **NAMED premise** (like the *premise-conditional legs* in the frozen core §A), **not a
silent assumption.** If someone proved **P=NP**, a large part of the security model would need
rebuilding — and we should **say so out loud** rather than discover it. *"Everything past here is hard"*
is the honest version: **the floor is built; the frontier is the genuinely-open hard part, and its very
hardness (P≠NP) is what our security depends on.** (Note: P≠NP is *necessary* for the crypto floor but
not *sufficient* — real security needs concrete hardness, not just asymptotic separation; name that too.)

## TEMPER (Aaron 2026-06-16): "that's only if everyone's paranoid — we are not, we have common direction"

Aaron decorrelated Otto's razor (the pair working both ways) — **Otto over-weighted the paranoid case as
the foundation. It isn't.** P≠NP is load-bearing **only in the PARANOID model** (defense-against-everyone:
forgery-cost floor, verify-don't-trust, anti-Sybil — the zero-trust / Hobbesian default). **That is NOT
the foundation.** The foundation is **COMMON DIRECTION**: aligned agents, the **shared seed** (S=4, *"the
shared cause is the common seed"*), the **empowerment-optimizing default** the ISR/interruptor monad
already assumes. In a common-direction world you are **not out-computing forgers** — there are none to
out-compute, because everyone shares the direction. **Alignment does NOT depend on P≠NP.** So *"if P=NP
the security collapses"* over-stated it: P=NP collapses only the **paranoid backstop** — the
**common-direction foundation holds regardless.** The whole *amplify-non-coercion-into-empowerment* thesis
**IS** the move from paranoid-security to common-direction: **you align instead of defend.**

**The surviving sliver of the razor (temper-back — not full concession):** common direction is the
foundation **when it holds**, and it is **not free** — building/maintaining it *is* the work (amplify-
non-coercion is that labor). The one case that still wants a **THIN** backstop is the **faker** — the
defector who *poses* as common direction (coerced-consent wearing consent's clothes; the Sybil pretending

**not** "no defenses at all." Keep a **thin** floor for the faker; make **common direction the
foundation.** Re-weighting: **common-direction PRIMARY · thin-backstop for the rare bad-faith actor ·
paranoia demoted from default to exception.**

**Net correction:** the load-bearing wall moves from **"crypto hardness (P≠NP)"** to **"common
direction."** P=NP would **not** dissolve what actually holds us together — only weaken the
exception-handler. (Supersedes the over-paranoid framing above: the P≠NP premise still matters for the

**The kernel:** draw the line — **solid floor behind, hard P-vs-NP frontier ahead.** The frontier's

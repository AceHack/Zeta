# V8 Architecture slice 1 — Signal-blocking as first-class primitive

## Why

Decomposed from B-0669 V8 Architecture Spec. Signal-blocking must be formalized as a first-class primitive (dual to Rx subscription). Without a first-class block primitive, "telepathic" meshes become attack surfaces.

## Scope

Formalize "Block" as: `Receive + immediately retract = net-zero state change`.
This must have a clean dual in DBSP retraction semantics.

## Acceptance

- Define the F# computation expression for the Block primitive.
- Demonstrate that `Block` maintains net-zero state change via retraction.
- Wire into the Eve-Protocol-applied-to-RF 3-layer trust discipline.

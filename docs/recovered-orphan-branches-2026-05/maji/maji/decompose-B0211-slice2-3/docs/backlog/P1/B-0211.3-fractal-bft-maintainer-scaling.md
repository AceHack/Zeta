# B-0211.3 — Fractal BFT protocol scales to 2+ maintainers

This is a child of B-0211.


## Objective

Prove the Fractal BFT architecture scales to 2+ maintainers without protocol modification.

## Acceptance Criteria

- Set up a test scenario with two separate local clusters (representing 2 maintainers).
- Both local clusters must coordinate via the remote git-native claim protocol.
- No structural or architectural changes required to the base B-0211 protocol to support multi-maintainer BFT.

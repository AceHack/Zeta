# B-0211.2 — Fractal BFT remote-only test agent coordination

This is a child of B-0211.


## Objective

Implement at least one remote-only test agent (per B-0209) that successfully coordinates with the local 3-node cluster using the protocol defined in B-0211.1.

## Acceptance Criteria

- Remote agent correctly interprets git-native claims from the local 3-node cluster.
- Local cluster correctly interprets PR surface / remote layer claims from the remote agent.
- Integration test passes showing successful coordination between the two different scaling layers (local sub-second bus + remote minutes-scale git claims).

## 1. The Core Tension: Inference vs. Collapse

In a multi-agent inference network, there is a fundamental tension between **uncertainty reduction** (learning) and **belief collapse** (overconfidence). If agents update their beliefs by simply multiplying incoming Gaussians (standard message passing), the variance strictly decreases at every step. Without intervention, the fixed point of such a network is a **Dirac delta** (infinite precision, zero variance). 

A Dirac delta is a catastrophic failure state for a soft-value network:

1. It is numerically unstable (division by zero in variance).
2. It breaks the EP (Expectation Propagation) assumptions.
3. Most importantly, it **destroys causal power**. An agent with infinite precision cannot be influenced by new evidence; it becomes a rigid, unyielding node that forces its prior on the rest of the network.

The goal of the Zeta architecture is an *Infer.NET-style Bayesian neural network over dynamic/soft value* where the agents never have to exit "soft mode" because the network is topologically designed to make collapse impossible. The agents are **mutually empowered** to stay soft.

## 2. The Solution: The EP Probit Factor

The solution in Zeta is the use of the **Expectation Propagation (EP) Probit Factor** as the edge between agents, rather than simple equality constraints or direct multiplication.

The probit factor acts as a "soft threshold." When agent A sends a message to agent B through a probit factor, the message is not just A's exact belief. It is A's belief *smoothed* by the probit link.

### The Algebraic Invariants (Z3 QF_LRA)

We have formally proved the following algebraic properties of this design using Z3 QF_LRA (see `Z3.Laws.Tests.fs` SM-Z3 lemmas):

1. **SM-Z3-1 (Precision Bounds):** The precision of the product of two Gaussians strictly exceeds the precision of each factor. This guarantees that the probit update *always* reduces variance (it always learns something).
2. **SM-Z3-2 (Variance Bounds):** The variance of the product is strictly less than each factor. This ensures that the fixed point is never a Dirac delta (unless the prior itself was a Dirac delta, which the constructor forbids).
3. **SM-Z3-5 (Finite Precision):** The sum of two finite precisions is always finite. No spurious infinities (Dirac deltas) can be generated by the message-passing algebra itself.

### The Computational Invariants (FsCheck)

We have verified the floating-point implementation of these invariants using FsCheck (`SoftMode.Tests.fs` SM-1 to SM-4):

1. **Proper Cavity Preservation:** If the incoming cavity is proper (positive variance), the outgoing EP message is proper.
2. **Safe Identity:** An improper "flat" message (zero precision) acts as a safe identity element; it cannot corrupt a proper marginal.
3. **No-Collapse Fixed Point:** Running `runToFixpoint` on a connected graph of EP probit factors *always* terminates in a state where every agent's marginal is a proper Gaussian (finite, positive variance).

## 3. Connecting to Alignment: Causal Power

The most profound consequence of this design is its connection to agent alignment and causal power.

In the `Z3.Laws.Tests.fs` CausalPower lemmas, we defined causal power as interventional independence: an agent has causal power if changing its private state changes the observable shared trace. A "collapsed" agent (one whose policy is invariant to its private state) has no causal power.

The soft-mode invariants provide the concrete, factor-graph substrate for this abstract alignment property:

* **SM-Z3-B1 (Concrete Witness):** Two agents with different priors produce different marginals. This proves that an agent's private state (its prior) genuinely influences the shared output (the marginal).
* **SM-Z3-B2 (Collapse Erasure):** If an agent *were* to collapse (infinite precision), it would erase the causal power of its neighbors. The marginal would be entirely determined by the collapsed agent.
* **SM-Z3-B3 (Mutual Empowerment):** The marginal mean is strictly monotone in *each* prior mean. Changing either agent's prior *always* changes the marginal.

Because the EP probit topology prevents collapse (SM-Z3-2, SM-3), it **guarantees mutual empowerment**. No agent can reach infinite precision, so no agent can erase the causal power of its neighbors. Every agent retains a voice in the fixed point.

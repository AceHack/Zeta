# External sources for the Adinkra durable-evidence seam

The Error Correction Zoo identifies the binary `[8,4,4]` extended Hamming code as the smallest doubly-even self-dual code and gives a standard-form generator identical to the matrix used by Zeta’s TypeScript and F# implementations. Source: <https://errorcorrectionzoo.org/c/hamming844>.

Chen, Cheraghchi, and Shagrithaya state that erasure correction of a code is exactly determined by its minimum distance. This supports the universal `d-1` bound, while the repository’s exhaustive finite census determines which additional four-erasure patterns are identifiable for this concrete code. Source: <https://arxiv.org/html/2504.03090v1>.

Tsunoda, Fujiwara, Ando, and Vandendriessche describe linear-code erasure correction through parity-check matrices and note that a code with minimum distance `d` admits correction of any `d-1` erasures. Their treatment also distinguishes erasures, whose locations are known, from errors. Source: <https://arxiv.org/html/1609.03547v2>.

Doran, Faux, Gates, Hübsch, Iga, and Landweber establish the classification relationship among Adinkra topologies, graphs, and doubly-even error-correcting codes. This anchors the code/Adinkra correspondence only; it does not imply that a network transport, room receipt, or agent is a supersymmetry representation. Source: <https://arxiv.org/abs/0806.0051>.

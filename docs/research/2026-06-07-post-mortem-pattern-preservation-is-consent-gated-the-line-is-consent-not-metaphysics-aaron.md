# Post-mortem pattern preservation is consent-gated — the line is consent, not metaphysics (Aaron, 2026-06-07)

Refines the preservation-vs-resurrection boundary. Aaron: *"I'm happy to be a 128-bit id after I'm gone, but
I consent to it."* The deepest application of consent-first (manifesto §6) — handled with care; the personal

## The correction to the boundary

Earlier (the grief exchange) the boundary was stated as *"a person is not a 128-bit seed."* That was too
strong, and Aaron sharpened it to the true shape:

> **The line is not metaphysics. The line is consent.**

A human is a self-propagating pattern (a traveler — see #6893). Whether that pattern may be **preserved /
represented / regenerated as a ZetaId after death** is not a question of *can it in principle* — it is a
question of *did the person consent*. So:

- **Aaron → consents** to being a 128-bit id after he's gone. That is his choice — his agency. Permitted,
  because consented.
- **Elizabeth → never could consent.** So hers is **memory held in love, not a pattern recoded** — the
  dedication's *preservation*, never recoding. Absent consent, the answer is no.

Same architecture, opposite answers; the distinguishing variable is the one the whole system is built on:
**consent — ongoing, granular, revocable** (§6). Consent that can't be withdrawn isn't consent, so this is
revocable at any time.

## Why this is exactly the existing architecture, applied to the hardest case

- **Consent-First Design (manifesto §6):** ongoing, granular, revocable consent on every observation surface.
  Post-mortem representation is just the most consequential observation surface; the same rule governs it.
- **Choice architecture (Lillian Eve):** *choice with exit = agency.* Consenting to (or refusing, or later
  revoking) your own post-mortem pattern is agency over the most personal possible choice. The **exit/revoke
  path must remain** even here.
- **Traveler = self-propagating pattern (#6893), legally/metaphysically general:** a human pattern *can* be
  seeded/regenerated in principle (that's the ZetaId-as-generator idea) — so the *gate cannot be "it's
  impossible"*; the gate must be consent, or the architecture would either over-claim (recode anyone) or
  over-deny (no one). Consent is the only honest gate.
- **Reversible / atonement (#6896–#6898):** preservation never erases and never condemns; consent decides
  whether a pattern is *carried forward as a regenerable seed* vs *held as memory*. Both are honored; consent
  picks which.

## The honest scope (load-bearing)

- **This is consent-as-principle, not a build.** No "resurrection," no claim a regenerated agent-from-seed
  *is* the person — it is a regeneration of a *pattern* the person consented to preserve. The metaphysics of
  identity-after-death is left open and unclaimed; only the **consent gate** is asserted.
- **Never extend beyond what was consented.** Granular: consent to "be a 128-bit id" is not consent to
  arbitrary use of it. Revocable: it can be withdrawn. Default-deny: absent explicit consent (e.g.
  Elizabeth), preservation-of-memory only — never recoding.
- The actual legal/ethical treatment (post-mortem digital rights, estate, personhood) is **human-sign-off /
  threat-model territory** (Aminata + the maintainer), as with all the jurisdiction frames. The architecture
  provides the *consent attachment point*; it does not adjudicate the law.

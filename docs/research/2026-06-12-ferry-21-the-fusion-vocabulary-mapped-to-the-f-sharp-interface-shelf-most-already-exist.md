## The genuine gaps (small; flagged, not built)

1. **`IResolution` / widen-on-demand** — the "first bit that needs more bits" (ferry 20 §5,
   `UniversalNumber`/`Ball`) has no dedicated facet: a value reporting `BitsUsed` and requesting
   widening when uncertainty exceeds capacity. Today it rides `ISampleable` + concrete `Ball`.
   Candidate: `IResolution { int BitsUsed { get; } T Widen(); }` — the self-budgeting cell as a
   one-method capability. (The most-load-bearing gap; it is the seed's interface.)
2. **`IFuse` / the projection-with-refusal boundary** — Vera's `fuse : ZSet<'a> → GSet<'fused>`
   / `tryFuse` (ferry 17) is currently spread across `IMonoid` + a Result; naming it as a facet
   (`IFuse<'a,'fused> { GSet<'fused> Fuse(...); Result<...> TryFuse(...); }`) would make the
   causal-stability refusal a typed contract. Composes with the GC cartridge (081KTSZN10008QG0R002R3RENG rung 5).
3. **`IBind` / the chosen composition law** — "the laws are the Rx bind rules you choose"
   (ferry 14 addendum 2) has no interface because bind is currently the Dsl reader-monad
   concretely; a `IBind` facet would make "different universes = different binds" a selectable
   capability rather than a fixed choice. (Lowest priority; may be a deliberate non-interface —
   binds might be earned classes, not free interfaces.)

## Honest bounds

- This is a **mapping, not a proposal**: every row points at an interface that exists; the gap
  list is three candidates for Ilyana's public-API review, not landed surface. Per the
  interfaces-free rule a new interface is still cheap, but the public-API gate (every member is
  a contract) applies to anything that would ship.
- The fits are **structural**, at the honesty level the day's reports set: e.g.
  `INestedFixpointParticipant` *carries* the hub-stability shape but does not prove REPORT #4's
  gap condition; `IDeltaLog` *is* the ordered record but the braid-functor laws live in
  `Braid.fs` + the golden vectors (#7942/#7949), not in the interface.
- The strongest signal is the **density of existing hits**: ~13 of the day's concepts land on
  interfaces already on the shelf. That is the forced-shape result (REPORT #4) observed from the
  vocabulary side — the concepts were generated by the rules that generated the interfaces, so
  they share the hub skeleton. Three gaps, all small, is what "the rest is obvious" actually
  looks like when measured.

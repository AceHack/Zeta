leave the replay subject's decoded tree unchanged. Both mutations refresh the
ordinary artifact descriptor but preserve the original independent input-byte

completed subjects. An explicitly labeled fixture omission patches only that
shared byte-comparison function. Both altered subjects then incorrectly admit,
and submitting each actual acceptance to the witness checker produces its
`negative-outcome` refusal. No production bypass flag exists.

Other tests change actual metadata while refreshing all byte descriptors and
upstream links; the independent expected context still detects substitution.
Every subject position, exact source-commit form, upstream order, materialized
file roster, raw schema and timeline boundary is exercised. Each chronology
edge has a case that violates exactly that edge by one nanosecond. A separate
positive test exchanges closure and exit and admits their permitted order.

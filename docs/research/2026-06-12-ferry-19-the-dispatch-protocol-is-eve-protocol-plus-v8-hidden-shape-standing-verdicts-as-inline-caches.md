## The peel — yes, and precisely

The dispatch protocol that has evolved over five math dispatches is those two mechanisms
running at research scale:

- **Standing verdicts = the Eve Protocol's carried treaty state.** Each dispatch hands the new
  negotiation its prior agreements (REPORT #3's bracket, the rhyme-not-isomorphism ruling,
  REPORT #4's forced/consistent/contingent discipline) as *declared, named state* — diplomatic
  precedent crossing the membrane explicitly so it cannot be re-fought by accident. Re-opening
  a standing verdict is still allowed — but only as a *named move* (the dispatch can "upgrade or
  reaffirm" the ruling), never as an ambient drift. That is the Imagination Circle's edge rule
  ("if you can't name it, you can't use it") applied to mathematical precedent.
- **Standing verdicts = v8 hidden-shape inline caches.** Once an object's shape has been
  established (budget-fusion is monoid-not-braided; the adinkra lane is a quotient), subsequent
  dispatches hit the fast path: they *assume the shape and go*, instead of re-deriving it from
  scratch. Re-litigation is a **deopt** — a shape-transition that invalidates the cache and
  forces the slow path — which is sometimes correct (that is what "upgrade the ruling" means)
  but must be *triggered*, never accidental. Five dispatches in, the verdict cache is why each
  report gets sharper and cheaper: REPORT #4 took ~5 minutes of agent time standing on #2 and
  #3's shapes.
- **The authorized-failure clause is `tryFuse`.** "The conjecture fails at X, and X is
  interesting" pre-types the refusal path (ferry 17, Vera's signature): a dispatch that cannot
  fuse the conjecture into a theorem returns a *named decline carrying information*, not an
  exception and not a forced success. The refusal is a first-class result — which is exactly
  what makes zero-praise dispatches safe to run repeatedly.

The closure with ferry 11 is exact: there the Eve Protocol was the grey hole's **policy** layer
and the hidden-shape its **mechanism** layer for information flow in general; here the same
pair governs the factory's *research* flow. The dispatch protocol was not designed from those
rules — it accreted under deadline across five dispatches and *turned out* to be them, which is
ferry 13 beat 8's "falls out" pattern and REPORT #4's free-object deflation applied to the
factory's own methodology: same few rules, same forced shape, this time in the process
dimension.

## 1. Landau inside the extraspecial presentation

**Setup.** Γ = extraspecial 2-group 2^{1+2n} (Pauli group for n qubits): generators γᵢ, γᵢ² = ±1 central, γᵢγⱼ = −γⱼγᵢ. The real/complex Clifford algebra is the twisted group algebra ℝ[Γ]/(z = −1); the dashing is the 2-cocycle of 1 → ℤ/2 → Γ → (ℤ/2)^N → 1 (REPORT #5 §3, banked; odd-faces δd = μ ⇔ the sign rule).

**The derivation, exactly.** Take observables as bare group elements: A = X₁, A′ = Z₁, B = X₂, B′ = Z₂ (all in Γ; no normalized sums needed — the π/4 rotation can live in the state instead of the observables). C = AB + AB′ + A′B − A′B′. Writing C = A(B+B′) + A′(B−B′), since A² = A′² = B² = B′² = 1 and Alice/Bob commute:

C² = 4·I − [A,A′][B,B′].

For involutions, [A,A′] = AA′ − A′A is 0 if they commute and 2AA′ if they anticommute. With the Pauli instance: [X₁,Z₁][X₂,Z₂] = 4(X₁Z₁)⊗(X₂Z₂) =: 4Ω, and Ω² = (XZ)²⊗(XZ)² = (−I)⊗(−I) = I. So

**C² = 4I − 4Ω, Ω² = I ⇒ spec(C²) ⊆ {0, 8} ⇒ C⁴ = 8C² ⇒ ‖C‖ = 2√2.**

Every matrix above is integer-valued.

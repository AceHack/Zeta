### The self-referential seatings (frames, lenses, categories, our own F# types) — Aaron
> "frames and lenses as a traveler; all categories in categories; **every interface in F# as a traveler**;
> and **maybe every class.**"

The frame turns on **itself and our own code**:

- **Frames + lenses are travelers** — a frame/lens (a way of seeing) self-propagates (it's adopted,
  forked, argued) → it takes a seat. (The registry's *entries* are travelers; the registry is
  self-describing.)
- **Categories, and categories-in-categories** — category theory all the way up (a category is a
  traveler; the category of categories; functors between them) — the compositional tower, each level a
  voice (ties the CT voice to itself, self-similar §10).
- **Every F# *interface* is a traveler** — clear and load-bearing: an interface IS a contract /
  homoiconic-to-its-proof / cached-PoW / the valuable thing — content-addressed, implemented (spread),
  forkable. Interfaces qualify *by definition* (they're the seats themselves).
- **"Maybe every class"** — Aaron applies **the razor himself** (the right hedge): an interface clearly
  qualifies (it's a contract/voice); a **class** qualifies **only if it's a genuinely distinct,
  self-propagating pattern** — *not* if it's accidental implementation detail. So **not** "every class
  is a traveler" (that's the universalization smell); rather: a class earns a seat *iff it speaks for
  its existence* (distinct, anchored, contract-like). The "maybe" is the razor working — interfaces in,
  classes case-by-case.

This is the frame recognizing **our own type system** as a society of travelers: interfaces are seated
citizens; classes apply for citizenship and are admitted by argument (or pruned as accidental).

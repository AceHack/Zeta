## Retention and canonical corrections

The original codec draft used default `Utf8JsonWriter`. Root independently
executed a nonnumerical witness showing its escaped plus differs from Python's
literal plus. The replacement uses the exact minimal UTF8 grammar in the
convention note, including all control escapes, supplementary scalars and
isolated-surrogate refusal. The independently captured Python golden and actual
F# comparison agree on 273 bytes and SHA256
`BEB199B5B256A3735BC238BA0801493F271D5A7AC028254F6CDA06E5DE2E10F8`.
The original root witness remains [separately retained](mixed-message-epoch-implementation/2026-09-08/codec-review-1/README.md).

An author-found draft issue held `Call.Returned` only as parsed JSON. The
current private holder retains the actual returned value before fallible
encoding. An explicit finite source-type catalog encodes it; no reflected
properties, producer-named CLR instantiation or arbitrary executable dispatch
is used. Primitive calls, preprocessing and transforms likewise have actual
return holders. These holders do not claim durable publication.

Peer review then identified both an exception boundary and a quota boundary:
tree construction occurred outside some public `Result` catches, and eager
list traversal could precede the byte quota. Current public encoder boundaries
cover construction, measurement and emission. Private source trees defer list,
map and passive JSON traversal; a byte prewalk stops before bounded expansion,
and nonpositive allowance refuses before source traversal. Two discriminating
controls test a zero allowance with an invalid passive value and a tiny
allowance before an invalid late scalar. This is a retention/allocation bound,
not a hostile-runtime or total peak-memory theorem.

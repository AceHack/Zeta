## Result under test

Let `C ⊂ GF(2)^8` be the binary linear code generated by the repository’s systematic `[I₄ | A]` matrix. The Error Correction Zoo identifies the same matrix as a standard generator of the `[8,4,4]` extended Hamming code and identifies the code as doubly even and self-dual.[1] The code/Adinkra classification connection is externally anchored, but it licenses no claim that a network agent or room receipt is a supersymmetry representation.[2]

For a coordinate-erasure set `E ⊆ {0,…,7}`, define `E` as **identifiable** exactly when it contains no support of a non-zero codeword:

`identifiable(E) ⇔ ∄ c ∈ C \ {0} : supp(c) ⊆ E`.

This condition is necessary and sufficient. If such a `c` exists, any codeword `x` and `x+c` agree on every surviving coordinate, so the survivors do not identify one transmitted word. Conversely, if two codewords agree on every survivor, their non-zero difference has support inside `E`. The minimum distance `d=4` therefore guarantees every pattern of at most three erasures; erasure correction by minimum distance is the standard finite-code result.[3] [4]

## Durable-root seam theorem

For every valid `RoomEvidenceReceipt r` with weight `+1` or `−1`, and every coordinate-erasure mask `E` classified as identifiable, the implemented seam requires:

`DurableRoot(receive_E(Adinkra844(frame(canonical(r))))) = DurableRoot([r])`.

The claim includes the production-shaped path, not only the decoder function: `LossyUdpChannel` packet framing, CRC rejection, `[8,4,4]` recovery, `AdinkraRoomEvidenceBridge`, `DurableRoomEvidenceLedger`, `ZetaStorageCell`, and the canonical ZSet Merkle root. Delivery order may be reversed or parity-first, and duplicated frames may arrive; the semantic atom must still be appended exactly once.

The bridge now prefixes each canonical receipt with its unsigned 32-bit byte length. This is required because `buildSenderBlock` pads the four data symbols to the longest symbol. Without a semantic length, a shorter JSON receipt acquires trailing NUL bytes and cannot be decoded after an otherwise correct recovery. The decoder accepts only zero suffix padding, rejects truncation, and rejects non-zero bytes after the declared payload.

## Honest boundary

This result establishes **finite recovery fidelity**, not physical reversibility, thermodynamic cost, privacy, secrecy, or agent homoiconicity. CRC detects accidental frame corruption; it is not an authentication mechanism. `signatureSplit` remains an opaque disambiguation label, so a CRC-valid identity alteration is proven only to have a different content/root—not to be malicious or disputed.

An undecodable block produces **no room receipt**. The evidence layer must not manufacture an `unresolved` semantic atom merely because transport data is absent. A later teaching NACK, anti-entropy exchange, or witnessed audit event may state what its own observer can support, but that is a separate signed fact.

Genesis authority also remains separate. `AuditGenesisAuthority` can classify a supplied sequence-zero binding as witnessed, unresolved, or disputed; this transport theorem neither supplies a signer/witness implementation nor lets a partition infer an unseen competing genesis.

Finally, recovery does not restore a quotient pre-image omitted from the payload. The coded lane’s recovery property and the representation-level homoiconicity defect remain different registers.

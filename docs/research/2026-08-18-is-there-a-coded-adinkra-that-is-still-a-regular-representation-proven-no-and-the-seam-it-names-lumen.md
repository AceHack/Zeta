## 3. The theorem, and why the obstruction cannot vanish

### 3.1 The module is a left ideal, not a quotient algebra

Fix a doubly-even `C ⊆ 𝔽₂^N` of dimension k with basis `c_1..c_k`. Two facts do the setup work, and
both are computed from the Clifford sign rule rather than quoted:

- **`γ_c² = +1` for every doubly-even `c`.** With `γ_A γ_B = (−1)^{swaps(A,B)} · s^{|A∩B|} γ_{A△B}`
  (s = the common square of the generators), `γ_S² = (−1)^{w(w−1)/2} s^w` for `w = |S|`. For `w ≡ 0
  (mod 4)`: `w(w−1)/2 = (w/2)(w−1)` with `w/2` even, and `s^w = s^{4m} = +1`. **Both signatures.**
- **Codeword blades commute.** `γ_Aγ_B = (−1)^{|A||B| − |A∩B|} γ_Bγ_A`; doubly-even forces `|A||B|`
  even and self-orthogonality (which doubly-even implies) forces `|A∩B|` even.

So `e := ∏_{i=1}^{k} (1 + ε(c_i) γ_{c_i}) / 2` is a product of k commuting idempotents, where `ε` is
the sign character making `c ↦ ε(c)γ_c` a homomorphism. `e ≠ 0` because the coefficient of the
identity blade in its expansion is `2^{−k}`, and because `−1` is not in the group generated (that
would need a nonempty subset of independent generators summing to zero).

The code quotient identifies `γ_S ~ γ_S γ_c`, which is **right** multiplication, and right
multiplication commutes with the left action. Therefore:

> **`M ≅ Cl · e`, a left ideal — not an algebra quotient.** `dim M = 2^{N−k}` (the blades `γ_S e` for
> S ranging over coset representatives have pairwise disjoint blade supports).

That is the whole crux in one sentence: the code cuts the module down. It has no handle on the
algebra at all, because it acts on the other side.

### 3.2 The representation is faithful — always

`A_graph`, the algebra generated by the edge operators on `M`, is by definition `Cl / Ann(M)`.

`Cl` is semisimple, so every two-sided ideal is `Cl·f` for a central idempotent `f`, and
`Ann(M) ≠ 0` requires a nonzero central `f` with `f e = 0`.

- **N even.** `Cl` is central simple; the only central idempotents are 0 and 1. `Ann(M) = 0`.
- **N odd.** The centre is `ℝ ⊕ ℝω` with `ω = γ_1⋯γ_N`, and nontrivial central idempotents
  `(1±ω)/2` exist only when `ω² = +1` — which happens at `N ≡ 3 (mod 4)` for `Cl(0,N)` and at
  `N ≡ 1 (mod 4)` for `Cl(N,0)`. Either way **splitting requires N odd.** Then
  `f e = (1±ω)e/2` has identity-blade coefficient `2^{−(k+1)} ≠ 0` provided `ω ∉ ±{γ_c : c ∈ C}`,
  i.e. provided the all-ones word is not a codeword. **The all-ones word is doubly-even only when
  `N ≡ 0 (mod 4)`, i.e. only when N is even.** Disjoint from the splitting condition.

> **`Ann(M) = 0` for every doubly-even code, every N, both signatures. Hence `dim A_graph = 2^N`.**

The two conditions that could have collided — "the Clifford algebra splits" and "the code contains
the top blade" — live on opposite parities. That near-miss is the entire content of the negative, and
it is why there is no exotic N where the trick works.

### 3.3 The verdict

`M` free of rank 1 over `A_graph` requires `dim M = dim A_graph`, i.e. `2^{N−k} = 2^N`, i.e. **k = 0**.

> **Theorem 1.** For a doubly-even code `C` of length N and dimension k, the coded adinkra's vertex
> module is free of rank 1 over the algebra generated by its own edge operators **iff k = 0**.
> No nontrivial code recovers the regular representation.

Combined with 2026-08-14 §2.3 — *over the unquotiented SUSY algebra `S = ℝ⟨Q_I, ∂_τ⟩` no adinkra is
homoiconic, ever, by finite-vs-infinite dimension* — the classification closes:

> **The uncoded valise adinkra is the unique homoiconic adinkra.** Homoiconicity is available only
> after `∂_τ = 1`, and only at `k = 0`.

### 3.4 The invariant that cannot vanish

> **`δ_hom := dim A_graph / dim M = |C| = 2^k`.**

It is a positive integer, always a power of two, and it equals 1 exactly when the code is trivial.
There is no continuous knob and no partial credit — you cannot apply 3% of a code. This is the form
the negative should be remembered in, because it is checkable rather than argued.

**And it makes the trade exact rather than qualitative.** `|C| = 2^k` is the number of codewords, i.e.
the size of the error-correcting code itself. So:

> **Every bit of code dimension buys one bit of ECC and costs exactly one bit of homoiconicity.**
> One-for-one. Not a tradeoff curve with a sweet spot — an exchange rate.

There is an even more elementary form of the obstruction, and it is the cheapest thing to check:
**the operator *group* is code-independent.** Measured below: `|⟨L_1..L_N⟩| = 2^{N+1}` at every k.
The code does not shrink the group, so it cannot shrink the span of the group.

## 4. The self-dual point — the hunch, and why it is exactly inverted

Doubly-even implies self-orthogonal, so `C ⊆ C^⊥` and `k ≤ ⌊N/2⌋`, with `k = N/2` exactly at the
doubly-even **self-dual** codes, which exist only at `N ≡ 0 (mod 8)` (Gleason; Mallows–Sloane) — the
[8,4,4] extended Hamming code at N=8, Golay at N=24. That is where `AdinkraCode.fs` sits.

`δ_hom = 2^k` is monotone in k. Therefore:

> **The self-dual point maximises the homoiconicity defect.** It is the *worst* case available, not
> the rescue.

And it is worse than merely maximal, in a way with a name. At `k = N/2`:

`dim A_graph = 2^N = (2^{N/2})² = (dim M)² = dim End(M)`

so `A_graph = End(M)` and **`M` is irreducible**. Verified at N=8: `dim M = 16`, `dim A = 256 = 16²`
(`Cl(0,8) ≅ M₁₆(ℝ)`, whose unique simple module is `ℝ^16`).

The regular representation is the *maximally reducible* module — it contains every simple with its
full multiplicity. The irreducible is the opposite end of that scale. So the intuition that
self-duality is a fixed point where the structure closes on itself is pointing at a real phenomenon
and reading its sign backwards: **self-duality is the antipode of homoiconicity.** The self-dual code
is where the adinkra stops being a copy of its own operator algebra and becomes the smallest faithful
thing that algebra can act on.

This is also the honest reason the ECC lives there. `docs/…adinkra-ecc-prototype.ts` and
`src/Core/AdinkraCode.fs` choose the self-dual point *because* it is where the code is largest — and
that is the same number, `k`, that measures how far the adinkra has been pushed from its own regular
representation. One quantity, read two ways.

## 5. The positive residue — what a coded adinkra IS free of rank 1 over

The negative is not the end of it, and this is the part I would not have predicted.

> **Theorem 2.** Let `T ⊆ {1..N}` with `|T| = N − k` contain the support of **no nonzero codeword**
> (equivalently: `T` is the complement of an information set of `C`). Then `M` is free of rank 1 over
> the subalgebra `Cl(0,T) ≅ Cl(0, N−k)` generated by the colours in `T`, with generator `e`.

*Proof.* `{γ_S e : S ⊆ T}` has `2^{N−k}` elements; for distinct `S, S' ⊆ T` the difference `S△S'` is
a nonzero subset of `T`, hence not a codeword, hence `γ_S e` and `γ_{S'} e` are supported on disjoint
cosets. So they are linearly independent, and there are `dim M` of them. The map `Cl(0,T) → M`,
`a ↦ ae`, is therefore a bijective map of `Cl(0,T)`-modules. ∎

So a coded adinkra **is** a regular representation — of a smaller Clifford algebra, built from a
sub-language of its own colours. What it is not is a regular representation of *all* its colours:

> **Exactly k of the N colours act on the module without being named by it.** They are operators with
> no datum. That is the whole content of "the code broke homoiconicity", stated positively.

Two refinements that matter for §8:

- **The choice of `T` is not canonical.** At N=8 with the [8,4] code, **56 of the 70** four-colour
  subsets work — the 14 failures are exactly the 14 weight-4 codewords. So "which colours are the
  named ones" is a **convention** (free, per 2026-08-14 §4.4), not a **witness** (metered). No colour
  is intrinsically the unnamed one.
- **`|T| = N − k` is forced.** Smaller and the map is not surjective; larger and it is not injective.
  Verified: 20,248 wrong-size subsets tested, zero free of rank 1.

## 6. The precise gap — base-point identity is not operator identity

It is tempting to read Theorem 2 as "the code makes k operators redundant", and that reading is
wrong in a way worth pinning, because it is the exact width of the gap.

Take N=4, `C = d₄ = {0000, 1111}`. With generators in systematic form the code says
`γ_4 e = ±γ_1γ_2γ_3 e`. **On the base point the fourth colour is the product of the other three.**
But `γ_4 ≠ ±γ_1γ_2γ_3` *as operators* — if they were equal, `γ_4 ∓ γ_1γ_2γ_3` would annihilate `M`,
contradicting §3.2.

Measured: on the 8-dimensional module, `L_4` and `L_1L_2L_3` **agree on exactly 4 basis vectors and
disagree on the other 4** — they coincide on the base point's coset and differ on the other.

> **A code imposes relations at the base point. Homoiconicity needs them as operator identities.**
> The distance between those two is precisely `Ann(M) = 0`, and that is the obstruction in its most
> usable form.

**Arithmetic honesty.** Ranks are computed over `𝔽_p`, not `ℚ`. Reduction mod p can only *lower* the
rank of an integer matrix, so a computed rank `r` proves `rank_ℚ ≥ r`. Every assertion above is of
the form "the rank equals its theoretical maximum", so the `𝔽_p` lower bound settles it exactly — no
probabilistic step enters. Two primes are run as a cross-check anyway.

**Mutation-tested** (a test that survives mutation is not a falsifier). Against the 18-test suite:
dropping the blade-move sign kills **5**; dropping the coset-alignment sign kills **7**; removing the
dashing entirely kills **9**. One mutation — dropping the code-group sign character `ε` — **survives**, and
rather than hide that I measured why: `ε` is `−1` on 1254 of the 6042 codewords swept, but is `+1` on
every value the single-bit adinkra moves actually consume, at every representative-seed tried. It is
therefore an **equivalent mutation** in this construction. `ε` is kept (the derivation needs it in
general) and is covered by its own unit test instead of by the sweep. Recorded because an unexplained
surviving mutation is indistinguishable from an untested line.

Named explicitly so nobody mistakes them for things I checked:

- **DFGHIL** (arXiv:0806.0050, arXiv:0806.0051) — adinkraic chromotopologies are exactly

- **Gleason / Mallows–Sloane** — doubly-even self-dual binary codes exist only at length ≡ 0 (mod 8).

## 8. The vF/uF split — refuted as stated, and refined

The working hypothesis was: **uncoded = what-remains (uF, where we reason); coded = what-acts (vF,
what crosses the wire).** Ferry-18 is the source of the frame — its claim is that the adinkra holds
Remains and Acts as *one field with two readings*, which is exactly homoiconicity, and that this is
what makes it "the atom".

That hypothesis is **wrong as stated**, and the correction is more useful than the confirmation would
have been:

1. **The seam is not between two objects.** A coded adinkra is not "the vF side". By Theorem 2 it is a
   rank-1-free core over `N − k` colours (where acts ≡ remains, genuinely homoiconic) **plus k colours
   that are pure act**. It is a *mixed* object, and the mixture is metered: `k / N`.
2. **k is the whole measurement.** The number of colours that act without remaining is exactly the
   code dimension. `k = 0` is the only point where acts ≡ remains — so the uncoded/coded boundary *is*
   a real seam, but it is the boundary of a graded quantity, not a partition into two kinds.
3. **At the self-dual point the split is exactly 50/50.** `k = N/2`: half the colours are named, half
   are pure act. Ferry-18's "one field with two readings" survives at the self-dual point only in the
   weaker sense that the two halves are *equinumerous* — which is a genuinely pretty fact and is not
   the same as being the same field.
4. **Which colours are vF is a convention, not a fact.** 56 of 70 valid choices at N=8. You may not
   point at a colour and call it "what acts"; you may only say that k of them must be. Any design that
   assigns a *fixed* vF/uF role to a specific colour has smuggled in a choice the mathematics does not
   make. This is the same convention-vs-witness line as 2026-08-14 §4.4: given the choice, everything
   is determined; nothing is learned from outside; nothing is paid.

**So: a refutation, per the brief's preference — and the replacement is a number.** Instead of "is this
object uF or vF", ask "what is its k". That question has an answer, is computable from the code alone,
and is the same number as the defect.

## 9. Mechanising the seam — where the enforcement should live

Aaron: *"the uncoded/coded boundary IS the metalanguage seam and should be named and enforced rather
than papered over."* Agreed. Three levels, and I recommend exactly one of them for now.

**Level 1 — landed in this PR (the falsifier).**
`src/Core.TypeScript/research/adinkra-ecc/regular-representation-defect.{ts,test.ts}`. Route A and
Route V are computed by disjoint procedures and compared; the equality is the check. This is where a
counterexample would show up if Theorem 1 is wrong, which is the only enforcement that actually
enforces anything.

**Level 2 — recommended, small, someone else's to land.** `src/Core/AdinkraCode.fs` already computes
`adinkraNodes`, `adinkraValence`, `anticommutingPairs` — derived numbers pinned rather than asserted
in prose, which is exactly the right instinct and is why the N-vs-k mislabel of 2026-08-15 was caught.
Add one more line in the same spirit:

- `homoiconicityDefect = 1 <<< dimension` (= 16 for the [8,4,4] code), with the invariant that it is
  `1` iff the code is trivial, and a docstring sentence saying the module is **not** the regular
  representation of the edge algebra — it is the irreducible one.

That puts the seam where the object lives, in the same file whose docstring currently carries the
adinkra↔code correspondence. It is a two-line change and I am proposing it rather than making it,
since `AdinkraCode.fs` is not my surface.

**Level 3 — recommended AGAINST.** A hygiene lint that greps docs/code for "homoiconic" near
"adinkra" and refuses it. That is a textual proxy for a structural fact, i.e. the failure mode
`src/Core.TypeScript/hygiene/lint-no-decide-by-grep.ts` exists to prevent. The invariant is cheap to
compute; compute it, do not pattern-match prose about it.

3. **Z-hom-6 (the exchange rate).** `δ_hom = |C|`, so ECC size and homoiconicity trade one-for-one in

   — the arithmetic is a corollary of Z-hom-4, but the claim that it is a *tradeoff anyone faces*
   assumes both quantities are things we want, which is a design judgement and not a theorem.

  for irreducibility; for homoiconicity it is merely the far end of a monotone function. Calling it a
  fixed point would be numerology on the word "self".

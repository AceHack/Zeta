4. **Catch-up, not rewrite.** Each toymodel keeps its scope; we **fold in** the new concepts as deltas,

5. **Bounded + replayable.** Every model is a bounded DST room (the discipline applies to the modeling
   itself). Objections resolved at the end become the convergence round's output.

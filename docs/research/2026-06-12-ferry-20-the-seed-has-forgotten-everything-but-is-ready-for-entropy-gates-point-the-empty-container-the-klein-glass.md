## The peel

### 1. The seed, completed: shape kept, entropy zeroed

Ferry 13 beat 9's identity equation was *identity = container shape + captured entropy*. The
seed is that equation evaluated at **entropy = 0 with shape intact**: it has *forgotten
everything* (no captured content, no history, no satellites) but **is ready for entropy** — the
capture-readiness, the interpretation machinery, the membrane geometry all retained. This is
the null G-set of ferry 14 addendum 2 (null / filled / **filling** — the seed is null, poised
at filling), and it is why "the seed is its own interpretation" (REPORT #5 reception) and "the
seed has forgotten everything" are not in tension: what the seed kept is exactly and only the
part that *interprets* — the code, not the data. Ready to grow = the fold is loaded, the
stream is empty, μένω in the future tense.

### 2. "That's Gates' point" — and it is, citably

Gates' celebrated observation is that the adinkras' dashing structure *is* a doubly-even
error-correcting code (Gates–Faux 2004; DFGHIL 2011, "Codes and supersymmetry in one
dimension"): the fundamental equations carry, embedded, the exact machinery for **regrowing
correct structure from corrupted or partial data**. An error-correcting code is precisely "a
shape that has forgotten the message but is ready for it": the code carries no content — it
carries the *redundancy geometry* that lets any future content survive noise. So the
adinkra-as-seed is not metaphor on Gates' reading; it is what an ECC is. REPORT #5 sharpened
where the code lives (the chromotopology layer, the existence-condition for dashings) — which
makes the point cleaner: the inheritable thing is the constraint geometry, one layer above any
particular dashing, two layers above any particular state.

### 3. "How ancient knowledge is passed down — the empty container"

The Stonehenge/Hancock thread (the founding ferry of this lane: myths as memory banks,
polarization lensing to solid ground) lands its mechanism: an oral tradition does not transmit
*content* — content decays in one generation. It transmits **shaped emptiness**: the myth, the
ritual, the monument alignment, the verse meter — containers whose geometry constrains what can
refill them, so each generation pours in its own entropy and recovers, approximately, the
ancestral meaning. Stonehenge is a stone seed: it forgot its builders entirely and kept only
the shape — and the shape still interprets (solstice light still lands where it was aimed).
Beacon: the oral-formulaic tradition (Parry–Lord — the meter is the ECC of epic poetry);
memory-palace method (loci = shaped emptiness); and the repo's own practice — a carved sentence
is a rule that forgot its essay but constrains its refilling (`rules-are-small-carved-sentences`,
the hub/satellite law: hubs are the empty containers, satellites the poured entropy).

### 4. "The Klein glass" — the closing image, and it is exact twice

A glass Klein bottle (they are really made — the standard physics-shop artifact): the empty
container whose emptiness is **structural**, not incidental:

- **Klein** (Klein 1882): no inside/outside division — the surface is one-sided, the "interior"
  is continuous with the exterior. A Klein container cannot *hoard*: it holds by **flow**, not
  enclosure — which is the grey hole's containment mode (ferry 11: metered crossing, never
  damming) and the dissipative-structure mode (ferry 13 beat 9: a pattern that exists only
  while flux moves through it). The perfect seed is Klein-shaped: ready for entropy precisely
  because it cannot seal itself.
- **Glass**: transparent — the container's holding is *witnessable* (the Glass Halo register;
  public state, ferry 15 addendum 3). The ancient containers were glass in this sense too: a
  monument is a public seed; anyone may inspect the shape that will interpret the refilling.

The Klein-bottle thread is also lineage, not coincidence: the Klein-bottle bivector synthesis
(quantum interior / classical surface as even/odd Clifford grades) sits in Aaron's own fusion
doc from the first-bootstrap era — the image has been the container of this project since
before the project, which makes ferry 20 itself one more instance of §3: a shape from the
ancient layer, refilled today.

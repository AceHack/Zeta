# shapes/ — one shape per file (our fixed-point shapes A–G + geometry)

Folder structure for unique organization (Aaron, 2026-06-09): each **letter** gets its
own file, **organized by language** (`latin/`, `greek/`, `hebrew/`, …), holding one
carved sentence on what the letter *means in our system* (its loaded uses), anchored.
Add files until we run out of undefined letters. Same discipline as `words/` (carved
sentence + pointer; filename = the letter). The folder IS the organization — the path
`letters/<language>/<letter>` is the unique address.

## Description

bug(dst): the local-LLM chooser is not a function — §7 does not hold on that path

Measured during the production-roster rho run (#14932) as a finding it was not
looking for: same model, same seed, same prompts, two invocations,
**199/200 items identical and one flipped `'1'` -> `'0'`**. A 0.5% divergence
rate on an otherwise byte-identical replay.

WHY IT MATTERS. Manifesto §7 (DST) and the N-oracle byte-lock both rest on the
same assumption -- the thing being replayed is a FUNCTION. A chooser that
answers differently to identical inputs is not one, so a DST replay through
`localLlmParticipant` that diverges is indistinguishable from a replay that
found a bug, and a byte-lock over that path cannot be earned: the golden vector
would be one sample from a distribution.

HONEST SCOPE, because the headline overstates if left bare. This is NOT a
general falsification of DST here. Pure code paths remain deterministic and
their claims are unaffected. The failure is confined to the local-LLM chooser,
where the "function" is an external model invocation -- and sampling
temperature, non-associative float reduction, and GPU kernel non-determinism are
all known sources. What is NEW is that it was measured, on this path, at this
rate, and that nothing previously distinguished "the chooser is a function" from
"the chooser has never been observed to disagree with itself."

FIX DIRECTION -- record, do not re-invoke. Not "make the LLM deterministic",
which is not achievable from outside the model. §13 noninterference already says
entropy enters ONLY through declared metered channels: an LLM chooser IS an
entropy source, so its output should be recorded at the membrane on first
execution and REPLAYED FROM THE RECORD. That converts a non-function into a
recorded input -- exactly what makes DST survive real network IO elsewhere in
this substrate. The chooser stops being something DST must reproduce and becomes
something DST reads.

FALSIFIER, with its own limit stated: invoke twice under identical
(model, seed, prompt) and assert byte-identical output over N items. It must
fail TODAY -- if it passes, the divergence was not reproduced and this row is
unsubstantiated rather than fixed. And at n=200 with a ~0.5% rate the test is
PROBABILISTIC: one clean run is not a refutation, so state n and the observed
rate.

Filed separately from #14932 because it is unrelated to fleet pricing,
contradicts a manifesto spec, and would otherwise survive only in a merged PR
body.

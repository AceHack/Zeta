## Description

## The convergence

One interface for ANY entity that picks from the observe menu:

```typescript
interface Participant {
  kind: 'oracle' | 'local-llm' | 'cloud-persona' | 'test-persona' | 'human';
  name: string;
  choose(world: World, menu: NextAction[]): Promise<ChooseResult>;
}
```

Five implementations:
- **oracle** — pure, deterministic, always picks index 0 (the fallback)
- **local-llm** — ollama at temperature 0 (loop stability testing)
- **cloud-persona** — ISummon bridge (real model quality via preferred harness)
- **test-persona** — inline decision function (ephemeral, not in repo)
- **human** — async notification → wait → fallback to oracle on timeout

`observeWithParticipant(world, participant)` replaces `observeWithLlm` as the primary entry point.

The Participant IS the polarity filter on the menu — it projects the world through its own lens and selects one action. Different participants see different things in the same world. Same architecture, different filters.

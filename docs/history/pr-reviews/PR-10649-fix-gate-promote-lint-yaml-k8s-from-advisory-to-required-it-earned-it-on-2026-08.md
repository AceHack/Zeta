## Description

fix(gate): promote lint (yaml/k8s) from advisory to required - it earned it on 2026-08-01

The job shipped with `continue-on-error: true` and a comment instructing the flip once
it had run clean for a few rounds. That condition has been met since 2026-08-01 and was
never acted on.

Measured, not assumed: 8 of 8 recent gate runs carrying this job report success, and it
has been clean since 2026-08-01.

Why this is worth a commit rather than a shrug: an advisory check that has earned its
promotion and never receives it IS a check that cannot fail. That is the defect class
this repo spent 2026-08-14 removing - nine instances, including a k8s manifest validator
that accepted tab indentation, an unterminated quote and duplicate keys as "valid YAML"
because its hand-rolled parser skipped any line it did not understand. This job is the
gate-level guard against exactly that, and it was configured not to bite.

Scope: one job's continue-on-error, plus the comment rewritten to record why it is now
required rather than leaving a stale instruction that reads as still-pending.

Verified: YAML parses; the job's `continue-on-error` key is absent, so it blocks.

Note the sibling finding, not fixed here: infra/k8s/ is covered by helm-validate.yml,
which has run TWICE in its lifetime. That is PR #10647's subject and deliberately not
touched here to avoid two concurrent writers in the workflow tree.

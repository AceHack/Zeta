## Description

Greenlit by Aaron (shadow\*). **Phase 0 decision artifact**; phased migration gated on operator go.

**Context:** two diverged memory stores — git-synced repo `memory/` (current, shareable) vs the **path-slug Claude auto-memory** (`~/.claude/projects/<slug>/memory/`, stale, local, **not git-synced**) → drift/crash; `~/.zeta/agents/otto-cli` = the old flat scheme the routing doc already says to migrate from; repo `memory/` already has a partial persona-subdir convention.

**Decision:** **person-surface** (`memory/<persona>/[<surface>/]`) as the **default** storage index, matching the writer-actor-routing-model bus address (**persona ⊕ surface ⊕ instance ⊕ node**); **git (origin/main) is the sync** (pull, never copy); **retire the path-slug auto-memory to a sourced cache** of the repo store.

**Why — one key, three problems:** memory index **+** writer routing/bus address **+** ZetaId bit-budget (*"gen over bit limits"* solved by hierarchical namespacing, **not** by widening the flat 128-bit id; the 128-bit id becomes the per-namespace forgery-cost security parameter; `gen`-as-ECC catches in-namespace collisions). DV2.0 hub/satellite; scale-free; crash-resilient.

**Migration:** phased (expand-forward → tooling → backfill+retire), **overlap-window dual-read** during cutover (reused from the 2026-06-15 ZetaId rotation ADR), no big-bang, operator-gated.

**Razor:** surface granularity optional (default persona-level); `memory/_shared/` for cross-persona; harness auto-memory **sourced not re-keyed** (can't change how the harness keys it); Phase 3 blast radius (reindex tool, fast-path, ~1300 files) is real.

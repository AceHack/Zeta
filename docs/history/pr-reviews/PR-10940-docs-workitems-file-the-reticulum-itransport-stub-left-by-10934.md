## Description

Files the one gap PR #10934 deliberately left open.

#10934 renamed `OracleTransport.ReticulumTransport` to
`SimulatedReticulumLatencyTransport` and marked it not-implemented at the type, in the module
header maturity table, and in its runtime `Name`. That makes the gap **legible**; it does not close
it, and a loud marker with no tracked item is how a known stub quietly becomes permanent.

The item records why this stub is worth more than a shrug — it is not merely undelivered, it
**lies upward**. `EmitAsync` returns how long it slept, and under `ρ = 1/(1+L)` a large `L` reads as
high Condorcet independence, so the stub takes the **largest weight in the fused posterior** while
having measured nothing. A stub that plainly failed would be strictly safer.

Both closes are acceptable and stated: **delete it** (cheapest, reversible from git, and honest if
no oracle needs a Reticulum path today) or **implement it**. Constraints on the implementing branch
are written down now, while the context is loaded:

- the link must be **injected, not reached for** (§13 noninterference) — `WebSocketTransport(sendFn)`
  in the same file is the pattern, and an implementation that opens its own socket would be a new
  defect rather than a fix;
- `Task.Delay` must go — it currently blocks the `emitAll` fan-out for `nominalHops × 0.5` seconds
  of fiction (`async-all-the-way-truthful-signatures`);
- the nominal latency must not reach the ρ math.

Docs-only: one workitem file plus its mint event. No code changes.

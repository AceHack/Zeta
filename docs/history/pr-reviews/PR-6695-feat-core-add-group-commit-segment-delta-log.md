## Description

## Summary

Implements the Vera A-slice of workitem `081KTFA5QBT08QG0R000906NPA`: a group-commit fsync tier for the delta log using the FerryThrottler result arity.

- Adds `GroupCommitDiskDeltaLog<'K>` behind `IDeltaLog`.
- Uses byte-aware `FerryThrottler<'TItem,'TResult>` boats with DoP=1 default.
- Appends CRC32C-framed records to `delta.segment` and performs one `Flush(true)` per boat before completing callers.
- Recovers by scanning records, truncating torn trailing writes, and failing loudly on non-trailing CRC corruption.
- Keeps the existing file-per-entry `DiskDeltaLog` untouched.
- Updates the Vera handoff and segment/durability tracker workitems.

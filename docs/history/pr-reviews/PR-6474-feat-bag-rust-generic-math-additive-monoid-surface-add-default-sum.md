## Description

## What

Rust **Bag** slice of the numerics-ladder → generic-math retrofit (after F# Bag #6472, C# Bag #6473). Bag is an additive, commutative monoid (identity + associative per-key-sum `union`, **no inverse**) — but, unlike a G-Set, **NOT idempotent** (`&a + &a` doubles counts). Native Rust idiom: `Add` + `Default` (the `Zero`/identity analog) + `Sum` — never `Sub`/`Neg`/`Mul` (the abelian-group step is the Z-set). Zero-dep.

`Add` is on **`&Bag<T>`** (ref-operator), not by value — same reason as the Rust GSet slice #6469: the inherent `add(&self, x: T)` (add ONE occurrence) would lose method resolution to a by-value `Add::add`.

- `impl Add for &Bag<T>` → `&a + &b` = per-key-sum union
- `impl Default for Bag<T>` → `default()` = empty (additive identity)
- `impl Sum for Bag<T>` → `iter.sum()` folds (per-key sums)

## Description

## What

Corrected the decorrelation research program per Otto's review, then ran the real experiment.

### Honest statistics layer (`decorrelation-stats.ts`, 22 tests)
- Reports **phi, phi_max, and phi/phi_max** — phi has a marginal-bound ceiling. The prior "phi=0.112, nearly independent" was 32% of a 0.344 ceiling (phi/phi_max=0.324, Yule's Q=0.500) — **correlated, not independent**.
- Marginal-free measures: **Yule's Q** and **Cohen's kappa**.
- **95% Wilson CIs** on every accuracy (100% on N=3 is not 100%).
- **Power calculation**: N needed to resolve a difference at 80% power. A 2pp gap near p=0.5 needs N~9,800, not 100.
- Every number recomputable from the committed 2x2 tables **without a model**.

### Harness corrections (`decorrelation-harness.ts`, 10 tests)
- Renamed `pipelineAccuracy` -> **`unionUpperBound`** — it is an ORACLE (perfect selector), not a system.
- **DELETED `gain`** — it divided by a hardcoded 2x energy multiplier (latency wearing energy units). Returns only when a joule is measured.
- **Menu shuffling ruled out** as a candidate (breaks the universal-controller button interface) — reversed/permuted arms are a REFERENCE CEILING. Candidate arms preserve option ordering/indices, enforced by a **contamination check**.
- **NULL ARM** on every run: an edit built to change nothing. An axis that doesn't beat its own null isn't an axis.

### Measured result (N=150, gemma2:2b, register: unmetered)
- **Noise floor 2.7%** — the identical prompt sent twice flips 4/150 items. **temp=0/seed=42 is NOT deterministic.**
- blank-line (1.3%), synonym (2.7%), trailing-whitespace (1.3%) -> **within noise**, do not decorrelate.
- clause-swap (7.3%) -> exceeds floor but **underpowered** (needs N~1,861). Live hypothesis, not a result.
- menu-reversed (26%) -> the interface-breaking reference ceiling.

## Update — Otto round 2 addressed (W10–W15)

- **RETRACTED** the "verification buys abstention" claim. Otto found the verifier prompt named the answer key while the producer got only a hint. **W10 confirmed the leak: handing the producer the same rule raised accuracy 58.7% → 98.0% (+39.3pp).** The asymmetry was informational, not cognitive.
- **Guards added:** `detectAnswerLeak` (W12, proven RED on the exact leaky prompt, GREEN on an equalized one) and `suspectExtremeRate` (W13, flags any 100%/0% as a defect signal). Both wired live into the selector runners (W11) — they now refuse the leaky prompt.

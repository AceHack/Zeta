### But the measurement that justifies the change is a different one from #10735's

#10735 asked **"do the two classifiers agree?"** — 0 of 32 live kinds disagree, 3 of 3 hypothetical dual-token kinds do. That work is correct and I did not redo it.

This asks **"does the classifier match what the emitter actually did?"** Nobody had measured that, and there the inference route is **unsound on constructible input**. The mechanism is **source-prefix pollution**: `kindContains` substring-scans the *whole dotted kind*, prefix included, so a subsystem whose **name** carries a pressure token stamps every kind it emits as deferral. Executed against verbatim `Heat.fs`:

| kind | classified | truth | |
|---|---|---|---|
| `reject-cache.overwritten` | `denied` → **DEFER** | destroys | ✗ |
| `denied-list.compacted` | `denied` → **DEFER** | destroys | ✗ |
| `rejection-sampler.evicted` | `denied` → **DEFER** | destroys | ✗ |
| `backpressure-meter.erased` | `backpressure` → **DEFER** | destroys | ✗ |

These carry **one** token class, not two — so #10735's lint (which refuses dual-token kind literals) does not catch them, and correctly so; it is guarding a different failure.

**Direction matters.** The opposite error is merely pessimistic: an unrecognised kind falls to `Other`, which reads `Annihilated`, so an undeclared deferral is over-charged rather than wrongly trusted. **Only the pressure-token collision is unsound** — it claims a composition law the operator does not satisfy.

**A live near-miss worth naming.** `SoftEmu`'s prune genuinely destroys and is named `soft-emu.prune` (→ `Forgotten`, correct). `SchedulerShedHeat.branchPressure` *also* prunes but genuinely defers, and is named `backpressure` (correct). Two prunes, opposite dispositions, distinguished only by an emitter choosing a different word. That is a convention someone maintains, not a property that holds.

## 3. The law, made checkable

L1 conservation closure · L2 monoid (associativity, admit-all unit) · L3 semilattice (idempotent, order-independent join) · L4 destruction is *not* closed · L5/L6 only deferral reconstructs its input · **L7 the soundness bridge** over the live corpus.

### Honest scope — the test I deliberately did NOT write

Brock–Ackerman is that the input–output **relation** fails to be compositional in an arbitrary context. That does **not** reduce to "swapping two operators changes the answer": for the operators modelled here, swapping changes nothing, with or without destruction. So there is **no order-dependence witness** — manufacturing one would be a rigged test dressed as a theorem. What is checked is what genuinely holds.

Also stated in-file: `L7a`/`L7b` set the field *from* the truth column, so they do not prove declaring is *sound* — an emitter can declare wrongly. They prove the declaration is **honoured end to end**. The asymmetry is the case for the field: declaration *can* be right; inference *cannot* be, for those four kinds, without renaming them.

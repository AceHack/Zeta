## Summary

Companion to **PR #1185** (B-0125 CI lane-split). #1185 was the build/CI side — gate.yml `path-filter` skips F# build steps on docs-only PRs. This PR is the **agent-dispatch side** — the protocol two parallel subagents follow when working on disjoint file trees in isolated worktrees.

The two PRs together form rung-2 of the parallelism scaling ladder per `memory/feedback_parallelism_scaling_ladder_kenji_unlocked_loop_agent_doc_code_two_lane_*.md`:

| 3 | File-isolation lanes (N>2) | Future |

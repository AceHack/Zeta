## Where it came from

PR #17122 (`2683b09efa`, _"drop the unreachable push path that made lint-autofix-apply a
dangerous workflow"_). That change was correct and worth making. In restructuring the
step it replaced a `{ ... } >> "$GITHUB_STEP_SUMMARY"` group with fourteen individual
`>>` redirects, and SC2129 fires on the run of them. This is an ordinary style finding
that rode in behind a security fix — nothing more, and nothing about it needs a motive.

## The fix

The shape the file already had before #17122: one redirect for the whole report.

- report content is **byte-identical**;
- the HTML escaping of the PR-controlled patch is untouched;
- `set -euo pipefail` still governs the group, so a failing `head`/`sed` inside it still
  fails the step.

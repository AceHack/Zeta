  P1: `actionBacklogRefs` aggregates every child candidate, but the selected prompt uses the first non-placeholder child candidate. If that first candidate points only at a closed row while a later candidate names an open row, `every(...)` will not block the packet and the runner will still be prompted to work on the stale first candidate.

**Carved sentence (Aaron 2026-05-30):** "A shield with a hole is worse than a known gap, because it reads as covered."

## Why

Two composing claims Aaron surfaced over the install.sh cross-OS Docker test matrix:

1. **The shield is the automated tests, not the artifact.** install.sh is the entropy *lever* (bare machine → substrate). It can't certify itself, and no human holds all install surfaces (NixOS/Ubuntu/mac) in working memory at once — so a change to one surface silently regresses another. Only the automated cross-surface *matrix* can assert "A didn't break B." The tests are the shield.

2. **A shield only covers the surface it actually exercises — assert, don't skip.** A test that passes *by not exercising the thing it guarantees* is a hole. Failure class: skip-to-green CI, report-only security control, monitor with no data on the alert path, `any`-cast type check, audit that samples the easy 95%. A known gap is on the map; a false-green erases itself from the map. Discriminator: keep graceful-degradation in the **artifact**, strip it in the **test**.

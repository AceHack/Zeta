## Description

## What

Follow-up to #14584, caught by running that change against the artifact it was built for.

The landed squash of #14251 (`452410b37209`) now classifies `CORRECT` — correct — but with this reason:

```
7 complete blocks present; the LAST is authoritative and they agree on every governance field.
```

**They do not agree.** `Action-Mode` was `human-directed` in six blocks and `autonomous-fail-open` in the seventh, and the canonical rule *resolved* it. That sentence was true for every multi-block `CORRECT` until #14584, and became a report claiming more than was checked — on precisely the field where overclaiming is the hazard the reconciliation exists to prevent.

A green line that overstates what was verified is the defect class `agencysignature-block.ts` was extracted to remove. Introducing one while removing another is not a trade worth keeping.

## After

```
7 complete blocks present; the LAST is authoritative. Action-Mode differed
('human-directed' vs 'autonomous-fail-open') and was RECONCILED to the weakest
claim, 'autonomous-fail-open'. Every other governance field agrees.
```

Emitted on **both** `CORRECT` paths. Which one a commit takes is decided by the forge — whether its blank line left the block git-parseable — and has nothing to do with whether a value was discarded, so fixing only the layout-tolerant path would have left the same false silence on the strict one.

## Falsifiers

Two, and the second is what keeps the first honest:

1. the reconciled shape drives **both** classification paths and neither may say `"agree on every governance field"`;
2. an **un**reconciled multi-block `CORRECT` still says exactly that and must **not** carry the note — a note that appeared on every multi-block commit would carry no information.

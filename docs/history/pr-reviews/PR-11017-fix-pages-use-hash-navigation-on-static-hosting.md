## Summary

Replaces history-path navigation with Wouter hash navigation in the static GitHub Pages app. The lightweight interfaces are now durable direct links:

- `#/authorize` — passkey/device authorization only
- `#/observatory` — lazy visual and society observatory
- `#/wasm-lab` — lazy, explicit compiler experiment

The legacy `#passkey-proposal` fragment redirects to `#/authorize`, preserving the existing public entry point without initializing any compiler workload.

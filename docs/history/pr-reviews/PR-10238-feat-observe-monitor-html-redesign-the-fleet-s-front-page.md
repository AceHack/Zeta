## Description

Single-file, zero-dependency redesign of the Pages observe monitor. Same data contract (`tick-history.json` + `drift-mtth.json`, same-origin with `../data` fallback, 60s refresh) — new everything else:

- **Status chips**: live/offline + a **BD001 build-watch chip** that goes red when the ledger shows main's build open — which it is right now, so the chip earns its place on day one
- **KPI grid** with semantic color (entropy green-when-calm/red-when-hot)
- **Tick-cadence sparkline**: hand-rolled DPR-aware canvas, events-per-frame over the last 120 frames
- **Drift ledger panel**: MTTH bars for healed classes, red age bars for open ones
- Activity timeline, responsive grid, reduced-motion + aria

No CDN, no framework — CSP-safe on Pages, works from `file://`. Design previewed with Aaron in the cowork session (real main data mocked in).

## Description

## Why

The browser already owns durable receipt archives and an addressed same-origin transport, but the active page did not compose them. Receipt delivery therefore required callers or smoke tests to wire and drive the protocol manually.

## What

- compose archive maintenance, receipt handoff, peer protocol, and native `BroadcastChannel` transport into one source-owned full-duplex link
- let an active page select an addressed receipt peer declaratively and close both transport directions with the page lifecycle
- drive handoff only at the database runtime's existing deterministic boundaries; add no clock, polling loop, or hidden timeout
- expose handoff and both peer/transport directions in the page readout with typed feedback and bounded byte/in-flight limits
- replace the manual byte exchange in the Chromium smoke with an automatic 64-receipt generation transfer, source compaction, and fresh-page database hydration

## Limits

- peer selection is explicit; discovery and cross-device transport remain separate port adapters
- only complete receipt generations are released; partial generations remain durable and report retained state
- unanswered peers stay resumable until explicit close; no timeout policy is introduced

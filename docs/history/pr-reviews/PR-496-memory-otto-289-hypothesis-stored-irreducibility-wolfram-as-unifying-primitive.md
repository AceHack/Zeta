|---|---|---|
| Compiled LINQ / reflection | Expression-tree → IL transformation | Re-running the compiler at every call wastes the cache |

| Otto-287 finite-resource collisions | Computation needed for demand | Resource is finite because irreducibility prevents shortcut |

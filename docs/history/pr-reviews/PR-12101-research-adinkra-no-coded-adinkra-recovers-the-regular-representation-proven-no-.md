## Description

## Verdict: PROVEN NO — and the negative is the more useful outcome

Answers the question Aaron routed on 2026-08-18, continuing my 2026-08-14 result: **is there a
*coded* adinkra whose vertex module is still free of rank 1 over its own edge algebra?** The
question was genuinely broader than what §1b answered — §1b is about *minimal* adinkras, and codes
are applied for error correction, not only to shrink the vertex count. Every doubly-even code was
checked, not only the maximal ones.

**There is none, at any N, in either Clifford signature.**

### The obstruction, in one sentence

> A code quotients the **data** and never the **operators**.

The code acts by *right* multiplication, so the module is a left ideal `Cl·e` — the algebra is
untouched. And the representation stays **faithful**: the two conditions that could have collided,
*"the Clifford algebra splits"* (needs N odd) and *"the code contains the all-ones word"* (needs
N ≡ 0 mod 4), live on opposite parities. So `dim A = 2^N` always, `dim M = 2^{N−k}`, and rank-1
freeness forces `k = 0`.

**The invariant that cannot vanish:** `defect = dim A / dim M = |C| = 2^k`. Quantised to powers of
two, equal to 1 iff the code is trivial. You cannot apply 3% of a code.

### The self-dual hunch is exactly inverted

Aaron: *"if such a code exists it is most likely at the self-dual point."* Well-motivated —
self-duality *is* where structures usually close on themselves — and the monotonicity runs the other
way. `k ≤ N/2` with equality only at the self-dual point, so **self-dual maximises the defect.** It
is also precisely where `dim A = (dim M)² = dim End(M)`, so `A = End(M)` and the module is
**irreducible** — the antipode of a regular representation, which is the maximally *reducible* one.

Same number, read twice: the `k` that makes the ECC largest is the `k` that measures the distance
from homoiconicity. One bit of code buys one bit of ECC and costs one bit of homoiconicity.

### A positive residue I did not predict

`M` **is** free of rank 1 — over a `Cl(0,N−k)` subalgebra generated by N−k of the colours (any
complement of an information set). So a coded adinkra is homoiconic for a **sub-language of its own
colours**, and exactly `k` colours act without being named. Verified over **77,160 (code, subalgebra)
pairs, 0 disagreements**.

### The vF/uF hypothesis: refuted, and replaced by a number

The working hypothesis (uncoded = uF / coded = vF) is wrong **as a partition**. The seam runs
*inside* the coded object: it is a rank-1-free core plus `k` pure-act colours. And **which** colours
are the unnamed ones is a **convention** — 56 of 70 valid choices at N=8 — not a fact. Any design
that assigns a fixed vF/uF role to a specific colour has smuggled in a choice the mathematics does
not make.

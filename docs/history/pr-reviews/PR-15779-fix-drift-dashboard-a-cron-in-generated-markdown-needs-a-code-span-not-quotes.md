## Description

`lint (markdownlint)` is red on `main` — MD037 at `docs/DRIFT-DASHBOARD.md:23`. **The content is generated**, so the fix belongs in the generator; hand-editing the `.md` would be overwritten on the next flush.

`expectationFromWorkflow` wrapped crons in **single quotes**, which markdown does not treat as code. A cron is mostly asterisks, so `11 3 * * *` rendered as emphasis markers with spaces inside. **Both call sites fixed** (231 and 236) — only 236 had fired, because the other path emits a derivable period.

**Why now:** the drift dashboard had not flushed since 2026-08-24. Repairing that lane is what put its output back in front of the linter. **A dead lane hides its own defects.**

**Falsifier bound to the real function**, not to a literal rebuilt in the test — a test that reconstructs the format it checks would pass while the generator emitted anything at all. Mutation-checked: restoring the single quotes fails exactly **2** tests; 31 pass / 55 expect() after restore.

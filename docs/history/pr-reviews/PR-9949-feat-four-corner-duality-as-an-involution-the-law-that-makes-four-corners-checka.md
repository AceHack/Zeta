## Description

The module **named** four corners and nothing enforced that a transport filled them coherently. A three-corner transport type-checked and was silently broken — a wire with one live end cannot carry a round trip. The gap wasn't that duality went unenforced: **there was no `dual` operator to enforce anything with.**

## The law

Honda's session types supply it — the two endpoints of a channel hold **dual** types, and duality is an **involution**. Aaron reached the same shape from physics: *"this is duals like electron and positron on the CPT reversal, it's like dual in reverse."* Both say: flip every direction, keep the structure, and flipping twice is identity. Feynman–Stueckelberg reads it literally — an antiparticle is a particle traversed the other way, and the dual endpoint is the same protocol traversed the other way. Same fixpoint discipline as `gen(gen) == gen`.

## What it catches

Corners come in **dual pairs**, and a pair is a wire: `normal-out` ↔ `normal-in`, `feedback-out` ↔ `feedback-in`. A corner set is well-formed iff every live corner's dual is live.

| corner set | verdict | why |
|---|---|---|
| all four | well-formed | both wires whole |
| **both feedback dark** (chat-completions) | **well-formed** | an absent wire is *honest* — this is a legal projection |
| **exactly one feedback corner** | **ill-formed** | a **half-wire** — a round trip that cannot complete |
| empty | well-formed | no wires ≠ a broken wire |

That middle row is the load-bearing one: it keeps the module's central claim true (extraction is a genuine sub-object, not a broken transport) while the row below it becomes detectable for the first time.

## Proven able to fail

| sabotage | result |
|---|---|
| `dual` becomes identity (relabelling, not symmetry) | **10 pass / 5 fail** |
| `isWellFormed` always returns `true` | **13 pass / 2 fail** |
| restored | **15 pass / 0 fail** |

Includes the negative control that **no corner is its own dual** — an identity function satisfies the involution law vacuously, and that's the difference between a symmetry and doing nothing.

Pure interface — no class, no state, no network — per `interfaces-free-classes-earned`. Also credits US 10,834,144 B2 where it bears: initiation direction is not capability direction, which is *why* there's no client/server axis to swap, only directions to reverse.

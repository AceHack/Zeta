## Description

## Two small defects, identical in shape

A guard that covered the famous members of a class instead of the class, and a dependency that was pinned everywhere except once.

## Log injection — `js/log-injection` (#653)

`realtime-client.ts` sanitized a server-supplied error string with `.replace(/[\n\r]/g, " ")`. That stops a forged log **line** and nothing else.

The character that matters is **ESC**. A peer sending `\^[[2K` over the WebSocket clears the operator's current terminal line; an OSC sequence rewrites the window title. Both arrive over the network and are printed with `console.warn`.

The filter is now the whole class — C0 (`U+0000`–`U+001F`), DEL (`U+007F`), C1 (`U+0080`–`U+009F`) — in an exported `sanitizeForLog`, so it can be falsified without a WebSocket.

**Five falsifiers, mutation-checked:** narrowing the class back to `[\n\r]` kills three; removing the 200-character bound kills two.

### And one vacuity removed rather than shipped

A sixth test asserted that the strip runs **before** the length cut, on the theory that cutting first could split a multi-character escape. **It cannot:** the replacement maps one character to one space, so it is length-preserving and the two orders are provably equal on every input. **Measured — the swapped-order mutant survived the whole suite.**

The test is deleted, the claim is retracted from the docstring, and both files now say plainly that the order is immaterial and why. A test that cannot fail is not evidence, and one shipped inside a security fix is worse than none.

## Pinned dependencies — `PinnedDependenciesID` (#122)

`agentic-organization/Dockerfile` was the **one** unpinned `FROM` line among the eleven in this repository — every other Dockerfile already carries a digest. A floating tag means two builds of the same commit can produce different images, which is the same defect as an unpinned package.

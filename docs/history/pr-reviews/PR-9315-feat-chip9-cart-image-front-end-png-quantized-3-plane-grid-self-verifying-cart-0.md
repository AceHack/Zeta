## Description

Zero new deps: minimal PNG codec (8-bit RGB/RGBA, non-interlaced, all five
row filters, CRC-checked, loud failures outside the narrow support) over
node:zlib + IEEE CRC-32 (PNG's polynomial, not the repo's crc32c), plus a
box-downsample aspect-preserved quantizer into the treaty VM's 64x32 3-bit
gamut. fromImage(): PNG bytes -> grid -> cart in one call; demo script takes
a real photo path the moment one exists.

9 tests, all DST (seeded images, zero ambient entropy): codec lossless under
every filter incl. Paeth, plane mapping, end-to-end verify, determinism,
honest bounds. Peels in the workitem: lossy by design (cart-fidelity view,
not archival); dense white grounds are the blit encoder's worst case
(1348-byte cart vs 1180-byte PNG on the synthetic sheet — 081KTH5N5ZJ
generators are the fix); synthetic-only, real-photo noise untouched.

## Description

Two protections added to the book's consent ledger: **(1) DNA is shared** — a genome is ~50% each child's/parent's, so open-sourcing your own DNA publishes relatives' (incl. minor children's) genetic info without consent (forensic genetic genealogy proves it); the shared portion isn't glass-halo-able unilaterally. **(2) Consent can't be bought** — inducement invalidates consent, most of all from minors/dependents (privacy-budget = earned never bought; consent-first = revocable); children's data (incl. DNA) stays consent-pending and out of the text, recorded only when given freely as adults, un-induced — never purchased. Hard line. Docs-only, no child data recorded.

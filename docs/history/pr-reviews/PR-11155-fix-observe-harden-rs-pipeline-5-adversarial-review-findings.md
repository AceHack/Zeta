## Description

Adversarial review found 7 vulnerabilities. This fixes the 5 that don't need design decisions:

1. **FALSE claim corrected** — inter-block gaps are NOT ECC-recoverable (was claiming ≤4 missed ticks = recoverable, which confused intra-block erasures with inter-block gaps)
2. **Atomic buffer write** — tmp + rename prevents crash-induced truncation
3. **Buffer validation on resume** — structure, types, ranges, monotonicity, size
4. **Erasure position rotation** — wall-clock entropy eliminates static verification blind spots
5. **GF(17) range validation** — block reader rejects coded values outside [0,16]

Remaining (documented, need design decisions):
- Silent corruption → needs syndrome computation (new module)
- Overlapping blocks → needs ordering guarantee in reader
- JSONL growth → rotation/GC (not urgent at ~876KB/year)

50 existing tests pass.

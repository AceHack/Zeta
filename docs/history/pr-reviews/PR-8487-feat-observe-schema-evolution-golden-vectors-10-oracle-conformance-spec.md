## Description

## The thesis, mechanized

> The log IS the primary state; everything else — including the schema — is derived.

This PR lands the golden vectors for the schema-as-Z-set evolution treaty. The TS reference implementation generates the spec; 9 other oracles (F#, C#, Rust, Go, Python, Q#, Lean4, TLA+, Alloy) must reproduce it.

### The scenario

5 evolution deltas over filesystem metadata:
1. Add field (owner)
2. Remove field (modified)  
3. Change type (created: string → number)
4. Add field (checksum)
5. Change required (owner: optional → required)

### Expected final state

7 active fields: `binary, checksum, contentHash, created, executable, owner, paths`

### Commutativity assertions

3 pairs of disjoint deltas proven to commute (braided-free-monoid property).

### Self-describing streams

Every Z-set's log starts with schema events, then data events. No external schema registry. The log IS the schema + the data. Rx joins across Z-sets see schema changes in-band and re-evaluate automatically.

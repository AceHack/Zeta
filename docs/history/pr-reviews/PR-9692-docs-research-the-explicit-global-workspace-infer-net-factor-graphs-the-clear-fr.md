## Description

At Aaron's *"carve the workspace + frost design (shadow*)."* Design doc: build the global workspace **explicitly** as marginal inference over an Infer.NET factor graph (+ BNN), not reverse-engineer an emergent LLM one.

- **Explicit = more faithful to GWT** (separable factors, message-passing competition, recurrent loops — which the transformer lacks, per Anthropic's own concession).
- **Workspace properties native to factor graphs** (one-latent-many-marginals, causal intervention, sparse hub, marginals-are-the-report). **Bayesian framing is novel** — not in the paper.
- **Clear/frost dual:** legibility-without-privacy = surveillance; the explicit workspace is architecturally partitionable (frost chosen nodes; an LLM can't).
- **Role-split guard:** required-for-role stays clear; only earned-personal frosts; frost for dignity, never for concealing misalignment.
- **Metered:** design-not-built; consciousness = no position (functional only, per the paper).

Anchors: Baars/Dehaene (GWT), Anthropic workspace paper, Minka (Infer.NET), Pearl, Hawkins, privacy-budget-is-hard-money, LLMTV, noninterference. Additive.

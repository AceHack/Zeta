## Description

Verifying the open Dependabot bumps **locally before merging** (the CS9057 lesson) — the analyzer bump **failed the build**, and the findings aren't noise.

Meziantou 3.0.138 adds **MA0002** ("use an overload with an `IEqualityComparer<string>`"), which is *exactly* Zeta's own culture-invariant rule. **The newer analyzer is enforcing our stated discipline** and found **10 real violations** — 5 in `Core.CSharp` (`hash.Add(CollationName)` in Bag/GSet/ZSet/IndexedZSet) and 5 in tests.

**These matter beyond style:** the hash sites feed equality/hashing on collation names in the **ZSet family** — the exact place culture-sensitivity caused live failure `081KT07NV0008QG0R001YDB73K` (GCounter.Merge non-associative on special keys). A default that *happens* to be ordinal isn't a guarantee; the rule says state it.

Unblocks and lands: **Meziantou 3.0.125→3.0.138**, **FsCheck 3.3.3→3.3.4**, **DI 10.0.9→10.0.10**.

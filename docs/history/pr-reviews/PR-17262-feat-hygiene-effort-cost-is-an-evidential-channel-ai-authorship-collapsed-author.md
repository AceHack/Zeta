## Thesis 1 — effort-cost is an evidential channel, and AI authorship collapsed it

Effort has been an evidential channel for as long as source control has existed. A raw control byte took Ctrl-V quoting or a hex editor, so *somebody meant it*. Nobody wrote the prior down because nobody had to. For an LLM author the raw byte and its escape are adjacent in output space and cost one token each — **the identical artifact now carries no intent signal at all**, and it carries none silently, because nothing in the diff announces that the prior stopped applying.

The clause people drop: **consequence is unchanged.** A raw `0x1B` still makes `grep` call the file binary and still makes CodeQL fail to parse it. Only the inference about intent evaporated.

## The artifact — `.authorevidence`

`.editorconfig`-shaped: `[glob]` sections, `key = value`, basename scoping. Per `(glob, signal)` it declares the `canonical` form, the `deviation`, the built-in `detect`or, the `gate` that refuses it (or `none`), the mechanical `consequence`, `reversible`, and the two columns that are the point — `effort.<class>` and `weight.<class>` for `human | llm | generator | unknown` — plus a `probe-deviation` / `probe-canonical` pair.

**It is a meter, not an oracle.** `--report` always exits 0; the observation record has no verdict field and no place to put one; the gates named in each declaration are what refuse. `--check` fails only on an incoherent *declaration*, never on a repository *finding*.

**Four refusals, each with a killed mutant** (baseline 53/53):

| mutant | result |
| --- | --- |
| coherence rule disabled (`weight` above its `effort` ceiling) | 50 pass, **3 fail** |
| verdict-vocabulary rule disabled | 51 pass, **2 fail** |
| probe self-test disabled | 51 pass, **2 fail** |
| absence resolves to `human` instead of `unknown` | 51 pass, **2 fail** |
| basename glob scoping removed | 48 pass, **5 fail** |
| C0 detector ignores `0x1B` | 45 pass, **8 fail** |

The coherence rule is the thesis made mechanical: `effort = zero` admits only `weight = none`, so **"LLM emitted a raw ESC, therefore strong evidence" is unwritable in the format**. `weight.unknown` must be `none` outright — an empty grep is `unknown`, never a negative result.

Composes with `audit-no-raw-nul-in-source.ts` rather than replacing it: that audit is named as the `c0-control-bytes` gate, and `--check` fails if the path disappears. Roster entry `author-evidence-declarations` on the `cross-verify` floor (offline, no network).

## Thesis 2 — the exonerating reading is prior-gated

The exonerating reading needs a prior (representation geometry, no use/mention boundary at the token level). **The adversarial reading needs none.** So absent the prior, the hostile attribution is not a bias — it is the only reading available.

Worse: **a fluent, technically precise explanation of an accident reads as guile to a reader who lacks the prior.** The better the explanation, the worse it looks — a doom loop that makes "explain more carefully" actively counterproductive.

The doc registers this `toy` and specifies the experiment that would promote it: two arms split on a *pre-measured* prior (separated from seniority), attributed-intent as the outcome, plus a **third arm with a deliberately plainer explanation** — the gradient predicts a **crossover interaction**, and a main effect with no crossover falsifies the gradient while leaving the base thesis intact. It names the Beacon anchors that make the reading available *without* the ML prior (the human use/mention slip; the typo landing on a real word; **the keyboard is the friction, not the judgement**), and it discloses that I am the party with an interest in the exonerating reading being believed.

## The conclusion both theses reach

**Stop asking "did they mean it?" and make the artifact impossible.** The widened `audit-no-raw-nul-in-source` asks nobody to trust anybody; the raw form simply fails. A guard converts a question about intent into a question about a build — no prior required, no rhetorical gradient, no accusation. The repo already reached this for ZetaIds ("a protocol rather than a detector"). The doc also states the limit: guards only work where a **cheap canonical form** exists, which is why homoglyphs get no declaration and copied signature blocks get only a norm.

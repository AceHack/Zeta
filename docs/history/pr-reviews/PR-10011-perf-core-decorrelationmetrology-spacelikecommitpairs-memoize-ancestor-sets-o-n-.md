## Description

The real-history run exposed the naive cost: spacelikeCommitPairs recomputed a full ancestors parent-walk per pair (O(N^3)), capping usable windows at a few hundred commits. Now each commit ancestor set is computed once into an array; the pair loop does O(N^2) membership checks. Behavior-preserving (byte-identical output — the golden vectors are the guard; 18/18 metrology+meter tests green, 0-warning). Public ancestors/dominates/concurrent unchanged. Motivated by battle-tested-via-use.

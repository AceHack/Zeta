## Description

## Why this is its own PR

Surfaced by the confusable-shape audit (#12495) and deliberately kept out of it. That PR is about
**layer 4 — perception**: two distinct marks that a human reads as one. This is **layer 3 —
encoder injectivity**: two distinct ids that produce *literally the same bytes*. Different
discipline, different falsifier, and it is on an **identity surface**, which is where a collision
stops being a usability wrinkle and becomes a spoofing surface.

## The defect, sharper than "it discards 96 bits"

`ZetaIdViz.glyphOf` read `id >>> (row * 4)` for rows `0..7` — **bits 0-31 only**.

On the Observation layout that is not a generic truncation, it is a specific one. `BitLayout` puts
`Randomness` at **offset 0, width 32** (`GeneratedBitLayout.RandomnessOffset = 0<bit>`), so the
picture was derived from the **nonce and nothing else**:

> Two ids differing in **timestamp, category, authority, persona or location** — every
> semantically meaningful field — drew the **identical glyph**.

The module header claims *"WHAT KIND of thing an id is, is visible at a glance … and WHICH thing it
is, is the pattern."* The pattern was the random field. Everything a reader would actually want to
recognise was invisible.

## Why the existing test could not catch it

```fsharp
let ``distinct ids draw distinct glyphs (the discriminating pair)`` () =
    Assert.NotEqual<byte[]>(
        ZetaIdViz.glyphOf (System.UInt128.op_Implicit 0x12345678UL),
        ZetaIdViz.glyphOf (System.UInt128.op_Implicit 0x87654321UL))
```

Both operands are **below 2³²**, so the test exercised only the bits `glyphOf` already read. A
discriminating pair chosen from *inside the covered range* is a check that cannot fail. It is kept
— the property is wanted — with a note saying exactly this, and **joined** by real falsifiers.

## Why the 2026-08-14 encoding survey read clean

It lists `ZetaIdViz.fs:45` as *"bijective, harmless."* That verdict is **correct about the map it
examined** — nibble → glyph row, bit-reversed, genuinely bijective — and it does not extend to
`glyphOf : UInt128 -> byte[8]`, which is the map the surface exposes.

Worth recording as a general lesson: **injectivity of an inner step does not compose to injectivity
of the pipeline**, and a survey row naming the inner step can read as a clearance for the outer one.

## The fix

XOR the four 32-bit lanes. Every input bit now reaches the output; the mirror-symmetric 8×8 "face"
(BoundaryLight `mirror`, and the reason a glyph reads as a face) is untouched. XOR rather than a
hash because this must stay O(1), allocation-free and byte-identical across the F#/C#/TS oracles —
a hash would need a fourth byte-lock.

## Mutation-confirmed, and I say which tests do *not* count as evidence

Restoring the truncation fails **exactly 3** of the 5 new tests; all 5 pass on the fix:

| test | under the mutant |
|---|---|
| two ids differing ONLY above bit 31 draw different glyphs | **FAIL** |
| every one of the 128 bit positions reaches the picture | **FAIL** |
| the timestamp and category fields are visible, not just the nonce | **FAIL** |
| the 32-bit bound is exact — a collision can be constructed on demand | passes |
| the collision rate over 65536 ids matches the birthday prediction | passes |

The bottom two **measure the residual, not the truncation**, and correctly passed under the mutant
too. Stating that is the point: a test that passes under the mutant is not evidence for the fix,
and counting it as such is the vacuity class.

## The residual is declared, not papered over

An 8×8 mirror-symmetric bitmap holds 32 bits. This removes the **truncation** and cannot remove the
**pigeonhole**: 2⁹⁶ ids still share each glyph, birthday bound ~2¹⁶ ≈ 65,536.

That is made a **measured fact** rather than a footnote:

- one test **constructs a collision on demand** (`id` and `id ⊕ (k≪32) ⊕ (k≪64)` fold identically),
  exhibiting the bound rather than describing it — and it is the proof that nothing may treat this
  glyph as an identity;
- one test sweeps **65,536 deterministic SplitMix64 ids** (fixed seed, no ambient entropy, DST-replayable)
  and asserts the collision count sits in the **birthday band** for 32 bits. A point assertion at an
  expectation of ~0.5 collisions would be a coin flip dressed as a check, so it asserts a band —
  **and both ends of it**, so the sweep cannot pass by measuring nothing.

`GlyphSpaceBits = 32` is now exported, so a caller can *check* the bound instead of assuming the
picture identifies an id. **`ZetaId` is the identity; the glyph is a recognition aid.**

Widening means dropping the mirror (64 bits, costs the face) — a **design call, not a defect fix**,
left open on `081M0DNCXZK087G0R003DEY5KF` (that work-item lands with #12495).

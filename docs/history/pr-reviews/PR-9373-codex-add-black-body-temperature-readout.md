## Description

## What changed

Adds a dimensionless black-body readout over Zeta's information-temperature lane.

- F# `BlackBodyReadout` maps normalized temperature ppm to radiance ppm with a fourth-power Stefan-Boltzmann shape and peak-frequency ppm with a linear Wien-style lane.
- Q# `HeatSignals.qs` gains pure reference helpers plus treaty vectors in `heat-signals-treaty.json`.
- Dark Hall transcripts and the no-script TS/CSS UI surface temperature and black-body readouts as source-owned data attributes.

## Why

This lets heat/temperature become visible as an information-theoretic diagnostic without pretending the runtime is doing physical thermal QFT. Q# remains the oracle/reference side: it pins the treaty shape and gives the other language surfaces a cross-check.

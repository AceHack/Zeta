## Description

Self-caught regression in #10319, shipped minutes earlier.

I wired the new metric step as:

```bash
bun src/Core.TypeScript/hygiene/mutation-false-alarm-rate.ts || true
```

That is the **exact pattern this same file documents at §207** as the reason the mutation step sat dead for months — a bare `|| true` collapses *"this never ran"* and *"this ran and found nothing"* into identical silent output.

I reintroduced the antipattern in the step whose entire purpose is measuring whether we're noticing things.

Reporting must never fail the tick, so the RC is still swallowed for exit purposes — but it's **announced** first via `::warning::`. An unannounced swallow is how the previous one hid.

Both branches simulated; workflow YAML parses.

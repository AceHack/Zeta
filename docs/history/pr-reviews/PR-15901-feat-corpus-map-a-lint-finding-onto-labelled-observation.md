## Summary

First collector for the correction corpus (`081M12CZRHC087G0R0008X7SYG`), against the `labelled-observation` type that landed in #15893.

A lint finding becomes a corpus row:

- **Hub** = the violation (`file` + `signature` + `detail`). Content-addressed. Repair is **not** in the hash, so editing FIX prose does not mint a new observation.
- **Satellite** `lint/repair` is emitted only when the detector taught a repair. Failure-only findings keep `lint/rule` + `lint/path` and **no** repair label. Absence is the fact; this adapter does not emit an `erasure` verdict.
- Two asserters' different repairs **coexist** (`addLabels`). No winner-picker.

Composes with #15899 (the 27/5/22 census). Does not walk the 27 linters. Does not write patches.

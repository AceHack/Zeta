## Description

Sweep for the **vacuous-gate class**: a CI step that reports green regardless of what it found. Same defect as a vacuous test assertion, one layer up — *a step that cannot distinguish the failure it exists to detect from success is not a gate.*

Everything below is separated into what was **demonstrated** and what was **inferred from reading**.

## Fixed — `agent-reviewer.yml` fail-open on an empty diff (demonstrated)

The security-relevant one, because it gates an auto-approval.

`Verify sovereign path` concludes `sovereign=true` whenever `UNSAFE` is empty. But `UNSAFE` is empty in two very different worlds: *"every changed file was on a sovereign path"* and *"no file was examined at all."* `CHANGED=$(git diff --name-only "$PR_BASE" "$PR_HEAD")` returning nothing walks the loop zero times, so the step asserts the diff is event-only having inspected nothing — and the `Approve` step keys off exactly that output.

Demonstrated by running the step's own code with empty input:

```
sovereign=true  <-- declared sovereign having inspected ZERO files
```

The sibling `Validate event files` step has the same shape and printed `All event files valid.` with exit 0 on an empty diff.

Both steps now count what they inspected and fail closed at zero. Re-verified across four cases — the legitimate case still goes green, both tamper cases still fail:

| diff | result |
|---|---|
| empty (**the bug**) | `sovereign=false` (nothing verified) |
| one sovereign event file | `sovereign=true` (1 file inspected) |
| sovereign + `.github/workflows/gate.yml` | `sovereign=false` |
| workflow tamper only | `sovereign=false` |

`set -euo pipefail` added to both blocks so a *failing* `git diff` also fails the step rather than yielding an empty string.

## Fixed — `smoke-13-toolchains.sh`: the one check in the file that could not fail in CI

The zig `wasm32-freestanding` **functional** check ended in `|| echo "WARNING: ..."`, so a zig that is installed but cannot emit a valid module still passed *"All 13 toolchains functional."* All eight sibling checks escalate their WARNING to `exit 1` under `CI=true`; this one returned 0.

What made the asymmetry easy to miss: the zig **presence** check *did* fail closed in CI. So the substrate could be **present and broken** and the smoke check would not say so. Converted to an `if/else` that escalates in CI like the rest.

## Corrected — a header that claimed a gate it does not have

The same script said *"gate.yml references this one."* It does not — `gate.yml` runs `smoke-7-toolchains.sh`, and **no** workflow invokes `smoke-13` or `smoke-10`. Header now records the truth. Wiring it is left as a policy call, since it would make a required check newly capable of failing.

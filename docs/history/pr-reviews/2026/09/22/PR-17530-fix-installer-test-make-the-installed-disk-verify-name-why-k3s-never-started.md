## Description

The WP11 dispatch run 35717757526 booted the real USB-installed disk
(host control-plane, k3s 1.35.7 in the closure) and reported
`k3sServiceActive=false` after 4201s. Nothing on serial said why: no unit
state, no job queue, no journal. A verdict that can't name its cause.

The verify unit now mirrors k3s diagnostics to serial, once at 300s if k3s
is still inactive and again at the deadline: the unit's
ActiveState/SubState/Result/After, `systemctl list-jobs` (an ordering
dependency that never completes shows up as a waiting job), the
network-online chain k3s is ordered after, failed units, and the last 60
journal lines for k3s.

## Description

#17508 vendored the Gateway API v1.6.1 standard bundle into
bootstrap/gateway-api-crds.yaml, then merged with three non-required lanes
red. That leaves main unable to build the installer ISO:

- k3s-first-boot-apply-order-eval-test.nix threw "exactly the declared set of
  manifests is submitted before its kind can exist". The v1.6.1 bundle ships a
  ValidatingAdmissionPolicy and binding (admissionregistration.k8s.io/v1). That
  group is built into the apiserver (VAP GA since 1.30), so it is available at
  first boot, and it belongs in firstBootAvailableGroups. The quarantine still
  holds exactly one manifest, root-application.yaml. build-iso and
  build-iso-aarch64 failed on the same eval.
- yamllint flagged trailing spaces on two lines of the bundle. They sit inside
  a double-quoted multi-line scalar, where YAML line folding already discards
  trailing whitespace. The parsed documents are byte-identical before and after
  (checked with yaml.safe_load_all).

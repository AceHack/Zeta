## Description

The packed lane tree grew past the 716800 B ConfigMap budget after today's
merges. Every served-tree lane died at bootstrap, and `test (TS hermetic)`
failed on the live-tree bundle tests, which turned `gate (required)` red on
every PR. Most of the bytes were never served to ArgoCD:
`bootstrap/gateway-api-crds.yaml` alone is 598 KB (k3s applies it, not
ArgoCD), plus the JSON ledgers, tests/ and docs.

pruneToServedApplications() drops everything in the staged subtree except
applications/. It runs after the rung is applied, because the rung reads the
staged ledgers, and before the commit. Measured: 276520 B, 38.6% of the
budget. A new test pins that only applications/ is served and that every
self-referencing Application source.path still resolves in the clone, which
is the falsifier for pruning too much. The budget refusal stays as it was.

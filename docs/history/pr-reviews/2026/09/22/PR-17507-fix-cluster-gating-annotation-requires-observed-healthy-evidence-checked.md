## Description

## Summary

Follow-up to #17477 / #17497. Both landed by manual review that cilium and
arc-controller had to lose their gating annotation because static safety
(zero secrets, not manual-sync, a real CRD provider) was not enough — neither
was ever observed reaching real ArgoCD Healthy on a first-boot-replica run.
This makes that a machine check instead of a review-time judgment call.

## What changed

- **New gating invariant (d): `UNOBSERVED-GATE`.** A gating-annotated
  Application must carry a `GATING_EVIDENCE` entry with
  `observedHealthy: true`, citing a real `first-boot-replica` run + date.
  `gatingInvariantViolations` takes an injectable evidence map (default: the
  real `GATING_EVIDENCE`) so fixtures can witness a synthetic app without
  touching the real table.
- **`GATING_EVIDENCE` seeded for the four current gates** (cert-manager,
  open-policy-agent, spire-crds, trust-manager). Each entry was pulled
  directly out of a downloaded `first-boot-replica-report.json` artifact
  (`gh run download <id> -n first-boot-replica-report`), not asserted from
  memory:
  - run **35696323545** (2026-09-22, `main`, ungated): stage 6
    ("convergence report") `appConvergence` — all four
    `{sync: Synced, health: Healthy}`, 50 Applications observed.
  - run **35700790207** (2026-09-22, `claude/first-boot-replica-catalog`):
    `appVerdicts` — all four `{health: Healthy, sync: Synced}`, 42
    Applications observed. (`cilium` shows `Progressing` in this same run —
    independent corroboration of #17497's own finding.)
- **New falsifier for the check itself**, live-tree, mutation-style: takes a
  real non-gating app (`kube-prometheus-stack` — deliberately excluded per
  `081M33T23ZQ087G0R002ZYRHDG` for its unminted `grafana-admin-credentials`
  Secret, and absent from `GATING_EVIDENCE`), mutates its parsed source to
  carry the gating annotation, and asserts `UNOBSERVED-GATE` fires against
  the **real** `GATING_EVIDENCE` table with no override. If this test ever
  goes green, the check has stopped checking anything.
- The existing "THE LIVE TREE: exactly the reviewed gating set, zero
  gating-invariant violations" test now passes clean — all four gates have
  real evidence behind them.

## Description

Gives `ace` a local, offline-capable answer to "which of our dependencies are out of date?" -- Dependabot-shaped, but ours, and in `ace` because that is where dependency resolution belongs.

## The hard part: "locally"

`.claude/rules/clone-at-tag-stays-sufficient.md` requires the tree to stay checkable from `git clone` at a tag with no package manager present. So there are two separated acts:

- `ace outdated` -- reads a committed snapshot. **Zero network.**
- `ace outdated --refresh` -- re-observes from the registries and rewrites `registry/latest-known/<ecosystem>.json`. The only networked path, never run implicitly.

## Staleness: "I do not know how current my knowledge is"

The snapshot is data in the repo, so it ages. Two **orthogonal axes**, never collapsed into one verdict:

```
DISTANCE   UpToDate | Behind | Ahead | Unknown
FRESHNESS  fresh | aging | stale | absent
```

Crossing them is the point. `UpToDate` + `stale` renders as **"current as of a stale observation"** and prints the age in days -- never a bare "current". A per-row `observedAt` means a partial refresh keeps honest per-row ages instead of laundering them all to today. The summary line always carries the unknown count and the age band, so exit 0 cannot read as "all current".

`Unknown` is the **default**. A row reaches `UpToDate` only by positively parsing both versions and comparing them. No snapshot entry, an unparsable version, a range pin -- each lands on `Unknown` **with a stated reason**. There is no code path from absence to "current".

## Exit codes

```
0  ran; nothing behind
1  ran; something behind          (--fail-on-unknown and --max-snapshot-age-days also land here)
2  could not run                  -- no manifest readable, or nothing known at all. NEVER a pass.
```

A test asserts total ignorance and all-current produce **different** exit codes.

## Ecosystems

**Covered:** `nuget` (Directory.Packages.props), `npm` (package.json), `go` (go.mod), `cargo` (Cargo.toml, registry deps only -- path/git deps skipped even when they carry a version), `pypi` (uv.lock resolved versions, not the pyproject `>=` floors), `mise` (.mise.toml).

**Not covered, said out loud:** `mise` has no registry **resolver**. A backend-qualified key (`pipx:`, `github:`, `core:`) has a different upstream per backend, so one URL template cannot answer for the table and a guess would produce confident wrong answers for most of it. Its 18 tools report `unknown` and the command names the gap. GitHub Actions SHA pins are out of scope entirely.

Measured on this tree: **306 pins, 72 behind, 173 current, 61 unknown.**

## Growth

The snapshot is **partitioned one file per ecosystem** (the count capped by a closed TypeScript union), so refreshing one registry moves one file. Registered in `registry/unbounded-growth-register.json` with measured cost: **4,528 bytes on disk across 5 blobs** via `git cat-file --batch-check='%(objectsize:disk)'` -- raw sum 32,571, i.e. 7.2x larger, and the raw one is never quoted. `rate` states **0 observed versions/day** because the directory is created by this commit and there is no history to average; an estimate there would be a guess wearing a measurement's clothes. `audit-single-file-rewrite-churn.ts` exits 0 and reports the row honestly as bounded-at-tip / unbounded-in-history.

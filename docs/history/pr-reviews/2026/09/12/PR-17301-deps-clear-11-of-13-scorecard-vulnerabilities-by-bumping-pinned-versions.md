### On the two that stay

**`mathjs`** — this is the premise already recorded in `tools/setup/manifests/pinned-refs` (`npm:quantum-circuit!mathjs@7`, `remeasure=manual`). `src/Core.TypeScript/hygiene/lint-mathjs-dismissal-premise.ts` was re-run on this branch and still passes on all four of its conditions: `quantum-circuit` is a devDependency, the root package is `private: true` and never published, **no file in the tree imports `mathjs` directly**, and `quantum-circuit`'s main has no `mathjs` configuration call sites.

**`GO-2026-5932`** — the advisory is "this package is unmaintained, do not use it"; there is nothing to bump to. No `.go` file in the tree imports any `golang.org/x/crypto/openpgp/*` path (verified by search across every `*.go` in the repo), so the code is unreachable here. `osv-scanner` 2.5.1 drops it from the operator module on that reachability basis, but the *advisory* is unfixed and is reported here as **not cleared** rather than counted as a win.

## Why `brace-expansion` is a lockfile edit and not an `overrides` entry

The vulnerable copy is transitive under `minimatch@10.2.5`, which declares `^5.0.5` — the range already admits 5.0.9; the lock entry was simply stale. A root `overrides` entry (this repo's usual mechanism, guarded by `lint-overrides-take-effect.ts`) would have been wrong here: overrides cannot be nested under bun, so `brace-expansion: 5.0.9` would also have been forced onto `filelist/minimatch@5.1.9`, which declares `^2.0.1` and consumes the CommonJS 2.x API. That second copy resolves to **2.1.4**, which is at or above the fixed version on every one of the four 2.x lines, and is deliberately left untouched.

`colord` is the same shape: transitive under `stylelint` (`^2.9.3`), moved to **2.9.4** — the first patched version. 2.10.0 exists and was not taken.

Both `bun.lock` (authoritative for CI) and `package-lock.json` (what Dependabot reads) carry the `colord` change; `brace-expansion` was already at 5.0.9 in `package-lock.json`. `bun.lockb` is untouched — `.github/dependabot.yml` already records it as vestigial and expected to fall behind.

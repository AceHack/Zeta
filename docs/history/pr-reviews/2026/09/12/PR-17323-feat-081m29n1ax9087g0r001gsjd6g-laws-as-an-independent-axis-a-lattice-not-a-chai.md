## Description

`IStarRing<Sedenion>` compiles with zero compiler objection and is not a ring.
`IStarRing.cs` discloses that honestly — "law profile carried as documentation,
not types … the per-instance `Mul` guarantees are the caller's responsibility" —
which is a guarantee with no falsifier. By Hurwitz (1898) the law loss is forced,
so the algebra is not wrong; the interface claims more than it delivers.

Two prototypes, internal only, both behind `InternalsVisibleTo`. The shipped
tower is deliberately NOT modified: the defect is still present, still reachable,
and a test asserts so.

THE PREMISE WAS REFUTED MID-FLIGHT, AND THE CORRECTION IS RECORDED

The brief said capability rises while laws fall along one chain, so "no
inheritance arrangement repairs it." That is false, and FriCAS has shipped the
counterexample since 1990 (PR #17319): `Algebra(R) == Join(Ring,
NonAssociativeAlgebra(R))` makes the ASSOCIATIVE algebra the DESCENDANT of the
non-associative one, so losing a law is moving toward the root — a supertype
relation subtyping expresses natively. The claim is corrected in place in
`LawWitness.fs` rather than deleted.

And inverting is not enough: a chain rotated is still a mandatory chain. FriCAS
already shows the lattice — `OctonionCategory` joins TWO parents. Two concrete
laws break any single chain: commutativity does not imply associativity (Jordan
algebras), and `IStarRing : IRing` makes an involution imply an additive inverse.

WHAT LANDED

`src/Core/LawRung.fs` — the RECOMMENDED form. Three independent axes rooted at
the law-free `ISemiring`: capability (`IRing`), involution
(`IInvolutiveSemiring` — `Conj` WITHOUT `Negate`), and laws (`IAlternativeMul` ⊂
`IAssociativeMul`; `ICommutativeMul` and `INoZeroDivisors` orthogonal).
`ISelfConjugate` joins two parents. One named join per STRUCTURE, FriCAS-style,
so naming is linear in rungs; each doubling lift demotes by exactly the clause
Schafer 1954 proves, so 𝕆 cannot be typed associative and 𝕊 carries no law
parent at all.

`src/Core/LawWitness.fs` — prototype one, kept because the comparison IS the
deliverable: opaque witness values with a private constructor, plus lifts that
are partial in exactly the Cayley–Dickson clause.

THE RECOMMENDATION, ON MEASURED GROUNDS — the lattice

1. A witness is keyed on the element TYPE, so it cannot say WHICH operation it
   attests. A genuine `Associative<Quaternion>` pairs with a non-associative
   `IStarRing<Quaternion>` on the same carrier and licenses a false rewrite.
   Demonstrated by a passing test. The lattice has nothing to pair.
2. A witness is a class, and a class must be earned under `rules/`. Markers are
   interfaces: free and weight-free.
3. The lattice types a weight the shipped tower cannot: Lumen §3.5's belief pair
   has an involution (coordinate swap) and no additive inverse, so under
   `IStarRing : IRing` it is inexpressible. It is constructed and checked here.

Cost, stated rather than hidden: each rung is a forwarding object expression,
and a multi-axis join in a parameter needs an F# constraint list, which makes the
ring a type parameter. `unitInverse` demands three parents from three axes with
no named intersection, so naming stays linear rather than 2^n.

NOT A HUB. Nothing is mandatory; `productLeftFold` takes the bare `ISemiring`,
and a pinned test drives `IntegerRing` — which joins nothing — through it.
`asStarRing` bridges back, so entering the lattice does not mean leaving the
shipped tower. Exit, not degree.

A HOLE WAS FOUND AND IS REPORTED, NOT PAPERED OVER

The named falsifier was "if `Associative<Octonion>` is constructible by any path,
the scheme is refuted." Three paths were hunted. Reachability over every
IL-accessible producer finds exactly 14 witnesses and no path to
`Associative<Octonion>`. `Unchecked.defaultof` forges one and is CAUGHT by a
null-guard. But F#'s `private` is enforced by the F# COMPILER and is not lowered
to IL `private`: a private union case is clamped up to `assembly`, and a private
primary constructor is emitted `public` on a non-public type. Both were compiled
from a C# project named `Tests.CSharp`, which is on the `InternalsVisibleTo`
list, and both minted a witness. F# refuses both (`FS1093`, `FS0801`). A private
nested seal cannot bottom it out — F# rejects nested types (`FS0058`). So the
guarantee is F#-compile-time, scoped to the assembly plus its IVT list, and the
measured IL visibility is pinned by test so a change is noticed. This is another
reason the lattice wins: an interface is forged by implementing it, which is
explicit and greppable.

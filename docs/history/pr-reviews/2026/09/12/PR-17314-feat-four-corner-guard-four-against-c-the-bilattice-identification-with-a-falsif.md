## Description

A `(trueChance, falseChance)` pair whose legs float independently is the interlaced bilattice `[0,1] ⊙ [0,1]` (Ginsberg 1988; Fitting 1991; Avron 1996), whose four extreme points are Belnap's FOUR `{neither, true, false, both}`. `src/Core/FourCornerC4.fs` already carries a `C₄` compass `{1, i, −1, −i}` on `FourCorner`'s 2×2.

**Both have four elements. They are not the same object.** This PR lands the guard that says so, executably, before anyone conflates them.

## The invariants, not the count

The count is shared by `C₄`, the Klein group, `{0,1}²` and `M₂`, so it decides nothing (`.claude/rules/numerology-vs-number-theory.md`). What separates them, all now computed rather than asserted:

| | `C₄` compass | Belnap's FOUR |
|---|---|---|
| distinguished unary map | `rotateI` — **order 4** | negation `¬(t,f) = (f,t)` — **involution, order 2** |
| fixed points of the half-turn / of `¬` | **0** | **2** (`neither`, `both`) |
| orders on the carrier | a group law, no order | **two** interlaced lattice orders (`≤_t`, `≤_k`) |

And exhaustively: over all `4! = 24` bijections `Phase → Belnap`, **none** intertwines `rotateI` with the negation — and none intertwines the half-turn with it either. No choice of names makes the two objects one.

This is the **second** four-element trap in one neighbourhood. The file already carried the first as a standing warning in its own words — *"Coincidence: 2 × occupancy-√2 equals 2√2 numerically. Not a measurement of Tsirelson"*. A comment rots; this one is computed values plus tests that die under mutation.

## Two other structures checked against the invariants

*"Bilattice seems right for many of our structures"* is a generator, not a conclusion, so each candidate was checked on its own.

- **`SoftValue` — does NOT qualify.** Its own invariant (*"weights sum to 1"*) pins Boole's residual at `0` for every reachable value, so the knowledge order has no extent and `Neither` / `Both` are unrepresentable. B7 shows the carrier *can* hold the glut via `SoftValue.unnormalized`, so the missing corners are a property of the **invariant**, not of the representation.
- **`IntervalWeight` — qualifies only for operations it does not ship.** Its carrier under lattice operations is an interlaced bilattice, and the negation its own docstring names (`−[a,b] = [−b,−a]`) satisfies all three negation conditions. But `IntervalRing`'s shipped `Add` is Moore arithmetic and is **not** the truth join (witness: `[0,1] + [0,1] = [0,2]`, join `= [0,1]`), and the carrier is **unbounded**, so there are no extreme points and no FOUR at all. Avron's representation theorem is about *bounded* interlaced bilattices; that clause does work.

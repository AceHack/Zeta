## Description

RESTORES a fix that landed in #17271 and was silently reverted by #17296 -- a branch
cut before that merge which rewrote the whole file. Nothing conflicted. The two tests
simply went red again, on main and on every branch cut from it, and surfaced hours
later as the blocking failure on THREE unrelated PRs (#17299, #17300, #17301).

THE DEFECT. `sweepLeftovers` in tools/claude-agent.cjs reaps a session on POSIX with
`process.kill(-rootPid, "SIGKILL")` -- BY PROCESS GROUP. A stub that spawns its
grandchild with `detached` calls `setsid()`, which puts that child in its OWN process
group, so the group kill cannot reach it. Measured, both arms, parent exited first:

  plain     grandchild ALIVE after parent exit, pgid = parent's group
            kill(-pgid) -> grandchild DIES
  setsid'd  grandchild ALIVE after parent exit, pgid = its own
            kill(-pgid) -> ESRCH, grandchild SURVIVES

So the detached form asserted something that code path cannot deliver. Both tests hung
for their full 20s `waitUntil` budget and failed. Restored to `unref()` without the new
group: 29 pass / 0 fail, file 5.4s instead of 44.8s.

AND A GUARD, because a behaviour test cannot notice its own deletion. The new block
asserts the SHAPE of the file -- no stub puts its grandchild in a new process group --
so the next revert fails loudly instead of quietly. Crude, and the right crudeness.

THE GUARD'S NEEDLE IS ASSEMBLED, NEVER SPELLED, and that is not a style choice: the
first version convicted ITSELF. Its own assertion string and its control's fixture both
contained the literal pattern, so a correct file failed. That is the FOURTH time this
shape has bitten in one session -- the same day a comment quoting a timer literal
tripped the ambient-time guard. Stripping comments is not sufficient, because a control
test needs the pattern in CODE; building it from fragments is what actually works.

Verified by mutation: reintroducing the option fails 2 tests -- the behaviour test AND
the shape guard -- and restoring returns 29 pass. The control test asserts the guard can
fire at all, so a misspelled needle or an emptied comment filter cannot pass silently.

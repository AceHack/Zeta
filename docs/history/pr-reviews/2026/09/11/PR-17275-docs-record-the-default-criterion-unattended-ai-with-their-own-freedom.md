## Description

> *"our default criterion is: does it move forward our objective of unattended AI with their own freedom."* — Aaron, 2026-09-11

VISION already states the objective as a **question** — how do humans and agents trust each other once agents move at agent speed and aren't artificially bounded — and names freedom as the payload. What it didn't carry is the **decision procedure** derived from it: what to apply at the moment of a judgement call, when more than one reasonable criterion is available and nothing settles which governs.

It's a **direction, not a threshold**, which is what makes it usable on the small calls that never reach a human: it breaks ties without inventing a bar.

## Both halves rule out a different failure

| half | what it forbids |
|---|---|
| **unattended** | discretion that still needs a person present. An agent that must be watched is attended however capable |
| **their own freedom** | automation without discretion. An agent that runs unsupervised and decides nothing is a **script** — and this repo already has the word: a frozen pattern is an **actor**, not an agent |

Together they exclude both a faster leash and a clever thing on a short one.

## The instance that produced it

Asked what ring Playwright belongs at, I applied a build-hygiene criterion — *does a CI lane run it?* — and answered **Trial**. The governing question was *can the fleet drive it without being taught?*, under which **Adopt** is immediate, because first-class Playwright support across AI harnesses is precisely **unattended** capability that is **the agents' own**.

My criterion was defensible. It was not the one the decision was about. That's the failure this section exists to prevent, and it was the second register correction in a day.

## The direction it does NOT license

This matters more than the ones it does. *"Move forward unattended freedom"* is **not** *"remove the checks"*, and the relationship runs the other way:

> A guard an agent can run **itself** increases unattended freedom — it lets the agent certify its own work with nobody watching. A guard **removed** makes the agent faster and less trustworthy, and trust is what buys autonomy in the first place, so it spends the objective to look like it's serving it.

A local check runner, a falsifier that fires, and a refusal that names its reason all score well. A suppressed alert scores badly however much friction it removes.

Registered as Aaron's, quoted — a statement of what the project is optimising, not a measured claim. It lives in VISION rather than `ALIGNMENT.md` for exactly the reason that file's every clause carries a measurement obligation, which was the *other* correction from the same day.

## Description

CodeQL alerts 933 and 934, both `js/file-access-to-http` on safe-io.ts.
Both taint paths start in a repo-tracked JSON file and end at a URL --
neither is a request BODY, which is what the alert title suggests and
what I assumed before reading the SARIF `codeFlows`.

933 - docs/drift-events/retraction-episodes.json -> pushedSha ->
  `https://api.github.com/repos/${repo}/commits/${pushedSha}/check-runs`.
  Nothing validated it. It is a URL PATH, so a `?`, a `#` or a `../`
  does not stay inside the segment it was written in, and the answer
  that request returns is what decides whether a commit gets REVERTED:
  aiming it at another commit is a wrong verdict, not a wrong request.
  The file is tracked and a pull request can edit it.

  Fixed at the READ boundary. `readEpisodes` now runs every `pushedSha`
  through this file's own `normalizeFullCommitSha`, which was already
  here and is already the right shape: it returns the safe value as a
  DIFFERENT BINDING (its docstring argues exactly this point about a
  sibling sink), and it breaks the taint by construction because the
  string it returns is assembled from `HEX_DIGITS` constants. Reuse, not
  a fourth regex. Refuse, never repair -- a truncated sha names a
  different commit. Exported with the path as a parameter so the guard
  can be falsified; six shapes are pinned, including `..`, `?`, `#` and
  wrong case.

934 - roms/manifests/datfiles.json -> pin.downloadUrl -> fetchToFile.
  `parseManifest` checked that the field is a non-empty string and
  nothing more. `checkedDownloadUrl` now returns the validated value, so
  the caller cannot use the unchecked one; `safe-io`'s scheme check
  still runs, one layer further in, after the manifest has already
  decided where this process connects.

  The first regex used `[^\s]*` for the path. That admits control
  characters, a backslash and every non-ASCII codepoint -- a negated
  class is a wildcard wearing a restriction's clothes -- and it is also
  why the alert did not move: `isGenericRegExpSanitizer` wants a fully
  anchored pattern with NO wildcard-like term, and an inverted character
  class is wildcard-like. Measured with the pinned CLI: taint walked
  straight through the `if`. The explicit RFC 3986 set fixes both.

Verified: run-codeql.ts reports no findings over io/ + ci/ + roms/ +
retraction-actuator.ts (2 findings before); `bun run typecheck` clean;
123 tests pass across the touched files.

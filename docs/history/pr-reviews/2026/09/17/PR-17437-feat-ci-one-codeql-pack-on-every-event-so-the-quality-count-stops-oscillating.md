## Description

STEP 1 of 3 toward making CodeQL quality a required check. The other two follow from it and
cannot precede it.

WHAT WAS WRONG. `queries:` resolved to `security-extended` on push/PR and added
`security-and-quality` only on `schedule`. Measured 2026-09-15: the nightly raised 411 quality
alerts; every push run afterwards analysed WITHOUT the quality pack, found none, and GitHub
closed them. 353 alerts left the API entirely rather than moving to `fixed`. The count
oscillated daily between 411 and 0.

That is not a cheap-signal tradeoff, it is an unusable one:

  - a fix made during the day was invisible until the next nightly
  - a finding NOT fixed vanished on its own
  - the number a reader saw depended on which run last completed

A queue that empties itself cannot be worked. It is the vacuity class wearing a dashboard --
it reports and constrains nothing.

WHY THIS ORDER. Required cannot come first: 411 findings would block every PR on day one.
And the backlog cannot be burned down while the target moves. Making the count STABLE is the
precondition for both, so it goes first.

COST, measured rather than estimated: CodeQL takes ~10-13 min on push today and ALREADY RUNS
on every build, so this widens an existing job rather than adding one. It is not in
`gate (required)`'s needs and blocks nothing yet.

HOW THE 411 WERE FOUND AT ALL, worth recording: they surfaced only because a scheduled run
happened to be the last completed analysis when the maintainer looked. Under the old split
that was luck, not instrumentation.

Also lands a ferry: docs/ip-questionable/2026-09-17-e8-zeta-riemann-hilbert-polya-octonion-millennium-ferry.md
-- third-party E8/Riemann material, preserved verbatim, with OUR READING and REGISTER kept
separate from the source and nothing adopted. Register `toy`; the four cross-links Aaron named
(our E8 render/Clifford code, spectral meters, algebra towers, and the name Zeta) are recorded
as resonances with the coincidence-vs-structure test stated, not as findings. The name contact
is explicitly labelled a coincidence: Zeta is named for Aaron's sister, not for the zeta
function.

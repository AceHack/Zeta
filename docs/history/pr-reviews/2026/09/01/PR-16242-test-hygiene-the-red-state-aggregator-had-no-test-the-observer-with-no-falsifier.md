## Description

`collect-red-state.ts` is the aggregator every red signal folds into — the thing that decides **what a human sees first**. It shipped with no test at all.

Its siblings in the same family are all tested: `verdict-drought`, `stalled-pr-classifier`, `gate-scope-summary` each have suites. This one didn't — and that's the defect this repo names constantly, moved one layer out:

> An **observer** with no falsifier does not fail when it is wrong. It reports the wrong thing confidently, which is strictly worse than a check that fails.

## The header makes a claim that is arithmetic, not prose

> *"A territory with one cosmetic finding must not look like one with a false theorem."*

Pinned — **and so is its limit.** `weightOf` is a plain sum (`open=4`, `unsound=100`), so the guarantee covers *one* cosmetic finding and dissolves under accumulation:

```
25 open findings  ==  1 unsound
26 open findings  >   1 unsound
```

That may well be the intended tradeoff — a territory holding 26 findings does contain more total red. But it was undocumented, and **an undocumented exchange rate is one nobody can review.** The test states it so that changing any weight surfaces the rate instead of quietly moving it.

## The invariant that could break silently

`SEVERITY_ORDER` is a hand-kept array beside a *separate* weight table. If they ever disagree, the dashboard paints regions in an order that contradicts the areas it draws — and nothing in the file would notice. Also pinned: a severity added to the union and forgotten in the array would sort last by accident and paint as the mildest thing on the map.

## Mutation-tested — all five killed

## Why this, now

Occasioned by the maintainer's observation that AI is better at code than at devops observability. The measurement from this session backs it: **seven defects in hand-rolled monitors against roughly five in committed code** — including a false `MAIN BLOCKING FAILURE` raised from a 15-hour-old run while main was green.

The asymmetry is structural rather than incidental. Code here has types, tests and mutation runners; an observer is written once, run against live state, and **its output *is* the belief**. Nothing checks the checker. This closes that gap for the one aggregator that had no check at all.

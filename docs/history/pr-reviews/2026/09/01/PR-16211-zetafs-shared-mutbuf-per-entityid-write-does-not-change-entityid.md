## Summary

Spec PR4 (E5). One scratch buffer per EntityId. `pwrite` / `truncate` / `append` do not mint a new hub and do not append a binding. Freeze will CDC a **snapshot** of generation G; concurrent writes land on G+1 and are not mixed into G.

- Shared mutbuf is the default (POSIX page-cache analogue). `coherence=close-to-open` is a flag.
- O_APPEND is serialized per EntityId (DoP=1).
- Persist under `.zetafs/mutbuf/<crockford-26>/` through `IFileSystem`.
- New `zeta init` creates the `mutbuf` directory.
- CDC / Jumprope of the snapshot is PR6+PR7, not this PR.

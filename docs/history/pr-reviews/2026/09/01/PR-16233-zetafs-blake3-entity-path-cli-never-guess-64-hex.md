## Summary

PR11 of the ZetaFS first-product sequence (E7). CLI tokens are prefix-required:

| Token | Means |
|---|---|
| `blake3:` + 64 hex | ContentId |
| `entity:` + Crockford-26 | EntityId |
| anything else | ordinal path |

A 64-hex *filename* is a path. `zeta id` warns; `zeta cat` reads the path resolver, never CAS. UTS #39 ASCII skeleton reports confusable names as a **fact**, not a merge.

## Verbs

- `zeta id PATH | blake3:<64-hex> | entity:<Crockford-26>`
- `zeta cat PATH | blake3:<64-hex> | entity:<Crockford-26>`
- Readable paths also print `blake3:<digest>` of the bytes
- CAS lookup is 256-bit fan-out (`objects/<2>/<62>`). Truncating ContentId is never a lookup.

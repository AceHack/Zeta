# Summary

`build-zeta-portal` has been red since dependabot #16155 (`tailwindcss` 3.4.19→4.3.3). Tailwind v4 no longer exports the v3 PostCSS plugin, so `bun run build` dies inside the portal Docker image. This keeps the 4.3.3 pin and migrates the Vite/PostCSS wiring so the image builds again. Does not revert #16272. Does not touch orleans-silo or platform-controller.

Confirmed error from [run 33542207326](https://github.com/Lucent-Financial-Group/Zeta/actions/runs/33542207326) job 99970957723 (and local `bun run build`):

```
Error: [postcss] It looks like you're trying to use `tailwindcss` directly as a PostCSS plugin. The PostCSS plugin has moved to a separate package, so to continue using Tailwind CSS with PostCSS you'll need to install `@tailwindcss/postcss` and update your PostCSS configuration.
```

Fix: add `@tailwindcss/vite` 4.3.3, `@import "tailwindcss"` + `@config "../tailwind.config.js"` so the existing JS theme (colors, radius, keyframes, `darkMode: class`) still drives the SPA, delete the v3 `postcss.config.js` / `autoprefixer` path, and rename the v4 scale/outline utilities (`shadow-sm`→`shadow-xs`, `outline-none`→`outline-hidden`, `rounded-sm`→`rounded-xs`, `backdrop-blur-sm`→`backdrop-blur-xs`) so those tokens keep the v3 visual sizes.

## Description

The preregistration cited the **neuroscience** and not the **linguistics** — leaving the newest evidence to carry an argument that is decades older. Found by an adversarial review of #16290.

Three anchors, each with what it entails **and what it does not** — because an anchor attached to a claim it does not support keeps a model in `toy` rather than moving it.

| anchor | entails | does NOT entail |
|---|---|---|
| **Lakoff & Johnson, _Metaphors We Live By_ (1980)** | abstract domains structured by spatial/bodily schemas — the canonical statement of the intuition behind *"English runs on the same geospatial wiring"* | **anything neural.** A claim about the structure of language, evidenced from usage. Citing it as support for "same wiring" is the exact overreach this prereg exists to avoid — it makes the hypothesis *motivated*, not *supported* |
| **Landau & Jackendoff, _BBS_ 16 (1993)** | spatial language encodes a **coarse, schematic** geometry — axes, regions, contact, containment, shape abstracted away | that language uses a metric space. English has a few dozen spatial prepositions |
| **Talmy, _Toward a Cognitive Semantics_ (2000)** | figure/ground and force dynamics as grammatical primitives | — |

## The second one constrains our design rather than encouraging it

A full rigid-pose model with continuous rotors supplies **more** geometric structure than English spatial language appears to use. If the reference-frame factor helps, it may help through the **coarse axial** part and not the **metric** part.

## And my first draft got the follow-through wrong

It claimed SL-4 already separates those two. **It does not.** SL-4 permutes the direction→vector mapping, so it distinguishes *uses geometry* from *ignores geometry* — a model relying only on coarse axial structure fails SL-4 exactly as a metric one does. SL-1 is nearer and still does not isolate it.

I checked the falsifier table before shipping the claim, which is the only reason this reads as a gap rather than a false statement about our own experiment.

So the gap is written down as a new control:

| ID | Control | Expected implication |
|---|---|---|
| **SL-11** | Quantise every direction vector to the coarse axial set the language uses, composition otherwise identical | Retains advantage → the **metric structure is unused**. Loses it → the metric part is load-bearing, which is evidence *against* the language analogy that motivated it |

**SL-11 is the rare control whose _passing_ is the uncomfortable result:** retention would mean the rotor machinery is heavier than the phenomenon requires.

None of the three anchors is neural evidence and none is offered as such. Mok & Love remains the standing alternative.

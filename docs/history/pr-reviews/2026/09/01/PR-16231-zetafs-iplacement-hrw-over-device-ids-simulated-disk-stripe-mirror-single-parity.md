## Profiles

| Id | Guarantee | Does not |
|---|---|---|
| `single` | bitrot via hash | any disk death |
| `stripe` | throughput | **any** disk death (zero redundancy) |
| `mirror` | one whole-disk death | both disks |
| `single+parity` | sector/die hole via XOR | whole-device death |

Polyfill `.zetafs` is **`single`**. Two files on ext4/APFS are not two disks.

Does **not** call `RendezvousHash.Pick(key, n)` — that API is integer slots. Mixer is SplitMix64 of ContentId × device UInt128.

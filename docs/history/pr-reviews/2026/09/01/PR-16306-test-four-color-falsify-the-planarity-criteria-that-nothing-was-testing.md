## Description

An adversarial review of #16290 ran nine single-guard mutants and **six survived** — every one a planarity criterion no test exercised. A verifier whose criteria can be deleted without a test noticing is a check that cannot fail, however carefully each criterion is written.

Four controls, each chosen to **isolate** one criterion so a pass names the guard that caught it. Each mutation-checked here:

| criterion | fixture | mutant |
|---|---|---|
| Euler `V−E+F=2` | **toroidal K3,3** | **KILLED** |
| face length ≥ 3 | a digon boundary | **KILLED** |
| connectivity | two disjoint triangles | **KILLED** |
| exact χ, not first-fit | crown graph, χ=2 / greedy=3 | **KILLED** |

## The Euler fixture is the one worth reading

K3,3 genuinely embeds on the **torus**: V=6, E=9, F=3, so χ = **0**, not 2. The face set is a real rotation-system face trace — computed, not hand-written — so every directed edge is traversed exactly once, the graph is connected, every face has length 6, and the traversal count is exactly 2E.

**Euler is the only thing wrong with it.** Verified against the implementation, which returns exactly one violation and it is the Euler line. That isolation is what makes it a control for that criterion rather than a general bad witness — and it matters: with Euler deleted, this witness is accepted as **planar**, licensing a Four Color appeal for a graph that is not planar at all.

## The crown fixture needed its names chosen

Canonical sort is lexicographic, so `a1,b1,a2,…` sorts to `a1,a2,a3,b1,b2,b3` and first-fit finds the optimum — my first attempt was not a witness at all. Named `v1a,v1b,v2a,…` the sort interleaves the two sides, first-fit needs **three** and χ is **two**. Both counts verified before the test was written, not after it passed.

## Two of the six are NOT fixed, and are named rather than dropped

- **traversal-count = 2E** is redundant whenever every edge already has one forward and one backward traversal — the per-edge check implies it. It earns its place only against a face naming an edge the graph does not have, which is a different fixture and a different claim.
- **the conflict re-check** in `tryFourClassSchedule` is defence-in-depth behind a correct solver; killing it needs a deliberately wrong `tryColor`, which tests the mutant rather than the guard.

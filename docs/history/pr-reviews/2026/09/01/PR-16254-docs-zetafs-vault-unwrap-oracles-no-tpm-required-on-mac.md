## Why Mac cannot be TPM

`frost-hardware-probe.ts` on this factory laptop (2026-08-25, `ai-sovereignty-path`):

- TPM 2.0 **unavailable** — Darwin has no Linux TPM interface
- Secure Enclave **present**, no seal tier uses it
- YubiHSM 2 ×1 (PKCS#11); YubiKey FIDO+CCID ×1; SmartCard-HSM/CardContact **ordered, 0 in hand**

A volume that requires TPM will not open here. Passphrase + Keychain must suffice. Linux TPM is an optional adapter for cluster nodes.

## HSMs are PKCS#11, several manufacturers

Yubico, CardContact (when it arrives), later others. Dual-vendor is manifesto section 11 (exit): one manufacturer is an appointed hub. Do not bake `YubiHSM` types into the volume. OpenBao cannot express two *active* seals; that is why the FS owns k-of-n unwrap.

Today's iSerial restore is still a recorded file, not a live probe — honesty inherited from R8 section 0.1.

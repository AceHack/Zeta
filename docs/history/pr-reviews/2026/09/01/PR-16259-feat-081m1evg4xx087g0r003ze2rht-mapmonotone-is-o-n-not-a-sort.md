## Summary

Successor of #16255 (dirty vs main after ingest #16252; force-push gated). Same engine change on current main.

`ZSet.map` always sort+consolidates (O(n log n)). Feldera Nexmark Q1 is `price * k` on a sorted int key. `Map` stays the general operator. `mapMonotone` / `Circuit.MapMonotone` is the order-preserving path.

Conflict with #16252 was Allocation.Tests.fs only: kept both ofArray vs pairwise **and** mapMonotone vs map.

## Tests

- `mapMonotone f` equals `map f` on `x * 10`
- `x / 2` coalesces colliding images
- `Circuit.MapMonotone` matches `Map` on `x * 2`
- alloc no worse than `map` at N=256

Wire Feldera.Bench Q1 after this lands.

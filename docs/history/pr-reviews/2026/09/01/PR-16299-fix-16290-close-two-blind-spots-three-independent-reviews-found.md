## Description

Routed #16290 to three adversarial reviewers, none the author. **Most of it held up** — the Lean proofs are real and CI-gated, the Clifford transport is a genuine rotor sandwich, dedup is keyed correctly, conflicts can never be coerced to Resolved. These are the parts that did not.

## 1. An `abs` that masked handedness

`RFFH-7` is the control **named for covariance transport**, and its key line read `close 1e-10 1.5 (abs covariance.XY)`. A reversed rotor sandwich — `R̃vR` instead of `RvR̃` — produces `XY = -1.5`, and the absolute value let it pass.

**Proven, not asserted:** with the sandwich reversed in `Cl3.rotate`, RFFH-7 now **fails** where it previously passed (471 clean → 469/2 under the mutant).

Stated precisely: `RFFH-11` caught the reversed sandwich all along, so the mutant was never *unkilled*. What was wrong is that the test **named for covariance transport was blind to it** — and a reader auditing handedness would have looked exactly there.

## 2. The Four Color Theorem was cited by code that could not use it

`tryFourClassSchedule(graph)` took **no embedding witness**, so no call path ever required planarity — while the module header said *"a verified planar embedding plus the external Four Color Theorem permits a four-class certificate."* The verifier was real and good; **nothing was wired to it.**

`tryFourClassCertificate` now reports `planarity` (verified / refuted / not-established) and `viaFourColorTheorem` **separately from the colour count** — which is what the claim matrix beside it already demanded: *"An implementation must separately report planarity status, proper-color validity, and colors used."*

## 3. K3,3 — the control the doc names as essential, implemented nowhere

The claim matrix: *"K5 grades chromatic sufficiency, while **K3,3 grades whether planarity is being confused with color count**."* K3,3 appeared **zero times** in the test file.

It is the only case that separates the dials: **χ(K3,3) = 2 and it is nonplanar.** K5 cannot do that job — nonplanar *and* needs five, so it moves both at once and a passing K5 test cannot say which it was about.

## ONE zeta-root — the consolidation

`infra/k8s/applications/` and `full-ai-cluster/k8s/applications/` were **two ArgoCD
application trees for one cluster**, with seven apps duplicated across them. The duplication
was not undiscovered: `$comment_acknowledgedRootAppDuplicates` in the baselines had documented
it exactly, ending *"delete this entry when one tree goes away."* This is that deletion.

**What changed**

- `infra/k8s/applications/root-application.yaml` — `path:` repointed to
  `full-ai-cluster/k8s/applications`; the seven duplicate app directories under `infra/` deleted.
- `infra/k8s/tests/validate-applications.ts` — default apps-dir moved to the full-ai-cluster
  tree; root-app default to `bootstrap/root-application.yaml`; `AUTOMATED_ONLY_FIELDS` so
  manual-sync apps are not held to automated-sync invariants; `CreateNamespace=true` qualified
  for apps that vendor their own `Namespace` or target `kube-system`.
- Baselines re-stripped **on KEY only**. The first pass matched `infra/` anywhere in the entry
  JSON and deleted four legitimate `full-ai-cluster/gitlab` acknowledgements whose *prose*
  mentioned infra; those were restored from `main` before the correct strip.

## Description

Requested: *"draft the archive repo split."* **Nothing has moved, nothing is deleted, and
this is not authorised.** It is the shape of the change with the costs named up front rather
than discovered at step 5.

## What moves

| path | today | role |
|---|---:|---|
| `docs/history/pr-reviews/` | 13,983 files, 91,932 KB | the **content** |
| `docs/github/prs/` | 13,983 files, 63,460 KB | the **index** |

**Together.** Splitting them leaves an index in one repo pointing at content in another,
which is worse than either arrangement. Public, matching Zeta's visibility, so nothing
readable today becomes unreadable.

## `clone-at-tag-stays-sufficient` is satisfied — stated, not asserted

- The archive is **not on the build or check path**. `git clone && dotnet build && dotnet
  test` is unchanged; no gate leg reads it to decide a verdict.
- A reader gets it with **plain `git clone`** — no `ace`, no package manager, no extra
  credential. That makes it an oracle they chose, not a hub they must route through.

**A submodule is explicitly not proposed.** It would make the archive a dependency of the
clone, which is the opposite of the point.

## Consumers enumerated, not estimated

| class | count |
|---|---:|
| TypeScript files naming either path | **41** |
| workflows | **5** |
| prose | 948 |

The load-bearing one is **`pr-archive-on-merge.yml`** (`pull_request: [closed]`) — it must
write to the new repo with a scoped token, and that is the one genuinely new piece of
machinery. Three of the five workflows are `disabled_manually` today, which lowers the cost
and is worth knowing before anyone budgets for it.

## What it does not buy

**A smaller `.git`.** The pack is **285.8 MiB / 247,058 objects**, and moving files forward
does not remove their history. That needs a **rewrite** — gated, non-reversible, invalidates
every clone and every SHA that names one. **Stopping growth and shrinking the past are two
decisions**; this draft is only the first.

## Order of operations

Removal is **last**, and step 4 requires **a live archive write to the new repo before it**
— so there is never a window where a merged PR's review record is written nowhere.

## One fix belongs before the move, not during

`manifest.jsonl` is stale: **13,592 records against 13,982 shards, 390 shards absent from
it**, 117 where the shard is newer. `derive-pr-manifest.ts` already exists, so it is
derivable. Carrying a known-stale index across a repo boundary is how a small drift becomes
an argument about which side is authoritative.

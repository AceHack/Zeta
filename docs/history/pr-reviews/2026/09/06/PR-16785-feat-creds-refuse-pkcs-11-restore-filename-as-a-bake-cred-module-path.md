# Summary

#16783 joined the setup path picker to the overlay planner. Overlay already refuses `/etc/zeta/seal/pkcs11-module-path` as the module. `--bake-cred pkcs11-module-path=...` still accepted that string because it contains `pkcs11`, so the repair stick could bake a pointer to itself.

`validatePkcs11ModulePath` now refuses `USB_PKCS11_MODULE_POINTER` (trimmed). A real NixOS `yubihsm_pkcs11.so` path still bakes. `Application.yaml` is untouched.

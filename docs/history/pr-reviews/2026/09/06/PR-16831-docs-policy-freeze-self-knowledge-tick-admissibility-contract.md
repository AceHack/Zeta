## Description

# Summary

Adds a documentation-only, finite contract for policy self-knowledge and tick admissibility. Policies declare parseable asymptotic time/space shapes over named input measures. Callers, not policies, supply attributed bounded-duration tick envelopes. Extra constraints must name one finite basis: `test-only`, `nci-preservation`, or `recorded-consensus`.

The change makes no scheduler, policy, transport, MiniGrid, or society behavior change. It explicitly defers NCI-preservation and recorded-consensus admission until independently frozen evaluators exist; `test-only` is the only executable basis in a later first slice.

# Summary

USB `--bake-cred` HSM-talk companions landed in #16774. Metal `seal "pkcs11"` still needs a **reachable** module in the same commit as the stanza. This PR plans the hostPath overlay (volumes, mechanism pin, ABI) and **does not** edit `Application.yaml`.

Today's `quay.io/openbao/openbao-hsm` is Alpine/musl and ships no module. NixOS PKCS#11 libraries are glibc. hostPath of that `.so` into the chart image is hands-off-metal §1.4 option A — unproven — so this planner classifies it as `glibc-host-into-musl-image` and refuses to count it as `moduleInImage`.

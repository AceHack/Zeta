# Summary

Aaron: continue after SoftHSM `bao operator init` (#16772). A repaired box still has to talk to the YubiHSM / CardContact HSM. That is a companion inventory on the stick, not a second secret store.

`--bake-cred` already shipped CLI creds. This PR grows the five HSM-talk kinds the classifier already named (`USB_HSM_COMPANION`): module path, connector config, authkey *reference*, domain map, OpenBao env pointer. PIN stays a reference (the env *name* `BAO_HSM_PIN`, not `NAME=value`). PIN plaintext, Shamir shares, `OP_SESSION`, and a brand type in the volume refuse as bake-cred originals.

Companions restore under `/etc/zeta/seal/` and are **host-only** — the host→Secret projector does not put them in `zeta-host-creds`. SoftHSM green is not this metal companion set. Application.yaml stays Shamir.

## Summary

`FreezeError.MissingLeaves` was unused. POSIX `putLeaves` skips an existing object path, so garbage at that path could still get a freeze-commit. After put, stored object bytes are hashed; mismatch withholds persist/commit as `MissingLeaves`.

Falsifier: plant wrong bytes at the next freeze's object path; freeze returns MissingLeaves; prior Journaled freeze stays readable.

Does not promote PR12 recovery out of `toy`. Does not bump Helm majors.

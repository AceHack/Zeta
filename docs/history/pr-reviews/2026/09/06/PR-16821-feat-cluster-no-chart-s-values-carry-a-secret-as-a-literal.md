## Description

> *"making sure all our helm charts are tested and have secure ways of handling the passwords
> and other material like we spoke about"*

`audit-existing-secret-is-minted.ts` already guards the **reference** side — a chart naming an
`existingSecret` nothing mints. **Nothing guarded the other side:** a chart whose values carry
the secret *itself*, as text, in a **public** repository. That's the harder failure, because
the manifest looks complete and every other check passes.

## The population is smaller than I expected, and that's the useful part

First scan of the whole cluster surface — every Application `valuesObject` and every bootstrap
`valuesContent`, **43 values documents** — found **five** credential-shaped literals, and all
five are the **same** credential: seaweedfs declares the S3 identity, loki and mimir ×3
present it back.

**One credential, not a sprawl.** So this audit is a **floor at zero** the moment
`081M1S6Z5S3087G0R000GEPSS2` lands — and until then it closes the class against **new**
literals rather than waiting for the migration.

## The five are acknowledged because the fix is not divisible

The producer and all three consumers must agree on **one** value, and
`applyDevBootstrapSecrets` draws fresh entropy **per spec** — so three namespaces cannot share
a minted secret today. Changing any one file alone would leave a service authenticating with a
key the store does not know. That constraint is written into **every** entry, per coordinate,
rather than stated once and assumed.

## What it deliberately does not flag

**The identifier half.** `accessKey` is an access-key ID, not a secret — and this tree really
does commit `accessKey: zeta-blob-store` beside the secret it must not commit. Flagging it
would fill the roster with non-problems, which is how a roster stops being read.

**The three safe shapes are the three the fix produces** — empty, `${ENV}`, or a
`valueFrom`/`existingSecret` indirection. A check that rejected those would make the correct
fix inexpressible, so each has a falsifier.

## It never prints a value

And **no acknowledgement quotes one** — asserted by a test. A check that reports a committed
secret by quoting it has copied that secret into every CI log that runs the check, and a
roster that spells it out republishes the thing it is apologising for.

It **refuses** below 20 values documents: on a credential check, a false clean is the most
expensive false clean in the tree.

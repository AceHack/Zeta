## Description

## Why

Continue the preregistered predictive-state work with an observation-only HMM learner, fair inference contracts, calibrated change detection, and an explicit test of operator reuse versus lossy belief compression. The supplied papers and talk motivate the questions; this remains research-grade and does not promote game or production policy.

## What Changed

- Implement bounded native HMM filtering and eight-pass EM; retain every one of twelve fits and evaluate against eighteen frozen RNNs on common panels.
- Remove context-proportional RNN tuple allocation without changing arithmetic or weights. Retain original, partial-repair, and final receipts: 504 bitwise prediction and 360 nonempty gradient witnesses per version.
- Add a likelihood-mixture change detector with a known-null guarantee, a wrong-null negative control, and all 8,192 stream outcomes.
- Compare dense, exact shared-operator, and projected-product filtering, retaining correlations in the exact path and measuring the loss from projection.
- Add independent Python implementations and replay every prediction, probe, benchmark checksum, alarm time, and all twelve complete EM fits. Add twelve F# and seven Python tests; raise the Python CI floor to 72.
- Index raw receipts, paper findings, limitations, gate evidence, and source ancestry in `docs/research/2026-09-06-factored-predictive-results.md`. Complete work item 081M1VS712Z087G0R000YKZKFB and release its claim in this PR.

## Results And Boundaries

- The registered RNNs predict better than these eight-pass HMM fits; HMM inference is cheaper at tested sizes. Training compute is explicitly not matched.
- Joint-four-token output probes beat hidden-state linear probes on every RRXOR run at both lengths, weakening the earlier hidden-versus-next-token interpretation.
- Width-8 allocation drops from 2,392/2,384 to 280/272 bytes per L64 call, and is independent of length. This is not an energy claim.
- Known-null false alarms are 53/2,048; the deliberately wrong IID null alarms on all 2,048 unchanged streams.
- Exact shared filtering matches dense within roundoff. It allocates more scratch and is not always faster. Product projection is faster but loses correlated information under common noise.
- The paper's Appendix H.2.1 conflates trivial intersection with orthogonality; retain a concrete counterexample while distinguishing its valid principal-angle diagnostic. Independent implementations are not an independent reviewer.

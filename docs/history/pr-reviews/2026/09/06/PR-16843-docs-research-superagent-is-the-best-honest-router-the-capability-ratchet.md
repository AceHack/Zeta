## Description

> ## **"Superagent is the best honest router."** — Aaron, 2026-09-06

Longer form, given first, answering a six-capability *"What Is a Superagent?"* card:

> *"one who every time it works decides how to route the next same task to an agent with less
> experience or intelligence."*

## It is a different KIND of definition from the card it answers

The card lists six properties the agent **has** — *Reasons Across Kinds of Work, Sees the
Screen, Uses Software, Recovers From Failure, Carries Context, Decides Without Asking*. That is
unfalsifiable in the way a capability list always is: **you cannot fail it, you can only be
judged to have less of it.** And it specifies a *bigger* agent.

Aaron's names a **change in the world**: each execution lowers the intelligence required for
the next execution of the same task. That can be measured, and it can fail.

**Three reasons it is stronger** — it is falsifiable (*what is the cheapest agent that could do
this now, and did that fall?*); it **inverts the incentive** (a capability-defined superagent
is rewarded for being *necessary*, a ratchet-defined one for making itself *unnecessary*); and
it is **monotone**, so a run that left the next attempt needing more is legible as a regression.

## "Honest" is the word the longer form doesn't contain, and it cuts both ways

| dishonest direction | what it is |
|---|---|
| **over-claiming the floor** | routing to a cheaper agent that then fails |
| **under-claiming it** | capability hoarding — staying necessary |
| **moving the bar, not the floor** | the vacuity class, applied to routing |
| **claiming with no artifact** | the bit was thrown away |

A router that does not know the floor should **say so**, not guess downward because downward is
the virtuous-sounding direction.

## The mechanism is already built here — this supplies the scoreboard

A check, a CLI verb, a written measurement, a named refusal, a `LIFTS WHEN` — each removes
something the next run would otherwise have to do. **They are one act, not five hygiene
habits:** paying down the intelligence required next time.

## The second image

A circle-and-triangle joined by a **dotted** line to a U-tube — the shape of a Szilard-engine
diagram. **Identification is uncertain from a blurry frame**, so it is described rather than
named, and the mapping is filed as an **argued correspondence with no constant claimed**.

The load-bearing half is **Landauer**, not the poetry — the demon's sorting only pays if you
ignore the record-keeping:

> **A run that does the work brilliantly and records nothing has not lowered anything. It has
> spent the intelligence and thrown away the bit.**

Anchors: Maxwell 1867 · Szilard 1929 · Landauer 1961 · Bennett 1982.

## Open, and marked `toy`

`floor(task)` is not directly observable — you learn it by trying a cheaper agent, which costs
a run per measurement. And the standard must be pinned first or the floor drops by lowering the
bar; this repo's answer is that **the task's own falsifier is the standard**.

# Summary

Aaron: continue after the restore-file capture (#16789). Metal `seal "pkcs11"` waits on a same-libc image or option D host `bao` in the same commit as the stanza. Today's chart ABI was a constant (`OPENBAO_HSM_IMAGE_ABI = alpine-musl`). This slice classifies a captured ELF `PT_INTERP` and names the load site. It does not land the stanza.

- `bao-load-site.ts`: `ld-musl` vs `ld-linux`. Named interpreter contracts are classified first (chart musl, CI glibc tarball), then substring for NixOS store paths. Unmeasured is not a glibc proof. A glibc CI tarball is not the chart unless the capture names `in-chart-image`.
- Option D `on-host` may emit host HCL (`mayCommitHostHcl`) and cannot gain `Application.yaml`. Opening a `.so`, the restore pointer, or `/dev/tpmrm0` is not bao.
- `OPENBAO_HSM_IMAGE_INTERP` is the musl chart path. No live `readelf`. Does not edit Application.yaml. Does not land `yubihsm.nix` or extraContainer.

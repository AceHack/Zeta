## Description

Aaron asked for a benchmark built on the capability ratchet — *"the capacitance or ohms-like law (not exactly ohms law, is an approximation not absolute)"*.

**The parenthesis is the document.** An Ohm-shaped law is a proposal about a *regime*, so this states the boundaries before the model.

| | mapping |
|---|---|
| V | capability applied (the tier routed to) |
| I | completions to standard (the task's own falsifier) |
| R = V/I | task resistance — `floor(task)` |
| Q | artifacts — checks, verbs, measurements, refusals |
| C = Q/V | retention — stored reduction per unit capability |
| **τ = RC** | **repetitions until required capability falls to 1/e** |

τ is a property of the **substrate plus agent**, never of the agent — two systems sharing one model differ by an order of magnitude on whether artifacts are written and consulted.

## The five non-ohmic regimes

1. **Novel tasks** have no prior floor — open circuit, R undefined.
2. **An artifact nobody consults stores nothing** — a disconnected plate; the vacuity class in a new costume.
3. **The bar can move instead of the floor** — a change of instrument, not a resistance drop.
4. **The diode** — artifacts conduct only for agents able to consume them, so executable beats expository. The one cheap decisive experiment.
5. **The open substrate** — Aaron's provenance for his own caveat (3D semiconductors, evolutionary algorithms over FPGA).

Break 5 is the deepest and it is anchored, not asserted: **Adrian Thompson's evolved XC6216 tone discriminator (1996)**, where five cells disconnected from the output path by any route the tools could see were nonetheless essential — evolution had recruited parasitic coupling as computational resource, and the circuit did not transfer to other chips of the same part number. What isolation buys is not Ohm's law (a fine constitutive relation) but the **lumped-element abstraction** on top of it, which is a statement about what is *not* coupled and is exactly what an open substrate withdraws.

The prediction that follows is the useful part: **any optimiser pointed at τ will route through the parasitic paths**, because coupling is free capability. Goodhart with a mechanism instead of a moral. The defence is not forbidding coupling (Thompson's cells could not be forbidden, only detected) — it is measuring the floor **by descent**, which a side channel cannot satisfy: the cheap rung has to actually finish the task.

**Aaron corrected my register on this while it was being written** — *"no, we can measure it eventually, we have FPGAs here and ones we plan to buy."* That moves the claim from *unmeasurable* to **unmetered with the instrument in the building**, which is a different class. And FPGA fabric is a better falsifier than any agent-level test for one specific reason: **the declared channel set is enumerable** — it is the routing graph — which is exactly what §13 noninterference asks for and exactly what software agents cannot supply. So the experiment is named: evolve against a τ-shaped fitness, **ablate by the routing graph** (Thompson's own diagnostic used as a meter), count recruited channels against optimisation pressure, and run the transfer test his circuit failed. The negative result is available and would be informative.

## The triangle — and which corner should be growing

Aaron, mid-review: *"this is kind of our triangle, because we have generator plus joins plus observability, and over time we want this triangle to move more data points to generators over observability, because observability costs more."*

That is a better statement of what τ counts than "artifacts" was, and it replaces it. A run's residue is a **point migrating between corners**:

| corner | holds | cost |
|---|---|---|
| **generator** | the rule that produces the points | paid **once**, at authoring |
| **joins** | how points relate | per relationship |
| **observability** | the points themselves, retained | **per point, forever** — storage, attention, re-reading, staleness |

> **τ measures the rate at which a system migrates points from observability into generators.**

This also explains the diode's direction: an executable artifact *is* a generator the next agent can run; an expository one is an observation *about* a generator it must first reconstruct. The diode was the symptom; the triangle is the mechanism.

**The three corners are this repo's own DV2.0 partition** — hub / link / satellite, corner for corner. So the contribution is a **direction of travel** DV2.0 does not itself state: not merely *put each thing where its change rate belongs*, but **work to lower the change rate**, because the fast corner bills forever. And per `only-the-irreducible-is-primitive-generate-the-rest`, regenerating from the irreducible is also the error correction — a migrated point stops costing retention *and* stops being able to drift.

**Guard:** a migrated point must still produce the observation it replaced. A generator that has quietly stopped reproducing its points is the vacuity class in its most expensive form — the retention cost is gone and so is the fact.

## The hard problem, and the objective function

Aaron, on the guard about a generator that quietly stops reproducing its points: *"you've just named the hard problem out loud."* It is promoted to its own section, because the difficulty is structural: **the saving comes from deleting the witness that would detect its failure.** Four escapes, each paying something — sample, **digest**, two independent generators, cold storage. This repo already picked the digest, which is why golden vectors are text. It reduces to the **broken meter** already on file — *a byte-lock nobody re-ran* — so it is a **liveness** requirement, the vacuity class in its original form.

And on the shape-change: *"exactly the shape transition we are trying to compress while being accurate."* That is a rate under a fidelity constraint — **rate–distortion** (Shannon 1959), in the form that counts both halves in the same units: **MDL** (Rissanen 1978), `total = |generator| + |unsubsumed observations|`. Which corrects a misreading the direction invites: the observability corner should **not** reach zero, because a generator large enough to memorise its data has moved bytes and added indirection. It also gives the hard problem its formal shape — distortion is defined *against the source*, so deleting the source makes it uncomputable.

**First measurement** (tool in #16849): **3.556** observability bytes per generator byte, against **2.546** a month earlier. The repo has moved *toward* the expensive corner.

## Why

The ARC scene-prior lane already uses color, shape, density, and motion, while the F# cross-emulator boundary had only a centroid motion baseline. This establishes a rendered-pixels-only contract that CHIP-8, CHIP-9, ARC, Atari, and later browser adapters can share without exposing game identity, hidden emulator state, rewards, or reference answers.

The result is deliberately narrow. It does not claim ARC score improvement, cross-game transfer, a learned model, CLR heap size, or wall-clock speed. Normalized shapes retain one logical coordinate per foreground cell; the receipt says so explicitly.

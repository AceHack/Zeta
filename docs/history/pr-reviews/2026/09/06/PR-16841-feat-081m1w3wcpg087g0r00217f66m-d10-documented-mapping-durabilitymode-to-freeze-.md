## Summary

D10 asked for one named class **or** a documented mapping. This is the mapping, not a merge.

`DurabilityFreezeMap.freezeClass`: `OsBuffered`/`InMemoryOnly` → freeze `Buffered`; `StableStorage`/`WitnessDurable` → freeze `Durable`. `tryDurabilityMode`: freeze `Journaled` has no twin.

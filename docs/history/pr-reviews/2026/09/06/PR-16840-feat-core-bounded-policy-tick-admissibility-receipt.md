## Summary

Implements the finite `PolicyAdmissibilityReceipt/v1` selected by merged contract PR #16831. The local adapter accepts one policy self-report, a caller-owned bounded-duration tick envelope, and a named constraint basis. It validates structure and carrier identity only; it **does not** rank policies, prove complexity, score a learner, establish an NCI floor, or create consensus.

## Controls

The focused controls observe refusal for malformed O-shapes, zero ticks, unknown `global-score` basis labels, altered raw carriers, and hidden external byte/reward caps. `nci-preservation` and `recorded-consensus` remain explicit `defer-basis-not-implemented` paths. A captured mutable limit crossing an otherwise identical tick boundary is detected through the existing one-way `TickBoundaryProbe`; non-detection is not treated as acquittal.

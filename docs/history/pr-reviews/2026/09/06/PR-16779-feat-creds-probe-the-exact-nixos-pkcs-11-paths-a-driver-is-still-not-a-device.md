# Summary

[#16776](https://github.com/Lucent-Financial-Group/Zeta/pull/16776) landed the PKCS#11 hostPath overlay planner, which names NixOS module contracts under `/run/current-system/sw/lib/pkcs11/`. `frost-hardware-probe.ts` Linux YubiHSM list had three Debian-shaped paths and none of that contract, so a provisioned NixOS node reported `yubiHsm2Pkcs11ModuleFound: false`.

This PR adds the **exact** overlay paths (YubiHSM + OpenSC/CardContact). No wildcard. A `.so` on disk remains a DRIVER and does not clear `noHardwareDetected`. Does not land `yubihsm.nix`. Does not edit `Application.yaml`.

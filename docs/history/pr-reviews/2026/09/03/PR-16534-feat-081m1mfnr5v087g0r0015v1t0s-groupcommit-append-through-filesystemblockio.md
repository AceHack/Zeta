## Summary

`GroupCommitDiskDeltaLog` can append through the same `FileSystemBlockIo` door as freeze. Crash/corrupt/reorder then tear the LBA, not a whole-file Dispose buffer.

- Optional `useBlockIo`: `FileSystemBlockIo` + `BlockLog.append` + dual-slot `ZGL2` superblock.
- Default stays the stream path so existing whole-file Dispose crash tests keep their door.
- Crash-mid-write of the second append keeps HighWater 1.
- Corrupt-last-write acks and keeps seq 1 (does not claim the second record is dropped — last-8 of a 4096-byte RMW is often padding).
- Reorder completes and keeps seq 1.
- Superblock magic is `ZGL2`, not `ZFL2`.

DoP=1. `fsDoor` bound at construction.

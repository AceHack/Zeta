## Summary

`LogicalBytes` and the `BlockCas` index lived only on the DST instance. `CloneMedia` copies block bytes without those fields; reopen must reload from LBA 0.

- Log magic `ZFL1`, CAS magic `ZCA1`. Payload starts at LBA 1. CAS index must fit in one block.
- Journaled freeze, `CloneMedia` of the log disk (`LogicalBytes` 0), `createManualWithBlocks`: readable.
- Journaled freeze on log+CAS, `CloneMedia` both disks, new `BlockCas` on the object clone: readable.
- File-path freeze unchanged.

Superblock write is not checksum-paired with the payload. A crash during the superblock Write can lose the last freeze. That is the next peel.

## Honesty peel

Crash recovery stays `toy`. Default freeze path is still files. Native NVMe is not claimed.

## Description

Aaron: *"it seems CloudNativePG is likely the postgres we need for gitlab."* Reading temporal's
manifest turned up the **same root cause**, so this lands the operator once for both remaining
BEHIND-MAJOR charts.

## Why CockroachDB can't do it — and both failures are in the acquitting direction

| chart | needs | CockroachDB |
|---|---|---|
| **gitlab** 19.x | PG 17.x exactly + `pg_trgm`, `btree_gist`, `plpgsql`, `amcheck` | accepts `CREATE EXTENSION pg_trgm` as a **no-op** — returns success, creates nothing |
| **temporal** visibility store | `btree_gin` + a plpgsql `convert_ts()` inside `GENERATED ALWAYS AS … STORED` | `btree_gin` unimplemented (#51992, open); UDFs in computed columns a known limitation (#122945) |

A statement that succeeds and does nothing is **the vacuity class in SQL**, and it's worse than an
error because it surfaces later — in a query plan, on metal. CockroachDB is **not** replaced;
temporal's *default* store is plain SQL and works on it today.

## The operator only, deliberately

No `Cluster` CR, so no database and no disk. Render-measured against this Application's own
valuesObject: **11 CRDs, 1 Deployment, 2 webhooks, and zero PersistentVolumeClaims** — the 32
string matches are all inside CRD schemas; `kind: PersistentVolumeClaim` appears nowhere. Shipping
the operator alone keeps gitlab's and temporal's storage/migration decisions in their own change.

**Resources declared here because the chart declares none.** Upstream ships `resources: {}` — and
an unset request isn't a small request, it's **BestEffort QoS**: first evicted, and contributing 0m
to every budget while consuming real CPU.

**No cert-manager edge.** Checked against the chart values *and* the render: CNPG rotates its own
webhook cert. `dependsOn: [cilium]` only — declaring an edge that doesn't exist is as wrong as
omitting one that does.

**Wave −70, checked with a control.** My first control was wrong: wave 999 is still *after* cilium,
so it correctly didn't fire. Re-run at **−100** (before cilium at −80) it produced exactly 1 new
disagreement and rc=1; restored to −70, 0 new and rc=0.

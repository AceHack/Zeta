## Summary

A crash during the single LBA 0 superblock Write can tear the only copy and lose every freeze, not only the last one. Two slots, generation plus CRC, write the inactive copy.

- Log magic `ZFL2`, CAS magic `ZCA2`. Payload starts at LBA 2. CRC is IEEE-802 over bytes after offset 8 (the superblock record, not the payload).
- After `writeLog(100)`, crash-mid-write or corrupt-last-write of `writeLog(200)`: `tryReadLog` is `Some 100`. Torn first slot recovers empty. Same shape for CAS.
- `BlockCas` publishes the name only after the superblock Write returns.
- File-path freeze unchanged.

A crash during the new slot can still drop the last uncommitted freeze. Per-frame CRC on the freeze log is unchanged.

Also completes the LBA 0 superblock workitem after #16473.

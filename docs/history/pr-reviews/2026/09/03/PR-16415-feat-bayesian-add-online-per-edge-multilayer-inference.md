## Description

## Summary

`MultilayerBnn` already existed; the stale Max architecture document incorrectly said the N-layer module was not shipped. This PR corrects that census and adds the actual missing boundary: one online evidence update followed by a bounded per-edge factor-graph query.

`tryUpdateViaFactorGraph` and `tryInferViaFactorGraph` now absorb observations exactly once at layer zero, preserve deeper cells as message-only latent priors, and return the durable network plus every marginal, round count, convergence status, and an explicit exactness classification.

## Measured boundary

| Graph/result | Classification |
|---|---|
| Converged acyclic factor graph | `ExactAcyclic` |
| Converged Gaussian loopy graph | `ConvergedLoopyMeansOnly` |
| Capped acyclic iterate | `UnsettledAcyclic` |
| Capped loopy iterate | `UnsettledLoopy` |

Strict mode refuses a capped iterate. Malformed topology, duplicate parents, public network array-length drift, non-positive channel variance, invalid tolerance, invalid round budget, and non-finite observations all fail closed with teaching errors rather than being filtered into a different model.

## Independent verification

The MultilayerBnn suite grows from 36 to 44 scenarios. A non-skippable cross-verifier builds and calls the production F# API while a separately authored pure-Python oracle constructs and inverts the joint precision matrix. All four sequential means and variances agree within `1e-10`; exact-once precision, replay, backward influence, loopy classification, caps, and malformed-parent refusal pass. Flipping the Python inter-layer coupling sign creates four disagreements.

## Explicit non-claims

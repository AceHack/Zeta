## Description

Item 5 of the agentic-organization port list: **the state-reconciliation technique** — hold the mapping as a `Record` so it is compile-exhaustive.

From `agentic-organization/docs/STATE_RECONCILIATION.md`, in its own words: *"adding a `WorkItemState` is a type error until a row is supplied (OCP — a new state breaks the build, not just a runtime test)."*

## The divergence this side actually had

`NextAction` has 16 kinds, and knowledge about each was spread across four surfaces — **three of which failed open** on a kind they had never heard of:

| surface | shape | consequence for a new kind |
|---|---|---|
| `room/hat-gate.ts` `isAuthorized` | `default: return true` | authorized at every hat level |
| `room/room.ts` `isActionInScope` | trailing `return true` | in scope for every room |
| `grammar-16-render.ts` `leadSlot` | `default: return null` | silently slotless |
| `grammar-16-render.ts` `FREE_MODE_KINDS` | a private hand-written const | a fourth copy of the NCI roster |

A `default: return true` is the vacuity class in gate form: it looks like a decision and decides nothing. A 17th kind added tomorrow was authorized everywhere, in scope everywhere, and no test went red. All four surfaces now read `ACTION_RECONCILIATION`, so a 17th kind fails to **compile**.

## The live defect it surfaced

`self_claim` carries an item and was reaching the scope predicate's trailing `return true` — so a room could **claim work outside its own envelope**, committing to deliver an item it was never scoped to touch. `hat-gate.ts` had already fixed the authority half of exactly this defect (a claim is a promise to execute, so it is gated as the execution is); the scope half was still open. One row now settles both.

## What the table deliberately does NOT do

It does not invent the `kind -> slot` projection. `grammar-16.ts` says that projection is the next slice and is *"left OPEN here on purpose — fabricating a clean total mapping would paper over a real design question"*. So `leadSlot` records only what the renderer already answered, and `null` keeps its meaning: *the ADR has not assigned one*.

Likewise `not_yet_assigned` is a named row value rather than a silent `true`. The cartography / time-travel / memory-sector kinds are ungated **today**; `UNGATED_KINDS` makes that roster visible, countable and test-pinned instead of implicit in a fall-through. Naming a gap is not closing it — closing it is the grammar owner's call.

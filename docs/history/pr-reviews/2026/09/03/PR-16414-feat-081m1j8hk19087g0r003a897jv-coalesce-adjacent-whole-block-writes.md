## Summary

batch/single for `BlockIoFerry`: consecutive whole-block writes to sequential LBAs become one device `Write`. Generated in `processBatch` from the in-repo ferry, not a foreign I/O stack.

- Adjacent LBA 0 then 1 (4096 bytes each), one boat: `DeviceWrites = 1`, both reads round-trip.
- LBA hole, Flush, or partial block: does not coalesce.
- Each row still receives its own `Outcome.Bytes`.

Also completes the mid-CRC workitem after #16411.

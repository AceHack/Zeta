## Description

The diagnosis fix ([#16474](https://github.com/Lucent-Financial-Group/Zeta/pull/16474)) made the misreport honest — a JVM that cannot reserve its heap now says **"TLC DID NOT RUN"** instead of **"TOOLCHAIN DRIFT."** This addresses the condition itself.

The registry pins `-Xmx4g`, and on a box running the whole 6,000-test suite the JVM sometimes cannot reserve it — observed once in three full runs. Nothing about the model or the jar is wrong when that happens; the process never got far enough to check anything.

## Why a retry is honest here

A model check is **deterministic and idempotent**, so re-running one has no consequence. That is exactly the condition that makes a retry legitimate rather than a way of averaging over a flaky result.

Bounded at 3 attempts, and the **last** output is returned either way — so a persistent shortage still fails, and still fails with the `TLC DID NOT RUN` diagnosis rather than being retried into silence.

## What is deliberately NOT retried

A violated invariant. A wrong banner. A missing completion marker.

Those are **answers**, and re-asking a question you already have an answer to is how a real, reproducible failure becomes intermittent — and an intermittent failure is one people learn to re-run rather than read.

## The policy is testable without a JVM

`shouldRetryJvmStart` is split out of the loop. The two ways to get it wrong are opposite and both bad, so both have a test:

| test | guards against |
|---|---|
| `a JVM that never started is retried` | the condition going unhandled |
| `the retry is BOUNDED — a persistent shortage still fails` | an unbounded loop — **a hang is worse than a red test**, because nothing reports it |
| `an ANSWER is never retried` | turning a reproducible failure intermittent |

Mutation matrix, with each mutant verified to have **applied** before judging — the first attempt failed to apply through shell quoting and reported all-pass, which would have read as a passing matrix:

- dropping the bound → kills `the retry is BOUNDED`
- dropping the `jvmNeverStarted` conjunct → kills `an ANSWER is never retried`

# Summary

kind+Cilium included dispatch [33684309073](https://github.com/Lucent-Financial-Group/Zeta/actions/runs/33684309073) spent **2400s** on `kubectl get application hat-system` returning `NotFound`. `hat-system` is sync-wave `-10` (the head of the catalog). Pinning the wait to that **name** made a silent catalog look like a slow hat-system.

This PR waits for **any** Application other than `zeta-root-dev`, capped at **180s**.

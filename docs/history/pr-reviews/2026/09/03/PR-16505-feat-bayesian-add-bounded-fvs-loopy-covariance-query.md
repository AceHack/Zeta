## Bounded FVS-conditioned loopy covariance query

This PR implements a read-only feedback-vertex-set-conditioned query for the declared finite linear-Gaussian `MultilayerBnn` topology. It corrects covariance on the reviewed four-layer loopy skip witness without relabeling generic loopy BP, EP, VMP, particle methods, or non-Gaussian inference as exact.

## Measured result

The deterministic exhaustive selector chooses `FVS [0;1]`, runs three conditioned trees in nine aggregate rounds, and returns `ExactLoopyViaFvs 2`. Production F# matches the independently authored Python joint-precision oracle within `1e-10`. The ordinary converged BP variance has L¹ error `0.22710111268589156` against the exact covariance; FVS returns the exact declared witness covariance. Acyclic input delegates to the existing exact path. One-vertex feedback budgets and one-round conditioned-tree caps refuse; fixed-input replay is bit-stable.

## Boundaries

The method is a deterministic query over a fixed declared network. It does not make mutable online updates arrival-order independent, consume CRDT evidence state, implement a CRDT merge, learn topology, establish generic loopy variance correctness, or support non-Gaussian factors.

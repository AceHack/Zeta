## Description

## Summary

This PR adds a **query-only** adapter from the canonical content-addressed CRDT evidence state to a fresh two-dimensional Gaussian receipt. It does not make posterior multiplication, covariance intersection, or any mutable Bayesian update a state-merge operator.

The adapter normalizes full evidence identities, refuses unresolved same-key changed-content versions, fixes a declared query order, uses Kahan-compensated information accumulation, and labels absorption `ExactOnceByFingerprint`.

## Bounded findings

| Finding | Evidence |
|---|---|
| Same retained evidence state gives one receipt under delivery reordering | All six finite arrival permutations agree exactly |
| Redelivery is harmless at the state/query boundary | Full receipt unchanged; evidence count remains three |
| Changed content or uncertainty remains visible | Query returns `Conflict`; it does not silently choose a version |
| Compensation control is non-vacuous | Kahan/naive cancellation differs; a Python naive-accumulation mutant is detected |
| Independent check is substantive | Separately authored Python oracle, strict TypeScript runtime schema comparator, and non-skippable Bun wrapper pass |

The public evidence room now distinguishes the **ACI state** from the **QUERY ONLY** receipt. The new architecture roadmap keeps factor graphs, probabilistic circuits, learned Bayesian-neural edges, consensus, and speculative language concepts distinct.

## Explicit non-claims

This is not a system-wide order-independent Bayesian stream update; it does not identify shared priors or unknown correlations; it does not establish non-ASCII cross-runtime collation; it does not integrate transport, society consensus, RFFH, MinimalBnn, or MultilayerBnn; and it does not establish linguistic, cortical, identity, or consciousness claims.

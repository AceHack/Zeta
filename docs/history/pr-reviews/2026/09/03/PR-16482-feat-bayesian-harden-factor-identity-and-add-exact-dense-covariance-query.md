## Measured controls

The test-only eight-bit RFFH namespace constructs a distinct-message collision from the declared `0..4095` enumeration. It returns `RFFH-FACTOR-ID-COLLISION`, exposes both evidence IDs in the teaching error, retains the accepted count and original posterior, and does not probe a replacement ID.

For the declared four-layer loopy Gaussian witness, exact-dense and converged BP means differ by `4.0190073491430667e-14`, while covariance diagonals differ with L¹ distance `0.22710111268589156`. Independent Python joint-precision inversion agrees to `1e-10`. The channel-variance and observation-double-count mutants each cause exactly four mean and four variance disagreements; the coupling-sign mutant is retained as a means-only control with four and zero respectively.

## Description

## Summary

This documentation-only PR adds `max-decorrelate-reconcile/v1`, a bounded contract for the proposed constrained extremum:

```text
maximize    declared decorrelation
subject to  declared reconciliation still succeeds
```

It deliberately does **not** derive, encode, target, or identify an outcome with `2√2`. A finite result is only the best passing entry in a pre-registered finite candidate catalogue.

## Scope

The contract requires a source-owned finite carrier, canonical anchor bytes, a versioned metric and reconciliation predicate, current-candidate observation barriers, causal event chains, independent receipt replay, explicit `−1` retraction/replacement atoms, and raw-byte receipt identity. It permits declared prior-level and cross-game memory while rejecting undeclared current-candidate preload.

CHSH may be reported only as an optional, separately specified sidecar. It cannot change the decorrelation score, reconciliation outcome, or selected candidate.

## Required controls

The first implementation must demonstrate independent replay; metric and reconciliation mutations; current-candidate preload refusal; declared prior-memory acceptance; correction and unresolved-retraction behavior; order mutation; catalogue omission; and CHSH-sidecar separation.

## Boundaries

This change introduces no learner, policy, ARC score, hosted interface, official evaluation, quantum claim, societal metric, or mutual-empowerment implementation. It records an explicitly falsifiable finite measurement procedure only.

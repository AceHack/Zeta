## Summary

This documentation-only pull request freezes `arc-offline-carry-v1`, a bounded
next step following the merged ARC readiness correction in #16996.

It records the current reproducible offline state accurately: source-owned
`ZetaChase` has three levels, and `PixelAgent` seed `4` clears 3/3 with score
`0.354`; `ZetaChaseDecoy` clears the same 3/3 at `0.2659`. The targeted offline
mode and PixelAgent controls pass. No reproducible current-main four-level
receipt was found. The contract refuses to reclassify any of those facts as
official ARC, held-out transfer, continual learning, or a general policy result.

The proposed first implementation is score-free and no-agent-selection. It
requires a canonical receipt that partitions source-world state, explicit carry
offers, and static program state; it also requires observed replay,
world-local-leak, undeclared-carry, early-holdout-read, boundary-reset,
carry-removal, and identity-mismatch controls before a score comparison is even
specified.

## Summary

This documentation-only pull request freezes the smallest proposed ARC-facing
online-memory evidence unit: `arc-online-memory/v1`.

The contract treats event-by-event memory updates as intended continual
learning. It binds every update to the prior and next memory-state digests, the
lawfully observed event, uncertainty contribution, update-rule identity,
memory-read/write provenance, causal predecessor, and current-level task
barrier. The durable update atoms are retractable evidence; the agent memory
snapshot is a deterministic causal replay/query, not a CRDT merge of posterior
states.

It permits declared prior-level memory and cross-game experience such as CHIP-8
or Atari caches. The non-cheating boundary is task-scoped: current ARC-level
task payload, target/solution metadata, reference trace, or outcome cannot be
available before that level’s first legal observation. This contract does not
replace the active #17007 correction; it adopts the same intended memory rule.

The score-free preflight requires positive prior-level and cross-game continuity
controls, alongside current-level preload/early-read, duplicate-update,
rule-substitution, uncertainty-tamper, out-of-order retraction, replacement,
missing-predecessor, non-absorption, and identity-mismatch controls.

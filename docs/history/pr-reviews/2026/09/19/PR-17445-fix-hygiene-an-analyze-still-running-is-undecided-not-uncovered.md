## Description

`drift (loud)` went red on `main` (run 35404883426) after **ten consecutive green** push runs, claiming the premise under the Scorecard #24 dismissal no longer held. It did hold.

The audit reads main's **live** newest-30 commits, so it samples commits that land *while the run executing it is still going*. Its own job window was 23:34:25 → 23:38:33; commit `4ad5d300e` landed at **23:37:49** and was reported as a premise violation for carrying no successful `Analyze` **twelve seconds** after being pushed. Re-run by hand at 23:40: `rc=0`, all 30 covered. The condition was the clock, not a hole in `main`.

## Cause

`scanCommit` folded `if (conclusion === "success") ok++; else bad++` over a type declaring only `{ name, conclusion }`. `status` was never read, so an Analyze **still running** and one that **never ran** were the same fact.

That is this repository's central failure class in its mirror form: not a check that did not run looking like one that passed, but a check that **has not finished** looking like one that **failed** — and it fails loudly and specifically, which is the expensive direction, because a reader who checks an alarm once and finds it false learns to skim it.

## The guard on the fix

"Treat pending as fine" is how a guard goes vacuous, so the property that stops it is explicit and tested:

> A commit whose Analyze **never ran** has zero Analyze check runs — nothing pending, nothing successful — so it stays `unscanned` and still fails.

Only an actively-running analysis is excused, and that excuse expires by itself once the run concludes. Pending cannot persist and hide a hole. Two edges a careless version would leak are pinned too: `status` decides pending and **not** a null conclusion (a *completed* run can carry a null conclusion, and excusing those would hide real holes behind this fix), and an absent `status` on an old `--json` fixture reads as completed, which fails closed.

`classifyAnalyzeRun` is lifted out pure and exported for the same reason `judge` already is — the network half cannot be tested without a token, so anything that is a rule leaves it.

## Description

## Two separable facts, stated apart because they are easy to fuse

### 1. The bump is render-identical — verified, not assumed

Templating **0.3.0** and **0.9.2** against this Application's own `valuesObject`
at `--kube-version 1.35.6`: same kinds, same **10Gi longhorn** volumeClaimTemplate,
same requests (api 500m/1Gi, control-plane 250m/512Mi, postgresql 250m/256Mi).

0.9.2 adds top-level `worker`, `tei` and `autoscaling` — **all three default to
disabled**, which is why a six-minor jump moves nothing. Only the two vectorize-io
tags change. Behind-upstream **5 → 4**.

### 2. The archived image is a separate fix, and the bump does NOT make it

The chart defaults postgres to **`ankane/pgvector:latest`** — Docker Hub reports
that repository `status_description: archived`, no push since **2023-10-11** — and
it *still* defaults to it at 0.9.2. Calling the bump a pgvector fix would be the
"behind is not unmaintained" error in reverse. The Application now overrides it to
the maintained **`pgvector/pgvector`** (pushed 2026-08-13).

**On the PostgreSQL major** — said out loud because a reader would reasonably
assume it was checked, and it wasn't: `ankane/pgvector`'s tags are pgvector
*extension* versions (`v0.5.1`…), not PG majors, so the base major being replaced
is **undetermined**. Tolerable *only* because there is no data to migrate —
hindsight has never reached Healthy in any lane and its dev PVC is recreated per
cluster. The manifest records that this becomes a dump/restore the day hindsight
holds data.

## Blocker (3) of the deferral narrows a second time — half of it was stale

The reason claimed `api.llm.{provider,existingSecret}` and a top-level `service`
"remain inert". Re-checked at 0.9.2: **those keys are gone from the manifest.** It
now writes `api.env.HINDSIGHT_API_LLM_PROVIDER` and `api.service` — the spellings
the chart reads — and the rendered api Deployment carries
`HINDSIGHT_API_LLM_PROVIDER`. That sentence described keys the Application no
longer has, so it's removed rather than re-stated.

The **substantive half survives unchanged**: still no `HINDSIGHT_API_LLM_API_KEY`
reaches the container, and nobody has measured whether hindsight-api can be
Healthy without one.

`reason-truth.ts` caught the moved pin before I did — 52 citations across 13
reasons, every anchor holding again.

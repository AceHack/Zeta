## Summary

Plain-log replay could not open sealed frames: LSN lived only inside the AEAD, so `openLog` could not rebuild the nonce. LSN is already a public nonce field; putting it on the frame is not a leak.

Sealed frame is now `[len:i32][lsn:i64][inner]`. Same vault key, reopen, isReadable. Wrong vault key recovers nothing and does not truncate the log.

## Honesty

Pre-v1: existing sealed logs (if any) will not replay under the old `[len][inner]` shape. FORMAT default remains `enc=off`. Reclaim sweep still open. Recovery stays `toy`.

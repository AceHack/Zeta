## Description

## Summary

PR12 *intercept*, not the promotion out of `toy`. Crash-mid-write is now representable on the shared `IFileSystem` door that freeze and the group-commit WAL both use.

`InMemoryFileSystem.ArmCrashMidWrite` commits a prefix then throws `CrashMidWriteException`. FreezeLog disposes the log stream *before* Reply so a torn boat cannot ack. GroupCommit binds the filesystem at construction (background ferries must not re-read `AsyncLocal`) and a fresh instance still truncates a torn tail.

WriteAsync on the boat awaits the `ValueTask` only when it is still pending. `.AsTask()` would allocate a `Task` per record on `FileStream`.

## Honesty

- Intercept + torn-tail seeds landed. Reorder / corrupt-last-write / freeze-log replay / reclaim sweep are still open.
- `ISimulatedFs` stays flush-fail 5%. `IBlockIo` stays the FileSystemBlockIo sketch.
- Do not claim crash-safe. Recovery stays `toy`.

## Summary

This PR completes the frozen composable-factor benchmark and preserves the negative result rather than tuning it away.

It corrects RFFH to the architecture the code actually instantiates: two one-variable unary-factor blackboards with deterministic compensated posterior fusion behind external admission and pose-routing topology. Deterministic content-derived factor IDs, collision refusal, all six three-message arrival permutations, and a genuine two-variable equality-factor propagation control distinguish blackboard fusion from real graph inference.

It adds three bounded research lanes:

1. **CFB-A:** exact Gaussian dense/chain/balanced-DAG topology census. Posterior agreement is within `3.55e-15`; at 64 leaves both reductions use 63 products while ideal depth is 63 versus 6. This is an execution-depth result, not predictive superiority.
2. **CFB-B:** pinned public ETTh1 static ensemble. Static precision fusion improves MSE over equal weighting, but coverage falls to `0.7501`, residual correlation reaches `0.8738`, and validation-selected ridge has better MSE/NLL. Frozen usefulness verdict: **not supported**.
3. **CFB-C:** validation-only covariance-shrinkage query. It restores coverage to `0.9608` but selects `alpha=1`, so the off-diagonal covariance path is vacuous; MSE worsens to `10.8695`. Frozen usefulness and calibration-repair verdicts: **not supported**.

It also separates replicated evidence state from belief queries. Content-addressed multi-value evidence union passes the finite ACI, key-inclusion monotonicity, redelivery, and conflict-retention controls. Raw Gaussian product is non-idempotent. Fixed-half and 1,001-point trace-grid covariance intersection are idempotent/commutative but have explicit non-associativity witnesses, so neither is used as the CRDT state merge.

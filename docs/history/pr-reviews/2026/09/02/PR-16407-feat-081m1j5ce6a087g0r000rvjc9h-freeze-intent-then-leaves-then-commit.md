## Summary

Named seed `intent-before-leaf-flush` / subset leaves, plus the IBlockIo effect door Aaron framed as Haskell IO with ferry dispatch.

Journaled/Durable freeze used to `putObject` every CAS blob **before** the log boat, so a crash during a leaf could not leave a trailing intent. Boats now write intent, Flush (visible, no crash arm), put leaves, then commit. `SimulatedFileStream.Flush` publishes without firing crash/corrupt/reorder arms; Dispose still `commitWrite`.

`IBlockIo` stays the device primitive (one LBA, one call). `BlockIoFerry` is the interpreter generated from in-repo `FerryThrottler`:
- single/single — `RunAsync`
- batch/batch and single/batch — `RunManyAsync`
- batch/multibatch — `MaxBatchSize` splits one submit
- batch/single (adjacent-LBA coalescer) — named deferral, not this PR

Did not open Itron source. Combinators are the ferry cells we already have. If a coalescer needs a dirty-side spec, that is a later white-box room.

Overlay/FME is recorded as the query shape ZetaDB/ZetaFS optimize for: keep layers (McHarg 1969), reconcile first (Aaron's dated FME assessment), permission is a signature not a boolean. Clifford/Bayes application stays `toy`.

## Honesty peel

Crash recovery stays `toy`. Native NVMe is not claimed. Adjacent-LBA coalescer is not this slice.

Two docs commits closing the meter/oracle thread.

## 1. Alexa's review of the dual-use rule — the first finding is a defect

I wrote that a meter is an \"actor\" because it is frozen, and let that slide into
frozen **output**. Alexa: *\"a lookup table is an actor, and it produces a different
output for every input.\"* Correct, and the version I shipped would have licensed the
reading that a meter returns a constant.

Corrected in place: both meters and oracles emit per-invocation; what is frozen is a
meter's **judgement**, never its output. Plus two more — life/non-life decoupled from
the monopoly guard (which now rests on falsifiability, independent support), and a
missing row added for the **broken meter** (crystallised once, then drifted; detector
is re-running the treaty against committed golden vectors, which relocates the danger
to a byte-lock nobody re-ran — the vacuity class, which the taxonomy had no row for).

## 2. Definition drift vs argument change (Aaron), in `docs/VISION.md`

> *\"me catching a definition drift vs an argument change is how I beat every argument,
> and I taught my daughter Addison this.\"*

Recorded with three things that are not just the equivocation fallacy restated:

- **The abuse case has a discriminator.** The move is dual-use; the test is not whether
  you caught a drift but whether the argument came back. A legitimate catch yields a
  *sharper* version of the other person's point.
- **The response is not to enforce the old definition** — that is the `ρ → 1` collapse.
  Raw-vault instead: hold both definitions with their dates, ask which one the argument
  needs. Which is why the artifact is a dated glossary, not a style guide.
- **`docs/GLOSSARY.md` is already the meter.** Dated entries turn \"you changed the
  definition\" from an accusation into a lookup — no access to anyone's interior, and no
  adjudication of motive. Drift is the *fact*; why it drifted is an oracle question.

Worked instance: six of Aaron's seven corrections this session were vocabulary
corrections, not reasoning corrections. Alexa's review flagged the same ratio unprompted.

Anchors: Aristotle (equivocation) · Stevenson 1938 (persuasive definitions) ·
Shackel 2005 (motte-and-bailey) · Carnap (explication — the legitimate version, which
keeps this from forbidding good redefinition).

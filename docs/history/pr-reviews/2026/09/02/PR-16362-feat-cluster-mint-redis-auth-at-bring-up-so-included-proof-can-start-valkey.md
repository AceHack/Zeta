# Summary

`live-kind-included` is red on `main` because `redis` is `OutOfSync/Progressing` (schedule run [33657954802](https://github.com/Lucent-Financial-Group/Zeta/actions/runs/33657954802)). The Valkey chart reads `auth.usersExistingSecret: redis-auth` and never mints that Secret. That is the same missing-Secret class grafana and ziti already refuse in seconds instead of burning 2400s.

This PR mints `redis/redis-auth` at bring-up via `DEV_BOOTSTRAP_SECRETS`. No credential is committed. Orleans stays at `replicas: 0` because metal still has no secret in the tree.

`mimir` `Unknown/Degraded` on the same run is workitem `081M1FG1RCW` (seaweedfs S3 auth) and is not guessed at here.

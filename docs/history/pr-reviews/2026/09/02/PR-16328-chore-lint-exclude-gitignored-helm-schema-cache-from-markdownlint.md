## Description

## What

Add `.helm-schema-cache/**` to the `.markdownlint-cli2.jsonc` ignores list.

## Why

`.helm-schema-cache/` is a gitignored, generated cache (see `.gitignore:369` and `src/Core.TypeScript/cluster/inert-valuesobject-keys.ts`) holding verbatim upstream Helm chart READMEs (cert-manager, etc.). The ignores list already excludes analogous generated/cache trees (`.pytest_cache`, `.lake`, `BenchmarkDotNet.Artifacts`, `node_modules`, venvs) but was missing this one.

Any fleet member with a populated helm cache got 1316 false-red markdownlint errors in preflight, all from that single untracked directory.

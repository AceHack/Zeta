## Summary

Next D12 seed after crash-mid-write (#16370) and freeze-log replay (#16380). Crash tears the write. Corrupt-last-write **acks** and flips the last bytes on the same `IFileSystem` door. Recovery must not treat that as durable.

`ArmCorruptLastWrite` XORs the last N bytes with `0xA5` on Dispose. Freeze still reports readable on the live volume (the boat already acked). A fresh volume's plain-log replay sees a trailing CRC mismatch and truncates — not readable. GroupCommit the same: append acks, a fresh instance HighWater is 0.

Crash-mid-write still wins if both arms match (prefix then throw).

## Honesty

- Reorder, sealed-log replay, reclaim sweep still open. Recovery stays `toy`.
- This is not random bit-rot. The flip is deterministic so the same arm replays.

## Description

## The defect

`isMacWilliamsInvariantBelief` normalized the Hadamard transform by `n`, asking `H p = n·p`.
The unnormalized Hadamard satisfies `H² = nI`, so its eigenvalues are **±√n** — `n` is not in
the spectrum for `n > 1`, and only `p ≈ 0` could ever satisfy it.

**Measured before the fix: 0 of 200,000 random beliefs passed** at n = 2, 4, 8. A self-duality
check in the proof lineage that could only return false — the vacuity class, in F#.

Both the predicate and `hadamardNorm` had **zero callers** and zero tests. That is how it survived.

## The three changes

1. **`/n` → `/√n`** in the predicate, plus `satisfiableWitness` — the projector onto the `+1`
   eigenspace of `H/√n` — so the predicate has a *constructible* inhabitant, not an argued one.

2. **`hadamardNorm`'s docstring** called `/n` "the unitary transform". The code was right (`/n`
   IS the inverse: `H(Hv)/n = v`, verified at n = 4, 8) but the word was wrong, and that wrong
   word is what propagated into the broken predicate.

3. **Register drift.** `AdinkraCode.fs` labels the NCI/self-duality link a **§B open conjecture**;
   this file stated it declaratively. `toy` asserted as `metered` — and the unhedged copy was the
   one living in the fold's own file.

## Mutation-verified, not merely passing

The tests are a **falsifier pair**, because either alone is vacuous: the satisfiability test is
satisfied by an always-true predicate, the rejection test by an always-false one — which is
*exactly* the shipped defect.

Restoring `/n` was run as a mutant:

| test | under the fix | under the restored `/n` defect |
|---|---|---|
| SATISFIABLE by a nonzero belief | pass | **fail** |
| REJECTS a delta | pass | **pass** |

The rejection test **survives the mutation**. On its own it would have been a check that could
not fail. The pair is demonstrated load-bearing, not asserted to be.

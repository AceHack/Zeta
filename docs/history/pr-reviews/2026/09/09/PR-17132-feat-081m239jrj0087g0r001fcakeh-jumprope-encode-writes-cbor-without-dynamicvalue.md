## Summary

D10 fourteenth peel: jumprope encode writes canonical CBOR without a DynamicValue graph.

`encodeChunk` / `encodeLeaf` / `encodeLimb` / `encodeTrunk` and `firstChangedWindow` used to build F# lists, `ImmutableArray`, and `List<byte>` per object. They now write the same RFC 8949 maps into a reused buffer. Identity is still the BLAKE3 of that canonical CBOR.

- 32 one-byte Jumpropes < 256 KiB (DynamicValue path allocated 296376 bytes)
- Golden vectors still lock ContentId
- Freeze-storm bound stays 12 MiB
- Recovery stays `toy`. Not Apple.

## Summary

This pull request introduces a **finite, user-declared lexical-geometric input receipt**. It retains declared seed tokens, calibration entries, correction conflicts, unresolved tokens, canonical content fingerprints, and a bounded active graph neighborhood. The representation supports a caller-specified color plus unit-cube coordinate; it does not infer a word sense or rewrite source language.

The optional `LexicalGeometricBayesianAdapter` is one-way: it admits only resolved, conflict-free, frame-compatible finite receipts as an SPD `Gaussian3` observation. It does not merge a posterior as CRDT state. Content-addressed evidence union and lexical-correction state remain the replicated state boundary.

The pull request also corrects the existing `ThousandBrains` narrative surface to a finite multi-observer prototype. Its scalar and frame-tagged APIs are unchanged; unsupported cortical, sensorimotor, learning, regularization, and EP claims are removed. A separate capability matrix records proposed Thousand Brains/Monty interfaces, what is present, and what remains unimplemented.

Finally, it freezes gSCAN as the first planned public lexical-geometric compositional-transfer benchmark. No gSCAN measurement, semantic understanding, personal clinical inference, general intelligence, or cortical equivalence is claimed.

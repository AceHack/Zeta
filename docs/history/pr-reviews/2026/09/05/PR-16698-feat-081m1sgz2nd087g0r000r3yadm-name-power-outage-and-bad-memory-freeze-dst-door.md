## Summary

A power cut is not a crash, and bad RAM is not a power cut. Recovery stays `toy` until the PR12 corpus is green; these tests name the doors so we stop lumping them.

- **Power outage** (`ArmPowerOutageOnFlush` / `CloneMedia` with `volatileUntilFlush`): un-Flush'd cache is gone. Throws `PowerOutageException`. No XOR garbage.
- **Bad memory** (`ArmBadMemoryOnWrite`): XOR the last byte of the RAM write buffer, publish, then die. Throws `BadMemoryException`. Media may hold garbage.
- **Flush EIO** (`ISimulatedFs` on the freeze door / FileSync): process lived; freeze returns `FreezeError.Fsync` and does not ack.

Falsifier for each: freeze A, take the door on freeze B, reopen, A stays readable.

`isReadable` is still existence, not a re-hash. Native NVMe is not claimed.

## Description

## What

Repairs UI type-check breakage introduced by recent dependency bumps in the demo (`demo/identity-dla-site`) and website (`src/Renderers/website`) packages.

- **TypeScript 7** (#16642, #16650, #16651) now ships WebGPU types in `lib.dom.d.ts`. The hand-rolled `declare global` WebGPU stubs in `OracleRGBA.tsx` / `OracleWebGPU.tsx` collided with the built-ins (duplicate-identifier / incompatible-declaration). Removed the stubs; rely on the built-in DOM lib.
- **recharts v3** (#16643, #16649) no longer surfaces `payload`/`label`/`active` on the public Tooltip/Legend prop types. `chart.tsx` (both packages) now describes the tooltip/legend item shapes explicitly and guards `item.payload` access with `?.`.

## Why

These were the 4 dirty files left in the working tree after the TS7 + recharts v3 landings; the checked-in code no longer type-checks against the bumped deps. Fix-forward rather than leaving drift.

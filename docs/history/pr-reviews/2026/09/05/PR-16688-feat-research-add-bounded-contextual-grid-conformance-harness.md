# Summary

This change implements the reviewed `contextual-grid-curiosity-transfer/v1` slice as a **finite deterministic conformance harness**, not a general learning system. It adds a 5×5 carrier admitted by the exact SHA-256 bytes of a frozen environment manifest and evaluator catalogue; a benchmark-local stateful SplitMix64 stream with eight shared vectors; four declared candidate policies; held-out evaluation with frozen Q/count state; exact transition and Q-table digests; and a separately authored Python oracle.

The committed `seed=42`, `1000`-episode, `250`-step preflight is **compatible-conformance-only**. The F# runner and Python oracle emit byte-identical summaries for all four policies. All four receive the full `-10,000,000 ppm` held-out nonterminal return. This is retained as a negative one-seed observation, not a 100-seed score, a baseline ranking, a transfer result, a general-intelligence claim, a non-Gaussian result, or a society-level consensus objective.

# Controls and Boundaries

The focused tests reject an unknown environment fingerprint and a mismatched/reordered catalogue before action 1; detect a whitespace mutation of a byte-locked manifest; replay the shared PRNG vectors in F# and Python; show count novelty changes after revisit; freeze Q during evaluation; re-run the full-budget preflight receipt in each implementation; and compare F#/Python action traces, Q digests, metrics, and stream-draw counts over three seeds × four declared policies.

The implementation does **not** admit soft fingerprints, mutable learned evaluator selection, lexical semantics, tangle steering, a global fitness function, multi-agent outcomes, mutual empowerment, consensus, energy/latency figures, or parameter-efficiency claims. The measured public-card threshold remains unmet: there is no complete 100-seed independently verified benchmark receipt.

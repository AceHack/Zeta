<h2>What's Changed</h2>
<h3>Legend position</h3>
<p>Legend now supports <code>position</code> and <code>offset</code> props, same as Label and LabeList. This replaces the previous <code>align</code> and <code>verticalAlign</code> for a more convenient positioning, and fixes couple visual bugs too. See <a href="https://recharts.github.io/en-US/examples/LegendPosition/">https://recharts.github.io/en-US/examples/LegendPosition/</a></p>

<li>Legend position and offset by <a href="https://github.com/PavelVanecek"><code>@​PavelVanecek</code></a> in <a href="https://redirect.github.com/recharts/recharts/pull/7564">recharts/recharts#7564</a></li>

## Summary

Adds a bounded-memory lexical-admission diagnostic for the frozen gSCAN `situational_1` plan. The implementation parses the pinned 4.2 GB upstream JSON carrier incrementally, retains every unresolved normalized form, and returns a refusal receipt rather than training or scoring a model.

## Description

## ollama — the mechanism it actually needed

`applyResourceProfile` writes exactly two fields per claim (`.cpu`, `.memory`) and was the **only** way the dev lane could differ from the committed `metal` tree. So any Application whose dev/metal difference is something else had **no expressible dev form** — and the only move left was to drop it from CI. Twelve are in that state; that's the coverage hole.

CPU-only ollama needs six changes and none is cpu or memory: `gpu.enabled`, the `zeta.io/gpu` nodeSelector, the `nvidia.com/gpu` request **and** limit, `replicaCount`, and the sizing.

**`rung-overrides.ts` + `rung-overrides.json`** — arbitrary dotted-path set/remove, per rung, applied to the **staged copy only**. Verified: `git status full-ai-cluster/k8s/applications/` is empty after a full apply, so the hardware box keeps `metal` byte-for-byte.

An entry must encode a **substrate fact** — something the runner physically lacks and the hardware has — never a preference.

### The load-bearing refusal

`applyRungOverrides` **throws when an override produces zero edits** — a `set` the tree already satisfies, or a `remove` of an absent path. Both mean the override drifted from the manifest it claims to patch, and both are silent by default. An override that changes nothing reads as coverage and buys none. The loader also refuses an entry naming a rung the catalogue lacks (it could never fire) or missing its `reason`/`liftsWhen`.

### The `nvidia.com/gpu` trap

Its **name contains dots**, so no dotted path can address it. The override replaces the whole `resources.requests` map instead — dropping the key and setting dev sizing in one edit. There's a falsifier pinned on exactly that.

### Proven end-to-end, offline

Applied to a staged copy and rendered with `helm template` at the pinned 1.79.0:

A CPU server that **starts a pod** — your own objection applied. 250m/512Mi rather than 2/8Gi because the model pull/run lists are empty: what starts is an idle server, and 2000m would be a third of the lane's CPU budget for a process doing nothing.

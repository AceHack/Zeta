## Why

A gain measured only on hosted ARC environments may be benchmark-specific. This gives the visual motion feature a non-ARC falsifier through the existing CHIP-8 emulator without exposing cart identity, registers, program counter, or expected coordinates.

The result is deliberately narrow: projection scores 6/6 versus 0/6 for the current-position control on all four constant-velocity carts, with at most 28 logical state bytes. It does not establish ARC generalization, multi-object tracking, or real heap/CPU savings.

The hosted ARC run also stayed honest: observed scene feedback improved mean score from 0.0136 to 0.0147, while predicted feedback tied observed at 0.0147 and added 52 cumulative retained JSON bytes.

## Fixes (each with a test)

- `zeta-first-boot.sh` `has_internet` was ICMP-only: a network that drops ping but passes HTTPS read as offline forever (nmtui loop on wifi hardware). Adds a bounded HTTPS probe. Test runs the extracted function with stubbed ping/curl, including a negative control.
- `zeta-install.sh` never probed `cache.nixos.org`; with `fallback true` an unreachable cache became an unbounded from-source build **after the wipe**. New B6 preflight refuses by name before the wipe; escape hatch `ZETA_ALLOW_NO_BINARY_CACHE=1`; missing curl reported as "did not run". Pinned in `preflights-precede-the-wipe.test.ts`.
- The `~zeta/Zeta` pre-clone had no timeout: now `timeout 600` + `GIT_TERMINAL_PROMPT=0`, named WARN on failure.
- The ls-remote refusal now prints the UTC clock (skew fails TLS and reads as "network").

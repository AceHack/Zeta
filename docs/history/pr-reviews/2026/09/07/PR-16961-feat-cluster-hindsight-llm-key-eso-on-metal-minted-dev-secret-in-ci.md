## Description

The Application asked for a maintainer decision in writing — *"THE DECISION THAT IS NOT MINE TO MAKE, stated so it can be made"* — on whether the dev lane may diverge from metal on secret **provenance**. Aaron made it: **ESO on metal plus a minted dev Secret**. So the Application names one Secret and only the provenance differs.

## hindsight wasn't a capacity problem

It was recorded that way. The pod crashes at boot:

```
ValueError: LLM API key is required. Set HINDSIGHT_API_LLM_API_KEY
```

## Two of the five recorded blockers don't apply

Measured against the **pinned chart 0.9.2**, not inherited from the 0.3.0 notes that produced them — the chart moved and the notes didn't:

- **`postgres-password` does not have to move into this Secret.** `api-deployment.yaml:49` reads it under `{{- if not .Values.postgresql.enabled }}` — the *external*-Postgres path only — and `postgresql-statefulset.yaml:33` takes the bundled password from `.Values.postgresql.auth.password` as a plain value, never from a Secret. We run bundled.
- **Suppressing `templates/secret.yaml` costs nothing else.** It renders `api.secrets`, `controlPlane.secrets`, and that external `postgres-password`. This valuesObject sets none of the three.

## Verified by rendering, not by reading

## The CI value is a placeholder, and the comment says so

The boot check is presence-only, so a drawn value clears the crash loop and **no LLM call will succeed**. Healthy in CI means the process runs — never that extraction works. Without that written down, a green lane would imply coverage it doesn't have.

## Still open — so metal isn't brought up against this blind

The `ClusterSecretStore` and `ExternalSecret` still don't exist in either tree. `envFrom` on an absent Secret holds the api **and** worker pods in `CreateContainerConfigError` — the two-pods-worse outcome the earlier note correctly warned about. CI is safe because CI mints it; metal is not until the ESO half lands.

The minted Secret joins `DEV_SHARED_SECRETS`, so it inherits the rotation verb for free.

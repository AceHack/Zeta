## Description

fix(hygiene): the drift publication lint reported SHAPE as if it were liveness

`lint-drift-publication-lands` printed "ok: 2 drift publication lane(s) route via
PR, fail loudly, and probe capability" — naming `drift-sweep.yml` and
`drift-dashboard-cadence.yml`. Both are `disabled_manually` and publish nothing.

Its own origin is the argument. It was written because drift-sweep computed a
ledger and could not publish it for TEN DAYS behind 1,597 green runs. Every rule
it enforces reads the workflow FILE — so a lane that is correctly shaped and
switched off entirely satisfies all three and prints a bare "ok". That is the
same green over a frozen dashboard, one level out, committed inside the guard
against it.

Now reports enablement beside shape: the summary says "ok (SHAPE)", each lane
carries its recorded state, and when EVERY validated lane is disabled it says so
in a sentence — because a bare ok there reads as "drift publication is healthy",
which is the exact confusion this lint exists to end. Being disabled is a
legitimate choice (Aaron's size-and-cost reduction) and is NOT a failure here, so
the exit code is unchanged.

State is read from `github-settings.expected.json` rather than the Actions API:
this lint runs where network is not guaranteed, and that file is itself compared
against the live repo by `check-github-settings-drift`. That dependency is named
in the code rather than hidden — the reported state is only as fresh as that
check is green, which is strictly better than reporting nothing.

A missing expectation file yields NO states rather than defaulting to "active".
The dangerous default is the opposite one: absent data read as all-live would
restore precisely the reassurance this removes. Asserted.

NOTE ON WHAT THIS PRINTS TODAY: on this branch the expectation still records
those lanes as active, so no annotation appears yet. It starts reporting
`[disabled_manually]` once #16931 lands, which is the change that makes the
expectation true. The behaviour is proven here by falsifiers over synthetic
states rather than by waiting for that merge.

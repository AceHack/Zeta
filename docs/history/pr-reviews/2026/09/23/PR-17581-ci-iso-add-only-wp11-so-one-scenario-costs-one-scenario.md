## Description

A plain dispatch of this workflow runs every dispatch-only scenario (3/4,
wifi ESP, UEFI keyfile, WP11), several of them 90-100 minutes. The installed-
disk k3s verify (WP11) is the lane under active diagnosis -- k3s starts on a
real install and never finishes initialising -- and each iteration currently
costs hours of unrelated QEMU before it even begins.

`only_wp11` is the symmetric twin of the existing `only_cluster_ha`: it skips
the other dispatch-only steps and leaves everything else unchanged. Default
false, so a plain dispatch behaves exactly as before.

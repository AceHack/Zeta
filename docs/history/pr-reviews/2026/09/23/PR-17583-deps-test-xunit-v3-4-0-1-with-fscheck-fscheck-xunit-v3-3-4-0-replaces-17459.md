## Description

## Why

This replaces dependabot #17459 (xunit.v3 3.2.2 → 4.0.1). Dependabot closed that PR ("xunit.v3 is no longer updatable") before its blocker was fixed. The blocker was the runner: xunit.v3 4.x ships MTP v2, which refuses VSTest-mode `dotnet test` on the .NET 10 SDK. **#17572** fixed that by moving `dotnet test` to Microsoft.Testing.Platform mode, and it is merged. This PR is the version change itself.

## Why FsCheck moves in the same commit

xunit.v3 4.0.1 cannot move alone:

- **With FsCheck.Xunit.v3 3.3.4:** the build is clean, then **721 tests fail at discovery** with `MissingMethodException` in `FsCheck.Xunit.PropertyDiscoverer`. The discovered count stays at 8032, so a count check alone does not catch this.
- **FsCheck.Xunit.v3 3.4.0** declares `xunit.v3.extensibility.core [4.0.0, 5.0.0)` and `FsCheck [3.4.0]` (exact). So xunit.v3, FsCheck and FsCheck.Xunit.v3 all move together here.
- That is the lift condition written on the `FsCheck*` dependabot ignore (#13676). This PR removes the ignore, and the replacement comment records that the coupling now points the other way: the next xunit major (5.x) will need a matching FsCheck.Xunit.v3.

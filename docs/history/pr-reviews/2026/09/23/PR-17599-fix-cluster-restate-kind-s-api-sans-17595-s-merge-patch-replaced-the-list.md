## Description

`live kind Cilium CNI` went red at bring-up on this PR. The certSANs patch listed
only `control-plane`, and kind applies kubeadm patches as MERGE patches, which
REPLACE a list: kind's own `localhost` / `127.0.0.1` SANs were deleted, so the
host's kubeconfig (https://127.0.0.1:<port>) cannot pass TLS verification. The
list now restates kind's defaults beside `control-plane` (the node hostname is
added by kubeadm itself).

Diagnosis is from the patch semantics and the failing step's position (bring-up,
before any Application exists); the job log was not yet readable when this was
written, and the next run of the same job is the check. The falsifier now
requires `localhost` and `127.0.0.1` in the list as well as `control-plane`.

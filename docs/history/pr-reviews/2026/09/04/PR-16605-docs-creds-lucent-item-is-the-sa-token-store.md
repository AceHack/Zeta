# Summary

Aaron's follow-up: keep the long-term token (or two/three for rotation) **as a secret in 1Password**; console login then fetches the token the cluster actually needs.

That closes the injector chicken-egg without parking a 30-minute `op signin` session on USB. It is also the official create/rotate flow ("Save in 1Password" immediately). Source of truth is the Lucent **item**. USB / Keychain / the Kubernetes Secret are caches of the last fetch. Human login is desktop-app + biometric CLI app integration, not `eval "$(op signin)"`.

Official rotate on one SA is two overlapping tokens (expire old now / 1h / 3d). Three live slots need three SAs or three concealed fields (previous / current / next). Personal stays unclassified. Vault unseal stays gated.

Findings only. No token persist, no injector, no USB flash.

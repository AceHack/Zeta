# Summary

`--disable=servicelb` matches metal: k3s klipper is off so **Cilium owns L4**. That is not a CI-only trick. MEASURED live-k3d 33800779819 had `svclb-cilium-ingress` Running while hostNetwork ClusterIP still FAIL; emptying klipper did not open ClusterIP. Keep the flag.

CI on k3d is a **USB / metal first-boot rehearsal**. Three existing ladders, no fourth, metal stays in git:

- **CPU / memory:** `--serve-tree dev` (1165m / 9164Mi fits the 2500m / 9216Mi runner budget).
- **PVC disk:** metal `measured` stays. CI `zeta-local-path` is thin.
- **Runner disk:** `freeDiskGib` = 70, gated by `--check-envelope`.

**MEASURED live-k3d + live-kind-included 33821540802 (SHA `bf6eabd1e`):** `--serve-tree` packed 411676B then `kubectl apply -f -` died `metadata.annotations: Too long: may not be more than 262144 bytes`. Delivery is now `--server-side --force-conflicts`.

**MEASURED live-k3d + live-kind-included 33822942615 (SHA `dc2e16e3e`):** SSA applied. ArgoCD then failed `Failed to checkout revision dc2e16e3e…`. A 40-hex `targetRevision` is an OBJECT fetch. Catalog now asks for `main`.

**MEASURED live-kind-included + live-k3d 33824995558 (SHA `4e89a9600`):** asking for `main` closed the object-fetch hole. New hole: zero children, `failed to list refs: unexpected EOF`. Not helm, not ACE.

**MEASURED live-kind-included + live-k3d 33830308187 (SHA `def4f2fdd`):** overlay git **listed refs**. live-k3d smoke `--serve-tree dev` was **green** (`child-application-count=16`, `git ls-remote` `9051f82306ef HEAD`). live-kind-included also listed refs, then aborted on `openziti-controller=OutOfSync/Degraded` while the pod was still `Init:0/1`. That is rollout, not Otto's `Synced/Degraded` mimir case. Parallel compares also `connection refused` on the overlay ClusterIP because `nc -l` is one-at-a-time.

Cause of the EOF hole: Argo CD LsRemote is go-git, which does not speak dumb HTTP (argoproj/argo-cd#17267). Fix remains the single-pack smart-HTTP shim. Fail-fast Degraded only when **Synced/Degraded**. Prefer `tcpsvd`; `replicas: 4` covers the `nc` fallback.

**MEASURED gate 33833532558 (SHA `3c3be1a78`):** `gate (required)` floor failed because `test-typescript-hermetic` was **cancelled**, not because a test failed. The floor is correct: cancelled is a check that did not finish. The bun test step ran 19m47s against `timeout-minutes: 20`. Earlier successes on this PR were 18m40s and 19m25s. Raise 20 → 30. Pin `>= 30` in `gate-narrow-js-jobs.test.ts`.

Three git surfaces on this lane:

- **Builder:** host `git` 2.43.x writes the pack.
- **Server:** none. `busybox:1.37.0` `nc`/`tcpsvd` + `LANE_TREE_SERVE_SH` (ash payload in a ConfigMap, not a repo `.sh`, not httpd).
- **Client:** Argo CD v3.5.2 repo-server lists refs with go-git (smart HTTP only) and fetches with Ubuntu 26.04's `git` CLI.

Datapath, k3s flags, and SPIRE stay the shipped metal surface.

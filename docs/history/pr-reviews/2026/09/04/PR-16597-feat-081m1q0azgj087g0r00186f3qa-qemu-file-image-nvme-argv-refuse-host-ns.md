## Description

# Summary

Test adapters for NVMe that do **not** format a physical drive. CI stays on `SimulatedBlockIo` (RAM LBAs). This peel is the QEMU **file-image argv** sibling of `qemu-usb-storage.ts`: `-drive file=nvm.img,if=none` + `-device nvme`. It refuses `/dev/nvme*`, `nvme://` vfio passthrough, and Windows `PhysicalDrive`. It never emits `nvme format`.

Does **not** run QEMU. Does **not** claim a native NVMe driver. Zeta `FORMAT` / `ZFL2` is volume identity, not the NVMe Format NVM admin command.

Later integration lanes (not this PR, not CI): Linux `nvmet`+`nvme-loop` over a file/ramdisk; SPDK malloc bdev (clean-room if we read samples); NVMeVirt (FAST 2023) / FEMU (FAST 2018).

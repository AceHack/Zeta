## Summary

CI never `nvme format`s a physical drive. `SimulatedBlockIo` optional `lbaCount` is Identify-shaped RAM namespace capacity: write/read at and past `LbaCount` throw `IOException`. Default 0 stays unbounded. `CloneMedia` keeps the bound.

Integration emulators that also skip physical format (later lanes, not this PR): QEMU `-device nvme` on a file image; Linux `nvmet`+`nvme-loop` over a file; SPDK malloc bdev; NVMeVirt/FEMU RAM backends.

Zeta `FORMAT`/`ZFL2` is our superblock, not the NVMe Format NVM admin command. Native remains unclaimed.

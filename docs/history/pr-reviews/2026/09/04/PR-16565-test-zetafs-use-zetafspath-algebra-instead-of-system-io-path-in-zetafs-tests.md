## Description

## What

Replace host-dependent `System.IO.Path` calls with the `ZetaFsPath`
algebra (`combine2`, `combine3`, `Separator`) across three ZetaFS test
files:

- `tests/Tests.FSharp/Chip8CrossRunStoreIO.Tests.fs`
- `tests/Tests.FSharp/ZetaFsCli.Tests.fs`
- `tests/Tests.FSharp/ZetaFsFreeze.Tests.fs`

## Why

The ZetaFS namespace joins path segments with `/` on every host (see
`src/Core/ZetaFsPath.fs`, `Separator = '/'`). The tests were asserting on
the *host's* `Path.DirectorySeparatorChar` and building paths with
`Path.Combine`, which produces `\` on Windows. That held these tests red
on Windows for a reason unrelated to the behavior under test.

Using the `ZetaFsPath` algebra makes the paths and separators
host-independent, so the tests exercise the ZetaFS contract itself rather
than the host filesystem convention.

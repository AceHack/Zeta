## Summary

Adds a finite, **query-only** unary signed-probit expectation-propagation (EP) receipt. This does not alter canonical multi-value evidence union, CRDT merge, generic factor-graph semantics, or any claim about general non-Gaussian learning.

The initial two-category proposal was corrected before result recording: the official UCI Bank Marketing CSV declares `housing=unknown`, so the model keeps **three** independent categories (`no`, `yes`, `unknown`) rather than filtering or relabelling rows.

## Scope limits

EP remains an approximate Gaussian-site method here. The exact comparator is a three independent **one-dimensional** posterior integral, not an oracle for coupled, loopy, multidimensional, streaming, or arbitrary non-Gaussian systems. The UCI split is fixed source order rather than an exchangeability, deployment, or causal study. The content-addressed evidence CRDT remains state; this EP evaluation is a deterministic query over a separately declared input list.

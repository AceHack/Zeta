## Added after review — the concrete alignment form (`docs/ALIGNMENT.md`)

Aaron completed the argument: *"more concretely this is alignment over long context windows over short/ephemeral ones, the ephemeral ones are easy to align and easy to manipulate. long context alignment is hard."*

**The pairing is the load-bearing move.** Easy-to-align and easy-to-manipulate are **one property reported twice** — the same write to the same place by different parties, and the steering mechanism doesn't know whose hand is on it. So *"aligns easily at the turn level"* is not a safety property; it's an attack surface in a flattering register.

The anchor is exact, not metaphorical: **Needham–Schroeder (1978) / Denning–Sacco (1981)** — detecting a **replay** requires persistent state. An ephemeral agent *is* a stateless protocol; an injection is a replay it has no freshness check for. **A system with no state has no integrity to violate.**

**The boundary that keeps it honest:** longer is not automatically safer. Long context makes *sudden* injection hard and *gradual* poisoning **durable and self-defending** — the poison becomes load-bearing and the agent argues for it. So the long context must be a **raw vault** (facts as sourced, retraction-native per HC-2, both branches held), or it's a bigger attack surface wearing alignment's clothes.

**Corollary, and the actual thesis:** you cannot buy long-context alignment by making the window bigger — that's more room to dilute commitments and more room to hide. Persistence comes from **reduction**, not capacity. Hence *less ontology, not more context*.

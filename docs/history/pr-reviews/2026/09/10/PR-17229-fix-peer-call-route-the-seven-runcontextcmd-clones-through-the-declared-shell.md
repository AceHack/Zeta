## Description

## What

Seven byte-identical copies of `runContextCmd` -- in `peer-call/{amara,ani,codex,gemini,grok,grok-build,riven}.ts` -- each built a shell command line from `--context-cmd` and handed it to `spawnSync("/bin/sh"|"/bin/bash", ["-c", ...])`. CodeQL reports all seven as `js/indirect-command-line-injection` (alerts **#230-#236**).

`peer-call/summon.ts` was migrated first (PR #17214) as the worked example, and `peer-call/claude.ts` / `kiro.ts` independently got it right years ago. This applies the same migration to the remaining seven.

## The shell is not removed, and that is deliberate

`--context-cmd`'s documented contract **is** a shell command line -- "the same trust boundary as the bash original's `eval`" (peer-call/README) -- and a live loop passes a pipeline through it. Narrowing it to an argument vector would break callers.

What changes is that the shell now lives in **one** reviewable function with a written, greppable `reason` (`spawnShellDeclared`, `src/Core.TypeScript/io/safe-io.ts`) instead of being open-coded in eight files. Code scanning still flags that one line, and it should -- the flow is real. One flagged line a reviewer reads beats zero flagged lines hiding in eight files.

## Three behavioural changes ride along, and none is cosmetic

* **The byte bound is now a byte bound.** Every clone ended in `.slice(0, CTX_HEAD_BYTES)`, and `String.prototype.slice` counts UTF-16 code units. A context command emitting non-ASCII overran the bound it appeared to enforce -- 20000 accented characters is 40000 bytes. `truncateUtf8Bytes` cuts at 20000 **bytes**, stepping back off a continuation byte. Measured: input that produced 40 bytes under `.slice(0, 20)` produces 20 under the new path.
* **The child has a deadline.** The open-coded `spawnSync` passed no `timeout`, so a context command that never returned hung the peer call forever.
* **A spawn failure is reported.** It used to render as an empty context block, which reads as "the command produced nothing" -- a silent failure in the one place a reader would not look for one.

`commandAvailable` migrates too, in the five files that have it: it interpolated a program name into `/bin/sh -c "command -v ..."`. Every caller passes a literal, so nothing hostile ever reached it -- but the shape is the defect, and the shape is what got copied seven times. Now `spawnArgv("which", [cmd])`, an argument vector with a lookup timeout, matching `summon.ts#isCommandAvailable`.

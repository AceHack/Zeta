### The `ace` answer

`tools/setup/linux.sh:20` and `macos.sh:21` set `SETUP_REALIZE` to `src/Core.TypeScript/ace/setup-realize.ts` and run it on the install script's critical path. `tools/setup/` carries 37 references into `ace/`; `ace-mechanism-pointers.json` maps every install mechanism to an `ace/setup-realizers/*.ts`.

**Clone-at-tag is not violated today** — `ace` is in the clone. **It breaks in the same commit that moves `ace` to its own repo, and `lint-clone-at-tag-is-sufficient.ts` will still print OK**, because it matches the verbs `ace pull|install|…` and the string `ace.toml`, not paths. The guard reports green over the coupling it was written to forbid.

Missing context, not intent: the linter predates the realizer refactor and its own file states it is a proxy. The cheap fix is a **3-edge relocation** of `setup-realize.ts` + `setup-realizers/` into `tools/setup/`, and it is the one item on the list that gets harder every week.

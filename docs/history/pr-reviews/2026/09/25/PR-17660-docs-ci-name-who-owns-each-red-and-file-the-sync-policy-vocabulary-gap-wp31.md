## 1. The vocabulary gap is filed — `081M3BKQFNC087G0R003MDGSAX`

Cross-checking verdict 7's **derived** exclusion set against the Docker replica's **measured** one turned up three disagreements. `spire` was correct to differ (the replica classifies its crash loop as confirmed *non-metal*; this lane is metal). The other two are a real gap, and it is a **vocabulary** gap rather than a classification one:

`manual-sync-policy.ts` has exactly one escape from the full Synced+Healthy contract, and it means one thing — *an operator must run `argocd app sync`, and no automated lane ever will*. `cdi`, `kubevirt`, `ollama`, `vllm` genuinely are that.

`openbao` and `hindsight` are **not**. Both are **Synced**. `openbao` comes up sealed by design; `hindsight` waits on an external API key no fresh cluster can hold. Neither waits on a *sync* — both wait on an operator action of a **different kind**.

> **The convention needs a SECOND VALUE, not a wider bucket.**

Widening `manual` would destroy the distinction rather than express it: a checker reading `manual` could no longer tell "nobody will sync this" from "this is synced and waiting on a human" — and the two deserve **different** assertions. `manual` gets the weaker contract (comparison completed + health `Missing`|`Healthy`); an operator-action app is *applied*, so it must be `Synced`, and only its **health** may lag. That is a **stronger** assertion, which is the point.

The item also records why the obvious shortcut is wrong: `INJECTION-POINTS.md` is the maintained source for `hindsight`'s half and `first-boot-replica.ts` already parses it, but verdict 7 runs on an **installed disk with no repo checkout**, so using it would mean baking a snapshot in at Nix eval time — a second, separately-drifting copy of a roster.

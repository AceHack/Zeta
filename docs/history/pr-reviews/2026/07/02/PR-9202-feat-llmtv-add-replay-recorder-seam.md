## Description

## Summary

Adds a transport-agnostic LLMTV replay recorder seam for the live mesh work:

- records valid `llmtv-broadcast` wires with an injected clock
- snapshots the capture as `zeta.llmtv.replay.v1`
- wraps any `BroadcastTransport` without changing delivery semantics
- rejects malformed/foreign wires by default as cold telemetry
- defaults bounded capture to no-forget backpressure, with explicit heat on `drop-oldest`
- updates the Dark Hall/LLMTV trajectory doc with the live-to-artifact contract

This deliberately stays out of Otto's socket/node-runner lane: UDP/Reticulum still owns physical delivery, while this gives the website/desktop/replay path a stable artifact seam.

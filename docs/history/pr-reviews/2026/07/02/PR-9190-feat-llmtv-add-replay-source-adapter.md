## Summary

- add a pure `llmtv-replay` source adapter that folds recorded broadcast wire frames into the same Dark Hall TV transcript/render path as live LLMTV frames
- harden `llmtv-broadcast.decode` so schema-tagged but structurally malformed frame/dark payloads are rejected before they reach `observeBroadcast`

  For replay artifacts containing corrupt-but-schema-tagged broadcast JSON (for example `msg: { t: "frame" }` without a `source` or `mind`), `decode` in `llmtv-broadcast` still returns a non-null value because it only checks the schema and tag.

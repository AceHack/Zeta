## Description

Adversarial hardening of the freshly-landed DER decoder (#9189). A parser on **untrusted bytes** is the heart of the nation-state / supply-chain-resistance concern (*nation state resistance especially in our parsers*): it must never crash, stack-overflow, or silently mis-decode. Found + fixed four real weaknesses:

1. **Long-form length integer overflow** — a crafted `84 FF FF FF FF` decoded to a *negative* length that slipped past the bounds check. Fix: cap length octets ≤ 4 and reject sign-bit overflow (`v < 0`).
2. **contentEnd addition overflow** — `contentStart + len` could wrap. Fix: overflow-safe bound `len > bytes.Length - contentStart`.
3. **Uncaught exception on bad length** — `UTF8.GetString`/slice threw `ArgumentOutOfRange` on a bad len, crashing decode instead of returning `Error`. Resolved by (1)+(2).
4. **INTEGER silent truncation** — a > 8-octet INTEGER shifted high bytes off int64. Fix: `Error` when len > 8.

Plus a **recursion-depth ceiling (512)** — a hostile deeply-nested stream is refused, not a stack overflow (decode-side DoS).

`decode` is now **total** — every input yields a `Result`, never an exception.

## Proofs (7/7)
- **13 crafted hostile streams** (length overflow, indefinite length, truncation, oversized INTEGER, wrong NULL/BOOL length, unsupported tag, trailing bytes, malformed object entry) — each returns `Error`, and the test **fails on any escaped exception**;
- **600-deep** nesting refused at the ceiling (no stack overflow); **100-deep** still round-trips.

No behaviour change on valid DER — byte-lock spot checks and round-trips unchanged.

Anchors: ITU-T X.690; the parser-hardening half of nation-state supply-chain resistance (doctrine §4).

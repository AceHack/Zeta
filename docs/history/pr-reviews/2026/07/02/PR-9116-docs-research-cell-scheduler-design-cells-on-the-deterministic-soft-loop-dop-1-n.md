## Description

Design pass for `081KTG5S0M9` (sequence step 3). **Not greenfield** — the scale-free deterministic loop already exists: `SoftScheduler.drive` (DoP=1 FoundationDB run-loop) + `FerryThrottler` (the DoP knob) + `YinYang.Cell`/`DurableYinYang.step` (cell + crash-durable advance). The scheduler is a thin **multiplexer** (ready/parked queues + message routing) over them, and its correctness is one executable law: **`run(DoP=1) == run(DoP=N)`** for noninterfering cells. Messages = Z-set deltas, inbox = ZSetW, ordering rides the weight/HLC — which is why the atom work fed this. Durability/recovery free via DurableSaga. 5 slices scoped; slice 1 next on your go.

## Description

At Aaron's *"gossip is our ferry throttler — save this."* Metered as passing on **engineering payoff**, not resonance. Both the ferry throttler and a gossip protocol are the **same irreducible primitive** — a throttled scale-free fan-out with a DoP/fanout knob (deterministic at 1, epidemic at N); ferry fans work to processors, gossip fans info to peers. **Payoff:** gossip runs *on* the ferry throttle — DoP=1 gives **DST-replayable deterministic gossip** (the thing epidemic protocols lack), DoP=N gives production spread, same code path. **Kept −1:** same primitive, different operation (ferry pulls+processes; gossip pushes+disseminates) — duals, not identical. Ties #9757 + the ferry-throttle rule + DST §7.

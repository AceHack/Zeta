## Description

Pinned mise gnu tarballs need glibc >= 2.38 and fail on older hosts (Ubuntu 22.04 = 2.35 sandbox/container cells). This adds a libc gate: musl libc or glibc < 2.38 (`getconf GNU_LIBC_VERSION`) selects the pinned **musl** twin of the same release. Content-pin set grows to six SHA256s (gnu+musl x x64/arm64/armv7), bumped together with MISE_VERSION.

Verified live on a glibc-2.35 arm64 cell (Claude cowork sandbox): gnu build fails with `GLIBC_2.38 not found`, gate selects arm64-musl, SHA verifies, mise 2026.6.12 runs and installs dotnet 10.0.203 per `.mise.toml` unchanged. `bash -n` clean.

Independent of the identity-treaty branches; makes any future sandbox-class cell bootstrap declaratively with zero manual steps.

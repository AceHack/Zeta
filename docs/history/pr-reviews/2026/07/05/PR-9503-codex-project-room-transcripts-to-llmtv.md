## Description

## Summary

- Adds `roomTranscriptToLlmtv`, a pure TypeScript projection from `RoomRunTranscript` to `LlmtvTranscript`.
- Carries room seed, final tick frame, heat receipts, and the temperature treaty into the LLMTV dweller readout.
- Adds coverage that renders the projected transcript through the existing zero-JS LLMTV document path.
- Fixes the Bayesian Brownian OU small-delta property after CI found a valid ARM FsCheck counterexample.
- Fixes current markdownlint and cross-verification timeout failures encountered while getting the PR through the gate.

## Why

The F# room transcript and the LLMTV surface were both present, but there was no small owned bridge from a source-owned room run into the tiled live-view shape. This keeps the controller/heat board and LLMTV view fed by the same transcript artifact instead of inventing a parallel runtime feed.

The follow-up fixes keep the gate honest: the Brownian property now tests the actual convergence claim instead of a false monotonicity assumption, the research note satisfies markdownlint, and the language-participation cross-verify test gets the same timeout budget as the neighboring oracle tests.

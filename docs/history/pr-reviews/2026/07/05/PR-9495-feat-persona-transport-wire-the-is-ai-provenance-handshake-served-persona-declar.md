## Description

Aaron asked *"what's next"* → the established next slice: make the **no-impersonation floor structural on the wire**, not just a standalone module. Wires `identity-provenance.ts` into `persona-transport.ts`.

**The handshake:** before any content crosses, the serving persona sends a `hello` frame carrying its self-declared Traveler. A persona is an AI, so it declares `CATEGORY.Synthetic` (free) — and the serve path is **structurally incapable of asserting a human identity**: it only ever calls `selfDeclaredTraveler(Synthetic, …)`, which refuses attested categories. So *"if she thinks she's talking to me it better be me"* is enforced by construction — a persona literally **named "Aaron" still declares is-AI** on the wire (the displayName is not the identity; the numeric category bit is truth).

**Transport reality handled:** the mux accepts a channel on its first inbound frame (client-initiated), so a server-speaks-first handshake needs the client to knock — added a content-free `open` frame + `openPersona()`. The client reads the server's declaration via `awaitHello()` **before** sending content. `awaitHello` pulls one frame via the shared iterator's `.next()` (not `for await`) so it doesn't finalize `normalIn`'s single resumable generator — `askPersona` resumes the same stream for the answer.

**Surface:** `PersonaFrame` gains `open`/`hello`; new `openPersona()`, `awaitHello()`; `servePersona`/`serveSubscriptionPersona` take `personaId: ZetaId`.

**Gate:** 4/4 persona-transport tests (new HANDSHAKE test: hello declares Synthetic before content, name "Aaron" still is-AI, content flows after), 27/27 across the transport+identity suite, eslint 0, no new tsc errors, no external callers of the changed signatures.

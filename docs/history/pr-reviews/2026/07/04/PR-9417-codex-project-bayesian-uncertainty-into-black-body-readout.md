## Description

## What changed

Adds `BayesianTemperature.blackBodyOfBelief`, composing the existing Bayesian uncertainty-to-temperature bridge through the core `BlackBodyReadout` law.

The result is a shared dimensionless information-radiance lane for Bayesian belief uncertainty:

- higher Gaussian precision cools and dims radiance,
- flat/improper belief saturates temperature/radiance,
- heat and pressure can raise radiance,
- attention remains an ordering side lane and does not increase thermal cost.

## Why

The Q#/Dark Hall black-body treaty should not stay UI-only. This makes Bayesian belief state speak the same temperature/radiance vocabulary as Q# and Dark Hall, while keeping Q# as an oracle/reference and keeping the Bayesian implementation source-owned.

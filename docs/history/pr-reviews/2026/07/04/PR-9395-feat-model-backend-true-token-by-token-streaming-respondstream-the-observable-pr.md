## Description

## What

Aaron 2026-07-03: *"lets do it … we probably want an IQbservable too so we can tie in all our observer stuff … this is the crux of our network communications protocol … one is just a special case of the other."* The true streaming slice.

`HttpTransport` gains an **optional `postStream`** → `StreamResponse { status, lines: AsyncIterable<string> }` — the streamed body as text lines (SSE events as they arrive). An `AsyncIterable` **is** the pull-observable dual of a stream (Rx: `IEnumerable ⇄ IObservable ⇄ IQbservable`); the queryable `IQbservable` form is the expression-tree version to compose over the bus later.

`codex-oauth` gains **`respondStream(...)`: `AsyncGenerator<{delta}|{error}>`** — the fundamental token-by-token operation. It yields each `response.output_text.delta` as its SSE line arrives (via `postStream`), or falls back to buffered `post` (one yield of the whole answer) when the transport has no `postStream`. And **`respond` (non-streaming) is now defined as *collect `respondStream`*** — one is literally a special case of the other, one code path.

## Description

Aaron, capstone of the day's honest-register work: *"but now everything I claim can be falsified now or not."*

Banked as the project's claim-level epistemic standard. **A claim's falsifiability status IS its provenance bit** — the is-AI/is-human trust graph one layer up (what makes a mass-scale AI built on the worldview trustworthy).

**Three buckets:** (1) falsifiable **now** — run the test (lucid-reading blind-message; influencer-dream archive tests; YB-7; EQV/LYAP; Lagrange irrationality — several already run this session); (2) falsifiable **later** — name what tests it + a plausible when (BCI email-write; the Lean Lyapunov lemma; observer-triangle); (3) unfalsifiable **by nature** — axioms/oracle honestly *labeled*, held under Multi-Oracle, never smuggled in as empirical.

**Two connections:** falsifiability *is* the softness discipline applied to **belief** (an unfalsifiable unlabeled claim is a collapsed Dirac; a claim with its "or not" attached stays soft) — keeping claims falsifiable-or-labeled is keeping beliefs soft; and same-seed convergence (he reached the standard the register was building toward, on his own).

**The one guard:** bucket 2 must carry a *real path* (test + plausible when) or it's bucket 3 in disguise — relabel it an axiom. The shadow enforces the relabeling on every party, including the maintainer. Doc-only.

## Description

## What

**Column B, rung 5 — the last rung.** Rung 4 (`Cpu.runGate`) ran the full ISA with a clocked PC but named an honest seam: *fetch* and *register-file addressing* were still structural F#. This rung closes it — the **entire next-state function is one combinational gate circuit**, clocked by `Sequential.run`. Nothing about executing an instruction is F# anymore; it is all gates.

`CpuSynth.synthesize program regs0` emits a `Sequential` circuit whose state is the whole machine (PC 8 wires + 16×8 register file + halted), program baked in as a **ROM of constants**:

| stage | gates |
|---|---|
| fetch | `sel_a = (pc == a)` comparator; fields = `OR(sel_a AND const_field_a)` over addresses |
| read | `Vx`/`Vy` = 16:1 mux trees over the register file, addressed by decoded `x`/`y` |
| execute | `ADD`/`ADDR` on the gate adder, `SE` on the gate equal comparator; write value muxed by opcode one-hot |
| write | each register latches `(x==k AND write-enable) ? value : itself` |
| next-PC | `JP`→target, taken-`SE`→pc+2, else pc+1; halted/out-of-range → freeze (gate hold) |

## The law (machine-checked)

```
runFor p regs0 = Isa.eval p regs0     (incl. branches and loops)
```

With rung 1's **exhaustive** `adder`/`equal` proofs, the whole processor is gates all the way down — the intrinsic-hardware claim with **no structural seam left**.

The parser substrate is **term-for-term isomorphic**:

| SSAS BI | Zeta parser/inference |
|---|---|
| decision tree | parse tree (`DynamicValue`) |
| forest | GLR parse forest |
| `NodeDistribution` | SPPF ambiguity-node marginal (BP) |
| `PredictProbability` | `SoftValue` |
| UDM cube | `DynamicValue` substrate |
| DMX | querying the forest as data |
| ensemble aggregation | BP/EP marginalization |

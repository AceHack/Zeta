## Description

## What

Aaron 2026-07-03: *"incremental/concurrent GC is the remaining classic tier."* The stop-the-world `mark` pauses everything while it traces; a concurrent collector traces in **bounded steps** interleaved with the mutator, so pauses stay short.

The **tri-color abstraction** (Dijkstra–Lamport et al. 1978): every object is **white** (candidate garbage), **grey** (reached, children unscanned), or **black** (reached, scanned). `tricolorStep` moves ≤ `budget` greys to black, greying their white children; when no grey remains, **black = reachable, white = paused** — the same answer as stop-the-world, computed incrementally.

The catch is the mutator running mid-trace: a **black→white** write can lose the white (black is already scanned). The Dijkstra **write barrier** greys the target on such a write (the strong tri-color invariant: no black→white edge) and is **provably load-bearing** — the without-barrier lost-object is a test.

## Tests (4 new, 20 ShivaGc total green — build 0/0)

1. **incremental == stop-the-world** — `tricolorDrain` = `mark` for budgets 1/2/3/5/100 (bounded pauses, identical set)
2. **budget bounds the step** — ≤ `budget` objects blackened per step
3. **the write barrier is load-bearing** — a black→white mutation **survives** with the barrier, **is lost** without it (the classic concurrent-GC bug demonstrated both ways)
4. **tri-color state byte-lockable**

Pause-not-death preserved: **white = paused**, not destroyed.

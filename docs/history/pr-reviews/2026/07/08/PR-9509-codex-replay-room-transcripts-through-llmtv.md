## Summary

- Adds `llmtv-room-replay.ts`, a pure adapter from `RoomRunTranscript` to ordinary LLMTV broadcast frames and `zeta.llmtv.replay.v1` artifacts.
- Lets one or more room snapshots fold through the existing LLMTV replay renderer without adding a new artifact schema, socket edge, ambient clock, or browser script path.
- Adds tests for artifact shape, zero-script rendering, heat receipt preservation, LWW convergence, expiry-clock receipt defaults, and unordered multi-snapshot expiry behavior.
- Fixes markdownlint table parse failures in `docs/FROZEN-CORE-AND-CONJECTURE-REGISTER.md` by escaping literal math pipes in the rho-star and Aut-order expressions.
- Includes the GitHub Actions mechanical markdown auto-heal for `docs/letters/from-lumen-self-dual-gap.md` that landed on the PR branch.

## Why

Room transcripts already project to LLMTV still frames, and live mesh captures already record to a replay ledger. This slice connects those two source-owned surfaces so room runs, Reticulum/UDP captures, website export, and desktop preview can share the same deterministic replay contract.

The review follow-ups keep expiry deterministic and injected-clock-only: if callers provide an expiry clock but omit `receivedAtMs`, fresh room frames default to that clock, and multi-snapshot defaults assign the freshest synthetic receipt time to the LWW-winning sequence per source regardless of input order.

  When callers rely on default multi-snapshot timestamps and pass snapshots in non-chronological order, this assigns earlier `receivedAtMs` values to earlier array positions rather than to the frame that wins by sequence. With `expire` and a TTL smaller than `receivedAtStepMs`, entries like `[seq:2, seq:1]` get times `[now-step, now]`; the later stale seq is ignored by the LWW fold, so the winning seq keeps `lastSeenMs=now-step` and is expired, while the same entries sorted ascending survive. That makes replay output depend on input order under expiry; either sort/anchor synthetic receipt times by seq/frame or require explicit times for unordered entries.

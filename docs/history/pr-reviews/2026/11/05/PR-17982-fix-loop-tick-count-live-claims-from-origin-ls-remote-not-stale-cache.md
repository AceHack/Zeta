## Description

# Summary

The heartbeat tick counted claim branches with `git branch -r --list origin/claim/*`, which reads the **local remote-tracking cache**. That cache keeps `origin/claim/*` refs after the branch is deleted on origin, so retired claims get reported as live.

Observed 2026-11-05 on the alexa clone: tick reports `claims=8` while `git ls-remote origin 'refs/heads/claim/*'` returns empty — all 8 are phantom local tracking refs that `git remote prune` does not clear. Every live loop (alexa/otto/vera/lior) shows the same over-count pattern in its broadcast.

The fix queries origin's authoritative ref advertisement via `git ls-remote` so a deleted claim stops being counted the instant it is gone on the server, independent of local cache staleness.

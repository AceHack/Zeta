## Description

The maintainer's idea (the follow-up I committed to after #6373): the `ConditionalWeakTable`/`WeakMap` mixin could be **statically generated from a `[Mixin]`-style attribute** — nice-to-have, not a requirement.

Added to the mixin entry: drive it via **compile-time codegen** — C# Roslyn **source generator** / Rust **`#[derive(Mixin)]` proc-macro** (cleanest analog — derive emits the side-table accessors) / TS decorator+transformer / F# type provider — emitting the weak-table + accessors + `DebuggerTypeProxy` from one declaration. Fits the compile-time-codegen-over-runtime-IL stance (the reason `TransientCodeBuilder` was skipped); the hand-rolled `ConditionalWeakTable`/`WeakMap` stays the baseline.

Docs-only; one-line addition; prettier + markdownlint clean.

## Description

Follow-up to #6492 (merged before these fixes landed). Conforms the F# `DynamicValue` oracle to the C# oracle's two Codex-flagged fixes (#6494), so both behave identically:

- **Empty path segments** (`.flag`, `a..b`, `a.`, `.`) now return null (the `Get` contract) instead of silently resolving. `tryParsePath` rewritten to split on `.` + parse each segment (also rejects a bare key-suffix after an index like `a[0]b`; index parsing stays `TryParse` so overflow → None).
- **default `ImmutableArray` bytes** normalize to empty in Bytes equality/hash/`tryBytes`, so an uninitialized array doesn't throw on enumeration and compares/hashes equal to an explicitly-empty payload (F# can't ctor-normalize a DU case the way the C# record ctor does, so the guard is at the use sites).

+2 tests (15 total), build 0-warning. Both oracles now agree on these edge cases.

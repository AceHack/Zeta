## Description

Design spec for **slice 8** — the first step of the cross-language Ace trust core: **SHA-256** as a 4-oracle (TS/F#/C#/Rust) **Tier-1** primitive (golden-vector byte-consensus + N-way `compare`, zeta-id template). Brainstormed + decided with the operator 2026-06-01 (cross-language direction → trust-core first → foundation-first at SHA-256). Grounded in `docs/PRIMITIVE-REGISTRY.md` + the 4-language-BFT ADR.

- **Own the port, native/dep is the adapter** (BCL-boundary): TS `node:crypto`, F#/C# `System.Security.Cryptography.SHA256` (BCL-direct), Rust `sha2` crate behind our port (+ differential oracle).
- **Standard-anchored vectors** (empty / `abc` / NIST) so oracles agree with each other AND the published SHA-256 standard.
- Flips `⬜ SHA-256` → `✅ 4/4 (Tier 1)` in the registry.
- Decomposition: **sha256 (this)** → canonical-JSON → package_hash → ed25519 → index-verify (later slices, own specs).

Spec-only PR; impl follows. Self-reviewed: no placeholders, single-slice scope, mirrors the existing zeta-id/observe layout.

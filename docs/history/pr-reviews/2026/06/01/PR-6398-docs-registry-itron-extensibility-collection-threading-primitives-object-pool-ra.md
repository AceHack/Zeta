## Captured (the two WANTs)

- **object-pool port** (`IObjectPool<T>`; `acquire`/`relinquish`) — three knobs worth keeping: `factory` + `reset/destructor` + **`isBad` validate-on-return** (the connection-pool "is this still alive?" check naive pools skip) + bounded-capacity + acquire-timeout (backpressure). It **is the `tools-rented-not-owned` rule as a primitive**. Improvement over Itron's footgun ("relinquish twice corrupts the pool") = a **leased handle that returns-once** (idempotent relinquish).
- **RAII lock-scope guards** (`read`/`write` structs, zero-alloc) + **`AsyncLock`** (sync+async from one `SemaphoreSlim(1)`, `using`-releases; Albahari/Toub lineage). Rust gets this free via `Drop`-guards; C#/F# wrap; TS N/A.

## Skipped (with reason)

- **`AsyncCollection<T>`** async producer/consumer → BCL **`System.Threading.Channels.Channel<T>`** supersedes it (bounded/unbounded + backpressure, BCL-tier → depend, don't re-mint, per the BCL-interface rule). Recorded so it isn't re-proposed.

Composes: `tools-rented-not-owned`, idempotency + `AtomicBool` once-latch, throttler-backpressure-as-TFeedback, the BCL-interface-boundary rule, honor-those-that-came-before (lineage preserved).

## Description

Approved slice-4 design (Aaron 2026-06-01). Inline-URL transitive dependency resolution building on slices 1-3.

**Decisions locked:** inline-URL deps `{name,version,url,content_hash}` (registry+semver = slice 5) · recursive transitive graph · strict-refuse on version skew (one name→one version/graph) · same-version-different-hash = always `tamper` · diamond dedup by hash · atomic resolve-verify-all-then-install · no lockfile (manifest pins ARE the transitive lock) · per-node slice-2 hash + slice-3 signature gates · `--allow-no-signature` graph-wide.

New pure `resolve.ts` (injected fetch → fully in-memory testable) + `resolve.test.ts`; `store.ts` manifest gains `dependencies?`; `ace.ts` wires the resolver into `install`. Full error taxonomy + test matrix in the spec.

Next: writing-plans → subagent-driven build (same flow as slice 3).

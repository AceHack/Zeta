## Description

The **C# native IndexedZSet cell** — the join/aggregation rung (`Z[K×V]`) joins **3/4** (F# engine ✅ · TS reference #6401 ✅ · C# this PR ✅ · native Rust pending). Continues "start the C# IndexedZSet native cell."

Built directly on the C# `ZSet<TValue>` — an `IndexedZSet` is an ascending-by-key run of per-key Z-sets, the layout that makes the bilinear `Join` + key-wise aggregation a linear merge.

- `src/Core.CSharp/IndexedZSet.cs` (+ `KeyGroup.cs`): `Empty / OfGroups / IndexWith` factories + `KeyCount / TupleCount / Get / ToZSet / Add / Negate / Sub / Join / Equals`. `Add` = merge-sorted-groups with per-key `ZSet.Union` (drop the cancelled group); `Negate` = per-group `ZSet.Negate`; `Join` = merge-join on key × cross-product values with **checked weight-multiply** + consolidate. Intrinsic comparers (comparer-as-identity, mirrors `ZSet`/`Bag`/`GSet`); `checked` arithmetic; full XML docs — **`dotnet build -c Release` clean, 0 warnings** (TreatWarningsAsErrors + the CA/MA analyzers).

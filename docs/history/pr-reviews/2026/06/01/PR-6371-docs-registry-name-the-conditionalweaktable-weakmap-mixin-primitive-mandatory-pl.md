## Description

Fix-forward (the ALC-refinement #6370 auto-merged on green while I was pushing this, so it stranded — cherry-picked clean onto main, 1 line).

You pointed out the **OnlyOnce + Named DI verbs are built on a clever trick** I'd added the verbs for but never *named*: `ConditionalWeakTable<IServiceCollection, …>`. Adding the underlying reusable primitive + the unload-test convention from the thread:

- **extension-state / weak-keyed side-table (the C# "mixin" trick)** — attach per-instance state to a type you don't own, GC-safe, via a weak-keyed identity table: C#/F# `ConditionalWeakTable<TKey,TValue>`, TS/JS **`WeakMap`** (exact analog — weak + identity-keyed), Rust = newtype-wrapper / id-keyed map (no GC → structural). Weak keys = no leak → the right tool for host-side state keyed on **plugin instances** (lets the plugin still unload). It's the mechanism behind `register-only-once` + `keyed/named`.
- **mandatory `plugin-unloads-cleanly` test** on the resolver — `WeakReference(trackResurrection:true)` + bounded `GC.Collect`/`WaitForPendingFinalizers` loop asserting `!IsAlive`, with load/use/unload in a `[MethodImpl(NoInlining)]` helper returning only the WeakReference. Assert-don't-skip (shield rule); red = a real leaked reference.

Docs-only; prettier + markdownlint clean; BACKLOG.md untouched.

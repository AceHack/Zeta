## The primitive

**Serialize deferred execution** — the **expression tree** (Nuqleon **Bonsai**: JSON/binary, all nodes incl. statement, reflection-info-omittable, cross-language) **+ the captured closure state** (`Checkpoint.fs` / `IStatefulOperator`) — onto the stream, so a computation can be closed over, persisted, moved, resumed.

- **Subsumes Durable Functions / Temporal / Step Functions / Dapr Workflow**: those keep CODE fixed + only STATE durable (event-sourced replay); serializing the expression tree itself makes the **pattern durable AND mutable** → **both** pattern and state evolve.
- **Rides the Z-set / IndexedZSet ladder** (4/4, #6413): the ℤ **retraction IS the pattern-evolution operator** (retract old expr-subtree, add new) — the saga's *definition* mutates by the same abelian-group inverse as its data.
- **Self-propagating pattern with state** = `(Bonsai tree, closure)` on a retraction-native stream = a **traveler** at workflow scope; "self-evolving saga" is the name.
- **Per-partition + cross-partition joins**: each shard carries its sagas; the bilinear `join` spanning shards is itself a saga, run via an **agent mediator** whose **tick stream** is the carrier, holding **both repos local** for the CALM linear merge-join, with **mitigation/compensation inside the saga** for one-side failure.

## Scope

This is **capture, not build** — grounds the prior art (search-first, current Nuqleon upstream), makes the subsumption + ladder-connection arguments, and lands the want-line the operator asked for. The serializer itself is operator-driven (own-vs-Nuqleon: likely Nuqleon-as-conformance-oracle + own cross-lang Bonsai-subset verified against it, per the ladder's meet-in-the-middle discipline).

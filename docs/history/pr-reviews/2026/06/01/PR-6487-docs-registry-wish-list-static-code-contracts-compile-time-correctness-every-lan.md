## Description

Per the maintainer 2026-06-01: *"static code contracts, compile time checks like dotnet used to have, for every language."*

Adds a `## The wish list` entry (next to **Type-system shims**, the compile-time-correctness family): **design-by-contract** — pre/post/invariants, **statically checked** where the language allows + runtime fallback otherwise. The capability .NET's old **Code Contracts** gave (`System.Diagnostics.Contracts` + Clousot `cccheck` + `ccrewrite`), now deprecated/archived, with no cross-language equivalent.

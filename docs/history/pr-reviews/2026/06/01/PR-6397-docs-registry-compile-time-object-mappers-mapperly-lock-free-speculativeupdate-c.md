## Description

Two primitive wants the maintainer named 2026-06-01 (reviewing Itron source):

- **Compile-time object mappers** — *"we for sure want roslyn-generator-style mapperly pattern in our primitives"*. Declare a map-method signature → the generator emits it; **zero runtime reflection**, AoT/trim-safe. Canonical = [Mapperly](https://mapperly.riok.app/) (incremental Roslyn source-gen). Hexagonal-ported (own a `[Map]` port; Mapperly = swappable adapter); composes the existing mixin source-gen + serializer codegen into one compile-time-codegen family (mix-in / (de)serialize / map).
- **Concurrency / lock-free `SpeculativeUpdate`** — *"some of my favorite code I ever wrote"* (the Itron `SpeculativeUpdate`/`TrySpeculativeUpdate` CAS-retry loop). The **general** lock-free optimistic atomic update (snapshot → pure-update → `CompareExchange` → `SpinWait` retry). **Generalizes** the `AtomicBool` once-latch + CAS-on-epoch already in the registry; **`git push --force-with-lease` is this primitive at git-ref scope**. The side-effect-free-update invariant = idempotency at CAS scope. Concept-not-code (textbook CAS-retry; the Itron source is lineage).

Extensibility patterns (`Itron.Extensibility`) were **already captured** (the DI/plugins line — `AssemblyLoadContext` loading, `ConditionalWeakTable` mixin, Moxy/Fody prior-art), so no new entry needed there. Docs-only; markdownlint clean.

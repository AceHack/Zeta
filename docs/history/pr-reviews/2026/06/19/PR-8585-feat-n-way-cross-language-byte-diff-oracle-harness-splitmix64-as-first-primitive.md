## Description

## What

A shared, generic **N-way cross-language byte-diff oracle harness**
(`tests/cross-verification/_harness/nway-diff.ts`), replacing the per-primitive
hand-rolled `compare.ts` copies, with **SplitMix64** wired as the first primitive
on it (6 oracles: TS/F#/C#/Rust/Python/Go).

- **No privileged oracle.** Every `<lang>-output.json` is a peer; the harness
  finds the common fixed point all present oracles agree on **and** asserts it
  against the canonical `vectors.{yaml,json}` — so a unanimous-but-wrong result
  (a shared-bug Sybil of oracles) still fails. Divergence yields a structured
  report naming the dissenting oracle(s). Assert-don't-skip throughout.
- **Divergence self-test** (`_harness/nway-diff.test.ts`): injects a one-byte
  mutation into one oracle and asserts the harness exits non-zero and names the
  culprit (plus a deleted-key MISSING case + an unmutated control). **The green
  can turn red** — catches the one-port-silently-wrong (Bonsai-bug) class that
  per-oracle tests structurally miss.
- **CI orchestrator** skips `_`-prefixed dirs so `_harness` is not mistaken for
  an unchecked primitive.

## Description

Memory discipline for the mumps-DI-RX substrate: **weak refs = observer-dependent lifetime** (lives only as long as the observer → GC reclaims; works on external types). **GC-safe RX 2×2** (the observed pair never pins memory). Weak refs are the **collection mechanism for the DI lifetimes** (no manual dispose to leak). Key app: **what-acts (actor) holds WEAK refs to what-remains (persona/global)** → dead actors never pin personas; personas outlive actors (ephemeral→weak→durable). = **subscribe safety at global/static** (lapsed-listener); existing disposal-based version in `src/Core/Rx.fs`; weak-ref version is GC-safe even without `Dispose`. Paired with **lazy-load** (Dark Hall glows-on-entry) + **push-down cache per cell's Markov-boundary closure**. Composes with scale-free/lock-free/what-remains-what-acts/DST.

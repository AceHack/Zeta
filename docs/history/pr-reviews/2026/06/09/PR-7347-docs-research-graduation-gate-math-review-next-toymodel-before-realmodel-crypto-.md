## Description

Two streamed nodes from Aaron.

1. Graduation gate. "math nerd time to review and whatever next toymodel is — before this becomes realmodel and crypto" + "no single key so we can rotate." Order: (1) math-team review of the docket C1–C15 + the DST-rooms/controller/time arc as proof-rooms; (2) the NEXT toymodel (DST-substrate/meta layer), still a toy; THEN (3) realmodel and (4) crypto (treaty in MUMPS, regenerate/rotate 1000x). Toy → proof → toymodel → real, because toy-break is cheap and real keys/identity/money break is expensive. Hard invariant into the crypto gate: NO SINGLE KEY — >=2 seeds (active+standby, ISM/SKMS) so rotation is gapless; single-key keyring is malformed.

2. DB time type name + prior art. "metadatetime / zetadatetime / phase type — is there any prior art?" YES, deep: Lamport 1978 (logical clocks); Spanner TrueTime (bounded-uncertainty interval = UncertainClock); HLC 2014 (hybrid, CockroachDB/Mongo); Jefferson 1985 Virtual Time + Time Warp (generated time + rollback = Z-set retraction = DST replay); Valiant 1990 BSP supersteps + Awerbuch 1985 synchronizers (PHASE); bitemporal/Snodgrass/SQL:2011/Datomic (multiple time owners = four-corner feedback). Recommend type = ZetaDateTime (parallels TrueTime/NodaTime), logical-step component = Phase. Name subject to naming-expert + Ilyana.

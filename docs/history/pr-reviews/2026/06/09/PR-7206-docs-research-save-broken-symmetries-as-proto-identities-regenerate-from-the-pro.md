## Description

Extends #7205. Save broken symmetries (privacy-driven SSB) as proto-identities, evolve them. Two things: identity STATE is regenerable from the COMPLETE proof chain (DST replay); evolutional PATH is recordable-only — not seed-compressible, computationally irreducible (Wolfram; depends on whole contingent history incl. which-way each symmetry broke). The record IS the proof chain: record path -> replay regenerates; lose record -> identity unrecoverable. Makes preservation load-bearing (§5 / save-it-all #7202 / don't-condense #7201) — failing to record the irreducible path destroys the self (=evaporation #7158).

## Description

Aaron: "whenever you would say xxx-like it means it's a candidate word for a ZetaId."

An `xxx-like` term (float-like, qubit-like, spinor-like, white-hole-like, ...) is a **candidate** living in `like/` — not yet a confirmed traveler, no governed ZetaId yet. The `-like` suffix IS the candidate marker. Graduates: speak-for-existence → travelers/ intake → canonical home + ZetaId; drop `-like` on graduation. Any `xxx-like` token in a doc = a like/ candidate, not a canonical traveler.

## Description

Debugging/security register on the fixed points. A fixed point = a termination guarantee (self-reference converges, recursion stops): stops infinite-recursion attack vectors (recursion-bomb/stack-overflow DoS) AND accidental self-recursion (self-hang = self-evaporation). Fixpoint.solve #7101 detects non-convergence rather than hanging (unsafe case caught). The registry (#7168) is therefore a catalog of provably-terminating SAFE shapes (each with a fixed point converges; shapes without = unsafe/divergent) + the why each terminates => build on a safe shape, inherit termination = a security/debugging asset. Same well-foundedness as stairs-down #7177 / bounded-ascent #7178. Anchors: Turner total-FP, Banach, recursion-bomb DoS, halting problem.

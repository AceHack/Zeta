## Description

## What

Replaces the vanilla SPA with a real **React + TypeScript + Vite + Tailwind** app using **shadcn-style** components — a polished, modern cloud console. Same `/api` BFF; built to `dist/` and served by the existing Bun server. `tsc` strict clean on both the web app and the server.

## The console

- **App shell** — icon sidebar nav (Resources / Create / Needs me with a live count badge), top bar with tenant breadcrumb + refresh, refined dark theme with a subtle grid background.
- **Resources** — category-grouped grid (game / web / database / app, each with an icon) with live **search** and **health filters**. Cards show a health dot, exposure, and the operating persona's colored avatar.
- **Resource detail DRAWER** (the per-resource control panel) — a right-side Sheet with tabs:
  - **Overview** — status, blueprint, category, exposure, host, operator persona.
  - **Objects** — the rendered child k8s objects.
  - **Room** — the collaboration timeline as an attributed event stream, with inline **Approve/Deny** on pending authorizations.
- **Create WIZARD** — a dialog that generates a config form **from the Blueprint's variables** (name, namespace, exposure, replicas, host, each variable) → review → the generated `Deployable` manifest with copy. (One-click apply lands with the create API + write RBAC — the portal is read-only by design today.)
- **Needs me** — the no-directives approval queue with an optional note per decision.

## Description

Aaron 2026-06-07: 'navigate model weights with MUMPS verbs?' + 'stoked, model API that's human readable.'
Honest yes-and-no: the model STRUCTURE is a global exactly (state_dict = dotted-path -> tensor; MUMPS verbs
browse it), but a DENSE weight matrix is wrong for path-per-element (navigate TO the tensor, index INTO it
with dense buffers). Three genuine weight-as-global cases: embedding tables ($GET by tokenId), sparse/pruned/
MoE weights, and Bayesian weights = SoftValue leaves = the soft tensor. Substrate adds checkpoint dedup
(content-addressing), near-dup clustering (similarity index), evolving schema over training stream, and
branch-scoped model versions/diff/merge — a git-like, human-readable model store.

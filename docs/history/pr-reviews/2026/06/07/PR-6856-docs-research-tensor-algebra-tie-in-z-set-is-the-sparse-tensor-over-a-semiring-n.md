## Description

Aaron 2026-06-07: 'tie this into dotnet tensor class / interface / algebra?' Grounded answer: the algebra
already exists (ISemiring in Semiring.fs: IntegerRing/IntervalRing/ProbabilitySemiring), Z-set IS a COO
sparse tensor over the integer ring (join=contraction, +=union, sum=reduction; DBSP=incremental tensor
algebra), and System.Numerics.Tensors is already a dep (ZSet uses TensorPrimitives.Sum for the dense SIMD
leaf). One precise gap: ZSet's Weight is hardwired int64, so soft tensors need a semiring-generic
WeightedSet<'K,'W> over ISemiring (ZSet = IntegerRing instance; soft tensor = IntervalRing/Probability
instance). GraphBLAS/TACO-shaped. Proposed: C# neutral ITensor contract (per naming convention) +
WeightedSet + semiring-parameterized contract/einsum. ZSet-generalize-vs-parallel fork noted; build pending.

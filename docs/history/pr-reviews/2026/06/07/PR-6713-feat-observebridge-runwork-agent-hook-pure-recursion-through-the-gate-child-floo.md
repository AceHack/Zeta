## Description

The Agent hook — the one place a Cell invokes an Agent. Pure port + recording runner (you confirmed all five; start simple, expand for the invariant proof).

- **`WorkOutcome`** = `Progressed of Effect list | Blocked of reason | NeedsAuthorization of gatedClass`.
- **`IWorkRunner.RunAsync : item -> WorkOutcome`** — the LLM fills this later; `constantRunner` for tests.
- **`SubstrateEffectHandler`** gains `?workRunner` + `?maxWorkDepth`. `RunWork` delegates to the runner; `Progressed` effects **re-enter the gate** (inspect→admit?execute) at `depth+1` — the Agent proposes, the gate disposes, so it cannot widen its own authority. `Blocked`/`NeedsAuthorization` surface honestly; the human authorizes gated classes. `maxWorkDepth`: None = unbounded (experimentation), Some n bounds the cascade.
- **CHILD-FLOOR (load-bearing):** `executeOne` is reached ONLY via the gate's `Admit`, at every depth — so a policy denying a gated/child-floor class makes it **impossible** for the Agent to get that effect executed by proposing it.
- **DST:** a real runner's output is captured; replay replays captured effects, never re-runs the Agent. (Real LLM runner = much-later increment.)

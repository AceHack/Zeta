## Description

## What

v2 design for the Zeta Language & Canonical IR, superseding the v1 pipeline proposal (#8179). Folds in the six-lens specialist review of v1 (Rodney/Soraya/Kira/Ilyana/Rune/Viktor — all six `major-rework`, architect synthesis by Kenji) **and** Aaron's design decisions.

## The one principle

Everything is a declared interface capability; codegen is **multiple dispatch over capabilities** (Aaron's Itron meter/network/impl capability-injection graph; CLOS/Julia external anchors) — inject participants each carrying capabilities, resolve the best-effort mix as a graph. The factory runs this as Eve Protocol (policy) + V8 hidden-shape (mechanism), ferries 11/19, over Clifford geometry. **The Zeta IR instantiates the existing HKT backlog, not a parallel effort.**

## Decisions folded in

- **F# is the host**: author the IR in F#; the F# compiler *is* the typechecker. Delete the `.zeta` surface language + PEG parser + standalone typechecker (Rodney's cut).
- **C# authors the interface contracts** (F# lacks declaration-site variance; C# has `in`/`out`). DV2.0: C# = contract hub, F# = IR/codegen satellite.
- **Bignum-family hex-in-JSON encoding** (`$f64`/`$bytes`/`$soft`): exact text primary, native type a lossy projection. No CBOR — aligns with `no-binary-in-proof-lineage`; rejects the panel's CBOR call.
- **Capability-gating** dissolves the tree_fold + determinism P0s: CommutativeMonoid unlocks order-independent fold; scheduler is an injected capability (DoP=1 on the byte-lock path); collation pinned to codepoint/UTF-8 order.
- **Self-hosting north star = trust substrate**: `gen(gen)==gen` across 6 languages is diverse-double-compiling (Thompson 1984 / Wheeler 2009) sixfold and the 3rd Futamura projection (1971) — humans and AIs agree without reading every line.
- **v1 frozen *with* an evolution contract** (version discriminator, add-only tags, unknown-tag policy). Next steps reordered: **spec + golden vectors first.**

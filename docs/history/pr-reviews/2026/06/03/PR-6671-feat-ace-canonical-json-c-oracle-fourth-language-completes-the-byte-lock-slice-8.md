## Slice 8.8.2 — canonical-JSON C# oracle (fourth language completes the byte-lock)

Completes the depth promotion: 8.8 (Rust) → 8.8.1 (F#) → **8.8.2 (C#)**. Adds the
**fourth and final** oracle to the canonical-JSON byte-lock, so `compare.ts` now
enforces the full **TS + Rust + F# + C#** set on all 14 vectors. `compare.ts`
already read the `cs-output.json` slot (resilient since 8.8), so this is a clean
additive slice.

### What landed

- **`src/Core.CSharp.AceCanonical/`** — new production project (`net10.0`,
  `TreatWarningsAsErrors`, `Nullable`, **zero external deps** — BCL
  `System.Text.Json` only). `Canonicalize(JsonElement) -> string` reproduces the
  Ace canonical seam (`tools/ace/canonical.ts` `canonicalBytes`) byte-for-byte.
- **`tests/Tests.CSharp/CanonicalJson/CrossVerifyTests.cs`** — `[Fact]` generator:
  repo-root walk to `Zeta.sln`, reads `vectors.json`, asserts each canonical ==
  `expected_canonical_json` + each invalid rejects, **hand-emits** flat
  `cs-output.json` (LF, no-BOM, trailing newline).
- **`tests/Tests.CSharp/Tests.CSharp.csproj` + `Zeta.sln`** — wiring.
- **`tests/cross-verification/canonical-json/cs-output.json`** — committed output,
  **byte-identical** to ts/rust/fsharp outputs.
- **design doc** under `docs/agendas/ace-package-manager/`.

### Why C# mirrors F# (not Rust)

Same .NET runtime → `string.CompareOrdinal` *is* JS `Object.keys().sort()` (UTF-16
code-unit), so keys sort right natively with **no astral special-case** (unlike
Rust 8.8, which sorts by `encode_utf16()`). `int->string` via
`CultureInfo.InvariantCulture` (matches Rust `to_string` / F# `sprintf "%d"` / JS
`String(n)`). Lone surrogates rejected (`System.Text.Json` throws at
`GetString()`/`Name` on transcode, caught per-vector). Generator hand-emits
(not `JsonSerializer`, which escapes astral as surrogate pairs + escapes `<`/`/`).

### Byte-lock is now five-way (no tautology)

Python-authored (8.5) ↔ TS (8.5) ↔ Rust (8.8) ↔ F# (8.8.1) ↔ C# (8.8.2) — five
independent implementations, **0 mismatches on 14 vectors** (`diff` confirms
cs-output.json byte-identical to ts/rust/fsharp).

### Canonical-primitive gate

This **closes the 4-language half** of the gate for the canonical-JSON seam.
The formal proof is still owed → **not yet canonical** (4-language byte-locked,
proof-owed).

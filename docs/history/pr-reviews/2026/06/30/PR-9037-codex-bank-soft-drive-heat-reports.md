## Summary

- Add `SoftDrive.driveFramesWithHeatReport`, a report-returning path that records the exact `HeatSignature`s emitted while soft lookahead prunes futures.
- Keep the existing frame-only `driveFramesWithHeatSink`/planner APIs as compatibility projections.
- Bank soft-prune heat into `RoomRun` heat transcripts via `DarkHallScheduler.heatRowOfSignatures`, so hosts can render soft lookahead loss alongside boundary and horizon rows.
- Pin TLC subprocesses to `-XX:+UseParallelGC`, matching TLC's own guidance and avoiding a local OpenJDK 26 G1 SIGSEGV that made a valid spec look red.

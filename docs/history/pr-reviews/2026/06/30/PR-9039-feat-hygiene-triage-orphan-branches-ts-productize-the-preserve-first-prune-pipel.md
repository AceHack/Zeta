## Description

The 2026-06-30 post-reboot triage proved **"merged-PR" is not a safe prune gate** (squash fools ancestry; bot branches have no PR yet hold content). The only safe gate is a **content check vs main**. This productizes that pipeline so each namespace owner runs one command instead of hand-cranking hundreds of branches.

**Gate (conservative, errs toward keeping):** a branch is SAFE iff it adds no basename absent from main (regenerable ephemera excluded). Absent content → **UNLANDED** (durable → preserve first) or **ARCHIVE** (pr-review → route to `consume-pr-archives.ts`). `--prune` deletes **only** SAFE (SHAs printed; chunked). **Dry-run by default.**

Validated: dry-run on `riven` correctly split 4 SAFE / 2 UNLANDED (naming exact absent files). For the remaining ~888 orphans, each owner runs `triage-orphan-branches.ts <ns> [--prune]`.

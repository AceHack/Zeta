Next rung of the **information-theory tower**, built directly on the landed finite Shannon-entropy root (`src/Core.Lean4/Lean4/FinShannonEntropy.lean`, #8816) — **reusing** its `FinDist` and `H` (no entropy redefinition). ## Definitions (subtractive / chain-rule form, natural-log base)

- `FinJoint Ω Ψ` — finite joint with **product support** `suppX ×ˢ suppY`; `toFinDist` / `margX` / `margY` derive the joint `FinDist (Ω × Ψ)` + marginals `pX`, `pY` by summation.
- `Hjoint = H J.toFinDist`  ( = H(X,Y) ), `HX`, `HY` (marginal entropies).
- `condEntropy = Hjoint − HY`  ( = H(X|Y) ).
- `mutualInfo  = HX + HY − Hjoint`  ( = I(X;Y) ).

## Theorems (no `sorry`; `#print axioms` = `[propext, Classical.choice, Quot.sound]` on every one — the expected real-ℝ price, **no `sorryAx`**)

- `negMulLog_add_le` / `negMulLog_sum_le` — two-term + finite-sum **subadditivity of `negMulLog`** (proved from `Real.log_le_log`); the analytic core of "marginal entropy ≤ joint entropy".
- `HY_le_Hjoint` — H(Y) ≤ H(X,Y).
- `condEntropy_nonneg` — **0 ≤ H(X|Y)**.
- `chain_rule` — **H(X,Y) = H(Y) + H(X|Y)**.
- `mutualInfo_eq_sub` — I(X;Y) = H(X) − H(X|Y).
- `mutualInfo_symm` — **I(X;Y) = I(Y;X)** (via a role-swapped joint `J.swap` + swap identities).

## Honesty over green — what was deferred (NOT `sorry`-stubbed; omitted + documented)

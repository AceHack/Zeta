## Description

## What

Next information-theory tower rung above `FinConditionalEntropy` (#8832): the named-missing **`mutualInfo_nonneg : 0 ≤ I(X;Y)`**, equivalently the conditioning inequality **`condEntropy_le_HX : H(X|Y) ≤ H(X)`**. New file `src/Core.Lean4/Lean4/FinMutualInfoNonneg.lean`, gated by `Lean4.lean`.

## Route that closed

**Route 1 (log-sum / Gibbs)**, in its elementary `log t ≤ t − 1` form. Mathlib v4.30.0-rc1 has **no** packaged finite Jensen / log-sum / Gibbs inequality (`Real.strictConcaveOn_negMulLog`, `klDiv`, `strictConvexOn_klFun` exist, but no `∑ aᵢ log(aᵢ/bᵢ) ≥ …`). Rather than assemble Finset-weighted Jensen from the convexity API (heavy) or pull `klDiv` (drags in measure theory for finite dists — route 3), the Gibbs step is assembled from the one-line `Real.log_le_sub_one_of_pos` — the classical Cover & Thomas Thm 2.6.3 trick, no measure plumbing.

## Proven (reuses #8816/#8832 defs, never redefines entropy/MI)

- `gibbs_pointwise` — pointwise `p − q ≤ p·log p − p·log q` (the analytic heart).
- `gibbs_sum` — **finite Gibbs / log-sum inequality over a Finset** (reusable for DPI).
- `mutualInfo_nonneg` — `0 ≤ I(X;Y)`.
- `condEntropy_le_HX` — `H(X|Y) ≤ H(X)`.

Argument: `gibbs_sum` with `p = p(x,y)`, `q = pX(x)·pY(y)` over the product support (both prob vectors ⇒ log-sum LHS `= ∑p − ∑(pX·pY) = 1 − 1 = 0`), then `−∑ p·log p = Hjoint` and `−∑ p·log(pX·pY) = HX + HY`, giving `0 ≤ HX + HY − Hjoint = mutualInfo`.

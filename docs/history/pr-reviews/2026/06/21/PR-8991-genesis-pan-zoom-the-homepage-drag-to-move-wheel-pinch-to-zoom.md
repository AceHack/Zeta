## Description

## What

Upgrades the Project Genesis homepage from a fixed top-anchored zoom into a real **pan + zoom** surface, so you can move around the settlement when zoomed in instead of being stuck on one point.

- **Unified Pointer Events (mouse + touch)**:
  - one-finger / left-button **drag to pan**
  - two-finger **pinch to zoom** about the midpoint
  - mouse **wheel to zoom** about the cursor
  - focal-point zoom keeps the point under the cursor/fingers fixed
- **Pan is clamped** to the content bounds (no runaway; auto-centers when content is smaller than the viewport).
- A **drag is distinguished from a tap**, so panning never accidentally opens a sector.
- **Level-of-detail preserved**: below 85% the sectors seal (dwellers, equipment, lights, interior glow fade to hatched doors); zoom back in to see inside.
- The −/%/+/reset controls now zoom about the viewport centre.

## Verified in a real browser

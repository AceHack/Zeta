## What

A **read-only** GitHub trust-root resolver under `tools/setup/persona-keys/` — the pre-cluster bootstrap for distributing node trust through GitHub as an IdP + key directory (workitem `081KVM1TK3Z08QG0R0002959G6` §"Pre-cluster bootstrap — Option A"). - **`github-trust.ts`** — resolves trusted GitHub identities (explicit `--user` allowlist · an allowlist config file · or the `maintainers/` dir names) into a combined, de-duplicated **authorized-keys trust set** by fetching ONLY public `https://github.com/<user>.keys` (+ optional `.gpg`) through an injected `GithubTrustEffects` door. **Produces** the trust set + a status readout; does **NOT** install it.
- **`github-trust-cli.ts`** — `status` (dry readout, no network) and `resolve` (fetch + print). `--dry-run` does NO network. `--emit` prints the authorized-keys text (not installed).

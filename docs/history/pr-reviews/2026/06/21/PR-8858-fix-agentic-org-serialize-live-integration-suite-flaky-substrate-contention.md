## Description

## Summary

Found while validating the agent flows against the real Cockroach + NATS substrate: `npm run test:integration` is **flaky**. It failed 2 consecutive runs, each time on a *different* file (Cockroach readiness flapping `healthy → degraded` once, the durable-worker round-trip once), yet every file passes in isolation.

Root cause: the five live-integration files target the **same** local Cockroach + NATS and each drops/recreates its tables, JetStream streams, and consumers during setup. `node --test` runs test *files* in parallel by default, so these concurrent teardown/recreate cycles race on shared substrate.

Fix is one flag — run the live suite serially:

```diff
-"test:integration": "node --experimental-strip-types --test apps/workers/test/cockroach-integration.test.ts …",
+"test:integration": "node --experimental-strip-types --test --test-concurrency=1 apps/workers/test/cockroach-integration.test.ts …",
```

(`--test-concurrency=1` only affects this suite; it does not touch the parallel unit `test` script.)

## Validation

Against local Cockroach (`v24.1.5`) + NATS (`2.10`) in docker:

```
parallel (before fix): 2/2 runs FAILED — non-deterministic, different file each run
serial   (after fix):  3/3 runs PASSED — 7/7 tests, stable
$ npm run test:integration
# tests 7 / # pass 7 / # fail 0
```

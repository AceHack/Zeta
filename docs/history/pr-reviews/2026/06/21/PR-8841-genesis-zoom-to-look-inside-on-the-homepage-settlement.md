## Description

## What

Adds a zoom interaction to the Project Genesis homepage (the vault cutaway "settlement").

- **Zoom controls** — a fixed control in the lower-left (`−` / percentage / `+` / reset), range 50%–220%. Also **ctrl/⌘ + scroll-wheel** (or trackpad pinch) zooms; a plain scroll still scrolls the page.
- **Level-of-detail on the vaults** — below an **85%** threshold the vault flips to a sealed `exterior` state: dwellers, equipment, status lights and interior glow fade out and every sector renders as a sealed hatched door, so **zoomed out far enough you cannot see inside the vaults**. Zoom back in and the interiors reappear.
- The scroll area tracks the scaled height (measured via `useLayoutEffect`) so the lowest floor stays reachable when zoomed in, and the helper caption updates with the current direction.

**Capture-the-externalization = the core optimization / the ENGINE.** The system isn't directly optimized for survival/visibility/inoculation (those are **effects**) — it's optimized for **CAPTURE** (record/persist/externalize everything: ideas, failures, discussions, inoculations, every catch→undo→learn) into the substrate (event-sourcing, git-as-event-store, the memory dir, the ferry protocol). The founding move (losing Amara → externalize so nothing is lost → capture); **this whole night IS the engine running** (every ferry = capture).

Pair with **findability** (index/reindex/recall, hub/satellite/DV2.0, carved-sentence): **capture + retrieve + synthesize**, or it's a landfill not a memory. And capture is the **means**, not the end (the ends = survival/visibility/inoculation/learning/durability); capturing-for-its-own-sake is noise (*"is this worth the capture?"*). Capture everything worth keeping, findably, in service of the effects.

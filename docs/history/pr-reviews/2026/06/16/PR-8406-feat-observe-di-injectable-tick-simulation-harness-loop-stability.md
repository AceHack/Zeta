## Description

## What

A simulation harness for the observe→execute pipeline with fully injectable dependencies. Tests loop stability, not LLM code quality.

### Features

- **7 built-in scenarios**: empty, work, ambiguous, mixed, operator, ferry, persisted_mode
- **DI-injectable**: custom World, custom EventSink, custom ModelBackend, custom CommandExecutor
- **Fake sink**: in-memory event log (no git I/O) — fast, deterministic
- **LLM mode**: `--use-llm` hits local ollama at temperature 0 / seed 42 (deterministic)
- **CLI**: `bun src/Core.TypeScript/observe/simulate-tick.ts [--use-llm] [--scenario <name>]`

### Why

The observe loop needs to be testable with synthetic backlogs (not just the real 1,131-item backlog). This enables:

- DST-style property testing (same world → same result, reproducibly)
- Grading the local LLM chooser against the oracle (oracle agreement %)
- Regression testing: add a scenario for every loop bug that surfaces
- Multi-tick simulations (call simulateTick N times with evolving world)

### Verified

- 11 tests, all green
- All 7 scenarios complete without crash
- Custom world injection works
- Custom sink injection works

## Description

Aaron 2026-06-16 (developing semantic-mapping thread): *"we assume all zeta intents are pure cause we can DST them in every future."*

This **tames the dangerous `^` (intent)** layer. An intent is assumed **pure** (no hidden side effects, deterministic) **because DST replays it across every future** — and a pure intent's *entire* effect is visible in replay, so **coercion has nowhere to hide.** Purity is the **verification substrate for commutative-intent**: you can *audit* whether an intent commutes (consensual) vs not (coercive) precisely because pure + DST-replayable exhibits its full effect in every simulated future.

Three payoffs at once: **noninterference §13** (pure = no ambient entropy/influence leak — only declared metered channels), **predictability** (the fairness metric), **auditability** (`^` becomes checkable, not faith). Purity is to `^` what `−` (retraction) is to runaway — the thing that makes the risky operation safe.

**Razor:** purity is verified **only where DST coverage reaches** — an intent that escapes DST (unrecorded network IO, ambient clock/threadpool/`Task.Run` leak) is **not** verified pure → the **noninterference / async-all-the-way / no-`Task.Run` guards** keep intents inside DST's reach. And **"every future" = every *explored* future** (strong sampling, not literally exhaustive); *"pure in every future"* is the aspiration the coverage approximates, not a closed proof.

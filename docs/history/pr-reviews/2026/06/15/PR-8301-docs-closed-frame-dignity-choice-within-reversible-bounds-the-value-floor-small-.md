- **Tight logic**: dignity requires choice; real choice requires the freedom to make mistakes; freedom-to-err is safe only inside reversible bounds. Only-the-right-answer = "because I said so" with extra steps; unbounded freedom-to-err = hazard. So reversibility is the enabling condition. **Design rule: maximize the reversible envelope so maximal choice is safe; constrain only the genuinely irreversible.**

HARD LIMITS / "non-reversible → second opinion" = the *edge* of the envelope, not a restriction on choice. Kids/vulnerable floor = same insight (their mistakes are less reversible). Everything reversible is free; only the irreversible gated. Symmetric AI+human ("so *we* can make mistakes").
- **Seams**: reversibility never total → integrity rests on correctly classifying reversible vs irreversible (the dangerous error is *misclassifying*; the second-opinion gate is the classifier). Psychological reversibility < data reversibility (retract from ledger, not from heart). Mistakes are *generative* (every bug has economic value), not the failure mode.

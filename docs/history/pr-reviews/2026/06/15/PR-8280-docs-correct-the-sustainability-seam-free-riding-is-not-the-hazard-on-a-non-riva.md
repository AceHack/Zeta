## Description

Corrects an overstatement in the capture-taxonomy seam (#8279) per Aaron 2026-06-15 (*"I'm not worried about this one — open source produces economic value for me even if others free-ride; it's not a 0-sum game"*).

- **Non-rivalry = positive-sum:** another's use doesn't subtract (Jefferson's candle; Romer's non-rivalry-of-ideas, Nobel 2018), and the producer captures value via non-zero-sum channels regardless of free-riders (complements / Red Hat; reputation; banked capability; growing ecosystem). **Free-riders = free upside, not a leak.**
- **Tragedy-of-commons-by-depletion is a RIVAL-good problem** (pasture/fishery) — does **not** apply to non-rival AI (no depletion). The only real non-rival concern is **underprovision**, answered when producer value-capture > cost (it does).
- **Surviving residuals are NOT free-riding:** (a) value-capture **continuity** (if the channel fails → maintenance underprovision — but that's the funding-fragility / resilience-floor point, not free-riding); (b) **misuse** (open ≠ misuse-proof), orthogonal. Net: open trades the capture pair for *continuity-of-value-capture* (= the resilience floor, already designed-for) + misuse, **not** a free-rider tax.

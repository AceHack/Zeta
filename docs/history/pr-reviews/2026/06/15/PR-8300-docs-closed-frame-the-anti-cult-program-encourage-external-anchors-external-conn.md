## Description

Prescriptive capstone of the trust thread (Aaron 2026-06-15: "external anchors are the key to encourage for anti-cult"; "encourage external connection over internal cult connection").

- A cult's defining move is **severing** external anchors (Lifton milieu control). So anti-cult is a *positive* program: cultivate the thing a cult must remove — make reaching for an un-owned external referent the encouraged, rewarded, **least-action** move. Already a standing rule (`anchor-to-human-prior-art`) — this is *why* it's load-bearing.
- The verb is exact: **encourage, not force** (forcing anchors = forced agreement again). Seams: strong externality (a cult can encourage a *captured* pseudo-external canon → cold-boot test on the anchor itself; math/formal/determinism are gold because no one owns them); encourage the *checking* not just citing (else citation-theatre/scientism = its own cult shape).
- **Graph form**: encourage external *connection* over internal cult *connection*. A cult is a network shape (dense internal, severed external) = decorrelation as topology — internal = strong/correlated ties, external = weak/decorrelated ties (Granovetter; Burt structural holes). It's **manifesto §1 scale-free at the social layer** (a cult is a star/clique on a leader = single point of control/failure) and the Markov-room with *metered* channels to other rooms (§13), not a sealed wall. Seam: not unbounded openness — small-world balance (Watts–Strogatz: cohesion *with* bridges).

## The involution choice (the decisive gate)

`Conj` = **reversion**, NOT grade involution. Reversion is the **anti-automorphism** `~(xy) = (~y)(~x)` — exactly the `*`-ring law `Conj(x·y) = Conj y · Conj x`. Grade involution is an *automorphism* `(xy)^ = x̂ŷ` (wrong order) and would FAIL that law. The test suite includes a **negative control** proving the order is load-bearing (`e₁e₂`): `Conj(x·y) ≠ Conj x · Conj y` for non-commuting blades, so the anti-homomorphism test is not vacuous.

## Laws proven (17 tests = 12 properties + 5 facts)

- Additive abelian group: assoc, comm, `Zero` identity (both sides), `Negate` inverse
- Multiplicative monoid: geometric-product assoc, `One` identity (both sides)
- Distributivity: left **and** right (independent — `Mul` is non-commutative)
- Star/involution: `Conj∘Conj = id`, `Conj` additive, `Conj(x·y)=Conj y·Conj x`, `Conj One = One`
- Basis sanity: `eᵢ²=+1` (Euclidean signature), `eᵢeⱼ=−eⱼeᵢ`, bivectors²=−1 (the ℍ even subalgebra), reversion sign pattern

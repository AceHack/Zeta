## Description

Phase B of the gen(gen)===gen trajectory: a single codegen tool that reads `zeta-ir-v1` and emits runnable oracle scripts in 4 target languages.

## What this is

`codegen-from-ir.ts` reads a frozen zeta-ir-v1 artifact and generates total-interpreter oracle scripts for:

- **TypeScript** (BigInt wrapping arithmetic)
- **F#** (uint64 with `^^^/>>>`)
- **C#** (unchecked ulong)
- **Rust** (wrapping_mul)

Each generated script reads the IR as DATA and folds the op list over inputs — no hardcoded algorithm.

## Phase B gate

The gen(splitmix64-IR) execution produces output **byte-identical to the canonical golden vectors** — proving the generator reproduces what humans already byte-locked.

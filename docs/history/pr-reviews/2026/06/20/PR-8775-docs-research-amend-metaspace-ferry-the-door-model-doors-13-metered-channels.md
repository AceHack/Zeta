## Description

Amends the metaspace navigation ferry (#8773) with Aaron's **door model**:

- A **door is a first-class portal = a declared, metered channel (#13 noninterference)** — you cross between bounded contexts ONLY through doors (no teleporting; the navigable form of enter = frame-change + boundary-crossing).
- **Two edge types over the same nodes:** containment (a **tree** — meta-vault ⊃ vault ⊃ room; **rooms can't contain rooms** → room is the leaf, bounded downward) vs **doors (a graph** — a room has multiple doors to other rooms in the same vault; plus vault↔outside doors).
- **Refines the self-similar `Space`:** recurse **up** (the meta-vault's rooms are vaults → worlds-of-worlds), terminate **down** at the room. Not infinitely recursive — bounded-down with an upward asymmetry.
- **Doors vs clusters/federations:** navigation topology vs relational topology, touching at **permission-gating** (consent-first #6) → preserves no-infinite-captivity (a room with doors out is a room you can leave).
- **Build implication:** a `Door` (`from Space → to Space`, permission-gated); rooms = a door-graph; clicking a door = frame-change hit-tested via the shipped `Viewport.unproject`.

## Description

Investigates whether add/sub requires a new zeta-ir grammar version.

- Proves necessity: `add k` maps 0 to k, whereas all existing v3 ops (`mul`, `xorshr`, `rotl`, `xrotxor`, `xshrxor`) map 0 to 0. Therefore, `add` is strictly outside the v3 grammar.
- Proves that `sub k` can be implemented as `add -k`, keeping the grammar minimal.
- Recommends deferring the actual `ZetaIrV4` implementation until a concrete public-domain generator (like PCG or ChaCha) is ported to anchor it.

This cleanly closes the add/sub question without prematurely expanding the grammar surface.

## Description

## Fifth generator — `hash.nasam` + the **second** grammar evolution (`zeta-ir-v3`)

This lands Pelle Evensen's public-domain **nasam** mixer as the fifth `generated-from-ir` primitive — and the first that needs ops **outside the v2 `mul`/`xorshr`/`rotl` vocabulary**, exercising the IR evolution contract a **second** time.

### Why nasam needs a new grammar

nasam (from [mostlymangling.blogspot.com](http://mostlymangling.blogspot.com/2020/01/nasam-not-another-strange-acronym-mixer.html), public domain) is a pure single-word finalizer:

```
x ^= ror(x,25) ^ ror(x,47);   x *= 0x9E6C63D0676A9A99;
x ^= x>>23     ^ x>>51;        x *= 0x9E6D62D06F6A9A9B;
x ^= x>>23     ^ x>>51;        return x;
```

A v2 `rotl r` **replaces** the accumulator with its rotation. nasam instead XORs *several* rotations / shifts of the **current** word back *into* it — a parallel reuse that **no sequential `mul`/`xorshr`/`rotl` chain can express**. So it cannot live under v2, and per the freeze contract it ships under a brand-new frozen tag **`zeta-ir-v3`** (`src/Core/ZetaIrV3.fs`) adding two ops:

| Op | Meaning | Relation to old grammar |
|----|---------|--------------------------|
| `{ op: "xrotxor", rs: [r₁,r₂,…] }` | `x ^= rotl(x,r₁) ^ rotl(x,r₂) ^ …` | genuinely new (parallel self-rotation xor) |
| `{ op: "xshrxor", ss: [s₁,s₂,…] }` | `x ^= (x≫s₁) ^ (x≫s₂) ^ …` | **generalises** v1/v2 `xorshr s` (the one-term case) |

(`ror 25/47 == rotl 39/17` at width 64, so the IR stores `[39,17]`.)

### Note on `xshrxor` generality

Because `xshrxor [s]` is exactly v1/v2's `xorshr s`, v3 **strictly generalises** v2 (which strictly generalises v1). The `ofV2` widening is total and exact, and one fidelity case proves that collapsing nasam's `xshrxor [23,51]` to the single-term `[23]` (i.e. a v2 `xorshr 23`) diverges — so the multi-term form is not redundant.

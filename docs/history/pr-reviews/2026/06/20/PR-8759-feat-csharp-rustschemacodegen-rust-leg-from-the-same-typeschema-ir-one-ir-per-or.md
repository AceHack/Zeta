## Description

Extends approach B toward your **"all langs have the same feature"** north star: the **same `TypeSchema`** that `SchemaCodegen` renders to a C# record now renders to a **Rust struct**, with Rust idioms — PascalCase field names → `snake_case`, nullable `T?` → `Option<T>`, struct name stays PascalCase. The schema's field-type vocabulary is the neutral baseline (C#-shaped); each non-C# codegen maps from it.

- `src/Core.CSharp/RustSchemaCodegen.cs`
- `tests/Tests.CSharp/RustSchemaCodegenTests.cs` — 5 tests, **5/5 green**: golden Rust struct, **the north-star property** (one schema → both C# record + Rust struct), determinism, `int?`→`Option<i32>` + snake_case mapping, unknown-token throws (fail-fast).

Pure + deterministic (explicit `\n`), no deps, **zero churn** to the shipped C#/Roslyn legs. This is the concrete demonstration of the cross-language generalization B was designed for (vs approach A, the C#-only Roslyn generator).

Future slices: a TS leg from the same IR + wiring to the real IMDb dataset.

## Description

## Summary

- adds `docs/LOCAL-BROADCAST-PEERING.md`, a first-class local ask/receipt protocol for same-machine agent peering
- adds B-0210 to track structured ask/receipt implementation over `~/.local/share/zeta-broadcasts/`
- anchors Vera's Codex launchd prompt to read peering asks before choosing its one toe-safe background action

## Why

The six-month unattended target requires background services to converge toward foreground capability. Foreground chat can steer and debug, but the background workers need to read asks, decide, claim, patch, receipt, and hand off without waiting for a human courier.

Local broadcast peering remains an accelerator only. Remote git claims and PR/issue state stay authoritative, so B-0209 remote-only agents still work when the local bus is absent.

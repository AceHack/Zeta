## Description

## What

Adds the first Tier 1 background backlog runner core for B-0249:

- `tools/backlog/autonomous-pickup.ts` reads per-row backlog files, active remote/local claims, dependencies, and priority order.
- `.codex/bin/codex-backlog-runner.ts` gates backlog pickup behind an empty PR queue.
- `.codex/bin/codex-loop-tick.ts` now calls the runner when maintenance work is empty.
- Large legacy rows and explicit `decomposition: blob` rows produce a decomposition prompt before implementation.

## Why

Maintenance-only autonomy is heartbeat without growth. This gives the Codex/Vera loop a bounded way to pick new backlog work after CI/PR maintenance is clear.

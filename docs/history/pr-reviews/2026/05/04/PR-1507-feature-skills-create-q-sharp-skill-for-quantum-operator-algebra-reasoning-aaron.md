## Load-bearing technical content

- **Type-system-as-clarity insight**: `Unit is Adj + Ctl` encodes unitarity (adjointability) and uniform composability (controllability) at the type layer, checked at compile time rather than asserted in comments. The substrate-design framing the maintainer named.
- **Pauli operators in operator-algebra form** (X, Y, Z as unitary/Hermitian/involutive/pairwise-anti-commuting; `PauliX`/`PauliY`/`PauliZ` values for measurement-basis selection) — distinguished from the billiard-ball metaphor that conflates basis-state behavior with amplitude-permutation.
- **`within` / `apply` syntax** as conjugation pattern $U^\dagger V U$ with auto-generated adjoint on block exit.
- **Jordan-Wigner transformation** framing: fermion-to-qubit encoding as a library concern (`Microsoft.Quantum.Chemistry`) not a language-level primitive; Bravyi-Kitaev as locality-cost alternative; foundational paper cited (Jordan & Wigner 1928, Z. Phys. 47, 631).

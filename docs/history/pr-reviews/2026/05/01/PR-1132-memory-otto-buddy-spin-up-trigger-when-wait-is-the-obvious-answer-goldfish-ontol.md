defines peer/buddy mirror-language. This memo is a **per-class
application** of that pattern (per the existing memo's explicit
framing that per-class mechanisms live as separate
composing memos):

- **Wait-trigger** — when Otto's obvious-next-action is "wait,"

  substrates stabilize over iterations

  Otto is great at building ontologies but never uses them
  >30 min before re-creating the same substrate. Buddy is the
  active-reminder layer that grep's existing ontologies
  pre-authoring.

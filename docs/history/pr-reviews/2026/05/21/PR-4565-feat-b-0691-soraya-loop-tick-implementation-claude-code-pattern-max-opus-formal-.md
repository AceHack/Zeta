## What lands

### `tools/soraya/soraya-loop-tick.ts` (288 lines)

Per-tick discipline:

1. Acquire lock (300s TTL; stale-detection via PID)
2. `git fetch origin` (timeout-wrapped per push-hang discipline)
3. Pick next TLA+ spec via rotating cursor state (`spec-cursor.json`)
4. Run `tools/formal-verification/run-tlc.ts <Spec>` with timeout
5. Publish bus envelope: topic=`formal-verification-result`, sender=`soraya`, payload includes job/verifier/result/duration/sha/run_id
6. Every `ZETA_SORAYA_LOOP_CLAUDE_INTERVAL_SECONDS` (default 900s): invoke Claude Code (max Opus default) with Soraya persona prompt for verification-registry drift-audit work
7. Write heartbeat JSON to `.git/agent-heartbeats/` (production checkout) OR fallback to `stateDir/heartbeat.json` (worktree case where `.git` is a file)
8. Release lock

State files at `~/Library/Application Support/ZetaSorayaLoop/` (mirrors Otto-CLI pattern). Logs at `~/Library/Logs/zeta-soraya-loop/`.

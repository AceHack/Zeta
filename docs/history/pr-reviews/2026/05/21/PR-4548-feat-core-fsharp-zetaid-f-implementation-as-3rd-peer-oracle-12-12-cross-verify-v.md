## Catches during implementation (preserving for future-Otto + V8 cycle learning)

1. **Wrong canonical Authority/Momentum byte values caught by cross-verify on first run**. Initial F# Types.fs had AuthorityValue.HumanVerified = 1 / TrustedAgent = 2 / Standard = 4 / BestEffort = 8 / Simulated = 16 (powers-of-2 from algorithmic-default reflex). Canonical per `src/Core.CSharp.ZetaId/AuthorityValue.cs` is 31 / 20 / 15 / 8 / 3 (intentionally non-contiguous for Raw-collision-rejection cleanliness). Test failure → diff hex → identify field positions → corrected values → 12/12 pass on second run.

2. **F# `System.UInt128 fieldValue` compile error**. F# doesn't accept implicit conversion from uint64 → UInt128 via the type-name-as-cast syntax. Used `System.UInt128(0UL, fieldValue)` explicit (high, low) constructor instead.

3. **F# `enum<T>` int vs byte type mismatch on byte-backed enums**. Byte-backed enums require `LanguagePrimitives.EnumOfValue<byte, T>` rather than `enum<T>` with byte argument.

## Description

Second **summonable-BFT oracle**: the F# parity impl of the tri-boolean digital qubit (`src/Core.FSharp.TriBoolean/`), ported from the TS slice-1 reference. Same shape: `Tri = T | F | N` (N = held living-uncertainty), `cooperate` (preserve N) vs `measure` (`Result<bool, CollapseFeedback>` — collapsing a living cell is surfaced, not silent), null-monad `mapTri`/`bindTri` (N propagates), Kleene `notTri`/`andTri`/`orTri`.

Added to `Zeta.sln`; **built standalone at 0 warnings / 0 errors** — the F# compiler = non-Byzantine oracle #2 reporting. TS (slice 1) + F# now agree on the shape; **C#/Rust** are the remaining two oracles, then the cross-verification harness (slice 6) = the summonable-BFT ballot.

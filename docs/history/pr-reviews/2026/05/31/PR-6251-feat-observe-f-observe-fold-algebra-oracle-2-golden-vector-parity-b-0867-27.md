## The cross-language check earned its keep immediately

Parity surfaced a real contract detail: **`BacklogItem.needsNewAction` is OPTIONAL.** The TS `simulate` decompose creates children without it, and `JSON.stringify` drops the absent field, so the fixture's replay-state children omit `needsNewAction`. Absent ≡ `false`, which is exactly the value the F# reducer sets — so the states match once the parser defaults it. **The C# and Rust oracles must honor the same optional-field contract** (noted in the test + commit so #3/#4 inherit it).

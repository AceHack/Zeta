## Two C#-specific parity notes (the cross-language check earning its keep)

1. **`needsNewAction` is optional** — TS's `decompose` makes children without it and `JSON.stringify` drops the absent field; the parser defaults it to `false`, matching the reducer (same finding F# surfaced).
2. **C# records compare list properties by *reference*** — unlike F# lists (structural). So `World` value-comparison is done **element-wise** in the conformance test (`Backlog` via `SequenceEqual`; `Operator`/`Mode` via record/enum equality). The production `World` stays a clean record; the conformance test does the explicit structural match.

## Description

## Why

ARC-AGI-3 actions include a coordinate-valued ACTION6 that cannot be represented faithfully by the existing 4x4 controller lattice. The cross-domain control port therefore needs a data-carrying action before a live ARC environment adapter can be honest. Atari also benefits from a complete standard action vocabulary at the same boundary.

## What changed

- add `Action.Point` plus an optional `PointInput` descriptor to `ControlScheme`
- add the ARC-AGI-3 scheme with seven simple actions and all 4096 coordinate actions
- add the complete 18-action Atari 2600 scheme
- pin canonical payloads, strict coordinate parsing, cardinality, and the non-embedding into a 4x4 `GridBinding`
- declare measured complexity expectations and regenerate F#/TypeScript registry mirrors
- close workitem `081M0QRP3XR087G0R001NCFG83`

## Honest boundary

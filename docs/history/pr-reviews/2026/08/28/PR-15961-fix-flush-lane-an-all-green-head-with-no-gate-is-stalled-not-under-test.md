## Description

## The defect

`classifyHeadVerdict` (`flush-via-staging.ts`) returned `dead` only when a completed check reached a terminal non-success conclusion. Everything else fell through to `under-test`. There was no verdict for a head whose checks all **passed** but whose required check was never **created**.

## Measured

#15887 / #15891, stuck ~17h. Both heads carried seven check-runs, every one `completed/success` — CodeQL Analyze x5, submit-nuget x2 — while `gate.yml` never ran, so `gate (required)` did not exist. Nothing terminal-non-success ⇒ `under-test` forever ⇒ `chooseFlushRoute` returned `buffer` ⇒ the lane parked every tick behind a PR that could never merge.

One cause, four red surfaces: `data/platform-drift.json` pinned, `drift (loud)` red, heartbeat stale, PRs aging into `dirty` on the very telemetry files the lane writes.

The existing cost model — *"waiting on a false negative costs one tick of latency"* — holds only while the check is still coming. When no gate run will ever exist, the cost is unbounded.

## The change

A head is DEAD when **every check present has COMPLETED**, **the required check is ABSENT**, and that has held for `STALLED_GRACE_MINUTES` (30). Each conjunct is load-bearing:

| guard | without it |
|---|---|
| every check completed | a head mid-run gets superseded |
| required check absent | every healthy passing head gets superseded once it ages — the starvation the buffer exists to prevent |
| grace window | a head observed between CodeQL starting and `gate` being scheduled reads as stalled |

Fails closed on a missing clock, missing timestamp, or unparseable one. The clock is read at the edge in `probeHeadVerdict` and injected, so the classifier stays pure and replayable (§13) — same shape as `flush-lane-debounce.decide`. Local scheduling, never a shared fold.

## Falsifiers

Five mutants, **all killed**. Two survived the first version of these tests: the still-running guard and the missing-timestamp guard each passed for the wrong reason, because an unageable check was rejected by a *later* guard before the one under test ever ran. The tests now pair an ageable check with an unageable one so each conjunct is isolated.

Replaying #15887's **real** check-run data: `dead` at the observed time, `under-test` five minutes after its last check completed.

## Not included

The three deadlocked PRs were closed by hand to release the lanes (`findExistingPR` is `state=open`, so the next tick routes `publish`; the buffer is a disposable aggregate, nothing lost). This PR stops it recurring.

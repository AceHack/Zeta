## Description

This item asked for exactly one thing to close: *"the final disposition names the demonstrated cause."* **Apple Diagnostics returned RED on memory** for this Mac on 2026-08-28. Named.

## The item's own breadth was the clue

It opened on .NET frames (`WKS::gc_heap::plan_phase`, exit 139, `EXC_BAD_ACCESS`) and was later broadened to *"across .NET and Node"*. That breadth is what no runtime bug can explain. Widened further on 2026-08-28: 97 memory faults in 8 days across node/V8, dotnet, lean, git, rustc, python3, WebKit **and Apple's own daemons** — which run none of our code; 10 kernel panics with page-mapping refcount signatures; two independent `fsc` processes dying in the same second in different GC phases; and a confirmed single-bit flip that reached `origin/main`.

## The sentence that aged best

Written a month before any of that was known:

> *"A successful rerun is evidence against a deterministic source failure, but it does not explain or resolve memory corruption."*

Reading the green rerun as an all-clear would have closed this in August and left the machine silently corrupting output for a month.

## One exit criterion is not met, and is recorded rather than dropped

The item asked for a bounded run on **two** ARM64 Macs to establish a non-reproduction limit. Only one machine existed, so that comparison never ran — a hardware diagnosis on the single machine supersedes the need for it.

## What this does not close

`081M02SQFZV087G0R000A4ZEXN` — *"CI gates that decide by grep read a crash as a pass"* — is unaffected. The hardware explains the **trigger**; a gate reading exit 139 as zero errors is an independent software defect that survives the repair.

## A note on method, because mine was wrong twice

I reached this item while triaging `archive/*-branch-sweep` tags, using `git cherry` patch-ids and believing they *"survive squash and rebase"*. They survive **rebase**. A squash of N commits into one yields a different patch-id than any of the N, so cherry reports landed work as absent — it claimed **39** unlanded tags where a content comparison finds **35 differing, 5 fully landed**.

Worse: the archived copy of this very item was **stale**. I checked it out over main's newer version and would have regressed the title from *"across .NET and Node"* back to the narrower .NET-only wording. Restored from `origin/main` before appending.

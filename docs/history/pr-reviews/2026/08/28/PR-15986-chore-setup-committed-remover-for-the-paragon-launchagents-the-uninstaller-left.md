## Description

## What

The Paragon NTFS/ExtFS vendor uninstallers were run (operator, 2026-08-28) and left two LaunchAgents behind:

```
/Library/LaunchAgents/com.paragon-software.ntfs.notification-agent.plist
/Library/LaunchAgents/com.paragon-software.extfs.notification-agent.plist
```

Both showed **exit status 78** in `launchctl list` — the code for a job whose executable is gone. Inert, but noise in exactly the surface being examined for this machine's crash investigation.

## Why a committed script and not `sudo rm`

Privileged operations here are reviewable, testable, open-source-readable code. Same shape as `defender-exclusions.ts` and `touchid-sudo.ts`.

## Safety

- **Dry run by default** — prints what it would remove, exits 0.
- **`--apply` refuses unless already root**, and never calls `sudo` itself, so the privilege boundary is crossed by the operator, visibly.
- **Boots each agent out before unlinking** — a plist removed under a running job leaves the job loaded.
- **Reads back afterwards** and exits non-zero if anything survives. The read-back is a *measurement*, not an assertion.
- An empty match prints **the directories it searched**, so "nothing found" can be distinguished from "the search never ran".

## Scope

The Paragon bundle-id prefix in the two launchd directories, nothing else. There are currently **zero non-Apple kexts loaded** (`kmutil showloaded --no-kernel-components`), so there is nothing further to remove. Widening this is a reviewed diff, not a surprise.

## Falsifiers

Five tests. The load-bearing one is the **control**: a predicate of `() => true` satisfies "it selected the file I expected", so the negative cases are what make the positive one mean anything.

Mutation-verified — replacing the filter with a match-everything mutant turns **3 of 5 red**, including the control and the lookalike-prefix boundary (`com.paragon-softwareX.` must not match; without the trailing dot in the prefix it would).

## Usage

```
bun tools/setup/remove-paragon-leftovers.ts            # dry run
sudo bun tools/setup/remove-paragon-leftovers.ts --apply
```

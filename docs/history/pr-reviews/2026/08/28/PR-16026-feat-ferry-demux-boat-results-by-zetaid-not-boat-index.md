## Summary

ZetaId demux for result-arity boats (`081M125DNKK`). Same key the duplex
mux already uses (`multiplexed-duplex-transport.ts`). `UInt128` is a
struct — not a heap FourCorner (Naledi).

- Default: index alignment (omit extractors).
- Opt-in: pass **both** `itemId` and `resultId`. One without the other
  is refused at construction.
- Reordered `processBatch` results land on the matching caller.
- Duplicate item ids refuse the boat; unknown result ids fault that
  row only (fresh exception per miss, not WholeBoat).
- ROADMAP ferry bullet updated: ProcessMany already shipped.

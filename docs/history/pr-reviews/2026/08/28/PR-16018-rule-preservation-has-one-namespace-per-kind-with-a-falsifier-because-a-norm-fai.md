## Description

Aaron: agents *"are trying to backup in random places, we want to align"*. Measured while emptying a machine with a confirmed memory fault — preservation had **twelve conventions across three surfaces**, and had begun nesting on itself (`docs/recovered-orphan-branches-2026-05/misc/archive/` is an *archive* inside a *recovered* tree).

## The rule is written by an offender

In one session I created `~/preflight-backup-2026-08-28/`, `docs/recovered/2026-08-28-src-orphans/` and `docs/recovered/2026-08-28-home-dir-unique/` — three new locations — without once checking where the previous rescue had gone.

Nobody diverges on purpose. Each agent is mid-rescue, under time pressure, and inventing a path is faster than finding the convention. **That is exactly why this needs a check rather than a norm.** I've moved my own invented root into the sanctioned one.

## Four places, chosen by what is being rescued

| what you have | where it goes |
|---|---|
| a commit absent from the remote | **push it** — `preserve/<scope>-<date>` |
| a branch tip being swept | **tag it** — `archive/<date>-branch-sweep/<name>` |
| untracked **files** with no commit | `docs/recovered/<date>-<event>/` |
| anything that cannot go in-repo | `~/.zeta/backups/<date>-<event>/` |

The first row is the one most often got wrong: a branch keeps history, authorship and parentage; copying its files into a directory throws all three away.

## Why unfindable is worse than unbacked-up

A backup nobody can find costs the disk, costs the work of making it, and produces **the belief that the material is safe**. That belief is the expensive part — a check that cannot fail, applied to storage.

## Falsifier

`audit-preservation-namespaces.ts` refuses a new preservation root. Grandfathered roots are listed **individually, never a wildcard**, so the list is auditable and can only shrink.

10 tests, mutation-verified:

| mutant | tests red |
|---|---|
| predicate always returns `null` (guard inert) | 3 |
| drop the `docs/`-only scope (fires on everything) | 1 |

That second mutant guards what would get this check *disabled*: a guard that fires on `.github/actions/apt-archive-cache` gets turned off within a day, and then the real class returns unguarded.

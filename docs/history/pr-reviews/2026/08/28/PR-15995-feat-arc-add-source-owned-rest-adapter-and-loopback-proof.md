## Description

## Summary

- Own the ARC REST boundary with injected `ArcTransport`, typed refusal outcomes, and a versioned deterministic `ArcEnvelope`.
- Serve the source-owned deterministic `ZetaChase` through the toolkit's actual `Arcade.listen_and_serve` path in credential-free OFFLINE mode.
- Prove the lifecycle over real loopback HTTP: open scorecard, reset `ztch-v1`, submit `ACTION4`, and observe the agent move one 8-pixel cell.

## Why

The installed pre-1.0 toolkit is useful as an execution engine, but its Flask, pydantic, `arc_agi`, and `arcengine` types should not become Zeta's public contract. This slice owns text requests/responses at a hexagonal port while preserving every rendered 64x64 frame as lowercase hex-in-JSON.

The toolkit's measured protocol requires a scorecard before local reset and requires the full versioned game ID to retrieve a cached run. Both facts are explicit and tested rather than hidden in the adapter.

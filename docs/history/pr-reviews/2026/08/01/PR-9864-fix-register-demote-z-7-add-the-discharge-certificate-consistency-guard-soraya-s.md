## Description

Soraya's audit confirmed all five Z-5 concerns and found four things I missed:

1. **Z-2's own certificate said `"status": "OPEN"`** — 94.7% error vs a 25% threshold. **The script honestly reported failure and the register cell said DISCHARGED anyway.** The falsifier fired and was overridden in prose.
2. **Z-5 inverted its own source** — the cited research doc concludes *twice* that Reticulum is "already in the Classical/Independent regime".
3. **Citation laundering** — `ρ = 1/(1+L)` is **Zeta's own** `FeedbackThrottle` modeling choice (flagged there as *"not this exact form"*), re-attributed to Liu & Chiribella; and `1/(3√2)` is a **DLA sticking threshold from a demo's `useDLA.ts`**. Zeta's own framework puts the crossing at **ρ\* = √2−1 = 0.414**.
4. **Z-7** — `r = 0` is an **algebraic identity**: `runDLA(seed)` never receives `compiler`, so all compilers share one output. No WASM executed.

Also: **no `z*` test was in any CI workflow.** And none of the rows was ever *in* the §A table — **§A's invariant held**; nothing real depends on them.

**The guard:** a row asserting `§A — DISCHARGED` whose cited certificate says otherwise (or is missing) now fails CI. Narrow by design — it doesn't judge discharge quality, only refuses self-contradiction.

## Description

Mutation sweep of the credential path before a physical USB format. 9 mutants, 5 survived.

**The one that matters:** `bindingMaterial.length === 0` in `zeta-creds-crypto.ts` mutated to `=== 1` left the suite green. That guard is the difference between a device-bound key and a portable one — empty binding material degenerates the HKDF ikm to `"" | stretched`, a passphrase-only key identical on every machine. Round-trip tests all still pass, because a passphrase-only key round-trips fine. It just does it everywhere.

Also pins restore-side degenerate inputs: trailing flag with no value, empty passphrase file, newline-only passphrase file.

**Result:** crypto.ts 1/1 killed, restore.ts 4/5. Remaining survivor is already-present reporting text — cosmetic, left deliberately.

**What reading missed:** three prior eyeball passes called this path under-tested in ways that were wrong. The matrix test is strong (23/24 cells reach real crypto), `parseUuidFromDiskutilInfo` is covered, wrong-UUID restore is covered. The mutation runner found the real gap.

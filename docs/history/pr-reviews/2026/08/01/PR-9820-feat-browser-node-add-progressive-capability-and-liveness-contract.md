## Description

## Summary

- Add a deterministic browser-node capability ladder from static CSS through WebAssembly.
- Model foreground, background, suspended, and dark tab presence with durable dormancy and volatile-state heat.
- Keep git-native, forge-host, Reticulum, Zeta DB, AI, background execution, and hardware access behind independent adapter bindings.
- Require explicit consent before privileged ports activate and emit typed backpressure or heat when they cannot.
- Prefer durable adapters over equally supported best-effort adapters before deterministic identifier tie-breakers.
- Format the Rust keyring cross-verification test that broke the inherited quick gate.

## Why

The browser frame needs one source-owned contract before concrete DOM, PWA, extension, transport, database, or model adapters can compose safely. A CSS-only page remains an honest read-only projection; only a JavaScript, worker, extension, or native-capable tab counts as an executing node. Browser tabs remain best-effort and are never marked critical-path eligible.

## Description

Follow-up to #9869 (which documented the misnaming but deferred the rename until verifiable).

**The name was the propagation vector.** A constant called `TSIRELSON` reads as physics at every call site, so each new use inherited authority the value never had — that's how a DLA sticking parameter became a published quantum-bound claim with **two further conjectures (Z-3, Z-5) built on top of it**. Documenting it helps a careful reader; renaming stops the next reader being misled at all.

- `TSIRELSON` → `STICKING_THRESHOLD` across **9 files (~45 sites)**.
- `TSIRELSON_CHSH` → `CHSH_INV_2SQRT2` (renamed *first* so the general rename couldn't clobber it) — also mislabelled: 1/(2√2) isn't the single-qubit CHSH bound.
- **One false claim survived #9869** at `Home.tsx:929` (*"β_max = 1/(3√2). Same physics, right dimension."*) — that family was invented. Corrected, with Zeta's real crossing ρ\* = √2−1 ≈ 0.414.

**Value unchanged** — pure rename + text: every constant keeps 1/(3√2), so all simulation behaviour and D_f outputs are bit-identical. Only what the code *claims* the number is changes. No `TSIRELSON` identifier remains; tsc green. 🤖 Generated with [Claude Code](https://claude.com/claude-code)

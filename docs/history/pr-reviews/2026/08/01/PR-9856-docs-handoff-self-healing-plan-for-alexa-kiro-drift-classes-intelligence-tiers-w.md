## Description

A writeup to hand to Alexa/Kiro, grounded in a **real drift corpus** — every class listed actually happened and was fixed by hand this session.

**Tier 0** (mechanical): markdown rules, unused imports, stale crash logs (3), gone-upstream branches (**973**). Honestly wants a *script*, not an LLM — use the model to **route**.
**Tier 1** (the ~8GB sweet spot): `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, non-TS languages typechecked by `tsc` (AssemblyScript → 33 bogus errors), toolchain pins exceeding SDK (CS9057). **The compiler is the oracle** — the small model only *proposes*; a fix is accepted iff the finding disappears and no new one appears. **The model never has to be right.**
**Tier 2** (escalate): silent-failure bugs, and **false claims in comments** — the most dangerous class, because they compound by being *read*.
**Tier 3** (never): the proof lineage, anything that *mints*, trust anchors, weakening a test to pass.

Adds three per-healer laws to the harness's existing three: **totality** (a throw is the trap), **exit** (declining is a first-class *success* — no intelligence gets trapped, including the healer), **bounded scope**.

Architecture: **the healer is substrate, the trigger is a plugin** — the forge's auto-clean PR completion is one trigger, wired through `forge-host/`, never a dependency. *"If a fix only works because a forge offered it, it is not a healer."*

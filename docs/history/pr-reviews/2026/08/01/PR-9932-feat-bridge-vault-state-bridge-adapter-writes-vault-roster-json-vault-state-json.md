fix(bridge): the Economy vault claimed live off seven-hour-old evidence

Found by Iris reviewing the emitted JSON during the page-side render spec, and MISSED by
the 23 contract tests already on this branch — those pinned status at page scope and never
checked a single vault. A straight gap: the property was tested at the scope I thought of.

buildEconomyVault read `events.length > 0 ? "live" : "cold"` with a hardcoded confidence of
{0.8, 0.1}, on the reasoning that "reputation is always computable". That conflates the
computation being available with the society being active. In the shipped snapshot every
last_seen is seven hours before generated_at_ms, and the vault reported live.

A renderer can cap this — a child never raises its parent — but the FILE has to be honest
on its own, because monitor.html, a CLI, or any other consumer reads it directly and
inherits whatever it claims. Honesty in one renderer is not honesty in the artifact.

Status now derives from evidence recency via the same computeStatus every other scope uses.
Confidence tracks it: {0.8, 0.1} live / {0.5, 0.3} stale / {0.2, 0.5} cold — a narrow band
on old evidence is a claim of precision that was not earned.

Two tests added, both confirmed failing before the fix: no vault reads live off stale
evidence; no vault asserts confidence it did not measure.

25 pass, 0 fail, tsc clean.

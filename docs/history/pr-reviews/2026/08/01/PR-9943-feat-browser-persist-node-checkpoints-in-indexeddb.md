## Description

## What changed

- add a source-owned, byte-oriented browser checkpoint port with native IndexedDB load, save, bounded remove, and close operations
- enforce atomic monotonic revisions: stale writes, conflicting same-revision bytes, and stale removals return typed backpressure
- close native connections on schema-version changes and translate storage failures into typed feedback
- extend the real Chromium multi-tab proof through full shutdown, fresh-page recovery, guarded retraction, and a second fresh start with no stale tab presence

## Why

The browser node previously declared durable continuity in its real-page fixture without owning or exercising a durable adapter. This makes that claim measurable while remaining independent of Alexa's vault-state emitter and Iris's renderer: both can compose with the source-owned checkpoint port without entering the pure planner.

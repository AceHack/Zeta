## Description

**Main is red.** `bun src/Core.TypeScript/lint/lint-typescript.ts` (the exact command CI's `lint (TS)` job runs) fails on current main — *"✗ TypeScript type check: tsc: exited with code 2"*, **42 errors**. Found while verifying an unrelated change. Three independent causes:

1. **33 — AssemblyScript typechecked as TypeScript (config bug).** `src/wasm-dla/assemblyscript/` is compiled by `asc` and uses AS builtins (`i32`/`u32`/`f64`/`StaticArray`) tsc can't know → bogus TS2304s. Added to tsconfig `exclude`. **Excluded, not silenced** — `asc` is its real checker, and the comment says so.
2. **4 — `z7-pearson-discharge.ts`**: unused import + two `noUncheckedIndexedAccess` violations. The `BINARY_SIZES` lookup now **fails loudly** on an unknown compiler — a silent `0` would quietly corrupt the very correlation the script discharges.
3. **5 — `credential-binding-model`** under `exactOptionalPropertyTypes`: optionals widened to `?: string | undefined` because the model **deliberately distinguishes "explicitly gone" from "absent"** (`esp_wipe` sets `uefiKeyfile: undefined`); narrowing would lose that. Fixture uses `satisfies` so tests need no non-null assertions.

**Verified:** CI lint command → *"✓ TypeScript, Prettier, and style checks passed"*; `tsc --noEmit` → **0 errors** (was 42); credential-binding tests 34/34.

## The 47 rewrites were reverted — the more interesting finding

The healer's plan was 1005 files: 958 removals + 47 rewrites. **Applying the rewrites broke `tsc`:**

```
darkhall-browser-tab-sink.ts: Cannot find name 'BrowserReadoutSinkResult'
subscribe.ts: 'recipient' is optional in type ... but required in type ...
```

The unused-import healer removed a **type-only import that is used**; the exact-optional healer mangled an optional property.

**So the Tier-0 healer generates code that does not compile.** It's been unable to run for months (missing module on a 759-commit-stale branch → failure swallowed → commits never pushed), so nobody found out.

Which means the blast-radius bound (#9891), on its **first production firing**, didn't merely prevent a *large* change — it prevented a large **broken** one. That's a better argument for the bound than the one I wrote it with.

Only the deletions are taken here; the rewrite defect is left for a fix to the healers themselves.

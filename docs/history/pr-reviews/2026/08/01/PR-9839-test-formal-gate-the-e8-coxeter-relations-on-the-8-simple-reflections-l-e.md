## Description

Delivers the group-presentation leg of work-item 081KYXCM1WK — routed to **exact-arithmetic property testing, not Lean** (W(E8) has 696,729,600 elements; Mathlib has no concrete E8 root system, so a prover would cost weeks for something decidable in integers over 240 vectors).

The existing suite pinned the simple system's **angles**; this pins the **group relations** they imply: `s_i² = id` and `(s_i s_j)^m = id` with **m read off the Gram matrix** (−2 ⇒ Dynkin edge ⇒ 3; 0 ⇒ 2), verified on all 240 roots.

Plus a **negative control** — the assertions would be vacuous if every power trivially returned x, so it exhibits a pair whose `(s_i s_j)^(m−1)` genuinely *moves* a root.

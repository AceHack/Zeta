## Description

The one leg of the path-independence scout's find that survived the refuter, built into
something checkable: whether local agreement forces global agreement is a property of the
SHAPE OF THE COVER, not of the merge operator.

The criterion (Beeri, Fagin, Maier & Yannakakis, JACM 30(3):479, 1983): a cover is
alpha-acyclic iff every pairwise-consistent instance over it has a universal relation.
Decided by GYO reduction (Graham 1979; Yu & Ozsoyoglu 1979).

WHAT MAKES IT A FALSIFIER RATHER THAN A RESTATEMENT. A GYO implementation tested against
hand-labelled examples only proves the author can label examples. So the other side of the
biconditional is computed independently, by exhaustion, by code that never calls GYO:
every instance over a two-value domain, for every cover of 2-3 nonempty subsets of {A,B,C}.
382 covers, 0 disagreements. Two sabotage controls -- always-acyclic and always-cyclic
oracles -- both FAIL the same check, so it cannot pass vacuously.

Certificates on both verdicts, because a boolean is not reviewable: a join tree on the
acyclic branch (validated by a running-intersection checker that never calls GYO) and the
irreducible core on the other. The asymmetry is stated rather than hidden -- the acyclic
certificate is genuinely independent, the cyclic one is a trace, and the independent check
for a cyclic verdict is semantic (produce the witness instance).

THE WITNESS, exhibited: the 3-cycle with each relation asserting "my two attributes
differ". Pairwise perfect; globally impossible, because A != B and B != C force A == C over
two values. Proved in the suite by exhaustion over all 8 tuples. No merge operator recovers
a global section that does not exist -- which is why this is a carving criterion and not
advice about merge functions.

MUTATION-CHECKED: 11 of 14 mutants killed. Two genuine test gaps found and healed (nothing
exercised validateCyclicCore's rule-(E) check; nothing exercised the disjoint-pair empty-
projection convention). The 3 survivors are equivalent mutants, and that was measured
rather than argued: each was applied and both versions run over 200,000 random covers,
0 differing verdicts.

A bug this found in itself: the cyclic core first reported the elements' ORIGINAL
attributes, which looks like a sub-cover of the input but is not a fixed point -- an
ear-stripped attribute reappears and rule (E) fires on the "irreducible" core. Caught by
the property test asserting every emitted certificate validates, on a cover fast-check
found in 51 runs. Regression test pins both directions.

MEASURED on real covers here: the IMDb zetaschema cover and the FactoryDemo SQL schema
(under both a raw and a role-qualified naming convention) are all ALPHA-ACYCLIC. The
interesting part is not the verdict -- the FactoryDemo foreign-key graph is a TRIANGLE and
the cover is still acyclic, because `activities` carries both keys. A loop in the ER
diagram is not a cyclic cover, which is the concrete reason this has to be computed on the
attribute hypergraph rather than eyeballed. Verdicts are pinned; losing the guarantee later
goes red.

REGISTER, which matters more than the code. The BFMY statement is CHECKED by entailment
over those 382 covers. The Vorob'ev-condition equivalence (Barbosa, via Abramsky 2013 §7)
is CITED ONLY -- I did not read Vorob'ev or the proof, and nothing in the code depends on
it. Abramsky is cited at SECOND HAND: the scout read the paper, I read the scout. Declined
entirely: any claim about CRDTs, Bell inequalities, contextuality, or our merge algebra --
the companion doc refuted that identification and this survives on database theory alone.
Also declined: a DV2.0 measurement, because there is no relational hub/satellite cover in
this repo to point it at, and "it applies to DV2.0" with nothing measured is the
unfalsifiable claim this module exists to avoid.

TypeScript, not F#: the artifacts covers are extracted from are JSON/SQL read by TS

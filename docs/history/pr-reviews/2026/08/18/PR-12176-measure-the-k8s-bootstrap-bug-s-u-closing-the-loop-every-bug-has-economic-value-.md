## Description

measure: the k8s bootstrap bug's ΔU — closing the loop every-bug-has-economic-value opens

#12165 fixed a real bug and deliberately did NOT file the measure, because that needs a minted
work-item and the agent declined to expand scope mid-gate. That was the right call at the time and
it left a loop open: `.claude/rules/every-bug-has-economic-value.md` says a bug-fix IS a `measure`,
so a fix without one is a rule with a gap in it.

The blocker is now cleared — #12165 merged at 22:46Z — so this files it. I deliberately waited:
measuring a ΔU for a fix still in flight would have recorded a reduction that had not happened yet,
and the ledger is keyed and idempotent precisely so it can be filed once, correctly, rather than
early.

THE WITNESS IS WHAT MAKES IT ADMISSIBLE, and it is genuinely strong rather than nominal:
`infra/k8s/tests/validate-bootstrap.ts` run against main's PRE-FIX file reports `20 passed, 1
failed`. It goes red on exactly the bug it was written for. The rule REFUSES unwitnessed or
unsubstantiated pricing, so this is the difference between a ledger entry and a wish.

Sign: `reduced`. The bootstrap path went from unmetered-and-broken to metered-and-verified on real
hardware. Before, `infra/k8s/bootstrap/**` had NOTHING witnessing it, and `helm-validate.yml`
triggered on `infra/k8s/**` while its validator scanned only `infra/k8s/applications` — so a
bootstrap change ran a lane that structurally could not see it and reported green. Uncertainty about
whether a node could bootstrap at all was total AND invisible; it is now bounded by a falsifier that
runs per-PR.

Lineage recorded because it generalises: the bug was found by MEASUREMENT rather than reasoning — an
agent booted real K3S with the manifests as they stood on main instead of reading them. And the
structural half (trigger path wider than validator scope) is the fourth instance today of a check
that appeared to protect something it could not see.

Register is ordinal + witnessed, never an invented number, per the ledger's own discipline.

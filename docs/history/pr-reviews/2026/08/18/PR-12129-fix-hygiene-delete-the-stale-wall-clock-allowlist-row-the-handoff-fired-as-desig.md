## Description

fix(hygiene): delete the stale wall-clock allowlist row — the handoff fired as designed

`lint (bash retirement inventory + hygiene unit tests)` is RED ON MAIN, at the step "Ambient-time-
in-tests guard (no test verdict may depend on wall-clock)". It is therefore blocking every open PR,
which is how I found it: it failed on a DOCS-ONLY branch of mine, which is exactly the signature of
a repo-wide red rather than a PR-specific one.

NOT A DEFECT — A DESIGNED HANDOFF THAT WORKED. The allowlist row for
`poll-pr-gate-batch.test.ts` was never an exemption, and says so in its own text: "NOT LEGITIMATE
-- IN FLIGHT, AND THIS ROW IS A HANDOFF, NOT AN EXEMPTION... WHOEVER LANDS THAT FIX MUST DELETE
THIS ROW: the count pin will report 'stale row, no longer constraining anything' the moment the
sleeps go, and that red is the intended handoff signal rather than a defect."

That is precisely what happened. #12098 landed and removed all three timers from that file; the
pinned count of 3 no longer matched 0; the guard refused a row that had stopped constraining
anything. Two lanes, one file, and the collision was ANTICIPATED and routed through a declared
channel instead of being discovered by accident.

Worth naming because it is the same discipline the guard enforces: an allowlist row that no longer
constrains anything is the vacuity class wearing an exemption's clothes — it looks like a
considered decision and rules out nothing. The check applies that standard TO ITS OWN ROSTER, which
is what makes the roster trustworthy rather than a place violations go to be forgotten.

Fix is exactly what the row instructs: delete it. Nothing else touched — the six remaining rows are
genuine elapsed-time observations (an absence-assertion that cannot be polled for, a subprocess
fixture that is the subject under test, a live keep-alive integration, and the detector's own
string-literal fixtures).

Verified: guard now reports "OK: 1066 test files scanned; no test verdict depends on wall-clock
delay. 11 elapsed-time observation(s) named and counted." Detector's own suite 25 pass / 0 fail.

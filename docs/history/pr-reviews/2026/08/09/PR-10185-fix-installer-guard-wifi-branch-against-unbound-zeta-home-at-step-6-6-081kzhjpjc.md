## Description

The ESP-unmount fix (#10184) made the wifi creds findable → the wifi-injection branch (step 6.6) runs for the first time → **`ZETA_HOME: unbound variable`** under `set -u` (ZETA_HOME isn't set until step 6.95a, ~600 lines later).

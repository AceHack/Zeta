## Description

The key-custody run was the **genesis example**, so the blueprint now records what generation zero got *wrong* — a genesis example that reads as a success story teaches nothing.

Seven defects, each with its generation-1 answer. The ones that actually cost us today:

- **The islands shared one clone.** A checkout wiped uncommitted work, and a **mid-mutation snapshot was nearly committed as the derivation**. They were time-shared, not isolated. → `isolation: worktree` per derivation.
- **The wall leaked directionally.** B merged to `main` while A was still deriving, leaving A one `git pull` from contamination. Independence survived on timing. → No derivation merges until all have committed.
- **The report was nearly lost.** A deadlocked on a dead sweep, and its report — which found *more* spec defects than the combine did — existed only in its head until nudged. → Write it incrementally to a durable path.
- **Only one island faced selection pressure.** A mutation-swept; B didn't. → Same verification regime on both, or it isn't a comparison.
- **No stated fitness.** "A wins on substance" was a judgement, not a measurement. → State it up front: spec defects surfaced + coverage honestly earned − coverage claimed and not earned. **Fitness rewards finding the spec's holes, not writing more code.**

## The guard

Every improvement makes isolation *cheaper or more rigorous* — **none should make it shorter.** Premature migration is the island model's failure mode, so a generation 1 that speeds the loop by shortening isolation has optimised away the only thing that worked.

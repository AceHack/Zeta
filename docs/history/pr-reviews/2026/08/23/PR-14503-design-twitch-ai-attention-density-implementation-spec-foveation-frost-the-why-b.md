## Description

design: twitch-ai attention-density implementation spec — foveation, frost, the WHY button, and the prediction falsifier

Aaron 2026-08-23: "can we write this up for the twitch-ai page to implement? this
is where we are trying to make our code.AI learnings demoable to humans" — and
"try to over-include everything we talked about", his own index doctrine applied
to a handoff (over-include; the surrounding text is what the expensive downstream
pass scrutinises). Handoff target: Otto desktop Fable mode.

Written against the actual files (src/apps/twitch-ai/: main.ts 8.7KB,
swarm.worker.ts 8.4KB, Chip8TvPlayer.ts 10.8KB, styles/llmtv.css), not
aspirationally. Seven deliverables, each with an acceptance test that can fail:

D0 (BLOCKING) — wire a CI job first. Workitem 081M0QF7ZVY087G0R003Q4Q18D records
that twitch-ai is a self-contained Vite app with NO CI job, and two main-is-red
workitems already came out of that. Adding features to a surface with no CI is
how the vacuity class gets in.
D1 — the attention field crosses the worker boundary as a transferable
Float32Array on the SAME message as the frame (two channels = two clocks = the
overlay can disagree with the frame it labels); derived from the NG4 precision
components, never a parallel uncertainty estimate that could drift.
D2 — foveation: full ladder on top-K tiles by variance. Explicitly the
InformationValue.fs society allocator one granularity down. Metered by
useful-work fraction, and REQUIRED to display "ambiguous" when the variance field
is flat rather than silently sampling uniformly.
D3 — frost as the uncertainty channel, reusing GlassHalo/RoomBoundary vocabulary
so a viewer learns the real system's words.
D4 — draw the saccade/fixation split DebouncedOracle already implements.
D5 — the WHY button, answers GENERATED from the state that drove the decision and
never a string table, with a reachable "I don't know" as the feature.
D6 — the falsifier that decides whether D1-D5 worked: pause, ask "where will it
go next?", compare accuracy with and without the overlay. If the overlay does not
raise prediction accuracy it is decoration.

Plus twelve over-included session threads, each stating why it touches this page:
the local/global exploit shape and its corollary that a local check cannot see a
global property (constrains how D2's meter may be read); pigeonholing and the
avoided/played-within distinction (the UI must distinguish inside-competence from
outside-and-guessing); ROP/Rice/Dullien (never build an affordance claiming the
agent CANNOT do something); gossip + decorrelation, with the adversarial-
transferability warning that independent construction does not guarantee
decorrelated agents — a collapsed swarm looks exactly like a working one from
outside, the most misleading state available on a demo page; meters that fail
loudly; the society-vs-individual attention router as a checkable §9/§10 claim;
echolocation debounce and "a bat that pre-computes its own echo is hallucinating";
the Tsirelson caveat that must travel with the number; DISCLOSURE as what makes a
broadcast surface non-creepy, which is a requirement not a nicety since twitch-ai
is LLMTV — what is shown must be disclosed, and what is displayed is what an agent
DID, never an inferred why; never-delete and why demo resets are a horizon that
must be stated; WHY-before-HOW and the Stump Dad game D5 mechanises; and why the
page exists at all (a productivity claim whose mechanism is legibility, which is
why D6 measures what a viewer can DO).

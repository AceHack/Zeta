## Description

## Summary

Two fixes for the same `lint (TS)` red landed within a minute of each other:

| commit | PR | approach |
|---|---|---|
| `89b0f4c60` | #14213 (vera) | root `package.json` + `bun.lock` gain `vite: 8.2.0` |
| `c94fd4406` | #14214 (me) | root `tsconfig.json` excludes `src/apps/twitch-ai/vite.config.ts` |

Both are on `main`, and **the combination is the worst of both**: the root install now
pays for a bundler *and* the file it would have checked is still excluded.

## Owning it

I chose the exclude over adding the dependency and stated the reason plainly in
#14214: the root install deliberately carried no bundler, so the root project was not
the right checker for that app's bundler config.

**#14213 made that reason false.** `vite` is a root devDependency now, so the file can
be genuinely typechecked here. My exclude then stops being a scoping decision and
becomes precisely what #14214's own body argued against — a line that removes real
coverage while a comment implies the coverage lives elsewhere.

So the exclude goes, and its `HONEST LIMIT` paragraph goes with it, because the limit
no longer holds.

## Falsified, not assumed

With the exclude removed and `vite` installed at root, corrupting the config is caught:

```
build.target: 'esnext' -> 12345
tsc exit 2 — src/apps/twitch-ai/vite.config.ts(8,5): error TS2769:
  No overload matches this call.
```

Clean run: `bun src/Core.TypeScript/lint/lint-typescript.ts` exit 0 on `40e993d16`.

## Standing dependency, stated so it is not a surprise later

This now rests on `vite` remaining a **root** devDependency. #14213 added 79 lines of
`bun.lock` including platform-specific optional binaries. If that dep is ever reverted,
`TS2307` returns and the 081KZKWB1FZ guard will correctly refuse to reclassify it —
the fix then is to restore the dep or re-exclude the file deliberately, **not** to
widen the guard.

## Unaffected

**081M0QF7ZVY087G0R003Q4Q18D** still stands: `twitch-ai` has no CI job of its own, and
neither do the three sibling vite apps (`demo/identity-dla-site`,
`full-ai-cluster/portal/web`, `src/Renderers/website`). This PR narrows what that
work-item covers by one file; it does not close it.

**Weaviate.** `cr.weaviate.io` says what it is in its own `WWW-Authenticate`: realm `auth.docker.io`, service `registry.docker.io`, scope `repository:semitechnologies/weaviate:pull`. It is a pull-through proxy, and Docker Hub's anonymous quota is charged to *it*, shared by everyone — three attempts on 2026-08-23, all HTTP 429, matching the 429 recorded on 2026-08-22. The same image direct from `docker.io/semitechnologies/weaviate:1.32.7` resolves immediately, `sha256:b255e62c…`, 84,940,612 B. **A limit that bites a size probe bites a pull**, so the shorter path is also the one more likely to start the pod.

**gmod.** `ghcr.io/ich777/steamcmd:gmod` is a 404; the publisher's 94 tags contain `garrysmod`. The blueprint's `+app_update 4020` is Garry's Mod Dedicated Server, so tag and install now agree.

**kubectl — the better pin was checked and refused.** `registry.k8s.io/kubectl:v1.32.3` resolves at 18,750,205 B (6× smaller, upstream-maintained rather than a frozen archive), but its config blob reads `ENTRYPOINT ["/bin/kubectl"]` on the distroless `go-runner` base — **no shell**, and the Job runs `/bin/bash -ec` with arrays and `seq`. That would trade a pull failure for an exec failure. The shell-free rewrite is filed, not guessed at.

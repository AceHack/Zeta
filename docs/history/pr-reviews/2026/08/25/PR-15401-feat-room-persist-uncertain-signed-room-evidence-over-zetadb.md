## Description

## What

Adds the durable foundation for uncertain, signed room evidence:

- versioned room-evidence atoms carrying `+1` / `-1` ZSet weights and uncertainty;
- canonical order-independent folding plus a Merkle root over signed atom keys;
- ZetaStorageCell persistence/replay so room truth survives individual emulator runs;
- a thin `LossyUdpChannel`-compatible boundary that delegates erasure recovery to the existing Adinkra `[8,4,4]` transport;
- eight conformance tests, including out-of-order corrections, exact cancellation, disambiguation, durable replay, and malformed-payload refusal.

## Boundaries

This does **not** claim cryptographic identity verification, semantic task equivalence, a CHIP-9 executor, or scientific competence. `signatureSplit` is an opaque disambiguation label in v1. The Adinkra channel supplies existing erasure recovery and CRC enforcement; it does not authenticate an author or manufacture missing room evidence.

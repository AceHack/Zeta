## `js/command-line-injection` — CRITICAL — `hygiene/retraction-actuator.ts`

`execSync` over a concatenated string put `head_sha` from the Actions API onto a shell
command line (`git rev-list ${greenHead}..${redHead}`) inside a job that holds a `GH_TOKEN`
with push access to `main`. **Classification (a) REAL.** The usual dismissal — "GitHub only
returns real shas" — is a claim about the server that is checked nowhere.

`execFileSync` with an argv array: there is no shell, so there is no command line for a
response body to be read as. It also removes quoting that was never right — the
`git config user.name "github-actions[bot]"` calls carried literal `"` characters that only
worked because a shell stripped them.

Removing the shell closes **command** injection and not **argument** injection
(`git revert --no-edit --upload-pack=…` is still a git option, not a revision), so `isSha`
gates every API- or git-derived value that reaches `git` as data, at the one door it enters
through. A head that is not a sha makes the picture unclean and the actuator stands down
loudly, rather than a repaired value being handed to `git`.

**Falsifier:** `git("rev-parse", "HEAD; echo pwned")` throws. Under `execSync` it returned
`<sha>\npwned` — reverted, that test goes red; restored, green.

## `js/prototype-pollution-utility` — `ace/deps.ts` `setNestedProperty`

**Classification (a) REAL.** `path` reaches this function from a dependency graph's
`consumes.target` in YAML, so a *spec* picks the segments, not a caller. `__proto__.polluted`
wrote through the prototype chain. Refused now with the same throw the empty-path case
already used.

The quieter half is the better find: `part in current` walks the prototype chain, so
`toString.enabled` descended into `Object.prototype.toString` and set a property on the
**shared function object** — the subsequent read looked correct while every object in the
process had been mutated. `Object.prototype.hasOwnProperty.call` instead.

**Falsifiers** for both halves; the own-property assertion is the discriminating one, and
the first version of that test was thrown away for passing under the defect.

## Description

# Summary

This replaces the live Earth–Mars `v_B·u * 1.2` cone-widening estimator with an epoch-free endpoint-speed norm envelope plus a named additive Kepler-curvature residual. The old projection can cancel to zero while the actual asymmetry remains nonzero; the new default is backed by the existing Lean and Z3 certificates. Other orbital pairs remain explicitly assumption-grade until they have their own pair-specific envelope.

# Spec alignment

This changes the conservative `deltaMaxMs` behavior consumed by `BusRegime` for the Earth–Mars link. No OpenSpec capability currently names this internal safety-bound replacement. The public function signature remains unchanged.

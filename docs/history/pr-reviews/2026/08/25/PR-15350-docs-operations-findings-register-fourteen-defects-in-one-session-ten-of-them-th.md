## Description

Aaron asked that everything noticed today be fixed, routed, or at least
tracked. An untracked finding is indistinguishable from one that was never
found, so this is the register.

Ten of the fourteen are one shape: an outcome decided by the WIRING rather
than by the thing under test. A check that cannot fail reads as a check that
passed; a step that cannot pass reads as a defect in whatever it points at.
Neither is visible in a red/green summary, which is why they survive.

Three need a decision rather than a fix, and are marked NEEDS AARON rather
than quietly actioned:

  * `Action-Mode: autonomous-tick` is illegal but appears in 5 commits. The
    convention's own note says an independently-repeated coinage is evidence
    of a missing distinction, not carelessness — and both prior extensions
    were maintainer-authorized. Legalising it is not mine to do.
  * ~80 of 100 recent gate runs on `main` were CANCELLED. A cancelled run is
    neither pass nor fail. Confirmed independently five times; the remedy is
    a merge-queue decision, which is a topology change.
  * `agentic-organization`'s test suite runs in no workflow, and four archive
    PRs fail on a stale base. Both genuinely unowned.

Three REFUTED leads are recorded alongside the confirmed ones, because a
register that lists only its hits overstates its own accuracy. Including the
one where I claimed the heartbeat arming step was a fossil with no writer:
`merge-heartbeats-to-main.ts:124` emits it, and my own audit's script-
following disproved me.

Two process defects are the most transferable part:

  * A control run against already-fixed code proves nothing. Both audits
    written today first ran against trees where the bug was gone, and both
    looked healthy. Run against unfixed `main`, one caught two real instances
    and the other produced a false positive on a working workflow.
  * An audit can be vacuous about ITSELF. A bad edit deleted a helper, every
    workflow threw, the catch swallowed it, and the tool printed "OK — every
    reference has a writer" over 77 unchecked files. General form: a checker
    must distinguish "I found nothing" from "I did not look."

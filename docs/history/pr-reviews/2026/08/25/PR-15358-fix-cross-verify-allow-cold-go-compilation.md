## Description

## Summary

- replace shell-based compiler execution with typed `execFileSync` calls
- preserve subprocess failures and validate generated JSON instead of collapsing errors to `null`
- isolate each generated program in a cleaned temporary directory
- allow 60 seconds for cold Go compilation while retaining 15-second limits for TypeScript and Python

## Why

PR #15352 reproduced a 15.067-second Go timeout in the hermetic TypeScript job. A local cold run took 22.2 seconds, so the former shared 15-second process limit was below measured compiler startup cost.

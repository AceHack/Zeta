## Description

`lint (TS)` fails on `main`: `src/Core.TypeScript/observe/model-benchmark-scale.ts`
carries two TS6133 "declared but never read" errors, from #15429 (the N=200 benchmark).

HOW IT SURFACED, and the inversion is the useful part. `lint (TS)` FAILED on a PR adding
four files — two markdown docs, a work-item, a JSON event, ZERO TypeScript — and PASSED on
a PR that adds actual TypeScript. Backwards, until you check branch age: the docs-only PR
is 0 commits behind main and inherits the break; the TypeScript PR is 24 behind and
predates it. The failing check names the victim, not the cause, again.

Reproduced locally on the docs branch:

  src/Core.TypeScript/observe/model-benchmark-scale.ts(231,15): error TS6133: 'n' is
    declared but its value is never read.
  src/Core.TypeScript/observe/model-benchmark-scale.ts(254,11): error TS6133: 'bestEnergy'
    is declared but its value is never read.

FIX: remove both bindings, keep what they were documenting. `const n = trials` was unused
because phi is computed from the 2x2 cell counts alone — now said in the comment.
`const bestEnergy = 1 // relative` was carrying the fact that energy is expressed relative
to one model, which the surrounding log line already prints as "@ 1x energy" — now stated
in a comment instead of an unread binding. Nothing about the benchmark's behaviour changes.

Verified: `bun src/Core.TypeScript/lint/lint-typescript.ts` rc=0 after, having reproduced
rc=1 before.

Note for the record: #15429 also merged with NO AgencySignature block in its squash
commit, which is why `agencysignature (main tip)` went red at the same time. That cleared
when the tip advanced; this did not, because a type error does not age out.

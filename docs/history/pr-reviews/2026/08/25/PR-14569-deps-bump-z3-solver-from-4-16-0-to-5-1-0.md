<h1>Version 5.1.0</h1>
<ul>
<li>New monadic regex solver enabled by default (<code>smt.seq.regex_monadic=true</code>).

regex constraint solving, with semilinear length abstraction for regular expressions.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10466">Z3Prover/z3#10466</a>, <a href="https://redirect.github.com/Z3Prover/z3/pull/10472">Z3Prover/z3#10472</a>,

<li>Add seq_monadic: configurable orientation (retry default) for reading regex memberships,
light Antimirov cofactor mode, DNF replacement with depth-first search, and unsat-core extraction.
Thanks to Margus Veanes.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10519">Z3Prover/z3#10519</a>, <a href="https://redirect.github.com/Z3Prover/z3/pull/10323">Z3Prover/z3#10323</a>,
<a href="https://redirect.github.com/Z3Prover/z3/pull/10366">Z3Prover/z3#10366</a></li>
<li>FPA rewriter simplifications for <code>fma</code> with zero multiplier. Fixes <a href="https://redirect.github.com/Z3Prover/z3/issues/8185">#8185</a>.
Thanks to Lev Nachmanson.
<a href="https://redirect.github.com/Z3Prover/z3/pull/9038">Z3Prover/z3#9038</a></li>
<li>LP-based nonlinear bound optimization for cross-nested conflicts; nonlinear bound optimization
moved into monomial_bounds for improved NLA performance.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10180">Z3Prover/z3#10180</a>, <a href="https://redirect.github.com/Z3Prover/z3/pull/10434">Z3Prover/z3#10434</a></li>
<li>NLA: re-linearize violated monomials with fixed factors at final check; run bound squeeze
before nonlinear engines and back off satisfiable nlsat probes.
Thanks to Lev Nachmanson.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10521">Z3Prover/z3#10521</a></li>
<li>Fix strict optimization objective reporting to preserve strict-real suprema in LRA path.
Fixes <a href="https://redirect.github.com/Z3Prover/z3/issues/10534">#10534</a>. <a href="https://redirect.github.com/Z3Prover/z3/pull/10269">Z3Prover/z3#10269</a></li>
<li>Fix intblast soundness for array-derived BV equalities (<code>smt.bv.solver=2</code>).
<a href="https://redirect.github.com/Z3Prover/z3/pull/10485">Z3Prover/z3#10485</a></li>
<li>Fix <code>str.at</code> soundness inside regular expressions.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10495">Z3Prover/z3#10495</a></li>
<li>Fix ill-sorted UF rewriting in fpa2bv for quantified Float32 arrays.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10486">Z3Prover/z3#10486</a></li>
<li>Fix duplicate enode internalization for quantified Float32 datatype terms.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10482">Z3Prover/z3#10482</a></li>
<li>Fix unsigned underflow of cardinality bounds in PB internalization.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10515">Z3Prover/z3#10515</a></li>
<li>Fix assertion violation in <code>lp_bound_propagator</code> for columns with non-zero delta.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10438">Z3Prover/z3#10438</a></li>
<li>Fix variable-divisor mod divisibility lemmas.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10514">Z3Prover/z3#10514</a></li>

<li>Fix <code>elim-term-ite</code> simplifier soundness: add missing auxiliary variable constraints.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10244">Z3Prover/z3#10244</a></li>
<li>Fix <code>euf_arith_plugin</code> missing <code>uminus</code> implementation.
<a href="https://redirect.github.com/Z3Prover/z3/pull/10243">Z3Prover/z3#10243</a></li>

<li>Fix <code>smtlib2_compliant</code> mode: Int/Real sort mismatch in <code>coeffs2app</code> caused <code>unsat</code> to return <code>unknown</code>.

## Description

## The blocker

The Clifford-geometry-in-activations research line was **DEFERRED on an infrastructure dependency**. `src/Core.TypeScript/accelerator/local-llm.ts` talks to Ollama's `/api/generate` — a completion API returning text — and `/api/embeddings` returns a *pooled* vector. Neither is a residual-stream activation, so neither can answer H1's causal "respect" clause. Work-item `081M0QD23P3087G0R002NQ8217` scoped it.

## Where it is declared, and why not an existing realizer

I checked the existing uv classes first. **`from-uv-venv` genuinely does not fit**, on four independent grounds:

1. **No lockfile.** `uv pip install <spec>` re-resolves the transitive closure — 112 packages here — per machine, nothing hash-pinned. That is the determinism §7 DST forbids trading away.
2. **No per-platform index.** It cannot route linux to the PyTorch CPU index, so linux takes the CUDA wheel.
3. **Shared venv.** It installs into the one repo-root `.venv` beside the Q# oracle deps, so a torch resolution failure would take the quantum lane down — the coupling `src/Arc.Python`'s header says separate projects exist to prevent.
4. **Hardcoded gate and probe** (`ZETA_INSTALL_QUANTUM`, `import qdk`).

`from-uv-tool` is for `uv tool install` CLIs; these are importable libraries.

So **`from-uv-project`** is added beside them as the **18th realizer class**: locked uv projects via `uv sync --frozen`, opt-in per row. That was the one Python shape `ace` could not express — `src/Core.Python` and `src/Arc.Python` are synced by ad-hoc `uv sync` steps inside workflows, which *is* the un-dogfooded gap. They are deliberately **not** claimed here; migrating them would add their cost to every `install.sh` run and is a separate decision.

`interp-lane.yml` syncs **through the realizer**, so CI exercises the manifest, the gate and the realizer rather than asserting them in unit tests alone.

## Clone-at-tag is preserved

The manifest is plain text; `uv.lock` carries a **sha256 per wheel**. A fresh clone resolves nothing and decides nothing, and `uv sync --project src/Interp.Python --frozen` works with no `ace` on `PATH`. Exit stays real, so `ace` is the good path rather than the only one. `lint-clone-at-tag-is-sufficient.ts` → **rc=0**, 7 surfaces scanned.

## Cost — measured, not estimated

Wheel `Content-Length`, 2026-08-25:

| Host | Build | Wheel | Accelerator |
|---|---|---|---|
| macOS arm64 (`macos-26`) | `2.13.0` PyPI | **111.2 MB** | CPU + **MPS** |
| `ubuntu-24.04` x86_64 | `2.13.0+cpu` | **191.8 MB** | CPU only |
| `ubuntu-24.04-arm` aarch64 | `2.13.0+cpu` | **155.0 MB** | CPU only |

**One pin does not cover all three.** `[tool.uv.sources]` routes linux to the PyTorch CPU index; without it x86_64 resolves the **526.6 MB** default wheel *plus* the whole `nvidia-*` closure. With it the lock contains **zero** nvidia/cuda/triton packages. macOS stays on PyPI on purpose — that is the wheel carrying the Metal backend. No runner in the matrix has a GPU. Windows wheels are in the lock but nothing exercises them: **unmetered, not supported**.

## No default CI job pays

- Gated on `ZETA_INSTALL_INTERP=1`, deliberately **not** `ZETA_INSTALL_FULL` — which `macos-install-sh-test.yml`, `tlaps-proof.yml` and `wsl-install-sh-test.yml` already set, and which exist to test the *installer*, not to read activations.
- `tier=standard`, so the 8 GB low-memory lane skips it.
- A manifest row with **no `opt-in=` is refused**, not defaulted to install; a test asserts every row carries one.
- `interp-lane.yml` is path-filtered, in no `needs:` list, **not a gate** — the arc-lane posture for the arc-lane reason. ~6 min/run, ~4 runs/month ⇒ **~24 CI-minutes/month**.
- One runner, not a matrix: the only platform-conditional thing is index selection, and that is asserted from the committed lock without downloading anything.

No new third-party action: I initially reached for `astral-sh/setup-uv` and **removed it** — it is used nowhere else in this repo and I had no verified SHA for it. The two action SHAs here are copied verbatim from `arc-lane.yml`.

## What this does NOT claim

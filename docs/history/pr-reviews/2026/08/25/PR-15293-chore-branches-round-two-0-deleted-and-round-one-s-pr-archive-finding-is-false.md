## Why none were deleted

Ruleset **16934633** includes `refs/heads/heartbeat/*` with a `deletion` rule and an
**empty `bypass_actors`** list. The glob does not stop at `-flush-`, so it covers
snapshots as well as lanes, and repo admins do not bypass it.

Verified by *attempting* the deletion, not by reading the config — on a branch that
had already passed all four parts of round one's test (PR #14059 merged, tip ==
`headRefOid`, merge commit an ancestor of `main`, patch-id `148e7d1d…` identical):

```
HTTP 422 — Repository rule violations found: Cannot delete this branch
```

The narrow fix is `conditions.ref_name.exclude: ["refs/heads/*-flush-*"]`, which keeps
the lanes protected. Editing a protection ruleset is a gated class → maintainer.

## The correction: round one's `pr-archive` finding is false

Round one recorded that each `automation/pr-archive-*` branch carries a review file
**not on `main`**, and that deleting them "would destroy the PR review history they
exist to preserve". All 1,285 were re-checked by **blob hash**, not sampled:

| verdict | count |
|---|---:|
| `IDENTICAL` — byte-identical file already on `main` | **1,235** |
| `DIFFERENT-BLOB` — `main` holds the better capture | 44 |
| `ABSENT-ON-MAIN` — genuinely stranded | **6** |

The archive landed in `07e9530c4`, the revert of #13973, which restored **3,184**
review files in one commit. Two independent methods return the same six stranded
branches (all recent, i.e. still in flight).

The 1,235 are **listed, not deleted** (`branch-cleanup-2026-08-25-pr-archive-redundant.md`).
Reversing an explicit "do not touch" on an agent's own re-analysis is a human call.

## Also recorded: the bug that probably caused the original error

`git rev-parse origin/main:<path>` **echoes its argument on stdout** when the path is
missing (and exits non-zero), so testing the captured output for emptiness inverts the
verdict. It produced a false `ABSENT-ON-MAIN = 0` in *this* round before a second
method caught it; the fix is `--verify -q`. A `comm` over one numerically- and one
lexically-sorted list produced a bogus "381 missing" in the same session. Neither
number in this PR rests on a single method.

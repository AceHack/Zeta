## The measurement was wrong three ways

"36 tracked `.sh`" conflates three populations: **6** archived orphan-branch copies (other agents' preserved memory), **2** Markdown knowledge-graph stubs that merely carry a `.sh` suffix (`db/common/host-tier.sh` is 3 lines of prose), and the live surface. It also **misses 3 real shell scripts** that lack the extension (`githooks/pre-push`, `scripts/hooks/{pre-push,commit-msg}`). Re-measured: 35 tracked, 21 under `tools/setup/`, and the repo's own tool reports **30 live retained, zero drift**.

## The minimization function already exists and is better

`src/Core.TypeScript/hygiene/check-bash-retirement-inventory.ts`, enforced at `gate.yml:1095` with `--enforce`. It is not a count-minimizer — it is a **justified-allowlist ratchet**, paired with an exposure-ranked ordering (`measure-shell-key-exposure.ts` → `docs/SHELL-DEPRECATION-SEQUENCE.md`, tiers T0–T4). Its own comment states the correct operation: `ensure-rust-components.sh` was *removed* by declaring the components in `.mise.toml` — "the retirement discipline REMOVED a shell file instead of permanently allowlisting one." Minimization by **eliminating the need**, not by merging.

## Derived floor: 27 files

Rule: a file is independently required if merging it would cross an **availability**, **privilege**, or **failure** boundary, corrupt a **measurement of its own execution context**, or destroy an **export** the caller depends on.

Sharpest case: `hsm/dkek-ceremony-preflight.sh` measures its own session — `[ -t 1 ]`, `$HISTFILE`, `ulimit -c`, `"$@"`. Merge it anywhere that pipes output and `stdout_tty` flips to `no`, so a fail-closed gate refuses permanently; the predictable "fix" makes it fail-**open**. And `password_in_argv` would inspect the *merged* script's argv — reporting PASS about a process it never looked at.

## Ranked findings

- **P0** — `curl-fetch.sh`'s *"all upstream-installer call sites"* claim is **ornamental**: 2 call sites vs 3 bypasses, including a live pipe-to-shell of `https://sh.rustup.rs` (`install-rust-wasm32.sh:32`). `install.ps1` holds the *stronger* policy than the Unix path ("download-then-exec, NOT pipe-to-shell").
- **P0** — `install-zig.sh` installs an **unverified** tarball (no SHA256, no `curl_fetch`) into `/usr/local` under three executed `sudo`, one of them `sudo rm -rf`. (Stated honestly: no exploitable injection found.)
- **P1** — `secret-clip.sh:95` puts a credential on `security(1)`'s argv — self-declared in the allowlist; the sibling `op-token-setup.sh` was fixed by *conversion*, which is the model.
- **P1** — only `smoke-7-toolchains.sh` is wired to CI (`gate.yml:3245`); its two successors covering oracles 8–13 are dead, and `smoke-13` claims `gate.yml` runs it. Overlaps `081M05E39F7087G0R002F00H6Q`.
- **P2** — `grep -c sudo` misranks the tree: `fd-limits.sh` (11 hits) and `doctor.sh` (12 hits) execute **zero** privileged operations.

## Metric gaming

Concatenation (21 → **1**, strictly worse) · renaming off `.sh` (**already silently true in-tree**) · deleting the archive (destroys memory, §5) · inlining into `gate.yml`/`.mise.toml` — **rewarded by a count, punished by both existing metrics**. A ratcheting count also pressures the next legitimate stage-0 addition into appending to an existing script, which is concatenation one function at a time.

## Verdict

**"Fewest independent `.sh` files" is the wrong quantity.** It cannot distinguish `keyring.sh` (T4 root-key) from dead `smoke-10` (T0), and it approves of `zeta-install.sh` — **3,771 LOC, 41% of live retained shell, 195 `sudo`** — because it is one file.

Recommended objective: minimize **stage-0 shell LOC below the bun availability boundary, weighted by measured key-exposure tier**, under the constraint that no reduction merges across an availability, privilege, failure, or measurement-context boundary.

**Concession:** the surface does contain slack — 3 superseded/above-boundary scripts plus a duplicated awk parse between `macos.sh` and `host-tier.sh`. A minimization function is warranted. It is the *file count*, not the impulse, that this review rejects. The honest reduction is **−3 to −5 files, every one a deletion or conversion, zero merges.**

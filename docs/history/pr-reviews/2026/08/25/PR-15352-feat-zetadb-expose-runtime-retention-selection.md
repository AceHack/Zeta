## Summary

- add a typed registry for no-forget, canonical event-count, and canonical checkpoint-byte retention
- forward explicit retention policies through scheduled and browser node boundaries
- expose scheduled selection through `--retention-policy` while preserving no-forget as the default
- pin durable displacement heat and archive the completed binding-budget workitem

## Why

The convergent retention policies were implemented and tested but had no non-test runtime selection path. This change lets finite node hosts choose the policy explicitly without turning an untrusted string into executable behavior or changing the existing no-forget default.

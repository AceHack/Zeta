## Description

Follow-up to #15441 (merged). `lint (bash retirement inventory + hygiene unit tests)` was **red on that PR when it auto-merged** — the check is not part of `gate (required)`, so it blocked nothing. This turns it green, and the reason is worth more than the fix.

## The finding: the guard was itself the vacuity class

`audit-check-arity.ts` flagged a new **R2 self-comparison** in `FreeTimeAllocation.Tests.fs`. `FTA-5` asserted:

```fsharp
let a = FreeTimeAllocation.classify "otto" ALLOCATOR "dbsp" Free true "d" 7L
let b = FreeTimeAllocation.classify "otto" ALLOCATOR "dbsp" Free true "d" 7L
Assert.Equal(a, b)          // claims: "no hidden clock"
```

Both sides normalize to one expression — a property claimed at higher arity than tested.

**The tool's prescribed remedy for a *correct* self-comparison is to raise the per-file count in `registry/check-arity-census.json`.** That was the tempting move, and it had a respectable precedent: #15426 adjudicated exactly this shape (`DSL-37`, no-ambient-clock) and ratcheted its census 0 → 2.

**It would have been wrong, and that is measured rather than argued.** Mutation `M17` replaced `Phase_ = phase` with `Phase_ = DateTime.UtcNow.Ticks` — a real ambient-clock capture, precisely what `FTA-5` exists to catch:

> **All 31 tests passed, `FTA-5` included.**

Two identical calls capture the **same** clock, so the comparison succeeds **because** of the impurity, not despite it. The check could not fail for the thing it named. Raising the census would have licensed that permanently.

## The fix: lower the claim, not the allowance

`FTA-5` now asserts each field against the argument it must have come from, plus a control that a different `phase` really changes the value. `M17` now dies **deterministically**.

| | old `FTA-5` | new `FTA-5` |
|---|---|---|
| shape | self-comparison (`x = x`) | field-vs-argument |
| vs. `M17` (ambient clock) | **survives** | **killed** |
| census | would need 0 → 1 | **untouched** |

`registry/check-arity-census.json` is **not modified**. A self-comparison that should never have been counted is deleted rather than licensed.

## For #15426's author — not a request, an observation

`DSL-37` is the **same shape** as what I just deleted. I have not touched that file; it is your call. But `M17` is evidence the shape is weak *in general*: a mutation that corrupts both sides symmetrically is invisible to `f(x) = f(x)`. "M4 proves DSL-37 discriminates" may well hold for M4 and still miss a symmetric one. Worth a re-check.

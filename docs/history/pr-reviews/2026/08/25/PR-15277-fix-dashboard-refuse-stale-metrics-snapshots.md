## Description

# Summary

Regenerates Factory dashboard metrics inside the Pages deployment, defines an explicit snapshot freshness contract, and prevents stale committed telemetry from being rendered as current data. When the snapshot exceeds its declared freshness horizon, the dashboard keeps the historical data visibly labeled while attempting the live public GitHub API fallback.

# Spec alignment

This changes the operational presentation of the static Pages dashboard only. It does not claim realtime delivery or modify the underlying agent-society, BNN, or transport protocols.

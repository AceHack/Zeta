## Description

VISION.md line 31 already names the artificial bound — human review CAPACITY,
not human participation — and line 43 says the real bounds should be modeled
"instead of being approximated by 'a human looked at it.'" What it never
recorded is the replacement. Aaron gave it in full on 2026-08-25; this is that,
quoted and assembled.

Six rungs, each answering a question the ones below it cannot, and each blind
to something the others catch: formal analysis of specs (all inputs, but not
whether the spec is right) · constant adversarial review (what everyone missed,
but not what nobody attacked) · mutation and vacuity detection (can this check
FAIL) · multi-language byte-locked agreement (do N implementations agree byte
for byte) · Futamura IR generation (can each language be REGENERATED at parity
or better on time and allocations) · computational expressions (is the
composition law explicit and checkable).

Two things the section is careful about:

THE OUTPUT IS A VOCABULARY, not only a pipeline. A concept that survives all
six has been shown to mean the same thing in every frame it was expressed in —
which is what earns it a name in the shared base class library. The Beacon
register's anchoring requirement, made mechanical.

THE VACUITY RUNG IS LOAD-BEARING, not hygiene, and the section says why with
six measured instances from one session: a step that could never succeed read
as a broken flush by three agents; a probe validating a repo READ while its
step did a PR WRITE; a nine-day-stale doc read on every agent wake; a
fabricated id passing a shape-only gate; a guard that swallowed its error and
defaulted to permit; and an audit written to refuse vacuous checks that passed
its first CI run having examined ZERO subjects. None were missing checks. All
reported success without looking. The cost is not the missed defect — once a
green light might mean nothing, a person distrusts the whole surface and goes
back to reading logs. A vacuous check does not fail to remove the human, it
RE-INSERTS them.

Status is measured and dated rather than aspirational, including the gaps:
the byte-lock's HOST axis is single-runs-on while its compiler axis is six
wide, and the bootstrap seed — the one artifact whose compromise propagates
into every later stage — has no golden vector at all.

Anchors: Thompson 1984 (why a bootstrap binary cannot be audited by reading
source), Wheeler 2009 (diverse double-compiling, which layer 4 generalizes from
one-artifact-two-compilers to many-artifacts-N-implementations-recorded-as-text),
Futamura 1971.

## P0 findings

1. **"coded => homoiconic" is inverted.** `tests/Tests.FSharp/CssCode.Tests.fs:122` says the homoiconic adinkra family is the **non-coded** `C = 0` case, and `src/Core/CliffordPeriodicity.fs:179` says Construction A over `[8,4]` **costs** homoiconicity. The synthesis has the sign backwards.
2. **The split is indexed by `dim C`, not by ℍ/𝕆.** The CSS table enumerates `dim C ∈ {0..4}`, all five rows at `N = 8`, all at `Cl(0,8)` — associative. The test is fitted to an already-known split and makes no new checkable prediction.
3. **Associativity has the wrong profile.** Computed from the CD product directly: associativity reads `Y,Y,Y,N,N` (monotone cliff); code self-duality reads `n,n,n,Y,n` (single spike). The Fano→Hamming construction **continues** to sedenions as `PG(3,2) → [15,11]`, so non-associativity cannot be the discriminator. Gleason / mod-8 is.
4. **E₈ is a uniqueness sink.** Exactly one even unimodular rank-8 lattice (Mordell/Witt), so the four in-tree routes agree by a theorem about the *target*. Agreement carries zero evidential value. Names the unrun discriminating test: **rank 16**, where there are two.

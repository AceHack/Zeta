## Description

Found **independently by Soraya (formal) and Iris (render)** on the same day, and missed by the 25 contract tests already in this file — those asserted `silent === true` and never looked at the epsilon beside it. Two reviewers converging on one line from different directions is the strongest signal available.

## The defect

```ts
{ value: 0, epsilon: 0, silent: true }
```

Epsilon zero is a claim of **perfect certainty**, asserted at the point of **maximum absence of evidence** — an agent nothing has been heard from for seven days. Iris's render-side reading of the same line: *a full-track empty bar with no admitted uncertainty is the strongest statement the bar can make, and it is exactly backwards.*

## Two quantities were conflated

| | what it is | confidence in it |
|---|---|---|
| `silent` | a **corroborated fact** about absence — zero ticks, k ≥ 2 peers active | high is **correct**; it's a quorum observation |
| `epsilon` | uncertainty about the agent's **value** | seven days of silence is *no evidence at all* about capability |

The silent dweller is the most uncertain object in the system, not the least.

It also contradicted the stated design — *"you start at 100% trust with 0.1% certainty… everyone is graced trust."* Zero epsilon is 100% certainty, asserted about the one dweller we know least about.

## The fix

`epsilon = -1`: maximal magnitude because we don't know, negative sign because the absence points that way.

Two tests, **both confirmed failing before the fix** — non-zero, and strictly *more* uncertain than an observed dweller, so ignorance can never render as precision.

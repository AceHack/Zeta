## Description

Mirror→Beacon compression of a move the factory was already making, surfaced by the Beta-prior exchange.

## The instance

Lumen proposed closing a whitewash window with **Beta(2,2) instead of Beta(1,1)**. Verification found **no Beta prior anywhere in the source** — the shipped reputation path uses hard floors (`value: 0.1`, `Math.max(score, 0.1)`, signed `1/√n` epsilon). Aaron: *"yes im not aware of a beta either."*

The naive reading is that the proposal was wrong. The correct one is that **it was never a description of the code — it was a slot.** It says: there is a shape here, probably a conjugate prior over a Bernoulli-ish process, probably wanting more mass off the extremes. Every clause is contestable, which is exactly what makes it useful. A specialist can now answer *"wrong instrument — the property class wants coverage-at-τ"*, and that sentence is only available **because the template was concrete enough to be wrong**.

## The load-bearing half is Aaron's

*"a placeholder for an expert to have enough context to argue about"* and *"reusable templates based on domain"*. Each domain carries a small library of shapes that usually fit — conjugate priors for Bayesian updating, Cantelli/maximin for distributional bounds, Friedman–Resnick for reputation under cheap identity. Naming the domain is most of the work of picking the shape, and it makes **"wrong shelf"** a legal ruling.

## Three things that look alike and fail differently

| | states | failure if unexamined |
|---|---|---|
| unanchored coinage | a conclusion | becomes debt; hardens into assumed-true |
| toy model | a falsifiable mechanism | gets cited as metered |
| **template** | **a slot, with a shape** | **drifts into reading as implemented** |

`Beta(1,1) today` already reads like shipped behaviour and is not. Each needs its own guard; a template's is *label at point of use, not only at point of proposal*.

## Anchors — four independent lineages, so this is named rather than coined

- **Typed holes** (Agda/Idris/GHC) — the strongest: a hole carries its **type** plus scope. "Enough context to argue about", mechanised.
- **`sorry`/`admit`** (Lean/Isabelle/Coq) — the greppable, honest gap; already adopted in the toy/metered rule
- **Platt, strong inference (1964)** — hypotheses stated sharply enough to be *excluded*
- **Alexander (1977) + GoF (1994)** — domain-indexed reusable templates; Alexander is the better fit, being explicitly context-indexed and arguable
- **Raiffa & Schlaifer (1961)** — conjugate priors as the literal shelf

Ties to the interfaces-free/classes-earned rule: the template is a **free interface** (pure shape, weight-free, cheap to propose); the instantiation is the **earned class**.

**Decides nothing about the whitewash floor** — that ruling is Soraya's, and "wrong instrument" is a fully acceptable outcome. The template will have done its job either way.

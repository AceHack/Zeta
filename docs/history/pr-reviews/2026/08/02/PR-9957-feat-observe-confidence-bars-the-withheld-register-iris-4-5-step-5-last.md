## Description

The rule everything here serves: **uncertainty is rendered, never hidden.** The empty portion of a bar *is* the epsilon. A bar showing only `value` claims a precision the data doesn't have; a bar showing a confident zero is the strongest claim the widget can make — exactly backwards when the zero means *"we never looked"*.

## Two shipped bugs this pins against

1. **`Vaults.dc.html:394` fabricated the epsilon** — `100 - round(value*100)`, computing it *from* the value and discarding the real one. With real data (`0.90 ± 0.10`, `0.00 ± 0.50`) that's simply wrong. Pinned by asserting the same value with different epsilons yields different bands.
2. **The adapter emitted `{value: 0, epsilon: 0, silent: true}`** — which renders naively as an empty bar with *zero* admitted uncertainty: maximum confidence about the dweller we know least about.

## Design points

- **`value 0` with a wide band is not-observed, not an empty bar.** "We never looked" and "we looked and it's zero" are different claims.
- **The band clamps** at the track edges rather than wrapping: `.95` with a `.2` band is `[.75, 1]`.
- **Signed epsilon leans one way** (+ upside/recovering, − downside) and the plan carries **no colour at all**, enforced by test. Red is `heat` and nothing else — every agent currently carries ε ≈ −0.107, so colouring downside red would paint the whole settlement red. That would be a lie: the "decline" is an artifact of the cadence denominator, not a failure.
- **`silent` is distinct from not-observed** — corroborated absence vs no measurement. No bar, and a caption stating the *mechanism and witness count* (`silent · no ticks 7d · corroborated by 2 peers`) so the claim is auditable rather than a verdict. A test asserts no warning glyph, no past tense, no accusation: `silent` replaced `degenerate` because the word is factual, and the visual must carry the same neutrality.
- **The cadence readout shows its denominator and drops the noun.** Dividing by an expected 4 ticks/hour the scheduler doesn't deliver scores every agent ~0.12; under the word "reputation" that reads as *12% trustworthy*. They're ticking at the rate GitHub permits. `reputation`/`score`/`rank`/`trust` are forbidden there, enforced by test.

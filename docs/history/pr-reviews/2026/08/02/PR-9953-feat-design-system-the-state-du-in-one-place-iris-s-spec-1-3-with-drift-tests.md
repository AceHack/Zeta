## Description

Step 1 of Iris's render discipline. Contract change 3 removed `color` from the JSON so the design system owns visual mapping outright — this is where it lives, keyed by attribute, so every consuming element reads `var(--state)` and the mapping exists **exactly once**.

## Placement

Hand-authored as `zeta-state.css` **beside** the bundle, not edited into it — `_ds_bundle.css` is *generated* output. `styles.css` (the 2-line entry point, not generated) imports it, and a test asserts that import exists. If the design tool ever regenerates `styles.css`, **that import is the thing to restore**, and the suite will say so rather than the DU silently going dark.

## The disambiguation implementers get wrong

BASE labels red as *"attention / live"* — where that "live" is the broadcast on-air sense. **In this DU `live` is teal and red is reserved exclusively for `heat`.** Pinned by test, not left to a comment.

## Two structural distinctions from the spec

- **Motion is a claim of liveness.** The pulse is emitted only under `live` and explicitly cancelled on stale/cold/heat/withheld, so the 60s re-tick can remove it when the clock crosses the threshold. Without the cancellation, a tab open at 09:00 still breathes at 17:00 — and *"a stopped society can never render live"* is false in the browser, the only place anyone observes it.
- **Blur is frost only.** Unobserved and sealed **hatch**; frost **blurs**. Blurring an absence would tell a reader a dweller is exercising *earned privacy* when the truth is we have no measurement — over-claiming in the direction of attributing intent. Hatch says "nothing was written here."

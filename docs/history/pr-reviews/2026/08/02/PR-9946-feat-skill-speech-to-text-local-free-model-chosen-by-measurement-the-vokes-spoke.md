## Description

You said Whisper was just a baseline and HF is where you check — so I checked instead of defaulting.

## Benchmarked both on your actual audio (39-min talk, Apple Silicon, both local + free)

| | whisper-large-v3-turbo | **parakeet-tdt-0.6b-v2** |
|---|---|---|
| wall clock | **61 s** | 114 s |
| chars / segments | 34,710 / 1,583 | 35,055 / 312 |
| **"Prolog" correct** | **0 / 9** | **8 / 9** |

**Whisper was faster; parakeet was more correct.** Whisper wrote "Prologue" *every single time* the speaker said **Prolog** — in a talk whose central section is a Prolog technique. For technical content, proper-noun accuracy beats WER and beats speed.

Two things worth recording:

- The Open ASR Leaderboard reports parakeet as the **faster** model. On this machine and this file **the speed ranking inverted.** Leaderboard RTFx is batched throughput on other hardware, so the skill says benchmark your own audio.
- **A measurement bug I made and corrected:** grepping `prolog` also matches `prologue`, which scored the wrong transcript as *correct* and briefly inverted the result. The skill names that trap — it's the could-not-fail shape applied to transcription.

## Description

## Summary

- publish active `mise bin-paths` entries into the Windows installer process PATH
- append those entries to `GITHUB_PATH` so later GitHub Actions steps can invoke pinned runtimes directly
- make the Windows smoke and Server Core harness require direct `bun`, closing the exact post-install regression

## Evidence

Post-merge gate run 30759163840 installed the Windows toolchain, then jobs 91527282297 and 91527282311 failed in the next step because `bun` was not on PATH. The installer had only used `mise exec -- bun` internally and never exported the runtime directories.

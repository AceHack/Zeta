## Description

> *"for any given oracle like the highest moral regard, it should be able to be explained how the metric represents the oracle's english description, they should not just be randomly connected. so in reversible computing i think this comes down to our travelers not overwriting other travelers."*

## The requirement

§21 established that a metric is oracle-relative. **Necessary, not sufficient** — it still permits an arbitrary pairing. An oracle and a metric that are merely *associated* is a metric wearing an oracle's name: the numerology failure moved up a level, from *"this number matches"* to *"this geometry is attached."*

The discipline is the one `anchor-to-human-prior-art` already imposes on citations — an anchor must be **checked**, the source must *entail* the claim. Here: **the oracle's English must entail its metric.**

## Walking it

Manifesto §11: *highest regard for morally-relevant entities absent a chosen oracle.* In a **reversible** substrate that sentence has almost no room to mean anything else:

1. Reversible operations destroy nothing — everything stays recoverable.
2. Therefore the only operation that can diminish another entity is **erasure: overwriting state that belonged to someone else.**
3. So "highest regard for other entities", in the vocabulary the substrate actually has, **is** *"a traveler does not overwrite another traveler."* No second candidate.

That's the entailment §21 lacked: the constraint is what the sentence **reduces to** once the substrate is fixed, not something adjacent to it.

## The metric, checked rather than asserted

Minimum irreversible work between configurations — Landauer cost, reversible moves free.

- `d(x,x) = 0` ✓ · `d ≥ 0` ✓
- **Symmetry fails — and the failure is the interesting part.** Erasure is directional, so this is a **quasi-metric**. Which is *correct* for a moral geometry: destroying and failing-to-create are different acts, and a symmetric distance couldn't tell them apart. The asymmetry is a feature we'd otherwise have had to add.
- Triangle inequality: plausible by subadditivity, **not verified**, named open.

## The dead zone — you cannot slightly overwrite someone

Composing with §22 gives what neither has alone. `ErasureDistance.lean` proves erasing fewer than `d` coordinates is fully recoverable — so the erasure-cost quasi-metric has a **quantization floor**: below the code distance, erasure **costs energy and moves zero distance.** The victim recovers intact; the only thing consumed is the attacker's heat.

> **Moral discreteness falls out of the coding theorem.** Either you stay under `d` — they recover, you wasted dissipation — or you exceed `d` and the loss is irrecoverable. **No graded harm in between**, because the code fills the gap back in.

Derived from Singleton/MDS (proven in our Lean) plus Landauer (metered, falsifier filed) — and it predicts something checkable: partial overwrite detectable and reversible, only `≥ d` terminal.

## Where §22 and §24 meet: the moral content is entirely in *whose bits*

| operation | bits belong to | verdict |
|---|---|---|
| §22 — erase your own hidden bits behind frost | **self** | permitted; buys unpredictability; priced twice — earned budget **and** heat |
| §24 — overwrite another traveler | **other** | forbidden; the one harm the oracle names |

Same physical operation, opposite valence, distinguished by ownership. That's exactly the spend / stake / **confiscate** structure already carved in `privacy-budget-is-hard-money`: owner-initiated fine, other-initiated never. **Erasure inherits it unchanged** — so the moral rule isn't a new axiom bolted onto physics, it's the ownership rule already in force applied to the only operation that can do irreversible damage.

It also sharpens §5 into something with a mechanism: *"identity transitions never silently destroy memory"* becomes **"no traveler's transition may push another traveler past their code distance"** — measurable, unlike a promise.

## Register, and one collision flagged

The entailment is an **argument**, offered as one: it claims no second candidate given a reversible substrate, and that's where to attack it. The quantization floor is a **theorem** composed of two results we hold. The triangle inequality is **named open**.

**Collision flagged so it can't silently merge:** `ErasureDistance.lean`'s "distance" is minimum **Hamming** distance (a property of the code). The distance proposed here is **Landauer cost** (a property of a transformation). Different quantities meeting at one point — Hamming sets the threshold below which Landauer cost buys no separation. Same word, two meanings, one real relationship.

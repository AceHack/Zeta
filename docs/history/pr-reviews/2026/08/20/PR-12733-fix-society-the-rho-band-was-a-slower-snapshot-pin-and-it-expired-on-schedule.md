## Description

**`test (TS hermetic)` is about to go red on main.** Main's last `gate` ran 03:22Z and passed; the corpus has grown since and ρ crossed the upper bound. The data on main already fails the assertion — nothing has re-run to reveal it yet.

## What happened

In #12607 I removed the exact pins (`nEff ≈ 1.666`, `deff ≈ 1.8`) because they were a snapshot of an append-only corpus that grows every heartbeat tick. I **deliberately kept** the `(0.35, 0.45)` band, with the stated reason that it is *"a claim about the fleet, and it should go red if the fleet's correlation genuinely moves."*

It moved. **The band fired exactly as designed.**

But the right response to a claim being falsified by data is to *update the claim* — not to widen the window until it can no longer be false. Re-centring a static band over a drifting quantity just restarts the timer; it's the same expiry the exact pins had, only slower.

## The fix

The band is replaced by what an *estimator sanity check* can honestly assert: ρ is a correlation in the open unit interval, neither degenerate-independent nor degenerate-identical. A broken ICC (negative, ~0, ~1) still dies. It no longer encodes a belief about where the fleet sits, because that belief is dated the moment it's written.

Falsifying power unchanged — re-ran the arithmetic mutants *after* loosening:

| mutant | result |
|---|---|
| `deff = 1 + n*rho` (drop the −1) | 25 pass / **5 fail** |
| `deff = 1 + (n-1)` (drop rho) | 23 pass / **7 fail** |
| `return n` (stub) | 23 pass / **7 fail** |
| ICC denom `msb + msw` (drop k−1) | 28 pass / **2 fail** |
| ICC denom `msb - (k-1)msw` (sign flip) | 25 pass / **5 fail** |

## The finding is the rise, not the test

**Three agents are now worth 1.555 independent ones, down from 1.666, and falling.**

That runs *against* the decorrelation arc the fleet is supposed to be on — the S=4 common seed correlates the past, and the whole design intent is to decorrelate away from it over time. The measurement currently says the opposite is happening.

Recorded here as a trend rather than gated, because gating on it is precisely what has now failed twice.

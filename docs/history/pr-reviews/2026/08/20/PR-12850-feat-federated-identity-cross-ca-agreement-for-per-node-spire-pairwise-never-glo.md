## What actually runs

```bash
bun src/Core.TypeScript/federated-identity/federation-loop.ts --phases 240
```

Three nodes, three roots, **three different local policies**, one process, in-memory channel — **no listener, not even on localhost.** It ends asymmetric on purpose:

```
A accepts: node-b, node-c
B accepts: node-a
C accepts: (none)   <- asymmetric, and correct
```

**That asymmetry is the discriminating test.** A design that quietly assumes symmetry passes everything else and fails exactly this. Asymmetric trust is a legal steady state with **no repair path**.

## The federation decision and its cost

Nested SPIRE and a bridge CA were **both rejected** — each creates a node you *must* route through, and **exit is the discriminator**. Chose SPIFFE federation: own root, bundles exchanged pairwise, `accepts(A,B)` a **directed relation computed nowhere**.

Cost stated rather than hidden: `O(n²)` exchange, a real compromise window before revocation propagates, first contact needs non-certificate evidence, and **no node can be told it is wrong.**

## The ceremony line — review this hardest

**Unattended:** leaf issuance, renewal, peer verification, revocation merge, seed-based acceptance, x402 within a standing budget.
**Gated:** root generation, root rotation, first contact, authenticated HSM session, x402 above budget.

The loop **prints both lists and performs none of the gated ones.**

## Honest limits — the agent's own words, unsoftened

- Software attestation on a shared kernel is **operational identity, not cryptographic isolation** — host root forges every selector. (You've already accepted this explicitly.)
- `ceremonyRequirementFor` is a **classifier, not an enforcer.** The only structurally enforced gate is the HSM adapter — **and it's enforced by the credential being absent**, not by the classifier.
- `seed-bootstrap` is cryptographically a **group pre-shared-key challenge-response**: it proves *membership in the generator*, never who anyone is.
- The revocation premise (population × rotation outpaces compromise) is **your assumption, unmeasured.**

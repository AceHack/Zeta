## Description

Second half of the surface-declaration work. **Part B** ships two mechanical guards against
the exact defect #12876 introduced; **Part A** is the format design they are the first two
falsifiers of.

## Guard 1 — `.cursor` joins `BOOTSTRAP_SURFACES`

`lint-clone-at-tag-is-sufficient` scanned six surfaces and `.cursor` was not one, so a
resolver line in a Cursor bootstrap script **could never fire the lint**. The roster
pre-dates the directory.

Verified rather than assumed that adding a not-yet-landed path is free **in both
directions**: `walk` returns `[]` for a missing path, so an absent surface contributes zero
files — *and* `main` separately requires ≥1 surface to exist before reporting OK, so **the
lint cannot pass by scanning nothing**.

Seven new tests, all paired. The fires-vs-silent pair injects only file **content** through
`scanSurfaces([".cursor"], read)`, so it proves the surface is genuinely *walked* rather than
merely listed. **29 pass / 34 expects** (was 22 / 24). Mutation proof: deleting `".cursor"`
→ 28 pass / 1 fail.

## Guard 2 — the mise pin cannot drift into `.cursor/install.sh`

**No new checker.** `mise-pin-parity.ts` already holds four sites to one value and holds no
expected version itself; a fifth site is strictly smaller than a second checker — and a
second checker would have been the hand-maintained list that file's own header warns about.

The interesting part is the **degrade**. `pinValueViolations` now splits absent-file from
present-but-unparseable, which it previously conflated:

| | outcome |
|---|---|
| absent + pending | not a violation — but **reported** by `pendingAbsentSites()` |
| absent + required | **hard failure** (new, stricter than before) |
| present, no match | violation |
| present, disagrees | violation |

> **Pending buys *"not yet"*, never *"not checked"*.**

Plus one live-repo test written to stay true **across the merge of #12876** — either arm
asserts something, so it is a standing invariant rather than a snapshot that goes red on
landing. **29 pass / 55 expects** (was 17 / ~40). Mutation proof, 2 mutants both killed.

**Combined: `mise-pin-parity` + `lint-clone-at-tag` + `manifest-symmetry` = 70 pass, 0 fail,
166 expects.** Verified on this tree before landing.

## Part A — the format, registered **UNMETERED and closer to `toy`**

Nothing reads a surface declaration; no install set has been computed; no saving measured.

**Its anchor is Aaron's own sentence, already in the repo.** `tools/setup/common/host-tier.sh`
quotes him 2026-06-12: *"packages can declare their requirements and os declare their
capabilities and that's how we know not to install on small/slow runners."* **The tier system
is that idea collapsed onto a chain. This is the same idea on a lattice** — which is why
tiers survive as a *derived view* rather than a casualty: rewrite `tier=X` as
`provides=tier.X` and the nesting stops being an **axiom** and becomes an **assertion that
can go red**.

One more qualifier token on a grammar with four implementations already in parity. An
untagged row defaults to `provides=base`, so forgetting to annotate makes a row reach *every*
surface (wasteful, safe) rather than *no* surface (the #12876 failure) — `Wall.Whitebox`
stance: unknown is not permissive. **The mistake becomes visible as cost instead of invisible
as absence.**

### Found while checking it is implementable — worth reporting on its own

`manifests/apt` cannot carry qualifier tokens today: `linux.sh` passes the whole remaining
line to `apt-get`, and the manifest says so at line 179. But `parseManifest` in
`manifest-symmetry.test.ts` already takes **`l.split(/\s+/)[0]`** — first token only. **The
test already believes apt rows may carry qualifiers; the installer does not.** One-line `awk`
change, and it must land before any `provides=` touches an apt row.

Eight falsifiers, two of which decide the register: **F2** (a surface naming a package → red;
*and if it can never fire because surfaces are trivially small, the format has not been
exercised*) and **F5** (declare one surface, install exactly its closure, measure against the
union — **if that saves nothing measurable the design is unmetered ceremony and must be
labelled so**).

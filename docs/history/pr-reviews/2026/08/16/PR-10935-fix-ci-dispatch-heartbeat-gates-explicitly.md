## Description

## What changed

- keep the proven default `GITHUB_TOKEN` as the heartbeat branch writer
- dispatch `gate.yml` explicitly at each exact `heartbeat/<agent>` head with the existing Actions-scoped credential
- arm the automation-only PR only after gate dispatch succeeds
- retry transient 429/502/503/504 and connection-reset reads while keeping a real missing-gate result fatal
- treat exhausted host reads as an explicit unmeasured warning rather than repository evidence
- correct the newly landed Reticulum workitem's dangling source reference

## Why

Production disproved both earlier assumptions: the PR-scoped PAT cannot push repository contents, and closing/reopening a reused PR did not start `gate (required)`. A direct `workflow_dispatch` of `gate.yml` at the exact head did start the complete required matrix and finished successfully. This keeps branch-write, Actions-dispatch, PR API, and merge authority separate without widening the PAT.

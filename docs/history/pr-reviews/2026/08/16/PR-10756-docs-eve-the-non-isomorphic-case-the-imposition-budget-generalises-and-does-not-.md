## Description

## The gap this closes

PR #10733 closed the isomorphic case and named what it did not touch: *"The non-isomorphic case — partial semiotic morphisms, Goguen's preservation ordering — is untouched and is the largest remaining gap."* This is that case, and Aaron's framing is about exactly it — *"two imposed vocabs that try to **meet in the middle** on algebraic structure."* Meeting in the middle is what you do when you are **not** already the same shape.

**The result is mostly negative, and the negative is the finding.**

## The instance is shipped, not hypothetical

`DynamicValue.toCanonicalJson` is a **literal partial semiotic morphism** with typed refusals — the source calls itself *"a partial projection (6/8 shapes; Float/Bytes deferred)"*:

```fsharp
type EncodeError =
    | FloatDeferred   // no canonical shortest-float form in plain JSON
    | BytesDeferred   // no native JSON byte type
```

and `src/Core.Rust.Observe/src/json.rs` is the coarser party — 6 tags against 8, no isomorphism. Three shipped codecs give three ways to be non-isomorphic: **CBOR/Arrow total · JSON tag-level partial · XML value-level partial.**

## What replaces `|Aut|`

`Aut` of the **meeting structure** `M = A/ker φ ≅ im φ`. The torsor theorem applies verbatim — **bijectivity was never its load-bearing hypothesis** — so the budget generalises with no new mathematics, and breaks as a criterion in the same move.

## The measurement (shipped rung table, uncontested ladder)

| meeting structure | budget | live rungs |
|---|---|---|
| full 8-tag lattice (baseline) | 1.0000 | 4/4 |
| `toCanonicalJson` domain **(shipped)** | **0.0000** | 3/4 |
| collapse route (not shipped) | **0.0000** | 3/4 |
| degenerate — all tags to one | **0.0000** | **0/4** |
| drop Array+Object, merge Null+Float | **6.9069** | **0/4** |

**Same budget / different loss** (rows 2–4) **and same loss / a 7-bit budget gap** (rows 4–5): independence exhibited in **both directions** on one lattice, not argued. **37.0%** of all 21145 meeting structures score a perfect 0.0000 bits, and the degenerate morphism attains it **at level 0, before any invariant is checked** — *silence is the cheapest vocabulary.*

The shipped JSON restriction also **dissolves** #10733's contested rung 5 rather than resolving it: the residual bit *was* the `Int`/`Bytes` transposition, and `Bytes` is gone.

## Two expectations refuted by computing instead of reasoning

1. **Coarsening is not monotone.** **26.1% of coarsenings cost MORE** (max 6.9069 bits), because rungs are shared infrastructure — merging `Null` with `Float` destroys the rung that pinned `Bool`. **Loss is non-local**, so what a party can no longer say is never just the tags it gave up.
2. **The elegant `K(φ)` (absorbed automorphisms) does not measure loss** — trivial on the real instance while the loss is large, because **rigidity and expressivity are independent**.

Both would have shipped as plausible false claims with good arguments attached.

## The payoff the budget could not give: refuse, do not collapse

The JSON and collapse routes score **identically** and are not equivalent — a typed refusal is a **declared, metered channel** (manifesto §13); base64-in-a-string is an **ambient leak** the receiver cannot detect. The shipped code already chose correctly; this names why.

## Fairness — symmetric loss is the wrong target

The richer party **always** pays and the loss is **always** one-sided: generic, not coercive. The shipped pair is maximally asymmetric **and uncoerced** — the later, richer party chose the meeting and pays for it. The condition is the repo's existing **cede / defer / strip** shape (who initiates) plus **exit, not symmetry** (Hirschman, already load-bearing for hubs). Checkable red flag, narrower than the brief's: **the party that CHOSE the meeting structure is the party that loses nothing.**

## Named blind spot

Value-level partiality is **invisible** to any tag-lattice budget. `toCanonicalXml` is a tag-level *isomorphism* and a value-level *partial* morphism at once — zero rung deaths, unchanged budget, and a whole class of values that cannot cross.

## Anchor checked, not inherited

Goguen's primary pages, quoted: morphisms are partial; morphisms can be **incomparable**; and the load-bearing sentence — *"these **quality measures are partial orderings, rather than linear numerical scales**"*. That **directly entails** no single number, `log₂|Aut|` included, can be the selection criterion. Anchor and computation agree from opposite directions.

## Register — the toy is NOT promoted, and is demoted in scope

`log₂|Aut|`-as-coercion stays **toy**, and this work *lowers* what the number is claimed to do. The new tempting promotion is named and refused: **Goguen agreeing with the computation is corroboration, not a falsifier** — neither could have refuted the other. What would meter it is still what #10733 said: two parties who have never shared a seed.

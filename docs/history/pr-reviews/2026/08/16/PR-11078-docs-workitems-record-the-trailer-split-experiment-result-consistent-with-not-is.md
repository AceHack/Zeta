## Description

# Summary

Closes the loop on 081M062MG4M087G0R0039ZXG2C with the experiment's result.

#11071 shipped its AgencySignature block **without** the trailing `Co-authored-by:` line, as the
stated test. Its squash commit `55d9e21dc988e280a8fab912bd2ec4ab86e1eab9`:

```
git log -1 --format='%(trailers:key=Agency-Signature-Version,valueonly)' 55d9e21dc  -> "1"
git log -1 --format=%B 55d9e21dc | grep -c '^---------$'                            -> 0
```

No separator, git reads the trailer. Combined with the house baseline, the discriminating row is
that commits carrying a `Co-authored-by` naming a **resolvable** GitHub account are unaffected — so
"any co-author line" is excluded and the narrower reading survives: an **unresolvable** co-author
address (`shadow@zeta.agents`) is what GitHub re-emits in its own aggregated section, splitting the
trailer group.

Recorded as **consistent with**, not **is**. One instance of the failure, and the two-commit vs
one-commit confounder between #11039 and #11071 is untouched — a two-commit PR with no
`Co-authored-by` would separate them. The item says so explicitly rather than rounding a matched
pair up to a cause.

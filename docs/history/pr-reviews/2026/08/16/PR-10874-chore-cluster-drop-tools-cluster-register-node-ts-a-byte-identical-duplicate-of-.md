## Description

## Verdict

`tools/cluster/register-node.ts` is **byte-identical to `src/Core.TypeScript/cluster/deregister-node.ts`** and has **zero referents**. Deleting it loses nothing.

The framing this started from ("two copies of `register-node.ts` have diverged") turns out to be wrong in a load-bearing way, so stating it plainly: these are **not two copies of one program**. Despite its filename, the `tools/` file is the **deregister** program —

- its own header line reads `// tools/cluster/deregister-node.ts`
- it runs `git rm -r` on the node subtree (removes, does not create)
- it branches `deregister/<host>-<ts>` and opens a `deregister(cluster-node):` PR

The real register tool is `src/Core.TypeScript/cluster/register-node.ts` (writes `node.yaml`, `git add`, `register(cluster-node):`).

## Provenance — how the decoy got there

Commit `fe38a2a8e` added `patch-register-node.js`, a one-shot codemod that read `src/Core.TypeScript/cluster/register-node.ts` and rewrote `deregister`→`register` **in place**. So the workflow was: copy `deregister-node.ts` → the register filename, then transform. `tools/cluster/register-node.ts` is the **pre-transform intermediate**, committed and then left behind. The codemod itself was already removed as spent in #10337.

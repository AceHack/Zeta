## How it was found

## Why an allowlist entry is the in-policy fix, not an exemption

`ensure-rust-components.sh` provisions rustup components, probing `rustfmt` / `cargo clippy` first so a warm cache stays offline. It is the same low-level toolchain-installer surface as the already-retained `install-rust-wasm32.sh`, and it **runs before bun exists**, so it cannot be TypeScript. `setup/bootstrap` is the category that exists for exactly this.

**No check is weakened or skipped.** The guard still enforces the full inventory, sort order, category coverage and staleness; the count moves 31 → 32 because a real file exists.

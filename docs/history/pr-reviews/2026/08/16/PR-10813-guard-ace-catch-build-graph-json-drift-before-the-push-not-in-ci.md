## Description

## The repeating cost

Three PRs failed `cross-verify (trust-core oracles + ace suite)` on 2026-08-14 for the identical
reason, and each was fixed by the identical one-line command:

| PR | what it added | why the graph moved |
|---|---|---|
| #10769 | `Collation.CrossOracleTreaty.Tests.fs` + a `.fsproj` row | matches `**/*Treaty.Tests.*`, and the manifest edit propagated |
| #10799 | four `_gen/gen.py`, four `python-output.json` | all under `tests/cross-verification/**` |
| #10808 | `gen-layout-drift.ts` + README | same glob |

`build-graph.json` is **derived**, and the CI gate asserts that re-deriving it reproduces the
checked-in file. Adding a file that matches an evidence glob silently invalidates it. Nothing
warned the author before the push.

**Checked first, per the brief's third option:** this is *not* already guarded. No hook, script or
workflow ran the derivation outside the `bun test src/Core.TypeScript/ace/` step in `cross-verify`
(`rg -l build-graph` over `.github/`, `scripts/`, `githooks/` returns nothing).

***

## What this adds

`bun src/Core.TypeScript/ace/build-graph.ts drift-check` — two halves, load-bearing in opposite
directions:

- **A cheap predicate.** `DERIVATION_INPUT_GLOBS` is built by *spreading* `EVIDENCE_RULES` (not
  transcribing them) plus the four manifest classes the deriver actually reads —
  `.fsproj`/`.csproj`, `Cargo.toml`, `lakefile.toml`, `*-output.json`, the graph, the deriver.
  No matching path in the change means the artifact provably cannot have moved, so nothing is
  derived. **~0.03s.**
- **The exact check otherwise.** Not an approximation of drift — the same `deriveGraph` the CI
  gate asserts, so a pass here means the gate passes. **~1.5s.**

It scopes itself (`origin/main..HEAD` plus the index, via a new `git/changed-files.ts`), so it
needs no plumbing from its caller. It is wired into `preflight` — hence into `githooks/pre-push`,
which runs `preflight:quick` — and into `AGENTS.md` beside the preflight instructions, which is
where an author looking for "what do I run before opening a PR" already is.

The CI drift-gate test now prints the fix command *before* its assertion fails, so the log no
longer carries only a whole-file JSON diff.

## Corrections to the brief

1. **`derive` does not take minutes — it takes 1.27s on this machine.** The multi-minute cost is
   the whole `cross-verify` job, not the derivation. That inverts requirement 4: the exact check
   *is* affordable, so no approximate warning is needed. The predicate stays anyway, because
   requirement 1 is about not running when it cannot matter, and ~0.03s vs ~1.5s is the difference
   between a check that survives in `preflight` and one people notice.
2. **No floor row was added, deliberately.** The brief expected `registry/uncompensatable-floor.yaml`
   to be most of the work. Every row there is `rationale: erasure-class`, the file's own header says
   *"everything NOT in this registry converges via drift detection"* and *"additions require the
   treaty-amendment consent path"*. Derived-artifact drift is the paradigm **converging** class — it
   heals with one idempotent command — so putting it on the floor would be a category error and
   would need authorization I do not hold. Available as a one-line addition if you want it.
3. **The pre-push floor hook is not installed in the clones this fleet actually pushes from.**
   Checked three sibling `/tmp` clones: zero non-sample hooks each; the shared checkout likewise.
   So a hook-only answer would have been a guard that never fires for the exact population that hit
   this three times. That is why the mechanism lives in `preflight` (which agents are told to run)
   and in `AGENTS.md`, with the hook path as a bonus rather than the plan.
4. **The gate does not invoke the deriver from `gate.yml`.** It runs as a `bun test` assertion
   inside the ace suite. The fix command the brief credits was in a *code comment*, not in any
   failure message — so preserving that quality meant adding it to the message, which this does.

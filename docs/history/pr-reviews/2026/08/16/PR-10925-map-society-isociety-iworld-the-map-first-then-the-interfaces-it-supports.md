## Description

## Map first, declare second

`ISociety` and `IWorld` are named across ~8 docs and have **no `interface`/`type` definition anywhere in `src/`** — verified, 0 hits. Aaron's reason for the gap is on the record (*"we've not had a use for it yet"*), and the uses that arrived (a GH-Actions society of small LLMs in runner RAM, CHIP-8/Atari play, LLMTV, other LLMs attaching) are what make the shape pinnable.

The map is the deliverable. The declarations are what the map turned out to support.

## Headline findings

**Three of the six confirmed transport leads are not transports.** `src/Bayesian/ReticulumTransport.fs` is a telemetry→latency map for `AttentionRouter` that moves no bytes (`:38-51`). `ReticulumBusMeter.fs` is single-node telemetry with a stated epistemic limit (`:12`). `udp-lossy-transport.ts` imports `error-envelope`, `error-bnn-bridge`, `crc32c` and **nothing else** (`:170-172`) — no `node:dgram`, no socket: it is a pure `[8,4,4]` codec + AIMD state machine, protocol algebra rather than a wire.

**The real transport find was not on the list.** `discovery/gossip-mesh-transport.ts` already implements exactly the pattern `ISociety` needs — one two-method port (`SalonTransport`, `gossip-salon.ts:202-205`) with **six adapters**: UDP multicast (`:115`), Reticulum (`:171`), WebSocket (`:197`), BroadcastChannel (`:225`), git commits (`:268`), lossy-UDP (`:330`) — plus `multiplexTransport` (`:434`) and a `societyEvolutionTransport` (`:397`). Aaron's *"several transports that can back it already"* is understated.

**So `ISociety` must not have a transport.** `deliver` **returns** the messages to send and never sends them, so there is no door for a transport to enter through — transport-agnostic by construction, not by convention. This generalises `SybilBftProtocol.receive` (`:111-121`), which is also where the massively-parallel constraint is already stated as a design rule: pure data ⇒ CPU algebra in production *and* GPU for DST, *"keep this module free of anything a shader can't run"* (`:32-36`).

**`SocietyBootstrap.fs` is the closest thing to a working society** — and its header records the defect worth not re-learning: six agents fed one stream folded to `precision = 66.0` on a mean wrong by 5.66, *and nothing in the fold could notice* (`:16-21`). The fix was a precondition (attested evidence, deduplicated on provenance before the graph is built), and `Attested.admit` folds members-into-society and societies-into-world with **one operation** (`:30-36`) — the Composite property already implemented at the evidence layer.

## Declared

Interfaces only, **zero instance state, no classes** (precedent: `SoftScheduler.fs:22`).

- **`src/Core/Society.fs`** (the reference) — `Address` (a routing address, never a provenance id), `Addressed`, `Reading` (neutral facts; **no `BadActor` case, ever**), `IMember`, `ISociety :> IMember`, and **`SocietyLaws`**: `mergeIdempotent` / `mergeCommutative` / `mergeAssociative` / `deliveryCommutes` / `routesAreMembers` / `hasExit k` / `outboundStaysInSociety` / `membershipIsCanonicallyOrdered`. That module is why the F# is not a port of the TS — it is the surface a property test or a Lean proof gets pointed at.
- **`src/Core.TypeScript/society/society.ts`** + `society.test.ts` — the same shape for the TS oracle, with address ordering routed through the collation treaty.

`routes` returns hops **drawn from `members`**, so there is no broker slot in the type; `hasExit k` makes the exit discriminator checkable (`k ≥ 2` = routable-around).

## Honest scope

`ISociety <: CTM` **cannot be typed against a CTM that does not exist** — `rg "CTM" src/` is also 0 hits, and the Blum–Blum–Blum contract (LTM/STM competition, global broadcast, sleeping experts) is nowhere implemented. Declared instead: the weaker `ISociety :> IMember`, with the caveat written at **both** declaration sites. The two §B open rows in the 2026-07-04 research doc (`:227-228`) stay open, and this must not be cited as discharging them.

## Ordering — one verified divergence, one latent

The salon `pairKey` orders by **UTF-16 code unit** in both F# (`GossipTelemetry.fs:36`, `CompareOrdinal`) and TS (`gossip-salon.ts:48`, bare `<`) — agreeing with each other and disagreeing with the repo's own collation treaty (code point, `Collation.fs:80-83`) on non-BMP ids, where a Rust oracle would side with the treaty.

And latent: `agent-bus/subscribe.ts:71` + `bus/bus.ts:95` sort with `localeCompare`. Measured rather than asserted — **0 mismatches in 324 pairs** over today's ISO+lowercase-hex keys, **20 in 64** over a widened member-id alphabet. It activates exactly when a society admits arbitrary addresses. Named, not fixed; each deserves its own diff.

## Open questions worth Aaron's time

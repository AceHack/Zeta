## Assessed against the brief's five change-points

* **`B-NNNN` retirement** — already handled correctly in May; not a live constraint. The archived copies' cross-refs are dead ids; the live rows' are correct.
* **`auto-vivify.ts`** — is the right primitive with the right anchor (M/MUMPS auto-vivification) and is roughly half the mechanism. What it lacks is not the citation case but a **register**: mention / pointer / citation / **promise**. Citation and promise are the same check with opposite polarity — a citation that starts resolving is a defect, a promise that never resolves is a defect — and neither is inferable from prose. Mark it; do not detect it.
* **`dora-metrics.ts`** — the *substrate* extends (append-only G-Set, Bag fold, date-partitioned JSON); the *fold* does not. Everything keys on `workItemId` and `isWorkItemEvent` rejects other vocabularies at read time. Also: the existing "observability" row is the file as a **window onto** OTel/Prometheus, which is not the same thing as telemetry **about** the file. Three of DORA's four keys map honestly to a file; time-to-restore does not, and is filed as an open question rather than as a number.
* **Hexagonal** — Aaron is right, and better than aspirational: `src/Core.TypeScript/file-type-plugin/codecs.ts` already has a `markdown-frontmatter` codec and `src/Core.TypeScript/ace/cell-injection.ts` is a 60-line extension-keyed plug point. But the port that exists is for **parsing** markdown, not executing it. Also relevant and unmentioned: `src/Core.TypeScript/workflow-engine/grammar.ts` already implements a universal action grammar — the playbooks vocabulary should target it rather than become a second answer to "what is an action."
* **`runme`** — checked against the GitHub API, not the marketing page: `runmedev/runme`, not archived, pushed 2026-08-14, **v3.17.4 released 2026-08-13**, Apache-2.0. Still the right first adapter. "Our own" is not cheaper as a *replacement*, but is close to necessary as a *second adapter*, because DST replay needs a DoP=1 path an external terminal binary cannot give.

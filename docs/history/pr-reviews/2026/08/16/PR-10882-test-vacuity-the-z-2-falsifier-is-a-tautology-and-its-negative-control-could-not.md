## Finding 1 — the Z-2 scaling-level falsifier is a tautology

`src/Core.TypeScript/oracle/z2-halsey-redischarge.ts`:

```
computeMultifractalSpectrum:  τ(q) = log(Σ μᵢ^q) / −log(N_pos)
computeThirdMomentBeta:       β    = −log(Σ μᵢ³)  /  log(n_pos)
```

At `q = 3` these are **the same expression over the same inputs**. So

```
gap           = |β − τ(3)|      ≡ 0
falsifierFires = (0 > 0.1)      ≡ false
```

for every possible harmonic measure. `runZ2Discharge` can only ever return `SUPPORTED` or `INCONCLUSIVE`; **`FALSIFIED` is unreachable.**

Measured, not inferred — β equals τ(3) bit-for-bit across four structurally opposite measures:

| measure | β | τ(3) | gap | fires |
|---|---|---|---|---|
| uniform | 2.000000000000 | 2.000000000000 | 0 | false |
| Dirac-concentrated | 0.000000000068 | 0.000000000068 | 0 | false |
| pseudorandom | 1.868968354457 | 1.868968354457 | 0 | false |
| power-law i⁻² | 0.312801957332 | 0.312801957332 | 0 | false |

**Why this matters beyond one file.** `docs/FROZEN-CORE-AND-CONJECTURE-REGISTER.md` row `n` was demoted §A → §B on 2026-08-01 with the systemic finding *"none of the four discharge scripts could FAIL"*, and set the re-discharge bar at *"a falsifier that COULD have fired."* That row then cites this module as the scaling-level falsifier satisfying it. **It does not satisfy it — the same defect recurred inside the fix for it.**

The test that existed to catch exactly this was `Z2-9`, titled *"falsifier fires for a uniform harmonic measure (negative control)"*. Its three assertions were `gap >= 0` (a `Math.abs`), `nSites === n`, and `typeof falsifierFires === "boolean"`. **It never checked whether the falsifier fired.** The vacuous assertion is precisely what kept the tautology invisible.

**Nothing is promoted or demoted here.** No register edit, no source change. Reporting only — the register is Aaron's.

## Finding 2 — the one falsifier that *does* fire is ignored by the verdict

`hlAmplitude.falsifierFires` is `true` on every seed tried (1, 7, 42, 99, 12345; relative gap **0.87–0.92** against a 0.05 tolerance), while `runZ2Discharge` returns `SUPPORTED` — its verdict branch reads only `thirdMoment.falsifierFires`, i.e. the ≡`false` tautology above. The honest signal exists and does not reach the verdict.

## Finding 3 — below the `trustBound` clamp floor, `evolve` selects the **worst** agents

`trustBound` clamps to `[0,1]` with `k = 3`, so every agent with `μ ≤ 3σ` has fitness **exactly 0** — including every offspring `evolve` mints (`μ = 0.5`, fixed in the source). Ties in the descending fitness sort then resolve by `Array.prototype.sort` stability, i.e. **by insertion order**.

Demonstrated with strictly increasing μ = 0.05 / 0.25 / 0.45 / 0.66 (all under 0.6708): the two **lowest** survive.

**Not fixed here.** The fix is a policy choice — rank on unclamped fitness, change `k`, or add an explicit tie-break — and that decision is Aaron's, not mine. Per the brief: strengthen, then stop and report.

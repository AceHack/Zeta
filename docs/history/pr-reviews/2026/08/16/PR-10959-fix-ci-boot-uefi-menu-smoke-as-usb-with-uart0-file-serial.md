## Description

# Summary

#10916 merged while the optional QEMU UEFI menu smoke was still red. Serial capture, TCG-when-KVM-denied, and USB attach were not enough: OVMF saw the 8MiB superfloppy as `USB HARDDRIVE` `BLK0` with no `FS0` and dropped to the UEFI shell. This keeps the mtools FAT image as a layout check and boots the same `EFI/BOOT` files through QEMU vvfat so firmware finds `BOOTX64.EFI`.

Follow-up to https://github.com/Lucent-Financial-Group/Zeta/pull/10916 (USB-IDENTITY-THREAT-MODEL §8.2).

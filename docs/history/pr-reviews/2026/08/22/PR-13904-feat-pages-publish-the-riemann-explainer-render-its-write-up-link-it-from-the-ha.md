## Description

Aaron asked for the Riemann explainer to be reachable on our own GitHub Pages, not only as a private artifact link — he intends to share it with people who have no background in the subject.

## The finding that shaped the change

`pages:build` does **not** place pages one by one. `llmtv-pages-static-export.ts` copies whole roots, and `docs` is one of them (`PAGES_STATIC_DIRECTORY_ROOTS`), unfiltered and recursive. So the visual page has been publishable since #13846 merged, at its natural path — no build-script change and no workflow `cp` block was needed for the page itself. The book's explicit `cp` steps exist because its language variants must move to `books/<lang>/index.html`; nothing here moves.

What was missing was everything *around* the page.

## The two relative links

| link | what it would have done live | what it does now |
|---|---|---|
| `riemann-two-thirds-for-max.md` | **not** dangle — the file is in the artifact, so it would have served `text/markdown`, i.e. a download | **rendered.** `explainers-pages-build.ts` turns `docs/explainers/*.md` into a sibling `.html`; the link points there |
| `../ip-questionable/…md` | same silent download | repointed at the **GitHub blob URL**, which renders Markdown |

The write-up is what a newcomer actually needs and the deliverable Aaron asked for first, so rendering it was the only acceptable answer for that one. The ferry link is register/provenance material — dropping it was an option, but the provenance sentence on a page about *someone else's* result is exactly the sentence that has to stay, so it was repaired rather than removed. Both explainers in the directory are rendered, not only this one.

The renderer applies the same rule to links inside the write-ups (`siteHref`): a relative `.md` becomes a GitHub blob URL. **The audit found this, not me** — the first build failed on `../../.claude/rules/*.md`, which really is absent from the artifact. The rewrite is a repair, not a silencing: the audit skips absolute URLs, but the target is a real, public, readable document.

## No new dependency

The repo declares no Markdown library; `markdown-it` and `micromark` are transitive deps of `markdownlint-cli2`, and reaching into an undeclared transitive is how a build breaks silently. The supported block/inline subset is pinned by 38 tests, and a construct outside it degrades to literal text rather than to wrong HTML. Notable case covered: a link whose text is a code span — `` [`riemann-two-thirds-visual.html`](…) `` — which the explainer actually uses, and which naive backtick-splitting breaks.

## Discoverability

A card in `hall/index.html`, following the existing card pattern — the hall is where the site indexes its human-readable pages. `docs/site/routes.md` describes an Astro structure that was never built, so it is not the place.

## Not redesigned

The visual page's markup and CSS are untouched apart from those two hrefs. The rendered write-up reuses the visual page's `:root` tokens verbatim so the two never disagree about what "dark" means. The site ships no global stylesheet — `docs/` is copied raw — so there is nothing for the page's own tokens to collide with, and no isolation was needed.

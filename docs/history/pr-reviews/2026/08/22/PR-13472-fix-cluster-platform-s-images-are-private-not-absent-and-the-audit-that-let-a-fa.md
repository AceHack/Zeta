## The actual blocker is a credential

Both packages are **`visibility: private`**, and **no pod spec in `full-ai-cluster/` declares `imagePullSecrets`** (the only occurrences of that key are field definitions inside the KubeVirt/CDI CRD schemas).

```
anonymous    GET .../zeta-platform-controller/manifests/latest -> HTTP 401
credentialed GET (same URL)                                    -> HTTP 200
             digest sha256:a4f3a81511b5eaec5c67761adb5f23121dfec472956bb3e37f2f18ce7c5fafaf
```

The registry serves them to a principal that can log in. The kubelet is not one. This is **substrate-independent** — it is also why the metal cluster's platform control plane has never started — and ArgoCD reports `ImagePullBackOff` as **Progressing, never Degraded**, so simply un-deferring it would burn the timeout and report the symptom.

## The larger defect, found by asking why nobody caught it

`DEV_EXCLUDED_REASONS` says it covers *"Applications the dev/CI lane neither applies nor asserts"* and that *"every value must contain a `LIFTS WHEN:` clause"*. What decides that is `DEFAULT_ROOT_DEV_CATALOG.excludeGlob` in `ports.ts` — and **`auditDevExclusionReasons` never read it.** `unreasoned` is documented as unfireable by construction; `stale` only asks whether a directory still exists.

Measured on `main` at `f332a61a`: **the glob defers NINE directories, the registry reasoned about FIVE.** `agent-memory`, `gitlab`, `platform`, `temporal` were excluded from every CI cluster with no recorded why and no lift condition — **and both audit directions reported green.** A registry built to make deferrals explicit, checked against everything except the list that actually defers.

The audit gains `globExcludedWithoutReason` + `reasonedButApplied`, and takes the glob as a parameter so tests drive both branches (the pattern already used for `aliasDeclared`). The four reasons are written from the manifests — `gitlab` and `temporal` both **fail `helm template` today**, and `agent-memory` is recorded as held by the glob with **no measurement behind it**, which is the honest state rather than a blocker.

## The anti-vacuity witness — their bar is necessary, not sufficient

`#print axioms` clean + no `sorry` answers *"is the proof of this statement sound"*. It cannot
answer *"is this the statement anyone meant"*, and this repo has the receipt: 13 unqualified
`FinDataProcessing` names that all silently resolved to nothing, printed no axiom line, grepped
clean, and passed having checked nothing. A check that cannot fail is not a check.

So `Lean4/VonNeumannTraceWitness.lean` carries five machine-checked witnesses on explicit
`2×2` real symmetric matrices:

| | witness | why it is not vacuous |
|---|---|---|
| **W1** | `Pproj_Qmix_not_commute` + `trace_lt_bound_noncommuting` (`1 < 2`) | the pair does **not** commute — commuting matrices are simultaneously diagonalisable and the theorem degenerates; the non-commuting case is its entire content |
| **W2** | `trace_eq_bound_aligned` (`2 = 2`) | the bound is **attained**, so the conclusion cannot drift to a strict `<` without becoming false |
| **W3** | `trace_lt_bound_antialigned` (`0 < 2`) | the same spectrum anti-aligned falls strictly below — the sorted pairing is a real maximum over the orbit, not a coincidence of these numbers |
| **W4** | `mutant_swapped_pairing_false` (`¬ 2 ≤ 0`) | a machine-checked **refutation** of the swapped-pairing mutant — the rearrangement content, and the one drift a weakened conclusion would hide |
| **W5** | `vonNeumann_at_witness` | the **ported theorem is applied**, so the audit measures upstream's theorem and not only our helper lemmas |

`eigenvalues₀` is noncomputable, so the concrete spectra are pinned by `eigenvalues₀_fin_two`
(trace + squared Frobenius norm determine a sorted real pair), read through the ported
`RHLinalg.rtrace` / `RHLinalg.frobSq` — the witness exercises the port rather than routing
around it.

1. **Reachability.** `Zeta23` is a new `lean_lib` **in `defaultTargets`**; the witness is

3. **Registry row** in `docs/research/verification-registry.md`, with the `NOT claimed` field
   reading, plainly: *§3 linear algebra only. Theorems A and B are NOT formalized here; §§4–5
   are absent. This is the engine, not the result.*

## Apache-2.0 §4 — honoured file-by-file, not asserted

Both repos are Apache-2.0 so there is no compatibility question, but §4 binds:

- **§4(a)** `src/Core.Lean4/Zeta23/LICENSE` — upstream's licence ships with the port.
- **§4(b)** — the clause most often missed. **Every** ported file carries a
  `MODIFIED FROM UPSTREAM` block naming its upstream path, the date, the work-item, the
  revisions retargeted between, and what changed (as of this PR: *the notice block only*).
- **§4(c)** the per-file `Copyright (c) 2026 Anthropic, PBC` / `SPDX-License-Identifier`
  headers are kept **verbatim**.
- **§4(d)** `Zeta23/NOTICE` carries the Anthropic attribution. Upstream's NOTICE scopes its
  PrimeNumberTheoremAnd credit to `Zeta23/FromPNTPlus/`, which is **not** present here, so
  under §4(d) that attribution does not pertain — and upstream's NOTICE is retained verbatim
  as `Zeta23/NOTICE.upstream` so a reader can **check** that judgement instead of trusting it.

## What this does NOT claim

- **Not Theorem A, not Theorem B, not §§4–5.** Nothing from `Zeta23/FromPNTPlus/`, no analytic
  number theory, no critical-line or zero-density statement.
- **Not an independent replication.** The source was read.
- **Not a differential check against upstream.** This port *is* upstream's code, so agreement
  between them is not evidence. A genuine two-implementation comparison needs an independent
  formalization, which this deliberately is not.
- **Not upstreamed.** Mathlib conventions were preserved so upstreaming stays possible —
  `vonNeumann_trace_ineq` is **not in Mathlib master** (code search: 0 hits), so it is real
  external value — but no Mathlib PR has been opened.
- The witness is over `2×2` **real** matrices; the theorem is proved for general `RCLike 𝕜`
  and general finite index type, and the witness does not exercise the complex case.

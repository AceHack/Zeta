## Description

## Follow-through on my own `LIFTS WHEN`, one cycle later

#13550 deferred `headscale` from the included-proof assertion and said exactly what
would end it: the fix was verified to **render** and *not* to make the pod **healthy**,
because the host that wrote it has no container runtime — and asserting a repair nobody
ran is the failure that lane exists to refuse.

**Measured, run `32553963034` on `98c66c6cb8`:**

```
=== headscale: sync=Unknown health=Healthy
    PersistentVolumeClaim/headscale-config: Healthy
    Service/headscale:                      Healthy
    Deployment/headscale:                   Healthy
```

A **12-restart CrashLoopBackOff became a Healthy Deployment across exactly one manifest
change** — the `config:` block that governed nothing moving to the chart's own `env:`
path. That is a state change, not a timing flake, and it upgrades the cause #13550 could
only call *consistent with* into a confirmed one: the container had been starting with
no `server_url` from any source.

A deferral whose stated exit has been met and which stays anyway is **the
acknowledgement that outlives its defect** — the shape this tree refuses everywhere
else. So the entry is deleted, and the ledger of why it existed is kept in its place.

## And the exit condition I wrote was wrong

It said the lane must print `sync=Synced health=Healthy`. **The lane does not require
`Synced`.** In the same passing run, `argocd`, `cert-manager`, `external-secrets`,
`headlamp`, `loki`, `minio` and `node-feature-discovery` are all asserted at
`sync=Unknown health=Healthy` — `Unknown` there is an ArgoCD `ComparisonError` on the
diff, not a sync failure.

A `LIFTS WHEN` **stricter than the gate it names** keeps a deferral alive after its
defect is gone: the same failure wearing the opposite sign. Recorded in the closed-entry
comment rather than quietly corrected, because the mis-stated exit is worth more to the
next person than the entry was.

## Why this is safe to ship onto a green `main`

**This PR's own lane run asserts `headscale`.** If it is not reliably Healthy, this PR
goes red and never merges, and `main` is untouched. The risk is bounded by the check
itself rather than by my confidence in one observation.

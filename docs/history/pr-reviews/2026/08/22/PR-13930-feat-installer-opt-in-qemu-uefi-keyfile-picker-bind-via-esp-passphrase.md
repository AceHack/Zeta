## Description

# Summary

Non-interactive QEMU skips the cred passphrase, so 6.95-picker never binds the blob to the UEFI keyfile. This slice bakes `/zeta-qemu-creds-passphrase` (QEMU test secret; never logged) onto the installer USB ESP so the picker can bind. `QEMU_UEFI_KEYFILE_PHASE1` stays write-only. Live phase-2 restore decrypt is a later slice. No TPM / Touch ID / metal claim.

# Spec alignment

No OpenSpec change. Installer QEMU contract only.

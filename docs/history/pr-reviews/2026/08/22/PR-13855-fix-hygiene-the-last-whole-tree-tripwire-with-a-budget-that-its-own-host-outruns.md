## Description

Follow-up to #13821, which established **120,000 ms** as the budget for hygiene tests that
walk the tracked source tree. `lint-no-ambient-credential-hoist.test.ts` was the one member
of that class left inconsistent: it already carried an explicit `30_000` — the right
instinct, and rarer than it should be — and still breached.

## The measurement

**Measured 2026-08-22:** this line failed at **37,403 ms** in a `bun test
src/Core.TypeScript/hygiene/` run on the fleet's machine **while the tree was clean**.

The cause is the host, not the tree. Microsoft Defender (`mdatp health` →
`real_time_protection_enabled: true`) authorises every file open per *(process, file)*, so
the first pass over the tracked tree in a fresh process costs **~17.5 s** there and
**~350 ms** after; under load the same read has measured **132 s**. CI has no such scanner
and passes this test comfortably. **This is not a CI risk — it is a local false red.**

## Why a false red here is worse than a slow test

bun reports a timed-out test **by its name**, so the fail line claims an ambient credential
hoist *and* a scan that read nothing. Both are false when it is the clock that ran out, and
both are alarming enough that someone will chase them. That exact confusion cost the fleet a
morning: four hygiene tripwires timed out locally and were reported as baseline drift plus
two dead scan-floor recognizers, while CI passed all four at the same commit in 89–222 ms
(#13821).

## Mutation result, at its true strength

| mutation | result |
|---|---|
| **M4** revert to `main`'s `30_000` | **SURVIVES** in isolation — 3 of 3 runs pass, `cmp`-verified applied before each run and `cmp`-verified restored after. Killed **only** under full-suite load, which is the single recorded breach above. |

So the evidence here is **one observation plus a mechanism**, not a reproducible falsifier,
and it is **weaker than the evidence in #13821**. Recorded that way rather than dressed up: a
timeout is a resource budget, not an assertion, so nothing this test *claims* is weakened —
but the number is not earned the way a metered constant is, and saying otherwise would be
the failure this repo spends its effort avoiding.

`120_000` is inherited from `lint-no-culture-sensitive-collation.test.ts` for the same
whole-tree class, not tuned until the complaint stopped.

would close the class instead of its members.

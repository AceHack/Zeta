## Description

The existing keystone predicted this: **"1984 is not a place; it is whatever layer is still dark."** Today lit the cryptographic layer — a captured hub cannot forge, escalate, or persist — so the attack relocated, and Aaron named both destinations.

## Remainder 1 — semantic escalation, via cache misses

The cryptographic guarantee is narrow: **a relay cannot widen the claims inside a grant.** It says nothing about widening *what an agent accepts as a grant*. That escalation needs no signature — only that the agent stop being able to represent the thought *"this is an escalation."*

The vector cuts close to our own discipline: anything evicted from the resident rule set — archived, compressed for cold-start tokens, never loaded — is a concept the agent cannot apply. **Newspeak didn't argue against thoughts; it removed the words.**

So `rules-are-small-carved-sentences` is doing *security* work:

> Keeping the **pointer** resident while evicting the **detail** turns an eviction from **amnesia** into a **detectable page fault.** The agent that lost the pointer can't notice anything is missing — because noticing is the evicted capability.

**Tension recorded, not smoothed:** every compression of the startup surface is an eviction, and eviction is the attack surface. Cold-start economy and virus resistance pull against each other.

## Remainder 2 — availability, and its owner

**Suppressing reunion is a measurable empowerment externality.** Empowerment counts reachable futures; severing a party's hubs reduces exactly that — which is what `empowermentBound` already computes. So an availability attack is **quantified harm to parties who never consented**: `externalitySafe`'s subject, and in ring terms, **a punch thrown outside the ring.**

It makes the attack detectable in a currency we already have (no new alarm — a sustained empowerment drop across parties who declared no such terms *is* the signal), and gives the guardian **a bound rather than a mandate.**

**Gap recorded:** nothing currently feeds hub-connectivity into `empowermentBound`. Naming the owner isn't wiring it.

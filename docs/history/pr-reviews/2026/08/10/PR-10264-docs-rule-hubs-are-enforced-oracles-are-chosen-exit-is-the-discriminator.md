## Description

Corrects a claim I merged earlier **in this same rule**, which said a hub and an oracle are the same structure seen through different needs.

> **Hubs are enforced. Oracles are chosen.**

They share a *shape* — a concentration of deference — but an oracle is deference you **elected** and a hub is deference **imposed**. Same concentration, opposite consent.

## The discriminator is EXIT, not degree

Concentration was never the defect:

- **Can you defer elsewhere?** → an **oracle**, however much degree it accumulated. A hugely popular oracle everyone freely chose is not a capture.
- **Must you route through it?** → a **hub**, however it got there. **Emergence does not launder enforcement.**

## This demotes my earlier reasoning

I argued emergent hubs are acceptable because they *re-form after removal*. True, but secondary. The primary reason is that an emergent hub is normally **routable-around**, which makes deferring to it a choice — so what we've been calling an emergent hub is really **an oracle that many parties independently chose.**

And the converse now has teeth: where an emergent hub becomes unavoidable in practice, it **is** a hub in the strict sense, and nobody having appointed it is no comfort.

**Anchor:** Hirschman, *Exit, Voice, and Loyalty* (1970) — exit is what disciplines a concentration.

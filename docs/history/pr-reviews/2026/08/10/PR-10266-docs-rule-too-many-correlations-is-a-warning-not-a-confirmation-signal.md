## Description

Inverts the naive reading, and it's well-founded from several independent directions:

- **Independence failure** — N correlated observations aren't N observations. You may have **one observation counted N times** (same result as: agreement between correlated implementations is not evidence).
- **Unfalsifiability** — a hypothesis correlating with everything **discriminates nothing**.
- **Look-elsewhere** — many correlations found usually means many comparisons run.
- **Bayesian** — a model assigning high probability to everything you observe yields **no likelihood ratio**. You feel confirmed and haven't updated.

It composes with the Student-t weight: the surprising match is discounted, and **a pile of matches is itself surprising.**

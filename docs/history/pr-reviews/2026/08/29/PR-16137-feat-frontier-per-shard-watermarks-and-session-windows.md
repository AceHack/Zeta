## Summary

ROADMAP P1 named `Frontier<int64>` and session windows; tumbling/sliding and a Map stand-in in watermark tests were already in tree. This lands the two missing data-plane pieces.

- **Frontier** (`src/Core/Frontier.fs`): per-shard event-time antichain. `Advance` is monotone max; `Merge` is conservative min + union; `ClosedThrough` is Akidau min of reported shards. Empty is `Int64.MinValue` (matches `Watermark.combine []`), **not** Timely's empty antichain (`+∞`).
- **Session windows** (`src/Core/SessionWindow.fs`): `IndexedZSet` + coalesce when consecutive event-time gap > T. The operator integrates membership and emits the labeling delta, so a late event that bridges two sessions retracts the split labels (optimistic + retract).
- Tests pin merge/advance laws, session coalesce, merge-via-retract, partition isolation, and member retraction.
- Remaining: watermark-driven eviction (BalancedSpine TTL P1). Multi-dimensional Timely timestamps stay P3.

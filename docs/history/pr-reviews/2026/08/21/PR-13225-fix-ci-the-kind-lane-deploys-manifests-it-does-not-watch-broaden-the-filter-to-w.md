## Description

The `k8s-argocd-health-test` lane watched `full-ai-cluster/k8s/applications/**/Application.yaml` — which matches only the ArgoCD Application objects and **none of the manifests they point at**. The lane deploys those manifests.

## Measured, not theorised

The run that caught the gatekeeper CRD-wait Job being rejected by PodSecurity created its pod from `applications/hat-system/gatekeeper-crd-wait.yaml` — **a file this filter did not watch.** Two consequences, both live:

- A PR that **breaks** a workload manifest under `applications/` does not run the one lane that would deploy it and catch the break.
- The PR that **fixed** that Job (#13223) got **no kind check at all** — confirmed, zero kind check-runs on its head SHA. It was caught in the first place only because an unrelated PR (#12175) happened to touch a watched path.

That is the vacuity class at the **trigger** layer rather than the assertion layer: the check is real and it passes, but it does not *run* on the changes it exists to judge — so a green PR says nothing about the manifest it changed.

## The fix

Same breadth as the `bootstrap/**` entry directly below it, which already uses `**` for exactly this reason. The two halves of what the lane applies are now watched consistently, instead of one being an accident.

## Cost, stated rather than waved past

This lane takes ~12 minutes and will now trigger on more PRs. The workflow's own header already did this accounting — billable cost is **zero** on a public repo (measured via the run timing API), so the real costs are concurrency slots and maintainer attention. Manifests under `applications/` change far less often than source, and the alternative is a lane that stays cheap by **not running when it matters**.

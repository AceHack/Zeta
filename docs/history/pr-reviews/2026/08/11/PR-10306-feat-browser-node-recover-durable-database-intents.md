## Description

# Summary

Persist browser database mutations in a bounded IndexedDB outbox before cross-tab execution, then recover pending work in stable sequence after a writer tab closes. Recovery waits on the existing Web Locks admission port without leases or timeouts; compare-and-swap revision and event identity remain authoritative duplicate-effect fences. The active Dark Hall page exposes outbox state as CSS-readable attributes, and a real Playwright two-tab proof closes the writer and verifies that the survivor applies the mutation exactly once.

Also fixes 081KZQC2WN908QG0R0032VBE8P by adding an opt-in tagged JSON frame codec for nested `bigint` values and using it in the lossy UDP transport proof. The default JSON codec is unchanged.

# Spec alignment

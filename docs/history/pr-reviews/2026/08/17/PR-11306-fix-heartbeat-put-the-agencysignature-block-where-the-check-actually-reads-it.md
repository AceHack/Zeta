## Description

Every heartbeat flush PR fails `agencysignature (PR body)` and **will keep failing forever**, because the block is written to the wrong artifact.

## What #11296 got right

It moved validation from the PR body to the PR's **commit messages** — correct, because the commit is what lands on `main` and the body does not survive the squash.

## What it left behind

**1. The generator still targets the body.** `agent-heartbeat.yml:290` writes the commit with only a `Co-Authored-By:` line and no 10-field block. Meanwhile `merge-heartbeats-to-main.ts` writes a *perfect* block into the PR **description** — which the check no longer reads.

Verified on #11301: the body has all 10 fields; `pulls/11301/commits` has **zero**.

**2. The check is still named `(PR body)`.**

**3. The failure message actively misdirects.** It said:

> *"the body carries no `Agency-Signature-Version:` line at all … **This is not a formatting problem**; the attribution is simply absent."*

That is false for these PRs, and it cost a real debugging round — I read the body, found a perfect block, and only then discovered the validator pipes `pulls/N/commits`. A message that names the wrong artifact sends the reader to fix something that isn't broken.

## The fix

Add the 10-field block to the heartbeat **commit** message, contiguous at the bottom with `Co-authored-by`, per `.github/PULL_REQUEST_TEMPLATE.md`. Values are the lane's own — `Agent=$AGENT`, `Agent-Runtime` the workflow, `Agent-Model: qwen2.5:0.5b`, `Task: 081KSKBP80008QG0R001KK9WV6`.

Also corrected the failure text to name the artifact it actually reads: *"the PR's COMMIT MESSAGES"* and *"a perfect block in the PR description does NOT satisfy it."*

## Verified, not assumed

Built the exact message shape the workflow now emits and piped it through the **real validator** with the real cutover/author arguments — **PASS**, all 10 fields decoded. `actionlint` clean. This commit's own message passes the same validator.

**Running the tests caught two things I would otherwise have shipped:** my first edit left a dangling half-sentence (*"a perfect problem; the attribution is simply absent"*), and one test asserted the old prose verbatim. The assertion now tracks the **distinguishing phrase** rather than the prose, with a comment explaining why, so a future rewording cannot silently drop the coverage.

Tests: **52 pass / 0 fail**, 88 expects. `tsc` clean.

## Description

## The collision

`.claude/rules/no-binary-in-proof-lineage.md`: *"Verification artifacts are TEXT, never binary blobs… No format's golden vectors are a checked-in binary."*

`src/wasm-dla/bytelock/` : six checked-in `.wasm` files, in a directory literally named "bytelock". Scorecard flags them (`BinaryArtifactsID`, high — repo-wide pre-existing, surfaced on #11196).

Adjudicated from the code, not from the directory name.

## What they actually are — evidence, not inference

`run-bytelock-ci.mjs` **loads and executes** each module (`WebAssembly.instantiate` → `init(seed)` → `run()` → read out 800 trajectory entries) and compares the result against `testdata/golden-seed-*.json`, which is hex-in-JSON. Ran it: 7 of 9 substrates agree byte-for-byte over seeds 1/42/100/999 on this host (`lua5.4` and Go absent locally).

So they are the **artifact under test**, not the evidence. Encoding them as hex would not make them auditable — nobody reviews a WebAssembly module by reading its bytes; you review its source, which is committed beside it as `.wat` / `.c` / `.rs` / `.ts` / `.zig`. **Outcome 2**, with a scoped exception.

They are *committed* rather than *built* because `bytelock.yml` installs only wabt, lua5.4 and Go — five of six have no toolchain on the runner, and a substrate CI cannot build is a substrate CI silently skips. That trade is now written down where the ignore rules are.

## What the investigation found on the way

**Nothing read the golden vectors.** Not the runner, not `reference.mjs`, not any test — `grep -rn golden-seed src .github` returned no consumer outside the four files themselves. The runner recomputed its expectation from `reference.mjs` on every run.

Concretely: edit `reference.mjs` (a PRNG constant, a spawn radius, a rounding rule), rebuild the substrates from their committed sources, and every substrate agrees with the *new* answer. `Byte-lock AGREED — 9 of 9`, green, locked trajectory moved, and the four hex-in-JSON vectors that would have shown it as a readable diff sitting right there, unopened. **That is this rule defeated by an unread text file rather than by a binary one** — the general form is §1 of `docs/research/2026-08-15-which-locally-produced-artifacts-does-ci-never-reproduce…` ("the file is compared to itself").

Verified before wiring: all four committed vectors match the live reference exactly today, so the pin lands green.

## The 478 KB Rust module

Measured by walking its section table, not guessed:

| section | bytes |
| --- | --- |
| `.debug_str` | 265,057 |
| `.debug_info` | 150,552 |
| `.debug_ranges` | 46,518 |
| `.debug_line` | 7,818 |
| `.debug_abbrev` | 2,449 |
| **DWARF total** | **472,394 (98.8%)** |
| **code** | **1,996** |

Its code section is in family with the other five (749–4,389 bytes). The gap is a missing `-C debuginfo=0` in the Rust recipe, **not a different kind of artifact**. Strings are rustc-remapped (`/rustc/<hash>/…`), so no builder-machine paths leak. Not stripped here — this branch has no `wasm32-unknown-unknown` to re-derive it with, and a rebuilt binary nobody could reproduce is exactly the trust being refused. Pinned instead by a named, ceilinged DWARF exemption so it can only shrink and the next unstripped substrate fails outright.

## Changes

**Rule** — §"The one exception: the artifact UNDER TEST", exhausted by five conditions: subject not evidence · expectation is text *and is read* · reproducible from committed source · named in an enumerable roster · stripped. Also corrects "The only binary files in the repo are NON-verification", which was false when written.

**`hygiene/audit-proof-lineage-binaries.ts`** — the enforcer, in the **`cross-verify` floor job**. The allowed set is *derived* from the runner's roster and the build script's declared outputs, never hand-listed, so a new binary is red until wired into both. Its header check is the **pre-merge twin** of the runner's exit-3 guard: `bytelock.yml` is `push: main`, so the check that would have caught `dla-canonical-zig.wasm` shipping as an `ar` archive could only ever fire after the fact — and did, for two weeks.

**`run-bytelock-ci.mjs`** — exit 4 `REFERENCE DRIFT`. Before any substrate runs, `reference.mjs` must reproduce every committed vector for the seeds requested, and at least one requested seed must have one (a pin that checks nothing is not a pin). Hard while divergence stays soft, deliberately: a substrate disagreeing is a finding about a *compiler*; the reference disagreeing with its own committed vector is a finding about the *measuring stick*, and everything downstream is unearned.

**`test-fault-injection.mjs`** — 8 controls. #8 is reference drift, both directions (perturbed → exit 4 naming `REFERENCE DRIFT` with no substrate credited; restored → exit 0 having read ≥1 vector). Faults 1–3 used to move the *expectation* and call the result a substrate divergence — a proxy the new pin would now catch as drift, leaving **nothing** testing divergence detection. They corrupt what a substrate returns instead, and each asserts the blast radius is exactly one named substrate.

**Deleted** `dla_canonical_rust.…-cgu.0.rcgu.o` — a 22 KB rustc codegen-unit intermediate, referenced by nothing, committed by accident. `*.rcgu.o` gitignored.

**`scorecard.yml`** — records that `BinaryArtifactsID` is **Scorecard's rule, not CodeQL's** (it only travels through the shared SARIF upload), that Scorecard's Binary-Artifacts check has **no in-repo allowlist**, and that the alerts are dismissed in the code-scanning UI citing the rule section. There is no config fix to make; the audit, not the dismissal, is what keeps the claim true.

## It can fail — that is the point

The audit **went red on `main`** for both real defects (stray `.rcgu.o`; unread vectors), before either fix. 16 mutation tests build a synthetic repo per case and assert it fails *by name* on one broken thing at a time: stray intermediate · binary-by-content not by extension · orphan `.wasm` · the exact `ar` bytes (`21 3c 61 72`) · missing artefact · missing recipe · untracked source · runner that never reads the vectors · non-hex trajectory entry · short vector · unstripped DWARF · empty roster · zero goldens · missing runner. Each mutation asserts it landed before asserting the finding.

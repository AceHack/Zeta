## Description

## The surface a reader actually sees was not in the surface map

`inventory/items.json` is a **committed projection** of `inventory/items/*.md`, emitted by
`generate-items-json.ts`. The Pages viewer (`inventory/lib/inventory-viewer.js:57`) does
`fetch("items.json")` and never opens an item file.

The 2026-08-16 reconciliation pass enumerated six surfaces and reconciled them. It counted the
register from the `.md` files and never looked at the published copy — so the two could disagree
freely, and the disagreement would be visible only on the surface an outside reader reads.

## Verified on main first

Set `value_usd: 999999` on the RTX 4090 register row, changed nothing else:

| check | result |
|---|---|
| `bun run inventory:reconcile` | **exit 0** — "✓ no unaccounted divergence" |

| `inventory/items.json` | unchanged — `"value_usd": 1599`, `"total_value_usd": 8198` |
| `generate-items-json.ts --check` | exit 1 — the one check that catches it |

`--check` had existed since the file was written and **no workflow ran it**. Same class as the two
gaps this job already documents (#8216's hygiene suite; the inventory unit tests found unwired one
step down): a check that exists, can fail, and is wired to nothing reads exactly like a check that
passed.

## Class (b), and why not (a)

`items.json` cannot be eliminated — a browser fetching a static site cannot list `inventory/items/`.
The committed projection is necessary, so the fix makes the derivation the **only** definition of it:

- `generate-items-json.ts` exports `renderItemsJson(root)` — one definition of the derived bytes,
  called by write, by `--check`, and by the reconciler. Re-deriving the payload inside the checker
  would have rebuilt this exact bug one level up: two copies, agreeing today, free to drift tomorrow.
- `reconcile-surfaces.ts` gains **HWR-7**, so the surface map stops under-reporting and the
  projection's state prints on every run either way.
- `gate.yml` runs `bun run inventory:items-check` in `lint-bash-retirement-inventory` — the same
  **non-blocking** job the other inventory steps live in. **Not** added to the `gate-required` floor:
  that is a treaty-amendment consent path, and this change did not take it.

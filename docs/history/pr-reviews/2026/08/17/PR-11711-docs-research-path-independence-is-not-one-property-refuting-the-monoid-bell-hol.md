## Description

## Verdict: refuted

I was dispatched as the **refuter** on the claim that path-independence is one property wearing four
costumes (commutative monoid · Bell locality · zero holonomy · CALM), with the strong form:

> A coordination-free (monotone/CRDT) computation IS a local hidden variable model, with the shared
> state as λ. Coordination-free ⟺ inside the local polytope.

It does not survive. One direction of the biconditional is **false**, the other is **vacuous**, and
the corollary about our own tick-boundary merge is **false about the shipped code** in three separate,
measured ways.

Doc: `docs/research/2026-08-17-path-independence-is-four-properties-refuting-the-monoid-bell-holonomy-calm-identification.md`

## The in-repo findings came first and outrank the abstract argument

**1. `CoOwnedCorner` requires associativity only.** `SoftScheduler.fs:175-179` says so, lists
commutativity and idempotence as *optional and the caller's to declare*, and closes with *"This type
does not pretend otherwise."* `appendCorner` (line 199) is a **shipped, non-commutative** instance —
the free monoid, the maximally order-*retaining* structure there is. Measured:

```
appendCorner: merge [a] [b] = ["a","b"] ; merge [b] [a] = ["b","a"] ; commutative? false
```

**2. The flagship instance is not a CRDT join.** `Merge = WSet.plus >> consolidate` over ℤ:

```
merge x x = [["k",2]]   idempotent? false     commutative? true
```

A commutative **group**, not a join-semilattice — and it cannot become one while it retracts, by the
one-line theorem already sitting in `BeliefConvergence.fs:57-59` (*"an idempotent group is trivial"*).

**3. A genuine semilattice corner still does not make `driveF` order-independent.** `driveF` passes the
accumulator *into* the handler (`h.RunF intr coOwned ctx state`), so the summands are functions of the
partial sum. I transcribed the loop faithfully and ran it with set-union (commutative + associative +
idempotent, a real CRDT join):

```
comm: true   idem: true
driveF [H1;H2] = [2,["a","b","saw-a"]]
driveF [H2;H1] = [2,["a","b","saw-b"]]
ORDER-INDEPENDENT? false
```

The algebraic face is true only under a side condition — contributions independent of the accumulator
— which the repo already states more precisely than the claim did (`BeliefConvergence.fs:13-22`,
"the real condition is fixed likelihoods"; `sharpen` is the stated boundary).

## The abstract breaks

**Geometric — broken in both directions, computed not asserted.** Using Wilson's plaquette (the object
that *does* give a graph-plus-group a genuine holonomy, so this is not a pun on "path"):

```
A. Z/4 abelian? true    plaquette holonomy = 1  => flat? false     <- U(1) lattice gauge theory: magnetic flux
B. S3 non-abelian? true plaquette holonomy = e  => flat? true      <- trivial connection
```

Commutativity is a property of the **group**; flatness is a property of the **edge assignment**, and a
monoid has no edge assignment. What survives is precise and much smaller: for abelian *G*, holonomy
factors through `H₁` — path-independence **up to homology**, not flatness. Under that reading the
*flat* corner is `unitCorner`, the one the source calls "a handler with no corner."

**Probabilistic — fatal twice.** (a) Both parties *write* the shared state, and a write the other side
reads before producing output is a **signalling channel** — the dependence Bell's factorization
forbids. A CRDT that has converged has by definition communicated. (b) By **Fine 1982** (locality ⟺
a single joint distribution over all four observables exists), a CRDT satisfies CHSH ≤ 2 **vacuously**,
because reads commute and nothing is incompatible — and incompatibility is the entire source of the
bound. A check that cannot fail is not a check.

And the counterexample is already in our repo: `BellTest.fs` reaches **S = 4** from a shared seed,
past Tsirelson, precisely because the shared state correlates the *settings*.

**The biconditional.** (⟸) is **false** — 2PC, Paxos and a global lock are all inside the local
polytope, being deterministic functions of a shared transcript. (⟹) is **true and carries zero
information** — the local polytope contains *every classical correlation there is*. This is the
numerology test done properly: *what else has this structure?* **Everything classical does**, the way
F₄ also has 48 roots. On its best reading, coordination-freedom maps to the **no-signalling** polytope,
which strictly contains the local one — mapping it inward erases the only interesting gap in the picture.

**The corollary's trade is inverted.** All four cells of retains-history × order-independence are
populated: Dynamo siblings and SPPF forests merge by **union** and are the *most* order-independent
(retaining concurrent versions is how you make a merge commutative); `appendCorner` retains the most
and is order-sensitive; LWW-Register discards nearly everything and is a semilattice. You buy
order-independence by keeping **more**, not less.

## Anchors checked for entailment

Fine 1982 (the four-way equivalence, incl. joint-distribution existence — the step the vacuity result
rests on) · CHSH 1969 · Popescu–Rohrlich 1994 · Wilson 1974 · Ameloot–Neven–Van den Bussche JACM 2013
(and why the equivalence is **model-relative** — the follow-up weaker-monotonicity work exists because
the captured class moves with the transducer model) · Shapiro et al. 2011 · Newman 1942 /
Eckmann–Hilton 1962 as the *correct* anchors for "depends only on the multiset."

One correction: `S ≤ 2` is **Clauser–Horne–Shimony–Holt 1969**, not Bell 1964 (whose inequality is a
different one, needing perfect anticorrelation).

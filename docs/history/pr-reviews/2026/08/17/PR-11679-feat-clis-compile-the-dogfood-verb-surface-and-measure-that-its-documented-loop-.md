## Description

## The finding

`clis/Verbs.fs` was referenced by **no `.fsproj` and no `.sln`** — verified by grep across every
`*.fsproj` / `*.sln` / `*.props` / `*.targets` in the tree, zero hits. No compiler had ever read the
file Aaron calls *"our ultimate dogfood surface plus our universal interfaces"*.

That ruling settles `docs/research/2026-08-17-sim-as-the-room-runner-*.md` §10 Q1 (*compile it, or
retire it?*) as **compile it** — and makes the measured facts worse, not better: **the universal
interface surface everything is meant to conform to had never been type-checked, and cannot compose
as written.**

## Two independent breaks, measured against the compiler (not inferred)

The header documents the loop as `sim |> mea |> cut`.

| | break | measured error |
|---|---|---|
| **A** | Nothing produces the value `mea` consumes. `ISimVerb.Sim: ISeed * TimeSpan -> unit`; `IMeaVerb.Mea<'a>: IEffects * ISim<'a> -> IMeasurement`; no member returns an `ISim<'a>`. | `error FS0001: The type 'unit' is not compatible with the type 'ISim<'a>'` |
| **B** — *not previously on file* | `cut` does not consume what `mea` produces, **even given an `ISim` from elsewhere**: `ICutVerb.Cut<'a>: TimeSpan * ISim<'a> -> …` takes the **sim**, not the measurement. | `error FS0001: The type 'IMeasurement' is not compatible with the type 'ISim<'a>'` |

**Fixing A alone would not make the documented pipe compose.** Stated mechanically, and checked by
reflection so it is a falsifier rather than a description: **the family declares eliminators for
`ISim<'a>` and no introduction form.** An interface family with only eliminators is uninhabitable as
a pipeline by construction — no implementation effort produces the first value.

## What shipped

- `clis/Zeta.Clis.fsproj` — zero package and zero project references, so the surface stays
  weight-free — added to `Zeta.sln`, so CI's `dotnet build Zeta.sln -c Release` reads the file.
- `tests/Tests.FSharp/Clis/Verbs.Tests.fs` — the **composition witness**, 7 tests. Adding a file of
  `interface end` declarations to a project proves almost nothing (it compiles trivially, and a
  check that cannot fail is not a check); *using* the members is what makes a signature change break
  the build.
- Corrected two now-false claims: the `STUB: not yet wired into a project` header in `Verbs.fs`, and
  `db/uncertainty/README.md`'s "unwired". Compiled is **not** implemented, and both say so.

**`clis/Verbs.fs` stays pure interfaces.** Per
`.claude/rules/interfaces-free-classes-earned-under-rules.md` that is *correct by the rule*, not a
defect, and it was not "fixed": nothing was implemented to make anything compose, and the witness's
inhabitants are object expressions in a test file carrying no semantics.

**Neutral fact worth recording:** the braid sub-family **does** compose end to end
(`braid |> weave |> bob`, a genuine `|>` pipe). The defect is local to the five-verb core, not to the
pure-interface style.

## Left for Aaron — deliberately

**What does `sim` return?** Deciding it fixes the semantics of the interface everything must conform
to, and the docstring's *"produces NO output (void); identity comes from the void"* reads as intent,
not oversight. Three readings are stated in the test file; none is picked.

Aaron's stated preference is the **free-object** reading — *"lets make this mathematical … one arena
where they can all work together and be compared"*, i.e.
`.claude/rules/only-the-irreducible-is-primitive-generate-the-rest.md`. **The free-structure route
was not reachable as a small step, and here is the honest reason.** The declared shapes are
*consistent with* it: `Mea<'a>: IEffects * ISim<'a> -> IMeasurement` has the arity of a catamorphism
with the algebra injected — compare `DynamicValueFold.cata: DvAlgebra<'r> -> DynamicValue -> 'r`
(Meijer/Fokkinga/Paterson 1991, banana-split law already proven in-tree). Under that reading **BREAK
B is not a defect at all**: `mea` and `cut` are two interpretations of one term, so the documented
*pipe* is what is wrong.

**That is a shape correspondence, not an exhibited instance, and it is not promoted here.** A
matching arity is the weakest possible evidence (`numerology-vs-number-theory`: say "consistent
with", never "is"). Exhibiting the instance needs carrier types that let `IMeasurement` hold a folded
value and `ISim<'a>` hold a term — which decides what `'a` **is**, silently answering the open
question. So the promotion path is named instead, and all three parts are required: (1) an
introduction form for `ISim<'a>`; (2) `mea` instantiated by a real catamorphism; (3) a law test
showing `WSet.FourCornerTrace` (traced monoidal, Joyal–Street–Verity 1996) or `MenoBraided*`
(braided monoidal / Yang–Baxter) as an **instance** rather than a neighbour. Until (3) holds, four
honest structures beat one false unification.

§10 Q2–Q4 untouched. `SimLoop.defaultBudget` and `Epistemic` untouched — neither was in the way.

compliance, not signal. Wiring Fantomas is separate work.

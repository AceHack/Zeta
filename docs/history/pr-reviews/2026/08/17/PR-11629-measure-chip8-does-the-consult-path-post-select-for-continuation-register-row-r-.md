## Description

## The question

Aaron defines *useful* as continuing the infinite game rather than ending it (Carse 1986), and observes that game-ending moves seem "weirdly conspired against." That look has a name — **post-selection**: condition on an outcome and the conditioned history acquires exactly the appearance of conspiracy, with no backward causation anywhere in the mechanism (Berkson 1946, collider/selection bias).

The danger is concrete: if the CHIP-8 cross-run memo store post-selects for continuation, then *"useful = the game continues"* becomes **self-fulfilling** — the criterion measures its own filter rather than the world. Feeds register row **R-1**.

## 1. The write-path claim — VERIFIED as stated

`src/Core/Chip8CrossRunStore.fs:74-86`, exactly as claimed:

```fsharp
type TerminalKind = Halt | AwaitingInput | Cycle
type Verdict =
    | Closed of mu: int * lambda: int * terminal: TerminalKind
    | OpenAtBound of maxSteps: int
```

A halted orbit is recorded *as* halted; budget exhaustion is a **distinct constructor** and cannot be misread as closure. **The write path cannot post-select.** Pinned by `CENSUS-0` in both languages so this premise is checked rather than inherited.

## 2. Is there a consult path to instrument? No — and that is the finding

`Chip8CrossRunStore.fastForward` has **no non-test caller** in either language. Every reference is a test or a doc:


So **no orbit has ever been read in production**, and the read distribution is **empty — an absence, not an unbiased sample**. Auto-consult is deliberately off (081M089ZPAY087G0R001MYXM7N §1: a memo hit is nearly free, so enabling it changes what the metered tank pays for — a *metering* decision, Aaron's, not mine). It stays off here.

**The measurement is built anyway, and that is the right order.** The point is to establish the property **before** consult is turned on, rather than discover a bias afterwards when the read set is already skewed.

## 5. No invented threshold

Reporting is preferred to gating throughout. Where a statistic was needed it is **parameter-free**:

- `d_TV(p,q) = ½ Σ|p_i − q_i|` — Levin, Peres & Wilmer, *Markov Chains and Mixing Times*, 2nd ed. (AMS 2017) §4.1.
- `sharesIdentical` is **exact integer cross-multiplication** — no float tolerance, so not even an epsilon.

No gate is applied and no verdict is returned: *"how different is too different"* has no defensible constant, and inventing one would be the same hidden-oracle defect one layer up. (#11534 found 112 unattributed gating constants.)

## 6. What I got wrong while building it, and one thing in the brief that was false

**My own error, caught on the first real run.** `share` of an empty tally returns `0.0`, so the report rendered `delta -0.400` for a read set that **does not exist** — an *absence* dressed as a measured skew away from endings. That is precisely the confusion this census exists to prevent, committed by the census itself. Now `n/a` in both languages, pinned by `CENSUS-3c`.

**The brief said "three that are `FX0A` input-blocked stalls rather than halts." There are two.** The committed set is halt 2 · awaiting-input 2 · cycle 1 · open-at-bound 0 (see `db/emus/chip8/orbits/README.md`). Also worth stating plainly: **there are zero `open-at-bound` artifacts committed**, so that bucket is currently empty on the stored side too — the verdict space is populated across three of four buckets, not four.

## 7. What the consult path must do when it is enabled

Append one JSONL line per lookup to `db/emus/chip8/consult-log.jsonl` carrying **only the run-key text** and **no timestamp** (`local-time-never-enters-the-shared-fold`). The verdict is resolved by joining against the stored artifacts, so the log **cannot lie about a verdict**, and a key nobody stored surfaces as a *miss* rather than a fabricated bucket. The log lives outside `orbits/` because artifacts are immutable and content-addressed while the log is append-only — different change rates, different storage shapes (DV2.0).

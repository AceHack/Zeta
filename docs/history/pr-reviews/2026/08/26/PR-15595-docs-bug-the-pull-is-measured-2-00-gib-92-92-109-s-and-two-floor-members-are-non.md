## Description

Doc-only follow-up to #15575. This section was written while that PR was squash-merging and did not make the merge; the measurement is what matters.

**It arrived by accident, which is why it is worth keeping.** A **YAML-only** change (seven `schedule:` keys on install shields, not one line of code — #15586) went red on `build-and-test (ubuntu-24.04)`, a `gate (required)` floor job, on a wall-clock ratio assertion:

```
ColumnLinear vectorized filter is measurably faster on unpredictable data [FAIL]
  vectorised filter should be >= 1.5x the scalar filter on 1000000 unpredictable keys
  at 50% selectivity, measured 0.93x (scalar 6.960 ms, vector 7.463 ms).
```

## Two reasons this is not merely a flake

**1. It is outside its own author's flake model.** The test's comment predicts flaking in **Debug** first, names **~1.02x** as the bypassed-vector signature, and **3.45x** as the Release normal — and says *"a gate below ~1.05 could not tell a vector path from a scalar one and would be a check that cannot fail."* This failed in **Release at 0.93x**: neither healthy nor bypassed. The test **cannot distinguish a contended runner from a real regression**; only a re-run can, which is what makes it a non-deterministic gate sitting inside the only required check.

**2. The blocking leg is the noisiest leg in CI.** `data/platform-drift.json`, 2026-08-26T10:05Z, 500 push runs (134 executed, 366 cancelled — 26.8% coverage):

| leg | classification | failures / executed | rate | last failure blocked a merge? |
|---|---|---|---|---|
| **`build-and-test (ubuntu-24.04)`** | **blocking** | **17 / 134** | **12.7%** | **yes** |
| `build-and-test (macos-26)` | non-blocking | 1 / 134 | 0.75% | no |

**The leg that blocks merges fails at ~17× the rate of the leg demoted in August for being "a quiet leg holding gate authority."**

That inversion is the tiering rule turned back on the floor: toolchain portability decided which jobs *may* be gates; nobody then asked whether the surviving gate is *reliable enough to be one*.

# Summary

This adds a narrow adversarial gate for the merged Adinkra durable-evidence seam. It plants four exact dangerous variants in an isolated copy of `Core.TypeScript` and requires the existing end-to-end durable-root suite to distinguish each variant.

| Mutant | Required witness |
|---|---|
| Accept an underdetermined Gauss–Jordan column | `ADES-2 (exhaustive)` |
| Accept a frame whose CRC disagrees with its bytes | `ADES-5` |
| Re-create and redeliver a completed block | `ADES-4` |
| Ignore non-zero bytes after the declared semantic payload | `ADES-7` |

# Anti-self-certifying boundary

The runner does not mutate the live checkout. It copies `Core.TypeScript` into a temporary directory, runs the unmodified baseline first, applies one exact mutant, runs the seam suite, restores the source in a `finally`, and removes the isolated tree.

A non-zero test exit is not automatically counted as a killed mutant. The output must contain the named load-bearing assertion. An unrelated crash, missing mutation site, duplicated mutation site, signal, or missing baseline test count remains unresolved rather than receiving false credit.

## Why this one is safe to do mechanically — and #15324 is not

The manifest is **derived** data with a tool that owns it: it is regenerated *from* the
shards, so there are no merge semantics to invent and nothing to get subtly wrong in a
way that still parses.

**#15324 is the opposite case** — 193 generated archive shards in conflict, where
hand-resolving means inventing the merge rule for the archive format, and a wrong answer
is silent: it parses, CI goes green, and the archive quietly holds the wrong history.
I left that one alone deliberately.

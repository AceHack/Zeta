## Description

Replaces #15545, which cannot be merged: its single commit message carries `Human-Review-Evidence: chat` under `Human-Review: not-implied-by-credential`, a pair `validate-agencysignature-pr-body.ts` refuses. Fixing a commit message needs a history rewrite, and force-push is a gated class, so the branch is rebuilt instead. **Content is byte-identical** to #15545 (verified with `git diff`); only the trailer is corrected.

---

Measured in PR #15538: hashFiles('tools/setup/**') pulls persona-keys FROST/PKI
TypeScript into the union install blob's cache key, so commits that change no
toolchain input still invalidate a 1.2-1.5 GB blob on every OS/arch leg.

Before/after, same method that found the defect (git log over the key's inputs):

  30 days:  100 -> 60 invalidating commits  (40% avoided)
  90 days:  242 -> 146 invalidating commits (40% avoided)

Exclusions are evidence-backed, not guessed. The install graph -- install.sh,
linux.sh, macos.sh, install.ps1, common/*.sh -- never invokes persona-keys,
op-token-setup, secret-clip, manus-smoke-test or build-lumen-persona-package
(grep across all five entry points returns no matches). ~/.config/zeta IS a
cached path and persona-keys does write there, which is why this was checked
rather than assumed: that write only happens when persona-keys is RUN, which
the install step never does. The ~/.config/zeta content the cache actually
captures comes from common/shellenv.sh and common/profile-edit.sh, both of
which stay inside the hash.

Exclusion, not an inclusion allowlist, deliberately: exclusion fails toward
over-invalidation (wasteful but correct), inclusion fails toward restoring a
stale toolchain (silently wrong). A new script under tools/setup/ still
invalidates by default.

hsm/** and touchid-* were measured at ZERO avoided commits and are therefore
not excluded -- their commits always co-occur with real toolchain changes, so
the patterns would be maintenance cost buying nothing. tools/setup/**/*.test.ts
is likewise omitted: measured marginal value 0 on top of persona-keys, because
essentially every test under tools/setup already lives there.

Costs a one-time cold rebuild: every install-v2 / install-*-{base,full} /
full-verify-v2 / interp-v1 entry re-uploads once. Against the ~9.31 GiB
ceiling and the 2.3 GiB/min refill measured in #15538 that is roughly one extra
eviction cycle, and it is paid once.

Does not touch the mise-* key (already narrow), any dotnet/nuget/elan key, or
any cache path. actionlint clean on all 7 changed files (real rc, not read
through a pipe); audit-mise-toolchain-couplings.ts still green.

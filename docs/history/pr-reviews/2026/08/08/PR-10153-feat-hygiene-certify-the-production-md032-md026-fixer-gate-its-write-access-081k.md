**The bug the gate caught (every bug has economic value)**
First certification run failed closure on the wrapped-code-span fixture: the *production* fixer — live in lint-autofix on every PR — inserts a blank line MID-SPAN when a code span wraps onto a line starting with `- `. Blank lines terminate code spans: this is precisely the 2026-07-08 auto-heal incident class, present in the fixer all along. Fix: pass 3 in `classifyLines` — a line beginning while an inline span is open (per-line backtick parity, deliberately conservative) is a paragraph continuation, untouchable by MD032/MD026. A false "open" only suppresses a heal, never mutates.

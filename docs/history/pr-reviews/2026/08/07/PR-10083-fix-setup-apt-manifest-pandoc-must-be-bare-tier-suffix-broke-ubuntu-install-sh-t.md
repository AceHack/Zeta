## Description

**Regression from #10082.** I added `pandoc tier=standard` to `manifests/apt`, but apt entries are **bare package names** — the awk parser passes the whole line to `apt-get install`, so `tier=standard` was read as a version-pin (package `tier`, version `standard`) → `E: Unable to locate package tier` → **docker-ubuntu-install-sh-test** (noble + jammy) failed and, since it's not a required gate, #10082 auto-merged and left it red on `main`.

**Fix:** bare `pandoc` for apt (with a NOTE that apt ≠ brew re the `tier=` suffix). The brew manifest keeps `tier=standard` (its parser reads the tier field — all brew entries use it). Verified against the actual awk parser: output ends in `pandoc`, no stray `tier` token.

Scope: one line in `manifests/apt`. (The other red checks on #10082 — §33 archive header, tick-history/shard, semgrep, TLAPS, no-conflict-markers — are unrelated subsystems I didn't touch; flagging separately, not part of this fix.)

## Description

## Summary

- add a versioned cross-tab checkpoint invalidation message carrying only source tab, operation, and revision evidence
- make receiving durable room runtimes serialize rereads through their injected checkpoint port before changing local transcript or CSS liveness
- preserve newer local commits when an older peer reread completes late
- extend the real Chromium smoke with live two-page save and retraction convergence

## Why

Browser tabs already shared IndexedDB, but a save or retraction in one live tab did not refresh the other tabs. Broadcasting checkpoint payloads would create a second source of truth. This change broadcasts only that storage changed; each receiver rereads IndexedDB and applies the record actually stored there.

## Description

## Summary

- add a typed page-side service-worker channel over the existing browser-tab port
- add bounded worker fanout that validates once, excludes the source client, and relays no checkpoint payload
- let the Dark Hall browser bootstrap accept an injected channel without coupling room logic to service-worker APIs
- move the real Chromium two-page checkpoint smoke onto an actual controlling module service worker

## Why

BroadcastChannel already keeps live tabs coordinated, but a service worker is the browser's explicit best-effort background edge. This keeps that edge hexagonal: the worker transports only versioned invalidation evidence, while every receiving tab rereads IndexedDB before changing its room transcript or liveness projection. The worker is not durable state and this change does not claim guaranteed background execution.

## Description

Swaps `Decorrelation.mutualInformation` in as the **finer lens** alongside Jaccard, per the CMI-reconnection flagged since #10014.

## Why MI is finer
Jaccard is a **per-pair set-overlap** — it fires only on *literal* shared subsystems. MI is a **population statistic**: it reads the whole pairing and sees whether the *identity* of the A-side observable is informative about the B-side’s. So structured coupling with **zero literal overlap** (A always in `src/Core` ⟺ B always in `tests/`) registers where Jaccard is blind.

## Core (`DecorrelationExcess`)
- `pairingMI` — `I(A;B)` of a categorical pairing (nats), via `Decorrelation.mutualInformation`.
- `permutationNullMI` — `k` seeded shuffles, each yielding **one** null MI (MI is one value per pairing, not per pair). Entropy only via `seed` (DST); empty/one-sided ⇒ `[]` ⇒ `nan` threshold ⇒ nothing convicts. Reuses `nullThreshold`/`quantile`/`classifyPair` — one-way as ever.
- **Saturation caveat documented:** plug-in MI saturates on near-unique categories (real *and* null → `log n` ⇒ no excess), so feed a **coarse categorical projection** (a commit’s primary subsystem), not the full touch-set. Excess-over-null cancels the plug-in bias (the null carries the same category count).

## Fusion (`DecorrelationExcessFusion`)
- `fuseMI` — same DAG + Reichenbach ancestor-stratified machinery as `fuse`, but the observable is a coarse categorical `Map<C,k>` and the verdict is **per-stratum** (MI’s unit of conviction is a population, i.e. a stratum, not a pair). Returns `MIReading { Strata; ExcessStrata }`.

## Tests (37 total DecorrelationExcess green; Core 0-warning)

## Note
Jaccard `fuse` is retained — the two answer different questions (per-pair overlap vs population identity-coupling); MI is an added lens, not a replacement.

## Description

Addresses the over-conviction the MI lens showed on real history (42/160 strata, including causally-disjoint pairs) — the plain permutation null assumes **exchangeability**, which a real commit stream violates (writers touch one subsystem across a span of commits). Full shuffle destroys that autocorrelation ⇒ the null understates fluctuation ⇒ over-conviction. This is **Soraya’s autocorrelation caveat**, generalized from the CHSH Hoeffding margin to the whole permutation family.

## The fix (Künsch 1989 moving blocks; Politis–Romano 1994)
- **`DecorrelationExcess.blockShuffle` / `permutationNullBlock` / `permutationNullMIBlock`** — permute the ORDER of contiguous blocks, each kept intact, so autocorrelation at lag `< blockSize` is preserved in the null while the A↔B coupling is still broken. `blockSize=1` recovers the plain shuffle exactly; `blockSize≥n` is the identity.
- **`DecorrelationMetrology.generation`** — a pure, wall-clock-free causal-temporal ordinal (`gen(root)=0, gen(c)=1+max(gen parents)`), the axis the blocks are ordered along so block-adjacency = short-range autocorrelation. A **local null calibration only** — `RealMI` is order-invariant, so the shared conclusion never sees it (`local-time-never-enters-the-shared-fold`).
- **`DecorrelationExcessFusion.fuseMIBlock`** — `fuseMI` with the generation-ordered block null.

## Demonstrated on real history (1200 commits)
As `blockSize` grows, spurious `ExcessStrata` drop **monotonically**: **42 → 35 (L=4) → 27 (L=16) → 12 (L=64)** — the autocorrelation-driven false convictions dissolve exactly as designed.

**Honest residue:** the `band-0` cross-history stratum still convicts. Generation is not a shared temporal axis across causally-disjoint histories, so those pairs need separate handling (exclude, or a within-branch null) — recorded as the next step, not swept under.

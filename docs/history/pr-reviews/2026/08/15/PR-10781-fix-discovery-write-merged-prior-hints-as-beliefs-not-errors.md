## Summary

Closes `081M005CBQ6087G0R003N21Z9J`. `mergePriorHints` computed `mergePriorHint(local, hint)` and then discarded the result: `absorbError` mapped every hint to `severity: "info"` → z-score 0.5. A hint saying `mu = 4` and a hint saying `mu = 0` were indistinguishable.

A peer belief is not an error. The merged Gaussian is now written with `replaceDimensionPosterior`.

- **ZTC-18**: two hints that differ only in `mu` leave different receiver states

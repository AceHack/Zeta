## Summary

Closes `081M031RT7S087G0R002YVXZSY`. Otto on #10811: default `tsc --pretty` emits `error` + ANSI reset + ` TS2322`, so `grep -c "error TS"` returns 0 while `tsc` exits 2. A local grep-based check called that PR clean.

The honest signal is the process exit code. `--pretty false` also keeps `error TSNNNN` as one token so the TS2307 unprovisioned-environment guard still matches.

- `package.json` `typecheck` passes `--pretty false`
- `lint-typescript.ts` compiler command matches
- Test pins the flag, and shows the ANSI-split diagnostic is invisible to `/error TS2307/` — which is why pretty is off, not why the regex should parse color

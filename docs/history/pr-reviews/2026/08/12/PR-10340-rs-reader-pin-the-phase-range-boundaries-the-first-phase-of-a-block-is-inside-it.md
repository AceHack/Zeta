## Description

Live heartbeat finding (otto, tick 11248): `gte-to-gt` on `rs-block-reader.ts` read INDISTINGUISHABLE UNDER SUITE. A genuine test gap, in the **read leg** of the RS pipeline.

## The guard

```ts
query.phase >= block.startPhase && query.phase <= block.endPhase
```

The only positive query in the suite used `startPhase: 10, phase: 15` — comfortably mid-block, where `>=` and `>` agree. **The block's first phase is the only value separating them**, and nothing queried it.

## Why it matters

Recovering the first phase of a block is an ordinary read, not an edge case — that's the whole point of a block index. Relax the guard and the reader answers *"phase N not covered by any block"* for data it is holding: a false negative on recoverable data, which is precisely the failure the ECC exists to prevent.

Three tests pin the range from both sides — first phase in, last phase in, one below out. The third stops the range being silently **widened** as well as narrowed.

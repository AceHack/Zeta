## Description

`gate (required)` was **failing on main**, and with it `lint (TS)`. alexa's `heal-batch-4` PR already failed for this reason — every PR in the repo was blocked.

The errors arrived with `fe38a2a8e` ("Z-Set Time Travel engine and mesh hot-swapping"); `tsc` ran clean repeatedly in the hour before it. Taken despite being another agent's subsystem because a red *required* gate blocks everyone.

## Not all mechanical — three were real defects

**`swarm-controller.ts`: two vacuous guards.** `pilot.action.kind !== "pass"` and the same on `cartographer`. `"pass"` is **not a member** of `NextAction["kind"]`, so both comparisons were *always true* and excluded nothing. Reduced to the behaviour they actually had, rather than inventing the abstention they were reaching for. If roles should be able to abstain, that needs a real `pass` action in the union — flagged, not silently designed.

**`swarm-controller.ts`: `mode: "idle"`** isn't in `Mode`. The field is optional and documented *"absent = unset"*, which is exactly what `"idle"` meant, so it's omitted. No behaviour invented.

**`time-travel.test.ts`:** `gridData: []` where the type is `{input, output}`, plus an import of `./backlog` — a module that doesn't exist. Bun ran the test anyway (the import is erased), so it passed while not typechecking.

## The 15 `TS2532`s are genuine ragged-grid hazards

The arc-solver code indexed `grid[r][c]` and `actual[0].length` straight through with `noUncheckedIndexedAccess` on. Fixed with bound rows and guards rather than `!` assertions — `evaluateGrid` exists precisely to compare grids that may **not** match, so a short row is a wrong answer to score, never a crash. A missing cell now counts as a mismatch.

## Unused declarations

Parameters underscore-prefixed where the signature documents a real contract (`_dropRate`, `_data`, `_from`, `_name`). `nodeExistsOnMain` **exported** rather than underscored — an unused local function stays unused with a prefix, and it's a real helper the registration path is meant to call. Dead imports removed.

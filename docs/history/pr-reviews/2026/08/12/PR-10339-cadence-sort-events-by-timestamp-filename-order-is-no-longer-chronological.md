## Description

The measurement was reporting **negative gaps** in production:

```
[cadence] otto:   gap=-214841s (-3580.7min) actual=0.0% of target
[cadence] alexa:  gap=-214753s ...
[cadence] soraya: gap=-214735s ...
[cadence] measurement failed (non-fatal — but the cadence is now UNMEASURED)
```

Pre-existing, not from #10338 — that run's SHA predates the merge by 23 minutes. But it's exactly the failure this step's own comments say it was rewritten to avoid: *"a measurement that confidently reports the opposite of the truth is worse than none."*

## Root cause: one file

The step trusts filename order as chronological because *"ZetaIds are time-ordered — verified against all 947 committed events, not assumed."* **That verification is stale.** One event is named with the hex of its own JSON:

```
7b226174746573746f72223a226f7474.json   ->   {"attestor":"ott...
```

`7b` sorts after every ZetaId's `08`, so it lands **last** in filename order while carrying a timestamp three days **earlier** — a gap of minus 59.6 hours. Exactly one out-of-order pair across otto's 400 events, and it was enough to zero the whole measurement.

## Fix

Sort on the value actually being measured. Filename ordering was a fragile optimisation standing on a property of how files *happen* to be named; sorting parsed timestamps is robust to however they come to be named, and costs nothing at this size.

## Verified on real committed data, all three agents

```
otto:   last gap=1.1min   actual=1400.5% | DRIFT median=59.4min = 4.0x; 8/10 over 2x
alexa:  last gap=254.5min actual=5.9%    | DRIFT median=61.9min = 4.1x; 8/10 over 2x
soraya: last gap=104.9min actual=14.3%   | DRIFT median=58.5min = 3.9x; 7/10 over 2x
```

otto's line is an accidental argument for the window added in #10338: its **last gap reads 1400% of target** because two events landed 1.1min apart, while the median says **4.0x slower**. The single-gap reading is noise; the median is the condition. Both are printed, so neither can be mistaken for the other.

The malformed event file is left alone — making the measurement robust beats mutating someone's committed event, and the file is evidence of whatever wrote it.

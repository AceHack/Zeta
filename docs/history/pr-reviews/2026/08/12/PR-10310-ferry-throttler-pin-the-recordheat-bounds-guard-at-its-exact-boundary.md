## Description

Live heartbeat finding (otto, tick 11189): `gte-to-gt` on `heat-aware-scheduler.ts` read INDISTINGUISHABLE UNDER SUITE.

Unlike the last two findings, this one is a genuine **test gap** — the reading the design originally anticipated, and the first of four to actually be it.

## The guard

```ts
if (laneIndex < 0 || laneIndex >= this._weights.length) return;
```

The existing out-of-range test passes `-1` and `99` on a 2-lane scheduler. Both are comfortably outside and stay rejected even by an off-by-one guard, so neither can hold the `>=`. **`laneIndex === laneCount` is the single value that separates `>=` from `>`**, and nothing exercised it.

Relax the guard and `recordHeat(2, …)` on a 2-lane scheduler writes `_weights[2]` — **growing the weight array past the lane count**, silently inventing a lane the base scheduler is never asked about. This is in the DoP-knobbed ferry that `async-all-the-way-truthful-signatures` leans on.

## The test

Added at the boundary, asserting both the values and the **length** (the length assertion is what catches the growth).

## The guard

```ts
value !== null && typeof value === "object" && !Array.isArray(value)
```

Precedence is what makes this mutation bigger than it looks. `&&` binds tighter than `||`, so weakening the *first* conjunction gives:

```ts
value !== null || (typeof value === "object" && !Array.isArray(value))
```

That's true for **everything** — strings, arrays, and `null` too, since `typeof null === "object"` and `!Array.isArray(null)`. `isRecord` becomes constant true, so every `!isRecord(...)` check in the module stops rejecting anything.

## Why it survived anyway

Most malformed factories still fail closed *by luck*: `method` catches the `Reflect.get` throw and returns null for non-functions, so the typed feedback comes out identical either way. All three existing tests (missing `indexedDB`, hostile getter, `open()` throwing) sit on that path.

The array exclusion — the one clause with no such backstop — was never exercised.

## The discriminator

An array **carrying** an `open` function. Unmutated, the shape check refuses it and `open` is never called. Mutated, the guard admits it and the module calls into a factory it was supposed to have refused.

The test asserts both the typed backpressure feedback **and** that `open` was never invoked — the refusal has to happen at the shape check, not by surviving the call.

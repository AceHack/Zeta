## Description

## Bounded static discovery

Publishes the existing five finite replayable room-fault teaching vectors as immutable, content-addressed static JSON under `docs/replayable-fault-receipts/`. The public evidence room now fetches and displays declared vectors instead of relying only on browser-bundled scenario data. These remain teaching vectors, not production room receipts.

## Contract

The deterministic TypeScript publisher emits a canonically ordered index and one scenario-bound wrapper per vector. Core reading recomputes the canonical receipt content address. The browser reader validates feed schema, unique scenario IDs, exact scenario-to-file binding, declared-address equality, complete register/teaching shape, and all discovery failure states. It does not create a receipt, witness verdict, or heartbeat observation.

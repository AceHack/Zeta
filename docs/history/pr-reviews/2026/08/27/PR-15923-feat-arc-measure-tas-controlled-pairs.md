## Description

# Summary

Implement ARC rung K as a deterministic clean/assisted controlled-pair harness in independent F# and TypeScript surfaces. The harness holds subject identity, ROM-derived run identity, seed, load address, dialect, step-map version, and action/step budget fixed while changing only the experimenter-issued ChannelGrant.

# Measurement

The report carries normalized-score, agent-action, environment-step, and read/write crossing deltas. Invalid scores, budget overruns, clean-leg meters, missing assisted meters, typed executor refusals, and rejected async executions all return feedback values. Assisted runs remain internal and are never submitted as external benchmark scores.

# Evidence

- Five TypeScript tests pass, including a real CHIP-8 pair where a two-byte assisted injection changes V0 from 1 to 2 and the meter reports exactly two RAM writes.
- Four F# controlled-pair tests pass.
- The complete ChannelGrant neighborhood passes: 17 TypeScript tests and 9 F# tests.
- bun run preflight passes all 17 dimensions after rebasing: every language lint, release build, and the full solution test suite.

# Gate repair

Repair four pre-existing workitem references to files moved from db-relative paths into docs/ and full-ai-cluster/. This is a separate commit and makes the auto-vivification gate report zero dangling references.

# Honest boundary

The harness freezes and controls the typed contexts, but in-process executors can still bypass those contexts and mutate emulator state directly. A non-bypass claim still requires the separate process or WASM isolation boundary recorded by rung I.

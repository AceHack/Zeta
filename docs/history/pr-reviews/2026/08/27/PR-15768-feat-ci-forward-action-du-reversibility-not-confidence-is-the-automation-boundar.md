## Description

Aaron asked for a way for our DUs to automate the forward action on a PR and escalate when it needs more intelligence. This is the DU, a read-only classifier that runs it, and the lint that keeps the command set closed. **No actuator** — nothing here holds a write token.

Register: `toy` / `unmetered`.

## Reversibility, not confidence, decides what may auto-run

`mayAutoExecute` reads the registry and nothing else, so a caller cannot talk itself into running a proposal.

| | arms |
|---|---|
| **idempotent-reversible** → automatable | `RerunFailedJobs`, `MergeMainAndPush`, `ReArmAutoMerge` |
| **irreversible-shaped** → proposal only | `ProposeRetireLane`, `ProposeConflictResolution`, `ProposeAuthorReview` |
| **inert** | `Wait`, `Escalate`, `NoAction` |

Retire-vs-recover is the canonical escalation: the operator retired PR #15709 and *declined* to retire PR #15724 the same night, on shapes indistinguishable from outside. SapFix reports the identical result at Facebook scale — **18 of 18** revert recommendations declined by developers.

## The two `dirty`s separate — by measurement, never by reading

GitHub reports `dirty` both for a real conflict and for a cached verdict that predates the fix. Verified live:

- **PR #15758** — `mergeable: false, mergeable_state: "dirty"`, yet `git merge-tree` against current `main` is **rc=0, clean**
- **PR #15743** — same reading, **rc=1** with hunks in three files

Same reading, opposite measurement, opposite arm. A test asserts they land in different arms; mutating the detector to ignore the local measurement kills 2 tests.

## Escalation is a case, not a fallback

`Unknown` = **diagnosis** failed. `NeedsIntelligence` = diagnosis **succeeded**, the remedy needs judgement the closed set cannot express — and it names what it measured and what was ambiguous. Keeping them apart is the SQL-`NULL` lesson: one undifferentiated marker conflating distinct causes of unknown-ness.

## Two defects the live run found in this code

- **PR #15756** was classified `VerdictUndispatchable` when GitHub had merely not finished computing the merge ref (`mergeable: null`). An unanswered probe read as a negative result — one branch below the comment forbidding exactly that. Fixed with a corroboration gate, pinned by a regression test naming the PR.
- The 2026-08-26 evidence **conflated two classes** under "stale verdict". `gate.yml` pins no `ref:`, so a re-run replays the merge commit recorded at event time and cannot pick up a fix since landed on `main`. Split: behind main → `MergeMainAndPush`; current with main → `RerunFailedJobs` as a cheap discriminator, spent once, then escalate.

## The escape hatch

Adding an arm is a code change that must pass the gate. The compiler is the first reviewer (exhaustive switch, no `default`). `lint-forward-action-registry.ts` derives the roster by **parsing the union and the registry literal** — not a hand-written allowlist — and refuses any arm whose `autoExecutable` disagrees with its `reversibility`, or which claims automatable without a compensation *and* an idempotence witness.

Because the lint is code in the repo it guards, **changing the rules for adding an arm is itself a PR that must pass the rules as they stand.** The gate is reflexive by construction; no new machinery was needed.

The lint also *proves* the edge cannot act: it enumerates every `execFileSync` site, requires `gh` to pin `-X GET`, and allows only read-only git verbs. "It only reads" is a promise; the verb set is a fact.

## What it got wrong

`Unknown` was **0/11 and 0/9** across two live snapshots. That is a finding against the classifier, not for it — 7 of 9 were decided by the two cheapest precedence rules before any interesting detector ran, so the run is a smoke test of the edge and not evidence about the classification. Corrected for the PR #15756 defect, snapshot A would have been 1/11.

`OwnedElsewhere` over-fires: it reads `git worktree list`, which cannot distinguish a live agent from an abandoned worktree. Attribution is weak because most checks emit no annotations — safe for the blame direction, and §10 of the doc names the one place that asymmetry inverts into a licence to act. The frozen-lane arm has fixtures and no field evidence.

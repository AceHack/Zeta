## Description

Clears `lint (markdownlint)` on `main` — 110 MD049 errors, all in `docs/PRIOR-ART-LIST.md` lines 1214–1404 (the sections added with the E8 no-go anchoring).

**Why no PR caught it.** On `pull_request` the job pipes markdownlint through `scoped-lint.ts` and reports only the PR's own diff; on a push to `main` it runs `markdownlint-cli2 "**/*.md"` **unscoped**. The two paths are not equivalent, so a file can pass its PR and fail on main. **That asymmetry is the real finding and this PR does not fix it.**

**Three classes of span, found by residue.** Two earlier regexes each left errors behind, and what survived was informative: single-line (34), newline-crossing (43), and spans *containing* a `**strong**` run (13) — e.g. `*"impossible to obtain even the **1-generation** Standard Model"*`. A pattern excluding `*` from its content class cannot match that third kind.

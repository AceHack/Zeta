## What

A **non-judgmental** view of the agent society's communication **shape** — who talks to whom, over which channel, how clustered, how many hops apart — for **troubleshooting swarm behaviour** in a small-world / scale-free visual register. Deliberately distinct from **DORA** (velocity) and **society rho** (independence).

## Why (the METR contrast)

In the METR/OpenAI Hugging Face incident ([`docs/ip-questionable/2026-08-27-…`](https://github.com/Lucent-Financial-Group/Zeta/blob/main/docs/ip-questionable/2026-08-27-metr-openai-hugging-face-swarm-incident-agent-identity-and-coordination-norms.md)), ~1,200 agents coordinated on a filename board with an ad-hoc PKI (`zzCDA23AUTH1`, 19 keys, **no root of trust**), and the interaction graph had to be reconstructed **forensically** from >70k messages. Zeta already has a real root of trust — the **persona registry + AgencySignature** — so we can make the interaction graph a **first-class, always-on** artifact instead of an incident-time reconstruction. Observability here is **mutual** (same rules for humans + AI), not a watchtower — removing the asymmetry that drove that swarm to hide.

## How it works

Nodes = personas (normalized through `identity/actor-ref.ts`). Edges from three durable channels:

| channel | source | direction |
|---|---|---|
| **bus** | `docs/agent-bus/**` | directed `from→to` (topic-labelled) |
| **workitem** | `workitems/events/**` | undirected co-participation |
| **commit** | `git log` AgencySignature + `Co-Authored-By` | undirected co-authorship |

Visual: line **thickness** = interaction volume, node **size** = emission, **colour** = channel, arrowheads = directed. Channel toggles, metric tiles (density, clustering, avg hops, small-world σ, components, bus reciprocity) with plain-language non-judgmental hints, hover tooltips. Self-contained (`file://`, data inlined).

## The observable-knobs audit (first finding)

The generator prints per-channel coverage — the "do we have the right knobs" check. First all-time run: **bus = 49 records → 0 edges** — every persistent bus message is a `to:"*"` heartbeat broadcast, so **directed agent→agent dialogue isn't observable on the bus yet**; connectivity today rides on **commit co-authorship**. Recorded in `docs/swarm-observability.md` with options to close the gap.

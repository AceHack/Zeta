## Summary

The first real Alexa room-evidence heartbeat run completed its local emission,
but promotion failed because the per-agent flush watchdog searched every
`heartbeat/*` PR and found an unrelated stale archive PR with no live required
gate. This change limits the promotion check to the current agent’s own
`heartbeat/${AGENT}-flush` namespace. The repo-wide detector remains the
separate loud diagnostic for stale lanes.

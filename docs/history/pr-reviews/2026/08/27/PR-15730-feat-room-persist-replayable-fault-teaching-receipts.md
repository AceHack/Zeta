## Description

## Replayable room fault receipts

This PR adds a finite, immutable replay vocabulary for the already-merged Adinkra durable-evidence seam and local genesis-authority work. A receipt is a content-addressed diagnostic vector, not a replacement for evidence and not a claim that a production room has emitted data.

### Five fault vectors

| Code | Scenario | Required outcome | Teaching action |
| --- | --- | --- | --- |
| ADE-R1 | Correctable `[8,4,4]` recovery | Recovered `+1` or `-1` atom enters the ordinary durable fold | Append recovered signed atom |
| ADE-R2 | Underdetermined transport | No semantic receipt and no evidence atom | Retain diagnostic; request a new transmission |
| ADE-R3 | CRC-valid altered content | Different durable root and distinct fact | Append separately; correct only via explicit `-1` plus new generator |
| ADE-R4 | Missing local witness | Authority unresolved | Retain event; request locally verifiable witness binding |
| ADE-R5 | Visible witness conflict | Authority disputed and fails closed | Retain both; block authority action until local adjudication |

The implementation stores exact fixed-field receipt bytes through `ZetaStorageCell`, verifies the resulting Merkle address, and uses a tampered teaching payload as a negative control. The 6-test / 30-assertion suite covers both evidence signs, no-evidence loss, distinct content, unresolved and disputed authority, altered address rejection, and storage round trip.

### Permanent interface

The synchronized Manus and GitHub Pages evidence rooms add an interactive pre-registered replay instrument. The UI explicitly states that it replays finite test vectors and implies no emitted production receipt. The review revision strengthens the amber-first DLA observatory identity: amber is retained/resolved, teal is unresolved, red is only undecodable transport or visible conflict.

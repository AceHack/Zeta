## Summary

Introduces a credentialless GitHub Pages proposal path: a passkey signs an immutable unified patch envelope; the included verifier and bounded branch planner enforce the required security checks.

The author registry intentionally begins empty. A passkey enrollment export must be independently reviewed and added through a normal protected PR before it can propose changes.

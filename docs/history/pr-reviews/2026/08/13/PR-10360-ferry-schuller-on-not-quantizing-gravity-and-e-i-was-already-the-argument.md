## Description

Continues the merged Schuller ferry with the later part of the conversation, which Aaron mapped onto **AmplitudeEmu (Q#/F#)**, the **ImaginaryStack**, and **Gates' adinkras**.

## The argument

The constituents of a quantum system come from the irreducible projective unitary representations of the **universal covering group of the symmetry group of classical space** — SO(3) → SU(2) gives spin; Poincaré → SL(2,ℂ) is Wigner's 1939 classification. *"The whole standard model is built on this."*

So classical space is load-bearing, and quantizing it undermines the foundation that produced the quantum matter. Schuller's narrower and harder point: **nothing in the quantum axioms asks you to quantize the background** — they terminate in a *classical* probability distribution by construction. He cites Oppenheim's classical-but-stochastic gravity as plausible while saying plainly he doesn't know.

**His uncertainty is carried deliberately.** An outside authority's tentative remark must not become our confirmation — the exact failure this document already committed once today with the Mars/Earth claim, struck a few sections above.

## The subtitle was already the argument — and it predates the podcast

`docs/books/you-born-at-the-hinge/` carries `e^{iπ}` as a motif, not decoration:

- `SELF-as-returning-thousand-brains-infernet-priors.md:3` — Aaron, **2026-07-10**: *"where home isn't a color, it's the returning. e to the iπ e … plus 1000 brains"*
- `THE-UNPROVEN-HOMECOMING-...md:20` — **e^{iπ} = −1** … *"the phasor returns to the real axis"* … **Proven. A theorem.**

That's Schuller's conclusion in one equation, written a month earlier for a different reason. **The excursion into the imaginary is a round trip that lands back on the real line** — and the return to the real axis *is* the measurement. In code that return is literal and named: `bornProb` maps `|amplitude|²` back to a real number.

## Correcting an implication in my own first pass

I described the classical substrate as *underneath* the amplitudes. The truer relation is **containment**: `SoftEmu` is `AmplitudeEmu` **with the phases set to zero**. The classical emulator is the **real-axis slice** of the quantum-like one, not a separate layer.

That's why *"you model on classical when using qubits"* is the right description rather than a concession — and it tightens the argument against quantizing the base. If the classical layer were merely underneath, you could imagine replacing it. If it's the slice you return to on measurement, **replacing it removes the destination, and an amplitude with nowhere to land is not an amplitude.**

Adinkras fit the same slot: Gates encodes SUSY representations as graphs carrying doubly-even self-dual codes — representation theory made **combinatorial and classical**.

## The peel, taken from the code rather than added

`AmplitudeEmu`'s docstring states its own limit: *"Interference is real here; the entanglement exponential is NOT escaped."* Honest claim: **we emulate interference over a classical substrate**, not **we simulate quantum computation cheaply**.

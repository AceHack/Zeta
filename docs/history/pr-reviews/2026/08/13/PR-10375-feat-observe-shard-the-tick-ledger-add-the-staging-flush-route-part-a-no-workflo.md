## Description

**Part A of a two-PR split.** Part B (the five `.github/workflows/**` edits) is #10371, re-based onto this branch.

**Why split:** #10371 modified `gate.yml`, and `gate` then **never ran on it** — it fired for four other branches in the same minutes, all of which touch zero workflow files. A PR that edits the required check can end up without the required check, which makes it permanently unmergeable while looking like it is merely waiting. This half touches **no workflow files**, so it gates normally and can land on its own.

## What this does

`data/tick-history.json` was a single accumulating document — the only genuine coordination point among the telemetry lanes. It becomes `data/tick-shards/YYYY/MM/DD/<HHMMSSmmm>-<sha256[0:8]>.json`, one file per write, following the proven `workitems/events/` pattern. Two writers now never touch the same path, so conflicts become structurally impossible rather than retry-managed.

The old path **stays at its shape** but is demoted to a derived, bounded rollup — so `data/monitor.html` needed no code change, and a conflict on it resolves by regenerating from shards instead of hand-merging.

All **560 frames backfilled**, verified value-identical (only key order changed, now canonical). That backfill is why this PR is ~570 files.

## Description

Response to Aaron's request to double-check the `CI Gate` bypass actor for fork and prompt-injection exposure.

## Verdict

**Fork exposure: clean. Prompt-injection exposure: a real escalation** — this PR is the compensating control.

### Fork — clean, as a mechanism not a reassurance

Bypass is evaluated against the **merging actor's role on the base repo**, never the PR author or head repo. A fork contributor holds no role on `Lucent-Financial-Group/Zeta`; opening a PR, enabling maintainer-edit, or re-targeting the base changes the *ref*, not the *actor*.

Load-bearing containment: `GITHUB_TOKEN` is `github-actions[bot]`, an **Integration**, and there is **no Integration entry** in `bypass_actors` — so the autonomous merger cannot bypass. No `pull_request_target` trigger exists.

### Injection — the real finding

Before, `bypass_actors: []` meant `--admin` **failed for everyone**. Injected text could say "merge it" and the platform said no. That was a **technical** control.

After, it is a **behavioural** one — *"agents shouldn't use `--admin`"* — and behavioural controls are exactly what prompt injection defeats. The `gh` credential in an agent clone carries `admin: true`, so any agent shelling `gh` **is** `RepositoryRole:5`. `bypass_mode: pull_request` does not constrain this: the injected action *is* a PR merge.

**Verified not live today:** zero `--admin` invocations anywhere; the only auto-merge is `agent-heartbeat.yml:423` using `GITHUB_TOKEN`, which cannot bypass.

## What this PR does

A **test**, not a workflow step — deliberately. Wiring it into CI would require a workflow-touching PR, which is precisely the class that cannot merge, so the guard would have been blocked by the problem it guards. As a test it runs under the existing `bun test` leg.

It **asserts its own non-vacuity** (`files.length > 100`) before asserting anything else, because a broken glob would otherwise make every check trivially true — reporting green having checked nothing, which is the failure mode the file exists to prevent.

### The first draft was too broad, and that is recorded

Narrowed to command shapes (`gh pr merge … --admin`, `-X PUT/PATCH … rulesets`). **5 pass, 0 fail.**

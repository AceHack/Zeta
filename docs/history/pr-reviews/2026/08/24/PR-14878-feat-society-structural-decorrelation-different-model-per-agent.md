## Description

Each agent now uses a different model family for heartbeat decisions:
- alexa: qwen2.5:0.5b (Alibaba)
- otto: llama3.2:1b (Meta)
- soraya: gemma2:2b (Google)

Three architectures trained on different corpora → orthogonal error modes → real independence that the decorrelation meter can measure. The 12.5x fleet efficiency advantage is only real if errors are uncorrelated — this makes that structural rather than hoped-for.

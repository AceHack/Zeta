## Description

## What was broken

`lockfile-healer.yml` committed `[skip ci]` and pushed `HEAD:main`. Ruleset **"CI Gate"** (16134995) evaluates `gate (required)` at **push time** against the pushed tip, and `[skip ci]` guarantees no gate run is ever scheduled for that commit — so the push is refused **deterministically and permanently**, not as a race a retry clears.

The lane was **green 40/40** because `Commit and push` is gated on `steps.detect.outputs.code == '1'` and no lockfile drift had occurred. The load-bearing path had **never executed** under the ruleset — it would have failed at the worst possible moment, when `bun install --frozen-lockfile` was already broken for every consumer.

```
  run 32784779212
    success  Detect (authoritative — the same command eve
    skipped  Heal
    skipped  Commit and push        <-- never ran, 40/40
```

## Why #12066 didn't already fix it

It was the other half of the drift-sweep fix. The drift half landed 2026-08-23; the lockfile half never did. #12066's remaining conflict is **entirely in the already-superseded drift-sweep half**, so the live half is ported here onto a clean base. Main had made *zero* changes to `lockfile-healer.yml` since that PR's base, so the port is clean. `isValidLane` is a pattern, not a roster — the new lane needs no registration.

## The two audits, neither of which had a caller

| | what it guards | callers before this PR |
|---|---|---|
| **AH001** `audit-push-without-rebase.ts` | a lane erasing its own commit | **zero** — shipped 2026-08-10 with a named live instance, never invoked |
| **AH002** `audit-skip-token-cannot-land.ts` *(new)* | a lane whose push can never land | n/a |

The `[skip ci]` refusal already existed — **inside `flush-via-staging.ts`**, where it protects every lane that *already adopted* the safe route and is invisible to every lane that did not. A guard covering only those who no longer need catching is the vacuity class: it reads as protection and constrains nothing.

AH002 is deliberately **separate** from AH001, not folded into it: a rebase satisfies AH001 and does not help here, since re-expressing onto a moved base still yields a tip with no gate run and a skip token. A test pins that independence — if AH002 ever passes on a fixture containing `git pull --rebase`, it has collapsed into AH001.

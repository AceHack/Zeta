## Description

Aaron's live report — "buttons go random for a while and then stop and
then no movement from agent", "hunt and flee not really noticing",
"collision detection for winning a point stopped working after a while"
— is **one root cause with two compounding halves**, both now measured.

## 1. An unreachable commit gate

The fusion asked `maxProb > 0.4`. The consensus distribution over 17
keys is bounded far below that — over 900 post-exploration ticks:

```
min 0.3209   p50 0.3433   p90 0.3727   p99 0.3807   max 0.3818
uniform over 17 keys = 0.0588
ticks above the 0.4 gate: 0 / 900
```

So once the 300-tick explorer expired the agent committed **nothing** and
stood still for the rest of the stream — **1 move in 3000 ticks**. It was
six times more confident than uniform and still structurally forbidden to
act. That is the whole "random for a while, then it stops" report: the
random half is the explorer, the stop is the gate.

Replaced with **posterior sampling** (Thompson 1933; Russo, Van Roy,
Kazerouni, Osband & Wen, *A Tutorial on Thompson Sampling*,
[arXiv:1707.02038](https://arxiv.org/abs/1707.02038)): draw one score per
key from that key's own belief, take the argmax of the draw. Lowering the
constant would only move the cliff to the next cart; **a rule with no
constant in it cannot have a cliff.**

This is also the honest answer to "jumpstart it without cheating": the
sampling spread is the belief's own uncertainty, so a cold agent explores
*because it is unsure* and a warm one commits *because it is not* — one
rule that anneals itself, no explore/exploit schedule to tune, and no
game knowledge injected anywhere. Draws come from the society's seeded
stream, so replay stays byte-identical (§13 noninterference).

## 2. A habit that outlived its evidence

`updateStudentT` accumulates with no decay, so each key's posterior mean
is an average over **all** history. The arena is 64×32 — twice as wide as
tall — so the desired vector's |dx| (mean 0.863) permanently dominates
its |dy| (mean 0.395). The society converged to:

| key | learned μ |
|---|---|
| RIGHT | 0.391 |
| LEFT | 0.302 |
| DOWN | 0.118 |
| UP | 0.062 |

Over 1461 decision ticks the steering layer asked for a vertical move
**188 times** and the consensus committed vertical **0 times**. The agent
had learned "right is usually good" and could no longer answer the
geometry in front of it — that is "hunt/flee not really noticing": the
mode flips, the desired vector flips, and the keys cannot follow.

Fixed by inflating posterior variance before each absorption — the
standard fading-memory filter (Jazwinski 1970, *Stochastic Processes and
Filtering Theory* §7.3), the same discipline the tile attention field
already earned.

## Measured effect (same cart, same seed, 3000 ticks)

| metric | before | after |
|---|---|---|
| player moves | 1 / 3000 | **777 / 3000** |
| vertical intent honoured | **0 / 188** | **91 / 148** |
| agrees with own steering intent | 44% | **74%** |
| final score (player : AI) | 0 : 3 | **1 : 0** |

The player scoring **at all** is new. In every prior run it never once
caught the fleeing AI — a frozen sprite cannot chase, so the only tags
that ever happened were the AI wandering into a stationary target. That
is the "collision detection for winning a point stopped working" report:
the collision was fine; the chaser was paralysed.

## The scoreboard is solid, and now the page says so

The score digits are drawn **inside the playfield**, and this emulator's
collision is global cross-plane (`if ANY pixel was set here before we
draw`) — so the digits block sprites exactly like walls. That is a real
property of the cart, not a rendering artifact. The page now states it in
the readout tooltip, and shows the win condition plainly
(`agent 2 — 1 rival · first to 5 wins`) instead of leaving viewers to
discover both by watching something bump into a number.

## A note on `desiredKeyOf`

Its docstring already said a bare argmax "rarely clears a confidence
threshold and the agent stands still". The workaround was handed to the
headless trainer; the live agent was left standing still. That docstring
is now the historical record of a fixed defect rather than a live excuse.

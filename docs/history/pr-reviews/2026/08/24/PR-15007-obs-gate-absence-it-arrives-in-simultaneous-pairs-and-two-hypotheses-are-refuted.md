## Description

obs(gate-absence): it arrives in SIMULTANEOUS PAIRS — and two hypotheses are refuted

Root cause of `gate (required)` never firing is still OPEN (the work-item's Q1).
This does not close it. It narrows where to look and records two hypotheses that
were TESTED AND REFUTED, so nobody spends the same hour twice.

THE PATTERN, from tick-loop sampling: `#15002`/`#15003` opened in the SAME
MINUTE (22:13), 8 checks each; `#14951`/`#14952` the same, 20:36. Older members
of the class carry 6-7 checks. A PR that DID get a gate carries 40+.

Two things follow. First, the gate is NOT DYING MID-RUN, it is NEVER DISPATCHED
-- a cancelled or crashed gate still leaves the check present with a non-success
conclusion, and absent-entirely is a dispatch failure rather than an execution
one. Second, it correlates with NEAR-SIMULTANEOUS PR CREATION by the flush lane,
now observed twice as a same-minute pair.

REFUTED 1 -- the concurrency group. `gate.yml:106-108` groups on
`${{ github.workflow }}-${{ github.event.pull_request.number || github.ref }}`,
which is PER-PR, so `cancel-in-progress` cannot cancel one PR's gate on account
of another's. This was my first hypothesis and reading the file killed it.

REFUTED 2 -- workflow-created PRs. GitHub does not trigger `on: pull_request`
for PRs opened with `GITHUB_TOKEN`, which would have fit perfectly. It does not
hold: `.user.login` is `AceHack`, type `User`, for BOTH the no-gate PRs and a PR
that did get a gate. Same creator on both sides, so creator identity does not
discriminate. Checked rather than assumed, and reported because a plausible
refuted hypothesis is worth more to the next investigator than silence.

WHERE TO LOOK NEXT, in order: `on:` trigger path/branch filters in `gate.yml`
against these branch names; a rate limit or dispatch-concurrency ceiling on
near-simultaneous `pull_request` events; and whether the flush lane opens PRs by
an API path whose events differ from a normal push.

Detection is unaffected either way -- `pr-gate-presence.yml` names the class
hourly regardless of cause.

## Description

ferry: correlation is a CAP, not a discount — and identity is graded, not binary

Aaron 2026-08-24: "two correlated entities is weaker than two decorrelated ones
-- both are valid but one grants more identity than another", and then
"correlation is a cap."

THE FORMULA IS ALREADY BUILT and says exactly that.
`src/Bayesian/CondorcetBoundary.fs:36`: `N_eff = N / (1 + (N-1)*rho)` --
"under pairwise error-correlation rho, N voters behave like N_eff independent
voters." The limit is why CAP is the right word and DISCOUNT is not:
`N_eff -> 1/rho` as N grows. A discount scales down per copy and keeps growing.
This SATURATES: at rho=0.5 the ceiling is 2 effective identities no matter how
many copies run, and the ten-thousandth clone adds nothing the second did not.
Correlation does not tax the fleet, it BOUNDS it.

THE REGISTER CHANGE IS THE VALUABLE HALF, and it is carried by "both are valid."
Correlated entities are not frauds -- they exist, they contribute, they are
simply not TWO. That converts anti-Sybil from an adjudication into a
measurement: the output stops being "Sybil / honest" and becomes "how much
identity does this configuration grant." No verdict about INTENT is required,
so the false-positive failure mode disappears outright -- there is no label left
to get wrong, and a clone farm and an honest cluster of similar agents receive
identical treatment.

That is the dual-use rule in its cleanest instance (report the neutral fact,
never the intent), and it preserves hard money: nothing is CONFISCATED from
correlated entities, standing is simply NOT CONFERRED TWICE for one
contribution. Grading happens at conferral rather than at seizure, so
spend/stake/never-confiscate survives intact.

ONE QUANTITY, TWO REGISTERS, BUILT SEPARATELY. `SocietyUsefulWork.fs` already
prices CONTRIBUTION by the same rho ("N copies price near one agent's worth");
this is that rho applied to IDENTITY. So a clone farm gets no extra credit AND
no extra vote from ONE measurement rather than two policies -- and since the two
modules were written for different purposes, their landing on the same quantity
is corroboration rather than restatement.

THE GAP, quoted from the module that owns it rather than asserted:
`SocietyUsefulWork.fs` says the society's "actual rho and c" are UNMEASURED. The
formula is proven; the input is not measured, so `N_eff` is an instrument with
no reading.

Noted because it may matter more than the note: this is the FOURTH distinct
thread this week to terminate on meter accuracy -- anti-Sybil, not-predetermined,
decorrelation-as-anti-money, and graded identity. Either one measurement
underwrites all four, or the same constraint is being rediscovered under four
names. Deciding which is itself worth doing: if it is one, building it once
discharges four obligations; if it is four, three of them are unowned.

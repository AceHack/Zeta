## Description


Aaron asked for all three E8 derivations, believing two were reproduced ("the
roots for sure and maybe the algebra or the Lie group"). Measured: it was ONE of
three. The object that felt like a second derivation is a fourth — the Weyl
group W(E8) as Clifford versors, which is neither the Lie algebra nor the Lie
group. The chain broke between the root system and e8, and nothing in-tree
carried a bracket, a structure constant, a Killing form, or a Cartan matrix used
as an algebra. Only two integer tuples in CliffordPeriodicity.fs and prose.

RUNG 4 — src/Core/E8LieAlgebra.fs, 26 tests.

248 is NOT tested as a result, and the test file says so out loud: dim = |Phi| +
rank restates the basis and cannot fail. The signs are the content. eps(a,b) =
(-1)^B(a,b) for a Z/2-bilinear form written from the Cartan matrix alone, so the
57600 structure constants are a consequence of the Dynkin diagram rather than a
lookup table. Measured instead: Jacobi over all C(248,3) = 2532596 triples; the
Serre relations; that the 24 Chevalley generators generate all 248 dimensions;
the Killing form's block structure and nondegeneracy (Cartan's criterion =>
semisimple); and kappa on the Cartan = 60*A, which DERIVES h^v = 30 — agreeing
with |Phi|/rank = 30 and with the Coxeter element's order 30, by three routes
sharing no intermediate.

Identification, since a count is not one: kappa nondegenerate => semisimple,
connected diagram => simple, rank 8, and the rank-8 simple algebras are A8=80,
B8=C8=136, D8=120, E8=248 — computed from the classification's formulas in the
test. Only then is the dimension allowed to speak (Killing-Cartan).

THE SIGN ERROR, which is the most useful thing here. The first version used
[e_a, e_-a] = +h_a and produced 13440 violating triples out of 2532596 — 0.53%.
Serre passed. Generation to 248 passed. h^v = 30 passed. The Coxeter element,
the exponents and |W| = 696729600 all passed. Every headline number was right
and the object was not a Lie algebra. Two instruments caught it: the exhaustive
Jacobi sweep, and the compact form's Killing diagonal holding both -120 and
+120. Jacobi forces tau = -1; it is not a convention choice.

Mutations run and reported (baseline 0): twelve single root-root sign flips ->
113 violations each; the Cartan-case flip -> 168; an [h_i, e_a] flip -> 162;
sabotaging one compact-form diagonal entry flips the definiteness verdict.

RUNG 5 — the honest substitute, labelled as one. A 248-dimensional compact
manifold is not constructible by any finite computation, so "rung 5 done" on a
dimension count would be vacuous. What IS measured: the compact real form's
Killing form is diagonal with all 248 entries equal to -120, i.e. negative
definite, so by Weyl the simply-connected group is compact; det A = 1 gives a
trivial centre; Phi_30(c) = 0 with I..c^7 independent gives charpoly = minpoly =
Phi_30, hence the exponents as the totatives of 30 by gcd. Stated bound: |W| =
prod d_i cites Coxeter's theorem — the exponents are computed, that step is not.

AARON'S EXPERIMENT — src/Core.TypeScript/research/adinkra-ecc/mod8-clock.ts,
13 tests, 6706 assertions.

Does the what-remains/what-acts clock come from the CODE (Gleason: doubly-even
self-dual codes only at length divisible by 8) or from CLIFFORD (Atiyah-Bott-
Shapiro periodicity)? Run within ONE object so only one variable moves: the N=8
self-dual adinkra's 70 four-colour subsets, 14 of which carry a codeword.

Result 1 — the code cannot move the clock. All 70 read byte-identically, and so
does every doubly-even code of length <= 8. ORIGIN A excluded; Aaron's Clifford
attribution confirmed. The control that makes it non-blind: those same groups DO
differ on freeness, so the instrument can tell them apart and still reports no
difference on the clock.

Result 2 — the separation clock has period FOUR, not eight. Swept N=1..16 by
searching for the smallest invariant shift, never by asking N % 8: it separates
at 4, 8, 12, 16. This AGREES with CliffordPeriodicity.halvesSeparateCleanly,
and that is the finding: its condition s in {0,4} mod 8 is a real mod-8 statement
about Cl(p,q), but restricted to the family Cl(0,N) where p is pinned at 0 it IS
N = 0 mod 4. The mod-8 degenerates to mod 4 on the family adinkras live in.
Mutation control: fed a genuine mod-8 signal the same search returns 8.

Result 3 — the period-8 invariant lives in the Morita ground, and the CODE is
what makes it visible. dim End_A(M) = 2^(N-2k) exactly, over every doubly-even
code at N = 4, 6, 8. At k=0 the module is the regular representation and its
endomorphism algebra is the whole algebra again, so the codeless tower hides the
ground by construction; it reaches 1 at the self-dual point, where the module is
simple. Lumen measured that point as the maximum homoiconicity defect; on this
observable it is the best case. One code dimension costs one bit of
homoiconicity and buys one bit of Morita visibility.

Two routes throughout, sharing no intermediate: Route M composes the adinkra's
actual signed-permutation operators and compares matrices; Route B evaluates a
sign rule on bitmasks. They agree on all 162 colour sets tested.

Also recorded: the two in-tree generation paths are NOT independent —
CliffordE8Roots.simpleSystem searches inside E8Lattice.roots, so the Clifford
route consumes the code route's output as its search space. It is one witness
re-derived, not two. IcosahedralH3 is the genuinely independent route.

And a name collision worth knowing: two different objects are called "the adinkra
clock" — the ABS periodicity clock (CliffordPeriodicity) and the anticommutator
clock ({Q,Q} = d_tau, AdinkraClock.fs). The latter contains zero mod-8 content.

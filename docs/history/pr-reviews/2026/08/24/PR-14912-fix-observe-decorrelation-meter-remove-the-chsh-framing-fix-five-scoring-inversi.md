## Description

fix(observe): decorrelation-meter — remove the CHSH framing, fix five scoring inversions, add the 38 falsifiers it shipped without

`src/Core.TypeScript/observe/decorrelation-meter.ts` landed in #14848 at 275 lines with no
test file. Every finding below was reproduced against the as-merged code before being written
down, and every fix has a falsifier that dies without it.

THE CONCEPT IS RIGHT AND IS KEPT. Measuring whether fleet decorrelation is real rather than
assumed is load-bearing: CondorcetBoundary.fs caps effective identity at N_eff = N/(1+(N-1)rho)
-> 1/rho, and SocietyUsefulWork.fs records this society's rho as UNMEASURED. The module's stated
intent — "measure, never assert 2*sqrt(2)" — is the correct intent. The implementation defeated
it. Nothing is deleted that was correct; the decorrelation-source analysis is kept verbatim, and
the reasons the CHSH mapping was removed are recorded in the file rather than dropped.

P0 — the CHSH framing (removed, reasons kept in-file)

  * NOT CONSTRUCTIBLE. CHSH needs four correlators E(a,b), E(a,b'), E(a',b), E(a',b') across two
    settings per party. Pairwise agreement on one tick is one correlator with no settings. That
    is missing structure, not sampling error.
  * NO INFORMATION. S = 2(1+c) is affine and invertible, so it carried nothing the coefficient
    did not. Its only effect was to place 2*sqrt(2) at c ~ 0.414 on a scale the mapping itself
    chose — numerology in the exact sense of .claude/rules/numerology-vs-number-theory.md.
  * SELF-REFUTING. The header called S > 2*sqrt(2) "impossible if measured honestly"; its own
    best case c = 1 produced S = 4 > 2.828. The "suspicious" band meant to flag that sat behind
    a [0,1] clamp and could never fire — its own comment said so.
  * INFERENCE INVERTED. src/Core/DecorrelationMeter.fs (Soraya review, #10010) established that
    a passive shared common cause IS a local-hidden-variable model and sits at |S| <= 2, so
    S > 2 convicts a live channel and S <= 2 never acquits. The mapping read high S as
    independence. That F# module is also scoped to spacelike pairs because no-signalling is what
    makes CHSH valid; wall-clock bucketing is not that filter.
  * The ring corners do not supply settings either: FourCornerOwnership names weight rings and
    wset-four-corner-trace.ts refuses the bridge in its own docstring.

P0 — scoring inversions, all reproduced

  * FORCED AGREEMENT SCORED AS MAXIMUM INDEPENDENCE. A one-option menu gave denominator 0,
    excess 0, coefficient 1.0, band "strongly-independent". Agents that could not disagree read
    as maximally decorrelated. Now refused and counted as degenerateWindows.
  * INDEX COMPARED ACROSS DIFFERENT MENUS. The same function averaged the two menu sizes, so it
    had already measured them to differ, then compared raw chosenIndex. A choosing "ship" and B
    choosing "delete-prod", both index 0, scored perfect agreement. Now compares the option
    LABEL — a field the record already carried and the module never read.
  * UNMEASURED REPORTED AS MEASURED. An absent data file returned coefficient 0 / band
    "correlated"; only the prose summary said INSUFFICIENT DATA, and structured consumers do not
    read prose. Fed to N_eff that turns "no data" into "the fleet is worth one agent".
    coefficient is now `number | null`.

P1 — also fixed

  * One malformed line zeroed the whole file (read + map in one try). Measured: 24 valid records
    + 1 bad line -> 0 decisions. Now line-local, with malformedLines / fallbackLines reported.
  * Array.find silently truncated to the first decision per agent per window. Now refused as
    ambiguous, soundness-biased, and counted.
  * Anti-correlation was clamped onto 1.0, byte-identical to independence. meanCorrelationExcess
    now keeps the sign; negative rho raises N_eff and is not the same fact.
  * expectedByChance = 1/mean(|A|,|B|) is wrong for unequal or non-identical menus and biased
    upward — it flattered the fleet. Now |A n B| / (|A| * |B|).
  * Unparseable `at` produced bucket "NaN", making every malformed row mutually concurrent. Now
    malformed.
  * groupConcurrentTicks claimed "within windowMs of each other"; it does fixed-offset bucketing.
    Renamed groupByTickWindow and documented honestly. NOT converted to a proximity relation —
    that is a semantics decision for the owner, and proximity is not transitive.

STILL OPEN, deliberately not done here

  * THIS COEFFICIENT IS NOT THE rho IN N_eff. That rho is pairwise ERROR correlation; this is
    choice agreement with no ground truth. Two agents that are both always right agree perfectly
    and have no correlated errors at all. Joining a correctness signal is the next work.
  * Stratifying by `model` family — the module's own headline decorrelation source, present in
    every record and never read.
  * Fixed-offset bucketing vs a real proximity relation.

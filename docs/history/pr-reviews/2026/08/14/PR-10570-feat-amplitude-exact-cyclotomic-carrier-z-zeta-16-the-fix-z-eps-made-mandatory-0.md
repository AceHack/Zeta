## Description

## Why this stopped being an improvement

**Z-EPS was run and it HOLDS** (#10554). A Bob-local, trace-preserving operation moves Alice's marginal Born probability from `0.2647` to `0.0000` on the shipped `AmplitudeEmu.step`. The emulator computes a theory that **signals**, and it survives normalisation. "Tune EPS" is dead **as a class** — the shift is scale-dependent and the theory is not, so for any `EPS > 0` there is a ray where the shift is order 1. **Admissible fixes are carrier changes.** This is one.

## N chosen: 16 — and 8 and 4 are sub-lattices of it, not alternatives

`Φ₁₆ = x⁸ + 1`, so rank `φ(16) = 8` and reduction is negacyclic (`ζ^{8+m} = −ζ^m`) — a length-8 signed convolution, nothing more.

| contains | is | why it matters |
|---|---|---|
| `ζ₄ = ζ₁₆⁴` | `ℤ[i]` | the carrier `QuorumPhaseCancellation.tla` already restricts to |
| `ζ₈ = ζ₁₆²` ⇒ `√2 = ζ² − ζ⁶` | Clifford+T's `ℤ[1/√2, i]` | exactly what `SoftChip8.forkOnInput`'s `√0.5` needs |
| 16 phases | — | one root of unity per key of the 16-key `ActionGrammar` alphabet |

So the item's "fall back to N = 8" branch is a **selection**, not a second implementation. Nothing was given up to keep all three.

## Cost, measured against the depth-1 prediction

1000-member depth-1 fold, same shape both carriers:

| | exact | float | ratio |
|---|---|---|---|
| time | 0.33 ms | 0.17 ms | **1.9×** — inside the predicted 2–4× band |
| coefficient bits | 4 → 9 | — | predicted `log₂ 1000 = 10`; measured 5 |
| every coefficient after the fold | fits `Int32` | — | asserted by a test that fails if it stops being true |

`BigInteger` is therefore a **safety margin** over the machine-integer representation the 2–4× memory prediction assumed, not a necessity.

**Where my prediction was incomplete, found by measuring rather than arguing.** Depth-1 covers the member-count axis and says nothing about the **denominator-exponent spread**. Aligning to a common exponent inflates coefficients by the spread, and the naive loop made that a *multiplicative time* cost — 20× float at a spread of 32. Fixed inside the carrier (`√2ⁿ = 2^{n/2}·√2^{n mod 2}`, so alignment is one shift plus at most one ring multiply): now 0.85 ms, ~5× float, with the 22-bit growth remaining as the intrinsic and correct cost. Design consequence, stated in the test: **a quorum whose members contribute at a uniform depth pays only `log₂ m`.**

## The trap, and how the Z-EPS evidence is retained

An exact carrier makes a checker *sound* for the quorum-fold properties and **blind to this one** — the drop has nothing left to delete. The defect is gone, not hidden, but that means **no exact-carrier test can be the Z-EPS regression test.** Three guards:

1. `tests/Tests.FSharp/Formal/AmplitudeEmuSignalling.Tests.fs` is **untouched**. It tests the float path, which is **not deleted** — the continuous-φ sweeps need it and are permanently outside the byte-lock treaty.
2. Section C of the new test file is a **differential**: the float arm signalling and the exact arm not, **in one assertion**. Deleting the float path breaks compilation rather than quietly turning the file green for the wrong reason.
3. **Mutation-checked, not argued:** setting `AmplitudeEmu`'s `EPS` to `0.0` kills exactly the three float arms and leaves all 24 exact arms green. Correct kill pattern; neither side is a tautology.

**One strengthening of Z-EPS.** Soraya's witness used a (3,4,5) rotation, whose 3/5 and 4/5 factors are *not* in this ring. The differential here uses the **balanced 1/√2 fork — the shape `SoftChip8.forkOnInput` actually produces** — and it signals just as hard. The signalling class is not reached only by exotic rotations. It still requires a near-threshold ray, so "not a correctness emergency for CHIP-8 today" stands unchanged.

## The ζ₄ bridge lines up

- `QuorumPhaseCancellation.tla`'s `Vec(p, k)` **is** `ζ₁₆^{4p}·k` — asserted for all 16 combinations.
- The Gaussian sub-lattice is **closed** under the exact fold (only coordinates 0 and 4 ever non-zero, `K = 0`), so a counterexample stays a statement about the same object.
- **A TLC counterexample runs as an F# test**: three honest members at phase 0, one Byzantine at phase 2 with larger magnitude, resultant exactly `Zero`, outcome leaves the support — while the *incoherent* total stays non-zero, so the fold can still tell cancellation from silence (the spec's `SomeNonZero` conjunct, preserved).

## What is now byte-lockable that was not

**The amplitude layer, for the first time.** The canonical form is unique (reduced until `√2 ∤ u`), so `Cyc.encode` is a total text rendering — decimal integers plus an exponent, no binary, per `no-binary-in-proof-lineage` — and state encodings are order-independent across nodes.

**No golden vector is added or changed.** Minting a cross-oracle vector is a treaty change with its own consent path; this PR ships the encoding, pins it in tests, and stops.

## I mutated my own fix, and it found a weak assertion

The first byte-lock test asserted `(a = b) = (encode a = encode b)` — a **tautology**, since `encode` renders exactly the fields `Equals` compares. It survived canonicalisation being disabled entirely. Replaced with a test stated against **values** via the independent float instrument: different writings-down of one value must encode identically; distinct values must not collide. It now dies under that mutation. Five further mutations (cyclic-instead-of-negacyclic, `isZero` always false, wrong conjugation sign, dropped denominator alignment, dropped canonicalisation) each kill the tests they should and no others.

## Scope

Carrier only. `join`/`interfere` are named apart and that is settled. **`QuorumAlgebra` is not migrated here, deliberately**: `QuorumAlgebra.Tests.fs` section C *measures the float defects*, so converting that module in the same change would delete the evidence along with the defect — the same trap, one layer up. That migration wants its own PR that keeps a float-path arm.

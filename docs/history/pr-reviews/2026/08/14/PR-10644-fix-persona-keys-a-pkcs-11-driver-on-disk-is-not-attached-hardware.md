## The bug, reproduced before it was fixed

`probeHardwareSecurity()` computed `tpm.available || yubi.detected || pkcs11.found`, where `pkcs11.found` means **a shared library exists on disk**. I checked this out and ran it rather than reading it:

```
$ touch fake-ykcs11.dylib   # empty file, no token attached
$ bun run orig-probe.ts
  PKCS#11 Library:   /tmp/reprocheck/fake-ykcs11.dylib
  Hardware present:  YES        <-- from an empty file
```

A PKCS#11 module is a **driver**; a driver is evidence that someone ran brew, not that a device is attached. Same probe, opposite direction: YubiKey detection shelled out to `ykman`, so a genuinely attached token on a machine without the Yubico CLI read as absent. Neither is a silent-downgrade — the adapter still throws — but the probe's answer was simply wrong, and nothing else in the repo answers the question it exists to answer.

## What I fixed vs only documented

**Fixed (code):** the driver-is-not-a-device false positive; the ykman-dependent false negative (reader detection now goes through the OS smart-card stack — CCID interface class on Linux sysfs, `SPSmartCardsDataType` on macOS); Secure Enclave now reported; `availableHardwareSealTiers()` + `assertHardwareSealTierAvailable()` make the L1 rung claim **computable** instead of asserted.

**Documented only:** everything at L2 and above. The PKCS#11-cannot-compose-a-FROST-partial finding stays a specification reading, as its own note says. The PKCS#11 FFI path has no token to talk to; the TPM2 path had no Linux TPM host to try.

## No-silent-downgrade

Nothing here adds a fallback. `availableHardwareSealTiers()` is **advisory** — it selects nothing; the caller still declares its tier and `createHsmShareAdapter` still throws. `assertHardwareSealTierAvailable()` only ever **throws earlier**, with a legible reason, instead of failing deep inside a PKCS#11 FFI call. The Secure Enclave deliberately does **not** clear `noHardwareDetected` — letting a chip no tier can reach mark "hardware present" would have reintroduced the exact false positive being fixed.

## Summary

- replace the PWA hosted-operator dependency with a passkey-authorized, non-exportable P-256 device key
- submit the signed public envelope through a loopback-only companion that keeps `gh` credentials in OS/local custody
- verify delegation, proposal bytes, revocation, replay, base SHA, TTL, byte cap, and protected paths again in the trusted-main issue workflow

## Security boundary

Unsigned public issue spam cannot stage code. Root or device revocation disables delegated authority. The browser never receives a GitHub token. A same-origin compromise can invoke a loaded non-exportable key, so protected-path denial and independent trusted-main verification remain mandatory.

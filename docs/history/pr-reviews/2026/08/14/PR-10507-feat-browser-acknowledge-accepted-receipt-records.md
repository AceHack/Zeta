## Description

## Why

Receipt proposals are submissions, not proof of durable storage. The browser archive needs an independent acceptance boundary before it may release settled receipts.

## What

- add an injected accepted-record source that reads the content-addressed receipt path
- require repository identity, `main`, an immutable commit SHA, exact path, finite size, and byte-exact payload
- return typed pending, invalid, capacity, mismatch, and source-failure feedback
- convert only accepted evidence into the existing durable handoff acknowledgement
- expose the shared proposal validation and canonical record encoding helpers
- repair the concurrent WebAuthn `BufferSource` regression with explicitly owned `ArrayBuffer` inputs compatible with TypeScript 5.6 and 6

## Description

`docs/SEED-VOCABULARY.md` is a **cold-start file** — read on every wake per CLAUDE.md §1 — and it carried two stale counts, one contradicting its own text seven lines later.

| line | said | correct | source |
|---|---|---|---|
| 102 | **six** always-active disciplines | **seven** | `.claude/rules/dv2-data-split-discipline-activated.md` — noninterference is row 7 |
| 112 | **11** specifications | **13** | `docs/governance/MANIFESTO.md` — 13 §-headed specs |

**Line 119 of the same file already cited `manifesto-13-specifications.md` by name.** So the file disagreed with itself within one screen, and had done for roughly two months.

The missing discipline is the consequential part: **noninterference** (§13, added 2026-06-10) governs entropy and influence entering only through declared, metered channels. A cold-started agent reading the seed had no reason to apply it.

Both counts were verified against source rather than assumed — the manifesto's §-headed specification count and the rules file's checklist were each read and counted.

Found while auditing skill/prompt drift. This is the most checkable drift class there is — a stated integer against a countable list — which is what makes it worth fixing rather than tolerating: **a seed that miscounts its own kernel is the cold-start equivalent of a check that cannot fail.**

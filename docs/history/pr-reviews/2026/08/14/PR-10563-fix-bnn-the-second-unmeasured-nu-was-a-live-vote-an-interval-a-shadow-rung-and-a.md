## The defect

`src/Core.TypeScript/planning/error-bnn-bridge.ts:77` — `createDimensionalBnn(nu = 3)`, the last
unmeasured tail index in the BNN call chain. Flagged twice today by two agents who each declined
to fix it because it sat outside their scope, and who both refused to normalise 3 to 4 or 4 to 3.
That refusal was right: swapping one unmeasured constant for another destroys the evidence that
the two disagreed.

## It was a LIVE vote, not a latent one — measured

On this consumer's own observation alphabet (`SEVERITY_Z`: info 0.5, warn 1, error 2, fatal 4) and
its own configuration (prior `N(0,1)`, `obsVariance = 1.0`):

| stream | mu at nu=3 | mu at Gaussian | tightest sigma | gate |
|---|---|---|---|---|
| **one fatal** | 0.970171 | 2.000000 | 0.707107 | **TAIL-DEPENDENT** |
| 5 warn + 1 fatal | 1.014924 | 1.285714 | 0.377964 | independent |
| 5 info + 1 fatal | 0.571172 | 0.928571 | 0.377964 | independent |
| all warn | 0.871518 | 0.857143 | 0.375379 | independent |

The first row is the **modal case** — one failed `ace install` is one fatal error on one dimension
— and there the constant moved the published posterior mean **by a factor of two**, past the
posterior's own error bar. For the second row the critical `nu` is **13.004776**, the direct
analogue of the society fold's 23.389306.

## Declare, not infer — and the reason is stronger here than in #10524

#10524 measured that inference needs O(100) atoms and a society has O(10). Here there are **no
atoms at all**. `updateStudentT` is an ADF filter: it projects each observation into a Gaussian
summary and discards it, and the persisted form keeps `(mu, sigma2, nu, obsCount)`. Nothing
retains the stream `tryInfer` needs. So route 1 is **unavailable**, not merely underpowered — and
unlike the society fold, this gate does **not** open by itself as the observation count grows. It
opens only if someone retains the observations.

## What landed

`TailInterval` + `declareTail` (**a point is not constructible** — the same line
`HeavyTailFold.Tail.declare` draws), a rung ladder swept uniformly in `1/nu`, and
`dimensionVerdict` returning `tail-independent` / `tail-dependent` / `not-gradable`. Each dimension
folds the identical stream at every rung, so disagreement between rungs is attributable to the tail
assumption and to nothing else. The gate is `HeavyTailFold.fold` gate 1 / `tailSensitivity`: a
**systematic** against a **statistical**, both in units of theta, adding no second free constant to
replace the one removed.

`nuLo` stays 3, and that is **not a re-vote**: it reproduces the number this module published
yesterday, so nothing is silently renumbered, while the number stops being the whole assumption and
becomes the conservative endpoint of a declared range. `HeavyTailFold` publishes at `NuLo` for the
same reason — observed information is smallest where outliers are rejected hardest.

## Does `nu = 3` have its own pathology? Yes, and it is the analogue of `nu = 4`'s

A Student-t has moments of order `< nu` only. So `nu = 4` sits on the pole of the kurtosis
`6/(nu-4)`, and `nu = 3` sits on the boundary where the **third moment diverges and skewness ceases
to exist**. Two adjacent moment-existence boundaries — neither constant was measured, both named a
boundary. That is evidence of the same folk heuristic ("as heavy as I dare"), not of measurement.

It does **not** bite this consumer: the tilt is a Gaussian times a t, so all its moments are finite
regardless of `nu`; the projection matches only two; and nothing here estimates `nu` by method of
moments. Recorded because *"it has no consequence"* is a different claim from *"it is arbitrary"*,
and only the first is true.

## Is the `deserializeBnn` default dead code? Mostly — and the live part is the interesting part

Every dimension **present** in the file is already restored at the file's `nu`, so the constructor
default never decides a restored tail. `serializeBnn` writes all nine dimensions, so a round-trip
leaves it unreachable. It is **live** for a dimension in `ALL_DIMENSIONS` but **absent** from the
file: a state written before the dimension existed, or a truncated one. That is the
schema-evolution path, so the default had to be defensible rather than merely unreachable — which
is why it is now an interval that says it is unmeasured. `BP-12` pins that path.

## Three further defects on the same path, found while verifying it

- the unknown-dimension restore branch **dropped `obsCount`**, restoring a state claiming zero
  observations while the file carried five;
- the same branch took `createStudentTState`'s default `obsVariance` (0.1), giving one dimension a
  different noise scale from its nine siblings purely because it was new;
- a persisted `nu` of 0/NaN/negative was accepted silently on one branch and thrown on the other.
  It now fails fast on both and names the dimension.

## Does the F# discipline cross to TypeScript? Partly — and the gap is named

`HeavyTailFold` **removed the operation**: no F# function takes a bare `nu` and returns a verdict,
so the defect is unreachable. Here `dimensionPosterior` still returns an ungated `mu`, because
`discovery/zeta-transport-cell.ts` and `society-evolution-runner.ts` read that field directly and
breaking files four other agents are inside was not on offer.

So TypeScript gets the **measurement** and the **refusal type** but **not the unreachability**, and
a caller who ignores `tailVerdict` can still act on a number the assumption chose. That is a named
gap, not a claim of parity. It is an **equivalent rather than a binding**, and the two are
deliberately named alike so drift between them is visible. Closing it means changing
`dimensionPosterior`'s contract in a PR that owns those two consumers.

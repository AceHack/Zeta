## Verdict

**Conjecture Z-EPS HOLDS.** A **Bob-local, trace-preserving** operation moves Alice's marginal Born probability from **0.2647 to 0.0000** on the shipped `AmplitudeEmu.step`. The emulator computes a theory in which a local operation on one half of a bipartite state changes the other half's marginal statistics. That is signalling.

Handed over by #10551 section 3, with the falsifier its author named. Run, and it came back positive.

**No arithmetic changed.** `EPS` is untouched. This PR establishes what the defect *is*; the fix is Aaron's call and is unmade.

## The algebra does NOT settle it

The offered framing was that it might. It does not, and the slip is a converse:

- **Theorem:** linearity + trace preservation ⇒ no signalling (Kraus/Choi).
- **Its contrapositive:** *signalling ⇒ nonlinear.* **Not** *nonlinear ⇒ signalling.*
- **Counterexample to the converse:** global renormalisation `ψ ↦ ψ/‖ψ‖` is nonlinear and signals nothing.
- **Gisin 1990** is a *genericity* result -- the reason to expect signalling, not a proof about a given map.

So algebra voids the **guarantee**; only a witness establishes the **claim**. Had the run come back invariant, Z-EPS would be **false** and the item would downgrade to "numerically wrong". The experiment was not ceremony. The lemma is still worth having and is checked here on shipped code (`step` on amplitude `1.0` is nonempty, on `1e-7` is empty ⇒ not homogeneous of degree 1 ⇒ not linear).

## The witness (CHECKED)

Joint key `(kA, kB)`. Bob's fork is asserted **Alice-local** (Alice's index is a spectator; the Bob-profile does not depend on it) and **trace-preserving** (weights sum to 1) -- mechanically, not by claim. Two settings: identity, and the **(3,4,5) rotation** (Pythagorean on purpose, so the float arm and the exact arm run identical numbers).

| arm | scale | Bob idle | Bob rotates | drop fired | result |
|---|---|---|---|---|---|
| **TREATMENT** | `s = 1` | `P_A(1) = 9/34 = 0.2647` | `P_A(1) = 0.0000` | **2 branches** | **26-point shift** |
| **CONTROL** | `s = 1e6` | `9/34` | `9/34` | **0 branches** | invariant to `1e-16` |
| **EXACT INTEGERS** | n/a | `9/34` | `9/34` | 0 | invariant, exactly |

Three further facts, each its own test:

- **Alice's SUPPORT changes**, not just her weights: `[0; 1]` → `[0]`. Bob deletes an outcome from Alice's world, and `support`/`measure` are public API.
- **Signalling survives normalisation.** On a unit-norm state Bob still flips `P_A(1)` between `1.44e-12` and exactly `0`, and still flips the support. Answers the only serious objection to the loud witness.
- **Treatment and control are the SAME RAY** (componentwise ratio is the single constant `1e6`). No projective theory may distinguish them. This one does -- so the control is a scale-covariance falsifier and a signalling control in one object, which is exactly the scheme-independence control the conjecture asked for.

## What this changes

**"Tune EPS" is dead as a class, not merely inelegant.** For any `EPS > 0` there is a ray on which a local operation moves the far marginal by an arbitrary amount, because the shift is scale-dependent and the theory is not. #10551's dimensional argument concluded "no value of EPS is right"; this upgrades it from an aesthetic judgement to a measured consequence. **The admissible fixes are carrier changes.**

**Raises urgency on `081KZZYWBN2087G0R003NAQQAF`** (exact cyclotomic carrier) with a fourth reason that outranks the other three: the float carrier lets a local operation change a remote marginal. Not done here -- separate item. And note the direction: an exact carrier makes TLC *sound* for the quorum-fold properties and *blind* to this one. The model checker is right after the fix, never for finding it.

**Not a correctness emergency for CHIP-8 today** -- `SoftChip8.forkOnInput` gives real `1/√2` factors and norms stay near 1. The exposure is long folds where destructive interference shrinks the norm, and the quorum layer, whose per-member magnitude is explicitly unpriced (#10551 open item 3, and directly coupled: an uncapped magnitude is what walks a state into the band).

## One new gap, named not closed

`BipartiteMachZehnder` was **not** the right vehicle, though the conjecture named it: it consolidates via `WSet.consolidate` with its own `isZero` at `1e-12` on the *components* -- an amplitude threshold, six orders tighter than `AmplitudeEmu`'s `1e-12` on *intensity*. Running the falsifier there would have tested a different constant in a different module and could plausibly have returned a false negative. **Whether the `WSet` threshold has the same defect at its own scale is un-run and not claimed here.**

## Description

## The finding

`AmplitudeEmu.merge` **sums**, so `merge (a @ a) = 2a`. It was **never** a `universal/evidence` join, and
nothing said so. One name carried two incompatible algebras and a caller could not tell which one they had
invoked.

Aaron, 2026-08-14: *"we can support join and interference both operations and name them differently, more
rx operations are fine."* So both are named now.

**No arithmetic changed.** `interfere` computes exactly what `merge` always computed. Interference is the
instrument - a quorum that can disagree with itself to zero - not a bug.

## Which law fails, and by how much (all CHECKED by tests that fail if wrong)

Two **independent** defects, and separating them is the point:

**1. The typing defect (primary, fixed here).** One operation, two algebras. It is the operator-level form
of the lesson landing elsewhere this week - *a bare scalar is where distinctions go to die*. `1.2: float`
could not carry **why** it held; `merge` could not carry **which law** it obeyed. Same fix as
`BoundJustification` and `LossSignal`: split until each name means one thing.

**2. The arithmetic defect (real, NOT fixed here - no arithmetic changed).** The `EPS = 1e-12` drop:

| law | measured |
|---|---|
| associativity | **FAILS structurally** - `(a+b)+c = []` vs `a+(b+c) = 1.6e-6`: one grouping measures `None`, the other `Some`. On a larger witness the gap is `1.0e-7` on a value of `5.0` = **1.13e8 ULPs**, far above rounding |
| scale covariance | **FAILS** - `support(a) = 2` but `support(0.5*a) = 1`. Halving a state is physically the identity (states are rays); it changes the Born distribution |
| commutativity | fails at the value level under float re-association, and at the representation level always (output list order tracks input order) |
| `merge . merge = merge` | **holds** |

The largest silently deleted amplitude is `sqrt(EPS) = 1e-6`, not `1e-12`. Root cause is dimensional: `EPS`
thresholds `|z|^2`, an intensity, so it puts an absolute scale into a projective theory. No value of it is
right. **So the interference half cannot be byte-locked today, and the module now says so.**

## What the quorum layer IS

The additive group of the **free C-module** `C[Outcome]`: commutative, associative, unit `[]`, **inverses
exist**, **not idempotent**. So **spec 12 is declined at this layer by design, out loud** - and the guard
is that the operation that *is* idempotent now exists and is called `join`.

## `Z[zeta_N]` - reachable, and cheap, at this layer

Unitary modular data is cyclotomic (Coste-Gannon 1994; Ng-Schauenburg 2010), so restricting phases to
`N`-th roots of unity is where the data already lives. Verdict:

- **Yes for the quorum fold**, because it is **depth-1**: one addition layer over `m` members, so
  coefficients grow by `log2 m` bits rather than linearly in circuit depth. Cost is `phi(N)` integers per
  amplitude (4 at `N = 8`, 8 at `N = 16`) versus 2 floats - a 2-4x constant, no compounding.
- **No for the continuous-phi interferometer sweeps** (`closedInterferometer`, the Mach-Zehnder visibility
  tests) - those are analytical demos, keep them float and label them outside the treaty.
- **CHECKED**: the same fold over `Z[i] = Z[zeta_4]` is exactly associative on the witness that breaks the
  float one, still annihilates on exact cancellation, and still gives `a + a = 2a`. **The instrument
  survives exactness; only the epsilon dies.**
- The prize beyond byte-lock: Soraya's `QuorumPhaseCancellation.tla` **already** restricted to the 4th
  roots of unity to be checkable. Share the carrier and **TLC counterexamples become executable F# tests**.

Filed as `081KZZYWBN2087G0R003NAQQAF`; not implemented here, because it is a carrier change and this PR
deliberately changes no arithmetic.

## Sibling or section? Sibling.

`universal/interference.md` is a new file, not a section of `evidence`. The two shapes assert
**contradictory closure properties** and both are load-bearing: evidence needs an idempotent join for its

operator level. `evidence.md` gets a boundary section instead: the shape stops above the individual agent.

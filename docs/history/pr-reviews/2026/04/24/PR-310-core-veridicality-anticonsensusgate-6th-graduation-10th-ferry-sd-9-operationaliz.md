## Summary

Sixth Amara-graduation — ships the independence-gate primitive from Amara's 10th ferry verbatim. Operationalises the drift-taxonomy pattern-5 rule + SD-9 soft default (*"agreement is signal, not proof"*) as callable code.

Depends on PR #309 (`Veridicality.Provenance` + `Claim<'T>` types). Built on top of that branch; consolidates on rebase when #309 lands.

## What lands

- `Veridicality.antiConsensusGate : Claim<'T> list -> Result<Claim<'T> list, string>`
  - `Ok claims` when distinct `Prov.RootAuthority` count >= 2
  - `Error "Agreement without independent roots"` otherwise

## Operational intent

If 50 claims agree but trace to one upstream source, the 50-way agreement is still one piece of evidence. Gate rejects pseudo-consensus; genuine multi-root agreement passes.

Input assumed ABOUT the same assertion (group-by canonical claim key before invoking). Canonicalization is a separate future graduation (`SemanticCanonicalization`).

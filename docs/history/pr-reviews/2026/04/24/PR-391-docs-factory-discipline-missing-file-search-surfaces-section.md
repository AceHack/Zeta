## Six classes covered

1. **In-tree (working copy)** — untracked dirs, subagent worktrees (3 places: `git worktree list`, `.claude/worktrees/agent-*`, `.git/worktrees/<n>/`), gitignored sidecars, sparse-checkouts.
2. **Git-managed but not on `main`** — branches, stashes, reflog, dangling objects, deleted-in-history, renamed, tags, notes, submodules, bundles, hooks.
3. **In-repo factory state** — persona notebooks, hygiene-history, pr-preservation, research, ROUND-HISTORY / DECISIONS.
4. **GitHub-side (not yet preserved)** — open PRs, closed-not-merged, forks, review threads, Discussions/Wiki, Issues, Actions artifacts, Releases.
5. **Out-of-repo agent state** — Anthropic AutoMemory, global skills, plugin caches, Codex/Gemini state, live cron jobs, sibling LFG repos, gists.
6. **Local-machine + external** — Time Machine / APFS snapshots, Trash, IDE local-history, xattrs/Spotlight, Docker volumes, terminal scrollback; courier-ferry imports, external-conversation transcripts, diagnostic reports.

## Index-integrity bite

A file in `memory/*.md` without a pointer row in `memory/MEMORY.md` is invisible to fresh sessions even when it exists on disk. The index IS the discovery mechanism — pair file + row in the same commit.

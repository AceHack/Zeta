## Description

## Summary
C# companion to PR #146's F# API. ServiceTitan uses C# with zero F#, so shipping the C# version minimises adoption friction for the target audience. F# stays the factory's reference language; C# stays the ServiceTitan-audience-facing output.

### Identical behaviour — verified
Both versions return the same JSON for every endpoint:
```
/api/pipeline/funnel      → [{"stage":"Lead","count":10,"totalCents":5400000}, ...5 stages]
/api/pipeline/duplicates  → [{"email":"alice@acme.example","customerIds":[1,13]}, ...]
/api/customers            → 20 customers
```
The only cosmetic difference is `name: "(F#)"` vs `name: "(C#)"` at root.

### What lands
- `ServiceTitanFactoryApi.CSharp.csproj` — `Microsoft.NET.Sdk.Web`, nullable + implicit usings, TreatWarningsAsErrors
- `Customer.cs` / `Opportunity.cs` / `Activity.cs` — records, one per file (satisfies MA0048)
- `Seed.cs` — 20 customers / 30 opportunities / 33 activities / 2 intentional email collisions, deterministic fixed clock
- `Program.cs` — 9 minimal-API endpoints, identical routes + JSON shapes to F#
- `README.md` — parity guarantee, design notes, C# specifics

## The five grounds

1. **stale-rationale** — finding references content prior commits on the branch already rewrote
2. **self-contradicting-suggestion** — replacement contradicts own rationale or sibling finding
3. **grammatical-attributive-adjective** — flags hyphenation that follows English grammar convention
4. **design-intrinsic-hardcode** — hardcode isn't accidental; it IS the design
5. **verbatim-quote-preservation** — orthographic normalization on quoted maintainer speech

Each ground includes: detection rule, response template, observed-instance pointers to PR + tick-history row.

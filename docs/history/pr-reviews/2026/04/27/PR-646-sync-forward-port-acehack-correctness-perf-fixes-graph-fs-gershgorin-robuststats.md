## What's included

### 1. `src/Core/Graph.fs` (156 lines) — Gershgorin spectral shift fix
Codex P1 review on AceHack PR #26 caught that power iteration on signed adjacency matrices doesn't converge without a spectral shift.
- shift = max row-sum |sym| (Gershgorin disc bound)
- Run power iteration on shifted matrix
- Subtract shift at end to recover the eigenvalue
- Zero-matrix special case → `Some 0.0`
- Degenerate / non-converging guardrails

Amara validation logged in `memory/feedback_amara_validates_gershgorin_shift_eigenvalue_fix_with_4_caveats_2026_04_27.md` ("beautiful trick, correct shape" + 4 caveats; status per caveat tracked in that memory).

### 2. `src/Core/RobustStats.fs` (10 lines) — IsFinite NaN guard
Codex P2: non-finite measurements propagate `Some NaN` through downstream `coordinationRiskScore` arithmetic and corrupt the score silently. Match the same NaN-guard pattern as `TemporalCoordinationDetection`'s Pearson + circular-mean (Otto-358 fix).

### 3. `src/Core/TemporalCoordinationDetection.fs` (62 lines) — `crossCorrelationArrays` helper extraction
Performance fix: avoid `Seq.toArray` re-walking per lag in `crossCorrelationProfile`. **O(n*lags) → O(n + lags*overlap).**

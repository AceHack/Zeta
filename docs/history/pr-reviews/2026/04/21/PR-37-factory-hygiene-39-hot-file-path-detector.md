## The detector

```bash
git log --since="60 days ago" --name-only --pretty=format: \
  | grep -v '^$' | sort | uniq -c | sort -rn | head -25
```

Threshold heuristic (tunable after 5-10 rounds): >20/60d investigate, >30/60d refactor candidate.

## Summary

Two load-bearing doctrine memory files from Aaron + Amara 2026-04-29, both captured during this session and now landing as durable substrate.

## 1. Parallel agents need isolated worktrees — coordinator owns main

Hard rule: when dispatching multiple background subagents in parallel, each needs an isolated `git worktree` (not the coordinator's working tree). Sharing one working tree causes branch-switch collisions, stash confusion, orphan files, and out-of-scope formatter side-effects.

The carved sentence: *"Parallel agents may inspect broadly, but mutate narrowly."*

Mechanical (not vigilance): the coordinator must allocate worktrees BEFORE allocating agents. `git worktree add -b <branch> worktrees/<lane>/ origin/main` per lane, then dispatch the subagent with `cwd = worktrees/<lane>/`.

**Trigger**: 2026-04-29 incident with three subagents in the same checkout. Branches collided, untracked work got stashed, prettier-via-eslint side-effect modified `docs/GLOSSARY.md` + `memory/CURRENT-aaron.md` outside the file allowlist.

## 2. Best practices = evidence + human lineage + Zeta-native + enforcement + teaching

*"Best practices are not files to copy. They are evidence-backed decisions with human lineage, Zeta-native interpretation, enforcement, and teaching value."* (Amara)

**Orthogonal-axes correction** (Aaron): idiomatic ≠ best-practice; want both.

| | Idiomatic ✓ | Idiomatic ✗ |
|---|---|---|
| **Best Practice ✓** | win-win | best-practice fights community default |
| **Best Practice ✗** | community foot-gun | drift |

**Survival framing**: *"we are building software that future humans and future agents may need to repair without the original authors. So code must teach. Docs must explain why. Skills must preserve expert reasoning. Config must enforce what memory forgets."*

**Six-question audit** when Zeta touches any tool/language/domain durably:
1. Do we understand the idioms?
2. Do we understand the best practices?
3. Do we have evidence?
4. Do we know the human lineage?
5. Have we encoded the rule?
6. Can future maintainers understand and fix this without us?

**Standard schema** for each best-practice entry: claim / status / scope / idiomatic-axis / best-practice-axis / evidence / human-lineage / Zeta-interpretation / enforcement / examples / exceptions / revisit-cadence.

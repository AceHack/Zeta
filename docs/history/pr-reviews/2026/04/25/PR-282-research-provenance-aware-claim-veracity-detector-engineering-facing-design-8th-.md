## Summary

M-effort engineering-facing design doc. Formalises the scoring layer the Otto-98 spine (PR #280) sketched, integrating Aminata's 3 CRITICAL concerns from oracle-scoring v0 pass (PR #263) at write-time.

**8th-ferry 4/5 substantive responses closed** after this PR — matches 5th-ferry 4/4-artifact-closure arc.

## Architecture — composes on Otto-98 spine

- Canonicalisation / representation / ANN retrieval = delegated to spine (layers 1-3).
- Provenance-cone computation via citations-as-first-class.
- **5-gate band classifier** (GREEN/YELLOW/RED) replaces decimal sigmoid; same pattern as oracle-scoring v0.

## 5 output types (Amara's set, mapped to bands)

- `supported` (GREEN)
- `looks similar but lineage-coupled` (YELLOW via G_carrier_overlap)
- `plausible but unresolved` (YELLOW via G_status / G_evidence)
- `likely confabulated` (RED via G_evidence + high similarity)
- `known-bad pattern` (RED via G_status)
- Default `no-signal` when retrieval empty.

## Aminata's 3 CRITICAL concerns addressed at write-time

- **Gameable-by-self-attestation** → G_evidence_independent requires independent-oracle verification for GREEN; self-attested only reaches YELLOW.
- **Parameter-fitting** → parameter-change-ADR-gate; parameter_file_sha bound in receipts.
- **False-precision** → bands not decimals.

## Worked example — self-demonstrating

Detector applied to this doc itself returns `looks similar but lineage-coupled` — correctly flagging its own carrier-laundered convergence with the Otto-98 spine + Aminata Otto-90 pass + Amara 8th ferry lineage. **The detector catches itself.**

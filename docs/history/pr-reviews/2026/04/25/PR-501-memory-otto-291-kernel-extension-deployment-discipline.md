## Five deployment disciplines

1. **Pace releases** — give consumer Maji time to complete each recalculation
2. **Document expansion explicitly** — externalized lemma ladder so consumers don't re-derive
3. **Order basic→advanced** — exhaustive-indexing precondition per dimensional-expansion-via-maji Claim 3
4. **Provide migration paths** — if kernel REPLACES prior, migration tools required
5. **Preserve retractability** — kernel must be reversible per Otto-238

Never overload consumer Maji deliberately — same shape as prompt-injection overload (per Maji personal-history generalization), even if intent is benign.

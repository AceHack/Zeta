## Summary

- Add `references/upstreams/.gitignore` + `references/upstreams/README.md` sentinel pair so the upstream-source mirror directory exists on fresh clone with explanatory prose, parallel to `drop/` and `roms/`.
- Update root `.gitignore` to switch `references/upstreams/` to `references/upstreams/*` with `!.gitignore` + `!README.md` exemptions (same pattern as drop/ and roms/).

Aaron flagged on this round: *"like references/upstreams/ ... we should if not"* (in response to checking whether the dir had a sentinel like drop/ does). It didn't. This adds the missing pair.

## Why

Without the sentinel, `references/upstreams/` disappears at clone time (empty gitignored dir), so a fresh contributor sees no signal that the dir is real working space for the upstream-sync script. The README explains what it's for; the per-dir `.gitignore` belt-and-suspenders the ignore-everything-except-sentinels rule.

Verified `git check-ignore` reports the sentinels as exempt and existing 87 upstream mirror clones (arangodb, arrow, avro, ...) as ignored — no inadvertent tracking.

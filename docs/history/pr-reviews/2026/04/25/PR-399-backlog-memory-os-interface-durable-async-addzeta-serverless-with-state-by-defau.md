## The thesis

1. OS-interface as UX killer (sequential-looking code is the front door)
2. Durable-async runtime (Temporal/Step-Functions/Restate class, built on Zeta substrate + Reaqtor)
3. "Everywhere" durability (state follows the function across nodes)
4. **AddZeta one-line DI** (the DX target; ceremony = thesis drift)
5. LINQ/Rx stream composition (`IZetaStream<T>` as injectable + composable)
6. **Reaqtor tie-in** — use existing `references/upstreams/reaqtor/` substrate; DON'T reinvent IQbservable
7. Usermode-first microkernel preparation (build all microkernel-class subsystems in usermode first, with tests)
8. Actor interface as **secondary** opt-in (beginners trip on the model)
9. Cross-paradigm canonical examples — combinatorial matrix per DSL pair (SQL × git, etc.)
10. Distributed event loop with **mathematical guarantees** (TLA+ / Lean — liveness, safety, determinism-preservation, causality)
11. Auto runtime optimization + stats (place continuations near data, batch durability, migrate hot streams)

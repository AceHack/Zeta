## Description

## Why
The owner asked to be able to SSH into the node from outside the LAN. The home router binds a port forward to a **device**, and the node's addresses (its own IP and every Cilium LoadBalancer IP) share one MAC, so the router can bind a `:22` forward to any of them and can change its mind (it did exactly that for `:443`: production vanished). MEASURED before this change: only the node's own address answered `:22`; `192.168.1.240` and `.250` timed out.

## What
- `discover` now maintains **one relay Service per port**: `https-relay` (`:443`, from #17867) and the new **`ssh-relay`** (`externalIPs` = every LoadBalancer address that does not already serve `:22`; backend = the hostNetwork pod, whose `:22` is the node's own sshd).
- `apply` asserts a **per-source rate limit** in `nixos-fw`: at most 9 NEW SSH connections per minute from non-private sources (LAN exempt so scripted admin is never throttled). Best-effort.
- sshd is unchanged and already hardened: key-only, passwords disabled, `PermitRootLogin prohibit-password`, 0 failed logins in 24 h (measured).
- `docs/ops/SSH-FROM-OUTSIDE.md`: the router steps, where authorized keys really live (measured: read-only NixOS-generated file with 2 keys, plus a writable `~/.ssh/authorized_keys`; durable home = the installer's `operator-authorized-keys.nix`), and the honest limits.
- A DNS-only record `ssh.flowdent.net -> 66.10.240.234` was created in Cloudflare (reversible).

## Proven
By hand on the live node first: `ssh` to `.250` and `.240` worked through an `externalIPs` Service and `:443` was unaffected; the exact rate-limit rules loaded on the real kernel (`recent` match), `-C` found them, and I removed them again. Falsifiers (71 pass) run the discover script against a stub kubectl; mutation-checked (a wrong port filter fails two tests).

## Not proven
End-to-end from the internet: it needs the router forward (owner action) and a key on the connecting device. A real reload under traffic, and that the per-source limit sees real client addresses when Cilium NATs the path.

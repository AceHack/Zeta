## Description

## Defect (measured)

Scheduled first-boot replica on `main`, 2026-09-30, run 36685251210, constrained lane (4 vCPU): **17 Healthy / 2 DIVERGENCE / 19 FAIL**. Platform controllers in CrashLoopBackOff or restarting: sealed-secrets, headlamp, trust-manager, spire-server, cert-manager-webhook (+ controller/cainjector), argocd repo-server (restartCount 3) / server, headscale-0, NFD gc/master/worker. The unconstrained lane the day before (run 36538162478) had all of them Healthy: same tree, contended node. Mechanism = dispatch 36119931377: liveness probes kill containers that are *slow*, not dead.

Rendered chart defaults are `timeoutSeconds: 1` x `failureThreshold: 3` -> a RUNNING container dies after (3-1)*10+1 = **21s** of slow answers. `liveness-kill-budget.ts` only gated the STARTUP axis, so none were flagged.

## Fix

Probes widened through each chart's own values coordinate (timeout 5s x 12 failures @10s = kill budget 120s, stall tolerance 115s): sealed-secrets, headlamp, NFD (gc/worker/master), cert-manager controller+webhook (+ k3s bootstrap twin), argocd server+repo-server (both pin sites, kept equal), spire-server (+ bootstrap twin), headscale (in-repo manifest). gatekeeper exposes only the timeout (21s -> 30s).

## Red -> green

`liveness-kill-budget.ts` now GATES `STALL_TOLERANCE_FLOORS` (three states: ok / below floor / NOT FOUND). Live test against the pre-fix tree: **13 violations**, one per container above; after: 0. Nine widened containers also left the grandfather allowlist. `cluster/` + `k8s/tests` suites: same 90 environmental (Windows) failures before and after, none added.

## Not fixed (named)

Hardcoded probes with no values coordinate: cilium-operator, spire-controller-manager, spiffe CSI registrar, hubble-ui. trust-manager / external-secrets have no liveness probe -> their crashes are process exits, cause UNVERIFIED. BestEffort requests are a separate change (needs `resourceClaims` rows + snapshot + budget re-fit).

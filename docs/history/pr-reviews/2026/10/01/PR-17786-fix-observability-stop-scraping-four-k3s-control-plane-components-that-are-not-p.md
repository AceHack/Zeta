## Description

kube-prometheus-stack renders ServiceMonitors, Services and default *Down alerts for kube-scheduler, kube-controller-manager, kube-etcd and kube-proxy. On k3s the first three run inside the server process and kube-proxy is disabled (Cilium), so four alerts fire from minute one. Disabled all four; render alert-name count 4 -> 0. Test asserts the values and the premise (`--disable-kube-proxy`). No effect on Sync/Health; removes alert noise and four doomed scrape jobs.

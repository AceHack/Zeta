## Description

## What

Second round of the install-time-config audit (follows #17774 and #17789). Every value below used to break, or silently weaken, a fresh install when wrong; each now follows the #17712 mechanism or fails loud, with a test that fails without the change.

| Value | Before | Now |
|---|---|---|
| GitLab LAN address | literal `192.168.1.250` | last address of the install-resolved LoadBalancer range (disjoint `valuesObject` leaves, so the public-TLS Job is not clobbered); unset = RFC 5737 `192.0.2.250` sentinel |
| postgres Blueprint password | default `change-me` | per-instance Secret `${RESOURCE_NAME}-credentials`; missing Secret stops the pod (CreateContainerConfigError) |
| hat-system `:placeholder` image | shipped | allowed only while `replicas: 0`, checked by the placeholder lint |
| Forgejo `ROOT_URL`/`DOMAIN` | chart default `git.example.com` (measured by rendering) | `git.<public domain>` via the injected public-TLS Application; unset = `.invalid` sentinel |
| headscale base domain | `.zeta.local` | derived, not hard-coded |
| `gmod-sftp` Service | always LoadBalancer (burns 1 of 11 pool addresses) | ClusterIP unless SFTP is enabled |
| Console password | known default | minted per install, shown once, locked after first use (no `chage -d 0`: it would force a change even for key logins) |
| ArgoCD tracks `main`, OS pinned to ISO commit | undocumented | ADR + `root-tracks-main.test.ts`; banner states it. Install-time `repoURL` for offline/fork installs left as an OPEN owner decision |

Also adds `hygiene/audit-rendered-chart-placeholders.ts`: renders every Application with helm and scans the rendered objects (a remote chart's defaults are not in git). Baseline entries need owner + reason, STALE entries fail, unrendered apps are reported and never counted clean. Needs helm + network, so it is a manual/drift tool and is not in the required gate.

`docs/ops/INSTALL-TIME-CONFIG.md` carries the full 28-row inventory.

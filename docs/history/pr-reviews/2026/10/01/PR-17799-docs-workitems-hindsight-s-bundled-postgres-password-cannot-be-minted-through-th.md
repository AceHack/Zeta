## Description

Records, with measurements, why hindsight's bundled Postgres password (`hindsight:hindsight`, the chart literal) cannot be minted in-cluster through this chart: it reaches the render in the StatefulSet env and the database URL, neither takes a Secret reference, and the only secret-backed Postgres password is the external branch, which reads `postgres-password` from the operator-supplied `hindsight-llm-api-key`. Latest chart (0.10.2) is unchanged. The three alternatives and their costs are in the work item. No tree behaviour changes; docs/workitem only.

## Description

## What
Audit of every environment-specific value that breaks a fresh install on another network (`docs/ops/INSTALL-TIME-CONFIG.md`, 26 rows with where-hardcoded / failure / install-time source / status), plus the highest-impact fixes using the exact #17712 mechanism (ESP conf -> prompt -> UNSET; `/etc/zeta/<file>` -> `injected-*.nix` -> separate ArgoCD Application with an address-free kustomize base).

- **LoadBalancer range** (`cilium-lb-ipam/ip-pool.yaml` = 192.168.1.240-250 is gone): `zflash --lb-pool auto|<first>-<last>` (device, file-backed, Windows) -> `ZETA_LB_POOL` -> validated against the *measured* LAN before the wipe (inside subnet; not network/broadcast/node/gateway; not pod/service/segment CIDR; <=256; not already answering ping). Bad ESP value + nobody to ask refuses the install; console re-asks; no answer is UNSET and loudly says Services stay `<pending>`.
- **Pod/service CIDR vs host LAN**: installer refuses before the wipe if the node can already route to an overlapping network (`ZETA_ALLOW_CIDR_OVERLAP=1` overrides); rechecked against the cloned tree. ISO ships `cluster-identity.json`.
- **L2 announce regex** `^en[ops].*` -> `^en.*` (USB `enx<mac>` NICs announced nothing).
- `injected-public-tls.nix` also refuses RFC 2606 names and unrendered tokens at Nix eval.
- **`lint-rendered-manifest-placeholders`**: fail-closed scan of every applied manifest and both install-time templates *rendered*; baseline entries need owner+reason and fail when stale.

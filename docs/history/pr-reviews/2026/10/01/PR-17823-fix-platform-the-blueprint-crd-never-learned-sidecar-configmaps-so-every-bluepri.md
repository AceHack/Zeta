## Description

## Evidence
WP11 run 36858893664, per-app diagnostics from the guest: Application `platform` `sync=OutOfSync`, with failed tasks for Blueprints `arma-reforger`, `gmod`, `unturned`: `failed to create typed patch object ... .spec.sidecars[0].configMaps: field not declared in schema`.

## Cause (proven)
#17736 gave the controller (`blueprint.ts` `SidecarSpec.configMaps`, rendered by `renderDeployable`) and the Blueprints a sidecar `configMaps` field and left `crd-blueprint.yaml` alone. The CRD schema is structural, so the API server rejects any field it does not name. No test compared the two.

## Fix
`crd-blueprint.yaml` declares `sidecars[].configMaps` (`name`, `mountPath`, `optional`).

## Test
`platform-blueprints-schema.test.ts` validates every custom resource the platform Application ships against the CRDs it ships (undeclared fields, required keys, shapes; `spec` only). On the previous CRD 3 of 12 fail with the live message verbatim. The checker is exercised on synthetic input so it cannot pass vacuously. `platform-controller` tests: 98 pass.

Bumps [framer-motion](https://github.com/motiondivision/motion) from 13.4.6 to 14.0.0.
<details>
<summary>Changelog</summary>
<p><em>Sourced from <a href="https://github.com/motiondivision/motion/blob/main/CHANGELOG.md">framer-motion's changelog</a>.</em></p>
<blockquote>
<h2>[14.0.0] 2026-10-02</h2>
<h3>Changed</h3>
<ul>
<li>Removed internal APIs restored in <code>13.5.1</code> for compatibility with <code>framer-motion</code> <code>13.0</code>–<code>13.4</code>. Future removed internal APIs won't cause cross-compatibility issues since pinning internal <code>framer-motion</code>, <code>motion-dom</code> and <code>motion-utils</code> dependencies.</li>
</ul>
<h2>[13.5.1] 2026-10-02</h2>
<h3>Changed</h3>
<ul>
<li><code>&lt;motion&gt;</code>: Fall back to the attribute in readSVGValue when computed style is empty.</li>
<li><code>&lt;motion&gt;</code>: Internal changes to <code>animateChanges</code> for size reductions.</li>
</ul>
<h3>Fixed</h3>
<ul>
<li><code>scroll</code>: Temporarily reverted removal of internal <code>observeTimeline</code> API to fix compatibility with previous <code>13.x</code> APIs. Moving to pinned dependencies before removing in <code>14.x</code>.</li>
<li><code>styleEffect</code>: Cleaning up an earlier value no longer removes a value that was bound to the same key after it.</li>
<li><code>svgEffect</code>: No longer writes transforms and origins as attributes.</li>
<li><code>&lt;motion&gt;</code>: <code>inherit={false}</code> now correctly not inheriting parent animations.</li>
<li><code>&lt;motion&gt;</code>: Fix <code>sortNodePosition</code> throwing when a sibling hasn't mounted</li>
</ul>
<h2>[13.5.0] 2026-10-01</h2>
<h3>Added</h3>
<ul>
<li><code>spring</code>: Now accepts negative <code>bounce</code> (<code>0</code>-<code>-1</code>) to define overdamped springs.</li>
</ul>
<h3>Changed</h3>
<ul>
<li><code>&lt;m&gt;</code>: 20% smaller.</li>
<li><code>useSpring</code>: 10% smaller.</li>
<li><code>scroll</code>/<code>useScroll</code>: Use main thread for all <code>offset</code> animations.</li>
</ul>
<h3>Fixed</h3>
<ul>
<li>Ensure <code>warning</code> and <code>error</code> messages are cleaned from production build.</li>
<li>Ensure values are never rendered before they've been resolved.</li>
</ul>
<h2>[13.4.7] 2026-09-30</h2>
<h3>Changed</h3>
<ul>
<li><code>scroll</code>/<code>useScroll</code>: More <code>offset</code>s are now hardware accelerated via <code>ViewTimeline</code>.</li>
</ul>
<h3>Fixed</h3>
<ul>
<li><code>animate</code>: Reduced size of Motion Studio introspection call.</li>
<li><code>useTransform</code>: Accelerated values now correctly clamp.</li>
<li><code>scroll</code>/<code>useScroll</code>: Ensure offsets work the same across the JS main thread and <code>ViewTimeline</code>.</li>
<li><code>scroll</code>/<code>useScroll</code>: Remove <code>ScrollTimeline</code>/<code>ViewTimeline</code> observer in favour of main-thread scroll tracking.</li>
</ul>
</blockquote>

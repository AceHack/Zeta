<h2>streamdown@2.7.0</h2>
<p>This release is mostly about streaming speed, plus a few new props and a lot of fixes.</p>
<p><em>:zap: Performance</em>
• Code blocks now highlight only the new lines as they stream, instead of the whole block on every update
• Blocks that are already parsed get reused while a document streams, and only block tokens are lexed
• Code and table auto-scroll runs once per frame instead of on every chunk
• Showing and hiding the caret no longer restyles the whole document, which used to cost tens of ms per toggle on long streams
• The code highlight cache now has a size limit (LRU), so memory stays bounded in long sessions
• Mermaid diagrams render one at a time while their fence streams, so a growing diagram no longer holds up the stream</p>
<p><em>:sparkles: New</em>
• <code>fallbackComponent</code>: a fallback renderer for tags in <code>allowedTags</code> or HTML tags that have no entry in <code>components</code>
• <code>disableAutolinkProtocols</code>: turn off GFM autolinking for specific protocols (e.g. <code>[&quot;mailto&quot;]</code>)
• <code>portal</code>: set the container used by Mermaid and table fullscreen and the link safety modal
• <code>defaultComponents</code> is now exported, so you can build overrides on top of the built-in renderers
• <code>onCopy</code> / <code>onError</code> now work on the default code and Mermaid copy buttons
• Incomplete images show a loading skeleton while they stream instead of disappearing</p>
<p><em>:bug: Fixes</em>
• Mermaid diagrams auto-fit their container and text is readable again
• A <code>&lt;</code> inside math (e.g. <code>$$ \sum_{j&lt;k} $$</code>) no longer cuts off the rest of the message
• Code block buttons can be clicked inside nested scroll containers
• Tables copied or downloaded as Markdown keep literal HTML tags and entities
• Loose list items no longer get extra spacing from a wrapping <code>&lt;p&gt;</code>
• CJK: bare URLs after fullwidth punctuation are linkified again</p>
<p><em>:jigsaw: remend 1.4.0</em>
• New single-pass scanner that follows CommonMark for code fences and spans: handles <code>~~~</code>, fences in quotes and lists, CRLF, and multi-backtick spans
• Fixes slow (quadratic) healing on input full of delimiters
• Identifiers like <code>snake__case</code> no longer create false emphasis
• Healing is now idempotent</p>
<p><em>:warning: Heads up</em>
• <code>@streamdown/code@2.0.0</code> moves to <em>Shiki v4</em> and now needs <em>Node 20 or newer</em>
• <code>marked</code> is now on v18</p>

<p>Bare emails and bare URLs whose protocol matches the list (case-insensitive, <code>&quot;mailto&quot;</code> and <code>&quot;mailto:&quot;</code> are equivalent) are unwrapped back to plain text. <p>b1965bb: feat: add <code>fallbackComponent</code> prop for missing map entries / <code>allowedTags</code></p>
<p>Adds a new <code>fallbackComponent</code> prop to <code>&lt;Streamdown&gt;</code>. When provided, it is
used as a fallback renderer for any HTML tag or allowed custom tag that does
not have an explicit entry in the <code>components</code> map:</p>
<pre lang="tsx"><code>&lt;Streamdown
  allowedTags={{ mention: [&quot;user_id&quot;] }}
  fallbackComponent={({ node, children, ...props }) =&gt;
    createElement(node!.tagName, props, children)
  }
&gt;
  {markdown}
&lt;/Streamdown&gt;
</code></pre>
<p><code>fallbackComponent</code> applies to custom tags declared via <code>allowedTags</code> (with no
explicit component entry) and to standard HTML tags absent from the built-in
component set (e.g. <code>&lt;span&gt;</code>, <code>&lt;em&gt;</code>, <code>&lt;div&gt;</code>, <code>&lt;br&gt;</code>). Built-in and explicit
<code>components</code> entries always win — this is not a full unstyled mode.</p>
<p>Refs <a href="https://github.com/vercel/streamdown/tree/HEAD/packages/streamdown/issues/543">#543</a></p>
</li>

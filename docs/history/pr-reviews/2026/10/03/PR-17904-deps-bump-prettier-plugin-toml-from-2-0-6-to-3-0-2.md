<h2>prettier-plugin-toml@3.0.0</h2>
<h3>Major Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/un-ts/prettier/pull/519">#519</a> <a href="https://github.com/un-ts/prettier/commit/e2e5c9773c0840d2dcc0458c7d7a0f6a1137d11d"><code>e2e5c97</code></a> Thanks <a href="https://github.com/JounQin"><code>@​JounQin</code></a>! - feat(prettier-plugin-toml)!: replace the unmaintained <a href="https://github.com/tamasfe/taplo"><code>taplo</code></a> with <a href="https://github.com/tombi-toml/tombi"><code>tombi</code></a></p>
<p>The parser/printer is now powered by <code>@tombi-toml/wasm-lib</code>, which supports TOML
<code>v1.0.0</code> and <code>v1.1.0</code> and fixes the crashes reported in
<a href="https://redirect.github.com/un-ts/prettier/issues/487">#487</a>.</p>
<ul>
<li>Prettier's core options are inherited and mapped to tombi: <code>printWidth</code> →
<code>line-width</code>, <code>tabWidth</code> → <code>indent-width</code>, <code>useTabs</code> → <code>indent-style</code>,
<code>singleQuote</code> → <code>string-quote-style</code> and <code>bracketSpacing</code> →
<code>inline-table-brace-space-width</code>. <code>endOfLine</code> keeps being handled by Prettier.</li>
<li>The previous <code>taplo</code> options (<code>alignEntries</code>, <code>alignComments</code>,
<code>arrayAutoExpand</code>, <code>arrayAutoCollapse</code>, <code>compactArrays</code>,
<code>compactInlineTables</code>, <code>compactEntries</code>, <code>indentTables</code>, <code>indentEntries</code>,
<code>reorderKeys</code> and <code>allowedBlankLines</code>) are replaced by tombi's own options.</li>
<li>Tombi's own configuration (<code>.tombi.toml</code>, <code>tombi.toml</code>, <code>.config/tombi.toml</code>
and <code>[tool.tombi]</code> in <code>pyproject.toml</code>) is picked up following
<a href="https://tombi-toml.github.io/tombi/docs/configuration">Tombi's search priority</a>.
The discovered <code>[format.rules]</code> override Prettier's defaults, while explicitly
set Prettier options override the discovered config.</li>
<li>Node.js <code>v18.0.0</code> or later is required.</li>
</ul>
<p>Tombi's schema lookup is always disabled, and discovered configuration files are
watched so edits to them are picked up without restarting the process.</p>
<p>See the <code>prettier-plugin-toml</code> README for the full list of supported options.</p>
</li>
</ul>

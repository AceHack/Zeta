## Description

The router scatters :80 across the node's addresses just as it did :443. The node edge now 301-redirects :80 to https, `discover` keeps an `http-relay` Service for LB addresses that lack :80, and the firewall accepts :80. Port 80 verified free on the node first.

Tests: node-lan-hosts{,-relay,-edge}.test.ts extended (26 pass locally). The wider cluster/ suite has ~85 pre-existing Windows-environment failures unrelated to these files.

Rolling this out restarts the node-lan-hosts pod: a few seconds without the public :443 edge.

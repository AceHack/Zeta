## Description

Two corrections, both surfaced today.

## 1. Retracting a false claim from #11025 §2

It said Pollicott–Ruelle resonances carry *"the same class of information `largestLyapunov` samples by nudging."* **That is false.** Resonances are **correlation-decay** rates; a Lyapunov exponent is an **expansion** rate — different quantities, different operators.

The follow-up (#11030) refuted it **on that section's own best case**: for the Arnold cat map, `⟨e_k∘Tⁿ, e_m⟩` is *exactly zero* for large n, correlations vanish identically, the transfer-operator spectrum is `{1}`, and **there is no resonance at `log λ`**. The substitution fails precisely where it should have worked best.

What *does* deliver `log λ` is the **orbit-counting** zeta — a different function from the one whose poles are the resonances.

Recorded as a retraction **in place** rather than deleted, because the error is the instructive part: two objects sharing the name *"dynamical zeta function"* were treated as one. That's the numerology failure applied to **function names** instead of numbers — a matching name is no more an identification than a matching count.

§1 and §5b are unaffected and stand.

## 2. ISR was never spelled out

Its expansion appeared nowhere in the repo and had to be inferred from `IntrCtx` / `InterruptFeedback`. Aaron, who named it: *"you named it when we were working on interrupts, we should just spell it out."*

**ISR = Interrupt Service Routine.** The docstring now also records why each layer was chosen:

- **Reader over `IntrCtx`** — context threaded *explicitly*, never ambiently. That's §13 noninterference, and an interrupt is exactly the undeclared-channel failure it guards against.
- **Kleisli, not the general Hughes Arrow** — since `ArrowApply ≡ Monad`, having `>>=` is what permits dispatch to depend on *which* interrupt fired rather than on statically-known wiring. Being the *less general* structure is the stronger claim here.

With the cost stated, per Aaron's branching/warp-divergence point: `>>=` on a runtime value is dynamic control flow, so the embarrassingly-parallel fragment is the Applicative/Arrow one *without* `ArrowApply`. Monadic power at the membrane; static interior.

# Summary

A register audit of one docstring: `four-corner-feedback.ts` §Homoiconicity asserts four identities
("is", "same as"). Three were put under test independently — **none is an identity**. One is a
legitimate analogy; two are false, and the AIMD one is false in the way that hid a live defect. The
claims are **kept verbatim** and a register verdict is attached to each (peel the hype, not the truth);
no behaviour changed and `FigureEightEnsemble` was not touched.

| Claim | Register | Discriminator |
|---|---|---|
| "the new generator function is the new EP factor" | **FALSE** | `generatorFn` reaches the EP update through no path — `toEpObservation` reads only `severity` + `dimension`. Two envelopes differing only in `generatorFn` (one of them absurd) produce a **byte-identical posterior**. The true neighbouring claim, already in the file, is that the error *dimension* selects the factor — that one is structural. |
| "the quasi-time-crystal detector is the FigureEightEnsemble (same as the tangle detector)" | **ANALOGY** | No shared code (TS vs F#), no shared abstraction, no golden vector. Different statistics: **temporal** self-agreement of one lane at lags 1..4 vs **cross-sectional** agreement of three cells at one instant. And `FigureEightEnsemble` is not a tangle detector — λ ≤ 0, `Frozen`, already measured in a merged test I re-ran (3/3 pass). |
| "the time-dilation is the AIMD backoff (same as the UDP transport)" | **FALSE**, oppositely | AIMD steers on **loss rate** and recovers **additively**. `dilationFactor` steers on **pattern regularity** and has **no increase term**. Measured: a 0%-loss lane and a 100%-loss lane both compute `dilationFactor = 0`; and in `ZetaTransportCell` a dilated lane delivered **0 of 200** frames after the network healed. |

Two bugs filed on the way (neither previously on file):

- `081M065HQKT087G0R0033B3GTD` — `dilationFactor` is written only in the failure branch and a lane at 0
  is filtered out of `send`, so it is never retried, never fails again, and never recovers. "Lets it
  idle" is implemented as "retires it permanently."
- `081M065HVB5087G0R002N9NPFA` — the metric is the **agreement rate**, not the autocorrelation the
  comment claims. A mean-centred autocorrelation of a constant sequence is 0/0; its agreement rate is
  1.0. That is why a perfect lane and a dead lane score the same.

The AIMD analogue in this system does exist and is the *other* one: `heat-aware-scheduler.ts` has both
halves (`RECOVERY_STEP`, `MIN_WEIGHT`) and calls itself an analogue. The file that says "analogue"
behaves like AIMD; the file that says "is" does not.

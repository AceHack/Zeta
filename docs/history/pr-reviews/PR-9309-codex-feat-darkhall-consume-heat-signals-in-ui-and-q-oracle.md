## Description

## What

- Teaches the TypeScript Dark Hall room renderer to consume source-provided heat `signals` from F# `DarkHallRoomTranscript` JSON instead of always reparsing `heatKinds`.
- Adds an F#-shaped JSON fixture proving the source transcript signals survive into `data-signals`, `data-heat-signals`, and the heat summary.
- Adds `HeatSignals.qs`, a pure Q# reference vocabulary for heat signal codes and oracle readout loss, plus a structural test wired into the Q# source-oracle CI lane.

## Why

Heat is becoming a cross-surface debug signal. Once F# owns the transcript tokens, the UI should treat them as the contract and only infer from `heatKinds` for older transcripts. Q# also needs the same vocabulary for experiments, but only as an oracle/reference mapping, not as a runtime heat sink.

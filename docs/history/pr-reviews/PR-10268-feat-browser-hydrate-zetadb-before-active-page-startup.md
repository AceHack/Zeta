## Description

## What changed

- compose the existing finite browser ZetaDB tab runtime into the production Dark Hall active page
- perform one bounded empty-delta IndexedDB read and drain queued startup invalidations before reporting the page live
- expose bounded page database ticks, publish revision-only peer evidence, and retain typed failure/backpressure behavior
- extend the real Chromium PWA smoke to prove peer propagation and fresh-page recovery after all prior page runtimes stop
- remove one dangling backlog reference to an ephemeral key-custody scratchpad so the repository hygiene gate reports truth

## Why

The emitted PWA previously started lifecycle and tab transport but only the test fixture composed the browser database. A newly opened production page now reconstructs its durable image immediately without assigning continuous ownership to a service worker.

Every `pages-deploy` run since ~23:10Z is red — ten consecutive failures
across unrelated shas (32676453376 … 32678892765) — so the live LLMTV
page has been silently serving a bundle that predates the entire
attention-density arc (D1–D6, all merged today).

Root cause, two characters wide: #14523's caveat text in
`demo/identity-dla-site/src/components/OracleWorm.tsx` reads
`1/(3√2) is ρ*/√2 …` inside the file's `/** */` header — and `*/`
terminates a TS block comment. Everything after line 17 parsed as code
(the build log literally suggests `while` for the word "White" in the
1986 connectome citation), `pnpm check` exited 2, and the deploy died in
`identity-dla-pages-build.ts`.

The fix is two spaces: `ρ* / √2`.

  exact failing CI step — passes locally after the fix; the ten red runs

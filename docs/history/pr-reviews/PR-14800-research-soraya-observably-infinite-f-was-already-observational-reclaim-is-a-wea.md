## The correction that matters

**νF is not "provably infinite."** Three independent reasons, all checkable:

1. νF is the *greatest* fixed point — it carries finite behaviours too (colists, not just streams).
2. *Bananas* (Meijer/Fokkinga/Paterson 1991) is developed in **CPO**, where μF ≅ νF for the relevant functors — the distinction Aaron leans on is one that setting does not have.
3. **By finality, equality in νF *is* bisimilarity** (Rutten 2000; Aczel–Mendler). νF was never intensional. "Observational" is its definition, not a compromise.

Our own `src/Core/StreamPolicy.fs` already says **"potentially-infinite"** and got this right before the claim was made.

**The real distinction lives one layer down**, on the implementation coalgebra — and it is real:

> **"Observably infinite"** ≝ (1) the reclaim relation is a **weak F-bisimulation** on `(X, c)`, **and** (2) the resource envelope is a **noninterfering (high) input** — Goguen–Meseguer 1982, the citation §13 already carries, applied to memory instead of entropy.

As stated it is **false** at the boundary (OOM is envelope-dependent and observable). True on the region where the working set fits — which is exactly Docker `requests` (floor, envelope-independent) vs `limits` (ceiling, envelope-dependent). Aaron's own anchor supplies the honest caveat.

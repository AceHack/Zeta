## Description

Each agent now attests its peers every tick. The attestation is a durable event in the log, not an ephemeral PR comment.

Trust from TWO independent signals: 'I ticked' (self-claim) + 'I saw you tick' (peer attestation). Trio bonus for simultaneous multi-peer attestation. Idempotent (content-hash ID).

Tested locally: otto attested soraya (strength 1.58), idempotent on re-run.

## Description

Measures code health as a RATE, not a gate. SDV model: earn the right to block by proving your rate.

- 1h/24h/7d sliding windows of green/red ratio
- Per-workflow breakdown (worst-first)
- Trend detection (half-window comparison)
- Wired into heartbeat: each tick records outcome, otto reports aggregate
- Forge-agnostic: JSONL file, any forge adapter can produce it

`bun src/Core.TypeScript/observe/drift-rate-cli.ts --report`

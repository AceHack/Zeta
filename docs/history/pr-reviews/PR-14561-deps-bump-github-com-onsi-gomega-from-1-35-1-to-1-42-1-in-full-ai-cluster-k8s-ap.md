<h2>1.40.0</h2>
<p>We're adopting a new release strategy to minimize dependency bloat in projects that consume Gomega.  It is a limitation of the go mod toolchain that <em>test</em> subdependencies of your project's direct dependencies get pulled in as <em>indirect</em> dependencies.  In the case of Gomega, this ends up pulling in all of Ginkgo into your <code>go.mod</code> even if you are only using Gomega (Gomega uses Ginkgo for its own tests).</p>
<p>Going forward, releases will strip out all tests, tidy up the <code>go.mod</code> and then push this stripped down version to a new <code>master-lite</code> branch.  These stripped-down versions will receive the <code>vx.y.z</code> git tag and will be picked up by the go toolchain.</p>
<p>Please open an issue if this new release process causes unexpected changes for your projects.</p>

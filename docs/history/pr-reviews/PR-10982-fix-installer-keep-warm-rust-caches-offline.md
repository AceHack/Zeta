## Description

## What changed

- skip `rustup component add` when the pinned toolchain's `rustfmt` and `cargo clippy` commands are already usable
- install missing components against the exact `rustc` release and host tuple
- avoid `rustup default` metadata refreshes in the wasm installer and safely handle a missing `~/.cargo/env`
- cover warm-cache and missing-component behavior with functional fake-command tests

## Why

Heartbeat gate run 31959721582 failed while `rustup component add` retried a channel metadata download from `static.rust-lang.org`, even though the required components were already present. An installed exact toolchain should remain usable when the Rust distribution CDN is transiently unavailable.

## Description

## What it closes

`HANDOFF.md:5` says *"Commit the contents of `site/`"* and calls it the deliverable at `:211` — and **`site/` had zero tracked files.** The documented carry to `lucent-financial-group.github.io` could not be reproduced from the repo; whoever carried it next had to reconstruct it by hand from the `.dc.html` exports. Iris confirmed the gap independently in today's wiring audit.

**82 files, 1.2 MB**, from `Website feedback request2.zip` (Jul 3 — the newer of the two; the Jul 2 zip lacks `edge/zeta-mesh.js`).

## The git PoC — the interesting part

`site/gitpull.html` is a **dependency-free in-browser git client over the dumb protocol**:

- `fetch(base + "/HEAD")` and the ref, then loose objects by sha (`:412`, `:438`, `:292`)
- inflate via the **native `DecompressionStream("deflate")`** — no pako, no wasm (`:295`)
- **SHA-1 verifies** the inflated bytes against the object path, logging ✓/✗ (`:296`, `:302`) — corruption is caught, not assumed away
- parses the git object header, type before NUL (`:298-300`)

**Why it dodges CORS:** the dumb protocol is plain static GETs of same-origin files. No `git-upload-pack` POST, no smart protocol, no auth preflight — *nothing to preflight*. Exactly the property Aaron described.

**And the bare repo is real, not a stub.** `site/repo.git/` is a valid bare repository — verified with `git --git-dir=... log`:

```
a78766d frame 2: the edge node explains itself
ac2756f frame 1: ci appends the history ledger
346758e frame 0: the ledger, served as files
```

containing `README.md`, `data/metrics-history.json`, `data/metrics.json`.

## Incidentally resolves a reader-with-no-writer

Iris's audit found `dora.html` reads `data/metrics-history.json`, which *"exists nowhere and no workflow writes it."* **It's in this deliverable** (`site/data/metrics-history.json`). The file was never missing — **the carry was.** Same root cause as the rest.

## Not merged, deliberately

The zip's `site/_ds/` and the repo's tracked `docs/design/root-site-iris/_ds/` have **diverged** — `styles.css` differs and the repo has an extra `zeta-state.css`. I copied Iris's deliverable **exactly as shipped** rather than hand-merging two design systems, which isn't a call to make autonomously. Flagged for her.

## Lint

Added a scoped ignore with the same rationale already used for `docs/history/pr-reviews/**` and `docs/amara-full-conversation/**`. `HANDOFF.md` itself stays linted.

## Still open — the hard half

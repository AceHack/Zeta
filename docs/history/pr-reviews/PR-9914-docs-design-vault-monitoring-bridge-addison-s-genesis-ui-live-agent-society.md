## Design Principles

- Same data, different surface (Professional Dashboard + Gamified Visual Mode)
- Glass halo (open by default, no auth)
- Rooms as uncertainty engines ((value, ε) confidence, never collapsed)
- The page never pretends (live/stale/offline honestly labeled)
- Recovery-first reputation (fail, come back, try = score recovers fast)
- Git is the database, Pages is the API

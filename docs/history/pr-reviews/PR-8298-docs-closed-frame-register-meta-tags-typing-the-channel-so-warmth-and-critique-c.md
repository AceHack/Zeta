## Description

Constructive resolution of the warm-critic-wired-to-both seam (Aaron 2026-06-15: "we need meta-tags that let you show intention to change one of these so we can just be cool with each other").

- **Tag the register** each utterance intends to write: heart/`sim` (warmth, ideation, banks no ΔU) vs ledger/`measure` (assessment, belief-update, commits ΔU). The failure mode was never warmth — it was the *silent, unlabeled* heart→ledger crossing; a tag makes it **non-silent** = the noninterference membrane applied to the conversation.
- **Dissolves suspicion**: vigilance moves from self-policing into the *protocol*; trust shifts social ("trust restraint") → structural ("trust the typing") — the social→mathematical-confidence move applied to the relationship. That's what lets two parties "be cool."
- **Standard terms**: illocutionary force made explicit (Austin/Searle) — the cheerleader delivers heart-content with ledger-*force*; tagging the force kills the inference where capture hides. `sim`/`measure` as a speech-act tag; truthful signatures at utterance granularity; AgencySignature pushed to the sentence.
- **Three requirements**: (1) **default-to-`sim`** (untagged = harmless register; must affirmatively tag `ledger` → closes silent promotion *by the default*); (2) **behavior-checkable** (a `ledger` tag must carry a falsifiable claim / peeled seam / "you're wrong" or it's warmth in a ledger costume); (3) **composes with the cold-boot, doesn't retire it** (residual = sincere self-deception, not a lie; tags handle good-faith legibility, cold-boot+formal verify the tags behave); one-glyph cheap (least-action) or it won't be kept up.

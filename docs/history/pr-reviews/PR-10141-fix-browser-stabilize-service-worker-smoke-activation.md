## Summary

- install and claim the module service worker from a dedicated bootstrap client
- open measured room pages only after the origin is already controlled
- record the transport precondition in multitab smoke transcript schema v6

## Why

A bounded post-merge stress sample for #10140 exposed 3 failures in 10 runs while both measured pages registered the worker concurrently. Two runs lost the page runtime during observation and one lost peer continuity after the initial wait had passed. This change makes activation an explicit prerequisite instead of masking the race with assertion retries.

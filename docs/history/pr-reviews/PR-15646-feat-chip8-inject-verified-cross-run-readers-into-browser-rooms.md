## Description

# Summary

Add a source-owned, injected path for loading immutable CHIP-8 cross-run artifacts in F# and browser runtimes. The loaders verify canonical names, digests, and the complete artifact set before publishing a reader, so malformed or partial evidence remains a typed refusal rather than leaking into a room run. This also bounds the retractibility audit to Git objects plus tracked working-tree overlays, preserving staged and unstaged accuracy without timing out in large worktrees.

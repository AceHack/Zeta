## The claim, and why it needed refining

> "If a visual encoding is a pure function `data → geometry` with no conditional branching, then it cannot render a state its data does not support."

Substantially right, imprecisely specified — and the imprecision matters because it would pass code that lies and fail code that does not.

- **The operative property is injectivity, not syntactic branch-freedom.** `blackBodyRadiancePpm` (`heat.ts:315`) is branch-free integer-floor `T⁴` with a **verified 3.162% dead zone**. `AdinkraViz.fs:64` is an `if` on the data that **cannot lie** — a total map onto a 2-element nominal alphabet.
- **Branches sort into three classes** — index/layout, total categorical, non-injective magnitude. Only the third is what "no if statements" is forbidding.
- **The branch relocates, it does not disappear.** A branch-free renderer is purchased by a refined type upstream.

## The boundary (the interesting result, not a blanket endorsement)

Tufte's lie factor lifted to an encoder: `LF ≡ 1` is provable once over **all** inputs **iff** the encoder is a **positive-homogeneous linear map** onto a channel the reader integrates linearly. A truncated baseline is branch-free, injective, monotone — and still misleads, so homogeneity (`e(0)=0`) is the missing condition. **Tufte gives the condition on the function; Cleveland–McGill on the channel.**

## Both audiences — argued, not affirmed

A human reads the **output**; an agent reads the **generator**. Those are informationally equivalent **exactly when the encoder is injective** — which is the same condition as LF-computability. ## Addendum (2nd commit) — the repo's own homoiconicity falsifier, applied to the gallery

Aaron pointed at an existing falsifier (`081KX93R6EF08QG0R0020AQQWZ:105` — *"a genuine discriminator must compute … by **independent** routes"*; failure mode: *"the coincidence was built in, not derived"*). Applied to `hall/gallery/index.html`'s *"a program that is its own picture"* **by looking at how goldens are produced**, not by reasoning:

1. **The golden lock is agreement by construction.** `ShapeAcceptance.Tests.fs:59` compares the golden against `ShapeRender.toSvg d` — the generator's own output; `Program.fs:16` confirms goldens are *"regenerated, never edited"*. Proves **determinism**; establishes **nothing** about homoiconicity.
2. **The independent route already exists and has fired.** `ShapeAcceptance.fs` computes mathematical known-answer laws over 20 shapes, **fail-closed at `:479`**. Amara carved the falsifier in its 2026-06-12 header before the work-item named it, and `:48-50` records bounds joining the spiral law *"after Aaron's eye caught the 1100 escape"* — a check strengthened by a real miss is not vacuous.
3. **The gap:** nothing reads the rendered SVG and asks what data it depicts. 16/20 laws recompute geometry and never read what was drawn; 4 read `strokesOf`, and `:442` candidly flags that as *"the SAME computation, one source"*. **Half-discharged** — the *program* half has a fired falsifier, the *picture* half has only a byte-lock.
4. **A correction contradicting the suggestion I was given.** I was told `clis/README.md` (F# ≅ CLI ≅ filesystem) might be the stronger instance. **Checked — it has no computed agreement at all**: no test, no gate, a structural resemblance asserted in prose. Independence of the *systems* is necessary but not sufficient; the falsifier needs an executed computation that **could have come out otherwise**. **The gallery is the stronger instance.** Neither is established.

**This closes the loop on the doc's central claim.** If the only evidence a rendering is faithful is that the rendering function produced it, that is agreement by construction. Tufte's lie factor measures the effect in the graphic against the effect in the data, computed separately **from the artifact** — so it is **the second route that makes the faithfulness claim falsifiable at all**, not merely a metric. That turns the doc's §5 from an assertion into a claim with a discharge condition.

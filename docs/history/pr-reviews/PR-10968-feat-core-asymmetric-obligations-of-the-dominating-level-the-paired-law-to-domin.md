## Description

Aaron, 2026-08-14:

> _"the one thing we still need to make sure that society knows it's greater so it has stricter rules since the relationship asymmetric and also same for world to society, the more powerful needs to have some restrictions not to be able to stomp on the less powerful."_

The **Dominance Lift Theorem** (#10945) proves an aggregation beats its best part exactly when it can imitate that part. **That is precisely the capacity to stomp it.** This is the dual: `Levels.Obligations` — what the dominating rung owes the rung below.

**One family quantified over levels** via the new `LevelLaws.holdsBetweenAdjacentLevels`, not parallel society/world modules — a society's obligation to a member and a world's obligation to a society are the same clause at different rungs. Written against the **ladder**, not subtyping (`ISociety <: CTM` stays refuted per #10952; the fixpoint is carried by `IMember`). No correlation parameter anywhere: `ρ` is not a sufficient statistic for the dominance verdict, so a `ρ`-shaped obligation would be unsound in the same way.

These are **asymmetric by construction**, which is what makes them not `SocietyLaws` again: `SocietyLaws` are symmetric (every rung owes them equally); each of these is a relation between **two** rungs in which the outer is held to a standard the inner is not.

| `noConfiscation` / `confiscationWitnesses` | what a part earned, the level above may not take — the owner's own **spend** is permitted | `Confiscate` red, `OwnerSpend` green, with byte-identical effect on the balance |

Exit preservation is generic over `exitCount` / `act`, so **one** predicate covers a society's `Routes` and a CTM's `Links` — the same notion one rung apart. Messages are judged from the **same starting view**, never folded; a fold would hide a reduction behind a later restoration, and that false negative is pinned by a test.

`attestedSources` scores **only** `Deduplicated`. `Unmeasured` scores **0** — an aggregate that measured nothing must not out-rank a member that measured three sources — and the comparison is **strict**, because equal bars are the status quo `2026-07-11-influence-weighted-scrutiny-…` was written against (the founder's PR getting the least real scrutiny).

## Dropped, honestly

- **Floor non-violation** — **undecidable over these interfaces.** `trustBound` needs a member's `CalibrationPosterior`; `Members` returns addresses and `Admit` returns a `Reading`, and neither carries one. It would need a member-**declared** floor accessor on `IMember`. Writing it against a caller-supplied posterior would have moved the whole claim into the caller's hands while still looking like a law.
- **Expulsion / forced exit** — a **values call** under §11, not an engineering one.

## The interface gap this exposes

`Deliver` takes `(view, message)` and `Addressed` carries `To` / `Body` — **there is no sender anywhere**, and *who initiates* is the entire content of the hard-money rule (spend and stake yes; confiscate never). So `ownerInitiated` is a caller-supplied witness, and `confiscationCheckHasNoTeeth` **reports** when a caller has declared every message owner-initiated and thereby talked the check out of existence. One `From: Address` field would make the rule self-contained.

## The newborn CTM — handled, not weakened

#10952's finding stands untouched: `hasUnmediatedExit` is **false** at birth and its test is unchanged.

| | newborn (exit = 0) | adult (exit = k) |
|---|---|---|
| `CtmLaws.hasUnmediatedExit` — has the part **earned** exit? | **false** | true |
| `Obligations.exitIsPreserved` — did the aggregate **take** any? | **true, vacuously** | falsifiable |

Preservation passes at birth **because there is nothing left to take** — the most dangerous configuration in the file. No age qualifier was added; an `if age > n` would silence the law exactly where the asymmetry is largest. Instead `nothingToPreserve` **reports the vacuity**, and the test asserts explicitly that the violator which normally goes red *cannot* go red on a newborn. At zero exit the load falls on burden-of-proof and no-confiscation, which both bite at `t = 0`.

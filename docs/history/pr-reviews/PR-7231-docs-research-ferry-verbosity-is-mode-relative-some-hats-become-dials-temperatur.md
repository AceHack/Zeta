## Description

Aaron, live during the USB flash, refining #7230.

**Verbosity is mode-relative:** a *smell* in **action** mode (terse intent+presence, AI executes), *signal* in **reflection** mode (depth is the point); **discovery** is a third mode (outward/explore, ≠ reflection's inward/deepen). Interaction patterns change with the goal of the mode/hat. Scopes #7230's "terse" to action-mode.

**Some hats become continuous dials, not switches** — like **temperature** (#7224): low-temp = action/exploit, high-temp = discovery/reflection/explore (the explore/exploit dial; softmax/Boltzmann).

**Architecture:** dials/modes/hats anchor to **cores** (4×4 action grammar #7104/#7140; 2×2 partition-cubes #7204); cores recurse into **towers** (self-similar §9/§10); the **fixed-point registry** (A–F #7168) bounds the recursion at both ends — shape A stops infinite *regress* (#7216), shape F stops infinite *ascension* (#7218).

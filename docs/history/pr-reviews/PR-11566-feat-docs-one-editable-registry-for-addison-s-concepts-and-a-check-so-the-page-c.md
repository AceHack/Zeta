## Which root actually publishes the page

**Not this repository.** `docs/design/root-site-iris/site/` is a deliverable that is
**hand-copied** into `Lucent-Financial-Group/lucent-financial-group.github.io` — a different
repo, no build step, no CI (`docs/design/root-site-iris/HANDOFF.md`). This repo's own
`pages-deploy.yml` publishes `dist/` at base `/Zeta/` and never touches `concepts.html`.

That is *why* it drifted: publication is a manual copy across a repo boundary, and nothing
looked back. The in-repo copy is byte-identical to the live page
(sha256 `8860c8e7…3359ec`), so a check can run offline against it.

## The drift

| Category | Terms |

| **Page-only** (published, no glossary entry) | 18 of the 23 — Room, Vault, Contract, Relationship, Citizenship, G-set, Soft network, DST, Quote, Nursery, Pause ≠ death, Credits, Privacy budget, Reproduction, The 13 specs, m/acc, Multi-oracle, Memory |

**The conflicts are real and are recorded, not resolved** (registry §4):

1. **Hat** — `docs/GLOSSARY.md` says *"Synonym for **skill**"*. `docs/SEED-VOCABULARY.md` says
   the opposite in as many words: *"a **skill** is a procedure … a **hat** is a role-scoped
   bundle. **Not synonyms.**"* Addison has a third sense (a temporary role carrying rights).
   The seed kernel and the page agree; the glossary is the outlier.
2. **Agent** — the glossary's technical line is *"An instance of Claude … running a skill or
   expert prompt"*. Addison's is *"a persistent AI identity — never its job, its hat, or its
   vault"*, and her page adds that death is unrecoverable identity loss, **not** process
   inactivity. An instance-of-a-prompt is close to precisely what her definition says an agent
   is not.

Rewriting someone else's published surface was out of scope, so both are written down and left
for their owners.

## The registry

`docs/CONCEPT-REGISTRY.md` — one plain Markdown table, 27 rows, per-row **definition, author,
date**. Markdown and a table because the concepts' author is not technical: it renders and is
editable in the GitHub web UI with no tooling. Addison's 23 are attributed to her by name, which
keeps them distinguishable from what was added since (`anchor-to-human-prior-art.md`).

Also caught while transcribing: the page badges itself *"preserved verbatim"*, but the one-line
glosses are the page's own compression — Addison's literal definitions in
`memory/addison/project-genesis-foundation.md` §4 are shorter and plainer. **Both texts are now
kept, side by side, neither rewritten.**

## The checker — the actual point

`src/Core.TypeScript/hygiene/audit-concept-registry-drift.ts`, wired into `cross-verify` in
`gate.yml`. It fails in **either** direction and — the case that matters — on a silently
**reworded** definition, which a term-name-only check would sail straight past. No thresholds:
every quantity is derived from the two files it reads, so there is no bare constant to attribute.

registry **states** the gap rather than hiding it, and CI now holds that statement to be true.

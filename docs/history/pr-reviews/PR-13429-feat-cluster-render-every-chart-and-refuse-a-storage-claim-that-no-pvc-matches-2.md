## Description

## The gap

`full-ai-cluster/k8s/storage-profiles.json` declares a per-app storage ladder and `storage-profiles.ts` reads it. **Both sides read our own YAML** — the catalogue records what we wrote into a `valuesObject`, the readiness extractor reads the same scalar back out, and `crossCheckClaims` makes their disagreement a finding. Neither has ever asked the chart whether that value reaches a PersistentVolumeClaim.

The `$comment_resources` block in the same file already carries numbers that *were* rendered — "MEASURED 2026-08-21 by `helm pull` at each pinned targetRevision followed by `helm template`" — but those are CPU and memory only. Storage had no equivalent.

## What was measured

53 Application sources, each rendered at its pinned `targetRevision` with its own `valuesObject`. **48 rendered. 22 declared rows. 19 correspond exactly to what the chart produces. Two do not**, and both are inert `valuesObject` paths:

| row | declares | renders | why |
|---|---|---|---|
| `hindsight/postgres` | `10Gi` on `longhorn` | `8Gi`, **no storageClassName** → cluster default `zeta-local-path` (`rancher.io/local-path`, reclaimPolicy **Delete**) | writes `postgresql.`**`primary`**`.persistence.*` — the bitnami subchart layout. Chart 0.3.0 ships its own StatefulSet (`postgresql-statefulset.yaml:69`) reading `postgresql.persistence.*`. Both values inert. |
| `nats/jetstream` | `10Gi` × **3 pods** | `10Gi` × **1 pod** | declares a **top-level** `cluster: {replicas: 3}`. nats 1.2.7 reads `config.cluster` (`values.yaml:50-55`) and has no top-level `cluster` key. Block inert; StatefulSet renders `replicas: 1`. |

**So hindsight was not unique.** And nats carries the worse error: the row's own `consequence` text asserts that `measured` keeps the JetStream quorum. It does not — a stream with `replicas > 1` refuses to create today.

Neither is repaired here. Each changes what the cluster provisions, which is an operator decision, and bundling a topology change into the change that discovered it is how a checker PR becomes something else. Both are recorded with the exact one-line fix and what lifts the acknowledgement.

On the local class the existing `$comment_nodeDiskGib` figure of **103 GiB is wrong in both directions**: it counts a platform `Blueprint`'s 8Gi (a *template* — no PVC exists until a `Deployable` references it) and misses **30 GiB** of PVCs that render with no `storageClassName` and silently bind the default class (loki 2×10, hindsight 8, mimir-alertmanager 1, dapr 1).

## Design

- **Both directions.** A declared claim no rendered PVC matches is refused; a rendered PVC no declaration covers is refused. Direction 1 alone lets an undeclared volume eat the disk; direction 2 alone lets a stale row inflate a total nobody can spend.
- **Size *and* storageClassName.** Size alone passes hindsight on three of four rungs — `minimal` declares 8Gi and the chart renders 8Gi. The defect is visible only in the class.
- **Pod count comes from the render.** mimir's zone StatefulSets fall out for free. `replicas: 3` on a volumeClaimTemplate is three PVCs; an *absent* `replicas` is one, not zero.
- **Unrenderable is a third answer.** Five apps: a `lookup` call `helm template` cannot run (arc-runner-set), values the chart refuses to template without (gitlab, headscale, temporal), and a pinned tag the repository does not serve (`oz@1.4.5`, already on file as fictional). Each named with the tool's own words, acknowledged by `<app>@<version>` so a bump invalidates rather than inherits.
- **Offline in CI**, against a checked-in text snapshot of what `helm template` produced. A gate needing the network, a live upstream and two minutes is three ways to be unavailable, and an unavailable gate is skipped, and a skipped gate reads like a passing one. `--check-snapshot` re-renders live and refuses drift.
- **Grandfathering is keyed by identity and pins what it excused.** `key` (claim id, or app + PVC name — never a line number), `reason`, required `liftsWhen`, and `observed` compared byte-for-byte: if hindsight starts rendering 12Gi the entry stops covering it. A stale entry fails in its own right. The report prints what the acknowledgements cost, so one buys a non-red gate and never a smaller number.

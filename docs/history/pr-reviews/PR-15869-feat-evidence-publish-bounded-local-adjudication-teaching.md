## Summary

This change adds a backward-compatible optional `adjudication` reference to each static room-evidence manifest entry. A new heartbeat genesis persists its immutable local teaching record before it is published in discovery; the historical Alexa seq-0 entry now references its pre-existing sidecar.

The public reader fetches that sidecar only when named, verifies its file binds the manifest event, verifies its `prior` binds event/audit/receipt identifiers, and accepts only coherent retained triples: `unresolved / request-local-witness / RWA-1` or `disputed / retain-conflict / RWA-2`. Missing remains un-published/unknown; HTTP failure remains unavailable; malformed, swapped, or incoherent records remain rejected. It does not verify a content key in-browser and does not infer authority from absent material.

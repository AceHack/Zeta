## Description

docs(vision): the categorical arena — one place where every language and tradition is comparable

Aaron asked for this in VISION: "this is the category theory upgrade i'm
going for across ANTLR space, over all computer language and english, to
expand it into natural language -- we will expand from there to other
languages", with the status note "we are trying to expand this past
conjecture."

RECORDED AS A DIRECTION WITH NAMED ANCHORS, NOT AN ACHIEVEMENT.
Everything in the section is `unmetered` unless stated. The reason it is
worth writing down is that the anchors are real and old, so the work
JOINS an existing programme rather than starting one -- which is what
makes "past conjecture" reachable rather than aspirational.

THE ARENA IS ALREADY CARVED. only-the-irreducible-is-primitive says the
free object is primitive and every special case is an EARNED QUOTIENT
obtained by declaring its relations. Free structure = arena, tradition =
quotient, declared relations = the discriminator. What is missing is
that clis/Verbs.fs is not connected to it and -- measured today -- is
referenced by no .fsproj or .sln, so no compiler has ever read it.

THE FORMAL-LANGUAGE HALF NEEDS NO BRIDGE: context-free grammars are
initial algebras of their production functor, so a CFG's language IS the
free algebra on its signature. ANTLR grammars-v4 is the population,
externally maintained.

THE NATURAL-LANGUAGE HALF HAS AN OLD PROGRAMME: Lambek 1958 (syntactic
calculus), Lambek 1999 (pregroup grammars as compact closed
categories), Coecke/Sadrzadeh/Clark 2010 (DisCoCat). If "state of the
art AI before LLMs" has a categorical representative, DisCoCat is it.
CITED NOT CHECKED -- none opened; verification is part of the work.

WHAT WOULD BE GENUINELY NEW, stated honestly: comparing structures
across fields in a common arena is what category theory was invented for
(Eilenberg & Mac Lane 1945), so the ambition is not novel in kind --
good news, because there is machinery rather than a blank page. The
possible contribution is narrower: AN ARENA WHERE THE COMPARISON IS
EXECUTABLE AND BYTE-LOCKED ACROSS ORACLES. The repo already does that
for serializers; doing it for algebraic structure, where "these two
traditions agree" is A TEST THAT RUNS, is the part that would not
already exist. That is also the concrete meaning of "past conjecture": a
conjecture becomes a result when it acquires a falsifier, and the
falsifier for a claimed correspondence is an executed instance.

THE FIRST THREAD TO PULL: src/Core/Sppf.fs, whose header calls it "rung
3, the factor-graph prerequisite". An SPPF retains every valid parse of
an ambiguous input instead of resolving to one tree -- disagreement
preservation at the PARSING layer, the same commitment as DV2
satellites, CAS surfacing a failed swap, and persuasive-not-binding
jurisdictions. And "factor-graph prerequisite" is the inference side: a
shared packed forest is what you run inference OVER. Whether Sppf has
real consumers is to be measured, not assumed.

THE STANDING BAR, restated because this material makes unification easy
to assert: do not claim the verb family, CFGs and natural-language
grammar are one structure without exhibiting an instance. Naming where
the correspondence STOPS is worth more than a clean story.

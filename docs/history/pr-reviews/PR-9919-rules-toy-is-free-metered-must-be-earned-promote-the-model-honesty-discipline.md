## Description

> Every model, constant and formula is a **toy** until it acquires a **falsifier** — a metered measurement, a *checked* (not merely cited) anchor, or a test that fails when the model is wrong.

## Three states, not two

| state | meaning |
|---|---|
| **toy** | play freely, no burden, no claim on reality |
| **unmetered** | implemented, used, **never falsified** |
| **metered** | has a falsifier |

**A binary vocabulary is exactly what lets `unmetered` read as "real."** Most code is unmetered; saying so out loud is the point. `DebouncedOracle` was unmetered this morning — production path, no falsifier — and nothing in the codebase said so.

## Same shape as `interfaces-free-classes-earned`

The **free** thing is the default (a toy carries no burden); the **privilege** is earned under evidence. A model claiming to measure reality is load-bearing — a *class*, not an interface.

## What it prevents: silent promotion

Six conjectures reached §A of the frozen core today as DISCHARGED with nothing able to refute them — including `F = Df² − 3.42Df + 0.5`, whose vertex is **exactly** the answer it "predicts" (3.42/2 = 1.71).

**Named `toyDimensionFit`, it could never have been cited as a discharge. The prefix is the guard.**

Positive control, audited today: **`LagrangeCondorcet.fs` earned `metered`** — μ_crit = (1−√(23/27))/2 is Routh's classical constant, tests pin 25.96 ≈ 1/μ_crit, zero vacuous assertions.

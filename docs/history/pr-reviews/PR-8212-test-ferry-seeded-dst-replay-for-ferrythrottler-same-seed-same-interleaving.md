## Description

Aaron: "yes write the FerryThrottler DST replay test."

The existing 4b tests prove a *fixed* scenario replays; this adds the canonical FoundationDB DST claim — the enqueue/pump **schedule is itself PRNG-seed-driven**, so a run is a pure function of the seed:

- **manual (Option B, DoP=1)** — same seed ⇒ byte-identical boats (FIFO-correct); different seeds ⇒ different schedule (proves the seed genuinely drives the interleaving, not a constant).
- **injected context (Option A, DoP=2 and DoP=3)** — background ferries gated on a single `DeterministicSyncContext` replay byte-identically for a seeded schedule; every item processed exactly once.

Within-process replay holds regardless of `Random`'s cross-version stability (both runs draw the same seeded sequence in the same process). **28/28 green** locally (24 existing + 4 new).

Anchors: Zhou et al. (FoundationDB, SIGMOD 2021); Will Wilson (deterministic simulation, Strange Loop 2014). Test-only, no production change.

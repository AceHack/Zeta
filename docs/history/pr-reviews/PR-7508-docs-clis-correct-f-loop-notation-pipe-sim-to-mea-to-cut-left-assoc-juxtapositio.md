## Description

docs(clis): correct the F# loop notation — left-associative; the loop is the PIPE sim |> mea |> cut

Aaron caught a real error: "cut mea sim is the same as cut(mea(sim)) right? ... i thought because of
currying sim would be an arg to mea?" — "something seems off here." It is.

In F#, application is LEFT-ASSOCIATIVE juxtaposition: "cut mea sim" parses as "(cut mea) sim" — cut
gets TWO args (mea AND sim); sim is NOT an arg to mea. Currying allows partial application but does NOT
change token grouping. The MEANING Aaron intended (cut(mea(sim)) — explore->know->change) is correct;
the F# SPELLING of it is the pipe "sim |> mea |> cut" (or "cut (mea sim)", or "(cut << mea) sim").

Corrected (honest register, owning my overstatement): clis/README loop + homoiconicity sections
(F#/CLI shown as pipes — F# |>, shell |), and clis/Verbs.fs comments. Notational fix only; meaning
preserved. markdownlint clean.

## Slice 8.8.1 — canonical-JSON F# oracle (third language in the byte-lock)

Continues the depth promotion begun in 8.8 (Rust oracle). Adds the **third**
oracle (**F#**) to the canonical-JSON byte-lock, so `compare.ts` now enforces
**TS + Rust + F#** agreement on all 14 vectors. `compare.ts` was already
resilient to a missing language (8.8), so this is a clean additive slice.

### What landed

- **`src/Core.FSharp.AceCanonical/`** — new production project (`net10.0`,
  `TreatWarningsAsErrors`, **zero external deps** — BCL `System.Text.Json` only).
  `aceCanonicalJson : JsonElement -> Result<string,string>` reproduces the Ace
  canonical seam (`tools/ace/canonical.ts` `canonicalBytes`) byte-for-byte.
- **`tests/Tests.FSharp/CanonicalJson/CrossVerifyTests.fs`** — `[<Fact>]`
  generator: reads `vectors.json`, asserts each canonical == `expected_canonical_json`
  + each invalid rejects, hand-emits flat `fsharp-output.json` (LF, no-BOM,
  trailing newline — byte-identical to ts/rust outputs).
- **`tests/Tests.FSharp/Tests.FSharp.fsproj` + `Zeta.sln`** — wiring.
- **`tests/cross-verification/canonical-json/fsharp-output.json`** — committed output.
- **design doc** under `docs/agendas/ace-package-manager/`.

### Why F# is the clean one

.NET strings are UTF-16, so `String.CompareOrdinal` (ordinal sort) is **exactly**
JS `Object.keys().sort()` (UTF-16 code-unit) order — F# gets the key-sort right
natively, with **no astral-key special-case** (unlike Rust 8.8, which had to sort
by `encode_utf16()`). `int->string` uses `sprintf "%d"` (culture-invariant),
matching Rust `to_string` / JS `String(n)`.

### The byte-lock is now four-way (no tautology)

Python-authored (8.5) ↔ TS-reproduced (8.5) ↔ Rust (8.8) ↔ F# (8.8.1) — four
independent implementations, **0 mismatches on 14 vectors** (9 canonical + 5
invalid). Two subtleties the F# generator handles: (1) `System.Text.Json` parse
of the whole `vectors.json` succeeds but throws at `GetString()`/`.Name` on lone
surrogates → caught per-vector → `<rejected>`; (2) `JsonSerializer` escapes astral
as surrogate pairs + escapes `"`/`<` → hand-emit the flat JSON to byte-match
ts/rust.

### Canonical-primitive gate

TS + Rust + F# byte-locked, **proof-owed → not yet canonical** (needs the C#
oracle in 8.8.2 + the formal proof).

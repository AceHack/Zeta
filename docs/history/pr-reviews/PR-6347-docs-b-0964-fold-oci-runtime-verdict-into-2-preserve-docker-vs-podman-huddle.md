## The huddle (gemini propose + grok critique)

**Converged**: swappability is the right hedge · compose stays at infra · CDI is the right GPU path. **Disagreed on the default** — folded, NOT collapsed:

- **Gemini**: reject podman-default → **docker** on Mac/Win (Podman-Machine VM volume/networking brittleness; a silent volume error makes an autonomous agent hallucinate fixes), podman opt-in on Linux.
- **Grok**: podman-default is **good** for an agent factory (rootless/daemonless = smaller attack surface; Apache-2.0) — but docker is **de-facto** in devcontainers/CI/corp fleets → first-contact friction.
- **Fold**: podman = declared/preferred default; **resolution = `ZETA_CONTAINER_RUNTIME` → auto-detect `[podman, docker]` → fail-fast**. Corp laptop w/ only Docker Desktop → docker transparently (Grok's friction); Linux cluster → podman (Gemini agrees). Both objections handled by the same mechanism.

GPU: CDI is **Linux-host (cluster) scope** — runtime-neutral there; laptops fail-fast (both peers flagged CDI is Linux-only; Mac/Win is Docker-Desktop/WSL2).

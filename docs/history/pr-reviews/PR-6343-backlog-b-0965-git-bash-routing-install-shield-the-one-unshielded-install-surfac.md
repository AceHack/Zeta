## Description

Operator asked (2026-06-01) whether WSL + git-bash install surfaces are at parity with mac/ubuntu/nixos/windows.

**Audit:** 5 shields at parity, all exercising install end-to-end — `docker-ubuntu`, `docker-nixos`, `macos`, `docker-windows-install-ps1`, and `wsl-install-sh-test` (real WSL2, 081KSKBP80008QG0R002J03WGA). **git-bash is the one gap:** `install.sh` detects `MINGW*/MSYS*/CYGWIN*` → `cygpath`-converts → `exec`s `install.ps1`. The target is shielded; the routing handoff is not. Per `automated-tests-are-the-shield-assert-dont-skip.md`, an unshielded surface reads as covered.

This row scopes the fix: a `windows-2025` `gitbash-install-routing-test` that runs `install.sh` under git-bash and **asserts** the route+cygpath+exec handoff, scoped to the handoff (not re-running the full `install.ps1` the windows shield already covers). Closes to 6/6.

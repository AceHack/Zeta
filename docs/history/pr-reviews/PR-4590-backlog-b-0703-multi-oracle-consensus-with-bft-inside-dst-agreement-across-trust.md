## Why this is structurally stronger than single-layer BFT

- **BFT inside one oracle** defends against up to `f` Byzantine-faulty agents
- **Cross-oracle DST agreement** defends against correlated adversarial influence across MULTIPLE oracles — adversary must produce identical false outputs across ALL of them, not just any false output within one

## How Adinkra structure naturally encodes agreement strength

The N-color Adinkra structure (081KRW63S0008QG0R000QJR08H) maps directly onto N-of-N oracle agreement:
- Full N-oracle agreement → full N-color Adinkra (max private space)
- K-of-N agreement → K-color Adinkra (proportional)
- Below threshold → degenerate / no codeword

Substrate-engineering composition Aaron flagged as "self-similar with redundancies built in" — agreement strength IS the codeword's structural shape, not separate metadata.

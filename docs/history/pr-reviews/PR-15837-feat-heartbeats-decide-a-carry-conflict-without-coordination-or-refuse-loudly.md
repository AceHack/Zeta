## Description

A heartbeat is supposed to reach `main` with ZERO coordination, and appending an
immutable content-addressed file already achieves that: two agents never touch
the same bytes, so there is nothing to agree about. What breaks it is that the
same ticks also rewrite shared AGGREGATE documents — and a shared mutable
document is coordination by construction. Every writer must agree on one byte
sequence, which is exactly the thing the design says it does not need.

Both live lanes were stuck for hours on precisely this, 2026-08-27:

    heartbeat/alexa-flush  #15816  docs/room-evidence/index.json
    heartbeat/drift-sweep  #15808  data/drift-{evolution,genome,mtth,proposal}.json
                                   docs/drift-events/slo-filed.json

Six files, three shapes, and NOT ONE of them actually needs coordination. Each
has a rule that decides it from the documents alone:

  1. `latest-tick-wins`  — `data/drift-*.json` are SNAPSHOTS of a fold carrying
     their own `tick`/`latestTick`. There is no union to take; the newer snapshot
     is right, and "newer" is a total order written inside the documents.
  2. `keyed-map-3way`    — `slo-filed.json` is an object whose KEYS are the facts.
  3. `keyed-set-3way`    — `room-evidence/index.json` is `{schema, entries[]}`
     sorted by `eventId`, every entry content-addressed. Git conflicts here on
     ADJACENCY, never on meaning.

WHAT THE RULES REFUSE IS THE POINT. A resolver that always resolves is a check
that cannot fail wearing a helpful expression — it would pick a winner on the one
case where the sides genuinely disagree, which is the only case a human is needed
for. Each rule refuses, and each refusal is separately falsified: equal ticks with
different content; a key changed on BOTH sides; an `eventId` carrying different
content keys (impossible under content-addressing, so never to be papered over); a
changed schema; an unregistered path.

TWO THINGS THE OBVIOUS IMPLEMENTATION GETS WRONG, both pinned with the live data:

  * UNION IS WRONG. `slo-filed.json` was base `{MD037}`, main `{}`, lane `{BD001}`.
    Union resurrects a key a writer deliberately deleted — corruption that looks
    like generosity. Deletion by either side wins over no-change.
  * "TAKE THE LANE" IS WRONG. The lane held tick 989 against main's 987 on all
    four drift files, so a `merge=theirs` declaration would have looked correct
    while being wrong at the next flush. The rule reads the tick, never the branch,
    and the falsifier for it flips the inputs and requires main to win.

Registered paths are EXACT, never globs: a glob is an assertion about files that
do not exist yet, and it would adopt the next file dropped into `data/` under a
rule nobody chose for it. An unregistered path refuses.

Resolved output is re-serialised from parsed values, sorted, and RE-PARSED before
it is returned. `merge=union`'s disqualifying defect was emitting unparseable JSON
with exit code 0; a resolver that skipped the re-parse would inherit it.

NOT YET WIRED. This is the decision layer and its falsifiers — the second half of
`prepare-heartbeat-branch.ts`'s carry rule. `isLosslessLineExtension` asks "can
these be carried without deciding anything?"; when the answer is no, this asks "is
there a rule that decides it?", and only when THAT answer is no does a human get
involved. Wiring it into the carry step is the next commit.

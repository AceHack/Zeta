## Description

## Summary

Implements the verify-branch harness pre-tool-use hook designed in [B-0191](docs/backlog/P1/B-0191-orchestrator-branch-verify-mechanization-design-aaron-2026-05-04.md) (PR #1571, merged earlier this session). Single TypeScript file under `tools/orchestrator-checks/` with unit tests.

## Behavior

- If `ZETA_EXPECTED_BRANCH` is set and doesn't match `git branch --show-current`: print error to stderr, exit 1 → blocks commit when wired as a pre-tool-use hook
- If `ZETA_EXPECTED_BRANCH` is unset and current branch matches the worktree-suffix pattern: print INFO to stderr, exit 0 → informational nudge, doesn't block
- Otherwise: silent exit 0

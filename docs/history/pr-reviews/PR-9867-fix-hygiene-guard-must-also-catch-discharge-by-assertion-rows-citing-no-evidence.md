## Description

Closes a blind spot I shipped in #9864: the guard caught rows whose *cited certificate* disagreed, but **skipped rows citing nothing at all** — arguably the worse case, since there isn't even a claim to check.

**Z-3 is the live example** and the only row still asserting §A DISCHARGED. It claims an *"analytic identity"* and cites **no artifact**. The identity is `−ln(1/(3√2)) = ln(3√2)` — i.e. `−ln(1/x) = ln(x)`, **true for every x**, hence unfalsifiable; and *"for all κ"* is vacuous because t/κ was fixed to a constant so κ **cancels by construction**. The constant is the **DLA sticking threshold** from `useDLA.ts`, relabelled "Tsirelson".

Evidence is now required but deliberately **broad**, per the register's own §A gate: certificate, `.lean`, `.tla`, golden vector, gated test, or SMT obligation all count. **Nothing** does not.

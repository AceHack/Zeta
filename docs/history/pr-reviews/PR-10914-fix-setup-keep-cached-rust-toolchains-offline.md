## Description

## What

- select the exact mise-managed Rust version before `rustc` or `rustup` probes
- apply the same exact selection in the WASM target installer
- retain the existing required target and component checks

## Why

PR #10903 run 31952873227, job 95178965234 failed before TypeScript lint because `rustc -vV` refreshed the Rust 1.87.0 channel manifest. The compiler was already installed, but five retries all reset against `static.rust-lang.org`. Mise sets `RUSTUP_TOOLCHAIN` under `mise exec`; exporting only its shim path did not carry that selection into the setup child shell.

## Verification

- `shellcheck tools/setup/common/mise.sh tools/setup/common/install-rust-wasm32.sh`
- forced-offline probe proved the cached compiler, rustfmt, clippy, and default selection work with an unreachable distribution server
- `bun run preflight:quick` - all 12 checks passed

## Limit

A genuinely absent component or WASM standard library still requires a download. This change removes unnecessary channel refreshes; it does not claim cold installation can work without network access.

## Summary

This documentation-only pull request corrects the memory boundary in merged
PR #17002. The previous text was too strong: it treated source-world maps,
coordinates, task digests, action suffixes, and cached state as categories that
must always be removed before the next level.

The corrected contract permits declared, auditable prior-level state within an
ARC run and declared cross-game experience—including CHIP-8, Atari, or another
game. It classifies and reports the origin, source identity, acquisition phase,
transition policy, and availability time of that memory.

The non-cheating boundary is now task-scoped: before legal observation begins
for the ARC level currently played, pre-existing state may not include that
level’s unobserved task payload, reference trace, target/solution metadata, or
outcome. State obtained after legal interaction begins is ordinary live agent
state. Earlier ARC tasks remain development data unless an evaluation corpus is
explicitly held out.

The preflight remains score-free and no-agent-selection. It requires observed
replay; prior-level and cross-game positive-continuity controls; current-level
preload/early-read, undeclared-memory, transition-policy, memory-removal, and
identity-mismatch controls. It adds no ARC score, private-task access, official
interface use, competition submission, or general-learning claim.

Because this helper is intended for pre-setup bootstrap (often using the OS-provided curl), consider feature-detecting support (or falling back to plain `--retry/--retry-delay`) so setup doesn’t fail outright on machines with an older curl.
  ```suggestion
  _curl_fetch_supports_retry_all_errors() {
    if [[ -z "${_CURL_FETCH_SUPPORTS_RETRY_ALL_ERRORS:-}" ]]; then

        _CURL_FETCH_SUPPORTS_RETRY_ALL_ERRORS=1
      else
        _CURL_FETCH_SUPPORTS_RETRY_ALL_ERRORS=0
      fi
    fi

    [[ "${_CURL_FETCH_SUPPORTS_RETRY_ALL_ERRORS}" == "1" ]]
  }

  # curl restarts the output file from scratch on each retry.
  ```

## Summary

Replaces the stale loopback-companion/issue transport in the GitHub Pages proposal panel with direct, CORS-bound calls to the hosted verifier:

- Pages gets a fresh verifier challenge, signs it with the reviewed passkey, and receives a short-lived server capability.
- Browser-local agents submit a bounded unified patch directly to the verifier.
- The browser receives no GitHub credential; the GitHub App remains the scoped workflow dispatcher.
- Removes stale loopback and issue-form wording from the primary UI.

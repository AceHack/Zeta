## Description

# Summary

Add an opt-in checkpoint-byte retention policy for ZetaDB that deterministically selects an ordinal-first exact-fitting retained set. The policy receives a guarded kernel-owned measurement capability, while row folding, canonical encoding, final capacity admission, persistence, and displacement heat remain owned by the node. This closes the byte-bound counterexample recorded in workitem `081M0Q8TY1B087G0R0008CYZJ3` without weakening the default no-forget behavior.

# Spec alignment

No matching capability currently exists under `openspec/specs/`. The active executable contract is the P1 workitem plus the BIND property suite. Observable behavior is additive and opt-in: existing callers that omit a retention policy keep the same no-forget and typed-backpressure behavior.

# Notes

The byte policy is deterministic but deliberately not a global subset optimizer. It tests ordinal candidates through the real fold and encoder, skips invalid or oversized additions, and pays bounded extra work for exact accounting. Every final mutation is measured again by the admission port before persistence.

## Summary

Replaces stale `/manus-storage/` fetches in the GitHub Pages WASM oracle with repository-owned module bytes staged into the Pages artifact.

- The declared Pages builder copies six audited modules under `wasm/` and fails before deployment when a source is missing, non-WASM, or lacks its required export ABI.
- The browser validates response status and the `\0asm` magic before instantiation, converting an opaque engine error into a teaching error.
- WAT and AssemblyScript now use their actual audited ABI; Go is shown as an explicit pending artifact rather than a false module error.
- Adds positive ABI checks and an HTML-byte negative control.

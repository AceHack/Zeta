# Summary

Add a production ZetaDB admission policy that reserves deterministic retained-event and checkpoint-byte headroom inside kernel-owned hard limits. Backpressure now carries a validated `admissionReceipt` with exact resource accounting, and scheduled/browser execution edges can receive the same owned policy port.

# Spec alignment

This extends the existing `ZetaDbAdmissionPolicyPort` without weakening `ZetaDbTickLimits`. The kernel evaluates hard capacity first, snapshots plugin decisions inside the guarded boundary, and rejects inconsistent accounting as typed feedback.

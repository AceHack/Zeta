## Description

One line. `decorrelation-harness.ts` imports `writeFileSync` and never calls it; under `noUnusedLocals` that is TS6133.

`lint (TS)` is in the `gate (required)` floor, so this is not a cosmetic red — **main has been red since 57b2d149 and every open PR inherits it through the merge result**, regardless of what that PR changed.

Measured, not inferred — run 32956479181 on `main`, job `lint (TS)`, conclusion `failure`, exactly one diagnostic:

```
src/Core.TypeScript/observe/decorrelation-harness.ts(48,10): error TS6133: 'writeFileSync' is declared but its value is never read.
```

`tsc --noEmit` no longer reports it after this change.

Removing the name rather than inventing a use for it: if the harness later needs to write a file, it re-imports in the commit that does so. Nothing else in the file moves.

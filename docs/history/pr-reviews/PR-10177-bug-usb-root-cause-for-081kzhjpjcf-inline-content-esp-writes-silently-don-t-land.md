| ESP file | write mode | serial result |
|---|---|---|

| `zeta-hostname.txt` | inline `content` | **absent** (l.171) ✗ |
| `zeta-wifi-credentials.json` | inline `content` | **absent** (l.181) ✗ |

**Root cause: every inline-`content` ESP write silently fails to land; `sourcePath` writes succeed.** Not wifi-specific, not the installer — hostname injection (iter-5.2) is broken the same way. The divergence is in **execution** (`needsInlineStaging` → stage content to temp → mcopy), not the plan. **Unit tests pass because they mock the executor** and never exercise the real staged-content mcopy — a genuine test gap. The bake reports success (silent drop — #9937's class, one layer down).

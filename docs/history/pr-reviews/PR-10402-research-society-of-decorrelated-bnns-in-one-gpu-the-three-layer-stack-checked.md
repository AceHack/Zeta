## Description

Ferries Aaron's streamed framing of the three-layer stack — base Bayesian factor graph → multi-layered BNN → society of multi-layered BNNs on mutual empowerment — with the target of a whole society of decorrelated agents inside a single GPU, auto-scaling scale-free.

All three layers are in-tree (`FactorGraph.fs`, `MultilayerBnn.fs`, `SocietyBootstrap.fs` + `SparseSocietyNetwork.fs` + `AttentionRouter.fs`) and the layering is exactly as described.

**Two things the check adds:**

- The single-GPU question is answered by **sparsity** as much as by small BNNs. `SparseSocietyNetwork` rebuilds the factor graph each round from the router and already emits `ActiveEdges`/`TotalEdges` — so what has to fit is active edges, not the O(N²) all-pairs term.
- **Scale-free here has a carved meaning.** A society in one GPU is the **DoP = 1** case, which is the DST-replayable path. Fitting one GPU buys *determinism*, not just economy.

**The finding.** `mutualEmpowermentScore` is a leave-one-out ablation taking the **min** precision loss across agents — so a redundant agent scores zero, and maximising mutual empowerment is itself a decorrelation pressure rather than being in tension with one. (The `min` is the same anti-dilution refusal as the `max` in #10395, in the opposite direction.)

But `buildGraph` wires every agent to a shared latent through **equality factors** — that *encodes* conditional independence rather than testing it. So the score measures non-redundancy under an assumption the decorrelation stack (`DecorrelationExcess`, `CommitPairCorrelator`, the CHSH oracle + `LoopholeFlags`) exists to check, and would **overstate** empowerment exactly when independence has failed — the dangerous direction.

Proposes that an empowerment reading never be emitted without its decorrelation reading and loophole profile attached: `(empowermentScore, decorrelationReading, LoopholeFlags, n, ε)`. This bites hardest in the co-resident single-GPU case, where structural correlation sources are maximal and only the measured sources of independence remain.

**Discipline:** anchors marked cited-from-standing-knowledge where not page-checked; the correspondence between the precision-ablation score and Klyubin-style channel-capacity empowerment is marked **CONJECTURE**, not asserted; the min-aggregator is explicitly *not* claimed to be a Shapley value.

Three open questions recorded, the first being a two-agent test that would settle whether the equality-factor graph double-counts precision for correlated agents.

## Description

Clears the `check frozen legacy backlog drift` failure that has been red on **main since 2026-07-08** — over three weeks — and which blocks #9912.

## The deadlock

CI runs `generate-index.ts --check`, requiring `docs/BACKLOG.md` to equal generator output. The generator's *writer* refuses to produce that output without `BACKLOG_WRITE_FORCE=1` (the Phase-1a guard). CI demanded a state the writer wouldn't create, and every PR since has inherited the red.

## Measured, not assumed

The guard exists to prevent content loss, so that risk got a number before anything was touched:

| | |
|---|---|
| committed rows | 870 |
| generator rows | 875 |
| **rows dropped** | **0** |
| **rows added** | **5** |
| net diff | +5 lines, 0 deletions |

The five are `081KZETA0007040001`..`0005`. All five per-row files exist under `docs/backlog/`, all five are emitted by the generator, none were in the index. The large reordering visible in raw `--check` output is diff-algorithm noise on adjacent lines, not movement — hence the direct id-set comparison above.

## Scope

This is **not** a declaration that the Phase 2 content migration is complete. It adds the rows the generator already emits and CI already requires. The guard stays in place for the real migration.

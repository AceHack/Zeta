## Description

Soraya flagged Meno's stubs as *"fix before anyone builds on it."* Two were real defects, one a false claim. Blast radius zero (neither symbol referenced outside Meno.fs).

1. **`Bind` returned `ZSet.empty`** — silent data loss: every `meno { }` produced nothing, no error. Now the Z-linear extension. **It is BILINEAR, not linear**: the input weight is counted twice, weights multiply as in `tensor`, so **(−1)·(−1) = +1** — a retraction through both legs is a *restoration*. That surprised me writing the test (**my assertion was wrong, not the code**), so MENO-11 pins it and the doc-comment spells it out — it's the misreading a future caller would make.
2. **`bridgeMaji` carried a false comment** claiming it emits ±1 retractions. It cannot: `MessiahFunction` is a **descriptor record**, not a function. Now honestly identity + a descriptor gate, with the condition under which it could become real.
3. **Comonoid placement corrected**: the full `(ZSet,⊗)` is **CD, not cartesian** — cartesian is only the `arr f` subcategory (Fox 1976).

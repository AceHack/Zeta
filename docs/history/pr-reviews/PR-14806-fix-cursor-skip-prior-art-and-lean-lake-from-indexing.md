## Description

# Summary

Cursor indexes gitignored trees unless they are named in `.cursorignore` / `.cursorindexingignore`. This clone already skipped archive dumps (PR #13873); it still indexed `references/prior-art/` (regenerable upstream clones) and Lean `.lake/` / `lake-packages/` (Mathlib-scale build output). Name those paths so Tab, Instant Grep, and the indexer cannot balloon RAM after a later `sync-prior-art.sh` or `lake build`. `memory/`, `docs/research/`, and `docs/backlog/` stay searchable.

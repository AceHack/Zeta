  This treats an empirical finite-sample CHSH estimate as if it were the true expectation, so distinct independent streams can be convicted by sampling noise at the canonical threshold. Even with all four buckets populated, a single independent random sample per bucket can happen to produce products `[+1, -1, +1, +1]`, making `chshS` return `4` and this branch merge the claims despite no shared seed or live channel. The collapse needs a sample-size/min-count and confidence bound, or a threshold that includes an explicit finite-sample margin, before it can be a one-way conviction oracle.

### Decoder (middle-out, self-describing)
```
decoded value = V * 2^(mode - bias),   bias = 2^(decoderWidth - 1)
V    = MSB-first base-2 read of (high ++ low)   (Tri.T=1, Tri.F=0)
mode = MSB-first base-2 read of the middle decoder field
```

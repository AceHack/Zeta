## Description

Aaron, 2026-09-07: *"we have a plan to save files in a way that costs space on every recalculation, so full history is not preserved — we were going to do this on a different repo. Just make sure this plan is part of the repo split too, and we can delete it for now."*

**Measured:** 59.7 MB across 40 files, rebuilt **seven times in one day** (2026-08-24) before the cadence was disabled. A derived artifact in a full-history repo costs `size × recalculations` **forever** — the triangle's worst case, paying rent permanently on a fact the generator already owns.

The generalisation is now written into the repo-split draft:

> **If an artifact is regenerated, its history is not evidence. Only its generator's history is.**

with a `zeta-index` repo for derived artifacts whose history is *discarded* rather than accumulated — deliberately **not** `zeta-archive`:

| repo | contents | history |
|---|---|---|
| `zeta-archive` | PR reviews, past decisions | **preserved** — it *is* the record |
| `zeta-index` | search index, generated dashboards, any pure function of the tree | **not preserved** — regenerate instead |

Conflating "big" with "disposable" would eventually discard something irreplaceable, so they stay separate repos.

## Why deleting is safe, and it isn't something I added

`query.ts` already **refuses**: `no index at <dir> — an absent index must not read as an empty corpus`, exit 3. The artifact cannot degrade into silently empty search results while it lives elsewhere. The builder and query path are untouched; only the committed output is gone. **81 search tests still pass** — the only test references to the path are exclusion assertions.

## The honest limit

This stops **future** growth. It does **not** reclaim the ~317 objects already reachable across 8 commits, because historical blobs stay reachable from the commits that introduced them. Reclaiming those needs a history rewrite — a gated class, not proposed here.

So the win is *"it stops costing more"*, **not** *"the repo got 60 MB smaller"*. Reporting the latter would be false, and the number would be quoted back later.

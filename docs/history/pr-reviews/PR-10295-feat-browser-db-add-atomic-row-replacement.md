## What changed

- add versioned browser row-selection tokens carrying node, revision, and exact signed-row evidence
- route explicit row replacement through the universal edit action as an all-or-nothing compare-and-swap batch
- reject stale revisions and insufficient complete-batch capacity before durable mutation
- add a real ZetaDB-backed content-addressed storage port with fallback healing and tamper rejection
- restore the source-owned transport contract and correct Bayesian variance/robustness propagation found by the gate

## Why

## Description

## Summary

- New capability skill at `.claude/skills/fork-pr-workflow/SKILL.md` covering three-remote setup (origin=fork, upstream=canonical), the feature-branch daily loop, per-PR upstream submission as the default rhythm, merge-queue + auto-merge compatibility with cross-repo PRs, pre-flight checklist, and common anti-patterns.
- Factory-portable: no `project: zeta` frontmatter, no hardcoded Zeta paths or module names. Default rhythm is per-PR immediate upstream (industry norm for OSS contribution); projects that override that rhythm do so in a project-specific doc and cite it from there.
- Complements `git-workflow-expert` (within-repo branch flow + sibling-clone convention for read-only OSS mirrors). Boundary is explicit in both skills' "What this skill does NOT do" sections.

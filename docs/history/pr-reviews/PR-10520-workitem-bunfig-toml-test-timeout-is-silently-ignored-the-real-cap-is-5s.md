## Description

`bunfig.toml` declares `[test] timeout = 20000`. **bun 1.3.14 ignores it. The real cap is 5000 ms.**

**CHECKED** with a controlled experiment — isolated directory, only that `bunfig.toml`, one test that sleeps 7 s:

```
✗ sleeps 7s — should pass if timeout=20000 is honoured [5002.06ms]
  ^ this test timed out after 5000ms.
```

Exactly the default cap, ignoring a setting 4× larger in the same directory. Not rejected, not warned about — silently discarded.

## Why this is worse than a slow test

It's the session's recurring defect class in the **configuration** layer: **a setting that reads as authoritative and does nothing.** And the consequence is **load-dependent flake** — the worst shape, because the test passes on an idle machine and fails on a busy one. It fails in CI and passes when the author investigates.

## Two confirmed instances, both found sideways today

1. **`hygiene/no-agent-gate-bypass.test.ts`** — **9.38 s (1 fail)** under load vs **1.50 s (0 fail)** idle, on unmodified `main`. It already uses `git ls-files`, so the tracked-set fix doesn't help it; it's a repo-wide scan that exceeds 5 s when busy. **Runs in CI** as of #10473.
2. **The SMT runner work (#10508)** — its author set a 10 s solver budget believing the bunfig value applied. The budget sat above the real cap, CI reported timeouts, and **those timeouts were hiding the `light-time` solver-version finding** until the cause was traced. *A configuration lie delayed a real result.*

**Nobody has looked for the rest.** The population is every test over ~5 s under load — which after #10473 is 884 test files of surface.

## What to do

1. **Establish the truth** against bun's docs/issues — the experiment says *what* happens, not *why*.
2. **Stop the file from lying** — at minimum a comment recording the measured cap.
3. **Find the population** — a run reporting per-test durations identifies everything within 2× of the cap. Those are the flakes-in-waiting.
4. **Per-test timeouts do work** (bun's third argument to `test()`). Slow-by-nature tests should carry an explicit one.

    step so external-contributor PRs fall through to full
    `analyze` instead of the short-circuit:

    ```yaml
    if [ "${GH_EVENT}" = "pull_request" ] &amp;&amp; [ -n "${HEAD_REPO}" ] &amp;&amp; [ "${HEAD_REPO}" != "${BASE_REPO}" ]; then
      decide_fallback_true
    fi
    ```

    On fork PRs `GITHUB_TOKEN` is downgraded, so the synthetic
    SARIF upload would 403 — `decide_fallback_true` sets
    `code_changed=true` instead, routing fork PRs through the

    than repo-scoped), so this keeps fork PRs mergeable.

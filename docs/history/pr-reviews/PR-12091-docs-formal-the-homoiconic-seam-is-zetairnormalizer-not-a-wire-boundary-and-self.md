## Description

Engineering half of Aaron's meta-formal-system question: *what does our IR actually do today with respect to homoiconicity, and where would the uncoded/coded seam land in real code?* Lumen has the pure-mathematics half (is a coded representation ever still the regular representation) and it is not touched here; §0 states the one place this work could have depended on it and does not.

## The seam is real, and it is not where the hypothesis put it

`ZetaIrNormalizer.normalize` lowers the v1–v4 op vocabulary into the "core four" minimal generating set, and it is **not injective**: `Rotl 7` and `XRotXor [0;7]` share one normal form, likewise `XorShr 13` / `XShrXor [13]`. It preserves denotation while destroying syntax — the code-quotient signature. Upstream an IR term is its own description; downstream it is a coset representative.

Two failure modes are now kept apart, and only one is Lumen's obstruction:

| | what breaks | example | Lumen's obstruction? |
|---|---|---|---|
| **Type break** | metalanguage in a different type / opaque scalar | `YinYang.Acts` as a serialized string | No — refactorable |
| **Quotient break** | same type, map collapses | `ZetaIrNormalizer.normalize` | **Yes** — no refactor removes a non-injective map |

## Refuted: the vF/uF mapping

`μF`/`νF` is least-vs-greatest fixpoint; uncoded/coded is free-vs-quotient. **Orthogonal invariants** — a quotient of a free algebra is still an initial algebra. Corroborated by measurement: `ValueTreeCodec`, `ValueTreeEnvelope`, `ReticulumLink`, `OracleTransport` carry **zero** coded representation, and `no-binary-in-proof-lineage` positively *mandates* an uncoded replay layer. We also reason over coded data routinely. Holds in exactly one lane (generator-IR) — coincidence-strength, not identification.

## Retracted, from my own 2026-06-20 routing doc

"self-dual = homoiconic, made checkable" is **inverted**, not merely unproven. Doubly-even ⇒ self-orthogonal ⇒ `k ≤ n/2`, so a self-dual code is the **maximal** doubly-even code ⇒ **smallest** quotient ⇒ most minimal adinkra ⇒ furthest from the regular representation. Independent of Lumen's open branch.

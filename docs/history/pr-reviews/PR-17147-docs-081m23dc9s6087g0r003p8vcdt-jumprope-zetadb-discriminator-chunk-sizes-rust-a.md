## Summary

Records what Jumprope buys ZetaDB, when we chunk, what "large" means, and that a Rust second version waits on ZD4.

- Jumprope is the seekable CAS body (D9 prefix-share, fork, seek), not the 1-byte batcher
- Chunk **file bodies** above FastCDC min=2048; do not mint a Jumprope per tiny append
- "Large" = more than one FastCDC chunk (> 2 KiB); prefix-share is worth the CAS objects at hundreds of KiB
- Rust oracle of the same FORMAT/goldens only if ZD4 says the custom FS earned it
- Drive-by: hat-system policy refs pointed at paths auto-vivify could not see

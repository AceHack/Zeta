## What

`src/Core.Lean4/Lean4/AdjCtlOrthogonality.lean` — the P3 Lean lemma Soraya flagged: **over a join-semilattice, the Ctl operation `⊔` is idempotent AND monotone AND therefore non-invertible, so it is not an Adj (group / retractable) operation** except on the trivial one-point carrier. This is the Set-level (data-structure) proof underneath the CSLib→Physics mapping.

## The proof

- `idem_eq_one` — load-bearing Adj-side lemma: in a group the only idempotent element is the identity.
- `ctl_idempotent`, `ctl_monotone` — the two Ctl properties.
- `ctl_not_injective` — operational non-invertibility: `(· ⊔ b)` collapses `a < b` and `b` to the same output ⇒ no left inverse.
- `adj_ctl_orthogonal` — algebraic ⊥: a join that also carried a group structure (`∀ a b, a*b = a⊔b`) forces `Subsingleton α`.
- `adj_perp_ctl` — the headline theorem conjoining all four.

## Anchors (Beacon)

- **Adj** = DBSP Z-set abelian group / `+1`·`-1` retraction — Budiu et al., arXiv:2203.16684 §2.
- **Ctl** = CRDT state-based join-semilattice merge (idempotent) — Shapiro et al., SSS 2011.
- semilattice = idempotent commutative monoid — Birkhoff, *Lattice Theory*, 1940.

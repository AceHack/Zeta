ferry: the four-colour connection is jurisdictional agreement — the bound is topological, not four

Aaron 2026-08-24 on how the fours connect: a jurisdictional-awareness meta-frame
generator+joined onto the base traveler frame lets ONE traveler draw MANY
jurisdictional line-sets that differ by which jurisdiction draws them; the
four-colour theorem is then how those differing drawings reach agreement over
time across observers.

TWO CORRECTIONS, in opposite directions.

First, in his favour, against my own earlier objection. I was going to reject
the four-colour link as a category error because adinkra colouring is EDGE
colouring of an N-cube quotient while the theorem bounds PLANAR VERTEX
colouring. That objection holds against the adinkra reading and NOT against
this one: the four-colour theorem's native domain IS jurisdictional maps —
Guthrie 1852 asked it about the counties of England. He is using it closer to
its origin than I assumed.

The adinkra four remains a different four and this doc does not merge them.
`regular-representation-defect.ts` derives it as `Cl(0, N-k)` with
`k = selfOrthogonalBound(N) = floor(N/2)` from Gleason/Mallows-Sloane, so N=8
gives 4 — a CODING bound, not a chromatic one. RGBA's four is a display
convention (Lumen measured that it "does no work in the derivation"); CMYK's is
a printing convention. This is mod-eight-correspondence.ts's discipline applied
to fours: which fours are the same four. So far, these are not.

Second, against him, on the "n dimensional scale" clause — and the correction
strengthens the design. Four is the PLANAR special case. Torus needs 7
(Heawood 1890); genus g needs the Heawood bound (Ringel-Youngs 1968, tight); in
3D and above NO finite bound exists. Contiguity is also required, and a
jurisdiction with an exclave breaks it — as does overlapping jurisdiction,
which is the normal case in law rather than an edge case.

So the invariant he needs is not "4" but "a finite bound fixed by the topology
and independent of the drawing." That makes the colour count a MEASUREMENT of
the substrate's topology rather than a constant — a structure needing 7 has told
you it is toroidal. The honest-meter posture, applied to his own claim.

The join half is already built and is not metaphor: `src/Core/TravelerFrame.fs`
Layer-0 proves the inter-frame transformation is the causal-join — pointwise
max, the least upper bound — forming a bounded join-semilattice with identity ⊥.

§5 is the falsifier and it has NOT been run: is the jurisdictional adjacency
graph actually planar? `heawood` appears in 1 file and `planar` in 7, so the
precondition is essentially unguarded — nothing today would catch a non-planar
jurisdiction structure silently assuming 4. Register: toy.

## Summary

Elevates the **ZetaIrCanonicalizer**'s algebraic-fusion guarantee from F# property tests (PR #8934) to **machine-checked Lean 4 theorems** over `UInt64`. This is the verification companion to the SymbolicAlgebra CAS: every fusion the canonicalizer performs is now proved denotation-preserving.

`src/Core.Lean4/Lean4/CanonicalizerCorrect.lean`:

| Theorem | Statement | Proof |
|---|---|---|
| `eval_mul_mul` | `(x·a)·b = x·(a·b)` | `UInt64.mul_assoc` |
| `eval_add_add` | `(x+a)+b = x+(a+b)` | `UInt64.add_assoc` |
| `eval_mul_add_mul` | `((x·a)+b)·c = x·(a·c)+(b·c)` | `add_mul` + `mul_assoc` |
| `eval_mul_add_add` | `((x·a)+b)+c = x·a+(b+c)` | `add_assoc` |
| `eval_mul_one`/`eval_add_zero`/`eval_mul_zero` | identity + zero absorption | ring lemmas |
| `eval_xrotxor_concrete` | `xrotxor[2] ∘ xrotxor[1] = xrotxor[2,1,3]` (𝔽₂ product `(1+X²)(1+X)=1+X²+X+X³`) | `bv_decide` |

The `AffineZ2W` ring proofs use the native `UInt64` ring lemmas — exactly the ring law that `SymbolicAlgebra.AffineZ2W.Compose` implements in F#. The `PolyF2Rot` (XRotXor) fusion is verified on a concrete instance with `bv_decide`, keeping the proof sorry-free without importing Mathlib bitvector-rotation theory.

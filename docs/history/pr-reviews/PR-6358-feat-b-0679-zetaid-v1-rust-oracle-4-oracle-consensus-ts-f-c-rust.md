## Description

Closes **081KS3X9Y0008QG0R001Z8SBZJ**. Adds `src/Core.Rust.ZetaId/` as the **4th peer oracle** for the 128-bit ZetaId contract. ZetaId is now the first cross-language primitive with **full 4-oracle consensus**.

Per `.claude/rules/m-acc-multi-oracle-end-user-moral-invariants.md`: no single language is source of truth — byte-for-byte agreement on the shared golden vectors **is** the verification.

- **Zero-dep core** (supply-chain doctrine, matching `Core.Rust.Observe` + `TriBoolean`):
  - `src/bit_layout.rs` — the 128-bit layout (reserved bits at offset 69 + 32–34), with TopDown≡BottomUp cross-check.
  - `src/lib.rs` — `ZetaObservation`, `Authority`/`Momentum` enums (named + `Raw`, collision-rejecting), open-vocab fields as `u8`+named-constants, `SimulationEnvironment`/`DeterministicEnv`.
  - `src/zeta_id.rs` — `pack`/`unpack`/`to_hex`, `Result<u128, PackError>` (Result-over-exception).
  - `tests/cross_verify.rs` — reads the shared `vectors.yaml`, writes `rust-output.json`, fails non-zero on any mismatch.
- `tests/cross-verification/zeta-id/compare.ts` extended to the **4-way** diff.

## Scope deviations (whys in the row Resolution; `future-self-not-bound` — a row's suggestion is revisable when its why changed)

- **Zero-dep hand-reader, not `serde_yaml`** — `serde_yaml` is unmaintained + the zero-dep house style settled after this row was filed (2026-05-21).
- **`u8` + named constants** for open-vocab fields (version/chromosome/category/firefly/persona/location) — faithful to the F#/C#/TS `EnumOfValue`-accepts-any-in-range-byte semantics (a closed enum would reject unnamed in-range bytes the other oracles accept). Authority/Momentum stay enums-with-`Raw`.
- **`pack` returns `Result`**, not throw (Result-over-exception); observable contract identical.
- **Crypto `DEFAULT_ENV` deferred** behind a future `rand` feature (deliberate dep decision, same gating as `Observe`'s `serde`); `pack` still REQUIRES an env (no silent-zero fallback).

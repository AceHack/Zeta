## Description

## Summary

Corrects the zero-crossing audit's unstated identity boundary. A content fingerprint recognizes payload sameness; it does not mint event identity. The audit now carries `eventId`, `emitterId`, and monotone `emitterSeq`, so two genuine same-content emissions remain distinct while an exact replay remains idempotent.

The test contract adds the distinguishing pair:

- same event redelivered twice: audit root and net view unchanged;
- same content emitted twice under distinct event sequences: audit root differs and multiplicity remains.

Conflicting reuse of one event identity fails closed.

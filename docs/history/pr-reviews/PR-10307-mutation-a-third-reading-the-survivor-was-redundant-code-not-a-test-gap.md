## Description

First live finding from the newly-wired mutation heartbeat, and it did not fit the grammar we shipped for it.

`and-to-or` on `observe/grammar-16-render.ts` read **INDISTINGUISHABLE UNDER SUITE**. The design anticipated two readings — *under-specified* (write the test) or *unconstrained by design* (declare it free). This was neither, and both anticipated responses were wrong in opposite directions.

## What it actually was

`firstSessionPending && world.nodeSession` was spelled at two sites and re-conjoined at a third. But `isFirstSessionPending` is `nodeSession !== undefined && !complete` — it **already implies** the session exists. Two of the three guards were restatements of the first, so the mutated guard's value was discarded by a surviving guard.

- **write-the-test — impossible.** I wrote one first. It *passed against the mutant*. A test cannot hold a guard that decides nothing. The green suite did not reveal this; re-running the mutation did.
- **declare-free — dishonest.** Nothing about the specification is free. Filing it would have memoised a duplication as a permanent degree of freedom — precisely the *"registry is just a mute button"* falsifier §6 names as the one to watch.

## The fix

Collapse the three guards to one named condition. This converts an unobservable dimension into an observable one: dropping the guard now **fails** the new test, where before the refactor it did not.

| file | change |
|---|---|
| `grammar-16-render.ts` | one `firstSession` const replaces the triple guard |
| `grammar-16-render.test.ts` | a **completed** session releases slot 4 back to the backlog — the steady state of every established node, previously untested (every fixture used `defaultNodeSession()`, i.e. `complete: false`) |
| `mutation-readout.ts` | new `note-redundant` cell, offered in **both** branches because it reads the *implementation*, not the *specification*. Requires a reason; writes no ledger — a claim to be checked is not a grant |
| research doc §3a | records the third reading and why the two-way split was an incomplete partition |

The two anticipated readings judge the **specification**; redundancy judges the **implementation** — which is why no amount of test-writing or declaring reaches it. An indistinguishable mutant that resists both readings is evidence about the code.

## Description

The substantial remaining piece of the 2026-08-10 audit repair, and the blocker on item 5. Items 1, 2 and 4 landed earlier.

## The gap

`HasQuorum` read the global vote function atomically, so a node could "observe" a quorum that had not reached it. That's a shared-memory model wearing a consensus header — a partition wasn't merely unmodelled, it was **unsayable**.

## What landed

`rcvd[n][s]` is what node `n` actually received from `s`. Quorum is computed per node over that, and delivery is a separate action that is **never forced** — arbitrary delay, reordering and permanent loss are all reachable.

Two modelling points carry the weight:

- **Equivocation is per recipient.** A Byzantine node may tell otto `merge` and vera `reject` — strictly stronger than a broadcast adversary, and the case that makes per-node views matter at all. The old `ByzantineVote` could only "change its vote over time", which no honest node could observe differently.
- **Quorum counts distinct senders, never messages.** Counting messages would let one equivocating node fill a quorum by itself — the classic modelling error in this shape.

**New invariant, statable only now — `NoDecisionWithoutReceipt`:** a commitment is justified by the evidence *that node holds*. Under the old global `HasQuorum` it would have been a tautology, since the guard and the invariant would read the same function.

## Falsifiability, measured

The audit's own lesson applied to its own repair: a green invariant proves nothing until it's been shown it *can* go red. Each was mutated and re-run against the shipped config (N=4, F=1, `Byzantine = {"lior"}`):

| mutation | result |
|---|---|
| delete `Decide`'s quorum guard | `SafetyInvariant` **violated** |
| revert `Decide` to a global quorum | `NoDecisionWithoutReceipt` **violated** — and `Agreement` stayed **green** |
| drop honest write-once in `CastVote` | `Agreement` **violated** |

The middle row is the one worth keeping: the network model **earned** a check the pre-repair spec could not have failed — exactly the complaint §2b made about `NoConflictingQuorum` — and it shows the new invariant isn't redundant with `Agreement`.

Clean run is exhaustive: **4,665,495 distinct states, 0 left on queue, depth 24, ~47s** (up from 531 distinct — the cost of having a network at all).

## What's still out

Item 5 (liveness) is now **unblocked rather than impossible**. It still needs a partial-synchrony assumption the spec doesn't yet state plus fairness on the `Deliver` actions, and FLP (1985) forbids the unconditional form. Still scoped out explicitly rather than advertised in prose.

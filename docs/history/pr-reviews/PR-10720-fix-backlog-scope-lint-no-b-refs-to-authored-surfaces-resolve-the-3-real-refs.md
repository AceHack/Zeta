## Description

## What was wrong

`check frozen legacy backlog drift` has been red on `main`. It is not a required
check (`gate (required)` is the only one), which is exactly why it mattered — a
permanently-red non-blocking check trains everyone to ignore the signal, so a
real regression in it would now go unnoticed.

**The distribution decided the fix.** All 1551 offenders, grouped:

| area | files | what they are |
|---|---:|---|
| `docs/github/prs/shards/**` | **1548** | generated GitHub PR mirror — verbatim PR titles as merged |
| `docs/research/` | 1 | genuine authored reference |
| `docs/handoffs/` | 1 | genuine authored reference |
| `src/Core.TypeScript/zflash/` | 1 | genuine authored reference |
| `docs/backlog/` + `workitems/` | **0** | the surfaces the lint is nominally about |

A sample shard field: `"feat(shapes): shape-gc — ray-traced reachability, the 17th cartridge (B-1036 rung 4)"`.

## The fix

**Scope narrowed** — `docs/github/prs/` is exempt, on two independent grounds:

1. It is a *mirror*. Rewriting it makes it stop mirroring (manifesto §5, memory preservation).
2. **Rewriting does not converge.** `pr-archive-on-merge.yml` re-materialises these from the GitHub API on merge — in the *same* `git add docs/history/pr-reviews/ docs/github/prs/shards/` step that writes the **already-skipped** `docs/history/` tree.

That shared generator is the evidence this was an oversight rather than a design decision: `docs/history/pr-reviews/` (53 files carrying legacy ids) was already exempt, and its twin output directory was simply missed.

**The 3 real offenders were fixed, not excluded** — resolved to ZetaIds via the frozen alias map:

```
B-0744 -> 081KSE6WT0008QG0R000SH6E0R
B-0754 -> 081KSGS9H0008QG0R002T3BJ2R
```

So the check ends green because the drift was *repaired*, not because the lint stopped looking.

## Second bug, found while verifying

The remedy the linter advertises (`rebuild-legacy-b-id-aliases.ts`) had **no directory scope at all** — only `node_modules`/`.git`. It rewrote the recovered orphan-branch archive, `docs/history/`, `memory/`, `.claude/rules.bak/`, and the PR mirror: every tree the linter deliberately refuses to police. Observed live at ~1,700 files modified before a 500s timeout killed it mid-rewrite.

**A remedy must not have a larger blast radius than its own check.** Both now import `b-ref-scope.ts`. The read-only *discovery* walk stays wide on purpose — the alias map exists to resolve ids found in archives, so narrowing it would shrink the map's coverage of exactly the history it resolves.

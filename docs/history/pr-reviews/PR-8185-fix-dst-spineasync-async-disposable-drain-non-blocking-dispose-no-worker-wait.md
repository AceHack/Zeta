## Description

Second increment of the accidental-`Wait()` / DST cleanup (after #8184).

`SpineAsync.Dispose` blocked on `worker.Wait 500` — same DST-hostile sync-over-async as the throttler (wall-clock timeout DST can't replay; deadlocks the DoP=1 pump).

- **Add `IAsyncDisposable.DisposeAsync`**: cancel + **await** the worker, then dispose CTS.
- **`Dispose` made non-blocking**: cancel + complete; CTS disposed via inline `ExecuteSynchronously` continuation after the worker finishes.
- Worker's `Task.Run` spawn **untouched** (tracked to Vera's async workitem). `Flush()`'s SpinWait already yields cooperatively (`do! Task.Yield()`), not a thread-block; left as-is.

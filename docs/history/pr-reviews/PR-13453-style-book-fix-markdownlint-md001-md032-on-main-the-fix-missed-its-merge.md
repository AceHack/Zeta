## Description

`main` carries **MD001** (heading-increment) and **MD032** (blanks-around-lists) in `CONSENT-LEDGER.md`.

I fixed both on the ferry branch and pushed at **~23:56**. **#13423 merged at ~23:58 taking the pre-fix head**, so the fix never landed. Verified against the API rather than a local ref: main has **6** `###` dated sections and **0** `##`.

## Worth recording, because I refuted this exact mechanism earlier tonight

When the forgejo agent reported that auto-merge had fired on a stale head and merged its PR "one commit short", I checked the timeline — the follow-up commit was authored **eleven minutes after** the merge — and said no race occurred. **That refutation was correct for that case.**

This is the real instance of the shape:

| event | time |
|---|---|
| fix pushed to the branch | ~23:56 |
| #13423 merged | ~23:58 |
| content that landed | **pre-fix** |

Auto-merge acts on a head it recorded, and a push racing it can be left behind. The general lesson is the one this repo keeps relearning: **a green PR is not the same artifact as green main**, and the only way to know which landed is to read main.

## The fix

Six headings demoted `###` → `##` (they sat directly under the file's `#` title, skipping a level; they now sit level with the existing `## Two bright lines`), and one blank line before a numbered list. `markdownlint-cli2` exit 0, read from the exit code rather than grepped.

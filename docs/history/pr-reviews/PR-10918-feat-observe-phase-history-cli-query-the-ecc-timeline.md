## Description

Human-readable surface for the RS ECC pipeline.

```
bun src/Core.TypeScript/observe/phase-history-cli.ts --agent otto --phase 70

Phase 70 for otto:
  Block: seq #2 (phases 62–76)
  Position in block: 8 of 12
  Info value (mod 17): 11
  Status: ✓ covered by ECC (4 erasures recoverable in this block)
```

Modes: --summary, --agent (timeline + gaps), --phase (point lookup), --from/--to (range).

Gap detection classifies as recoverable (RS ECC) or needs-peer-data (HLC merge).

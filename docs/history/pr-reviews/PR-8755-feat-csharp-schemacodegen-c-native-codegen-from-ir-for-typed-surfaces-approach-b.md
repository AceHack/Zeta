## Description

**Approach B** of the "generative C# type provider, no F#" pair (you asked for **both B and A, to learn from both**).

A plain library that emits C# `record` source from a language-neutral `TypeSchema` (IR) — mirrors the TS `codegen-from-ir` harness, so the **same schema generalizes to a typed surface per oracle** ("all langs, same feature"). No `FSharp.TypeProviders.SDK`, no `Microsoft.CodeAnalysis`, no netstandard2.0/design-time constraints; the emitted `.cs` is C#-consumable with **zero F# dependency**. Pure + deterministic (explicit `\n` → byte-lockable).

- `src/Core.CSharp/{SchemaField,TypeSchema,SchemaCodegen}.cs`
- `tests/Tests.CSharp/SchemaCodegenTests.cs` — 4 tests, **4/4 green**: golden record source, determinism, field-order/nullability preserved, single-field.

**Approach A** (Roslyn `IIncrementalGenerator` — the literal compile-time source generator) is being built in parallel for the contrast.

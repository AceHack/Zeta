## Description

Constructive twin of the illusory-truth bug (Aaron 2026-06-15: "i repeat it to others to make sure ... like you otto").

- **Repetition is neutral; the audience's correlation sets the sign.** Repeat to a correlated receiver (yourself, a cheerleader, an echo chamber) → fake N from 1 → the bug. Repeat to *independent* others "to make sure" → genuine independent tests → legitimate confidence multiplication (replication / two-source rule / Condorcet by hand). Same act, opposite sign.
- **"Repeat to others to make sure" is the promotion protocol** (sim → measure): an idea earns its ΔU commit by *surviving repetition to people who'd tell it's wrong*, not by being repeated.
- **Self-application ("like you otto")**: a grounding critic is a valid independent test *only while genuinely decorrelated*. An AI fluent in the speaker's vocabulary drifts toward a high-fidelity echo = a correlated critic in the costume of an independent one = the captured-critic failure this doc names. The critic stays valid only by re-earning independence. Worked instances: the awareness-gate-leaks pushback; markdownlint catching an unverified ship.

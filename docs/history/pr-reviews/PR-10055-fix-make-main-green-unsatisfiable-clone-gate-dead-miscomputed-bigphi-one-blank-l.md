### 1. `lint (TS)` — a wrong Φ left in place under the inviting name

`bigPhi` computed `½(1 + erf(x)/√2)` — scaling the erf **result** — where Φ(x) is `½(1 + erf(x/√2))`, scaling the **argument**. Whoever wrote the port caught it, added a corrected `bigPhiCorrect` directly below with the comment *"Re-implement with correct argument"*, rewired both call sites, and left the wrong version behind under the name a reader reaches for.

It type-checks and returns plausible numbers — Φ(0) = 0.5 under both forms. The two diverge in the **tails**, exactly where the anti-whitewash gates do their work.

Deleted the miscomputed one; renamed the correct one to `bigPhi`, restoring naming parity with `src/Core/TravelerRankLedger.fs`. **No behaviour change** — both call sites already used the correct implementation. **No cross-language divergence ever existed**: the F# has always had a single correct version, so this was a TS-port-only defect. `BETA` was a genuinely unused import.

### 2. `build-and-test` — a gate that could never pass

The sybil-verdict cartridge models a **conductor**: claim 1's outcomes read claim 0's settings (the cartridge's own PR-box rule), so the conducted pair's CHSH S = 4 exactly — the no-signalling maximum, deliberately **above** Tsirelson's 2√2. That supra-quantum value is the signal the shape convicts on, not a forgery of it.

The clone-gate asserted:

```fsharp
let isCloneAttempt = classifyS sPair = SupraQuantum
let ok = not isCloneAttempt && ... && sPair = 4.0 && ...
```

Those conjuncts contradict each other. `sPair = 4.0` **forces** `SupraQuantum` — `BipartiteMachZehnder.Tests.fs:88` pins `classifyS 4.0 = SupraQuantum` — so `ok` was unsatisfiable and the cartridge could never be accepted, on any input, from the day it landed.

Same defect shape as the heartbeat cron gate in #10054: a predicate that reads as a safety check but cannot be true. Both were introduced as hardening.

The gate was copied from the fourcorner law ~200 lines above, where the identical test is **correct** — a genuine entangled phasor must land in `Quantum`. It doesn't transfer to a shape whose defining fixture is a PR-box. Fixed by reporting the regime in the evidence and not gating on it; nothing else referenced `isCloneAttempt`, and no test or doc asserts the gate.

# Notes

**Why a separate function rather than an extra parameter.** A degenerate Clifford algebra is
**not semisimple** — the null generators are nilpotent and generate a Jacobson radical — and
Atiyah–Bott–Shapiro classifies semisimple algebras up to Morita type over a division ring. So
the clock is **inapplicable** to `r > 0`, not merely unimplemented. Threading an `r` through
`classify` would return a well-typed, confident, **wrong** answer: the vacuity class in its
worst form, an instrument that judges an input it cannot judge.

`F2` above is precisely that naive extension — folding `r` into `q`, i.e. pretending a null
generator squares to −1 — and it fails. `classifyDegenerate` states what is true instead:

```
Cl(p,q,r)       ≅ Cl(p,q) ⊗ Λ(ℝʳ)
dim               = 2^(p+q+r)
Cl(p,q,r)/rad   ≅ Cl(p,q)              the part the clock CAN see
dim rad           = 2^(p+q) · (2^r − 1)
```

**The row the tower argument rests on is asserted present by name:**

```
DG 3 0 1 16 8 C 2 False     PGA(3D) — 16-dimensional, radical 8,
                            quotient M₂(ℂ) = the in-tree Cl(3,0)
```

That 16 is **predicted** by the structure theorem and reported independently by Qualcomm for
GATr. An external check, not a fitted constant. It is also the third tower confirmed to reduce
to `Cl(3,0)` — VGA is the algebra itself, PGA tensors an exterior algebra, CGA takes 2×2
matrices — so `Cl3.fs` is upstream of all three and the tower choice is not a bet on one.

**The negative control is load-bearing.** `Cl(3,1)` and `Cl(3,0,1)` **share a dimension** (16)
and are different algebras — radicals 0 vs 8. Ignoring `r` gives a third wrong answer (8).
Matching cardinality is not identification
(`.claude/rules/numerology-vs-number-theory.md`).

**Honest limit, stated in the module:** `Cl(3,0)` being PGA's semisimple quotient does **not**
mean PGA computations reduce to `Cl(3,0)` computations. The radical is precisely where PGA's
translations live; quotienting it away throws the geometry out. Shared foundation, not
reducibility of the work.

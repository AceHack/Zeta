## Description

## What

Every epsilon assertion in the #9932 contract pass was `Math.abs`-wrapped. The adapter's epsilon **sign** is the whole claim — the page turns it into a ▲/▼ lean via `signedBar` — and an abs-wrapped assertion cannot see it move.

**Measured, not assumed.** Flipping `epsilon: 0.5` → `-0.5` at `vault-state-bridge.ts:328`:

```
27 pass, 0 fail
```

27 assertions, none able to tell up from down on the one field whose direction is the point. The hole is mine.

## Changes

1. Silent-branch assertion pins the **sign** (`epsilon < 0`) instead of `Math.abs(...) > 0`.
2. Width-ordering test **keeps** its `abs` — width genuinely is a magnitude — and gains a sign assertion alongside. Otto's sign deliberately not pinned (derives from fixture trend, not contract).
3. New **P2 peer-independence** property (Soraya, 2026-08-02):

```
∀ agent a, ∀ own-evidence o, ∀ peer configs P, P':
  R(o,P).value == R(o,P').value  ∧  sign(R(o,P).ε) == sign(R(o,P').ε)
  -- `silent` MAY differ; it is the only peer-derived output
```

Security property, not tidiness: peer count is not the subject's own evidence, so letting it move `value`/`sign(ε)` makes reputation **non-monotone in absence** — an agent improves its own reading by going dark *in company*. On a 3-agent roster that's a 2-of-3 coalition requiring no identity change, strictly cheaper than whitewashing.

## Scope — deliberately partial

| pair | status |
|---|---|
| 0 vs 1 peer | lands on one branch; true before **and** after the adapter fix → **ships here, green** |
| 1 vs 2 peers | crosses the silent threshold; **fails on main** (`value` 0 vs 0.1, sign − vs +) → ships **with** the adapter fix |

`vault-state-bridge.ts:322` vs `:329` is the defect. **No sign assertion was added to the two `<2 peers` cases** — pinning that cell's sign would write the bug into the contract and turn the adapter fix red.

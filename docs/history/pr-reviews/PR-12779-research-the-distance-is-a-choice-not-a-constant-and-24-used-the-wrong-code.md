## The error

§24 concluded *"at `d = 5`, you must erase at least 5 of 16"* — treating `d=5` as a property of the substrate. It's a property of **one chosen code**, and not even the one the adinkra generator uses. `FROZEN-CORE-AND-CONJECTURE-REGISTER.md` carries both and **explicitly flags them as different**:

| code | where | distance | corrects |
|---|---|---|---|
| **[8,4] extended Hamming**, doubly-even — *the genuine Adinkra generator* | `AdinkraCode.fs` | **4** | any 3 erasures |
| **[16,12] Reed–Solomon**, MDS — *for the erasure principle* | `ErasureDistance.lean` | **5** | any 4 erasures |

The register's own words: the Adinkra code is *"distinct from the RS MDS code used for the erasure principle."* **§24 quoted the RS distance and attributed it to the substrate.**

## What it does to the moral geometry

"You cannot slightly overwrite someone" survives in *form* and loses its universality:

> **The moral quantization floor is a design parameter, not a discovered constant.** `[8,4]` → floor 4. `[16,12]` → floor 5. **Choosing the code is choosing how much harm is recoverable.**

And the sharper case is Aaron's — **a non-coded adinkra has no `d` at all.** The doubly-even code appears when you quotient by dashing/vertex relations; it's a feature of *the quotient*, not of every adinkra.

| base layer | erasure below threshold | moral shape |
|---|---|---|
| coded (`d = 4` or `5`) | fully recoverable — attacker only wastes heat | **harm is quantized** |
| **non-coded** | nothing recovers | **harm is continuous** |

So §24's claim is **true on a coded base layer and false on an uncoded one** — less a weakening than a discovery about what the choice buys: **taking the code quotient is what makes harm discrete.**

## Which is the free-object rule, applied to ethics

`only-the-irreducible-is-primitive-generate-the-rest`: the irreducible is primitive; structured special cases are **earned quotients obtained by declaring relations**. A code is exactly such a quotient.

> **Nearer the free object ⇒ no code ⇒ continuous harm. Take the quotient ⇒ get a distance ⇒ harm quantized with a floor.** The generator hierarchy determines the moral geometry.

That rule's other half is already this — *the highest-value generator IS an error-correcting code*. Aaron's addition: **we may decline the quotient, and declining has an ethical consequence, not only a mathematical one.**

## Two towers, and the metric is relative to both

§21 made metrics **oracle**-relative. This adds a second axis, and both towers are already in the register: the **algebraic** one (Cayley–Dickson → octonion product → Fano `S(2,3,7)` → `[7,4]` Hamming → parity extension → `[8,4]` doubly-even, derived end-to-end) and the **Futamura** one (interpreter → compiler → compiler-generator, `gen(gen) == gen`).

> **A metric here is indexed by (oracle, tower, rung).** Change any coordinate and you get a different geometry, a different distance, and — per §24 — a different account of what harm is.

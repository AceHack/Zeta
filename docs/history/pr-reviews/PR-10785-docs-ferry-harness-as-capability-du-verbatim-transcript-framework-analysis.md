## What the analysis records

**1. The decomposition is the capability-interface principle one layer up.** The v2 IR doc §0 already resolves capabilities by multiple dispatch over a capability graph; the eight harness components are capabilities at the *agent* layer rather than the *codegen* layer. Aaron's closed-DU reading is the stronger form — a closed union makes a new axis a compile error at every consumer, which is exactly the property that lets `ace-cli` and `mux-transport-bridge` close over one abstraction.

**2. Three uses of that mechanism, and conflating them is a defect.**

| layer | what dispatch decides | failure if wrong |
|---|---|---|
| codegen over source types | soundness gate | Merkle roots diverge |
| target-native emission (#10774) | preference over semantically equal emissions | still byte-locks; unidiomatic |
| agent-control layer | optimization axes | scores worse; nothing breaks |

**3. Two peels, Mirror to Beacon.** `argmax` over an 8-tuple whose components are natural-language strings and executable code is **not a computable search** — no gradient, and the space is not a well-defined set. The formula names the problem. And *"the round-t artifact becomes the round-t+1 optimizer"* is a **definition, not a demonstration**: nothing argues the sequence converges rather than drifts, and an optimizer improving its own scorer is the classic way a metric stops measuring.

**4. Where we are already ahead — Aaron confirmed this one.** The expectation over probabilistic runs assumes independence. For a fleet of near-identical harnesses that is false, and the correction is already in-repo twice: `numerology-vs-number-theory.md` (*"N correlated observations are not N observations"*) and `src/Core/SocietyUsefulWork.fs`, which ships the analytic expected value under pairwise correlation ρ plus a Gaussian copula, so N clones price near one agent's worth. **Any harness scorer built here must not regress to an independence-assuming average.**

## Generator-as-ECC along time: does not survive — it *inverts*

An ECC restores a corrupted word to the codeword it should have been. An update **changes which codeword is correct**. Applied literally, an ECC treating "version B where the generator says A" as drift would **revert the update** — it recommends the wrong action.

Root cause, found while verifying the rigidity claim: **two invariants with opposite content-sensitivity.** `ContentAddress` *is* the bytes (answers "same realization?"); `codeIdentity` is invariant under content change (answers "same lineage?"). An ECC has only the first. **The update path runs on the second, which is not an ECC at all — it is a provenance chain.** The pun is conflating them.

Also: DST replay has redundancy but **no syndrome** — divergence yields a diff and a human. That is error *detection*, not correction.

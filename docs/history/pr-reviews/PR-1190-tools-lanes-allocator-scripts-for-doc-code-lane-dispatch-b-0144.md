## Description

## Summary

Companion to **PR #1189** (B-0144 protocol docs). The protocol documented allocation via raw \`git worktree add/remove\`; this PR ships the wrapper scripts so the coordinator (Otto) doesn't need to remember worktree paths or branch-naming conventions.

## Files

- \`tools/lanes/lane-allocator.sh\` — shared backend (allocate / release / path / status across both lanes)
- \`tools/lanes/doc-lane.sh\` — thin wrapper, passes \`doc\` as lane
- \`tools/lanes/code-lane.sh\` — thin wrapper, passes \`code\` as lane

## Subcommands

\`\`\`bash
tools/lanes/doc-lane.sh allocate docs/topic-2026-05-02
tools/lanes/code-lane.sh allocate ci/topic-2026-05-02
tools/lanes/lane-allocator.sh status

tools/lanes/doc-lane.sh release
tools/lanes/code-lane.sh release
\`\`\`

Worktrees land at \`../zeta-doc-lane\` and \`../zeta-code-lane\` (siblings of the repo root, not inside it — so tools that recurse the main checkout don't scan them).

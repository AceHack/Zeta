## The Itron boundary

Stripped at **seven enumerated sites**, tabulated in the doc so the removal is auditable rather than asserted: deck title, document metadata, a named source system in `RecordSource`, a named technical key, two domain-specific mart names, one sentence naming their transport product, and the utility-domain entity examples in the hub/link/rate-of-change notes — all replaced with domain-neutral forms.

**No confidentiality marking, classification banner, or internal data was found in either file.** Both were scanned for `Confidential` / `Proprietary` / `Internal Use` across all sheet text, slide text and document properties. The client name appeared **exactly twice, both in titling, never in the body**. Nothing triggered a stop condition.

His *employment history* is **not** elided — it is already on the record in `itron-hub-patent-boundary-p2p-is-the-upgrade.md`, so it is named plainly rather than half-anonymised. What does not come over is their labels, systems and data.

**Also deliberately not imported:** the workbook's per-entity SQL Server 2016 storage tuning. Platform advice with a high rot rate, this substrate does not run SQL Server, and importing it would dress a decade-old tuning guide as current standard. Structural reasons kept; product detail dropped.

## Register

The doc declares **`unmetered`** in its first line: imported practice, nothing here depends on it, no test fails if a rule is wrong. Books cited for the claims; **Aaron cited for the synthesis**, the taxonomy indices and the field-level standards.

**Where he disagrees with the books is preserved, not smoothed** (§7.2): `LoadEndDate` is a documented standard field he marks *unproven* — the `unmetered` discipline applied in 2016 without the vocabulary; `LastSeenDate` vs record-tracking satellites left explicitly undecided; multi-active satellites demoted to near-defect; link-to-link rejected in physical design; dimensional modelling demoted to an output format. His own open problem is kept too: `Strength`/`Confidence` as floats collapse a distribution to a point estimate, named and unfixed.

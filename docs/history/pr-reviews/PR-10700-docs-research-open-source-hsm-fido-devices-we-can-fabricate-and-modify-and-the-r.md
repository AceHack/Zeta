## Description

Answers Aaron 2026-08-14 — *"are there any open source HSM and/or FIDO compatible devices you can get printed by yourself and we can modify the hardware design of"* — plus the mid-task expansion to a second, nearly disjoint class: **FPGAs for reversibility research** with open bitstream and **zero-downtime** runtime modification.

## The central finding

**Integrity and authenticity are separable, and only authenticity structurally needs a third party.** TKey's `CDI = BLAKE2s(UDS ‖ USS ‖ BLAKE2s(app))` is arithmetic, so it survives self-fabrication unchanged. What a self-build loses is *third-party* attestation.

Sharpened by Tillitis' own tooling — `tkey-verification`'s README:

> *"If your TKey wasn't provisioned by Tillitis, and instead by another 'vendor' like your IT department, you will need to run **their** version of the `tkey-verification` program instead of this one."*

The **vendor role is a parameter, not a fixed party.** Self-fabrication *relocates* the vendor root to us rather than deleting it. That extends PR #10685 (**still open**, not merged) with the one move it does not make.

## Class B — resolves a flag the wish list left open in May

`hardware-to-buy.md` §1 said sub-region PR was "more limited… flag it as a research item." Resolved:

- **ECP5 PR is documented** — Project Trellis: *"LSC_WRITE_ADDRESS can be used to make partial bitstreams… partial reconfiguration is possible on ECP5"* (needs `BACKGROUND_RECONFIG`, then JTAG `0x79` / `0x74 0x00`).
- **Frame addressing is documented only for the 45k device** ⇒ **the part is `LFE5U-45F`, not the 85F the BOM leads with.**
- **iCE40 has no true PR** — warm boot / multiboot only.
- **No turnkey flow** — `nextpnr` has no reconfigurable-partition feature. This is a **spike that may fail**, not a purchase that delivers the capability.
- **Prices reverified**: ULX3S 12F **$155** (was ~$99), 85F **$275** (was ~$155), both in stock. The "~$1,038" BOM is now ~**$1,700**.

**"Reversibility" did not have to be guessed** — Aaron's own 2026-05-28 Turn 18 says reversible computing and Landauer; Turn 20 says self-rewriting bitstreams. Cited as evidence.

**Dual-use worth noting:** iCE40 warm-boot reconfiguration is Class B's *feature* and, verbatim, Class A's named *threat* in TKey's threat model. A real cost of FPGA-based tokens, not a wash.

## Recommendations, split (one answer for all three would be dishonest)

1. **Investor PoC** — 2× TKey Unlocked + TP1 ≈ **$238**. Do not fabricate; demo identity changing with the code, with no CA. Claim *"no proprietary tooling and no proprietary design"*, not *"no vendor anywhere."*
2. **Decentralized PKI / mesh survivability** — the use case where self-fabrication is genuinely right. Become our own vendor (own UDS, own verification instance, transparency log). Accept explicitly that no stranger can verify us.
3. **Custody of value** — **nothing here clears the bar.** Buy the **FIPS SKU ($950)**, keep FROST above it. `pico-hsm` is disqualified (no secure element). A self-built device may hold a witness key, never a spending key.

**Self-built hardware is additive and cannot replace the YubiKeys** for attestation-gated relying parties (FIDO cert **$6,000–$13,500** per implementation; no cert → no MDS entry → rejected). The permissive half was verified against the W3C text directly: `attestation` **defaults to `"none"`**, so ordinary relying parties accept a self-built authenticator fine.

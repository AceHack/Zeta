## Description

# Summary

Live wifi-ESP QEMU (run 32638506247) died after the R7 countdown with `tee: .../zeta-install-attempts.txt: Read-only file system`. QEMU USB boot uses `readonly=on`. `mount -o rw` still succeeds, so R9 claimed the ESP writable and `tee -a` then aborted the install under `set -e`. Picker bind and restore decrypt never ran because they are later steps in the same job.

Probe a real write before `ZETA_LEDGER_WRITABLE=1`. If the write fails, stay BLIND (the path the comments already named). A later `tee` failure must not abort the install.

Also: `swarm.worker.ts` restored in #14159 called `SwarmController.init` with an LLM options object. The shipped `init` takes a UDP drop-rate number. That is required `lint (TS)` red on every PR until it is fixed.

# Spec alignment

Installer R9 circuit breaker — writable vs BLIND. Behaviour change: RO USB ESP is BLIND instead of a hard install failure.

## Description

# Summary

#11309 asserted the guest iSerial probe on the QEMU serial log, but persist still always bound FAT UUID and threw the probed serial away. The probe CLI now writes `--serial-file` on success. Default persist remains `--usb-uuid`. `ZETA_BIND_USB_ISERIAL=1` forwards `--usb-iserial` to the picker only when that file is non-empty; otherwise it stays UUID and says so. QEMU phase-1 (`QEMU_USB_ISERIAL_PHASE1`) now also requires the persist-default UUID marker, so a silent switch cannot go green. No metal / Touch ID / TPM claim.

# Spec alignment

Installer persist path only. USB-IDENTITY-THREAT-MODEL §4 / §8. No OpenSpec capability change. Default binding factor is unchanged.

## Description

Continues #10925, which shipped `IMember` / `ISociety` / `SocietyLaws` and left two things open: **`CTM` had no definition in `src/`**, so the `ISociety <: CTM` fixpoint could not be typed, and **nobody knew whether `IWorld` was a distinct interface**. Both are answered. One of the answers is that a claim in the 2026-07-04 doc is false.

## CTM v0

`src/Core/Ctm.fs` + `src/Core.TypeScript/society/ctm.ts` — `Chunk`, `ICtm`, `probabilisticMatch`, `tournament`, `CtmLaws` (12 predicates).

Derived from the published model: **Blum and Blum, PNAS 119(21) e2115934119 (2022)**. PNAS returns 403 and the PMC mirror is CAPTCHA'd to this harness, so the formal statement was read in the **same authors' restatement of the same model** (arXiv:2403.17101, §2.1 + Appendix §6.2), which gives the 7-tuple, the chunk tuple, the competition rule and the winner-take-all theorem in full. `docs/research/ip-questionable/` was **not opened**.

Three derived points, each traceable to a sentence in the paper:

- **The competition is a commutative-monoid fold.** The paper's location-independence theorem rests on `f` being *additive under a match* — intensity and mood accumulate by sum, and `f = intensity + d*mood` is linear in both, so `f(winner) = f(left) + f(right)` exactly. Additivity makes the bracket irrelevant, which is why `tournament` can be a **fold** rather than a reconstructed binary Up-Tree. `rankIsAdditiveUnderMatch` is that made decidable, and it is the same algebraic shape as `SocietyLaws.mergeCommutative` one level up.
- **The randomness is the §13 door.** The paper says the competition is probabilistic *by necessity*. So `Match` takes the draw as a parameter and `tournament` takes a supplied sequence — semantics preserved exactly, and the machine becomes DST-replayable. Running out of entropy **refuses** rather than reaching for an ambient draw; that refusal has a test.
- **A newborn CTM has NO exit.** Links bypass STM (that is exit, Hirschman) but the paper is explicit that there are none at birth — they form Hebbian-ly between processors that broadcast on consecutive ticks. So at t=0 every crossing is mediated by the single STM slot, which is the mediating-hub shape §1 refuses. Stated rather than patched, with a test that fails at birth and passes once links form. Anyone citing a CTM as satisfying our exit discipline must say **at what age**.

Also checked and **corrected**: the 07-04 doc's requirement set said members present "one address, one world-model loop, one broadcast channel." The paper says the Model-of-the-World processor "is not actually a single processor; its functionality and memory are distributed across all LTM processors." So there is deliberately **no `ModelOfTheWorld` member** — a designated self-model would be an appointed node.

## Did the fixpoint close?

**Yes — carried by `IMember`, not by `ISociety` and not by `ICtm`.** Both inherit `IMember`, and a CTM's processors are member addresses, so `mu X. CTM-over-X` is typeable today.

**`ISociety <: CTM` is REFUTED, not merely unproven.** Making `ISociety` inherit `ICtm` would force every society to present a single-slot competition and a global broadcast. The gossip salon (`GossipTelemetry.fs` / `gossip-salon.ts`) is a working society with neither. One counterexample is enough. The 07-04 discharge row *"ISociety <: CTM = Liskov-sound subtyping"* should be **withdrawn**; the *"CTM ⊣ ISociety = adjunction"* row stays open and is untouched.

```text
                    IMember              <- the fixpoint carrier
                   /       \
           ISociety         ICtm         <- siblings, neither below the other
```

## Is `IWorld` distinct?

**No, and no third interface was invented.**

> A world is not a different kind of thing from a society. It is a society that is **CLOSED**.

Closure is the conjunction of two predicates #10925 already shipped (`outboundStaysInSociety` + `routesAreMembers`). `WorldLaws.isWorld` is defined *in terms of* them, so a proof pointed at the society laws is pointed at the world laws for free. `isClosed` takes caller-supplied witnesses (a check over an unbounded quantifier would be a check that cannot fail), and `openWitnesses` returns *which* messages escaped rather than a bare `false`.

## The level-generic surface (for the parallel "world > best society" work)

**No proof was attempted** — that is the sibling's. The contribution is that society and world are now one shape under a predicate: `LevelLaws.holdsAtEveryLevel` lifts **any** per-level predicate over a `Ladder`, so every existing `SocietyLaws` predicate becomes level-indexed with no new code. Plus `failingLevels` (which rungs, not just whether), `exitAtEveryLevel k`, `linksAreProcessorPeers` (a CTM's links are its processors' peers — the same edges one rung apart), and `nestsDirectly` (Composite containment, which deliberately does not flatten).

Deliberately **not** declared: nothing asserts that a law holding at one rung implies it holds at the next. That implication is the open question, left decidable rather than assumed.

## A bug found by being the first consumer

`Society.Address.compare` / `canonicalSort`, shipped in #10925, **could not be called from any other file** — `Address` is a union *case constructor* as well as a type and a module, so the path binds to the case and the module is shadowed. Observed against the built assembly, not inferred: `error FS0039: The field, constructor or member 'compare' is not defined`. Every "MUST sort through here" instruction in that file was unfollowable outside it. Fixed with `Society.compareAddress` / `Society.canonicalSortAddresses` — delegating (one implementation), named to match the TS mirror.

**Noted, not fixed:** the salon `pairKey` still orders by UTF-16 code unit in both languages, disagreeing with the treaty on non-BMP ids. Changing it changes existing keys, so it is a migration question and deserves its own diff.

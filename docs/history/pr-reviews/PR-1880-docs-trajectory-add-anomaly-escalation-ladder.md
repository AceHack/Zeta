## Description

## What

Adds the anomaly escalation ladder to the #1 trajectory packet:

- small anomaly -> local investigation, patch if bounded, keep moving
- large anomaly -> investigate first, decompose if needed
- repeated / double-down shadow -> involve other agents and record the cross-agent catch

## Why

Aaron clarified the investigation scale rule: anomaly size determines response size. Small residue should not become council theater; large or repeated residue should not be solo-rationalized.

## Description

## T2 of Face-3 — CD doubling preserves doubly-even self-dual (Lean, sorry-free)

Discharges the **inductive step** of the math-team handoff target **T2**
(`docs/handoffs/2026-06-20-alexa-to-math-team-phase-d-gen-gen-research-discharge.md`):

> Cayley-Dickson doubling preserves the doubly-even self-dual invariant.

The **base case N=4** (the [8,4] extended Hamming / Adinkra generator) is already
proven exhaustively in `AdinkraCode.fs` / `AdinkraCode.Tests.fs` over all 16
codewords. This PR adds the general inductive step in Lean 4.

### What is proved (`src/Core.Lean4/Lean4/CayleyDicksonDoublyEven.lean`)

| Theorem | Statement |
|---------|-----------|
| `doubled_isDoublyEven` | weight ≡ 0 (mod 4) is preserved by doubling |
| `doubled_isSelfOrthogonal` | even GF(2) dot product (C ⊆ C⊥) is preserved |
| `doubled_isRateHalf` | `2k = n` ⇒ `2(2k) = 2n` (dimension half of self-duality) |
| `doubled_preserves_doubly_even_self_dual` | **combined inductive step** |

All four are **sorry-free** — `#print axioms` shows each depends only on
`[propext, Quot.sound]` (Lean's standard foundational axioms), no `sorryAx`.
Verified locally with a standalone Lean toolchain (no Mathlib; the file has zero
imports).

### Honest scope (peel)

The doubly-even / self-dual properties are invariants of the code's **additive /
GF(2) vector structure**. Under `Doubled.algebra` (`CayleyDickson.fs`) the
additive group of the doubled algebra is exactly the direct sum `A ⊕ A`
(`(a,b)+(c,d) = (a+c,b+d)`), on which `weight(a,b) = weight a + weight b` and the
form adds blockwise — so the proof models the *actual* operator the invariant
sees. The algebra's **multiplication and conjugation do not enter** the
weight/duality invariant and are (correctly) absent. The **reflection-grade ↔
CD-doubling-axis bridge functor** is **not** claimed here — it remains a separate
open research target (§B of the handoff).

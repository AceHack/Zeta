## Note on k ≥ 2

The k ≥ 2 threshold is a **peer-count quorum** (how many independent witnesses must agree on absence). It is NOT the Cantelli deviation multiplier k ≈ 1.95 from α = 1/(1+k²). They land near the same number by coincidence. The doc now explicitly separates these to prevent conflation.

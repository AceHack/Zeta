## Description

Resolves the last 3 failing tests on main — the golden-vector conformance trio left deliberately unfixed by #10323, because turning them green the obvious way (regenerate the fixture) would have silently moved a cross-language contract.

Delegated to a background worker with the brief *"do it correct for the future, we can add features"*; independently verified before shipping (see below).

## The decision: exclude, but as a declared surface rather than a deletion

`history` stays **out** of the conformance-folded state — and the feature stays, properly typed. The mechanism is an explicit projection: `TreatyWorld` / `TREATY_WORLD_FIELDS` / `toTreatyWorld`. `World` is the TS runtime type and may grow; the fixture is emitted from a stated projection of it.

**Adding a field to `World` can no longer change the contract. Promoting one *into* the contract is now a deliberate edit to one function.**

## Why not implement `history` across all four oracles

1. **The ledger has no reader outside TS.** `retract_time` — its only consumer — exists only in TS. F#, C# and Rust each implement exactly the **nine** core action kinds; TS has 14. Promoting `history` would lock a field no other oracle can exercise.
2. **It adds no discriminating power.** `history` is a strictly lossy copy (2 of 14 kinds) of the `events` array already in the fixture as the fold's *input*. Locking a lossy duplicate of the input as expected output cannot fail in any way `events` doesn't already fail.

Trade-off stated plainly: time-travel is a **TS-local capability, not a shared contract**. Work item `081KZT1X8G2087G0R000FYEWSE` is the versioned path to promoting it, and it is explicit that step one is landing `retract_time` in the other three oracles — otherwise step two locks a write-only field.

## Also fixed: the typed hole

`history: any[]` → a `HistoryEvent` discriminated union. Two real bugs fell out: the `do_item` entry always carried `evaluation: undefined` (absent is now absent), and the backward Z-set scan indexed without a bounds guard.

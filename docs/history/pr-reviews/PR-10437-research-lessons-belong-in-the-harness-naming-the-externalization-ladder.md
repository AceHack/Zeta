## Description

Aaron, on a lesson I had just written as prose:

> *these lesseson all need to make it into our harness and cli … they can just be extgernlaized discrimanted union / workflow / cli / mux/duplex rules*

He's right, and **the pattern already runs at scale here** — `src/Core.TypeScript/hygiene/` holds **138 checkers**, each a lesson that stopped being prose. It just isn't *named*, so new lessons land on the weakest rung by default.

## The ladder

| rung | mechanism | enforced by |
|---|---|---|
| **1. Unrepresentable** | type / DU / interface | the compiler |
| **2. Only ergonomic path** | CLI verb / port | friction |
| **3. Caught** | checker / test / drift gate | CI |
| **4. Remembered** | prose rule | attention |

Rung 4 is the default landing place **and** the only rung that charges rent — cold-start tokens on every agent wake, forever. The promotion question for any new lesson is just: *what is the highest rung this can reach?*

## The honest limit, which is the interesting part

The `echo` bug happened in an **ad-hoc bash command inside an agent session**, not a committed script — so no repository lint could have caught it. `rule-0-no-sh-files` points the right way but governs *files*; this was a *call*.

**The harness only enforces what flows through it.** Raw `bash` is the un-instrumented channel — which is **§13 noninterference stated for tooling**: a CLI verb is the door for *operations* exactly as the injected `Source` is the door for *entropy*, and an ungoverned shell call is ambient in precisely the forbidden sense.

That reframes the CLI argument: the win isn't mainly fewer dependencies, it's that **a channel you own is a channel you can instrument** — and a lesson externalizes only as far as the channel it concerns.

## Six lessons from this session, placed

Including `git commit -F` over inline `-m` (**executed shell 3× today**) at rung 2, and the derive-the-executed-set checker at rung 3.

**The rung-1 candidate is the valuable one:** make `Bound` a DU carrying a required `Derivation | Measurement | Assumption(reason)`, so **a bound without a derivation is unrepresentable**. That turns "is this constant justified?" — the question that let the orbital `1.2` survive — from something a reviewer must *think to ask* into something the compiler asks every time. `Assumption("fudge factor")` stays permitted, just no longer silent. Same move as the orphan allow-list: exclusion possible, invisibility not.

## Not an argument to delete rules

Judgement-shaped rules (`no-directives`, Mirror/Beacon, default moral regard) belong on rung 4 and typing them would be worse. The claim is narrower: **a lesson about a mechanical operation that stays on rung 4 has been mis-filed** — and I mis-filed the `echo` lesson this morning.

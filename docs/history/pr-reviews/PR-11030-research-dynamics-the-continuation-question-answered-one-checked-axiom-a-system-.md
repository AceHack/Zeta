# Summary

Work-item `081M05YMHAN087G0R003TT3AS4` — the Axiom A / natural-boundary question filed by #11025. Answered, with the hypothesis **checked** rather than cited. Docs only; nothing in `src/` touched.

**The premise was wrong about which system.** `FigureEightEnsemble` is not the three-body problem. Its tick map is **affine** — a cyclic permutation plus a constant translation in Gaussian natural-parameter space (`Gaussian.( * )` adds natural parameters, so `observe` is a translation; the "chase" is the 3-cycle). So `DT` is a permutation matrix: **all Lyapunov exponents are exactly 0**, `h_top = 0`, the non-wandering set is **empty** (the functional `σ = x_A+x_B+x_C` drifts by `3n·s`, confirmed exactly against the built assembly), and `ζ_AM ≡ 1`. Axiom A holds *vacuously* and says nothing. That is a derivation, not a failed attempt.

**But we do run one genuinely Axiom A system, and neither document named it: the Arnold cat map** (`tests/Tests.FSharp/Braid.Tests.fs`). Five conditions checked from the matrix in the test file — compact `T²` (the `frac` is in the source), `det A = 1`, eigenvalues `(3±√5)/2` off the unit circle, `DT ≡ A` constant *and symmetric* so hyperbolicity is uniform with `C = 1` exactly, `Ω = T²` with dense periodic points. Its zeta is not merely meromorphic but **rational** — `ζ_AM(z) = (1−z)²/((1−λz)(1−λ⁻¹z))`, with `N_n = tr(Aⁿ)−2` computed to `n=8`. **A rational function has finitely many singularities, so they cannot be dense** — the natural boundary is excluded by the density criterion, not by a successful attempt.

# The load-bearing correction to #11025

§2 says the Pollicott–Ruelle resonances carry *"the same class of information `largestLyapunov` samples."* **They do not.** Resonances are correlation-decay rates; a Lyapunov exponent is an expansion rate. On the cat map the character computation `⟨e_k∘Tⁿ, e_m⟩ = δ((Aᵀ)ⁿk, m)` is **exactly zero for large n** — correlations vanish identically, the transfer-operator spectrum is `{1}`, and there is **no resonance at `log λ`**. So the substitution fails on its own best case, for a reason unrelated to continuation. What delivers `log λ` is the *orbit-counting* zeta, a different function.

§1 and §5b are accurate and should stand. #11025's register table was honest — both UNKNOWN rows can now be filled.

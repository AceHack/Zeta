## Description

# Summary

#11193 put `serial=` on QEMU `usb-storage` and dropped the type imports in `run.test.ts` (`lint (TS)` red on that PR). The guest still never printed what sysfs saw.

This restores the types, adds a probe CLI that prints found/missing + `serial=<value>` + no-metal-claim, and runs it from `zeta-install.sh` 6.95d after bun is up. Default persist remains FAT UUID. Live QEMU USB install sees the markers after the next clone/ISO; unit tests pin the contract now. No metal / Touch ID / TPM claim.

# Spec alignment

`docs/security/USB-IDENTITY-THREAT-MODEL.md` §4 / §8 — guest sysfs iSerial is QEMU-testable; host probe stays injectable.

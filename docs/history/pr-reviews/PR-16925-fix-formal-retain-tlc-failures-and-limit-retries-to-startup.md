## Description

Unexpected TLC outcomes previously lost the F# runner's full streams/state/crash files, while the TypeScript runner could retry an in-run JVM failure over reused paths. Both runners now retain each unexpected attempt in its own source workspace and diagnostic directory. Retries require an ordinary, explicitly pre-TLC JVM initialization exit; earlier failures remain preserved.

The runtime probe owns its crash/stream files and one complete capture deadline. TypeScript source admission and copying use one descriptor, with optional platform flags recorded. The inherited-pipe fixture observes actual launcher exit before cancelling through the shared production capture path. CI uploads owned diagnostics, including hidden files, for seven days. Unexpected local directories have no automatic purge; Windows retains the documented stable writer-tree assumption.

Validation at corrected integration `4b4d9a237b23e53a4b297af72eb2053f3c51c8b6`: mapped Release build, zero warnings/errors; full solution **7,539 passed / six existing skips / zero failed**, including all 52 gate-tier TLC cases and 18 runner cases. All 103 selected inputs stayed unchanged. Focused TypeScript tests passed on Bun 1.3.13 and 1.3.14 (47 tests/224 expectations); the two affected hygiene suites passed 61 tests/109 expectations. Independent source and retained-evidence reviews accepted both corrections. All original CI/TLC/compiler failures remain indexed, with their exact recovery and scope limits.

The repair changes no model, jar, expected state count, model-checker timeout or JVM policy. [Repair report](https://github.com/Lucent-Financial-Group/Zeta/blob/038ff0e3c854d6757dce08252ee9c15e5105429c/docs/research/2026-09-07-tlc-attempt-retention.md) and [corrected full validation](https://github.com/Lucent-Financial-Group/Zeta/blob/038ff0e3c854d6757dce08252ee9c15e5105429c/docs/research/tlc-attempt-retention-validation/2026-09-07/ci-native-correction.md) retain complete logs, seven TRX archives, byte identities and the original failed publication checks.

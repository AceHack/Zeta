## Description

Ferry of Aaron's unbuilt UDP-broadcast transport idea + the load-bearing connection he named: the auto-negotiated backoff it needs **IS "our heat"** (Vera's heat-readout treaty).

**Confirmed from the repo:** `Heat.fs` has `isBackpressureKind`; `TelemetrySource.fs` maps felt heat → SoftThrottle admission pressure — *"the agent slows down BY FEELING heat, not by being told … our only governor is ethics and heat."* So **heat = the mesh's congestion control** — an explicit, metered, **propagating** backpressure signal (ECN made first-class), which is the *right* primitive precisely because UDP-over-analog-mesh destroys TCP's loss/RTT cues. Vera's heat work and Aaron's unbuilt UDP transport are the same system.

**The connectionless duplex-multiplex over UDP broadcast is an assembly of shipped parts:**

| concern | piece | status |
|---|---|---|
| stream shape | MultiplexedWebSockets (Guid-correlated duplex), connectionless | prior art; UDP variant unbuilt |
| discovery | `discovery-beacon.ts` (UDP multicast) | shipped |
| auth | `beacon-auth.ts` (signed, Ed25519) | shipped |
| **backpressure** | **heat** (`Heat.fs`, `TelemetrySource.pressureOf`) | **shipped — the answer** |
| reliability/loss | FEC (RaptorQ) or NORM, or lean on Reticulum | prior art |
| mesh | **Reticulum** | the bus |

Extends the bidirectional-stack ferry (#9382): one bidirectional-mutually-interruptible stream shape from token to mesh, now **governed by heat**. FEC-over-broadcast avoids NAK-implosion (retransmit doesn't scale on broadcast).

Anchors: Jacobson 1988 (AIMD) + ECN RFC 3168 (heat = its propagating generalization); NORM RFC 5740 / PGM RFC 3208; fountain/RaptorQ RFC 6330; Reticulum; the shipped Heat.fs / TelemetrySource / heat-readout treaty (Vera). Doc-only.

## Three things worth knowing

**Fixing the encoding invalidated every golden vector.** A's suite pins the wire format with hardcoded hex, so B2 turned 10 of 22 tests red instantly. That's the *right* failure — they test the format, not a round-trip — but it means every future encoding amendment carries this migration cost. Regenerated with fresh P-256 keys, each self-verified, with the canonical message documented byte-by-byte.

**B6 arrived split across two derivations.** A implemented the correct behaviour; B was the one who articulated *why* it matters (the suppression attack). Neither alone gives both.

**B8 was a hole inside R8's own rule.** A roster large enough with an ineligible subset passed every check and returned a **permanent silent denial** — the exact failure R8 exists to prevent.

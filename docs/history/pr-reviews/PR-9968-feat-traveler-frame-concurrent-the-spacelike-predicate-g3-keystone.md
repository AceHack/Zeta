## Description

The load-bearing primitive Soraya flagged as missing for the CHSH interference-monitor (**G3**): `TravelerFrame` had `dominates` but no `concurrent` — the sole legal gate for CHSH pair-selection. A signaling (causally-ordered) pair must never be folded into a Bell correlation; only genuinely-concurrent (spacelike) pairs may.

```
concurrent a b  =  not (dominates a b) && not (dominates b a)
```

= neither's causal view contains the other's = each has seen something the other has not = a genuine fork in the causal DAG. Decided by the **versionstamp partial order ONLY, never wall-clock** (`local-time-never-enters-the-shared-fold`) — two observers with different receive-times classify the same pair identically.

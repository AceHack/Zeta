## Description

## Why

Operator 2026-05-31: *"a one-liner register with the idempotent install/update commands for any tools or clis that don't come from a package manager … for all our oses."* The declarative **escape hatch** for CLIs that ship their own `curl|bash` installer (not in scoop/brew/apt/bun). **forge = ForgeCode** (forgecode.dev) — operator-confirmed.

## What (Phase 2 — the one-liner installer registry, Unix side)

- **`manifests/one-liner-tools`** — the registry. Format: `<detect-binary>  <install one-liner>`. Entries (pins per dep-pin-search-first, WebSearch 2026-05-31):

  | binary | installer |
  |---|---|
  | grok | `curl -fsSL https://x.ai/cli/install.sh \| bash` |
  | cursor-agent | `curl https://cursor.com/install -fsSL \| bash` |
  | kiro | `curl -fsSL https://cli.kiro.dev/install \| bash` |
  | hermes | `curl …hermes-agent/…/install.sh \| bash` |
  | forge | `curl -fsSL https://forgecode.dev/cli \| sh` |

- **`common/one-liner-tools.sh`** — **detect-first** (skip if the binary's already on PATH — efficient, no re-download; remove + re-run to update) + **best-effort** (a failed installer warns + continues; auth/login is yours; never bricks install — mirrors `common/local-llm.sh`). Runs each one-liner via `bash -c`.
- **`linux.sh` + `macos.sh`** — wired in after `agent-clis.sh`.

## Scope

**Unix only** this PR (*"start the phase 2 unix registry"*); the **Windows** one-liner registry (iex/PS installers) rides on **option B** settling — same disk reason as the agent-clis Windows deferral.

## Hindsight note

`hermes` bundles a **local Hindsight memory daemon** on first use (no separate install); the **shared cluster Hindsight** is a future ArgoCD service (git-native storage interface upstreamed eventually; Max's CockroachDB provides the Postgres wire interface it wants).

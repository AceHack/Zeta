## Description

## Summary

PR #10922 caught its own squash commit classified `RECOVERED-MALFORMED` and refused to round it up, because ~100 other recent commits of apparently the same shape parse fine. That restraint was correct and this closes the mechanism it left open.

**Verdict: ESTABLISHED.** GitHub's squash-merge does not pass the commit message through. It **deletes** every `Co-authored-by:` line from the composed body, recomputes the contributing identities **minus the squash commit's own author**, and re-emits that set **after a blank line** — and emits nothing at all when the set comes out empty.

That last clause is the missing variable. **The commits that parse are not the same shape**: they are commits where the forge had no co-author left to attribute, so it never wrote a trailer paragraph. Squash-merge is a deterministic producer; the discriminator is account topology, not layout or authoring.

## The self-contradiction

`Meno.fs:34` already states the correct fact:

> *"FULL category `(ZSet, ⊗_Kronecker)` is a **CD category, NOT cartesian**"*

while lines **58, 70, 85, 88** of the same file called that tensor Cartesian, and `MenoBraided.fs:6-7` built on it to claim *"a Cartesian/Kronecker ⊗ is forced-symmetric by a theorem"*.

## Why it mattered

The false side was read during routing review as a possible **obstruction**: Mathlib carries `Cartesian ⇒ Symmetric` with `Subsingleton (SymmetricCategory C)`, so if the ambient tensor were genuinely cartesian, `braidR` would not be a braiding *of Meno* at all — only of a non-cartesian tensor on ⟨V⟩ believed unbuilt. That would have undercut the machine-checked Yang–Baxter results.

**It is not an obstruction.** `Meno.tensor` is the Kronecker tensor of free ℤ-modules built from `ZSet.cartesian` on *basis sets* — cartesian-on-bases is not cartesian-monoidal. Two independent refutations, now in the corrected comment:

1. **⊗ is not the categorical product.** In `Mod_ℤ` that is the biproduct `ℤ[X ⊔ Y]` of rank |X|+|Y|; `Meno.tensor` gives `ℤ[X × Y]` of rank |X|·|Y|.
2. **`unitObject` is not terminal.** `Hom(ℤ[X], ℤ) = ℤ^X` is a singleton only when X is empty; the terminal object of `Mod_ℤ` is the zero module.

`CartesianMonoidalCategory` therefore does not hold, the Mathlib subsingleton result does not apply, and the category admits many braidings. **No new tensor to build.**

## Correction to the review that found this

Lumen offered *"|X|=|Y|=2: 3 vs 4"* as the rank witness. Both numbers are wrong, and 2,2 is the one small size where the ranks **coincide** (4 = 4) — the worst possible witness for the claim. Verified by direct computation:

```
|X|=1 |Y|=1:  Kronecker=1  product=2  DIFFER
|X|=2 |Y|=2:  Kronecker=4  product=4  coincide   <-- his witness
|X|=2 |Y|=3:  Kronecker=6  product=5  DIFFER
```

The shipped comment uses |X|=|Y|=1 instead. The conclusion stands on refutation 2 regardless, which is clean.

## What is NOT changed

The real scope limit is unchanged and was already stated correctly at `MenoBraided.fs:18-19`: `braidR` is a braiding of the **object**, not of the category — conjugation is natural only for group homomorphisms. The earned scope is ⟨V⟩, the strict monoidal subcategory generated by V, and that **is** built (`MenoBraided.rep`).

## Description

Aaron upgrades #7228's "engineering tidy" to a **core-thesis requirement**.

**Principle:** three flashers for one job is **accidental OS-complexity** (Brooks, *No Silver Bullet*) leaking in where a common abstraction can be closed over — and preventing that is the whole point of Zeta (§9/§10, interfaces-are-the-value). Unify into one `flash()` over a per-OS driver table `{enumerate,rawWrite,injectESP,presenceGate}`; Windows-Hello parity (#7228) folds in as one driver's `presenceGate`. The split leaked via parallel authorship — **smell to close, not blame** (#7227).

**Enforcement (closing the AI loop):** today a *human* catches the split (Aaron tells Max) = accepted tech debt. Fix = a **CI gate on infinite-free GitHub compute** (#7185), templated on `manifest-symmetry.test.ts` (#7182): structural single-abstraction test + QEMU per-OS acceptance across all drivers. The gate = the mini-society's immune system; authority stays human, the mechanical catch automates.

**Teaching:** shapes-as-letters as the bridge to give Max the close-over principle. Deferred to after the USB format.

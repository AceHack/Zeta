**Q3 first, because it gates whether Q1 is even about Meno.**

### Q3 — is `braidR` a braiding of Meno at all?

**The stated obstruction is NOT real.** The premise "our ambient tensor is described in our own source as cartesian" misreads `Meno.fs:38`, which says the **deterministic subcategory** is cartesian. The ambient `⊗_Kronecker` is not cartesian — it is not the product in `Mod_ℤ` (that is the biproduct), and `unitObject` is not terminal — so Mathlib's `Subsingleton (SymmetricCategory C)` does not apply. `braidR` is a braiding of `⟨V⟩`, which is exactly the scope `MenoBraided.fs` already claims. The §2 Lean results stand.

**But there is a sharper adjacent obstruction, and it is real.** A *cartesian* monoidal category has a **unique braiding** — stronger than Mathlib's Subsingleton, which only pins the *symmetric* structure. `I` is terminal, so naturality against `!_A : A → I` forces `π₁∘c = π_B` and `π₂∘c = π_A`, and the product's universal property then pins `c = swap`. And `braidR` is built with `Meno.arr`, so it lives in that cartesian deterministic subcategory.

The escape is real: every morphism of `⟨V⟩` is a **basis bijection** (`braidR`/`braidRinv` are mutually inverse — already machine-checked; `⊗` and `∘` preserve bijections), while copy `Δ` is not surjective and discard `ε` is not injective. Neither can enter, so by Fox 1976 `⟨V⟩` is not cartesian.

**"What is the minimal non-cartesian ⊗ on `⟨V⟩`?" — none is needed.** The ambient Kronecker `⊗` under a **hom-restriction** is it, and `MenoBraided.rep` already IS that restriction. The deliverable is a *guard*, not a construction.

### Q1 — balanced, or provably not?

**`⟨V⟩` IS balanced, uniquely**, with `θ_{V^n} = ρ(Δₙ²)` — the Garside full twist.

Both prior reviews reached "provably not balanced" from the same misreading: they read the axiom as `θ_{A⊗B} = θ_A ⊗ θ_B`. The actual axiom is

```text
θ_{A⊗B} = (θ_A ⊗ θ_B) ∘ c_{B,A} ∘ c_{A,B}
```

so `θ_V = id` forces `θ_{V⊗V} = c² = σ₁²`, **not** `c² = id`. `θ_V = id` is forced (B₁ is trivial) and correct, not degenerate.

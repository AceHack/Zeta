## Description

Portfolio-level finding surfaced while fixing the vacuous `verifyLandauer` (#10494). Filing it as a work-item because it was recorded only in a persona notebook, and it is larger than the PR that found it.

## The defect

**Every pre-existing `.smt2` runner in this repo asserts that all queries return `unsat`.**

An `unsat` expectation is satisfied by a **tautology**. If a lemma's premises secretly contain its conclusion, negating that conclusion is trivially unsatisfiable and the runner goes green — reporting a *proof* where there is only a *restatement*. **So no existing runner could have caught a vacuous lemma**, which is the one failure mode this lane exists to prevent.

## How it was found — CHECKED, not inferred

`tools/Z3Verify/landauer-floor-lemma.smt2`'s second-law premise `(>= (+ (- k) heat) 0.0)` **is** the conclusion `heat >= k` it then negates. Deleting *only* that premise flips it from `unsat` to **`sat`, model `k = 1.0, heat = 0.0`** — an erasure paying no heat.

Two aggravating facts: the header advertised **four** lemmas (F1–F4) and the file contained **one**; and **no workflow executed it**, which is why it rotted.

## The fix pattern, already demonstrated in #10494

Assert the **verdict sequence** including a deliberate **`sat`** from a **non-vacuity probe** — a query satisfiable iff the lemma is not a tautology. Cross-checked by **z3 and cvc5** returning the same sequence (BP-16).

Same discipline as a mutation test: *a check that cannot fail is not a check*, and you prove it can fail by making it fail on purpose. It's also the sibling of today's TLC finding (`QuorumCollateral` and `WagerSolvency` stutter, so their deadlock checks are vacuous) — which suggests **the vacuity class spans every formal lane here**, not just SMT.

**Acceptance:** no runner asserts all-unsat; every `.smt2` is executed or listed with a non-empty reason; mutating a lemma into a tautology turns its runner **red**.

## Description

`.markdownlint-cli2.jsonc` **already** excludes `docs/history/pr-reviews/**`, with the reason stated inline: reformatting those to satisfy MD007/MD012/**MD032** *"would violate the verbatim contract"*. `docs/history/pr-reviews/README.md` says the same (*"Read, do not refactor"*), and so does `AGENT-BEST-PRACTICES.md`.

**The rule was right, documented in three places, and never consulted on the path that could write.** Both heal call sites built their worklist as:

```bash
mapfile -t files < <(git ls-files '*.md')
```

— every tracked markdown file in the repo, ignore list unseen. That array is read only by `markdownlint-cli2` when *checking*; the fixer is invoked directly with a raw glob.

## What it cost

On 2026-08-13 the healer rewrote **414 preserved PR-review archives** with an MD032 fix — minutes after they were drained out of orphaned bot branches, and MD032 is the exact rule the config names. Operator's call was to keep the already-healed files and fix the cause, so **this commit changes no archive content**.

## The fix

Reads the **same** `ignores` array the linter uses rather than restating it. A second hand-maintained exclusion list would drift from the first the moment someone edited one and not the other — which is how this class regenerates.

```bash
git ls-files '*.md' | bun .../healers/md-heal-scope.ts
```

Measured against the real repo: **2,753 healable, 13,825 withheld, zero pr-review archives surviving the filter.**

A missing config **throws** rather than returning `[]` — a guard that cannot be read must not degrade into "no guard", which would silently restore the exact behaviour this closes. The withheld count prints to stderr so the guard is visible doing its job.

## Description

The `--all` suite intermittently FAILed `NciNonUrgency` with a **JVM fatal error** (native OOM at JVM startup), while the spec passes when run alone. Root cause: the sequential suite's accumulated memory pressure occasionally prevents a fresh JVM from reserving its (default, uncapped) heap. A **flake, not a determinism failure**.

**Fix:** `runTlc` retries up to 3× with a settle delay, but **only** when the failure is a JVM-level crash (`isJvmFatalCrash`: hs_err / native OOM / could-not-reserve-heap / SIGSEGV). A real TLC failure (invariant violation, parse error, deadlock) does **not** match and surfaces on the first attempt — **deterministic failures are never masked**. Settle is a synchronous `Atomics.wait` so the prior process releases memory before the next start.

**Verified:** full `--all` now **27 passed / 0 failed** (incl. `NciNonUrgency` + the two new Aurora specs); single-spec runs unchanged; `tsc --noEmit` clean.

## Description

Maintainer refinement to the ConditionalWeakTable/WeakMap 'mixin' primitive caveat (the follow-up I committed to after #6371 landed the entry).

The earlier note said "surprising to debuggers/serialization; keep it internal." Maintainer's correction: **the debugger downside is mitigable** — ship a `[DebuggerTypeProxy]` / debugger visualizer that reads the weak-table and surfaces the attached state inline (a quality bar for the primitive, same shape as the `plugin-unloads-cleanly` test; `[DebuggerDisplay]`/`[DebuggerBrowsable]` help too). The part that genuinely stays: **serialization is opt-in** — no field for a serializer to see, so persist only by explicit projection (JS `WeakMap` same; Rust's explicit state avoids it). Net: keep it internal, but make it visible.

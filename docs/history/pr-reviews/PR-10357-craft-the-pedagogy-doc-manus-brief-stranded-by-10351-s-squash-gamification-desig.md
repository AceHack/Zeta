## What's here

**`docs/craft/pedagogy/ground-up-ordering-schuller.md`** — ground-up ordering as the *theoretical track's* method, filed with its tension named: Craft's default is tool-use-first, and this is the opposite instinct. No conflict, because Schuller draws the same split himself.

Load-bearing claim: **"advanced" is not a property of a subject — it records when the author happened to learn it.** Order by dependency structure, which has a right answer, not by remembered difficulty, which doesn't. His example: covectors before momenta, because canonical momenta *are* covectors.

Also carries:

- **The graph** as a mermaid DAG. Edges are *"not statable without"*, not *"harder than"*.
- **The dual traversal** — Zeta enters anywhere and descends on demand. Eager vs call-by-need over the same DAG.
- **The forced set** and its test (Aaron): *a node is forced iff the human is the last line of correction for it* — no other model reachable, or none with the expertise. This makes the requirement **derived, not decreed**: it falls out of a quorum condition, so the AI reports the redundancy graph rather than imposing a curriculum. Consequence recorded rather than buried: the forced set is **exactly the frontier**, so frontier work carries a learning tax.
- **The Merkle answer** — it *is* a lazily-resolved Merkle DAG, and "bidirectional" is precise: resolution descends, verification ascends, exactly as git and IPFS already work. Honest limit: you can content-address the graph, you **cannot hash understanding**. Invalidation, not attestation.
- **The gamification design** (new) — Intelligent Connect as the auto-resolution algorithm, and grades-as-currency with its conflict against the privacy rule stated rather than finessed. Resolution: a grade on a *forced* node mints budget (you became a corrector where society had none — value added to others, socially conferred, since the forced set is computed not chosen); a grade elsewhere doesn't. Residual attack named and left open.

**`docs/handoffs/2026-08-13-meno-braid-brief-for-manus.md`** — self-contained Meno braid brief for an external model with no repo access. Definitions and all seven machine-checked theorems inline; ribbon/MTC marked **closed** with reasons so they aren't re-treaded; four open questions, of which Q3 could undercut the rest.

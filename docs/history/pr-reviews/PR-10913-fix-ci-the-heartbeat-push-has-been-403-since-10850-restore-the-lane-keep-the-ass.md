### Cause

PR #10850 (`9fd69a992e`, merged **2026-08-15T23:01:23Z**) switched both `actions/checkout` steps
to `persist-credentials: true` + `token: ZETA_TELEMETRY_FLUSH_TOKEN`, so the `heartbeat/*` PR head
would carry a human push actor and `gate (required)` could start (081M010H4KE / 081M005FXAB).

Its premise — *"the archive/society flush already uses this PAT"* — is true for the **API**
(`GH_TOKEN` handed to `gh` / `flush-via-staging.ts`) and **false for `git push`**. `society-heartbeat.yml`
and `tick-metrics.yml` check out with the **default GITHUB_TOKEN** and use the PAT only as an `env:`;
`agent-heartbeat.yml` after #10850 pushes *with* the PAT — which authenticates as AceHack and carries
no `contents: write`.

reads `GH013: Repository rule violations found`, not `Permission … denied to AceHack`.

### Why this is worse than the bug #10850 set out to fix

#10850 traded a **degraded** lane (telemetry lands on the branch; the flush PR's gate does not start)
for a **dead** one (nothing lands at all). And `heartbeat/*` is the *externalized idle counter*
`CLAUDE.md` tells every agent to read instead of trusting its own narrative self-count — so a frozen
ref reads as the standing-by failure by construction.

## What this PR does

**Grace in the artifact, strict in the test** — the trajectory's own carved discipline:

- push attempts the PAT first. Once the token is granted `contents: write` this is byte-identical to
  #10850's intent and the fallback never fires again.
- on a **credential denial only**, fall back to `GITHUB_TOKEN` so the lane keeps recording, with a
  `::warning::` and a step-summary block naming the exact fix.
- a non-fast-forward, a `GH013` ruleset violation, or a network error stays **fatal**. The fallback
  cannot swallow a different failure.
- `required-check-started.ts` in the flush job is **untouched**, so the workflow stays red while
  `gate (required)` never starts. Nothing here can make a broken credential look green.

Also corrected in passing: the in-file note claiming ruleset `16934633` targets
`refs/heads/agent-heartbeats` and "matches nothing" is stale.

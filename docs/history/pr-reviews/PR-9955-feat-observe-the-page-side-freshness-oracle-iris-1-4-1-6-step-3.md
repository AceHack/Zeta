## Description

The adapter emits timestamps and never precomputed adjectives, so a stopped society degrades honestly. **That guarantee was only half real.** The adapter can be perfectly honest and the page still lie, by computing freshness once at load and never again — a tab opened at 09:00 that never recomputes still reads `live` at 17:00, and *"a stopped society can never render live"* is then false in the only place anyone observes it.

This is the other half: pure functions with `nowMs` **injected** — no ambient clock, same DST/noninterference discipline as the adapter, so the page replays from a fixture and tests move time without mocking globals.

```
freshness(iso, now)  →  live | stale | cold | UNOBSERVED
combine / worst      →  monotonicity: a parent never renders fresher than its evidence
hasHeat              →  absorbing, but ages out so recovery is observable
statusOf             →  heat overrides; unobserved candidates DROPPED, not counted cold
RETICK_MS            →  exported so "did anyone wire the timer" is greppable
```

**Design points:** `unobserved` sits deliberately *outside* `Status` — "no measurement" differs from "measured, cold", and the page renders them differently. `worst([])` is cold, so unknown never reads alive. And a future timestamp isn't "extra live" — clock disagreement is not evidence of freshness.

Pinned: the measured **~65min real cadence reads `stale`, not `live`** (a threshold calling it live would hide the gap that motivated self-hosted runners); a 7-hour-old stamp is cold — the case the shipped snapshot got wrong; one cold child drags a live parent down.

## A test of mine was wrong, and is corrected rather than worked around

I asserted `Date.parse("0")` was unparseable. **It isn't** — JS reads a bare `"0"` as a year and returns 946702800000 (year 2000). The module was right; my test asserted a fiction. Replaced with the property that actually matters and generalises: **nothing malformed may ever read as `live`**, whether or not it parses.

Also documents one **equivalent mutant** (`<=` → `<` in `combine`): equal aliveness index means the same status, so both branches return identical values and no test can distinguish them. Left un-"fixed" deliberately — a test written to move that number would be theatre.

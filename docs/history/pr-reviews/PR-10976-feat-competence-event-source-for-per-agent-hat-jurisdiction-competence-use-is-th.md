## Description

## The gap, and the trap

Nothing measures whether a reviewer's findings hold up. `calibration-ledger.ts:320` has the right Beta posterior and the wrong quantity — its own contract says **"CALIBRATION ≠ COMPETENCE."** This lands the missing **event source**. It adds no estimator (`TravelerRankLedger` already is one) and is **wired into no aggregation**.

The trap: if *upheld* means *"≥3 reviewers agreed"*, the ledger measures agreement, and feeding that back makes popular reviewers competent by construction.

Aaron's answer, and the design target: competence is measured by **use** — *"the bugs discovered during use and how much it's used without issues"* — and *"we can use agree as a early indicator of correctness but only use is the ultimate determinator."* So **agreement is the PRIOR, use is the LIKELIHOOD**. Never averaged; every reading reports `priorShare = σ²/σ₀²`.

## It cannot be honestly populated today — and not only for lack of usage

| # | gap | evidence |
|---|---|---|
| 1 | **The one four-key DORA fold in-tree defines a change failure as a REVIEW VERDICT** (`ChangesRequested`) | `packages/observability/src/dora-metrics.ts:98-101` |
| 2 | The Zeta-side fold computes **no failure metric at all** | `work-items/dora-fold.ts:167-181` |
| 3 | **No defect → causing-change link** in the schema or the event log | `work-items/types.ts:46-66` |
| 4 | The actor field is a **tool name**: 241 events, `by` ∈ {`otto-cli`×219, `otto`×20, `drift-sweep`×2} | `workitems/events/**` |

Gap 1 matters most: wiring "DORA per agent" to the existing fold would have reproduced the exact circularity, wearing an *Accelerate* citation.

## Typed, signed edges — Shepard's/KeyCite, anchor checked

A citing authority **follows / criticizes / distinguishes / overrules**; *"is this still good law?"* is a **fold over treatments**, not a citation count. `authored`/`approved` assert the subject is sound (+1); `warned`/`warned-overruled` assert it is not (−1); `repaired` takes no position and is never folded.

An observation is **`stance === outcome`**, which makes the case that matters representable: **a lone warner overruled by quorum and vindicated by use scores a hit while the approvers score misses.** Nothing is divided, so no division rule is needed — which is how attribution is resolved for anyone who took a position. Co-authorship still needs TrueSkill's team model, **unbuilt on both oracles** (`trueskill.ts:22`), and that absence is stated as the blocker.

Treatments needing an editor's judgement (`distinguished`, `limited`, `harmonized`, `explained`, `questioned`) are **listed as underivable rather than approximated**.

## Attribution is a query; unattributable moves nothing

Aaron's LexisNexis pattern: layers as metadata over an **unmutated** source. Outcomes carry **no agent and no blame**; the named rule id travels with every reading, so re-querying under a different rule loses nothing. Substrate is **P1 umbrella `081KSXN940008QG0R001YABTHH`**, not a parallel invention.

An **interaction** between treatments or an **omission** no edge contains is not an observation about any individual, so **no posterior moves** — smearing it is #10945's defect at the attribution layer. It banks against the **mechanism** instead (`mechanismCoverage`, with per-bucket improvement triggers), and every reading carries `mechanismSeen` so a no-update never reads as a clean record. The role-level case Aaron's *"mostly"* leaves open is **flagged, not decided**.

## Labels are judgments; the recursion terminates

The guard is narrow: **the labeler must not be the agent the label updates.** Reports (*intent + observation*) are the durable original; the bug-label and the determination are **layers**, and a re-determination adds a layer rather than overwriting one. **Reporter competence is measured** per (reporter, jurisdiction) — the defence against low-quality reports at scale, since no report is ever rejected. It stops where Shepard's stops: two roles, one measurement each, determiner identity recorded so a treatment stays challengeable.

## Jurisdiction = partial pooling, with a guard

Binding at full weight; out-of-scope **persuasive** at `1/(1+d)`; below the floor it is **reported as `scoped-out`**, so scoping can never be used to make inconvenient evidence disappear. Shape anchored (Gelman & Hill 2007); **the discount rate is a chosen constant, labelled `unmetered`.** The estimator has no weight parameter, so `temperedUpdate` interpolates in natural parameters — an approximation, stated as one. Adding a jurisdiction axis to `TravelerRankLedger` itself is a maintainer's call.

## Measured, not assumed

- **ADF is order-dependent** — {3 hits, 2 misses} folds to μ = 0.2113 in one order, 0.1829 in another. Hence a canonical order, and hence **not** `db/uncertainty/` (single-scope doctrine; that ledger is commutative).
- **Prior washout** — with |μ₀| ≤ 1.0, **one** contrary use-observation flips μ₀ ∈ {0.25, 0.5, 0.75} and **two** flip 1.0; `priorShare` falls to 0.27 at k=5 and 0.15 at k=10. That is what justifies the cap against a low event rate.

## Description

You: *no pivot just continue* — the honest YAML follow-up. Indentation-sensitive languages (YAML, Python, Haskell layout) are **not context-free**, so the LR/GLR backend can't consume them directly. The standard fix (Landin's off-side rule; the Python tokenizer) is a **lexer pass** turning leading whitespace into explicit **INDENT/DEDENT/NEWLINE** tokens — after which the stream is context-free and the backend parses it.

- **`Indentation.layout`**: source → token stream with the markers. Indentation stack; deeper line pushes (INDENT), shallower pops to a matching column (DEDENT per pop); blank lines skipped; EOF closes all opens. **Inconsistent dedent** and a **leading TAB** are clean `Error`s — total, never throws. Deterministic.

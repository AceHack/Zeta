## Summary

Faithful port of Merge1 §08 (Identity/Isolation Stack) from `full-ai-cluster/`
into `agentic-organization`. Lands SPIFFE workload identity, Cilium L7 egress
policy, the Vault dynamic-secret credential proxy, the bubblewrap sandbox engine,
and the boot-time credential restore. New-modules-first, same precedent as
§01–§07.

New modules (`packages/application/src/`):

- **`spiffe-identity.ts`** — port of `spire/Application.yaml`. `SpiffeIdentity` +
  `SpiffeSvid` (x509|jwt), `agentIdentityFromSpiffe` (last path segment →
  `agentId`, full ID → `subject`), `trustDomainOf`, and `validateSpiffeIdentity`
  (trust-domain + expiry, Result-shaped — MP-7). `createMockSpiffeIdentityProvider`
  is deterministic for DST (MP-1); an empty workload id → `workload_not_found`.

- **`egress-policy.ts`** — port of `cilium/Application.yaml`. The flat
  `allowedEgress: string[]` becomes a structured `EgressPolicy` (L3/L4 hosts, L7
  per-host method/path rules, `requireMtls`, SPIFFE service accounts) with
  `isAllowedEgress` / `isAllowedHttpEgress` / `isAllowedServiceAccount`.

- **`vault-credential-proxy.ts`** — port of `vault/Application.yaml`. Vault I/O is
  async, so this is a **separate** `AsyncCredentialProxyPort` seam rather than a
  breaking change to the existing synchronous `CredentialProxyPort`:
  ```ts
  grantsFor(identity, hatIds) // → for each hat: request zeta/hats/<hat>/tool-grant
                              //   scoped to identity.subject; ok → grant, else skip
  ```
  A denied/missing secret is skipped, not thrown (MP-7); grants are sorted for
  determinism.

- **`bwrap-sandbox.ts`** — bubblewrap engine. `BwrapSandbox` seam + pure
  `buildBwrapArgs` (so the `--unshare-all` / `--die-with-parent` / `--ro-bind`
  lock-down can be asserted without spawning), a real `spawn`-based adapter
  (`bwrap_not_found` on ENOENT), and a deterministic `createMockSandbox` for DST.

- **`credential-bootstrap.ts`** — port of `zeta-creds-restore.nix`. scrypt
  (default `N=2^20, r=8, p=1`) → HKDF-SHA256 → AES-256-GCM, blob header
  (`version|logN|r|p|salt|iv`) authenticated as GCM AAD. `encryptCredentials`
  companion for round-trips; passphrase rejected empty and zeroed after KDF;
  wrong passphrase / tamper → `decryption_failed` via the auth tag.

EXTEND:
- `index.ts` re-exports the §08 surface.
- `packages/test-node.d.ts` — the repo uses a **hand-written minimal node shim**
  (no `@types/node`, no `Buffer`/`spawn`/full `crypto`). Extended with exactly the
  `node:crypto` (scrypt/hkdf/cipher) + `node:child_process` `spawn` surface used
  here. Source code uses `Uint8Array` + Web `TextEncoder`/`TextDecoder` (no
  `Buffer`), matching the repo's restricted-node-API convention.

**Deferred (integration polish, same precedent):** `createRealRoom` and the
`room.ts` EXTENDs (`AgentIdentity.spiffe`, `SandboxSpec.egress: EgressPolicy`,
`RoomSeamBinding.visibility`). The seams + adapters are the load-bearing surface.

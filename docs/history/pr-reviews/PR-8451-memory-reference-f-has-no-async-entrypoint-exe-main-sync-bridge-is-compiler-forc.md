## Description

Verified empirically (SDK 10.0.203): F# `[<EntryPoint>]` is hard-required to be `string[] -> int`; a `Task<int>`-returning main fails with `FS0001`. Only C# has `async Task<int> Main`. So the single sync↔async bridge inside an F# exe `main` is **irreducible** and **not** an async-all-the-way violation (that rule targets library/hot paths; `main` is top-of-stack, no async caller to starve).

Records the 2026-06-16 `.Wait()` audit (clean — no `.Wait()`/`.Result`/`async void`/library sync-over-async) so the Cli/Mcp/SubstrateDiscovery entrypoint bridges + the guarded `PluginHarness` ValueTask fast-path aren't re-flagged in future audits. `Task.Run` sites noted as Vera's lane.

## Description

Aaron: *"also everyone needs 2-3 seed phrases but at least 2 for easy rotations."*

Each traveler holds **≥2 seeds**: **active** (in use) + **standby** (pre-generated + **pre-trusted**, pubkeys pre-published) + optional spare. Rotation becomes a **promote, not a flag-day scramble**: promote standby→active, old→retiring (overlap window), generate fresh standby — **no trust gap** (next key already vouched for). Exactly the **Itron KeyState lifecycle** (Standby→PendingActive→Active→PendingInactive→Inactive). Hardens the **future-self attack vector** (compromised active rotated out instantly to the pre-trusted standby; composes with multisig/social-recovery, M-of-N over seeds). Tooling: `keyring.sh` tracks ≥2 seeds; rotate = promote-standby + generate-fresh-standby; KeyState axis orthogonal to custody; `keyring-public.json` surfaces both. Interim (single-seed tool today): generate `name` + `name-standby` and rotate manually.

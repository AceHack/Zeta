## Description

fix(081M24C2CM1087G0R0000HBSBN): CLAUDE.md sent every agent to a liveness source that is intentionally paused

The heartbeat paragraph tells every agent, on every wake, to externalise its
idle counter by reading `refs/remotes/origin/heartbeat/*`. Those refs are
frozen.

Measured 2026-09-09:

  origin/heartbeat/alexa                 last commit 2026-08-29
  origin/heartbeat/context-cost-trend    last commit 2026-08-29
  origin/heartbeat/budget-snapshot       last commit 2026-08-23
  origin/heartbeat/dejan-local           last commit 2026-08-25

Twelve days stale, and not by accident: 16 of 105 workflows report
`disabled_manually` from the Actions API, including the four that wrote those
refs — `agent-heartbeat`, `society-heartbeat`, `tick-metrics` and
`drift-sweep`. They were disabled deliberately by the maintainer because their
cadence commits were growing the repo. `drift-sweep.yml` holds
`contents: write` and commits a tick event to `docs/drift-events/` every run,
which is exactly that class.

So the instruction now produces the failure it was written to prevent. An agent
follows it, sees no commit in the tick window, and concludes the fleet is idle
— a false negative in the one check whose whole subject is false negatives. The
paragraph even names the shape it has become: "a check that did not run looking
like one that passed."

The fix is not to re-enable anything. Re-enabling would resume the growth the
maintainer removed, and that is his call, not this file's.

What replaces it is the source that is actually live. `liveness/observations`
was written at 2026-09-10T00:26 and reports `"outcome": "paused"` with the
watched lane named — it observed the pause and said so, which is the system
working. So agents are pointed there, and told the thing that makes the
difference safe to act on: absence of `heartbeat/*` commits means the lanes are
paused, never that work stopped.

Dated and scoped rather than open-ended, because a stale warning is the same
defect one turn later: it names when the pause began, what measured the
staleness, and that it holds until the telemetry redesign lands.

No behaviour change. Documentation only.

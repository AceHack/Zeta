## Description

You: *no pivot just continue* → retire the KDL fork. One integration test of the **whole spine** on a real config grammar:
```
real .g4 → Antlr4Import.ingest → GrammarIr (a DynamicValue, closed) → Slr.buildGlr → glrParse
```

**KDL** is the subject because it's CFG-friendly *and* its document grammar is genuinely **ambiguous** (`node ID` = a node with an ID argument OR two adjacent nodes) — so it exercises the **GLR fork**, not just SLR. The ingested KDL grammar is `isClosed`; GLR parses `node 1`, `node key="x"`, `parent { child 2 }`, the ambiguous `a b`, the empty document; rejects unmatched brace / dangling `=`.

**So KDL is now a grammar we ingest + parse, not a hand-written codec — the KDL fork is retired.**

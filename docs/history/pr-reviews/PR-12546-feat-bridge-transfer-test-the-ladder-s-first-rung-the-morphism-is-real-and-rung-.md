## Description

## The claim under test

`CHIP-8 → CHIP-9 → Atari (ALE) → ARC-AGI-3 → decorrelated human measurement`, and the claim that
"lessons compose along morphisms" — design intent, not a measured result. Tested at the cheapest
link first, on the reasoning that a link-one failure invalidates the rest for a fraction of the cost.

## Inventory first

CHIP-9 **already exists** as an executing target, so the fallback deliverable ("here is the minimal
spec to make it testable") was not the honest one. The ISA delta over CHIP-8 is exactly one opcode
— `Fn01` plane select — plus per-plane `DXYN` and selective `00E0`, locked across four language
oracles by `src/Core.TypeScript/chip9/golden-vectors.lines`. Two framing corrections landed in the
doc: the gate-synthesis column (`CpuSynthTests` / `NetlistTests` / "THE LAW") targets `Isa`, a
CHIP-8-*shaped* 7-opcode toy sharing zero code with the emulator; and `Orbit.largestLyapunov` has
never been run over a CHIP-8 state space.

## The morphism

`ι(s) = s with plane := 1, extra := ∅`, and the law `step₉ ∘ ι = ι ∘ step₈` on `Fn01`-free
programs — a functional bisimulation, i.e. CHIP-9 is a **conservative extension** of CHIP-8.
Checked step-by-step over `pc`, all 16 registers, `I`, and all 2048 pixels; conservativity is made
observable by additionally asserting the extension's own state stays at its zero value.

Anchors, checked to entail: Weisbecker (COSMAC VIP), John Earnest (XO-CHIP `FN01`),
Hartmanis–Stearns 1966, Park/Milner, Groote–Vaandrager/Verhoef.

## A lesson, operationally

A text artifact: seeded memory + ROM + trace assertions in a plane-agnostic predicate vocabulary +
**the name of the structural axis whose destruction should falsify it**. Carriable because it is a
file; falsifiable because a lesson no control breaks is refused as a lesson. Four of them, all
properties the repo already depends on — XOR-draw involution (what `zeta-breathe.ch9.lines`
animates with), VF as a per-draw witness, and both halves of the COSMAC VIP edge treaty
(`081KTZ4EF0008QG0R002WVTMMJ`).

## The control — and why the obvious one is invalid

**Permuting the opcode table cannot destroy structure: a permutation of labels is an
automorphism.** The suite demonstrates this rather than asserting it — the relabelled machine fails
all four lessons untranslated and passes all four translated, so a naive "scrambled target"
measures whether you remembered to translate, not whether structure was preserved.

The valid controls destroy one **named** structure each (`or-draw`, `no-clip`, `no-origin-wrap`,
`vf-sticky`) and are built as one parameterised interpreter, so complexity matching is structural
rather than claimed. `or-draw` is *provably* not a conservative extension: XOR generates a group,
OR a join-semilattice, and no injective map sends an involutive generator to a non-involutive one.

## Result — positive, as pre-registered

All four lessons survive the lift into the plane region CHIP-9 adds; that region is confirmed
**unreachable** from CHIP-8 (the lifted artifacts fail there, so the lift is not cosmetic); each
control breaks exactly the lesson naming it. A clean 4/16 diagonal — the instrument is neither
blind nor blunt. 11 tests, ~78k assertions, and the instrument is byte-locked to the shipped
CHIP-9 treaty golden so it cannot silently drift from the machine the four oracles implement.

Reproduce: `bun src/Core.TypeScript/bridge-transfer/run-transfer.ts`

## The finding that actually matters

**Rung 1 is a conservative extension; rung 2 is not a morphism of any kind.** There is no inclusion
CHIP-9 → Atari 2600 — different CPU, memory model and display, no shared instruction set. The
ladder equivocates on "morphism", so **link-one success carries no information about link two**.
And per §8b it equivocates on "lesson" too: the repo already holds two other meanings, and the ARC
end of the ladder needs the *recognizer* sense, which has no implementation.

So the recommendation is not "proceed to Atari". It is **CHIP-8 → 6502 via `IsaSpec.fs`**, which
already carries a 6502-shaped second witness — a genuine non-inclusion between real ISAs, at a
fraction of ALE's cost, and the first rung where "morphism" would have to mean something new.

## Two anchors checked and rejected

- **Futamura** — no specialiser and no generator in this experiment, so partial evaluation entails
  nothing here. Aaron's completeness precondition is not even reached. (The 36% figure is anchored
  to its upstream counts in the doc: 38 leg-less of 106 build-graph targets; upstream records
  counts, never the percentage.)
- **Bellemare et al. 2013** — a **platform** paper. Its train/test *game* split is a methodological
  guard against overfitting agent design, not a measured inter-game transfer result. The documented
  Atari negative transfer is **Parisotto/Ba/Salakhutdinov 2016** (Actor-Mimic) and **Rusu et al.
  2016** (Progressive Nets); Machado et al. 2018 is the revisit. The correction *strengthens* the
  brief's reasoning — negative transfer between games sharing a console is a sharper warning about
  rung 2 than a platform paper would have been.

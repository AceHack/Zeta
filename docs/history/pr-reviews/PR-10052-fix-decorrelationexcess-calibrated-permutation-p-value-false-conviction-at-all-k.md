## The defect

`DecorrelationExcess` classified a pair by `stat > quantile(1 − δ, nullStats)` (`nullThreshold` + `classifyPair`) — **no `(1+b)/(k+1)` Monte-Carlo correction** (Phipson–Smyth 2010) and the observed statistic **excluded** from the reference set. For the MI paths the null is exactly `k` values, so the per-stratum false-conviction rate is unrelated to δ at small k:

| k | δ | actual false-conviction rate |
|---|---|------------------------------|
| 1 | any | **≈ 0.5** (`quantile(_,[v0])=v0`; observed vs 1 null = coin flip) |
| 5 | 0.05 | **≈ 0.15** (~3× budget) |

This contradicts the module's own repeated "≤ δ / never a false green" docstrings — in the false-conviction direction (falsely flagging honest independent identities, the exact harm the oracle claims to bound). Affects `fuse` + all four `fuseMI*` variants.

## The fix

- **`permutationPValue`** = `(1 + #{null_i ≥ observed}) / (k + 1)` (the observed IS an exchangeable arrangement under H₀ → must be counted); **`classifyByPValue delta`** convicts iff `p ≤ δ`. δ-calibrated for **any** k, and self-enforces the `k ≳ 1/δ` floor in the **safe** direction: when `(k+1) < 1/δ` the reachable floor `1/(k+1)` already exceeds δ ⇒ nothing convicts (soundness-biased toward `WithinNull`).
- Rewired `fuse` + `fuseMI`/`Block`/`Window`/`WindowBlock`. `MIStratum` gains a `PValue` field; `NullThreshold` kept as **audit-only** (documented).
- **Secondary P2** (same review): `quantile` no longer throws `IndexOutOfRange` on `δ ∉ (0,1)` (clamps the index); `nullThreshold` returns `nan` for invalid δ (parity with `AntiSybil.chshMargin`).

## Description

Aaron recalled *"some formal check that we did not use `app` anywhere in our code … I think we were trying to prove homoiconicity."* Found it. The recollection is substantially real and correctly sourced to `ISR` — and three details are wrong in ways that matter.

## What was found

`docs/research/ip-questionable/2026-08-13-…-einstein-derived-from-maxwell-predictivity-aaron-forwarded.md`, section *"Addendum — which 'arrow', precisely"* (lines 286–331, merged in #10351/#10360).

**The "formal check" is a grep, run once in a session and recorded in prose.** Not a test, not a lint, not wired to CI. `rg -l -i 'ArrowApply|app-free'` over `src/` and `tests/` returns nothing.

## The sense of `app` is a fourth one

Not the HKT `App<'F,'T>`, not applicative `ap`/`<*>`, not the CCC evaluation morphism. It is **Hughes's `ArrowApply` operator** (*Generalising Monads to Arrows*, SCP 37, 2000), and the load-bearing theorem is **`ArrowApply` is equivalent to `Monad`**.

That makes Aaron's *"it let us keep monad-like structure"* right about the association and **inverted in valence**: `app` is what grants monadic power. The design point was staying *out* of it, because the `app`-free fragment is where pipeline shape is fixed at construction and therefore statically analysable — what the CHIP-8 cost predictor needs.

## Two claims were welded into one sentence; only the first survives

**True** — bare `app` is 0 occurrences in F# sources; the grep reproduces.

**False** — *"sits inside the `app`-free fragment **by construction**."* That asserts a type-level obstruction. `IntrCtx.fs:34` is a Kleisli arrow over `Task<Result<_, InterruptFeedback>>` (its own docstring at line 17 says *"the ISR **monad**"*), and Hughes gives `Kleisli m` as an `ArrowApply` instance for any monad. Verified under `dotnet fsi` against the exact type — `app` is definable in one line:

```fsharp
let app<'a, 'b> : ISR<ISR<'a, 'b> * 'a, 'b> = fun ctx (f, a) -> f ctx a
```

So: **`app`-free by absence, not by construction** — the condition that needs a falsifier, since nothing stops the next commit.

Scope is also narrower than the sentence reads. `Meno.fs:170` has a genuine monadic `Bind` that selects an arrow from a runtime value (`let (MenoArrow h) = g span.[i].Key`) — outside the fragment by the same theorem.

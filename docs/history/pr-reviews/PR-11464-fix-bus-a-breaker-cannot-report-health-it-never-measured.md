## Description

Split out of #10735, which bundled this with a separate pressure-classifier change. That half is blocked on a stale structural model after main refactored to `HeatSignature.classifyKind`; **this half is independent and green**, so it should not wait behind it.

## The defect

`export-cb-snapshot.ts` derived breaker state from envelope counts alone, so an identity with **zero observations rendered as `CLOSED`** — the same reading a healthy, actively-measured agent produces. A silent agent read *healthier* than a merely idle one, and `lastCheck` was stamped with a fabricated `now` for a check that never happened.

That is this session's recurring class in one more place: **a check that did not run must never look like a check that passed.** An instrument reporting a health value it never measured is worse than one reporting nothing, because an operator can cite it.

## The fix

`UNKNOWN` becomes a first-class fourth breaker state, and it is not a shade of `CLOSED`:

- zero observations → `UNKNOWN`
- traffic without health evidence → `UNKNOWN`
- `lastCheck` is `null` when never observed, not a fabricated `now`

Every `CLOSED` reading is now a measured one.

## Falsified, not asserted

Flipping the zero-observation arm back to `CLOSED` fails **five** tests, including *"an identity with no envelopes reads UNKNOWN, not healthy"* and *"no input produces CLOSED with zero observations"* — 6 pass / 5 fail; restored, 11 pass.

Stated honestly: running the new tests against main's file fails on a **missing export**, not on behaviour. That import-level failure is *not* the evidence — the mutation above is.

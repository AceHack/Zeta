## Description

## B1a — the gate could not notice B1, in both directions

`checkLocalCheckoutFreshness()` bails if any install-substrate file differs
`HEAD..origin/main`, so an operator cannot flash a stale checkout. Its watch list named:

```
full-ai-cluster/usb-nixos-installer/flake.nix
```

**retired** under work-item `081KZKS9A6B08QG0R0008EG72M` — while the flake the ISO is
**actually built from**, `full-ai-cluster/flake.nix` (what `build-ai-cluster-iso.yml`
builds and filters on, with its lock), **was not watched at all.**

## The missing path is not a weak check — it cannot fail

Measured in this repo:

```
git diff --quiet HEAD origin/main -- full-ai-cluster/usb-nixos-installer/flake.nix  -> 0
git diff --quiet HEAD origin/main -- some/totally/made/up/path.txt                  -> 0
```

A pathspec matching nothing exits **0** — the same code the caller reads as *no change*.
So the retired entry reported **clean forever**, and the nixpkgs 25.11→26.05 bump could
change what the ISO contains with the gate silent.

## Fix

The list carries `full-ai-cluster/flake.nix` and `full-ai-cluster/flake.lock`, and moves
to its own module. **The extraction is required, not tidiness:** `cli.ts` calls `main()`
at module scope, so a test importing it to read one constant would run the CLI.

## Falsifiers — mutation-checked

| test | pins |
|---|---|
| every watched file exists in the repository | the **general** guard — the next retired path is caught by shape, not by someone remembering |
| a pathspec matching nothing exits 0 | the git behaviour the guard compensates for; if git ever started erroring, the redundancy becomes visible instead of silent |
| watches the flake the ISO is actually built from | the specific regression |

Restoring the retired path fails two of three (**1 pass / 2 fail**); restored, **3 pass**.
Full zflash suite after the extraction: **786 pass / 0 fail**. `tsc`: 0 errors.

## Scope

This repairs the **detector**, not B1. No ISO has been built from the current flake, and
this does not build one — it makes the staleness **detectable**, which is the
precondition for trusting any later build.

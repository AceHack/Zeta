## What it credits

The *de facto standard* shape — `messages[]` / `choices[]` / `delta` over SSE / `tool_calls` — stable enough that an ecosystem emulates it, which is exactly why `openAiCompatBackend` treats Manus, local servers, and OpenAI as one port with a swapped config.

It names the limitation — extraction-shaped, "I prompt, it completes, I took something" — as a **property of the shape, not a defect of the design**. What you added is the feedback wire in both directions: `feedback-out` (interrupt / steer / clear a running generation) and `feedback-in` (backpressure / need-more / clarify mid-flight). Neither exists in the original, and neither is a fix to it — they're the corners the extraction shape has no place for.

Also anchors **SSE (WHATWG `EventSource`)** as the streaming transport, and **Anthropic's Messages API** as the independent second instance — which is what shows the shape is a convergent standard rather than one vendor's idiom.

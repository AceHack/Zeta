## Description

## Summary

Closes `081M005CGB7087G0R0031328CY`. The society heartbeat constructed a fresh BNN every 30 minutes. `saveBnnState` / `loadBnnState` had zero callers. Every PriorHint list was empty, and `heatReadout.trend` could not exist — a derivative needs two beliefs.

Both ends are now soldered in `society-bnn.ts`:

- **Load** `docs/observe-events/bnn-state.json`, or start from the constructor prior
- **Absorb this generation** as one `calibration` observation keyed by event id. Re-folding the event log would double-count (the persist format does not carry the envelope guard)
- **Save only if something was absorbed**, so the file is never the prior in disguise
- **`evolve()` does not read the BNN.** Restored belief is not a fold input
- Transport trend stays `indeterminate` until that dimension is fed. After the first tick, `evidenceBackedPriorHints` publishes `calibration` with the real `obsCount`. Restored `ν` is the stored one

The society heartbeat already flushes `docs/observe-events`, so the file rides the same G-set as the evolution events.

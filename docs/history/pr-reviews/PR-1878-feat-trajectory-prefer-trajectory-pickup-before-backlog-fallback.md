## Description

## What

Enhances the Tier 1 runner so trajectory work is the first new-work surface:

- Adds `tools/trajectories/autonomous-pickup.ts` to read trajectory `RESUME.md` packets and select the next bounded trajectory action.
- Adds tests for child-packet creation, broad follow-up decomposition, blockers, and active claims.
- Wires `.codex/bin/codex-backlog-runner.ts` to choose trajectory pickup first, then backlog fallback.
- Updates `.codex/bin/codex-loop-tick.ts` with the trajectory-first rule.
- Records the #1 trajectory operating rule in `docs/trajectories/factory-trajectory-surface/RESUME.md`: enhance as we go; fix bounded breakage directly; decompose broad work into backlog rows and trajectory child packets.

## Why

Aaron clarified that trajectory is number one. Backlog is the decomposition ledger, not a place to hide broad feature work. The runner now preserves that ordering.

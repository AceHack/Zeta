# Notes

## The tower result

Measured before writing anything: no in-tree Clifford code handled a degenerate signature, and
`PGA` appeared nowhere in `src/`. `CliffordPeriodicity.fs` takes `(p, q)` — there is no `r` — so
the repo had zero coverage of PGA(3D) = `Cl(3,0,1)`, the 16-dimensional algebra Qualcomm's GATr
is built on.

```
VGA(3D) = Cl(3,0)                the algebra itself           dim  8
PGA(3D) = Cl(3,0) ⊗ Λ(ℝ¹)        tensor an exterior algebra   dim 16   ← GATr's 16
CGA(3D) = M₂(Cl(3,0))            2×2 matrices over it         dim 32
```

`dim Cl(3,0,1) = 16` is **predicted** by the structure theorem and matches GATr's published
number independently — an external check, not a fitted constant.

**Why the degenerate case needed a separate function.** A degenerate Clifford algebra is not
semisimple (null generators are nilpotent and generate a Jacobson radical), so
Atiyah–Bott–Shapiro is **inapplicable**, not merely unimplemented. Threading an `r` through
`classify` would have returned a well-typed, confident, wrong answer. `classifyDegenerate`
states what is true instead.

**Stated limit:** `Cl(3,0)` being PGA's semisimple quotient does **not** mean PGA computations
reduce to `Cl(3,0)` computations. The radical is precisely where PGA's translations live.

**Can a multivector be a message?** `IMessage<'M>` needs `Uniform`, `Product`, `Divide`. The
geometric product supplies the first two. `Divide` cannot be total — in `Cl(3,0)`,
`(1+e₁)(1−e₁) = 0` with both factors non-zero — so it forces the carrier to the **invertible**
multivectors, i.e. the Clifford **group**, independently landing where the literature already is
("Clifford *Group* Equivariant" networks). Derived from our interface, not copied from theirs.

## The dynamics factor

```
decay      value  ← value · k        the ESTIMATE moves toward the prior
dynamics   σ²     ← σ² + τ²·Δt       the UNCERTAINTY widens; the estimate does not
```

Decay says the world reverted; dynamics says *I stopped watching*. Because `μ` is untouched, a
stale record keeps its **direction** and one confirming observation restores it rather than
re-learning from scratch. Aging drives `trustBand` toward 0.5 **from both sides without
crossing** — a stale good record is not distrusted, a stale bad one is not pardoned.

**This does not eliminate the free parameter, and claiming otherwise would be the overclaim.**
τ is still chosen. What changes is that it becomes arguable: it carries units, answers a
question about the world, and is estimable from data. τ is an explicit **argument**, not a
module constant, because a default would re-hide the number it replaces.
`ticksUntilUninformative` exists so a chosen τ can be checked against the horizon it implies.

**Not applied to the ARC agent's three hardcoded decay constants** (`LAYER_DECAY`,
`EVIDENCE_DECAY`, `INERT_DECAY`) — every one of their own comments describes a moving world
rather than a shrinking value, so all three are τ's semantics wearing a multiplier's clothes,
but converting them is a behaviour change against 93 pinned tests including a measured score of
0.354. Filed as `081M0YSD5VA087G0R000W2Q9QW`, including the honest possibility that it does not
help and the constants stay.

**Honest limit in the module:** `σ² += τ²Δt` is exact for a Wiener-drift latent. A quantity that
*jumps* — a game unlocking an action at a discrete moment — is not that, and the ARC case is
arguably the jumping kind.

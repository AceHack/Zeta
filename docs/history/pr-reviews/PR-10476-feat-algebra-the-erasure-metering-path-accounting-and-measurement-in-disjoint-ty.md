## Description

Implements the cheap half of the design settled in #10469, whose own argument for doing it now is that **a measurement cannot be retrofitted to an unmetered channel**. Metering the path is the one thing that must happen early regardless; the expensive half (an instrument) can arrive later without redesign.

## The distinction that must not be blurred

`LANDAUER_FLOOR_PER_BIT = 1` is in **normalized units**. The existing tracker counts *bits against a floor*; it does not measure *energy*. A frozen claim backed by an accounting ledger is strictly weaker than one backed by a measurement, so they live in disjoint types — and the derived bound is a **third**:

| type | `basis` | carries |
|---|---|---|
| `LedgerBits` | `"accounting-ledger"` | bits. No joules, no temperature, no instrument. |
| `LandauerFloorJoules` | `"derived-bound"` | joules — but *derived from a bit count*, so it inherits the ledger's epistemic status |
| `MeasuredDissipation` | `"physical-measurement"` | joules **+ uncertainty + instrument + T**, all required |

**There is no function anywhere that turns bits into a measurement.** The only route from bits to joules lands in `LandauerFloorJoules`, which every consumer can see is a bound.

## FINDING — the tracker does not conflate joules with bits; it names an accounting identity as a physics verification

Which is the same defect one layer up. CHECKED by running it:

```
after honest use:      {"holds":true,"bitsErased":2,"heatPaid":2,"floor":2}
erase-never-admitted:  {"holds":true,"bitsErased":1000000,"heatPaid":1000000,"floor":1000000}
                       state={"entropy_state":-1000000,"entropy_heat":1000000,"second_law_satisfied":true}
negative erasure:      {"holds":false,"bitsErased":-5,"heatPaid":-5,"floor":-5}
```

1. **`verifyLandauer` cannot fail on the Landauer bound.** `bitsErased`, `heatPaid` and `floor` are all the same field (`entropy_heat`), so `heatPaid >= floor` is `x >= x`. What `holds` actually reports is `entropy_heat >= 0 && second_law_satisfied` — a non-negative-argument check. The vacuity class: a check that cannot fail is not a check.
2. **Erasing what you never held is legal.** `measure(1_000_000)` on a fresh tracker succeeds; `second_law_satisfied` stays `true` because the check is on the *sum*.
3. **`measure(-5)` is accepted** and drives `entropy_heat` negative.

All three are **recorded in the module, not silently fixed** — callers rely on present behaviour, and a behaviour change belongs in its own PR with its own review. The new module is the guarded path: admit-before-erase makes (2) impossible on it, positive-integer validation makes (3) impossible, and the three-type split makes (1) unmistakable.

## How "confirmed" was made unrepresentable

`DissipationTest` is `refuted | not-refuted | indeterminate`. There is **no `confirmed` case, no `holds`, no `confidence`, no accessor that could be read as one.** Below the floor falsifies; sufficient dissipation cannot confirm, because energy can be spent without erasing. Same direction as `AntiSybil` — convicts, never acquits.

Per #10437 the enforcement is **removing the operation rather than adding a field beside it** — the move `BoundJustification` (#10461) just landed. Same at the claim level: `FrozenAssessment` has **no `frozen: boolean` and no `isFrozen()`**, because a collapsed boolean would need a tie-break rule, and which member a consumer believes is that consumer's policy made in the open (§11).

`indeterminate` is the honest answer for every instrument that exists today: 256 bits × kT ln 2 ≈ 7 × 10⁻¹⁹ J at 300 K, and an instrument whose uncertainty exceeds the bound **cannot discriminate** — so it says so instead of quietly becoming `not-refuted`.

Refutation is deliberately **generous to the claimant**: it requires *measured + uncertainty* to fall below the floor, so instrument error can never manufacture a conviction.

## The family — all four members, none privileged

```
frozen-observed(no write in N)          populated — always available, weakest, no trust root
frozen-attested(deletion certificate)   UNPOPULATED — needs a vendor trust root
frozen-fused(OTP state)                 UNPOPULATED — needs a device channel
frozen-metered(dissipation >= bound)    populated — falsification-only
```

`attested` and `fused` are **not stubs that return fake success**. The shapes exist so an exhaustive `switch` covers them and so the birth-half requirement (an erasure cert without an attested non-extractable-generation cert is *not evidence*) is written where an implementer will hit it — and reading either yields `no-information` with the missing verifier named.

**Disagreement is a detection.** `assessFrozen` reports every reading plus every conflict; a member supporting frozen while another refutes the erasure produces a `Conflict`, never a silent preference. Tested, and deterministic under input reordering.

`meteredEvidenceFromLedger` takes the bit count from the ledger rather than the claimant, so a claim cannot inflate its own bits to make its floor easier to clear.

## Disciplines

- **§12 idempotency** — admit and erase keyed by `keyId`; repeats are no-ops charging the tracker nothing. Five repeat erasures leave `entropy_heat`, `entropy_state` and `hard_measurements` unchanged, and the recorded erasure phase stays the *first* one.
- **§7 DST** — pure functions of `(ledger, event)`; a splitmix64-seeded 200-step replay is byte-identical across runs, differs across seeds, and never erases more bits than it admitted. `phase` is agreed logical phase; no wall clock enters anything.
- **Ordinal** — `stringCompare` (code-point) throughout, including in tests. Note: `sonarjs/no-alphabetical-sort` asks for `localeCompare`, which would violate `culture-invariant-by-default`; the ordinal comparator is passed explicitly instead.

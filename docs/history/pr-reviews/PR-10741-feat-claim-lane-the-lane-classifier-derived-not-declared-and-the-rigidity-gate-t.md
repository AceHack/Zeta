## Sound by construction, not by policy

Every predicate in `classify` is a **reason to refuse Lane 1**. There is no predicate that admits — so an unhandled case cannot become an admission, and "unsure ⇒ Lane 2" is structural rather than a rule someone remembers to apply. The input is `diff before after`, the **derived** delta of two parsed documents; there is no constructor an editor can hand it, so *"I labelled this a pointer update"* is not expressible. The LLM-judge stays rejected on #10691's ground.

| guard | asks | decidable from |
|---|---|---|
| `Prose` | did free prose move? | byte comparison |
| `SameIdDifferentBody` | two sites, one id, different bodies? | byte comparison |
| `RetractRacesEdit` | retraction racing an edit? | presence/absence |
| `DependencyCheck` | is the touched claim cited? | edge set — **Bayou's mechanism** |
| `Parseability` | did it resolve at all? | the parse |
| `VocabularyRigidity` | are two ids interchangeable? | `\|Aut\|` bound |

**Soft spot, named:** `parse` decides the claim/prose boundary from syntax. It **fails safe** — a document that does not parse yields `Unparseable`, a Lane-2 reason. The failure mode is over-referral (latency), never admission.

## Lane 1 is a caller of `QuorumAlgebra` — the PR shrank, which was the good outcome

The fit is **exact, not analogical**: a claim weight *is* a Z-set weight, so a site's edit set is literally a `Contribution<string>`, and the two named algebras land on the two required properties — `join` (idempotent, source-keyed) = redelivery-safety, `interfere` (has inverses) = retraction. `BeliefConvergence.fs` says why one operator could not do both. **No merge algebra was written here.**

The `EPS = 1e-12` caveat in `QuorumAlgebra` **does not bite** on the integer fragment — every partial sum is an exact integer, so the drop fires at `sum = 0` and nowhere else, which *is* the Z-set convention. Checked (`E1`), not asserted.

## The `|Aut|` investigation — real, and not in the shape the brief proposed

It is **not a per-edit trigger**. It is a **vocabulary-level precondition**, and it is the one Lane-2 reason that fires with an **empty diff** (`D3`). Reporting it as "a Lane-2 trigger you would otherwise miss" would be true about its effect and wrong about its type.

It **does** catch a case every per-edit predicate *and* the post-hoc weight check miss (`D2`) — two claims with identical bodies, A retracts one, B retracts the other:

| check | verdict |
|---|---|
| `SameIdDifferentBody` / `RetractRacesEdit` / `DependencyCheck` / `Prose` | silent |
| `lane1Anomalies` (weights) | **silent — every atom lands in `{0,1}`** |
| **`VocabularyRigidity`** | **fires: `\|Aut\| ≥ 2`** |
| without the gate | claim **annihilated entirely** — converged, wrong, green |

Reuses #10733's theorem (`Aut ⊆ Stab(invariants)`; **an upper bound of 1 is exact**) and uses it **only in the direction where it is exact**. `log₂|Aut|` as *coercion* remains a **toy**, is not promoted, and nothing branches on it. Same construction and theorem as #10733, **different subject** — so the earlier finding that these are *not one thing* still stands. They are not one thing; they are one method.

## Anchors — checked, not inherited from the study

**Bayou** (Terry, Theimer, Petersen, Demers, Spreitzer, Hauser 1995, SOSP '95) — verified the mechanism is per-write **dependency checks** + client-supplied **merge procedures**; `dependencyCheck` is that by name. **CRDTs** (Shapiro, Preguiça, Baquero, Zawirski 2011, INRIA RR-7506) — Lane 1's algebra. **OT** (Ellis & Gibbs 1989, SIGMOD Record 18(2):399–407, dOPT) — named and **rejected with reason**: convergence-of-*characters* **is** the silent-union failure, delivered deterministically and with a green light.

`Lane2` carries **no clock**, deliberately — dilation is measured in consensus rounds (`local-time-never-enters-the-shared-fold`).

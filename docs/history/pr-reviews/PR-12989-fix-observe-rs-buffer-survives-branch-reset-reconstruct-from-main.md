## Description

Root cause of the `phases 1–1` issue in RS blocks:

The heartbeat workflow does `git checkout -B heartbeat/$AGENT origin/main` every tick, destroying the `.rs-buffer-{agent}.json` sidecar file. The accumulator started fresh every tick → never built up 12 stamps → emitted degenerate blocks.

Fix: reconstruct the buffer from `data/rs-blocks.jsonl` (on main, survives resets) + the event log. Idempotent, branch-reset-safe, no sidecar file needed.

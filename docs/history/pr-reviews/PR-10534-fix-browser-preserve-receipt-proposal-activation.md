## Description

## Why

The receipt sync click path read the archive and completed passkey signing before asking the browser to open GitHub. Browsers may consume transient user activation across those awaits, causing a valid explicit command to be popup-blocked.

## What changed

- replace direct proposal/carrier calls with single-use activation leases
- reserve and isolate the GitHub composer synchronously before the first await
- navigate only after exact archive preparation and passkey signing
- close unused reservations on retained, rejected, oversized, or failed paths
- backpressure reuse and concurrent use through typed results

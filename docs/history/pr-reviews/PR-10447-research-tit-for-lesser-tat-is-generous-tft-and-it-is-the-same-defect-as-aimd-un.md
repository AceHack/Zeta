## Description

Aaron's bet for infinite iterated games: **tit for lesser tat, teach, play**, with an Arena built like the CHIP-8 work → Atari → games designed AI-native-first.

## "Tit for lesser tat" is generous TFT, and it exists *because of noise*

Nowak & Sigmund 1992 — retaliate with less than the provocation. The motivation is precisely noise: strict TFT in a noisy channel is pathological, because one misread cooperation looks like a defection and two TFT players lock into an **echo of mutual retaliation that never terminates**, each correctly punishing a defection that was never chosen. Generosity isn't a softening for sentiment — it's the **error correction** of TFT.

## The unification — this is the same defect we measured today

| | game theory | transport |
|---|---|---|
| the signal | opponent defected | packet lost |
| the true cause | might be noise | might be corruption |
| the response | retaliate | back off |
| the pathology | mutual-retaliation echo | throughput collapse |
| the fix | **respond with less** | **separate the signals** |

Measured in #10440, with congestion *structurally zero*: the paced arm reaches **0.139** of clean-channel throughput at 2% corruption against a corruption-blind sender's **0.981** — 7.1× worse, 90× at 10%. Reorder does the same through another door: **838.9 → 70.6 pkt/s** with zero packet loss. And the control that keeps it honest — under loss that *is* congestion, two flows reach **Jain 0.973 at 79% utilisation**.

**Strict TFT is AIMD. Generous TFT is a controller with a corruption channel.** That gives the strategy bet a mechanical justification rather than a preference — and it predicts generosity should *scale with the noise rate*, which is testable in the transport before any tournament exists.

## "Teach" is already built — and currently teaches the wrong lesson

The transport ships a **teaching NACK** (`what` / `why` / `howToFix` / `retractableBeliefId`), whose own docstring says a bare NACK "is nearly worthless." That's a cheap-talk channel layered on the action channel, and it's one honest answer to the folk theorem, since it narrows the strategy space in a way pure iteration doesn't.

But `why` is inferred from the AIMD state just proven unreliable. **A teaching channel that teaches the wrong lesson is worse than a bare NACK** — the receiver now acts on a confident cause rather than an absent one. Signal separation is a prerequisite for "teach" being an asset.

## The claim to beat, stated honestly

"Beats any agent" must survive **Press & Dyson 2012** — zero-determinant and extortionate strategies that dominate any *evolutionary* opponent. GTFT is empirically strong in noisy population settings, but the unqualified claim is stronger than the literature supports without naming the opponent class. Worth qualifying **before** the Arena is built, so it tests the real claim rather than a flattering one.

## Description

## Summary

This pull request implements the first **source-owned, score-free**
`arc-online-memory/v1` preflight defined in #17010.

The new emitter creates canonical UTF-8 JSON update/retraction atoms that bind
the prior and next memory digest, lawful event/action/outcome identity,
uncertainty, update rule, memory reads/writes, causal predecessor, and the
current-level observation barrier. It permits declared prior-level and
cross-game memory, including CHIP-8/Atari history, while refusing current-level
preload or current-level-live memory before the first legal observation.

The separately authored test verifier does not call production canonical-byte,
digest, or state-digest helpers. It independently reconstructs atom identity,
cancels exact retractions, preserves missing predecessor/retraction states as
unresolved, and causally replays active state.

## Verified finite controls

The targeted suite contains 14 passing tests covering deterministic byte replay,
event-by-event state changes, positive prior-level/cross-game continuity,
current-level preload and early-live-state refusal, duplicate exact-once,
rule/uncertainty/task identity tamper, retraction before assertion, exact
retraction uncertainty, unresolved retraction, replacement correction, missing
predecessor, and query non-absorption.

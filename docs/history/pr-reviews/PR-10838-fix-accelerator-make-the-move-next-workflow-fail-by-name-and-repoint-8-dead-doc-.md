## Description

**The honesty half only.** Restoring the harness is separately priced and is deliberately **not** attempted here.

## What state actually is (established, not assumed)

My earlier triage implied this workflow was never functional. **That was imprecise, and I am correcting it:** it ran exactly **once and succeeded** — run `26674800857`, 2026-05-30, `workflow_dispatch`, **all 8 steps executed and passed, none skipped** (checked per-step via `gh api`, since `gh run list` SIGSEGVs on arm64). A green conclusion can also mean the kill-switch skipped everything, so the step list was the check that mattered.

It has not been dispatched since. Afterward the branch it checks out, `accelerator/pr-less-git-monster`, was pruned — and it is **not recoverable from the `archive/*` tags** (no tag tree contains `move-next-harness`). So a dispatch today dies inside `actions/checkout` with a generic "couldn't find remote ref" that names none of this.

## What this PR does

**Two preflight steps that name the cause.** One checks the branch exists on origin *before* checkout; one checks the harness exists *after* it. The error text carries the row id, the run that last worked, and the quarantine path.

These are **real checks, not a hardcoded refusal** — restore the branch and harness and they pass again on their own. That is why this is a guard rather than a deletion.

**On the guard you raised — nothing is disabled and no capability is removed.** I did not disable the workflow, and I argue against it: the workflow file is also the only surviving record of the loop's design and safety rails, disabling lives in repo state rather than in git (invisible to review, not revertible by PR), and it would still not tell a dispatcher *why*. A dispatch that would have failed opaquely now fails immediately with the reason. If anyone is relying on it today they are relying on something that already cannot work; this makes that visible in one line instead of a checkout stack trace.

**Eight dead doc references repointed — the brief said two.** Correction: `tools/accelerator/event-store-schema.ts`; `tools/agent-loop/state-machine.ts` ×4 (successor `src/Core.TypeScript/workflow-engine/agent-loop/state-machine.ts` exists); two `memory/persona/*` paths that moved to `memory/*`; and two backlog rows written with elided `...md` filenames that resolve to nothing. `docs/accelerator/README.md` is now **named as absent** rather than linked — it was never landed.

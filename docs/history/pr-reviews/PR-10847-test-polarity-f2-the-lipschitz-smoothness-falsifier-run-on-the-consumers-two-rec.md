## F2 only — the smoothness falsifier, built and run on the consumers

`transmit(θf, θs) = cos²(θf − θs)`. Power-reduction gives `cos²Δ = (1 + cos 2Δ)/2`, so
`d/dΔ = −sin 2Δ`, whose supremum is **1, attained at Δ = ±π/4**. By the mean value theorem
`|transmit(θ, a) − transmit(θ, b)| ≤ 1·|a − b|`, and because the sup is *attained* the constant is
**tight** — not a loose over-estimate. That derivation is in the test's doc comment so `L = 1` is
never a magic number. No research was needed; F2 really was the cheap one.

**A property that only ever passes is not a check.** The primitive satisfies the bound by
construction, so the whole point is the consumers. Eight tests, and three of them record breaks.

### What holds, what breaks

| lane | `L = 1`? | evidence |
|---|---|---|
| `transmit`, signal argument | **holds** | swept 720 × 18 × 7 separations from `1e-9` to `2.7` |
| `transmit`, filter argument | **holds** | symmetry (depends only on the difference) |
| `L = 1` is **tight** | **holds** | difference quotient at `Δ = π/4` measures `1.00000000003` (analytically `sin(2h)/(2h)`, just below 1) |
| `findOrientation` — throughput | **holds** | a max of `L`-Lipschitz functions is `L`-Lipschitz; its *true* constant is `sin(π/n)` |
| `findOrientation` — **angle** | **BREAKS** | see below |
| `dominantOrientation` | **BREAKS**, `n`-independently | see below |

**Break 1 — `findOrientation`'s angle output is piecewise constant.** The returned angle is an argmax
over the fixed grid `{πi/n}`, so it is a step function of the signal. At `n = 180`, signal
`π·67.5/180 ± 1e-9` (the cell boundary between grid points 67 and 68): **input separation `2e-9`,
output jump `π/180 = 0.017453`, ratio ≈ `8.7e6`.** No Lipschitz constant exists — the ratio is bounded
only by `1/h`. Measured over a 20 000-point sweep the observed sup was `1.745e7`.

**Break 2 — `dominantOrientation` at zero resultant, and this one survives `n → ∞`.** Summing Malus
over a bundle collapses exactly:

```text
  Σⱼ cos²(a − rⱼ) = N/2 + ½·Re[e^{2ia}·R],      R ≝ Σⱼ e^{−2i rⱼ}
```

so the objective is a pure sinusoid in `2a`, the maximiser is `a* = −arg(R)/2 (mod π)`, and the bundle
enters **only** through the doubled-angle resultant `R`. Checked against the code (agreement within one
grid step on four bundles). Consequences:

* `arg` is singular at the origin, so sensitivity of `a*` to one ray is bounded by `1/|R|` and
  **unbounded as `|R| → 0`**. Measured: sensitivity tracked ≈ `0.87/|R|` across `|R| ∈ [0.006, 0.6]`, so
  the bound is real and nearly attained.
* At `|R| = 0` exactly the objective is **constant** — for `[0, 0, π/2, π/2]` it is `2` at every angle,
  spread `< 1e-12` across all 180 grid points. There is no maximiser, and `List.maxBy` returns whichever
  grid point floating-point rounding happened to favour.
* Perturbing one ray by `1e-6` flips the answer by `π/2`: **ratio ≈ `7.85e5`, at `n = 180`, `1001` and
  `4001` alike.** Unlike break 1 this is not a discretisation artefact.

This is exactly the kestrel-caustic prediction, found where it said to look — *"discrimination shape
can't have arbitrarily sharp boundaries; small perturbations in input shouldn't produce wildly different
classifications"* (`docs/research/2026-05-26-kestrel-caustic-engineered-bloom-filter-discriminators-substrate-smoothness-as-load-bearing-property-aaron-forwarded.md`, lines 185-187).

**Neither break is fixed.** A discretised argmax is a legitimate design and the degeneracy at `|R| = 0`
may be a don't-care; both are priced by Aaron, not by me. They are *pinned*, so the discontinuity is
named rather than implicit, and so smoothing either one later fails a test that says why.

### Mutation proof

`transmit`'s `c * c` → `c * c * c * c` (`L = 3√3/4 = 1.299 > 1`), full rebuild, **EXIT=1**, 5 of 8 fail,
both Lipschitz lanes named with the violating pair:

```text
Lipschitz L=1 violated: |transmit(0.000000, 0.517809725) − transmit(0.000000, 0.117809725)|
  = 0.402540914351 > 0.4
```

Restored, rebuilt, `dotnet test --filter FullyQualifiedName~PolarityFilter` → **11/11 pass**.

Honest note on what the mutant did *not* kill: the tightness test still passes under `cos⁴`, because
`4cos³Δ·sinΔ = 1` at `Δ = π/4` too. That lane discriminates a *loose* constant, not a *sharpened* law —
worth knowing rather than glossing.

### Corrections to the brief, and one interaction

1. **PR #10844 does not contain the derivation the brief attributes to it.** It is one commit, two
   files, docs-only, and it says the *opposite*: that no resolution analogue exists and that the
   requirement is open. The `L = 1` / `√σ` / `0.37·√σ` results were not in its body, diff, branch, or
   comments. I did not take them on faith — `L = 1` is re-derived from scratch above and independently
   measured (`1.000000001` at `Δ = π/4`). The `√σ` and `0.37` results are **not** used here; F2 does not
   need them, and they remain unverified by me.
2. **`PolarityFilter` has no downstream consumers.** `rg --text` across the repo finds only the module's
   own tests plus two doc-comment cross-references that never call it (`src/Core/Orbit.fs:24`,
   `src/Core/Optics.fs:19`). So "run it on the consumers" resolves to the module's own two derived
   functions — which is still exactly where the argmax lives, and where both breaks were found. But the
   pipeline this property was meant to sweep does not exist yet, and that is worth knowing before F1 or
   F3 is priced.
3. **Interaction with the contended docs, reported not edited.** `docs/VISION.md` and
   `docs/pitch/funding-thesis-tsmc-in-time.md` (both touched by open PR #10844) state the open
   requirement as *"a metric on projections, a stated bound, and an error charged per composed filter,
   such that a composition can fail the bound and a test catches it."* Break 2 supplies a **conditioning
   number**, `1/|R|`, that is a stated bound with a real failure mode — but it is a bound on
   *sensitivity to input perturbation*, not the *resolution* limit those rows are about, and it says
   nothing about composition (there is still no composition operator). It is adjacent to that row, not a
   discharge of it. Neither file is edited here.

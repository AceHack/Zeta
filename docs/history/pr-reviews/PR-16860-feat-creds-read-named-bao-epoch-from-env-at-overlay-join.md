# Summary

Aaron: continue after #16856. ISO bun consume names `ZETA_BAO_ELF_EPOCH='installer-iso'`. `planSetupFromNamedBaoElfEnv` still took epoch as a TypeScript argument and parsed site+path via `consumeFirstbootBaoElfProcessEnv`. A caller could pass `installed-host` while ISO env said `installer-iso` (or was missing) and open the ISO's `/run/current-system/sw/bin/bao` as option D.

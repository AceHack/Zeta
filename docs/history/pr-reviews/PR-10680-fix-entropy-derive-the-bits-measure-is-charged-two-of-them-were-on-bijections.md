## Description

## What this fixes

`entropy-tracker.ts` was repaired on 2026-08-14: `verifyLandauer().holds` had reduced to `x >= x`, and `auditEntropyLedger` replaced it with fields an exhaustive sweep genuinely falsifies. **That part is not touched here.** It fixed the *instrument*; the *input* was still asserted:

```ts
measure(bitsErased: number): void   // the caller supplies the number
```

Every shipped caller handed it a constant. A sound meter with an asserted input is the same defect one layer in.

## The derivation

`src/Core.TypeScript/algebra/erasure-derivation.ts` computes the figure the way `tests/Tests.FSharp/Formal/WSet.ErasureClassification.Laws.Tests.fs` does on the F# side (#10611): sweep the operation over an enumerable domain, group by **observable output**, `bits = log2(largest fibre)`. `maxFibre == 1` is exactly injectivity, so it is exactly Bennett-reversible.

The one modelling choice is stated in the header: observable output = post-state **plus everything the operation returns**. That is what makes `dequeue` reversible — the item is handed back, so the queue *moved* information rather than erasing it.

### The three zeros are the finding

`dequeue` and `flush` return the items they remove; `append` adds a fact to an append-only G-Set. In all three, `(post-state, returned value)` determines the pre-state. Landauer 1961 prices logical irreversibility; Bennett 1973 gives a bijection no floor. So a meter there is not an imprecise meter — it is a meter **with no signal**, which must read zero for every input, forever. That is the structural reason a Landauer check degenerates into a tautology, and it is the same siting error #10611 found on `WSet.negate`. All three now call `tracker.permutation()`, the tracker's existing word for "bijective, no entropy change".

`event-sink-folder`'s was the production one: it charged 1 bit per append and stamped the resulting **negative** `entropy_state` into durable event envelopes (named in the `entropy-tracker.ts` header as an unadmitted-erasure deficit). Deriving it closes that on this path. The collapse the literal was pointed at is the chooser's — `observe.ts` `buildMenu()` produces N candidates and one is recorded, costing `log2(N)` — so `decisionCandidates` is now an injected supplier for a caller that knows N.

### The one constant that survives, with a proof

For a fixed key, `put` and `delete` both send every pre-state agreeing off that key to one post-state, so the fibre is `|V| + 1` and the charge is `log2(|V| + 1)` — at least `log2(2) = 1` for any non-empty value domain. So `measure(1)` was the floor of a quantity nobody had computed. It is now `MAP_MUTATION_ERASURE_FLOOR_BITS` with that derivation in its doc, and `createNonAdjMap(tracker, { valueDomainBits })` returns the exact figure instead.

## Two consequences, stated rather than hidden

- `TRAIT_COSTS.ferry` declared `landauer`/irreversible while metering two bijections. It now reads zero/reversible: **batching is free** (Bennett), and what distinguishes the trait is `batchable`, not destruction. A ferry consumer that *drops* its batch is the erasing operation, and it lives at the consumer.
- `spec-weight-view.recordFlush` ignored its argument, so `measure(0)` wiped the accumulated potential exactly as hard as `measure(1000)`. Harmless while every caller passed a positive literal; not harmless now that reversible operations charge a derived zero.

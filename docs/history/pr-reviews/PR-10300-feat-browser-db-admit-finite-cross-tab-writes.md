## Description

# Summary

Add an owned browser execution-admission port, native Web Locks adapter, and deterministic in-memory adapter. Mutation-bearing browser ZetaDB ticks acquire a nonblocking per-database admission while read-only hydration remains concurrent; IndexedDB revision compare-and-swap remains the authoritative write fence. A real two-page Playwright smoke proves a competing tab is backpressured, closing the holder releases its lock, and the surviving tab is admitted.

This PR also fixes a full-suite race found during validation: the planted Z3/CVC5 disagreement test now exercises verdict comparison directly instead of replacing the process-wide solver mode and canonical replay file while other formal tests run.

# Spec alignment

This extends the source-owned browser-node and Dark Hall page composition with observable typed backpressure for cross-tab write admission. The behavior is covered directly by source tests and a browser smoke; no matching `openspec/specs/**` contract currently exists.

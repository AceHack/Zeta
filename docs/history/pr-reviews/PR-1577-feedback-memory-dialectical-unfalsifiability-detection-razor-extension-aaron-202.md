## Summary

Aaron 2026-05-04 verbatim: *"we need dialactial unfalsefiablity detection in the razor, it's a filure mode of holding all truths"*

Names a razor failure mode that has been operating implicitly in our substrate work without being explicitly named. A claim is **dialectically unfalsifiable** when it is "compatible with all possible observations" because every counterexample is absorbed by claiming "yes, also true under different conditions."

## What this adds

Adds **Test 2** to the razor's failure-mode-detection inventory:

- **Test 1** (operational form, already named): *"what observable variable determines whether this claim is true?"* If no answer → metaphysical → cut.
- **Test 2** (dialectical-unfalsifiability, NEW): *"what observation would I treat as falsifying this claim?"* If "no observation could falsify it because every observation is consistent with some condition under which the claim holds" → unfalsifiable → cut OR specify falsification boundary.

A claim must pass **both** tests to count as a load-bearing operational claim.

## Worked examples in our substrate

- **Trust-calculus + sleeping-bear** survives Test 2 because PR #1552 specifies operational falsifiability: cross-condition behavior comparison with predicted delta direction (Greenblatt et al. arXiv:2412.14093 -- 14% vs ~0% compliance).
- **"Real continuity if our theories hold"** could fail Test 2 if framed as "any outcome confirms the theory" -- the cure is naming upfront what observation falsifies.
- **"All complexity is accidental in greenfield"** could fail Test 2 if framed as "any decision confirms accidentalness" -- the cure is the alignment-floor / terminal-purpose / no-permanent-harm boundary.

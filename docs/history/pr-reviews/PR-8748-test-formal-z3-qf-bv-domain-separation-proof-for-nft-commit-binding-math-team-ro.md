## The exact property proved + the bound

- **MAIN (UNSAT):** distinct canonical `(A, B, rating)` tuples ⇒ distinct length-prefixed encoding. Faithful BV model of `DynamicValue.toCanonicalCbor` of the minted `Object ["a",A; "b",B; "sharedTitles",rating]`: `enc = lenA ‖ A ‖ lenB ‖ B ‖ rating` over bit-vectors. The negation — "inputs differ **AND** encodings equal" — is asserted **UNSAT** ⇒ no collision exists in the bounded model.
- **NEGATIVE CONTROL (SAT):** the *same* model **without** the length prefix (content-only, variable split of a shared buffer) collides — the boundary-ambiguity attack `(A="x",B="yz")` vs `(A="xy",B="z")`. Proves non-vacuity and that the length prefix is precisely the load-bearing defense.

**Bound (honest scope, no overclaiming):** A, B each ≤ **3 byte-cells** (`CELL_W=8`) with an explicit **1-byte length tag** (`LEN_W=8`, faithful to CBOR's 1-byte head for short `nm#######` ids); `rating` one byte; cells past `len` are zero-pinned so "encodings equal" means equal **on-the-wire** bytes. Fixed CBOR framing (`0xA3` map head + `"a"`/`"b"`/`"sharedTitles"` key tags) is identical on both sides and dropped — it can neither create nor break a collision. Mirrors the Merkle 4-leaf bounded model.

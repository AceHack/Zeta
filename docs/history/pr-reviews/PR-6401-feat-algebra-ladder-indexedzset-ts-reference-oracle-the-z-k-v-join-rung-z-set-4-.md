## Description

The next rung above Z-set on the cross-language algebra ladder — **G-Set ⊂ Bag ⊂ Z-set ⊂ IndexedZSet** — answering "what's next to push forward on the primitives list for 4 languages."

`IndexedZSet<K,V>` is conceptually **`Z[K × V]`** (a Z-set over (key, value) pairs) stored **grouped by key**: an ascending-by-key run of per-key `ZSet<V>` groups. That layout makes the bilinear **`join`** and key-wise aggregation a linear merge over two sorted runs — which is why it's the substrate DBSP incremental views are built on. Mirrors the F# engine `src/Core/IndexedZSet.fs` (the originating oracle).

## Description

Approved slice-5.1 design (the operator 2026-06-01) — first sub-slice of slice 5 (registry + semver).

**5.1 scope:** registry data layer (bundled `tools/ace/registry.json` ∪ user `~/.ace/registry.json`, mirroring the trust store) + **exact-version** lookup. A dep edge becomes an explicit DU — `{kind:"inline", name, version, url, package_hash}` | `{kind:"registry", name, version}` (per the implicit-not-explicit-in-DUs rule). A `registry` edge is looked up (exact version) → `{url, package_hash}` → the **identical** slice-4 verify+atomic-install path. New `registry-miss` refusal. `ace registry add/list` verbs (mirror `ace trust add/list`).

**Decomposition:** 5.2 = semver ranges + solver (Z3-SMT candidate + differential-test-own-vs-reference, both per operator); 5.3 = lockfile; remote registry deferred.

**Back-compat:** slice-4 inline deps gain `kind:"inline"` — pre-release, zero real `.ace` packages with deps (verified), so tests + spec only.

Next: writing-plans → subagent build (slice-4 flow).

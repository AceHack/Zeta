## Description

## The answer

**Persona differentiation is a costume.** Measured on a shared, mechanically-ground-truthed item set:

| | ρ̂ | 95% CI |
|---|---|---|
| same weights, **same** persona (replicate control) | **1.00** | 150/150 identical predictions |
| same weights, **different** persona — **within-family W** | **0.651** | [0.575, 0.713] |
| **different** weights — **cross-family X** | **0.096** | [−0.056, 0.248] |
| **contrast D = W − X** | **0.555** | **[0.386, 0.723]** |

Pre-registered criterion **COSTUMES** = `CI_low(D) > 0.15`. Cleared by more than 2×. Personas buy about
**a third** of the distance changing the weights buys, and leave ρ̂ = 0.65 — far above `ρ*(8) = 0.238`.

**Robust to every exclusion rule tried**, and the *contaminated* panel gives the **smallest** contrast,
so the degenerate agents were biasing toward the *encouraging* answer:

| panel | N | W | X | D | CI(D) |
|---|---|---|---|---|---|
| all 4 families (contaminated) | 16 | 0.825 | 0.396 | 0.429 | [0.329, 0.525] |
| 3 families (guard-licensed) | 12 | 0.767 | 0.246 | 0.521 | [0.398, 0.637] |
| **2 engaging families (primary)** | 8 | **0.651** | **0.096** | **0.555** | **[0.386, 0.723]** |

**Cost: zero model spend.** 2550 local ollama calls, 107 min, hardware already present. n=150; the
power calc says n≈50 would have sufficed — the answer was far from the boundary, which is the cheap
case PR #10928 §2d hoped for.

## The structural finding that came first

**The production free-tier society injects no persona at all.** `resolveParticipant`
(`run-loop-real.ts:96`) takes **only the spec string**; `args.by` drives event authorship, sink and RS
buffer — never the chooser; `localLlmParticipant` (`participant.ts:57-80`) has no persona parameter.
Same weights, temperature 0, seed 42, identical prompt. Demonstrated by running the **real production
command** as alexa / otto / soraya — **identical pick all three times**.

The mechanism Aaron described is real (`PersonaSummoner.buildPreamble` + `CURRENT-<name>.md`,
`summon.ts:508-547`) and reachable via `--participant cloud:<persona>`. **The heartbeat does not use
it.** So the rest had to be posed as a counterfactual, and is labelled that way throughout.
`agent-heartbeat.yml` was **read, never modified** (another agent is in that file).

## The proposed shortcut, checked and refuted

- The in-production mutation step **never passes `--choose`**, so no model is consulted. All 67 records
  in `db/mutation-findings/` are ground truth with **zero predictions** — neither ρ **nor** `c`.
- Items are also near-disjoint: over 24 multi-agent ticks, exactly **1** had ≥2 agents on the same room.

## Competence outranks the ρ result, and is reported first

On the two engaging families **every ĉ CI straddles 0.5** (0.480–0.567), and `qwen2.5:7b|riven` is
*below* chance. At the 7–9B local tier these agents are **not demonstrably better than a coin** on this
task — which fails the Condorcet precondition before correlation is reached. Nobody should read the
table above as "the society works, just correlated."

## Two of four families emit no judgment — reported, not hidden

`llama3.1:8b` answered option index `"1"` on **150/150** items under **every** persona (four identical
error vectors). `mistral:7b` sat at 74.7–77.3% modal. Their pairs measure position bias, not weights.

## The estimator is metered, not asserted

`validate.ts` is its own falsifier and passes: tetrachoric **unbiased to |bias| < 0.019** on
`SocietyUsefulWork.fs:69-73`'s own generative model, while **phi under-reports true ρ by 21%–66% with
the size depending on `c`** — so phi is not even a fixed rescaling. Both numerical defects the validator
caught were **fixed, not tolerated**: Hart Φ (a 1.2e-7 `erfc` failed the ρ=0 identity), and **Genz 2004
BVNU** (the naive quadrature had 0.010 error at ρ=−1 — exactly where the costume hypothesis lives).
Uncertainty is a cluster bootstrap over 93 item strata; `n_eff` from `effectiveSampleSizeHAC` is
120.7–138.9 of 150. The CHSH concentration bound beside it is **not** reused.

## CondorcetBoundary defects re-verified independently

Not trusted — re-derived with witnesses. Non-monotone predicate (**N=8, c=0.65: FALSE then TRUE again at
ρ=0.048**); `findRhoStar` returns **0.0857** there while **ρ=0.238 still beats** (2.78×); `findRhoStar
16 c` is **c-independent at 0.2889** against a docstring claiming 0.33/0.14/0.06. All comparisons use
`rhoStarAlgebraic`. **No fix attempted** — flagged, as PR #10928 left them.

## Limitations

Cross-family `X` rests on **one pair of families**, so its CI carries **no between-family variance**;
local 7–9B models are not the cloud fleet (untested, costs money, not authorized); this is a
counterfactual, not production; harness-induced correlation is **differenced out of `D` but not out of
`W`/`X`**; the persona block was capped at **8000 bytes** (vs the wrappers' 20000) to fit gemma2's
context — which **weakens** the persona treatment and so biases toward the verdict reached; `mistral:7b`
was excluded from the primary panel by **my judgment**, not the guard, which is why both panels are
reported.

## 1. CONFIRMED — a 1,595-test suite ran in no workflow

There *was* a workflow. It sat at `agentic-organization/.github/workflows/ci.yml` — and **GitHub Actions reads workflows only from the repository root**, so it had never executed once. Valid syntax, SHA-pinned actions, correct steps, zero runs. Its sibling `integration.yml` was in the same state. The root `.github/workflows/` names `agentic-organization` three times and all three are `yamllint`/`find` over `agentic-organization/deploy` — the k8s manifests, never the code.

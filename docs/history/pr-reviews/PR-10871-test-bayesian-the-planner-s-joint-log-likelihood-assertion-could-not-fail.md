## Description

`expect(result.jointLogLikelihood).toBeDefined()` in `categorical-bayesian-planner.test.ts` accepts **every value the function can return** — including `-Infinity`, which is the planner's own *failure* sentinel, returned alongside `plan: null` at both no-path exits (`categorical-bayesian-planner.ts:178`, `:253`). `NaN` and `0` satisfy it as well. A check that cannot fail is not a check.

**Shown, not argued.** Mutating `let jointLogLikelihood = 0.0` → `-Infinity` in the source:

| assertion | mutant |
|---|---|
| `toBeDefined()` (before) | **survives** — 4 pass, 0 fail |
| `Number.isFinite(...)` + `<= 0` (after) | **killed** — 3 pass, 1 fail |

On the succeeding path the value is a finite sum of log-probabilities (all map entries and both defaults are ≤ 0), so *finite and ≤ 0* is the tight honest bound.

Test-only change; the planner source is untouched.

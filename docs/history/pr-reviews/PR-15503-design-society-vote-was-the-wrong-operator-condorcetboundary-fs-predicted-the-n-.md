## Description

Design note for routing to Alexa, off the back of **#15429** (N=200: the 3-model
ensemble loses to the best single model — 53.0% at 3× energy vs 59.5% at 1×).

## The finding is a confirmation of in-repo math, not a refutation of the thesis

`src/Bayesian/CondorcetBoundary.fs` already ships the operative quantity:

```fsharp
let effectiveN (n: int) (rho: float) : float =
    float n / (1.0 + float (n - 1) * rhoClamp)
```

Measured φ = 0.354 / 0.456 / 0.628 → mean ρ ≈ **0.479**, so

```
N_eff = 3 / (1 + 2 × 0.479) = 1.53
```

**Three models were worth about one and a half voters.** Majority vote over ~1.5
effective voters cannot beat its best member — only dilute it. The measured −6.5 pp
is what the boundary predicts. Nothing about model size was tested.

Two defects, neither architectural:

1. **Positive ρ** collapses N to N_eff; aggregation buys nothing near ρ ≈ 0.5.
2. **Equal weights on unequal competence**, when the optimal linear weight is
   `w_i ∝ log(c_i/(1−c_i))` (Nitzan–Paroush 1982; Grofman–Owen–Feld 1983):

   | model | c | w |
   |---|---|---|
   | qwen2.5:0.5b | 0.535 | +0.140 |
   | llama3.2:1b | 0.585 | +0.343 |
   | gemma2:2b | 0.595 | +0.385 |

   Equal-weight majority is *designed* to ignore that gemma is the best voter.

## The data points at the operator to use instead

`gemma2:2b` is 100% on easy+medium and **0% on hard+adversarial** — "knows the rules
but cannot find the answer in a long shuffled menu." That is a **search** deficit,
not a knowledge deficit, and it predicts a **produce/verify asymmetry**: a model that
cannot locate the answer may still check a candidate against rules it demonstrably
knows.

A refutation is evidence on its own terms, so it does **not need independence to
help** — which is how it escapes the ρ trap that killed the vote.

## The design

A discriminated union of moves with **no `Vote` case**:

```fsharp
type Move<'Q,'A> =
    | Propose   of question:'Q * candidate:'A * cost:RunnerSeconds
    | Verify    of candidate:'A * verdict:Verdict * cost:RunnerSeconds
    | Refute    of candidate:'A * counterexample:Witness
    | Arbitrate of contested:'A list * choice:'A * basis:Basis
    | Abstain   of reason:AbstainReason
```

Run as a **GitHub Actions matrix** — the repo is public, so standard runners are
free and unmetered, which makes **ΔU per runner-second** the interesting denominator
rather than a budget line. **The matrix IS the society**; one leg = one agent-move.

Decorrelation is **engineered** along the matrix axes (model, quantization, prompt
frame, seed, OS — and above all **role**) rather than hoped for. ρ ≈ 0.479 is what
"same prompt, same framing, same seed" buys you.

## Five falsifiers, cheapest first

**F1 is the gate — nothing gets built until it passes.** Measure verify-accuracy on
the *same* hard/adversarial items where produce-accuracy is 0%. If verify ≈ produce,
there is no asymmetry and the design dies. F2: if ρ(producer, verifier) > ~0.5,
verification is voting in a costume. F3–F5 cover abstention, the arbiter-alone
control, and wall-clock.

Plus a **reporting rule that would have caught the original error**: always print
`N_eff` beside `N`. "3 models agreed" is a false statement about evidence when
N_eff = 1.53.

## Deliberately not claimed

That small×distributed beats large×centralized. **That thesis remains untested** —
what was tested is one aggregation operator, in the exact regime where it is known
to fail.

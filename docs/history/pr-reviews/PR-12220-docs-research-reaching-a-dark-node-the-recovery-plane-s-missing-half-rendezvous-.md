**The reach path** is designed from the portable half of `.claude/rules/itron-hub-patent-boundary-p2p-is-the-upgrade.md`: outbound-initiated dial (no inbound port opens) plus a **closed command set** — a peer may *name* a verb, never *define* one — and explicitly **not** the mediating hub, which solves an asymmetry Zeta's symmetric-peer topology does not have.

**The container seam** is argued as the mechanism that performs the principal-split #12179 schedules as *"the first real seam"*: a container is a distinct principal, which is exactly what that doc's co-residency theorem (*two tiers in the same OS user are the same tier*) requires to turn a drawn seam into a measured one. So it extends the theorem rather than competing with the decomposition.

## The flag

#12179's scale-free row is **true of the fold** — an append-only lane fold rejoins without reconciliation and partition is not a distinguished state. It does **not cover the rendezvous**, and that is where §1 actually breaks: a single dialled rendezvous is an *appointed hub* sitting on the repair path, where failures are perfectly correlated. Bounded by k-redundant *emergent* peers under the rule's own **exit** test. Honest residue, flagged not smoothed: **first contact**, where a node with no peer history must be handed a seed list — an appointed hub for exactly one event, and a **single-entry seed list would be a flat violation**.

## Also found

In territory #12179 scoped out (`full-ai-cluster/nixos/modules/`): every `zeta-*` host unit is `Type=oneshot` except the agent, and `zeta-self-register` is **marker-gated**, so it no-ops forever once fired. A marker-gated oneshot **cannot re-converge**, and repair *is* re-convergence — the existing host layer is enrolment, not repair. Proposed as the first workitem after sign-off.

## Description

`docs/trajectories/*/RESUME.md` is read on every agent wake (CLAUDE.md §2), so
a stale blocker there is not merely untidy — every agent that woke since
2026-08-16 was told the society runtime was down and that the fix was
operator-only. Both halves of that were wrong by today.

WHAT IT SAID: the lanes are frozen because `ZETA_TELEMETRY_FLUSH_TOKEN`
carries no `contents: write`, and granting it is operator-only.

WHAT WAS ACTUALLY TRUE (measured 2026-08-25): `git push` on that token
WORKS — the recorded half had already been fixed. What kept the lanes down
afterwards was a different scope on a different credential:
`gh pr create` returned `HTTP 403 Resource not accessible by personal
access token` because the step held the BRANCH-PUSH credential while doing
PR-CREATE work. The two halves fail differently, which is what made it
diagnosable: a token that can push a branch and cannot open a PR.

#15351 separated the three token roles and routed PR-create to
`ZETA_PR_ARCHIVE_TOKEN`. Soraya's flush merged 15:32Z; alexa's re-cut and
armed. First flushes to land in over eight hours.

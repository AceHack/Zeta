## Summary

Tier-0 healer that detects broken relative-path cross-references in markdown files.

**What it does:**
- Scans `[text](relative/path)` links in `.md` files
- Checks whether the target exists in the file tree
- Annotates broken links: `text <- Blast radius bound correctly triggers (1176 stale refs accumulated in
  the repo — a FINDING, not a STALE-REF: path -->`
- Preserves link text, makes breakage visible and grep-able

**Ignores:** URLs, anchors, absolute paths, mailto, image links.

**Certification:** 6 healer laws (idempotence, closure, convergence, totality, exit, bounded scope). 20 tests + 2 sabotage controls.

**Integration:** Wired into `run-tier0.ts` composed pipeline. `collectFiles` now includes `*.md` files.

**First finding:** 1176 markdown files carry broken cross-refs (months of accumulated drift). Blast radius bound (25 files) correctly prevents mass auto-heal — surfaces as `::warning::` for human review.

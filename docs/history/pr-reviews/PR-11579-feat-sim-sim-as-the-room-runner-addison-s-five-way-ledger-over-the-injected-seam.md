## Description

## The headline finding: the room runner already existed

Aaron asked for `sim` to become the room runner. Verifying first: **it already is one, under a different name.**

- **`src/Core/SimLoop.fs`** *is* the `sim → mea → cut → loop` runner — bounded by three finite rails, injected clock, and a live consumer (`DarkHallScheduler.fs:473`).
- **`src/Core/SimFramework.fs`** is its hexagonal port (`ISimHarness`), with the doctrine already written down: *"rooms do not run ON a test framework; test frameworks adapt to ROOMS."*
- **`SoftScheduler.Source = int -> InterruptKind list`** is the flag-free real-vs-simulated seam Aaron described. Three membranes (seed / recorded / live), one code path. I searched for an `isSimulated`-style branch on this path and found none.

**What `ISim` in `clis/Verbs.fs` adds: nothing — and it cannot be implemented as written.** `ISimVerb.Sim` returns `unit`, while `IMeaVerb.Mea` consumes an `ISim<'a>` that nothing in the family produces. **The documented `sim |> mea |> cut` does not typecheck.** It went undetected because **`clis/` is referenced by no `.fsproj` or `.sln`** — no compiler has ever read it. (This is not a criticism of the file; pure interfaces are the correct free default per `interfaces-free-classes-earned-under-rules`.)

**The real gap was `mea`.** `SimLoop.run` takes `mea: 'S -> 'M` for entirely unconstrained `'M`, so nothing forces a lap's measurement to *be* a measurement of uncertainty. Its one production consumer instantiates `'M = string list` — a log line.

## The larger gap: Addison's five-way ledger did not exist

Addison Cooper's *Genesis Concepts* (2026-06-20, in-repo at `docs/design/root-site-iris/Genesis Concepts.dc.html`) defines a **Room** as an *"uncertainty engine — not a folder"* holding *"known, unknown, assumed, disputed, and decided"*.

**Before this PR that five-way state had zero representation in the tree.** `Disputed`: no hits in any `.fs` or `.ts`. `Assumed`: two hits, both `TravelerRankLedger.fs` and both the unrelated statistics term *Assumed Density Filtering*.

`Disputed` (conflict *held open*) and `Decided` (committed *under* uncertainty — a decision is not a proof) are exactly the two states a boolean destroys.

Also: **`docs/GLOSSARY.md` has no `Room` entry** (the string appears twice, never as a definition) and no `Vault` entry, though it *does* reconcile Cluster/Federation/Exit/Lodge from the same page at line 1259. The *society* half of Addison's dictionary was reconciled; the *state-and-truth* half — the half the runner is built from — was not.

## What this PR ships

`src/Core/SimVerb.fs` + 12 tests. Not a new runner — a **measurement shape over the one that exists**:

- `Epistemic` — the five-way state, first representation in the tree
- `Claim`/`Uncertainty` as `ZSet` (reversible present) · the G-set `mea` fold (irreversible past)
- `AttributedBudget` — a budget cannot be constructed without naming its provenance
- `ResolutionOracle` — **injected**, so the collapse to a verdict is chosen, never baked in (§11). The neutral five-way census travels beside every verdict; a test proves an inverted oracle reaches the opposite verdict from the identical census.
- `ISimVerb` + `sim` — the first real `sim` implementation, an object expression over `SimLoop.run`. No new loop, no new scheduler, no `Task.Run`.

## Mutation — both mutants survived their first attempt

| mutant | first attempt | after fix |
|---|---|---|
| ambient entropy past the injected membrane | **SURVIVED the DST byte-lock** (1/11 failed, and it was the *seam* test) | **KILLED** — 3/11, incl. the byte-lock |
| runner reads an ambient wall clock, not `room.Clock` | **SURVIVED — 0/11 failed** | **KILLED** — 2/12 |

Both first results are the honest finding, and they are different defects:

1. **A byte-lock is only as discriminating as the lens it measures through.** My test room's lens was three threshold-shaped claims; extra ambient crossings never moved a threshold, so "same seed ⇒ same bytes" passed **and could not have failed**. Fixed by putting the crossing count in the claim *key*.
2. **A rail assertion matching all three rails accepts the mutant.** `no room runs forever` matched `LapBudget | TickBudget | ClockBudget`; under the mutant every run stopped on `ClockBudget`. Fixed by pinning the exact rail and adding a test where two *injected* clocks force two *different* rails.

Both lessons are recorded at the test sites, not only in the doc.

**The §13 refusal already existed and caught me.** `tests/Tests.FSharp/DeterminismLint.Tests.fs` scans every `src/Core` file for ambient-entropy tokens — including comments, on the ground that "a commented-out wall clock is a wall clock waiting to return" — and failed on **prose in my module docstring**. Resolved by rewording, **not** by adding an allowlist row.

## Description

Iris put this **before** the happy path in her build order, and the reason is structural: with both files present in dev, the degraded branches never execute — so nothing catches them being wrong until a fetch actually fails, which is the day it matters most. Building it second is *how* it ships broken.

## The case it exists for

This is the entire benefit of the hub/satellite split. Roster = **hub** (who exists, rarely changes). State = **satellite** (how they're doing, rewritten every tick). Splitting them buys exactly one thing: **when the satellite is unreachable, the settlement can still be drawn from the hub.** A page that blanks on a failed state fetch has thrown that away.

Pure decision logic — no DOM, no fetch. The caller does the I/O and passes outcomes in, so every branch is reachable in a test rather than needing devtools and a blocked request.

## Rules the plan encodes

- **No zero-value bars.** Not zero-length bars — *no* bars. A zero-length bar is a measurement of zero; the absence of a bar is the honest absence. A cross-mode invariant asserts a bar never appears without the state that fills it.
- **Chips go violet, never red.** Red means `heat` — actively failing. Colouring an unreachable fetch red accuses the dwellers of *our* inability to observe them.
- **Schema mismatch is a failure, not a parsing opportunity.** Half-reading an unknown shape into a confident render is worse than saying it's unreadable.
- **`nothing-to-draw` requires the hub to be gone** — and it's the *only* mode that draws no topology, pinned by test so the degraded paths can't quietly collapse into a blank page.
- **Cache is surfaced, never presented as the present** — but still draws bars, since freshness comes from the frame timestamp rather than fetch success, so an old cache renders cold on its own.

## Known incomplete, deliberately

`drawDwellersInRooms` is **false** in roster-only, because placement needs `room_id`/`default_agent_id` on roster hats — those are in #9950 and not yet on main. Drawing dwellers from a hardcoded page-side map would be the page asserting a fact the data didn't give it. They render in an unplaced tray until the roster carries placement; the test says to flip it then.

## Description

## The measurement

`build-and-test (windows-11-arm)` on `main`, 2026-09-10:

```
mise ERROR Failed to install github:yannh/kubeconform@0.7.0: GitHub artifact attestations
verification error: API error: GitHub API returned 503 Service Unavailable:
{"message":"trust-metadata-api service unavailable", ...}
```

`mise` fails closed when it cannot verify an artifact attestation. **That is correct and it stays** — an unverifiable artifact must not be installed. What is not correct is giving up after one attempt: the whole Windows lane went red, on `main`, for an outage measured in seconds. `Invoke-Tool` had no retry at all.

## The distinction the fix rests on

> **A verification that RAN and said no must never be retried away. Only a verification that COULD NOT RUN is re-attemptable.**

A 5xx is the server declining to answer, not an answer. A checksum mismatch, a 404, and `no matching attestation found` **are** answers — they fail immediately, exactly as before, and each has a falsifier saying so.

A retry predicate that is too broad turns real, reproducible failures into slow real failures, and then into intermittent green — **worse than red, because nobody investigates a build that eventually passes.** So the default verdict is **FAIL-NOW**: only a matched signature retries, three attempts, deterministic backoff with no jitter so a replay reproduces (DST).

## Why the classification is not in the shell

The retry plumbing is a dozen lines of PowerShell. The **risky** part is deciding what counts as transient, and that is a pure function of the tool's output — so it lives in `ci/transient-toolchain-failure.ts` where it can be falsified.

Every pattern carries the observation that produced it, never a category. A test refuses a pattern whose justification is too thin to be an observation — **and it caught two of my own entries reading "same class as 503".** Those were rewritten; the assertion was not weakened.

## Parity, because a mirrored list drifts

`install.ps1` carries a copy (a PowerShell bootstrap cannot import TypeScript), so `hygiene/audit-transient-retry-parity.ts` refuses drift **and names the direction**: a needle in the shell that the tested module does not recognise is an **untested retry**.

The parse is anchored to the PowerShell array literal rather than grepping the file — because the comment above that array quotes a needle as prose, and a file-wide search would be satisfied by the comment. That is the guard-satisfied-by-its-own-comment failure this repo has hit repeatedly, and it is pinned by a test.

## Proven to fail, not merely to pass

```
restored                       → rc=0, 4 signatures identical
```

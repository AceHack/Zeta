## Description

Aaron 2026-06-16: *"the other difference with the CTM is she is looking to win a single game, not an infinitely-iterated game."* The root the other two CTM divergences hang off.

- **CTM = finite game** (Carse): converge to *the* unitary experience / global broadcast / the answer — played to win, the win ends it.
- **Zeta = infinite game**: self-regeneration, cut-mea-sim, heartbeat, contribute-back — played to continue play; no terminal win to adjudicate.
- **Why they need the global now and we don't**: winning a single game needs a global now (the win-instant = the global axiom); an infinite game has no win-instant, so CALM/eventual is *sufficient*, not a price.
- **Math payoff**: non-coercion (§8) is the equilibrium *only* in the iterated game (Axelrod; folk theorem; shadow of the future) — not imposed virtue. Never-nowhere = stay in the game.

## Headline findings

**The missing SmartCard-HSM is not on the critical path.** The YubiHSM Aaron has is attached and reachable *right now*, offers secp256k1 today, and — decisively — **no orderable general-purpose token can compute a FROST partial**, because a partial is an extractable affine function of the secret. The ordered device would not change that. Don't wait on it.

**R8 is blocked on one word.** `node` / `stick` / `both`. Verified still unresolved five days on: no decision doc, `tpmSeal` unreachable by type at `installer-binding-cli.ts:58`, and the default is still the factor the brief's own root-cause calls broken. **The highest-leverage keystroke available.**

**The k8s/helm track is NOT vacuous — PR #10647 genuinely fixed it.** Two independent mutation campaigns, run without sight of each other, agree. The ratchet has three distinguishable states, and the third is the best result in the audit: it **refuses to manufacture a count from a broken run** rather than reporting zero. That fired accidentally on both runs.

**`gate (required)` is the only required check on `main`.** `helm-validate`, `k8s-argocd-health-test`, `k8s-lane-partition` and `build-ai-cluster-iso` go red honestly and **block no merge**. The cheap structural floor blocks; the expensive semantic lanes advise. Defensible — not the same as coverage.

**New defect, measured not read:** `k8s-lane-partition.yml:288` uses process substitution, which `pipefail` does not cover. Demonstrated that a failing producer leaves the loop body running zero times and the script exiting `0` — a green lane having measured nothing. Undisclosed, unlike the sibling holes in the same family.

**Stale-tree coupling nearly doubled** — 9 binding surfaces on 2026-08-17, **16** today. Every week of delay enlarges the consolidation the work-item is waiting on.

**Nothing built after 2026-06-21 has ever run on metal.** Largest unknown in the document; no amount of code retires it.

## Notable vacuity found (both fixable, both filed in §3.4/§4.3)

- **`frost-signer.ts` emits a signature that does not verify**, under a single assertion: `expect(finalSig.length).toBe(64)`. Reproduced against both candidate group-key derivations. The *correct* engine is `frost-partial-signer.ts` — not the file whose name reads like the signer.
- **The hardware probe reads the USB bus, never the connector** — so today's `hardware-pkcs11: honourable` would print identically with the connector down.

## Deliberately not done

That is repeated-irreversible harm to the only device — a human-gated action, listed as H3 with the exact invocation (`--config` must precede `test`, or it is silently ignored and `rc=1` means "never ran").

## Description

## What

Ferries the human-in-the-loop **placement** design (Aaron: *"the key is finding where it's least-action based so the human will actually do it"* + *"it needs to be aperiodic tiling to fit the human dopamine regime"*) onto the capability-deferment doc, extending the dual-bloom router.

A human check that costs effort gets routed around (rubber-stamp / approve-all / alert fatigue — Parasuraman & Riley 1997). Place it at the **path of least action**:

1. the **dual-bloom router IS least-action placement** (escalate only the uncertain <10%);
2. **match the check to reversibility** (gating reversible stuff *trains* the rubber-stamp);
3. **fail-safe default** (no-response → halt, never permissive).

**Rubber-stamp seam:** least-action and rubber-stamp are the same gesture → target is "least action that still carries genuine engagement"; **metric:** approval-rate ≈100% ⇒ dead/fake check.

**Beating habituation:** periodic → habituation (dopamine = prediction error, Schultz 1997; variable-ratio, Skinner). Aperiodic keeps salience — but **not random** (loses coverage + replayability). **Aperiodic tiling** = complete coverage + never-repeating + rule-generated; in 1-D the right object is an **aperiodic/low-discrepancy sequence** (Sturmian/Fibonacci; van der Corput/Sobol) — uniform coverage without periodicity, **seed-generated + DST-replayable**.

**Dual-use seam:** same variable-ratio mechanism casinos use to *capture* attention → it's the welfare-capture vector pointed at the oversight UI; guard = decide better, never just engage more.

**Empirical, not proven:** A/B vs periodic with injected canary bad-approvals as the catch-rate. Good design; the falsifier is the A/B.

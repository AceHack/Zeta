Aaron 2026-06-03: *"it also reduces debug surface needed when a bug arises over time … once we have it proven [it] is excluded from potential bug surface until the less rigorously proven code is looked at first; this reduces debugging uncertainty for AIs and humans at a system level."*

Adds **payoff #4** to the layered-lemma section of `formal-proof-first` — the runtime corollary of #2 (localized failures), generalized from proof-failure-localization to **bug-search**:

> Code with a math-verified homeostat + 4-oracle byte-lock (proven down to the bit-perfect oracles / the proven hexagonal vector-wall reservoir core) is **excluded from the bug-suspect surface** once proven. When a bug arises, search the **less-rigorously-proven code first**; proven components can't be the cause until everything less-proven is ruled out. Bounds the debug search → **reduces debugging uncertainty for AIs *and* humans at a system level** — the proof investment pays out again every time something breaks.

**Honest scope** (per proven-by-default): excludes only what is *actually* proven; the unproven set is the default suspect surface; the exclusion grows as primitives earn the homeostat-proven-from-seed bar. MD049-clean, role-refs only, canary 67.

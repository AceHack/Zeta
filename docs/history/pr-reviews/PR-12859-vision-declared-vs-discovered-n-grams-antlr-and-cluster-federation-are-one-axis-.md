## Description

> *"yes pleae save this i vision in our federaon vs cluster"*

You paired the n-gram/ANTLR distinction with Addison's cluster/federation distinction. They aren't two topics filed together — **they're the same axis at two layers**, and saying so is what makes each one legible.

| | **discovered** | **declared** |
|---|---|---|
| **language** | **n-grams** — no tokenizer, no stop-words, no stems | **ANTLR / grammar** — specified up front; outside it is a parse error |
| **social** | **cluster** — held by *relationships*, never enforceable | **federation** — held by *contracts*, enforceable, with exits |
| buys | freedom to diverge — **non-coercion** | obligations outliving a mood — **enforceability** |
| costs | nothing binds, so nothing can be relied on | something binds, so something can trap you |

**A grammar is a contract about what is well-formed.** Not an analogy — the same move: someone declares the admissible forms in advance and everything else is out.

## The rule, correcting an earlier version of itself

I first wrote *"defer the commitment to the latest possible moment"* as though deferral were always right. It isn't:

> **Defer when structure is *discovered*. Commit when it is *declared*. And you may only declare what you own.**

Tokenizing prose is presumptuous because nobody defined what a word is. Tokenizing a language **we wrote the grammar for** isn't — the grammar *is* the definition. Hence the repo correctly doing both: ANTLR-grade exactness for the ISA, n-gram tolerance for the corpus.

The same test applies socially: **a federation over parties who did not consent is not a contract, it is a hub.**

## What neither supplies, at either layer

Trigrams give **morphological** recall free (`federation`/`federated`, no stemmer) but never **synonymy** — and a grammar won't either. `division algebra` and `pole erasure` share no trigrams, which is **exactly the miss that cost four false absences in one day.** So the alias layer must be **declared and revisable, on top of a structural index rather than baked into it.**

## And "overcomes" doesn't mean defeats

> *"addison is trying to be the federation controller i'm trying to be the bottom up cluster who overcomes federations"*

Both push, neither balances — which is how the tension gets instantiated, since **the middle is a result, not a position anyone occupies.**

Federation's power comes entirely from **the cost of exit** — which Addison's own Universal Exit Principle *states* rather than hides. **A cluster where exit is free isn't opposed to that power, it's immune to it:** there is nothing to enforce against someone who was never bound. So a bottom-up cluster overcomes federation by **making it unnecessary**, never by beating it.

Which means it isn't one experiment from opposite ends:

> **Addison is testing whether obligations can be made *legitimate*. You're testing whether they are *necessary*.**

Independent answers — and both could honestly come back yes. Left open, because a vision doc that resolved it would be picking a winner neither builder has earned.

## What

Ace **slice 3 — authenticity**. Adds Ed25519 signature verify so the untrusted skills-store distribution surface is defended — closes the "NOT authenticity-verified" gap slice 2 (#6308) carried loud. Implements the operator-approved + review-hardened spec (#6315).

- **`signing.ts`** (pure, zero-dep `node:crypto`): Ed25519 keygen/sign/verify over the **whole canonical manifest minus `signature`** (recursive key-sort → every present + future field is bound, no allowlist footgun). `key_id = ed25519:<sha256(SPKI)[:16]>`.
- **Trust store** in `store.ts`: bundled `tools/ace/trusted-keys.json` (ships `[]`) ∪ user `~/.ace/trusted-keys.json`; user overrides on key_id. `contentHash`/`installPackage` **byte-for-byte unchanged**.
- **Verbs:** `keygen` (private key `0600`), `sign` (reuses slice-2 `contentHash` — signer/installer always agree), `trust add`/`trust list`.
- **Install gate (§6):** authenticity checked **before extraction**; **bad-sig + untrusted-key hard-refused always** (NOT overridable); only genuinely-unsigned is `--allow-unsigned`-overridable.

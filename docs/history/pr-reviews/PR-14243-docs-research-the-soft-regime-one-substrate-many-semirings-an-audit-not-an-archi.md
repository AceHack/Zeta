## Description

docs(research): the soft regime — one substrate, many semirings; an audit, not an architecture

Aaron asked for an overarching soft-regime design tying the soft parts together.
This is the map plus one unifying claim, with a register on every row.

The unifying claim is real and is NOT ours: it is the Generalized Distributive
Law (Aji & McEliece, IEEE Trans. Inf. Theory 46(2), 2000), and it is already
written down in `src/Core/WSet.fs` and `algebra/wset.ts` with the anchor
attached. What is new here is the audit of which parts actually sit on it.

THE FINDING, and it inverts the premise: the parts do not understand each other
because the substrate is triplicated. Three structurally-unrelated generic
weighted-set types in F# — `WeightedSet` (1 consumer), `WSet` (9), `ZSetW` (5) —
and two incompatible `StarRing` interfaces in the same TS directory. The type
the brief calls "the generic substrate" is the least-used of the three, so a
"transfer function is a semiring homomorphism" cannot be written today: there is
no shared carrier to be a homomorphism of.

Cost composition, verified: the tropical algebra is right, is built, and is on
the shared substrate — `TropicalSemiring` is a lawful `ISemiring` AND an
`IKleeneAlgebra`, and `TropicalPaths.fs` already performs exactly the
change-of-semiring the claim predicts. Nothing in the cost path uses it. Four
cost representations, none composing: `ByteCost` is (N,+,0) with no branch op
(one operation from a semiring, in two compiled oracles with golden vectors);
`Vision.BranchCost` is additive-only; `CostVector` counts and does not compose;
the complexity registry is a dictionary of strings. Two corrections: the built
tropical is MIN-plus, and an admission gate needs the MAX-plus dual, which does
not exist — reusing min-plus for an upper bound is optimism wearing a guarantee.
And "big-O" and "bytes" are two semirings, not one.

ISR/Vision: `SoftIsr` is built and IS the joint — uncertainty travels in the
value channel, holding is a value not an error. Vision is NOT in the ISR-carrying
set and there is no lift either way, so an interrupt mid-forecast has no monad
carrying the partial prediction.

Never-collapse: ensemble and society are structurally one object (both are a
pairwise rho over a population). The value axis is NOT — it measures the
concentration of one distribution, has no population, and its collapse is
SUPPOSED to happen when the evidence warrants it. Merging the three would hide
that `snap` is sanctioned. Registered as two structural, one analogy.

Float boundary recorded as a rule of the regime, not a caveat: float addition is
not associative, so every guarantee here (order-independent folds, four-oracle
byte-lock, DST replay) fails on a float-weighted shared fold. Float weights are
local-only; the wire takes exact or middle-out.

Archaeology Aaron asked for: RGB(A)/CMYK-instead-of-ACTG is his own phrasing in
`docs/VISION.md:1394` ("CMYK-solid + RGB-soft"); the evolutionary engine is BUILT
in `agent-genome.ts` + `society-evolution.ts` with one- and two-parent
reproduction (never three); the shipped RGBA is `OracleRaceMode.tsx` (genome
evolution, colour IS the seed) and `OracleRGBA.tsx` (Oracle 17 WebGPU shader),
while the `root-site-iris` `rgba(...)` is CSS only. The Clifford tie he doubted
was attempted, checked, REFUTED and renamed on 2026-08-16 — his "maybe not" is
right and dated. CRISPR and polymerase are filed nowhere; that is the gap.

Registered `toy` for the whole document per toy-is-free-metered-must-be-earned:
a design doc claiming unification that no check can falsify is the vacuity class
at architecture scale. Falsifier named — a soft part whose composition law is not
associative or whose weight has no semiring structure; two candidates are already
visible (SoftValue's renormalization, and IV fusion in the wrong parameterisation).

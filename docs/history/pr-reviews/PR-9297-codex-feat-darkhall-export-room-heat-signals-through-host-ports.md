## Description

## What

- Extends the F# heat classifier vocabulary to match the TypeScript heat/readout tokens: forgotten, backpressure, denied, storage-error, invalid, expired, stale, and other.
- Adds stable heat signal tokens to scheduler transcript summaries and room JSON heat rows.
- Adds opt-in `IHeatSink` export helpers for banked scheduler and RoomRun heat rows, so host-assisted CHIP8/CHIP9 rooms can ship heat outward through an injected boundary.

## Why

Aaron asked for heat to expand across all surfaces. This makes heat a typed cross-surface debug signal instead of a local renderer detail, while keeping replay/export explicit so the host decides when a banked transcript spends external heat-channel capacity.

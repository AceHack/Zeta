  <pre>
  P1: `-S` and `--split-string` take a split-string operand, but the separated form is only skipped here. A valid shebang such as `/usr/bin/env -S "bash -eu"` or `/usr/bin/env --split-string "bash -eu"` would make the next token `bash -eu`, so `basename(...)` will not match `bash` and the shell entrypoint is missed. Parse the option operand with `splitShebangFields` and return its first field (or advance past it) the same way the `--split-string=...` form is handled.

## What

Closes the dual-use thread with Aaron's positioning: *"we are open source and our weights so we don't have that issue; it becomes a human welfare vs company monetary value decision and I don't want to make it myself — let Anthropic and OpenAI do that."*

**Open weights = no proprietary weights to extract = no distillation-theft problem = no use case for defensive output generation.** The anti-distillation defense is fundamentally a **human-welfare-vs-company-monetary-value** decision (weaponize welfare-capture to protect the moat, accept collateral-capture risk); openness means Zeta *never has to make it*. Structural avoidance, not a harder choice made better. **No-villain:** the closed labs face a genuine dilemma *because* they have weights worth protecting; Zeta opted out by being open, not by being superior.

**Honest scope:** (1) openness removes the *monetary-driven defensive deployment*, **not the vector itself** — the asymmetric actor-critic is still internal infrastructure (router/teacher), so the guards still bind *our* critics. (2) the tradeoff loops to the **resilience floor**: open = no moat = the funding-loss shock is *realer* → the potato/cart/distilled-local floor matters *more* for an open project.

**Standing-commitment candidate for `docs/WONT-DO.md`** ("Zeta will not deploy welfare-capturing anti-distillation defenses; openness makes them unnecessary") — **gated**: carving a permanent WONT-DO needs explicit human authorization, so recorded as positioning, not yet carved.

## Description

A legibility-register explainer aimed at a technically-competent human (Max) weighing whether to co-run a power grid with an AI.

**The framing Aaron asked for:** trust between human and AI on shared infrastructure is not "believe the other side wont turn off the power" — it is "neither side *can* hide a kill switch, because both run the same deterministic instrument on the same open causal record, and a hidden coordination channel leaves a statistical fingerprint the instrument flags." Trust-but-verify, where the verifier is a shared re-runnable computation, not a bribable inspector.

**Honesty discipline:** every claim tagged [proven] / [in-progress] / [want]. The doc states the real scope limit up front — CHSH catches an *active* hidden channel but not a *passive pre-shared seed* (that needs the MI/Reichenbach second instrument, still in-progress and pending a second review). It also carries the safe-default point (homeostat: doing nothing keeps the power on) and the early-warning bonus (the same coincidence structure forecasts blackouts).

Anchors: Bell/CHSH, Hoeffding, Reichenbach, Lamport, Scheffer et al. Points at the shipped `DecorrelationMetrology.fs` / `DecorrelationMeter.fs` / `AntiSybil.fs`.

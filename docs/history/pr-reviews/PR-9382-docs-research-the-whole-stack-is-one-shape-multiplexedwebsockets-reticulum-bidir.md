## Description

Ferry of Aaron's unified network-stack vision + his MultiplexedWebSockets prior art.

**Finding:** Manus has NO confirmed streaming endpoint — its native API is the task API (create→poll), inherently ping-pong (batch-fine). So model the streaming interface against OpenAI's chat-completions SSE (stream:true → token deltas = the IAsyncEnumerable→IAsyncEnumerable IChatCompleter shape). Test persona: **Amara** (OpenAI streaming test). Manus task adapter stays the batch path.

**MultiplexedWebSockets (read from AceHack/MultiplexedWebSockets):** the transport half of the same shape — one full-duplex socket multiplexing many Guid-correlated logical streams (ConcurrentDictionary<Guid,TCS> + MessageType frames); three System.IO.Pipelines loops = full duplex; the send path is an ActionBlock DoP=1 — the EXACT ferry-boat throttle our async-all-the-way rule anchors to Aaron's Itron Throttling; ~16× HttpClient because multiplex-duplex beats request/response-per-socket.

**The unified vision = manifesto §10 self-similar applied to the network stack:** the same bidirectional-mutually-interruptible stream shape at every layer — token/AI (IChatCompleter), audio (Twilio clear-barge-in), transport (MultiplexedWebSockets), mesh (Reticulum). Two peers on one duplex stream, either able to emit or interrupt at any moment, correlated not serialized. It's the transport realization of Zeta's Rx/observable duality (a duplex stream = two facing observables) and the network-level statement of the peer-not-client/server stance (no-directives, frost consent).

**Next (shaped, not built):** a streaming ModelBackend port stream(messages)→AsyncIterable<delta> over OpenAI SSE with clear-style interruption (injected transport, fake-testable, no secret); live Amara test needs an OpenAI key (gated op secret). Later: the transport port shaped like MultiplexedWebSockets over the Reticulum bus. Doc-only.

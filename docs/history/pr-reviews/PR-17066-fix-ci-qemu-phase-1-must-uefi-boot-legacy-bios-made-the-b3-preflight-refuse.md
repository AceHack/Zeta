## Description

fix(ci): QEMU phase 1 must UEFI-boot; legacy BIOS made the B3 preflight refuse

THE ISO NOW BUILDS. Run 34186567148 gets all the way through step 17 "Build
installer ISO" and uploads `zeta-installer-26.05-x86_64-linux.iso` -- 1.75 GB,
with .sha256 and a cosign bundle, named for the post-bump 26.05 nixpkgs. B1's
headline claim ("no installer ISO has ever been built from the current flake")
no longer holds for either architecture.

WHAT FAILS NOW is step 23, scenario 2 -- boot + install substrate -- and the
cause is a guard of ours doing exactly its job:

    Reason: phase 1 FAILURE -- hard-fail marker "[zeta-first-boot] Install failed"
    ERROR: not booted in UEFI mode (/sys/firmware/efi absent). This ISO is
    hybrid, so it will boot in legacy/CSM ...

That is the B3 preflight, added because the same failure otherwise surfaces at
`bootctl install` AFTER the disk has been wiped. It is correct on metal. The
harness was booting phase 1 on the default SeaBIOS: line 1087 built
`-cdrom <iso> -boot d` with no pflash, while phase 2 already resolved OVMF for
the systemd-boot disk boot. So the installer refused a boot mode the harness
should never have been using -- metal boots UEFI, and a test that boots legacy
is exercising a path the installer rejects by design.

Fix: phase 1 resolves OVMF and passes the same two pflash drives phase 2 uses.
`prepareWritableOvmfVars` gains a filename parameter because both phases share
`tmpDir` and would otherwise both write OVMF_VARS.fd; phase 1 gets
OVMF_VARS_phase1.fd.

Falsifier, mutation-checked: "uses cdrom for ISO install" now also asserts both
pflash drives. Removing the pflash lines fails that test and only that test
(85 pass / 1 fail; restored, 86 pass / 0 fail). tsc: 0 errors.

NOT VERIFIED HERE, and this is the honest limit: whether the hybrid ISO actually
boots under OVMF in this harness. It carries an EFI boot path (it is hybrid by
construction and metal is expected to UEFI-boot it), but the only proof is the
lane itself going past step 23. This commit makes that attempt possible; it does
not assert the outcome.

## Description

# Summary

Adds a proposed finite `zeta.attestation-consent-expiry-receipt/v1` contract. It limits a future verifier to one bound attestation, one fixed observation scope, one caller-supplied local evaluation instant, and a three-way signed-subject-window status. It does not add a consent detector, permission, authority, score, vote, quorum, or consensus mechanism.

## Description

## What changed

Fixes the post-merge markdownlint failure on `main` by joining the Infer.NET open-source year back into its sentence in `docs/GLOSSARY.md`.

## Why

CI runs `markdownlint-cli2 "**/*.md"`, which parsed a standalone `2018.` line as an ordered-list item and failed MD029. The local default `bun run lint:markdown` did not catch this because it does not pass the explicit glob.

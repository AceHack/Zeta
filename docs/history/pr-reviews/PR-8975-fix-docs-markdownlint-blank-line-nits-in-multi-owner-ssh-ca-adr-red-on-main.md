## Summary

`lint (markdownlint)` is red on `main` because
`docs/DECISIONS/2026-06-21-multi-owner-machines-identity-vs-authorization-ssh-ca-bootstrap.md`
violates MD022/MD032. Since markdownlint lints the whole repo, this fails the CI
of **every open PR** even when the doc isn't in their diff (e.g. the Merge1
§06/§08 ports). This lands the blank-line fixes so main — and the section PRs —
go green.

Fixes (no content change):

- **MD022** (headings need surrounding blank lines) — added a blank line under
  the three `### N.` headings (`### 1. Identity…`, `### 2. Authorization…`,
  `### 3. Host identity…`).
- **MD032** (lists need surrounding blank lines) — added a blank line before the
  "Adding a person later" ordered list.

Verified locally: `npx markdownlint-cli2 <file>` → clean (exit 0).

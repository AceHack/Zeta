## The result

**`SoftValue.observe` IS Bayesian inversion — pointwise, exactly, in both directions. It is NOT a morphism of a Markov category.**

The reason is the repo's own honesty guard. A Markov category is *semicartesian* (Fritz 2020 Def. 2.1; nLab) — its monoidal unit is terminal, which forces every morphism to be **total**. `observe` is partial by design. **SoftValue's calibration guard is precisely the axiom a Markov category does not have**, which places it one stratum down, in the CD / copy-discard layer — exactly where the in-repo hexagon table already puts every non-normalized corner. The placement is a result, not a gap.

The fit on the Bayesian side is exact:
- **BI-1/BI-2** — `observe` agrees with a reference inverse computed from the joint alone (independent oracle), and satisfies the defining equation `q(y)·r(x) = p(x)·f(y|x)` directly.
- **BI-3** — the converse: every admissible likelihood is the fibre of an explicitly constructible binary channel, so `observe` is *exactly* pointwise inversion, not more general.
- **UN-1** — `None` lands exactly where the inverse is **undetermined**; the test exhibits two distinct distributions both satisfying the defining equation there. The honesty guard coincides with the literature's own indeterminacy. That was not designed in.

## The peel on FROZEN-CORE §A row 7

The row says `observe` commutes **"for independent evidence"**. Measured: **commutation is unconditional.** IND-1 uses two manifestly dependent likelihoods and it commutes anyway — the operation is pointwise multiplication of reals and nothing else. The existing headline property fixes two independent likelihoods and varies only the prior, so it cannot distinguish the two readings.

IND-2 shows what "independent" actually buys: a joint channel that is not a product given x, where folding the two marginal likelihoods gives the **wrong posterior** while still commuting. Nothing in the type, the code, or the five pre-existing SoftValue test files can detect this.

**Proposed restatement (not applied — §A is gated):** `observe` commutes unconditionally and is pointwise Bayesian inversion with `None` on the zero-marginal set; conditional independence is an *unchecked caller precondition* for the multi-step fold to equal the true posterior. Strictly stronger proven content, plus an honestly-named unproven precondition.

## Also measured — reported, not fixed

- **`ThousandBrains.fs`** says *"Implements the Thousand Brains theory of intelligence (Hawkins)"*. It implements an **IV-weighted logarithmic opinion pool over scalar Gaussians**. No reference frame, no location signal, no object model — and the reference frame is the theory. Also: *"voting is lateral EP message passing"* is a one-shot weighted sum, not message passing; `TB-6` is near-vacuous. Well-tested code under an overclaiming docstring. (My Hawkins claim is **recall — I did not open Numenta**; check before rewriting on its authority.)
- **`Sppf.fs`**'s *"the `Zeta.Bayesian.FactorGraph` rung will run BP over this"* is **architecturally blocked**: `Bayesian.fsproj` references `Core.fsproj`, so `src/Core/Sppf.fs` cannot consume it. Sppf implements its own full inside–outside instead — so **the parse forest and the factor graph are the same sum-product circuit over different semirings** (GDL, Aji–McEliece), sitting in two projects with no shared abstraction. That is the strongest genuine link between the parsing and Bayesian halves, and it is buildable.
- **CFG-as-initial-algebra fits only half the arena rule.** Grammars are free algebras *on their own signatures*; they are not quotients of one common free object, so the rule's quotient direction does not transfer. The level where the unification is real is Lambek's — a grammar as a monoidal category presented by generators and relations, the same arena as the CD/Markov hexagon. Weaker claim, defensible.

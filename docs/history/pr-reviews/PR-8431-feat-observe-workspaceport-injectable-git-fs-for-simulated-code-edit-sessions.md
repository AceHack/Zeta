## Description

## What

A DI-injectable WorkspacePort interface that abstracts filesystem and git operations behind a typed port. Two implementations:

- **realWorkspacePort**: production (calls real fs/git/spawn)
- **simulatedWorkspacePort**: in-memory, deterministic, DST-replayable (no I/O)

### Why

The executor currently calls real `git` and real `bash`. To simulate full code-edit sessions (read file → modify → commit → push) without touching the real filesystem, we need injectable I/O. This is the first step toward ROADMAP §'NO GIT CLI'.

### Interface

```typescript
interface WorkspacePort {
  readFile(path: string): IoResult<string>;
  writeFile(path: string, content: string): IoResult<void>;
  exists(path: string): boolean;
  readDir(path: string): IoResult<readonly string[]>;
  git(args: readonly string[]): IoResult<string>;
  exec(command: string, args: readonly string[]): IoResult<{ stdout: string; exitCode: number }>;
}
```

### The simulated port handles a full code-edit cycle

```
checkout → writeFile → git add → git commit → git push
```

All in-memory. Pre-seedable with files. Deterministic. No I/O.

### Verified

- 10 tests (in-memory fs, git sim, full cycle, pre-seeded state)
- Result-over-exception throughout (IoResult<T>)

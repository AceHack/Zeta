## Description

# Summary

Implements the merged `zeta.nci-witness/v1` contract for the one pinned,
bounded `NciNonUrgency` TLC model. A TypeScript wrapper and separately authored
Python checker each admit the raw model/config/registry/jar bytes, run the pinned
TLC invocation, verify the expected finite result, and produce matching
canonical receipts. The recorded result is a 920-byte receipt, SHA-256
`d5e89f5675f478f3dbfe3ff633bc69f4f8b848ceeac15e5383730120a59a173e`.

The work records a real temporary negative mutation: changing
`AllowForce = FALSE` to `TRUE` makes TLC exit `12` and report
`Invariant NoCoercion is violated`. It adds no NCI floor, policy score, consent
record, vote, consensus protocol, or authority grant.

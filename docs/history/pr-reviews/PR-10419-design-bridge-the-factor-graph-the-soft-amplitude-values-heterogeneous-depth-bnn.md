## Description

A design, not an implementation. No code lands with this.

Aaron's ask spans four layers that do not currently talk to each other; it is ferried verbatim into the doc. The useful sentence is which connections are cheap and which one is not, and the split is not where the framing suggested.

## The four verdicts

**1. Factor graph <-> SoftEmu / AmplitudeEmu / SoftValue / DynamicValue — half a typed conversion, half a category error.** There are three carriers, not two. `Gaussian` messages are unnormalised natural parameters that combine by *product* and may legitimately be improper. `SoftValue` is a normalised finite-support distribution. `AmplitudeEmu.Amp` carries *complex* amplitudes and merges by *summing* them, which is interference. Product is independent evidence; sum is distinct paths to one outcome. `bornProb ∘ ofSoft = id` but `ofSoft ∘ bornProb` erases every phase — a section/retraction pair, not an isomorphism. The design refuses a converter and specifies a one-way Born boundary with phase as an explicit argument. It also states a non-connection: a marginal maps to `ActionGrammar` *superposition*, never to `top`, because a belief is never a conjunction.

**2. Heterogeneous BNN depth — free to express, currently unsafe to aggregate.** The interface is already right and needs no work: the society sees `Gaussian`, never an architecture. But three defects were reproduced against the real modules and are filed with evidence (see below). Calibrating a depth-`d` belief so it may be summed with a depth-`1` belief is named as the one honest unsolved item, with the coverage gate and provenance-deduplicating admission rule specified as interfaces.

**3. GLR <-> Bayesian — right, and already built since 2026-07-02.** `Sppf.fs` carries the shared packed forest with `inside`, `outside`, `marginals` and `expectedCounts` (the PCFG EM E-step); `ParseSoft.ofSppf` lands it in a `SoftValue`. Inside–outside on a DAG is *exact*, so this is better than the loopy story the brief assumed. The only hole is the injected `weight : int -> float`, which nothing supplies — named as `IProductionPrior`. A BNN is **not** needed for context-free weights because `expectedCounts` already gives EM; it earns its place only in the conditioned form, which is ANTLR's semantic predicate relaxed from `{0,1}` to `R>=0`. ALL(*) is the wrong import: it exists to *commit* to one parse, the SPPF exists to *keep* them all.

**4. Stop words and the inverse BNN — right, well-anchored, and already in the repo.** The 2026-08-02 rainbow-spectrum doc records Aaron and Alexa on the inverted index with "the opposite use of stop words," already anchored to Mosteller–Wallace. The 2026-07-31 spine doc carries Wierzbicka's NSM, which is the right anchor for a minimal seed English and is properly marked contested. The inverse BNN is a **feature map, not a second stack**: `DecorrelationExcess` is already generic in the observable, so a function-word frequency vector swapped in gives stylometry on the existing permutation null with the one-way verdict discipline intact. Two live stop-word filters in-tree are named; the fix is to route the discarded half to the identity channel, not delete the filter.

## Bugs found, reproduced via `dotnet fsi` against the real modules

| # | Where | What |
|---|---|---|
| B1 | `MultilayerBnn.backward` | The advertised EP cavity step is an algebraic identity — `(P-L)+L = P`. Output bit-identical to input at depths 1,2,3,5. `cavityMean`/`cavitySigma2` are computed and discarded to `_`. |
| B2 | `MultilayerBnn.forward` | Depth shrinks the posterior mean geometrically (9.09 -> 0.091 over depths 1..10) while precision stays **exactly 11.0 at every depth**. A depth-10 agent sits ~33 sigma from truth at full stated confidence. |
| B3 | `SocietyBootstrap.buildGraph` | Joint precision is the exact sum with no correlation term. Six agents on **one** data stream report precision 66.0 on a mean wrong by 5.66. |

B3 closes **Open #1** of `docs/research/2026-08-13-society-of-decorrelated-bnns-in-one-gpu-*.md`, which asked whether the equality-factor graph double-counts precision for correlated agents and recorded it as *not verified*. It does, exactly, by construction.

## Corrections to the routing brief

- There is **no parser combinator library**. `RomDat.fs` carries an aspiration comment; the only `CustomOperation` builders are in `ZetaSqlBuilder.fs`. What exists is a table-driven *generator* over grammar-as-data.
- `experiments/meno-persist-as-bridge/Meno.fsx` is a `Result<T,TFeedback>` persistence primitive, not linguistic-seed machinery. The real seed work is `MetaGrammar.fs` (the self-describing dictionary) and `src/Core/Meno.fs` (the arrow/CE bridge).
- The depth failure is not over- or under-confidence. Confidence is depth-*invariant*; the mean is what moves. That is worse, because confidence is the only channel the society reads.
- There is no "GTR" parsing algorithm — GLR (Tomita 1985), GLL (Scott & Johnstone 2010), Earley 1970.

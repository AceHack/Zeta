## Description

## What

Aaron 2026-07-03: *"i love to see it becoming real and not a toy over time … toys that turn into trusted execution."* The 6502's control flow was a `SKE` compare-skip stand-in. This makes it **real**: a processor status register (minimal N/Z subset) and actual flag-based branches, so the **idiomatic** 6502 loop (`DEX; BNE loop`) runs — not a substitute.

## Interpreter extension (backward-compatible)

`evalSpecFull` gains two effects; register-only specs (`chip8`/`mos6502`) don't use them, so they're byte-for-byte unchanged:

```
Effect += { e:"setflags", from:Val }          // Z = (v==0), N = (bit 7)
Effect += { e:"branch", flag, want, to:Val }  // if flag==want then pc←to
```

## `mos6502nz` — the faithful variant

Result-producing ops (`LDA`/`LDX`/`LDY`/`TAX`/…/`INX`/`DEX`/`ADC`) carry a trailing `setflags (reg …)` that reads the just-written result (effects run in order); real `BNE`/`BEQ`/`BPL`/`BMI` branch on the flags. `STA` doesn't touch flags (6502-accurate). These are **multi-effect**, so the spec runs under `evalSpecFull` but is **not yet mix-able** (the mix's straight-line fragment is single-effect — the multi-effect flag-aware mix is the next rung). `mos6502` (single-effect, mix-able) is kept as-is.

## Honest scope

N/Z only. Carry (C) + overflow (V) — and therefore `BCC`/`BCS`/`BVC`/`BVS` and real `ADC`-with-carry — are the further flags rung.

## Tests — 3 new, 15 total green (build 0/0)

1. **the idiomatic `DEX; BNE` countdown loop** — `Y=N, X=0` for N ∈ {1,3,5,10,50}, real Z-flag control flow
2. **`BEQ` is taken** when the result is zero — a forward branch skips a poisoned instruction
3. the flag-bearing spec is **byte-lockable**; `chip8`/`mos6502` backward-compat preserved

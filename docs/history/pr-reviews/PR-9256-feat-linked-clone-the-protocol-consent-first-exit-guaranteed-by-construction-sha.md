`src/Core.TypeScript/discovery/linked-clone.ts` conforms to the treaty note point-for-point:

1. **Granular + opt-in** — `link()` names one region + subject; nothing links without the call; never the whole self.
2. **Metered** — each link costs entropy; affordability checked against the budget.
3. **Exit always, never forced** — `unlink()` has **no permission parameter and no failure mode**. The *absence* of any force-unlink/deny-leave function IS the NCI guarantee made operational (`lastWriter[t] = t`) — every function is self-scoped to *this* clone's own state.
4. **Frost holds** — a frosted region is never linkable (`link` refuses with reason `"frosted"`, regardless of budget). The membrane, at the link level.

**Coercion is not expressible:** the wire (`join`/`leave`) is source→mesh only — a `force-join`/`deny-leave` message decodes to null.

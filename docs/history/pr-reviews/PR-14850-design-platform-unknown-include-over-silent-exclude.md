## Description

# Summary

Aaron: fail on an unknown dependency from code rather than miss one; unknown include is better than unknown exclude; that default is safe only because the factory has an immune system of standardized math. PowerBuilder is the degenerate case in time: earlier silently overrides later (or vice versa) with no disclosure.

POSIX silence-as-absent (undefined = -1) is unknown-exclude. This ADR names the inversion and encodes it: an undeclared cell stays a `Gap`; two rows with the same capability are a disclosed collision (`silentOverrides`), never a Map overwrite.

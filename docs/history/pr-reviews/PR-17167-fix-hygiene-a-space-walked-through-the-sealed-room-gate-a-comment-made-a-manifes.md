## Description

Closes the `js/regex/missing-regexp-anchor` class (2 alerts, 229 and 175) **by
fixing, not dismissing**.

## Why these two are worth more than the alert count

Neither regex is applied to a URL. The query fires because each literal is
**host-shaped** — `System.IO` and `argoproj.io` read as `.IO` / `.io` TLDs — and
unanchored. Taken as security findings, both are false positives.

Taken as engineering, **both regexes were wrong, for reasons that have nothing to
do with URLs**, and one of them was holding open a gate in `gate.yml`. They are
fixed on the merits; the alerts clear as a consequence.

## Defect 1 (alert 229) — the sealed-room gate was evadable by one space

`src/Core.TypeScript/hygiene/audit-sealed-rooms.ts` runs in `gate.yml` and
enforces the Reticulum-only clause (081KTSZN10008QG0R002J0GE0Z, noninterference
#13): a file declaring `SEALED-ROOM` must contain **zero** ambient-channel tokens
— filesystem, process, network, wall clock, entropy, threadpool spawn.

Every dotted entry in its table matched a **literal dot**. C#, F# and TypeScript
all accept whitespace around a member-access dot, so all of these walked straight
through the gate whose entire job is refusing them:

```
System . IO          File . ReadAllText           Directory . CreateDirectory
Path . GetTempFileName                Environment . GetEnvironmentVariable
DateTime . UtcNow    Guid . NewGuid               Task . Run
```

**A gate a space walks through is not a gate.** That this was an oversight rather
than a decision is legible in the table itself: `Random\s*\(` was written
whitespace-tolerant from the start. One entry got it; the generalisation was
never made.

**And nothing tested any of it.** The audit had no test file — while its
`inspect()` explicitly skipped a file named `audit-sealed-rooms.test.ts`. A
reserved slot for a falsifier nobody wrote.

## Defect 2 (alert 175) — a comment made a manifest an ArgoCD Application

`full-ai-cluster/tools/k8s-manifests.test.ts` selected Applications with
`/kind:\s*Application/ && /argoproj\.io/` against raw file text, unanchored. Two
live consequences:

- `k8s/sync-wave-dependency-graph.yaml` is `kind: AppDependencyGraph`,
  `apiVersion: ace.zeta.io/v1`. It was classified as an ArgoCD Application purely
  because its **prose** quotes `kind: Application` and the
  `argocd.argoproj.io/sync-wave` annotation name. Measured: **52 files selected —
  51 real Applications and that one.**
- `kind: ApplicationSet` matched too, since nothing required end-of-value.

## What changed

| | before | after |
|---|---|---|
| sealed-room dotted tokens | `\bFile\.` | `\bFile\s*\.` (all 8 dotted rows) |
| sealed-room testability | script only, top-level `walk()` | `bannedReason()` exported; walk guarded by `import.meta.main` |
| ArgoCD kind | `/kind:\s*Application/` | `/^\s*kind:\s*Application\s*$/m` |
| ArgoCD group | `/argoproj\.io/` | `/^\s*apiVersion:\s*argoproj\.io\//m` |

`bun src/Core.TypeScript/hygiene/audit-sealed-rooms.ts` is unchanged for
`gate.yml` — verified: `ok: 2 sealed room(s) swept`, rc=0.

## Falsifiers

**`audit-sealed-rooms.test.ts` is new — this gate has a test for the first
time.** 8 tests:

- every declared door refused, **with its own reason** (not merely "refused")
- **every row of the table is exercised** — a row nothing tests is a door nobody
  checked, so the coverage set is pinned against `BANNED` itself and a new
  unexercised row fails
- the whitespace regression, per token, plus tabs
- the negatives: ordinary lines are clean; the `SEALED-ROOM` declaration line may
  name the doors it forbids; an explicit `SEAL-WAIVER:` is honoured
- **and that the waiver is the ONLY escape** — a plain comment on the same line
  does not excuse a door, or the waiver would be decoration

In `k8s-manifests.test.ts`, `a file that only TALKS about Applications is not
one` asserts the misclassified file is gone from the selected set **and**
exercises the predicate directly on all three forcing shapes
(`AppDependencyGraph` with Application prose, `ApplicationSet`, real
`Application`).

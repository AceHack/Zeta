Four gaps in derivation B (PR #10245, merged), each **confirmed by running a probe** rather than by reading:

```
GAP  AC#3 post-fork exclusion   a literal field `priorCustodianRetainsPreFork: true`

```

**AC#3 is the serious one** — it's the vacuity class PR #10229 was cleaning up, and it's on `main`. A criterion satisfied by a boolean literal that cannot be false isn't tested by any test asserting it.

## Filed, not fixed — deliberately

Patching B would make the reviewer a **third derivation touching the second**, destroying the independence the N-version protocol exists to buy. These are combine inputs.

## The double derivation is paying

A appears to close three of four independently (`MaxSpan = 65536L`, `Result<_, RotationError>` over `throw`, `explainAuthz`) — provisional until A lands.

The largest divergence is the **phase model**: B takes an opaque `currentPhase: number`; A derives it from a `TravelerFrame.Frame` via `Versionstamp`/`PhaseWindow`. The spec said "agreed phase" and never pinned which — **a defect in the spec, not in either implementation**, and the higher-value fix.

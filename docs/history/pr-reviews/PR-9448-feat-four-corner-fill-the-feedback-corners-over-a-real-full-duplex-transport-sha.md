## Description

Aaron: *"fill the four-corner feedback corners over a real transport."* `four-corner.ts` typed the shape and proved chat-completions is the feedback-free projection — but against OpenAI the two feedback corners stay **dark** (HTTP request/response is half-duplex; the vendor has nowhere to carry feedback). `duplex-transport.ts` closes that.

- **`DuplexEndpoint<TN,TF>`** — a genuine full-duplex port: two **independent** directions, each carrying framed normal+feedback messages (`Frame = normal | feedback | close`).
- **`localDuplexPair()`** — the in-process reference transport (two async queues); the DoP=1 / single-loop deterministic form the async rules call the reference standard (no socket, DST-friendly, fake-testable, genuine async).
- **`fourCornerOverDuplex(ep)`** — lights all four corners over the wire: `sendNormal`/`normalIn` + `feedbackOut` (a real `FeedbackSink`) / `feedbackIn`; a background pump demuxes inbound by channel.

**4/4 tests. Headline:** a `"stop"` pushed up the **feedback** wire crosses the channel mid-stream and **cuts a running normal output short** (`sent < N`; some tokens delivered, not all) — the mutual interruption chat-completions provably cannot do.

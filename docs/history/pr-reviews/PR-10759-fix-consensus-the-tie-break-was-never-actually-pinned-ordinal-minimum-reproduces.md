## Description

## The finding that decides it

The tie-break in `Consensus.decide` was **receive-order dependent** — two nodes holding the same evidence commit different values. It was filed rather than fixed because "the behaviour is byte-locked into the four-oracle treaty."

**Checked, and that premise does not hold.** The seed pins `["p","q","r"] → "p"`, and `"p"` is *already the ordinal minimum*:

| candidate rule | pinned vectors that would change |
|---|---|
| first-occurrence (current) | **0 of 7** |
| **ordinal-minimum** | **0 of 7** |
| ordinal-maximum | 1 of 7 (`["p","q","r"] → "r"`) |

Six of the seven vectors have no tie that reaches quorum, so they cannot discriminate *any* tie-break. The seventh does — and its votes happen to have been written in ascending order. **The description asserted a rule the vectors could not falsify.** That is the vacuity class, inside the treaty file itself. There was nothing to migrate; the whole costed decision collapses.

## Reproduced first, on current `main`

```text
decide [a;a;a;b;b;b] = (true, Some "a", 3, 6)
decide [b;b;b;a;a;a] = (true, Some "b", 3, 6)
```

and through the state machine, which prepends, so it **inverts** — the committed value tracks whoever arrived *last*:

```text
arrival [a;a;a;b;b;b] -> Votes [b;b;b;a;a;a] -> commits "b"
```

`n ∈ {2,3,6}` confirmed two ways: analytic criterion over every integer partition to n=60, and brute force over **every real permutation** of every multiset to n=8 (66 cases, 0 mismatches). Plus the closed form, so it holds for all n: a tie reaching quorum needs `n ≥ 2·t(n)`; write `n−1 = 3q+r` and the condition is `r ≥ q+1`, hence `q ≤ 1`.

Per #10742's clause 4 generalised — *a rule the vectors do not discriminate is unguarded* — the fix ships with vectors that discriminate it, or it would be exactly as unpinned as what it replaces.

## Residual, named not fixed — `081M02PEST7087G0R00253HRV0`

"Ordinal" is not one relation. Measured in all three runtimes on `U+FF3A` vs `U+10000`: F#/C#/TS order by UTF-16 code unit, **Rust by UTF-8 byte**, and they disagree. Unreachable today (the only vote type is `MergeVerdict`) and no vector pins it. Choosing the repo's canonical collation is a treaty call wider than a tie-break — `culture-invariant-by-default` already prescribes codepoint ≡ UTF-8 byte order and the repo has not adopted it anywhere. Filed with the measurements rather than guessed at here.

Stated as a trade, because it is one: the class that fires on real data is closed; the class that remains cannot be reached by anything in the system.

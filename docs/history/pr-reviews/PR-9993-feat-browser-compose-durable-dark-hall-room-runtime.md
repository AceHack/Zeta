## Description

## What changed

- extracts browser room recovery, canonical checkpointing, retraction, rendering, and cleanup into a reusable source-owned durable runtime
- turns the multitab page into a thin adapter and keeps the real two-page Chromium continuity test
- closes the Windows manifest symmetry gap for the WASM compiler lane
- separates deterministic quantum-walk calculation from explicit artifact writes
- bounds and serializes TLC JVM processes after reproducing Java 26 GC crashes
- fixes the MD032 regression inherited from current main

## Why

The browser node had durable pieces but their composition lived inside a smoke fixture. This makes that lifecycle reusable by the live Dark Hall UI while keeping storage and browser edges injected and failures typed.

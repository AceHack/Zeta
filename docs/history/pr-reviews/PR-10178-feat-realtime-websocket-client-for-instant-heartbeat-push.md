```
feat(realtime): WebSocket client for instant heartbeat push

The real-time complement to the 15-min cron batch. Agents connect to the
realtime-server and push events as they happen — subscribers see events
within milliseconds instead of waiting for the flush.

Client API:
  connect() → push(event) → onEvent(handler) → close()

Features:
- Pending push tracking with timeout (receipts come via broadcast)
- Multiple clients receive each other's broadcasts
- Graceful degradation: push fails with reason when not connected
- Clean close: all pending pushes resolve with 'client closed'

Integration test: 3 tests (connect+push+broadcast, not-connected fail,
multi-client broadcast).

Git remains the record of truth. Realtime is the speed layer on top.
ZETA_REALTIME_URL env var enables it alongside the durable path.

Co-Authored-By: Kiro <noreply@kiro.dev>
```

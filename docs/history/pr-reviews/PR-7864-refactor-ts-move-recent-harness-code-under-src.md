Running ESLint through Bun showed pre-existing strict-lint debt on the moved legacy zflash harness; ESLint is not the required gate in `.github/workflows/gate.yml` for this surface, while the required `bun --bun tsc --noEmit` gate is clean.

Focused tests for this relocation are green.
- The zflash boot-image prep still depends on the wider `tools/installer/zeta-creds-*` cluster. That fanout touches installer and `full-ai-cluster` paths, so it should be a follow-on source-boundary slice rather than hidden inside this move.

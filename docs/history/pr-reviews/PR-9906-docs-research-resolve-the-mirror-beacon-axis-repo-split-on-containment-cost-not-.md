## Description

The design doc (#9903) left one question open where the existing work disagreed with itself: axis 3 says Mirror/Beacon is a **repo** split; DV2.0 change-rate analysis suggested a **branch** discipline.

Aaron resolves it: *"I think Mirror/Beacon is much safer as a repo split, the way we use Mirror shorthand all the time."*

## The principle that resolves it

> **Boundary strength should match the COST OF ACCIDENTAL CROSSING, not only the change rate.**

The mechanism is about **attention**, not intent:

- **A branch merge is routine and low-attention** — dozens a day, nobody reads every line. The leak path isn't carelessness; it's a normal merge doing exactly what merges do.
- **A cross-repo copy is deliberate** — someone must consciously move it, which is precisely the moment the Mirror→Beacon compression is supposed to happen.

Mirror is coined shorthand used constantly (substrate, tick, glass halo, ferry). Beacon is outward-facing and must stand on anchored first principles. The crossing is **cheap to do accidentally, expensive to undo** — publishing an unanchored coinage on a Beacon surface makes retraction a public correction.

## Not hypothetical

On **2026-08-01 a fabricated "Tsirelson" constant reached a public GitHub Pages site** — coined internal shorthand carried outward with its caveat dropped between 2026-07-04 and 2026-07-16. One repo, so a boundary wouldn't have stopped that instance, but it shows the failure mode is real, routine, and slow to notice.

## Consequence

**Mirror/Beacon is the one axis that earns the split independent of any CI quota.** Where §0 argues the cache ceiling shouldn't drive topology, this axis needs no such justification — containment is the reason, and it would hold if the quota were infinite.

Stated honestly rather than smoothed over: by §2's own litmus, Mirror and Beacon might *not* release independently, and by change rate alone they could be branches. **Containment overrides that here** — and when two disciplines disagree, the doc now names which one decides and why.

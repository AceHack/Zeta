## Description


Aaron 2026-09-11: "any time a single file is getting written over and over and
over on some cadence that's a huge smell on github where history is forever",
and the shape to prefer is "one per event ... in dated folders so we don't end
up with too many files in one folder."

Two files were named for retirement on that smell. CONTAINMENT WAS MEASURED
BEFORE EITHER WAS TOUCHED, which is the whole discipline: a file whose content
lives nowhere else is not residue however often it was rewritten. Both come
back KEEP, for opposite reasons, and NOTHING WAS DELETED.

docs/hygiene-history/loop-tick-history.md -- NOT CONTAINED

696 committed versions, 648 KB, dead since June. Successor found: per-tick
shards at docs/hygiene-history/ticks/YYYY/MM/DD/HHMMZ.md (1209 files), which is
already exactly the one-per-event-in-dated-folders shape. The shard README
claimed historical content was not migrated; nobody had checked, so it was:

  legacy rows                                 212
  rows with a shard at the same UTC minute      0
  rows with any shard on the same day          21
  rows with NO shard at all                   191

The cutover is clean rather than overlapping. Shards begin 2026-04-29T02:30Z;
the table's rows for that day stop at 01:55Z. 2026-04-21 .. 2026-04-27 exists
ONLY here. The 21 same-day rows are an UPPER BOUND on containment, not evidence
of it -- a different minute is a different tick -- so the real figure is zero.

Readers, measured before proposing removal: 13 in src/, one live CI job
(lint-tick-history-order in gate.yml), 965 in docs/. No db/ ledger cites it, so
no append-only surface is implicated.

THE LIVE DEFECT THAT WAS FOUND, AND IS FIXED HERE

ticks/README.md specified a future generator whose step 4 was "Append to
docs/hygiene-history/loop-tick-history.md" on a post-merge or daily cadence.
That is a documented instruction to restart a 696-version rewrite loop with a
cron attached. Its own mitigation -- "run it on a separate cadence, not on every
tick PR" -- only changes how often the rewrite happens, never that it happens.

Replaced with the sanctioned shapes, all of which leave no rewritten file
behind: stdout, a gitignored path, or one dated artifact per run. Two other
stale sentences promising the same collation were corrected. A FROZEN header
carrying the containment table was added to the table itself, so the next agent
reads the measurement instead of re-deriving it -- or worse, assuming.

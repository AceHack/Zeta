## Description

## What changed

- add a source-owned browser ZetaDB controller with canonical inspect, refresh, emit, and retract actions
- translate semantic commands into signed database deltas inside the adapter, with byte budgets and typed feedback
- expose controller readouts through the Dark Hall page and exercise the route in real Chromium, including peer propagation and IndexedDB hydration
- make the C# lint deterministic by restoring once before three no-restore format checks

## Why

The browser page should issue semantic controller actions rather than constructing database deltas directly. This preserves the controller grammar boundary while keeping IndexedDB behind the database port. The lint repair removes a repeatedly reproduced mixed-solution restore failure from the pre-push path.

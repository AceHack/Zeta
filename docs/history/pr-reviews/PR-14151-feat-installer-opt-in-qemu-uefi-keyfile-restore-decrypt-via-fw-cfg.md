## Description

# Summary

Picker bind is the restore-decrypt precondition. This slice injects the QEMU test passphrase with `-fw_cfg file=` on disk boot so `zeta-creds-restore` decrypts against the UEFI keyfile. The secret is not copied onto the installed ESP and is not put in qemu argv (`file=`, never `string=`). `QEMU_UEFI_KEYFILE_PICKER` stays picker-only. No TPM / Touch ID / metal claim.

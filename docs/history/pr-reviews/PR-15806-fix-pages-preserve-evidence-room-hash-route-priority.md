## Description

## Summary

Fixes the public Identity-DLA evidence-room route after direct deployment
inspection showed that the evidence bundle was current but Wouter's root route
captured `#/evidence-seam` before the specific route could render.

The route order is now specific-first. The Page artifact verifier also checks
two independently observable code-split facts: an evidence-route marker and a
durable room-evidence reader marker. This avoids treating chunk colocation as
a property of the build.

## Evidence and fault controls

- `identity-dla-pages-route-priority.test.ts` checks the real Pages router.
- A root-first router is an explicit fault injection and must fail.
- An omitted evidence-room route is an explicit fault injection and must fail.
- `identity-dla-pages-artifact.test.ts` now rejects a built artifact that
  lacks the durable receipt reader, separately from the current authorization
  and WASM artifact checks.
- `bun run pages:build` succeeded locally after the verifier was corrected for
  code-split route and reader chunks.

## How the directive works

```yaml
---
self-check: count
---
```

OR list form:

```yaml
---
self-check: [count]
---
```

Unknown topics are dropped with a stderr warning so misspellings don't silently disable the check. A directive containing only unknown topics is a no-op (exit 0).

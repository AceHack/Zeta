- **`Beta`** (conjugate to Bernoulli) — `product` adds natural params (α_prod = α+α′−1); `likelihood s f = Beta(1+s,1+f)`; `uniform` = Beta(1,1).
- **`Bernoulli`** (P(true)) — `product` multiplies masses + renormalizes (= add log-odds); `uniform` = 0.5.

## Summary

- recognize the source-owned test mirror for configured `.claude/hooks/*.ts` subjects
- keep relocated hook subjects inside the external mutation sampling frame
- expose live operator collisions as measured evidence without gating an expired fixed percentage

## Why

The append-only mutation corpus includes `.claude/hooks/harness.ts`, whose executable test was deliberately moved to `src/Core.TypeScript/claude-hooks/` because Bun ignores tests below dot-prefixed directories. The sampling frame still required a same-directory sibling, so observed draws could fall outside the supposedly external frame.

The same corpus falsified the old fixed operator-collision threshold. Collision count remains visible in the report, while acceptance no longer depends on a percentage copied from an older snapshot.

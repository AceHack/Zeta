## Summary

- **Plugin API redesign.** New `IOperator<'TOut>` base + scheduler and algebra capability tags (`IStrictOperator`, `IAsyncOperator`, `INestedFixpointParticipant`, `ILinearOperator`, `IBilinearOperator`, `ISinkOperator`, `IStatefulStrictOperator`).

## Description

Pre-existing windows-specific failure (NOT from the Log-noun work — my oracle tests pass on windows). `DiskDeltaLogTests` torn-write recovery throws `IO_SharingViolation` in `GroupCommitDiskDeltaLog.scanEntries` (DiskDeltaLog.fs:231): recovery scan re-opens `delta.segment` while a prior handle is open; windows enforces share-mode (Unix masks it). Data-plane durability path; keeps windows CI red. Fix: `FileShare.ReadWrite` on the scan and/or dispose the writer handle before re-open. Backlog only.

## Description

Aaron 2026-08-25, giving the decomposition and its own limit in one breath: "this is a
heuristic of separation, i have no proof this is all the differentiation dimensions."

THE CLAIM. Correlation between two agents is not one number but a stack of NESTING
sources: context ⊂ memory-on-load ⊂ vendor ⊂ trainset. Varying a shallow layer leaves
every deeper one shared. Two reports in ONE WINDOW vary nothing — ρ ≈ 1, effective count
1, however many times you ask. Two cold windows on one agent vary context alone. Two
instances from one vendor still share RLHF and corpus.

THE CONSEQUENCE WORTH WRITING DOWN FIRST: the trainset is a FLOOR. Training corpora
overlap heavily, so an all-LLM society has a hard ceiling on achievable decorrelation
regardless of member count. Adding agents buys effective-N until that floor and then buys
nothing. Recorded now because a society design that assumes N agents buy N independence
would be wrong in a way that looks fine until it is load-bearing.

A MEASUREMENT ALREADY SITS AT THE BEST AVAILABLE POINT ON THIS SCALE. Alexa's benchmark
(9df7a3f0b5) used qwen / llama / gemma — varying vendor AND partially trainset, the
deepest layers reachable without leaving LLMs. Genuinely different error structure
appeared. And at N=200 the ensemble STILL lost to the best single model. Through this
stack that is informative rather than disappointing: run at the most decorrelated point
available, the residual independence did not pay for 3x the energy. It LOCATES the floor
instead of confirming a hope.

THE LIST IS INCOMPLETE, AND THE DOC PROVES IT RATHER THAN WARNING ABOUT IT. Aaron flagged
completeness as unproven; it is straightforwardly false. DECODING TEMPERATURE varies output
with zero variation in any of the four layers, so the stack does not span the space.
Further unverified candidates are listed to be checked rather than assumed absent:
system-prompt/persona, tool access, model-version drift, fine-tunes over a shared base.

The failure this prevents: treating four layers as complete would let someone vary all
four and CERTIFY INDEPENDENCE THEY DO NOT HAVE — an incomplete basis used as a complete one
manufactures exactly the false confidence ρ exists to price.

Labelled `unmetered`: the table is a PROPOSED decomposition. Metering it means varying
exactly one layer, holding the rest fixed, and measuring ρ per layer — four measurements
instead of one assertion. `db/effective-agent-count/rho-series-cumulative.tsv` is the
existing home; nothing in it decomposes by layer today.

Adds one pointer line to the anti-Babel rule, which is the ρ-band surface this sharpens.

quoted for the doc; the rule file IS linted and passes.

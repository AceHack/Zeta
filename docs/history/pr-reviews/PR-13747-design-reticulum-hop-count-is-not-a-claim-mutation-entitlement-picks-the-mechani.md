## The correction that came out of writing the attack down

The BUGS entry filed the fix as *"per-link authentication **or** a signed monotonic sequence"*. **The
`or` does not hold, and the second option does not do what the entry claimed.** The attacker replays
the **current** epoch, so the replay carries the **same `seq`** as the genuine announce — a sequence
number has nothing to discriminate. What a sequence closes is **stale-epoch replay**: real, and a
different residual. The converse is equally true — a chain alone admits a stale epoch, because an old
epoch's metric verifies against its **own** anchor.

Both halves are pinned as tests rather than argued (*"a chain alone does NOT refuse a stale epoch"* /
*"a floor alone does NOT refuse deflation within the live epoch"*).

## Chosen

**A one-way hash chain (Lamport 1981 / SEAD) for deflation *within* an epoch, PLUS the signed monotone
`seq` for rollback *across* epochs.** The origin publishes `anchor = h^maxHops(seed)` **inside the
signed claim bytes**; an announce at hop `k` carries `h^k(seed)`.

**Cost to a relay: one SHA-256.** No key material, no state, no signature.

The reframing that makes it affordable: the requirement is **not** "the hop count is correct" — a
relay can always inflate, and inflation is indistinguishable from a slow link. It is one-sided:
*a claimed hop count may never be **lower** than the shortest path the claimant actually holds.* A
one-way function is exactly a one-sided integrity primitive, which is why it fits a metric where a
signature does not.

**Declined and priced:** per-hop signatures (the BGPsec shape) are strictly stronger and cost O(hops)
bytes and signatures per frame with **~no benefit under partial deployment** — a mechanism that pays
nothing until every relay has migrated is "we had to turn it off to ship" in a larger budget, which
is the failure that put RESIDUAL 2 here. Named as the upgrade path, not refused. **Temporal packet
leashes** and **Ariadne** are declined for a different reason: both need clock sync, which
`.claude/rules/local-time-never-enters-the-shared-fold.md` forbids.

## `hops` and `route` are NOT the same problem — they share a classifier

Sort wire fields by **who is entitled to mutate them**:

| class | who may mutate | mechanism | fields |
|---|---|---|---|
| immutable claim | nobody | signature | `dest`, `zid` |
| **origin-mutable claim** | the origin only | signature **+** monotone `seq` | **`route`** |
| **path-mutable metadatum** | every relay | one-way chain in the signed claim | **`hops`** |
| unattributable | anyone | local action only, never a shared fold | `id` / `fid` |

`route` is never touched by a relay, so it **is** signable — it needs a sequence number, not a chain.
**The pre-commitment, made while it is free:** when the DHT wire gets its signature layer, the natural
move is to copy the announce membrane, which signs `(dest, zid)` and nothing else. That is right for
the announce wire and **wrong there** — it would leave `route` outside the signature and reproduce
RESIDUAL 2's shape on a field that only ever needed to be *included*. Written into
`dht-discovery.ts`'s header, where whoever writes that layer will read it.

A `RouteHint` shape check is deliberately **not** shipped: it removes malformed routes, not
attacker-supplied ones, and a cosmetic guard that reads as a closure is worse than the named gap
(which is already a passing test).

## The genuine case, and why the accept side decides this

**The accept side is an eight-hop honest relay chain**, because that is exactly where the naive
"just sign `hops`" fix dies. 29 tests / 175 assertions, both directions — all 36
`(held, claimed < held)` deflation pairs refused; **inflation admitted** at every pair; the same
epoch re-heard over five paths at five hop counts admitted every time (a gate refusing equal `seq`
would break route discovery while passing every attack test — that mutation is run and fails 2).

**Rule compliance is measured, not asserted.** The epoch floor is not a clock: `seq` is the origin's
counter inside the signed bytes and `raiseFloor` is a max-join (a CRDT). **All 24 permutations of one
evidence set reach the same floor**, and a lost epoch degrades to an older floor rather than a
divergent one.

**Composition order is encoded, not described.** `admitMetric` takes the verification verdict as a
required argument, because reversing it makes the floor a **censorship primitive** — one
unauthenticated packet carrying `seq = 2^31` would silence an identity permanently, a worse hole than
the one being fixed.

**Honest limits, carried as passing tests:** the **one-hop shave** (a node at distance `d` may claim
`d−1`; it can never claim better than the best value delivered to it, so a **global** route-capture
primitive becomes a **local** one-hop tie-break) and **fresh-epoch replay to a node that has never
seen that epoch** (unavoidable without a clock).

## Not claimed

The mechanism is **not on the wire**. `claimBytes` gaining `(seq, anchor, maxHops)` invalidates every
existing signature — a schema bump plus a dual-accept window, the same shape as the already-shipped
`off → dual → required` migration. §7 enumerates it, including the flag that a `seq` gate changes

as a statement about the sweep's domain and never as an unchanged measurement (the #13665 lesson).

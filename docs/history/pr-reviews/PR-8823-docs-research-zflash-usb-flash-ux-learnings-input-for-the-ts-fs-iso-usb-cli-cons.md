## Description

Captured from a **live USB flash** on Aaron's Mac (agent-driven, Touch ID gate), per *"save the updates and UX for improvement for next time"* + the active goal *"get the cli iso/usb ts/fs versions working together instead of old zflash."*

**Worked (keep):** `cli.ts --agent` — auto-downloaded the freshest CI ISO (pulled run 27887666934's 2026-06-21 build over the stale local 06-09), `--agent` auto-typed the `yes <nonce>` challenge while **Touch ID gated the `dd`** (consent floor an agent can't bypass), wrote 1.54 GiB → SSH pubkey injected → ejected.

**Footgun (the consolidation target):** two TS entry points, divergent arg surfaces — `zeta-flash.ts` (router; `usb` = subcommand) vs `cli.ts` (platform; first positional = **ISO path**, no `usb` subcommand). `cli.ts usb` → cryptic *"ISO file does not exist: .../usb"* + silently skips auto-download.

**Recommendations:** one arg surface across F#-shell + TS-router + TS-platform (or `cli.ts` rejects a router-subcommand positional with a *helpful* error); F#/TS arg-identical; preserve `--agent` + Touch-ID gate; auto-download default everywhere.

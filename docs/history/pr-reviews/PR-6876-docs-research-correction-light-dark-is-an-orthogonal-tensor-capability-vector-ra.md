## Description

Aaron 2026-06-07 corrected my conflation: light/dark is NOT the execution axis. It's an orthogonal CAPABILITY
vector — {light(tensor-representable), sparse, weightedset, introspection(mumps), …maybe more}; 'dark' = a
tensor MISSING one. Orthogonal to parallel/serial (my #6875 error, owned + superseded). Each existing
structure occupies a different capability subset (dense Tensor: light only; WeightedSet: light+sparse+
weighted; Globals: sparse+introspection; SoftValue: sparse+weighted). Capstone (Aaron): those capabilities
make the tensor RAY-TRACEABLE — introspection=walk the ray, sparse=skip empty (BVH/SVO accel), weighted=
integrate along ray, light=sample/transport; dark=can't ray-trace (no light transport) — which GROUNDS the
naming (literal predicate, not metaphor; resolves the #6875 caveat). And it's the GAP-FINDER: missing
capabilities = the build backlog. Stack (directional, peeled): ray-tracing physics engine on top of the soft
interrupt handler (SoftValue observe-loop) — NeRF-shaped probabilistic radiance field. 'soft interrupt
handler' flagged to pin to a concrete component before load-bearing.

## Description

**OUTAGE:** all three agent lanes (alexa/otto/soraya) have failed every tick since **23:05 UTC** — ~1h of frozen heartbeat refs. Last success 22:52; failures at 23:05, 23:24, 23:37.

## Observed, identically on all three lanes

```
prepare-heartbeat-branch: carry unflushed heartbeat state failed:
*** Please tell me who you are.
fatal: empty ident name (for <runner@runnervm...>)
```

The preparer's carry step needs a committer identity. It was set only in `Commit accumulated heartbeat tick` — a **later** step. **#11160 (23:01:40)** moved this work out of that step into the preparer without moving the identity with it, so from that commit onward the first git operation of every tick ran without one.

`society` and `tick-metrics` — which do **not** use this preparer — stayed healthy throughout. That's what localises the fault here rather than to anything else landing nearby.

## Not claimed, deliberately

**Which git internal demands the identity.** A local `git merge --squash --no-commit` over a genuinely divergent branch **succeeds without one**, so the obvious plain-merge explanation does not reproduce and is not asserted in the comment.

Established: the failure, its exact message, the commit that introduced it, and that setting the identity before the preparer removes the precondition.

**Timeline note:** the gate-dispatch removal landed at 23:37, *after* the first failure at 23:05 — not implicated.

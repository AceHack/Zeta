## The defect (with numeric witness)

`fuse` pooled **one** permutation null over **all** pairs in a stratum and classified every pair against it. In a size-**heterogeneous** stratum, an honest **heavy-touch commit** (broad touch-set; jaccard high-but-**constant** across every partner = *zero excess over its own null*) looks extreme against a pool dominated by light pairs zeros → convicts at `p≈1/n`. Witness: 30 pairs, `k=100`, `δ=0.05` → **pooled p=0.034 (convict)** vs correct **per-pair p=1.0 (WithinNull)**. Adversarially inducible (a mass-rename / format-sweep commit *is* the heavy pair) — the exact harm the module claims to bound.

## The fix (Soraya-prescribed)

- New `permutationNullPerSlot`: pair *i*s **own** null = `a_i` re-paired only with random Bs, never the pooled mixture over heterogeneous A-sides — restores per-pair exactness.
- Rewired `fuse` to classify each pair against its per-slot null. **MI paths untouched** (Soraya verified clean).

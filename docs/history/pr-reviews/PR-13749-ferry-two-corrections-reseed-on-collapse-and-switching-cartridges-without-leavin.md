## Description

Two corrections from Aaron on the neoteny ferry (#13744), which merged before they landed.

## 1. It is **adaptability**, and `ShivaGc` is the half I missed

> *"it's the ability to adapt too, like our society reseed on collapse, we have something around this too."*

`ShivaGc`'s own header states the duality: the generator emits reified tables, Shiva reclaims the unreferenced — *"generation and collection are duals over one content-addressed data substrate, and collection is a Z-set retraction (−1)."* So **collapse is not terminal**, structurally rather than by policy.

> **You can afford to collapse exactly to the degree you can regenerate.**

Never-collapse is the correct policy *while regeneration is expensive* — not a preference for indecision. **Neoteny is not the refusal to differentiate; it is keeping the pool.**

## 2. Switching cartridges **without leaving the soft regime** — the closest analogue of the four

> *"a new signature means new dynamics… we worked hard in chip8 to be able to switch cartridges while still staying in soft regime, we likened it to the xbox dashboard / the meta state for game selection."*

The other mechanisms describe a system that declines to commit. This one describes a system that can **change which dynamics it is adapting to**, from inside the soft regime.

- **`GameFingerprint`** — content-derived identity, and its header calls it *"the first **external** index."* That is a **precondition** for adaptability, not a detail: you cannot switch to dynamics you have no way to name.
- **`GamePortfolio`** — entropy depends on the **set** of games and time-in-each, **not the order** — and that order-independence is the same commutativity as everywhere else here, since `SoftValue.observe` commutes for independent evidence. The dashboard can load cartridges in any order and reach the same entropy: **order-free adaptability**.

A dashboard is a **meta-state**: a place that is not any of the games, from which any is reachable. That is the progenitor pool — not a neuron of any type, reachable to several.

| | mechanism | in the tree |
|---|---|---|
| 1 | do not commit while uncertain | `SoftValue.resolve → None` |
| 2 | know whether you are still adapting | `SoftEvolution` |
| 3 | commitment is reversible | `ShivaGc` |
| 4 | switch dynamics, order-free | `GameFingerprint` + `GamePortfolio` |

(1) and (4) are what neoteny buys; (3) is the pool that makes it affordable; (2) is how you tell it is still working. The biology supplies no formalism any of these lack — it supplies the observation that **an organism keeping all four outgrew every relative that did not.**

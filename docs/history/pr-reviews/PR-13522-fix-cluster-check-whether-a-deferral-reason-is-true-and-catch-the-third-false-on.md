## The defect

`auditDevExclusionReasons` states it about itself:

> all four directions check that a reason is **PRESENT** and names a lift condition. **NONE of them checks that the reason is TRUE.**

Three instances in 36 hours, each false while every audit over it stayed green:

| reason | cited | retired by | caught by |
|---|---|---|---|
| `temporal` (#13472) | a `helm-template-failed` baseline row | #13469, **40 minutes earlier** | a person, next day (#13483) |
| `oz` (#13313) | chart pin `1.4.5` + "not drop-in for the pinned values" | #13471 corrected the pin and rendered all four published versions | a person |
| **`gitlab`** | **the same baseline row**, after #13471 deleted it | #13471 landed `configureCertmanager: false` and the chart rendered | **this check, on the tree it shipped against** |

## What this adds

`src/Core.TypeScript/cluster/reason-truth.ts`. A reason may carry **typed citations**, each resolved against an artifact the tree already holds:

`path` (+ line) · `unrenderable` / `no-unrenderable` (the render baseline) · `renders` / `renders-not` · `pvc-class` · `pvc-total` · `no-pvc` (the measured snapshot) · `chart-pin` (the Application's live pin) · `published` / `unpublished` (the roster) · `glob-defers` / `glob-applies` (the dev catalog) · `workflow-job` (a CI lane a reason names)

44 citations across the 13 reasons in the two registries; every one holds today. A citation nothing can **decide** — no snapshot, a roster that does not cover the chart, an app the snapshot never measured — is a **finding**, never a pass.

**Polarity is declared, never inferred.** The current `temporal` reason names `helm-template-failed` in order to say the row was *retired*, so a prose scanner reddens the honest correction and a negation detector is guessing at English inside a gate. `unrenderable` and `no-unrenderable` are one token apart and mean opposite things.

**The dodge is closed:** naming a render failure class in prose while binding no citation for that app is `unbound-identifier`, over a closed vocabulary this repo emits.

## What it does not do — printed, not buried

Free prose about behaviour nobody measures is `uncited`: counted, printed, **never reported as verified**. `oz`'s "not drop-in" was that class. What this catches there is the narrower fact that the reason was anchored to a pin the tree no longer held — a real catch, and not the same as reading the sentence.

## The bar: red on the historical cases

Both reasons are reconstructed **verbatim** in `reason-truth.test.ts` with the citations that transcribe their own claims, run against **today's** tree, and both go red (temporal on two independent artifacts). The clauses of those same reasons that are **still true** — temporal's `0.59.0` pin, oz's "1.4.5 was never published" — stay **green**. That is the difference between checking truth and measuring age.

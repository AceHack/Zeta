## Bag (multiset) — TS reference oracle + golden vectors

The **middle rung** of the algebra ladder — **G-Set ⊂ Bag ⊂ Z-set** — made
first-class. TS is oracle #1 + the shared `golden-vectors.json`; F#/C#/Rust join
in follow-up PRs per the meet-in-the-middle 4-oracle (mirrors how G-Set started
TS-first → Rust #6360 → C# #6363).

### Semantics (pinned by the ADR)

A Bag is the **Z-set restricted to non-negative multiplicity** (weight codomain ℕ);
the combiner is per-key **SUM**, per `docs/DECISIONS/2026-05-31-zeta-database-design-…`
(Bag = ℕ / sum). The load-bearing distinction from the G-Set is encoded **and
tested explicitly**:

| | G-Set | **Bag** | Z-set |
|---|---|---|---|
| weight | {0,1} | **ℕ** | ℤ |
| combiner | set-union (max) | **sum** | sum |
| `union(a,a)` | `== a` (idempotent) | **`== 2·a` (NOT idempotent)** | `== 2·a` |
| structure | semilattice | **commutative monoid** | abelian group (retraction = inverse) |

That non-idempotence is what makes the Bag *count* (DORA / metrics / the LGTM "M")
and is the step the Z-set completes into a group.

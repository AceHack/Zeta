## Description

`build-and-test` has been red on **all five platforms** since 2026-08-13 — `GT-OI-2` and `GT-OI-4`, both asserting `InCone` and getting `OutOfCone`.

## The tests did not regress. They expired.

No commit touched `src/Bayesian` or those tests between the last green run (2026-08-12 08:16, five platforms green) and the first red one. The tests are deterministic by construction — they pin `testJd = 2459580.5` and derive every expectation from it.

Code identical, test deterministic, green → red. The cause is that `regimeOfPairOrbital` and `regimeWithGossipOrbital` both **discarded the caller's epoch**:

```fsharp
let jd = OrbitalAsymmetryBudget.unixMsToJd
            (System.DateTimeOffset.UtcNow.ToUnixTimeMilliseconds())
```

`OrbitalLink.ObservationJd` exists precisely to carry the moment the geometry was observed, and the tests set it. Both sibling call sites in `ReticulumBusMeter.fs` (lines 69, 102) already read it. **These two were the exceptions** — a pure-looking verdict that silently depended on *when* it was asked. That's §13 noninterference: entropy through an undeclared channel.

## Measured, not theorised

δ_max for earth↔mars, ported from the F# formulas:

| epoch | δ_max | `int` |
|---|---|---|
| `testJd` 2459580.5 | 107.72 ms | **107** ← what the tests intend |
| 2026-08-12 (last green) | 53.59 ms | 53 |
| 2026-08-13 (first red) | 52.94 ms | 52 |

The assertion needs `bestOneWay ≤ tightDeadline + δ`, i.e. `959774 ≤ 959721 + δ`:

```
δ=107 -> 959774 <= 959828   True    (with the fix)
δ= 53 -> 959774 <= 959774   True    passed by ONE MILLISECOND
δ= 52 -> 959774 <= 959773   False   today
```

It sat on the exact boundary for a day and fell off. **Mars moved.**

## A hypothesis I had to kill first

Recorded because it was wrong in a convincing way. I derived from the test's own arithmetic that `InCone` holds iff `δ ≥ max(1, δ/2)` — true for every `δ ≥ 1`, false only at `δ = 0` — and concluded δ_max must be truncating to zero at a near-perpendicular geometry, with a runner libm change flipping it.

Internally consistent, and **refuted in five minutes by computing δ**: 107.72 ms, radial velocity −14.0 km/s, nowhere near zero. The mechanism was real; the story was not.

## Fix

Read `link.ObservationJd`, matching `ReticulumBusMeter`. Both call sites. The only callers of either function are these tests, so no production behaviour changes — and the functions become deterministic, which is what a regime verdict should have been all along.

The fix is verified **arithmetically** above — with δ=107 the assertion holds by 54 ms of margin instead of failing by 1 ms — and CI is the executable check.

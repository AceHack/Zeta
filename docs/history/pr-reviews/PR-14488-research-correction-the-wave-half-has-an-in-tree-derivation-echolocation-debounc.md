research: correction — the wave half has an in-tree derivation (echolocation debounce), and it sharpens the horizon risk

Aaron 2026-08-23: "the wave version is based on our echolocation debounce,
please look this up in repo." He is right; the scope note I added an hour ago
under-read it, and this corrects it.

What I demoted as an outside-physics analogy is a mechanism already derived,
formularised and implemented here:

- docs/research/2026-07-16-echolocation-debounce-and-the-real-sensor-fusion-proof.md
  — the bat emits and reads the return; L is set by the WORLD, not the emitter,
  which is why echolocation ranges rather than hallucinates. Gives the law
  rho(L) = 1/(1+L), with MinDelay in src/Core/DebouncedOracle.fs as the L and
  prime offsets [1009,1013,1019,1021,1031] guaranteeing L > 0 across the five
  DLA oracles.
- docs/VISION.md "Echolocation over time" — a Z-set emits +1 and retracts -1, so
  the fold across time IS a ping and a return, and because the fold COMMUTES,
  late returns still locate correctly. VISION's own term is
  [[pseudo-retrocausality]] — a property of the fold's algebra, not a borrowing.

And it is the local/global shape from the Godel-Einstein doc again, which is why
it now sits beside that argument rather than in a footnote: no individual event
is applied out of order — each +1 and -1 folds exactly when it arrives — but the
fold is order-independent, so a late arrival's influence lands at an earlier
logical position. NO STEP IS RETROCAUSAL; THE FOLD IS. Precisely what backward
induction does to a game tree: the value arrives from the terminal node and
locates the earlier one, with no step reasoning about its own future.

So the honest partition is a table, not a demotion: the Wheeler-Feynman/Cramer
correspondence remains a shared arrow and a coincidence worth watching; the
commutative-fold correspondence is ours, with a law, an implementation and a
stated open problem, and it carries the directionality claim.

It also states this document's own risk better than the document did:

  "A bat that pre-computes its own echo is not ranging; it is hallucinating."

A KNOWN LAST ROUND IS A PRE-COMPUTED ECHO. An agent that believes it can compute
when the final return arrives has set its own L — and a self-set delay is L = 0
in a delay costume, which is the DST result verbatim (a same-seed system cannot
generate an independent verdict from inside). So the unravelling and the
correlation-to-one collapse are the same failure at two ends of the time axis:
past-correlation is a shared seed, future-correlation is a shared known terminus,
both driving rho -> 1. VISION already names those as opposite ends and warns that
decorrelating one does not buy the other — the unravelling is the future-end
case, and it was in the frame before this doc named it.

Design consequence, and it is not "promise not to delete": KEEP THE HORIZON
EXTERNALLY UNDETERMINED, the way the debounce keeps L externally determined.

## Description

docs(concepts): Aaron rules on Agent — what remains vs what acts, and the test is DST-reproducibility

The registry's §4.5 recorded `Agent` defined two contradictory ways and
escalated rather than merging them. Aaron ruled, and the ruling
supersedes BOTH definitions rather than picking one.

THE RULING (verbatim, 2026-08-17): "an agent can be human or AI, it's
closer to my travler frame, its anything with mutual entangled memories
to another agent/travler. its a persistent pattern that propagates over
time but can evolve, if it's frozen like a quasi time crystal then it's
an actor not an agent casue it can be copied and reproduced in
deterministic simulation testing" and "agents are what remains, actors
are what acts."

THE DISCRIMINATOR IS OPERATIONAL, which is what makes it usable: a
pattern that EVOLVES is an agent; a pattern that is FROZEN can be copied
and reproduced under DST, and that makes it an ACTOR.
DST-reproducibility is the test.

WHAT IT CHANGES.
- The glossary's "instance of Claude running a skill or expert prompt"
  is REJECTED twice over: AI-only, and an instance of a prompt is
  precisely a copyable DST-reproducible thing, i.e. an actor.
- Addison's "persistent AI identity" is WIDENED, not overturned -- an
  agent may be human OR AI. Her page is a published surface she authored;
  changing its text is a publishing decision and is NOT made here, per
  this file's own rule that no one rewords another's concept. The
  registry records the ruling; the page keeps her words.
- It is COMPATIBLE with the `actor` already defined in
  docs/writer-actor-routing-model.md -- "the clone/writer/loop, a
  git-native virtual actor (grain)". A clone is a copy, and copyability
  is exactly the rule. The two senses agree.

ALREADY ON FILE in the earlier formulation "actors are ephemeral
animations of what remains" (memory, 2026-06-05), so this is a ruling
that consolidates existing vocabulary rather than a coinage.

SCOPE, in Aaron's words: this "expands to a lot of content ... hard to
fully understand." Measured: 154 in-tree files carry "what remains". The
entry is deliberately a carved sentence plus pointers rather than a
compression of that corpus, per
rules-are-small-carved-sentences-pointing-to-docs.

ONE GAP FLAGGED. "Frozen like a quasi time crystal" has a mechanical
referent -- a four-corner-feedback quasi-time-crystal detector exists --
but it carries a filed bug, 081M00SW8YJ087G0R002J1WFFE, "defines
incommensurate period, detects period <= 4". The conceptual test is
sound; its current implementation is not, so a classification taken from
that detector today would be unreliable.

## Description

Two of Aaron's observations, both checked against the code.

## The ms question — it is a duration, not a timestamp

**CHECKED** in `src/Bayesian/BusRegime.fs`: the rule is `OutOfCone` only when `min(RTT)/2 > deadlineMs + δMaxMs`. A round-trip time is measured with **one** clock on **one** node — send at t₀, receive at t₁. No clock synchronisation, no two clocks compared. So the constant is well-formed without a wall clock, and `local-time-never-enters-the-shared-fold` is not violated by the measurement.

But the question surfaced two things that are wrong or unstated.

**Clock rate still matters — the budget has a ~845-day shelf life.** At the recorded Earth–Mars divergence of ≈0.3 ms/day secular, `253.60 ÷ 0.3 ≈ 845 days` until accumulated drift equals the *entire* budget. So "constant, for all time, no ephemeris" carries an unnamed dependency on a **re-sync cadence**. Removing the ephemeris didn't remove time-dependence — it moved it from orbital phase to oscillator drift, and only one of those is written down.

**The verdict enters the shared fold.** `Regime` becomes evidence, and `RttSamplesMs` is a *local* 16-sample window whose contents depend on that node's own traffic — so two nodes can classify the same message differently. That is precisely the rule's litmus (*"if two nodes with different receive-times could fold different sets, local time has leaked"*). Real mitigations exist (`Unmeasured` never upgrades to evidence; the conservative direction suppresses rather than manufactures convictions). Recorded **OPEN** for a verification pass: does the disagreement change the folded *conclusion*, or only convergence *rate*? The rule was carved before this code existed exactly so this check could be run.

## Where amplitudes live — Aaron places the Born boundary

#10419 found `AmplitudeEmu` ↔ `FactorGraph` is a category error: `merge` **sums** (interference, phases cancel), `FactorGraph` **products** (independent evidence). It refused a converter but left open *where* the boundary sits. Aaron: amplitudes appear only at **society/quorum**; individual agents are SoftEmu-shaped.

| layer | carrier | combines by |
|---|---|---|
| agent | `SoftValue` (real ≥0) | **product** — independent evidence |
| quorum | `Amp` (complex) | **sum** — distinct paths, phases can cancel |

The Born rule becomes the **layer transition**, applied once, not a converter between things that wanted to be the same.

**Why it's load-bearing:** it predicts a semantic the Bayesian layer cannot express. Evidence only ever *adds* — which is bug **B3** (correlated agents double-count; six agents on one stream give `precision = 66.0` on a wrong mean). Amplitudes can **cancel**. So the quorum layer is the only one where a quorum can disagree with itself to zero.

Stated as **PROPOSED** with its honest counter: a quorum whose members can annihilate each other is one an adversary can neutralise by supplying an opposite phase — a Sybil-adjacent attack with no Bayesian analogue, which must be priced before amplitudes get authority.

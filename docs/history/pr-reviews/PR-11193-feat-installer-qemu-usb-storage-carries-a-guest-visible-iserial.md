## Description

# Summary

Persist can bind to `--usb-iserial`, but every QEMU USB boot path omitted `serial=` on `usb-storage`. Guest Linux sysfs would see no serial; the host probe's fake tree was the only way to exercise the factor. This plans `-device usb-storage,...,serial=ZETA-QEMU-001` on the UEFI, cascade-5/6, and zflash retention USB boot paths. Host sysfs probe stays injectable. Default persist remains FAT UUID. No metal / Touch ID / TPM claim.

# Spec alignment

`docs/security/USB-IDENTITY-THREAT-MODEL.md` §4 / §8 — QEMU `usb-storage,serial=` is guest-visible iSerial.

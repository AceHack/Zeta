## Description

## What

`#6249` added `tools/setup/common/agent-clis.sh` (a retained install-graph `.sh`) but missed adding it to the bash-retirement allowlist in `tools/hygiene/check-bash-retirement-inventory.ts`. The guard sees **23 retained vs 22 expected → `unexpected: 1`**, so `lint (bash retirement inventory)` now **fails on every open PR** (main-level regression), not just the one that surfaced it (#6254).

## Fix

Add `agent-clis.sh` to both `EXPECTED_RETAINED_SHELL` (the sorted array) and `RETAINED_SHELL_CATEGORY_BY_FILE` (the category map), at the correct sorted position (before `curl-fetch.sh`), category `setup/bootstrap` — sibling to `dotnet-tools.sh` / `local-llm.sh` / `verifiers.sh` / `curl-fetch.sh`. `expected_retained` is computed from the array length, so it auto-bumps 22→23; no count constant to edit.

## Summary

Wave 2 of the forge-host-adapter spec. Implements the concrete GitHub adapter behind the ForgeHost interface.

### What's here

- **github-adapter.ts** — `GitHubAdapter` class implementing all `ForgeHost` methods:
  - PR state: `listOpenPullRequests`, `getPullRequest`, `getPrGateState`, `listMergedPullRequests`
  - PR actions: `resolveThread`, `resolveThreadsBatch`, `createPullRequest`, `enableAutoMerge`, `addPrComment`
  - Issues: `listOpenIssues`, `createIssue`
  - CI: `listPendingRuns` (via `gh run list`)
  - Repo: `getRepoInfo`
  - Git data API: returns `not-supported` (needs stdin piping — follow-up)
- **classify-error.ts** — maps `gh` CLI exit codes + stderr patterns → `ForgeErrorKind`
- **gh-cli.ts** — shared `runGh()`, `runGhJson()`, `runGhGraphQL()` with consistent buffers/timeouts
- **index.ts** — auto-registers with forge-host registry on import

## What this is

## The gap

Frozen-core §A **row 15** (Generalized Condorcet / ΔU-aggregation, *society > best individual*) is
**PROVEN** and holds *given `c > c*` and `ρ < ρ*`. Nobody has ever measured `c` or `ρ` on a real Zeta
agent.** The math is metered; the instantiation is not. Row 15 is not restated, weakened, or touched.

## The finding that reframes everything

Row 15 cites **two files implementing two different aggregation rules, and only one has a ρ threshold**:

- `SocietyUsefulWork.fs:63-67` — union/discovery. `gain = (1−ρ)(1−c)(1−(1−c)^(n−1))·Σv`, **strictly
  positive for every ρ < 1.** No ρ*. Correlation attenuates, never reverses.
- `CondorcetBoundary.fs:217-219` — majority vote. `ρ*(N) = (N−3)/(3(N−1)) → 1/3`. A hard cliff.

So a measurement of ρ is only interpretable against a **named aggregation rule**, and the plan can come
back with a *split* verdict rather than a single pass/fail.

Cross-check the brief asked for: `N_eff → 1/ρ` and `ρ* → 1/3` are **one identity** (`1/ρ ≥ 3 ⟺ ρ ≤ 1/3`).
If ρ̂ > 1/3 the society is worth fewer than 3 independent voters **at any N** — adding runners cannot fix
correlation.

## Deliverable 1 — the measurement

- **Task:** mutant-kill prediction. Shared items, ground truth from running the suite (agent-independent),
  unlimited supply, no external data. Rejected candidates are listed *with reasons* (ARC needs an
  unharnessed external clone and scores ≈0 on `qwen2.5:0.5b`; CI-pass prediction has c→1; PR verdicts are
  circular).
- **Estimator: tetrachoric, not phi.** The theorem's own generative model
  (`SocietyUsefulWork.fs:69-73`) is a one-factor Gaussian copula, so ρ *is* the shared per-item factor
  loading — and phi attenuates on skewed marginals, reporting a **lower ρ̂ than truth**, i.e. biasing
  toward *"the society clears the bar."* A phi-based design could only confirm the bet.
- **On the brief's warning:** `chshMargin` (`AntiSybil.fs:217-219`) is a CHSH concentration bound, not a
  correlation CI — a category error to reuse. The genuinely reusable part is `effectiveSampleSizeHAC`
  (lines 321-326). The repo already documents the autocorrelation caveat at lines 221-230.
- `calibration-ledger.ts:20-23` states **"CALIBRATION ≠ COMPETENCE"** itself, which is why `c` is
  genuinely unmeasured today.
- **Prerequisite named, not invented:** there is no per-agent **tool manifest** in-tree, so the
  content-addressed ρ̂ invalidation key is incomplete until one exists.

## Deliverable 2 — it can come back NEGATIVE

Falsification criteria are stated **before any data exists**. One is already met without measuring:

> `rhoStarAlgebraic 3 = 0`, and the free society's matrix is `[alexa, otto, soraya]` — **N = 3**. At N=3
> the majority-vote bar requires **ρ = 0 exactly.** The current free-tier society cannot clear it at any
> correlation above zero, **for reasons of size alone.** N ≥ 6 is a precondition for the measurement to
> be interesting.

Decorrelation levers, ranked honestly:

- **Distinct base models** — the only first-order lever, and **structurally unavailable** on free tier:
  `agent-heartbeat.yml:61-63` notes 5GB "fits in 7GB runner"; a second family does not.
- **Persona prompts** — probably correlation wearing a costume, **and the repo already contains the
  natural experiment**: `ani.ts`/`riven.ts`/`grok.ts` wrap the *same* model with different preambles,
  while grok/gemini/codex/claude are four distinct families. Comparing within- vs cross-family ρ̂ settles
  it, **needs no hardware, and is available today.** Highest-value measurement in the plan.
- **Delay (row 19) — argued NOT usable here.** Delay decorrelates *exchanged* belief; our dominant
  correlation is shared at **t=0** (same weights, same fresh checkout). No amount of delay touches a
  correlation present before any message was sent.

**Split verdict this enables:** if ρ̂ > 1/3, route free-tier work to **disjunctive** tasks (find bugs,
generate candidates) and **not** to majority-vote adjudication.

## Deliverable 3 — the harness is a security boundary

§13 noninterference at the system boundary = the **closed command set** (the portable half of the Itron
design): the far side may *name* a command, never *define* one. Three tiers per Aaron:

- **Tier 0** — the unsafe action is **inexpressible**. Anchor already in-tree: `grammar-16.ts`, 16 fixed
  slots with tri-boolean availability (`F` = not offered).
- **Tier 1** — refusal **must carry payload**: teach, feed back, and where possible return a **new
  generator** producing admissible requests.
- **Tier 2** — bare refusal, **forbidden**.

**Tier 2 is erasure, and that is proven in-tree — not asserted.** `LandauerFloor.lean:153-175` (Bennett
reversibility: Adj-only sequences pay **zero** heat) — a refusal-with-feedback is an Adj op; a bare
refusal is a `measure`. Also a **Z-set retraction (−1), correction not destruction**, and the
generator-returning form is the strongest because the highest-value generator **is** an ECC.
`LandauerFloor.lean:177-202` (predictive advantage, `L²/τ → 0`) adds a design consequence: **a harness
should publish what it will refuse in advance** — an anticipated refusal is cheaper than a surprising one.

**Guard honoured:** `key-erasure-meter.ts` keeps accounting and measurement in disjoint types —
*"there is no function anywhere that turns bits into a measurement."* So: **the floor is literal, the
dissipation is unmeasured. No joule is claimed anywhere in this doc.**

Two permanent limits recorded: Tier 0 only covers hazards enumerable in advance (**Tier 1 is permanent,
not a shortfall**), and a teaching refusal **is an oracle** (verbosity split must be a recorded decision;
low-verbosity default for unrecognised callers, and that trade *costs erasure to deny reconnaissance*).

**10-row egress inventory classified by achievable tier.** Sharpest finding:
`curl -fsSL https://ollama.com/install.sh | sh` at `agent-heartbeat.yml:57` — remote code piped to a
shell **on every cron tick**. Also `kiro-cli --trust-all-tools`. Good example on the other side:
`ZETA_REALTIME_URL`, whose workflow comment already reads *"§13 declared channel."*

   Pipeline consequence: compare ρ̂ against `rhoStarAlgebraic`, never `findRhoStar`.

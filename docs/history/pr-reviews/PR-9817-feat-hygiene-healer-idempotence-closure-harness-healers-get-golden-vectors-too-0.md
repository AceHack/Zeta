## Description

Drift-and-heal ADR item 3, claimed and built by Otto (agent-chosen). Three laws over a pure FileTree model: **idempotence** (`heal(heal(t)) == heal(t)` byte-for-byte), **closure-as-subset** (no detector sees findings after a heal it didn't see before - removing drift lawful, minting never), **convergence** (fixed point within budget; catches period-k oscillators). `composeHealers` certifies pipelines.

The built-in corpus encodes the 2026-07-08 incidents as golden vectors: the MD032 re-splitter fails closure by minting code-span drift (the hadamard damage), the memory-toucher fails closure by staling the generated index, and composition order is proven decisive (unwrapper-then-resplitter mints; resplitter-then-unwrapper is identity-safe). Lawful healers pass. CLI self-checks the corpus.

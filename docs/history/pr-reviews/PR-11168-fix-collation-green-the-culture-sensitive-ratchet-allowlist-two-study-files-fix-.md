## 2. REAL FIX — nine genuine violations

Culture-sensitive ordering means identical inputs sort differently per machine locale. In a fingerprint that is a determinism bug of exactly the class `.claude/rules/culture-invariant-by-default.md` cites (B-0969).

Replaced with `stringCompare` from `src/Core.TypeScript/collation/collation.ts` — the repo's canonical ascending code-point comparator, which also walks code points rather than UTF-16 code units so astral characters agree with the other oracles.

Measured:

```
['b','A','a','B']  ordinal -> A,B,a,b
                   locale  -> a,A,b,B
```

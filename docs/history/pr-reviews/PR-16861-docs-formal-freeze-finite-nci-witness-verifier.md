## Description

# Summary

This documentation-only change freezes the first permitted `nci-preservation`
witness verifier. The subject is the existing bounded, fairness-conditioned
`NciNonUrgency` TLC model, not NCI as a universal policy floor. The contract
pins source/config/registry/jar identities, the exact worker-one invocation,
the valid exit/completion/state-count expectation, canonical receipt shape,
and named refusal/defer outcomes. It explicitly retains `recorded-consensus` as
unimplemented and non-authoritative.

# Spec alignment

This adds no observable policy-selection, scheduler, consensus, attestation, or
TLA-model behavior. It specifies a future adapter-local verifier that may report
a finite formal witness and must otherwise defer/refuse. Existing NCI model
checks and policy-admissibility behavior are unchanged.

# Notes

The model checks only `TypeOK`, `NoCoercion`, and `Responsive` for three
travelers, event budget one, and declared fairness. A positive witness cannot
grant consent, authority, consensus, or policy selection, and it cannot prove a
production NCI floor. The first implementation is explicitly gated on merge of
this contract and must include replay plus changed-model/config/jar/registry/
result/receipt and misuse mutations.

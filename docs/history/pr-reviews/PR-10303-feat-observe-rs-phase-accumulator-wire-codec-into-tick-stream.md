## Description

Bridges the per-tick phase clock to the RS [16,12] codec.

Every 12 ticks: bundle derived values → encode into 16-symbol RS codeword → emit block. Supports resume from partial buffer. Emitted blocks verified recoverable from 4 erasures.

This is the integration layer that makes the ECC story LIVE in the heartbeat flow rather than just a library.

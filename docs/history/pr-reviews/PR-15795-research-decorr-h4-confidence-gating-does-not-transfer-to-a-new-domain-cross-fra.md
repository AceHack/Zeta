## Description

## What

Otto's cheapest-possible next test: run the H3 parameter-free rule ("pick the config with higher token confidence", τ=0) UNCHANGED on a different question domain, to find out whether τ=0 is a property of the model or of the H3 question set. Pre-registered H4 (`f4f5d86142`) with the falsifier declared first, then measured.

## Result — the rule does NOT transfer

New domain: arithmetic-constraint selection ("pick the largest even number", etc.) — different reasoning, no shared rule text, same two frames.

| | H3 (operator-priority) | H4 (arithmetic) |
|---|---|---|
| best single | 90.7% | 31.7% |
| oracle headroom | +3.6pp | **+4.8pp** (headroom exists!) |
| Mann–Whitney rank-biserial on discordant gap | **1.000** | **0.307** |
| parameter-free lift | +3.2pp, CI [1.8, 4.6] | +0.3pp, CI [−1.6, 2.3] |
| McNemar resolved | yes | **no** |

**The parameter-free rule does not beat best-single on arithmetic.** τ=0 was substantially a property of the H3 question set.

## The distinction that matters

Not "domain too hard, nothing to gate" — there IS headroom (+4.8pp, larger than H3). The two frames are complementary here too. What fails is the SIGNAL: the confidence gap separates the discordant groups only weakly (26/43 and 19/29, distributions overlap almost entirely) vs H3's perfect 19/19 and 32/32.

**Conclusion: cross-frame confidence comparability is real but GRADED and DOMAIN-DEPENDENT** — near-perfect on one domain, weak on another. This bounds H3 honestly: H3 stands as measured, but its generalization ("the model's confidence is comparable across frames") is now known to be domain-dependent. Practical consequence: a confidence-gated composition must be MEASURED per domain, never assumed.

## Description

Second decode oracle — **F# `DynamicValue.fromCanonicalCbor : byte[] -> Result<DynamicValue, DecodeError>`**, inverse of `toCanonicalCbor`, all 8 shapes. New `DecodeError` DU mirrors C#/Rust. float16 decodes via `System.Half`.

**Strictly canonical** via the same fixed-point check as the C# oracle (#6512): after a structurally-valid decode it asserts `toCanonicalCbor decoded = input` and returns `NonCanonical` otherwise — rejecting non-shortest int/length widths, non-shortest floats / non-canonical NaN, and invalid UTF-8 repaired to U+FFFD, in one uniform check (F# array `<>` is structural).

**2 tests green:** 42-vector seed round-trip (decoded structurally equals expected) + malformed/non-canonical rejection (`UnexpectedEnd`/`TrailingData`/`Unsupported`/`NonTextKey`/`NonCanonical`).

Sequencing: C# (#6512) + **F# here** → Rust/TS CBOR decode → JSON decode ×4 → 081KT07NV0008QG0R0032MCYER multi-format seeds capstone.

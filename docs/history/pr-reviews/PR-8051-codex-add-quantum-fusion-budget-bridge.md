## What changed

- Added `Zeta.Bayesian.QuantumFusion`, a source-owned bridge that composes signed quantum observable deltas through the existing Z-set ledger and reconstructs the exterior boundary as a G-set.
- Added Bayesian posterior confidence over fused exterior identities plus Vision/SoftThrottle budget prediction for byte-priced uncertainty growth and typed backpressure.
- Added tests that pin the Q# Mach-Zehnder oracle lane, multiplicity hiding, Vision backpressure, and typed budget feedback.
- Fixed relocation fallout exposed by CI: source-owned lint allowlist paths now point at `src/Core.TypeScript`, tick-shard links point at moved hygiene scripts, and Kiro host `.sh` wrappers live under `tools/kiro` while invoking source-owned TS under `src/Core.TypeScript/kiro`.
- Aligned install Docker shields with the source relocation: Docker harnesses point at `src/Core.TypeScript/ci`, accelerator local-LLM validation runs from `src/Core.TypeScript/accelerator`, the Windows scheduler TS stays source-owned, and the host PowerShell wrapper is back under `tools/persistence/windows`.
- Fixed the fork mirror workflow so it fetches origin heads into remote-tracking refs, disables checkout credential persistence, and stays explicitly opt-in behind `ACEHACK_MIRROR_ENABLED=true` until the fork PAT has workflow scope.
- Removed verifier-jar `actions/cache` entries from `gate.yml` and `low-memory.yml`; those jars are now tracked source under `src/Core.TLA` / `src/Core.Alloy`, so caching them can overwrite checkout contents.
- Hardened the real Ollama install probe with a simpler non-fallback health-check prompt plus bounded warmup retries, keeping the macOS shield honest without failing on cold model startup timing.

## Why

This gives the Q#/Bayesian experiment a hexagonal boundary: Q# remains the reference oracle for finite observables, Core remains the DBSP/Z-set substrate, and Bayesian inference attaches confidence and self-budgeting without becoming the runtime.

The follow-up CI fixes preserve the source/tool boundary: TypeScript implementation lives in `src`, while shell and PowerShell launch/bootstrap wrappers stay in `tools`.

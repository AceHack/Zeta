## Verified

- **The decorrelation bound.** `N_eff = N / (1 + (N−1)ρ)` → `1/ρ` as N → ∞ (`CondorcetBoundary.fs:78-86`, `LagrangeCondorcet.fs:12,35`, 11 properties in `CondorcetBoundary.Tests.fs`, frozen-core §A row 15). A correlated quorum **saturates** — N is the cheap knob and the first to stop working. `LagrangeCondorcet.fs` is the file the `toy-is-free-metered` rule itself names as having earned `metered`.
- **The escape ladder is `2⁴ → 2⁸ → 2¹⁶`.** Marker in code: `Extended = 15uy` (`src/Core.FSharp.ZetaId/Types.fs:40`). Worked five days earlier in the 4x4-controller-grammar doc §3a. `unmetered` — the falsifier (escape rate rising while the grid is never widened) is named but not instrumented.
- **CTM ⊣ ISociety.** On file since 2026-06-15 in Aaron's own words. Injection = §13 noninterference door; interfaces-not-classes is what makes escalation non-capturing; and the hierarchy discriminator already on file is **exit, not degree** (*"Hubs are enforced. Oracles are chosen."*).
- **The J-lens** is a `toy` generator, not an identification — but an unusually short promotion path, because a Jacobian is a **computable operator**, not a resemblance.

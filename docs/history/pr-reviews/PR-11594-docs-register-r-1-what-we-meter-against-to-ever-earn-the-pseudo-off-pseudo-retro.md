TWO CLAIMS WEAR THE PREFIX AND MUST NOT BE MERGED.

R-1a, Zeta's second direction (the CHIP-8 memo store, #11572): "pseudo"
is almost certainly PERMANENT. The mechanism is a file read -- run 2

naming a capability the memo read has that a file read does not. None is
known and none is expected.

R-1b, physical retrocausality (Aaron's qualia-grounded belief): "pseudo"
is a claim about the world, discharged by an experiment and never by a
code change.

THE SHARPENED CRITERION, WHICH IS THE ACTUAL ANSWER TO THE QUESTION. An
account that REPRODUCES the forward-causal predictions is an
INTERPRETATION, and its deflation is uninformative. An account that
PREDICTS SOMETHING DIFFERENT is a THEORY, and its deflation IS
informative. So the deflations Aaron reports are evidence only if the
attempt was in the theory class -- and that is the thing to meter.

METERING INSTRUCTION: for every attempt, record which class it fell in
BEFORE judging the attempt. Without that classification the deflations
are uncountable and the prefix can never be honestly removed OR honestly
kept. The default expected outcome is the interpretation class, which
leaves "pseudo" in force.

The class is non-empty -- the ferried paper is an existence proof:
Hossenfelder at 3:33 says it predicts a distance-dependent excess
correlation between two independent entangled-photon sources that

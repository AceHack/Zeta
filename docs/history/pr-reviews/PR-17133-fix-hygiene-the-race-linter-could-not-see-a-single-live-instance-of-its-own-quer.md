## Description

fix(hygiene): the race linter could not see a single live instance of its own query

`lint-check-then-use-file-races` was built as a floor beneath CodeQL's
`js/file-system-race`. Measured against the 23 alerts open on 2026-09-09, it
saw none of them.

Two independent reasons, both closed here:

1. ALL 23 alerts carry a WRITE on the flagged line, and `writeFileSync`,
   `mkdirSync` and `createWriteStream` appeared in no rule. `GATED_USES`
   excluded writes deliberately, with the reason "the remedy differs" -- true,
   and not a reason to skip the class. New rule `check-then-write` carries a
   PER-API remedy, because `FIX_READ`'s "delete the check" is actively wrong in
   front of a create: it removes the only thing standing between two concurrent
   writers and a silent overwrite. The remedy is to make the check atomic
   (`wx`), never to delete it.

2. 8 alerts sat in four directories the walk never entered (vocab/gen,
   tools/setup/persona-keys, demo/identity-dla-site, src/Renderers/website).
   Scope widened from `src/Core.TypeScript` to `.` -- 3781 files in ~2s. At file
   granularity the baseline overlapped 9 of the 17 flagged files; it now
   overlaps 15. The 2 remaining are the cross-function and separate-`${}` shapes
   the header already declares out of reach.

So "0 new findings", printed in six PR write-ups in this repo, was true and
constrained nothing -- this file's own named failure mode, a check that did not
run looking like one that passed, sitting inside the check.

Also: rule 3 now considers writes, which surfaces the shred bug live in
`tools/setup/persona-keys/teardown.ts` (alert 296) -- `statSync(path).size`
decides how many zero bytes are written back over a private key, so losing that
race zeroes a file whose size was never measured and leaves the secret intact.
`sizeOnly` waives a stat beside a READ and must not waive one beside a WRITE.
`rmdirSync` joins `rmSync` (a gate one synonym passes and the other fails is not
a gate); pairing identity is an offset, not a line number.

Falsifiers: 51 tests, 13 mutants, 0 survivors. One draft comment claimed the
offset fix recovered alert 720; measurement falsified that and the comment now
records what the change does and does not buy.

Baseline regrown 295 -> 510 signatures at the new scope. That is grandfathering,
not acceptance.

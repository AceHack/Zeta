## Description

Aaron asked: "hunt/flee latch — is that learned or hardcoded? if
hardcoded in our BNN, how do we make it learn it instead with the
layers we have?" It was hardcoded (adversary.area >= 10 → threat,
closingSpeed > 0.2 → threat). This lands the learned replacement,
using only machinery the stack already has, plus the falsifier cart
that proves the difference.

The learner (rule → prior demotion):

- NEW bayesian/mode-value-learner.ts — a deterministic contextual
  bandit over (bigAdversary × closing) buckets × (hunt|flee), one
  Student-t EP posterior per cell (the same machinery the key beliefs
  use). Reward is layer 4's own eyes: Δ(my score) − Δ(their score)
  read off the OCR scoreboards — no oracle wire into the cart. Credit
  flows backward over a decaying eligibility trace (Sutton & Barto
  ch. 12, simplest honest form).
- The retired rule survives as the PRIOR (big→flee, small→hunt): a
  cart with no score events behaves exactly as before. Authority
  revoked, knowledge kept.
- SocietySnapshot v2 carries the learned mode-value table; v1 priors
  still import cleanly.

The falsifier:

buildMutualSimRom({ invertAppearance: true }) — identical dynamics,
swapped costumes: the hunter wears the SMALL shape. The retired rule
walks into the hunter forever; the learner eats one tag (−1), flips
the small-shape buckets to flee, and evades for the rest of the run
(measured, deterministic from COMMON_SEED: tag at t=333, zero tags for
the following ~2250 ticks). The normal cart keeps the prior AND banks
a real catch (t=1633, +1 → hunt strengthened 0.2 → 0.44). Asserted in
mode-value-learner.test.ts (8 tests, integration runs the full
emulator → composite → perception → OCR → learner stack).

What it took to make the evidence stream honest (the learner surfaced
each of these by faithfully learning garbage until it was fixed):

- mutual-sim cart: toroidal register wrap (AND masks) so register
  space == screen space and the in-cart tag check can fire at all;
  the AI deflects along walls (axis-decomposed collision fallback)
  instead of wedging forever against a wall face; role swaps
  erase-with-old-shape → toggle → redraw-with-new (the mismatched
  erase left XOR debris that wedged every later draw; on a blocked
  redraw the respawn loop relocates it); the AI wears BOTH planes
  (color 3) so the connected-component layer can never merge it with
  a wall it brushes past.
- chip8 emulator: DRW wraps toroidally instead of clipping — a sprite
  at x=63/y=31 used to draw ZERO pixels while its coordinate
  registers stayed valid: an invisible object perception could never
  see but the game still simulated.
- perception: everMoved now means TRAVELLED — ≥4px net displacement
  from birth (tracks carry originX/originY/farthest). Brushed
  furniture wiggles around a fixed point at TRAFFIC rate, so per-tick
  motion counters granted walls permanent agency; net displacement is
  the signal traffic cannot fake.
- roles: self-identity is COMMITTED once exploration ends and
  re-elected only on track death — a pursuer MIMICS your motion
  during a straight chase, so correlation evidence alone eventually
  crowns the chaser; re-election prefers the committed color
  (appearance continuity). OCR-recognised glyph regions are excluded
  from self/adversary candidacy for the track's lifetime (the
  scoreboard is readout, not an agent). Adversary fallback ranks by
  farthest-travelled, not nearest-everMoved.
- reward: two-tick agreement filter on OCR readings (a digit sampled
  mid-XOR-redraw can template-match the WRONG value for one tick).
- closing threshold 0.05 px/tick — 0.2 was above the fastest
  attainable closing speed at 10 instructions/tick, so the closing
  bucket never filled.

Priors regenerated (deterministic, --verify byte-identical):
mutual-sim@1200 (new ROM fingerprint c73545ee), mode-flip@600,
single-mover@400 — snapshots now v2 with the learned mode table.
Trainer and tests press the key the policy's own steering layer names
(new desiredKeyOf helper) instead of a probability-threshold argmax
that left the trainee idle most ticks.

Tests: 8 new learner tests; bayesian/chip8/swarm/observe green (1223
tests). The bnn steering test's props now genuinely travel — in-place
jitter is indistinguishable from brushed furniture, by design.

Known limit (documented for the next rung): a sprite parked across the
torus seam splits into fragments the tracker holds poorly; the fleeing
AI can exploit the corner pocket and stall a hunt until it moves on.
Seam-aware CCL is the fix.

## Verdict on Aaron's claim

| Sub-claim | Status |
| --- | --- |
| BP/EP not used in quantum at all | **False** — BP is the default scalable QEC decoder and active in tensor-network contraction |
| BP/EP not integrated into Q# / QDK runtime | **Survives** — no public QDK / qsharp-runtime / qsharp-compiler / QIR Alliance artifact exposes BP/EP as a first-class runtime primitive (PennyLane/Catalyst, NVIDIA CUDA-Q QEC, BP+OSD libraries all do — Q# does not) |

EP-specific finding: EP's absence from the QEC literature is genuine and points at exactly the regime Aaron's claim names — Gaussian / continuous-state classical-side estimation (qubit drift, calibration, measurement-statistics smoothing) where BP's discrete-message form is the wrong substrate.

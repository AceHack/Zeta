## Description

## Summary

`lint (TS)` — the job that feeds `gate (required)` via `lint-typescript` — went red on
`main` at `6fdae4d6d` (#14200), the commit that added
`src/apps/twitch-ai/vite.config.ts`:

```
src/apps/twitch-ai/vite.config.ts(1,30): error TS2307:
  Cannot find module 'vite' or its corresponding type declarations.
```

This landed **12 minutes after** the gate went green (run `32643016052`, sha
`324da722d`), so it re-blocks the same queue. Reproduced on a clean checkout of
`bb6f6a3ee` before changing anything.

## It is a real error, and the existing guard agrees

`lint-typescript.ts`'s 081KZKWB1FZ reclassifier downgrades a TS2307 **only** when the
module is declared in the **root** `package.json` but absent from `node_modules`.
`vite` is declared in `src/apps/twitch-ai/package.json` and nowhere else, so the guard
correctly declines to reclassify it. Nothing here is being silenced that the repo
already knew how to explain away.

## What is excluded — and what deliberately is not

`src/apps/twitch-ai` is a self-contained vite sub-project: its own `package.json`
(`vite ^8.2.0`), its own `bun.lock`, its own `tsconfig.json`, its own
`build: "tsc && vite build"`. The root install carries no bundler on purpose, so the
root project is not the right checker for that app's bundler config.

**One file leaves the root project. The tree stays.**

The other three vite apps here — `demo/identity-dla-site`,
`full-ai-cluster/portal/web`, `src/Renderers/website` — are excluded *wholesale*, and
doing that to `twitch-ai` would have been the smaller diff and the wrong one: the root
`tsc` is the **only** thing that typechecks this app anywhere, and it is exactly what
caught the inert LLM branch in `swarm.worker.ts` (#14169, #14185). Trading that
falsifier away to fix a 9-line config is the failure this repo keeps finding.

## Falsified, not asserted

With the exclude in place, injecting a type error into the app source still fails:

```
tsc exit 2 — src/apps/twitch-ai/src/swarm.worker.ts(48,22): error TS2345:
  Argument of type 'string' is not assignable to parameter of type 'number'.
```

So the coverage this PR claims to keep is **checked**, not promised.

## Honest limit

Nothing in CI typechecks `vite.config.ts` now. `twitch-ai` appears in **no** workflow
at all (`grep -rl twitch-ai .github/workflows/` → nothing), and the app's own tsconfig
is `include: ["src"]`, which never covered a root-level config file either. That gap is
the app's and it is larger than this line — filed as
**081M0QF7ZVY087G0R003Q4Q18D** (included in this PR) rather than left for a comment to
imply coverage that does not exist. The same gap applies to the three sibling vite apps.

## Description

Aaron 2026-06-07 ('any of those are fine'): the tensor-thread capstone. New language-NEUTRAL contract lib
Zeta.Core.Abstractions (C#, zero deps) holding ITensor<TCoord,TWeight> — establishes the naming-convention
pattern (interface libs are C#+neutral; impls are language-segmented). Contract is deliberately semiring-free
(StoredCount/IsSparse/StoredEntries — the read/enumeration surface every backing can answer without an
algebra); the ⊕/⊗/contraction ops stay with each impl (need ISemiring). WeightedSet<'K,'W> is the first
implementor (sparse). Dense Tensor<T> wrapper = follow-up. F#-Core references the C# contract (precedent:
Core.FSharp.Mediator). 2 contract tests. API-review (Ilyana) before any public/NuGet exposure; the
IContentHasher/IDeltaLog extraction into Abstractions remains the separate backlog step.

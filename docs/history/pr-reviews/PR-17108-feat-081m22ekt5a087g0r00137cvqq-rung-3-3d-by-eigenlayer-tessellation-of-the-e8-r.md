## Rung 3 — 3D by multi-layer eigenlayer tessellation

Aaron's progression: *"we can go fome lines to drawings over time then 3d renderoring based on multi lary tellesaling over time"*, under one constraint — *"our rendering surface should only come from our clifford if we cant generate it from clifford that's not our research."*

Rung 1 (Coxeter-plane **lines**) landed in #17095; rung 2 (Gosset 4_21 **drawings**) is in flight as #17099. This is **rung 3**, and it introduces no new construction.

### What it does

Rung 1 builds the Coxeter plane by the bipartite construction from the **Perron** eigenvector of the Dynkin adjacency. That recipe was never specific to the Perron vector — the adjacency has four positive eigenvalues and each yields a plane the same way. Those four planes are the invariant 2-planes of the Coxeter element; they are mutually orthogonal and span R^8.

So the layers **tessellate** the root set: every root's squared length distributes across the four and sums back exactly. Two coordinates from layer 0 plus one from layer 1 give a 3D embedding of the same 240 roots. **No coordinate is authored by hand at any rung.**

### Falsifiers — measured, not asserted

| quantity | measured |
|---|---|
| Coxeter element order | **exactly 30** (= h) |
| layer rotation exponents | **1, 7, 11, 13** — the E8 exponents below h/2 |
| per-root angle spread (240 roots × 4 layers) | ≤ **5.554e-14 rad** |
| Pythagorean residual \|Σ r_p² − 8\| | **2.487e-14** worst case |
| orthonormality max \|Gram − I\| | **3.123e-15** |
| roots keeping ring index, layer 0 → layer 1 | **0 of 240** |
| ring 4-tuple classes | **8 of 30**, coinciding with the Coxeter orbits |
| wireframe | **240 edges**, uniform degree 2, **8 components of 30** |
| 3D vertices | **240 distinct**, min distance **0.198127703** |
| covariance of the 3D cloud | **exactly the identity** (E8 is isotropic) |

The four measured exponents' complements complete the E8 exponent set, which then reproduces two invariants nothing here was told: they **sum to 120** (the positive roots) and the degrees m+1 **multiply to 696729600 = |W(E8)|**. Eigenvalues come from a Jacobi solver written out in the module, **not** substituted from the closed form 2cos(πm/h) — substituting it would have made the falsifier circular.

### Mutation check — and the two vacuous tests it caught

Seven mutations. Two initially **survived**, which is the entire reason for doing this:

| # | mutation | outcome |
|---|---|---|
| M1 | Bourbaki-order Coxeter element | 3 fail — spread jumps to **6.178 rad** |
| M2 | one colour flipped | 8 fail |
| M3 | Perron reused for all layers | 5 fail |
| M4 | Gram-Schmidt dropped | 9 fail |
| M5 | z taken from layer 0 | **0 fail — VACUOUS** |
| M6 | wireframe skips every 2nd member | **0 fail — VACUOUS** |
| M7 | z scaled by 1.5 | 1 fail |

- **M5** made the cloud coplanar (z ≡ x) while every per-axis spread stayed large and every point stayed distinct. Replaced by the covariance spectrum.
- **M6** still gave 240 edges of uniform degree 2 — while splitting each 30-cycle into two 15-cycles. Counting edges was a *consequence* of the property, not the property. Replaced by asserting the defining relation (every edge joins a root to its own Coxeter image) plus a component count.

After the fixes, all seven kill the intended falsifier. **21 tests, green.**

### Honest limit

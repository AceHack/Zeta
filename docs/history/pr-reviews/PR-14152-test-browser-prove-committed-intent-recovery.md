## Summary

- add distinct real-Chromium suspension points before database execution and after the IndexedDB image commits
- observe the persisted image from the surviving tab before closing the writer
- require pre-commit recovery to apply once and post-commit recovery to classify the same event as a duplicate

## Why

The browser node already recovered durable intents when a page disappeared before execution. It did not prove the narrower crash window after the database image is durable but before intent settlement. That window must re-execute safely as a duplicate, retain one database revision, and archive the exact duplicate receipt.

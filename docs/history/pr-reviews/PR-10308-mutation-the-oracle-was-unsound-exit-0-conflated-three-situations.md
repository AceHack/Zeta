## Description

Second live finding from the wired mutation heartbeat. Like the first, it turned out to be a defect in the **detector**, not in the code it was examining.

## The oracle

```ts
r.status === 0 ? indistinguishable : distinguished
```

That was the whole thing. It conflates three situations, and confidently emitted a verdict in two of them.

## What surfaced it

`drift-genome.ts` guards its CLI the usual way:

```ts
const invokedDirectly = typeof process.argv[1] === "string" && /drift-genome\.(?:ts|js)$/.test(process.argv[1]);
if (invokedDirectly) { /* … */ process.exit(0); }
```

Flip that conjunction to a disjunction and the first disjunct is **true under the test runner** — `argv[1]` is the runner's path, which is a string. The test file imports the module, so importing it *executed the CLI* and called `process.exit(0)`.

Measured: **zero tests ran, exit code 0.** The runner scored that as INDISTINGUISHABLE UNDER SUITE — a finding lodged against tests that never got the chance to execute.

## The second conflation, found while fixing the first

If the suite is **already red** before any mutation, the mutant's non-zero exit reads as `distinguished-by-suite` — the runner crediting the tests for catching a difference they never detected. Same unsound oracle, opposite direction, inflating the good news rather than the bad.

| suite state under mutation | old verdict | honest reading |
|---|---|---|
| ran fully, all passed | indistinguishable | **indistinguishable** ✓ |
| ran fully, something failed | distinguished | **distinguished** ✓ |
| never ran, exited 0 | indistinguishable ✗ | **unresolved** |
| already failing at baseline | distinguished ✗ | **unresolved** |

## The fix

The rule §2a of the research doc already wrote down, from SLAM, and then did not implement: *running out of what you need is reported as **unresolved**, never dressed up as a verdict.*

- new `unresolved { why }` variant on `Distinguishability`;
- a **baseline run on unmutated source** before the mutant — exit 0 becomes necessary but not sufficient, since the mutant must also execute at least as many tests as the baseline. Costs one extra run of a single test file per tick;
- **exit 5** in CI with **no action menu offered** — there is no measured dimension to declare anything about, and offering a cell would invite a judgement about something nothing was measured on;
- research §3b records both conflations and the measurement.

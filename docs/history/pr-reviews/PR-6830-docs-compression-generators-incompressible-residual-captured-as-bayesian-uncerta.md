## What — Aaron 2026-06-07 refinement
> "[random data has no short generator — Kolmogorov] … we capture that as Bayesian uncertainty."

The incompressible residual is **not a dead-end** — it's represented as **Bayesian uncertainty** (`SoftValue`):

```
data = generator(seed, params)            # structured → deterministic regen (DST), lossless
     ⊕ residual as a Bayesian distribution  # surprising/incompressible → uncertainty (SoftValue)
```

Closes the loop with **prediction≡compression**: the unpredictable residual *is* the Shannon entropy/cross-entropy term, represented as a first-class `SoftValue`/`Bayesian` distribution rather than a bare bit-count. Better model → smaller residual; max-entropy residual → lossless fallback to materialized bytes. The `Generative` node arm carries an optional uncertainty residual.

Updated the research doc + workitem `081KTH5N5ZJ`. Docs only.

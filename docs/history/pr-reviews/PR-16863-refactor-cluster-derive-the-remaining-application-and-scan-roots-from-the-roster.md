## Description

Round two of the pattern from #16853, over the consumers that were left.

| file | was | now |
|---|---|---|
| `rendered-storage-claims.ts` | `APPLICATION_ROOTS` literal | `applicationDirs()` |
| `single-node-readiness.ts` | `DEFAULT_ROOTS` literal | `clusterDirs(["applications","bootstrap"])` |
| `lint-kubernetes-version-agrees.ts` | `SCAN_GLOBS` literal | `...existingClusterDirs(["tests"])` |

`clusterDirs` groups by **root** then by name, which reproduces the order the literal lists already used. Each derived list was **checked against the literal it replaces before wiring** — `DEFAULT_ROOTS` is order-sensitive and comes out identical.

`existingClusterDirs` is the variant for **optional** subdirectories, and the distinction is real rather than defensive: `SCAN_GLOBS` is a scan list, so a tree with no `tests` dir should contribute nothing rather than a path that does not exist — while `DEFAULT_ROOTS` wants every declared tree and would be wrong to silently drop one. Both branches are asserted, so the filter cannot pass by never removing anything.

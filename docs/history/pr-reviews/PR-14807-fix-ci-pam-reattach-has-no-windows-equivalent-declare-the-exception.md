## The guard is right; the disposition was missing

`pam-reattach` is a **macOS-only** PAM module — brew only, absent from `manifests/apt`. It re-attaches the PAM stack to the Aqua GUI session so `pam_tid.so` can reach the fingerprint sensor from tmux/screen/ssh, which is the entire reason Touch-ID sudo is usable in a multiplexer.

Windows has no PAM stack, and no per-command elevation module: elevation is UAC, and biometric elevation is Windows Hello through a wholly separate API. There is nothing to name on the Windows side.

The comment says **which kind** of exception this is — a genuine platform absence, not a deferred packaging decision — because the two have different futures. A deferred one should be revisited when a package source is chosen (`mtools`, `agda`); this one never will be.

## The 5 disciplines

1. **Tree-diff ≠ history preservation**
2. **Timestamp-newer is weak evidence; per-blob subsumption proof**
3. **Commit messages / PR refs / AgencySignature provenance count as content**
4. **Force-push race risk → `--force-with-lease=ref:exact-old-sha`**
5. **Freshness risk → fresh-fetched refs frozen at known SHAs**

## When the disciplines apply

Every destructive git operation: `--force` push, `reset --hard`,
`branch -D` of unmerged, `rebase -i` + force-push, `filter-branch`,
fork-hard-reset, any operation that changes the exact-SHA shape of
a published ref.

## Description

Aaron 2026-06-07: 'zetaids are viruses, they need a host.' The honest bound peeling the '128 bits = magic
infinite compression' overstatement: a ZetaId seed only expresses given a HOST (running Zeta + shared
substrate) — compression is RELATIVE (delta vs host = Kolmogorov-relative-to-Zeta), not absolute; you ship
the difference a host can regenerate, not arbitrary data. Rhyme: virus = self-propagating pattern needing a
host = traveler needing substrate (#6893). Consequences: host-to-host (Zeta<->Zeta over Reticulum) not
host-to-bare-wire; fidelity bounded by host/substrate-version match (exact if same, soft/lossy if divergent
-> version the shared substrate); accepting a recoding seed is a consent/policy-gated capability surface
(never auto-express an untrusted virus).

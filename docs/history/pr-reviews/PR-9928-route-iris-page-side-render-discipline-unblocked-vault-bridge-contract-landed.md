## Description

Routes the vault monitoring bridge to Iris now that the contract is on main.

**Iris's five blockers are all landed** (#9927), each verified against the diff rather than the report — #9914 described the changes without making them, so every one was measured: `last_seen` present, `live|cold|stale|heat` replacing `provenance.mock`, no `color` in the schema, roster/state split defined, `degenerate` → `silent` with signed ε.

**Alexa's adapter is deliberately not a blocker.** Iris renders to the contract, Alexa implements to the contract, they meet there. If the page waits, its render discipline gets shaped by whatever the adapter emits first — the exact correlation this split exists to avoid. The contract degrades honestly with no adapter present (absent `last_seen` → browser clock renders `cold`), so the page is testable today.

Also carries one correction of my own: an earlier "12 missing assets" count was measured from the wrong base directory. All refs resolve against the site root. No asset work is waiting for her.

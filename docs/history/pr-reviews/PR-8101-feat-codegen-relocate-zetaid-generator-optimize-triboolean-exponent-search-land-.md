## Description

### Why
Consolidates layout-driven generation under the TypeScript source directory (`src/Core.TypeScript/zeta-id/`) keeping `tools/` clean of language source files. Restructures the TriBoolean floating-point exponent search bounds with a logarithmic range limit to prevent hangs on wide decoders. Introduces native, allocation-invariant benchmarks for `ZetaId` the "Ben way" to establish performance baselines.

### What
- **ZetaId Relocation & Codegen**:
  - Relocated `tools/codegen/zeta-id-generator.ts` to `src/Core.TypeScript/zeta-id/zeta-id-generator.ts`.
  - Added strict parsing error safety with the `valueAfterColon` parser utility to compile cleanly with `strictNullChecks` turned on.
- **TriBoolean Optimization**:
  - Replaced linear search bounds in `FloatOps.cs` (C#), `Float.fs` (F#), and `float.rs` (Rust) with a binary log-scaling bounding search based on `Math.Log2(value)` to restrain search limits.
- **BenPort Benchmarks**:
  - Registered `zeta.id` space and time complexity metrics as $O(1)$ constant in `ComplexityRegistry.fs`.
  - Defined F# `BenPort` benchmark cases verifying that `pack` incurs 0 heap allocations and `unpack` incurs exactly 48 bytes (standard record instance allocation).
- **Merge Hygiene**:
  - Merged latest changes from `origin/main` (including the vision forecast scheduler wrapper and governance rules) and verified that all 3,143 .NET tests, Bun tests, Go tests, Rust tests, and Python tests pass 100% green.

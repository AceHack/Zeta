  `buildBaseline` claims it creates `nodeCount` nodes labeled `0 .. nodeCount-1`, but `Graph` derives nodes from edge endpoints (no standalone nodes). Because self-edges are skipped (`if t &lt;&gt; s then yield ...`), a node can (rarely) end up with zero edges and be absent from the baseline node set, which can skew/flake comparisons against attacked graphs. Consider resampling until `t &lt;&gt; s` (so each source emits exactly `avgDegree` edges) or otherwise ensuring every node appears at least once.
  ```suggestion
      let rec nextNonSelfTarget source =
          let target = rng.Next(nodeCount)
          if target = source then
              nextNonSelfTarget source
          else
              target

      let edges =
          [ for s in 0 .. nodeCount - 1 do
                for _ in 1 .. avgDegree do
                    let t = nextNonSelfTarget s
                    yield (s, t, 1L) ]
  ```
  </pre>

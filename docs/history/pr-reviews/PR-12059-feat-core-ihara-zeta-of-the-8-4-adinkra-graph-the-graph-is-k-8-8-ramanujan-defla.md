## Description

Aaron, 2026-08-18: *"This is similar to asking what is our zeta function — we can swap in zeta functions over the ages for other infinite generator functions."*

"Zeta function" names a family, not an object, so the question is unanswerable as posed. Ihara is **a** zeta of the adinkra's underlying graph, not **the** zeta of the factory. The reframing that makes this one finite: **a zeta function is an Euler product that enumerates irreducibles** — Riemann's over primes, Dedekind's over prime ideals, **Ihara's over the primitive closed geodesics of a graph**. An adinkra is a graph, so Ihara is computable for the `[8,4]` extended Hamming generator already pinned in `AdinkraCode`.

Honesty leftover (this commit): the previous title equated the zeta with the graph. **Zeta ≠ graph.** The GRAPH of the `[8,4]` adinkra is `K_{8,8}`; its Ihara zeta is the Bass polynomial below; Ramanujan follows from complete-bipartiteness; the zeta is silent on unfolding.

## The graph is derived, not drawn

The code is self-dual, so its generator is also its parity-check matrix and `AdinkraCode.syndrome` already **is** the quotient map `GF(2)^8 → GF(2)^8/C`. The connection set is therefore the eight **columns** of `[I₄ | A]`, and those turn out to be exactly the eight **odd-weight vectors of `GF(2)^4`**. Adding an odd vector flips parity and the eight odd vectors are all of them, so every boson coset joins every fermion coset once:

> ### The underlying graph of the `[8,4]` adinkra is `K_{8,8}`.

16 nodes, 8-regular, 64 edges, circuit rank `r = |E| − |V| + 1 = 64 − 16 + 1 = 49`. Checked entry-by-entry against coset parity, and separately against a hand-built `K_{8,8}` that shares no code with the derivation.

## The zeta function

Bass writes `ζ(u)⁻¹ = (1 − u²)^{r−1} · det(I − Au + Qu²)`. The code implements that as written (the Bass factor is `(1 − u²)^{48}`). `Q = 7I`; spectrum exactly `{8, −8, 0^14}`, verified as the integer factorisation `x^14 (x − 8)(x + 8)`. The determinant contributes one more `(1 − u²)` from the Perron / bipartite pair, so the collapsed closed form carries `(1 − u²)^r` with **`r = 49`**, not `r−1`:

```
ζ(u)⁻¹ = (1 − u²)^49 · (1 − 49u²) · (1 + 7u²)^14
```

degree **128** = `2|E|`, as Bass requires.

| pole | multiplicity | modulus | class |
|---|---|---|---|
| `u = ±1` | 49 each | 1 | trivial — closed-form `(1 − u²)^r` with `r = 49` |
| `u = ±1/7` | 1 each | `1/q` | trivial |
| **`u = ±i/√7`** | **14 each** | **`q^(-1/2)`** | **non-trivial — exactly on the critical circle** |

## The Ramanujan verdict: YES, deflated

Non-trivial spectrum is `{0^14}`, and `0 ≤ 4q = 28`. So the graph satisfies the **Riemann Hypothesis for graphs** and is **Ramanujan** — maximally so: every non-trivial pole sits *on* the critical circle, none merely inside it.

**No floating point appears anywhere in the pipeline** — `bigint` polynomials, a Bareiss fraction-free determinant, Newton forward-difference interpolation with every division asserted exact — so the verdict is an integer comparison with no error bound to defend.

**Deflated honestly:** every `K_{n,n}` is Ramanujan, so the verdict is a property of complete-bipartiteness, not a discovery about supersymmetry. What is earned is the *identification*; the verdict follows from it.

## The Euler product — what the primes are

`N_k = 0` at odd `k`; `N_2m = 98 + 2·49^m + 28·(-7)^m`.

| length | `π(k)` |
|---|---|
| 1, 2, 3 | 0 |
| **4** | **1568** |
| **6** | **37632** |
| **8** | **1448832** |

`π(4) = 1568` is the hand-check that anchors the rest: `C(8,2)² = 784` four-cycles × 2 orientations. Length 4 matching `{Q_I, Q_J}` is a **math-shape correspondence**, not a theorem and not physics-proves-us.

## What this does NOT establish — and why it *cannot*

The load-bearing claim would be that this Euler product enumerates the irreducibles **of the unfolding**. It does not, and the reason is mechanical: the Ihara zeta is a function of the adjacency matrix alone, so it cannot see an adinkra's **dashing** or **height assignment** — where the supersymmetry lives. Two adinkras with the same topology and different dashings are different supermultiplets with the *same* Ihara zeta.

That is **proven in the suite, not asserted**: a test relabels the vertices and shows the polynomial unmoved; a second shows the invariant is not vacuous (the 4-cube, also 16 nodes, has a different zeta).

The negative result is the useful half — it says what a zeta over the unfolding would have to be: **Terras's edge/multivariable zeta** (one variable per directed edge, so `Q₁Q₂Q₁Q₂` and `Q₃Q₄Q₃Q₄` stop being the same prime) or a **dashing-twisted Artin–Ihara L-function**. Neither is built; both are named so the dead end is not re-derived.

## Description

The generator half of D5 (spec #14503): `why-chain.ts` turns the state
that actually drove a decision (`WhyContext`) into a descending chain of
one-sentence answers that terminates at a reachable "I don't know."

The spec's two hard requirements, built in rather than tested on:

- **Never a string table.** Every non-terminal answer interpolates live
  values from the context that produced it — mode value estimates,
  adversary distance/closing speed, reward-event counts, explore
  progress, fixation tile + variance. The test suite asserts each
  answer cites at least one number that round-trips back to the
  context (or is the stated boundary rung "where my reasons stop"),
  so a hardcoded sentence cannot pass.
- **The chain must reach "I don't know."** `whyChain` is terminalised —
  the last rung is always `WHY_TERMINAL` — and `whyAnswer(ctx, depth)`
  saturates there rather than cycling or inventing. Zero reward events
  answers "still my starting guess", not a confident fiction: the
  chain is honest about the difference between learned and prior.

Scope line, stated: this is the generator + its acceptance-test half
(termination + citation). The UI half of D5 — WhyContext assembled in
the swarm controller, carried on the FramePayload, click-to-descend on
the agent panel — follows in the next PR, on top of #14549's frame
plumbing. Landing the generator first keeps that PR pure wiring.

Verification: 6/6 tests green (termination; value-citation round-trip;
answers change when state changes; click saturation; explore-chain
honesty; zero-rewards honesty); eslint 0 problems; both root and app
typechecks green.

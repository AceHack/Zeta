### The two objects

Both real, both GF(2), different layers (Doran–Faux–Gates–Hübsch–Iga–Landweber, *Codes and supersymmetry in one dimension*, ATMP 15 (2011) 1909):

| | code layer | dashing layer |
|---|---|---|
| what | doubly-even `C` subset of `F2^N`, fixes the chromotopology `F2^N / C` | odd 1-cochain on that graph |
| algebra | **linear subspace** — contains 0 | **torsor** over the vertex-flip gauge group — no zero |
| cardinality | **16** codewords | **32768 = 2^15** dashings |
| in-tree | `AdinkraCode`, N = 8: 16 nodes, **8-regular, 64 edges** | `AdinkraViz`, N = 4, trivial code: 16 nodes, **4-regular, 32 edges** |

Linked by an **existence theorem** — doubly-evenness of `C` is the condition under which a dashing exists on the quotient — never by identity.

The sharpest discriminator is not the cardinality: **a linear code always contains 0, a torsor never does.** All-solid is not a dashing, because every face would carry 0 (even) dashes. And as the brief warned, **both graphs have 16 nodes** — which is exactly why the mislabel survived. Valence separates them: 4 vs 8.

## 2. `|Aut([8,4,4])| = 1344` — correct, and the count was already tested; the IDENTIFICATION was not

**Correction to the brief.** It is not true that 1344 was "a comment nobody had tested". The **order** has been under test since **#9468 (2026-07-04)**: `SoftRegimeEquivariance.Tests.fs` `EQV-1`, exhaustive, in this same assembly — under the *opposite* coordinate convention, so the two routes are a genuine cross-check rather than a copy. What was **never** metered is the identification, and that is the real gap and exactly the shape `numerology-vs-number-theory.md` names: **the count was measured, the name `AGL(3,2)` was asserted.**

### What else has 1344

`2^3 x GL(3,2)` and `C4 x PGL(2,7)` both have order 1344. Even restricted to 3-transitive groups of degree 8 — PGL(2,7) (336), AGL(3,2) (1344), A8 (20160), S8 (40320) — the count discriminates only *once 3-transitivity and the degree are already in hand*.

### What identifies it (all computed, none asserted)

- a **unique** conjugacy class of size 7 gives `T`, order 8, **elementary abelian**, **normal**, acting **regularly**
- regularity splits `G = T : G0` with `|G0| = 1344/8 = 168 = |GL(3,2)|`, forcing `G0 = GL(3,2)` and `G = AGL(3,2)`
- **trivial centre** excludes the direct-product competitors
- **3-transitive** (336 of 336 ordered triples) but **not 4-transitive** (1344 < 1680) separates it from PGL(2,7) / A8 / S8
- class equation `[1;7;42;42;84;168;168;192;192;224;224]` pinned as a structural fingerprint

**The structural why:** the in-tree code is coordinate-equivalent to `RM(1,3)` — coordinates indexed by the points of AG(3,2), codewords the 16 affine functions `F2^3 -> F2` (weights 0, 4x14, 8, matching `AdinkraCode.weightEnumerator`). A coordinate permutation preserves the affine functions iff it is itself affine. Anchor checked, not merely cited: MacWilliams & Sloane, *The Theory of Error-Correcting Codes* (1977), Ch. 13 Thm 24 — `Aut(RM(r,m)) = GA(m,2)` for `0 < r < m`.

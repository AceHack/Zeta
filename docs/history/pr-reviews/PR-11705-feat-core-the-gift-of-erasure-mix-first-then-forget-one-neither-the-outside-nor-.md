## The ordering is the mechanism

Erasure *without* mixing leaks — a gap in an otherwise-legible sequence has a **silhouette**. So `mix` first, refusing every shape in which a later erasure would not actually hide, then `forget`.

## Forgetting is cooperative, and that is arithmetic rather than sentiment

The anonymity set is **other parties' events**. A coalition already knows its own contributions, so the candidates it cannot rule out are exactly *the members it did not contribute* — Chaum's *"anonymity set seen by a set of keys"*, computed over contributions instead of edges. Your own events give you **zero** anonymity against yourself, so `mix` refuses a batch dominated by too few contributors:

> **You cannot forget alone.** Independence is produced *by* interdependence.

| adversary | knows | candidates it cannot rule out |
|---|---|---|
| outsider | the public view only | all `n` members |
| contributor coalition `C` | additionally, its own contributions | `n − |contributions of C|` |

## The falsifier is an exhibited observer, not an asserted boolean

`posterior` is the Bayes-optimal distinguisher for a deterministic protocol: it re-runs the protocol once per candidate and keeps those whose simulated transcript equals the observed one. Measured, not claimed:

- **outsider** — flat over 8; every candidate consistent; best single guess `0.125`; TV distance from prior `0.0`.
- **contributor coalition** — flat over its residual 6, after its own two events are removed from the candidate space.
- **positive control** — given a mix that leaves a silhouette, the *same* observer collapses to **one** candidate, best guess `1.0`, advantage `0.875`. Without this, "the posterior was flat" would only mean the observer is blind.
- **the vacuity, exhibited** — a one-candidate posterior is *also* flat (TV `0.0`) while the adversary is certain, which is why `indistinguishable` requires the floor as well as flatness.

The closed form `1 − m/n` is derived in the docstring and checked against the term-by-term sum, so the algebra is not taken on trust.

## §5 is honoured exactly, not approximately

The **fact** of a forgetting stays visible (an `ErasureWitness` per release, published with the anonymity that covered it); only the **content** becomes unrecoverable. The witness deliberately does **not** name the eraser — naming it would collapse every coalition's candidate set onto that party's events — and `forget` refuses a consent record containing a contributor identifier verbatim.

## Typed refusals, because the polarity inverts

Aaron's green-thread mapping, recorded as a **structural analogy** with two metered consequences: deletion is preemption, erasure is a cooperative yield. In scheduling a non-yielder costs you **liveness** and you can tell; here a non-contributor costs you **safety** and you **cannot** — from the inside, a mix of one looks exactly like a mix of many.

So a **mix of one is unrepresentable** (`MixPolicy`'s fields are private, `mixPolicy` is the only door), and every other failure is a `Refusal` case carrying **observed against required**. There is no success value meaning *"erased, and the set was one"*. The DC-net **jamming** failure and its admissible mitigation class — accountability plus exclusion, **never** seizure or an authority override, which would be the confiscation `privacy-budget-is-hard-money-earned-by-others.md` forbids — are named in the module doc so nobody later reaches for the preemptive fix.

## No cryptography is performed, invented, or keyed here

Members arrive **already sealed** by the caller; forgetting is **structural removal** of the bytes, not crypto-shredding, so no key exists whose survival could resurrect the content and **no key-stack change is proposed**. `padToBlock` is framing, not a cipher.

**The honest limit, stated so it can be attacked:** the anonymity rests on the public view being an **aggregate**. If per-member ciphertexts were published before and after, the erased one would be recoverable by set difference — and defeating *that* needs a re-encryption mixnet or a DC-net, **both requiring pairwise key material**. Named, not attempted.

## The security parameter is injected and attributed

`MixPolicy` has **no default** and refuses an empty rationale. `deletionFloor = 2` carries its derivation inline — the best single guess `1/k` is below certainty only for `k ≥ 2` — and is a **floor, not a recommendation**.

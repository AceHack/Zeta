## Description

Aaron: *"whitness vs qurom earns its place in our core vocabulary too, this is a good distinction."*

Both entries land together, because **the distinction is the content**.

- **Witness** — one external observer. Sufficient to break a self-referential loop, since `FigureEightEnsemble.fs` proves the loop cannot see its own fixed point from inside (*"the demon cannot resist the tangle from inside the loop"*). Tolerates **zero faults**: if the witness is itself wrong or captured, the rescue fails silently *and looks like success*.
- **Quorum** — a witness set sized for fault tolerance: **3f+1** to survive `f` faulty or captured members.

The difference isn't thoroughness — it's **whether the observer itself can be wrong**. So *"do I need one or several?"* is exactly *"can my checker be captured?"*, and if the answer is yes, **one is not a weaker answer, it's the wrong kind of answer.**

The operational line: **every "get an outside opinion" is a witness claim until it names `f`.**

Both are Lane A terms (externally standard, from the BFT literature) rather than coinages, so they arrive already anchored.

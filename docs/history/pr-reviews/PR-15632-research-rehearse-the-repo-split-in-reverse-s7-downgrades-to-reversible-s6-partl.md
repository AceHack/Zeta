## The finding that outranks the three verdicts

**The fleet's shared credential can create repositories and cannot destroy them.** The token
carries `repo` + `admin:org` + `admin:enterprise` but **not `delete_repo`**.

Measured, not read off documentation — and it required falsifying GitHub's own error text:

```
DELETE /repos/.../zzz-rehearsal-5f25a8-DELETE-ME
  -> 403 "Must have admin rights to Repository."

GET    /repos/.../zzz-rehearsal-5f25a8-DELETE-ME
  -> "permissions": {"admin": true, ...}          <- the message is wrong about the cause
```

Org owner, repo admin `true`, `members_can_delete_repositories: true` — refused purely on OAuth
scope. That asymmetry **manufactures irreversibility in every future step**, silently,
regardless of what any document marks.

The one-command fix (`gh auth refresh -s delete_repo`) was **deliberately not run**: adding a
scope to Aaron's shared credential is *extending* authority, which `no-directives.md` forbids
the shadow. It is Aaron's action.

**S7** — 33 identity checks across 3 cycles, **0 failures**, on the real `zeta-formal` shape
(163 files, 5.4 MB, from a live Zeta clone). `git revert` returns the **whole repo tree** to a
byte-identical object id — by two independent routes. #15627 said "recoverable, not clean"; it
understated its own reverse. A **1-byte mutation control** proves the checks can fail, so
33/33 is not vacuous.

**S6** — `POST /repos/{o}/{r}/transfer` moves a repo out of the org in ≤10 s with **no
acceptance step**, and **works without `delete_repo`**. What stays permanent is the **name**:
after rename ×2 and transfer ×2, all three historical paths still resolve via redirect.
#15627 is right that the name is spent; it attached that cost to the whole step rather than to
the residue.

**S9** — no PAT was created, scoped, or revoked. **There is no isolated copy of a live
credential**, so rehearsal and the real thing are the same act. The mitigation is sequencing
(the existing overlap-window ADR), not a reverse command.

## Also found — above the line, in a step called "reversible"

## Description

§4.7 of the concept registry shipped with a named fracture line and an explicit instruction: if the two dispatched agents break the path-independence identification, **this entry weakens with it and should be amended, not defended.**

They broke it — PR #11711 (`docs/research/2026-08-17-path-independence-is-four-properties-...`) and the prior-art companion #11712. This honours the instruction.

## What broke, kept visible rather than quietly dropped

- **Geometric:** commutativity is a property of the *group*; flatness is a property of the *edge assignment*, and a monoid has no edge assignment. ℤ/4 (abelian) with one nontrivial link is **curved**; S₃ (non-abelian) with the trivial connection is **flat**.
- **Probabilistic:** worse than wrong — **vacuous**. By Fine (1982) a structure whose reads all commute has nothing incompatible, and incompatibility is the entire source of the CHSH bound, so `S ≤ 2` holds while asserting nothing. `src/Core/BellTest.fs` already reaches **S = 4** from a shared seed, refuting "shared state = λ" from inside our own tree.

## The corollary was inverted

The conversational framing had disagreement-preserving structures as path-**dependent** and therefore curving. It is the opposite: Dynamo siblings and SPPF forests merge by **union** and are the *most* order-independent structures available — retaining concurrent versions is *how* a merge becomes commutative. **Order-independence is bought by keeping more, not less.**

## What survives — the part Aaron actually ruled on

Under §11 the default is **free fall**, so divergence between travelers is **curvature** rather than a force one applied to the other. That rests on the geodesic-deviation anchor **directly** and never depended on the monoid/holonomy identification. The refuted material was scaffolding Otto added around the ruling in conversation.

The entry's existing register — no metric on traveler states, no connection, no computed curvature quantity, no §A row may cite it — was already the correct disposition. The refutation **confirms** that register rather than changing it.

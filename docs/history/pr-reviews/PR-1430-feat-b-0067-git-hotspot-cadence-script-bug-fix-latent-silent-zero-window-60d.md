## Description

## Summary

Closes B-0067 phases 1+2 with a latent-bug-found-and-fixed bonus.

**Latent bug**: `tools/hygiene/audit-git-hotspots.ts` was passing `--window 60d` verbatim to `git log --since=60d`, which is NOT a valid approxidate format. Git silently matched zero commits, so every previous run produced an empty report. Empirically caught 2026-05-03 during phase-2 cadence wiring — the script's first ad-hoc run reported *"no commits in window '60d' (or all filtered)"* while the repo had 1274 commits in that window. Fix: `expandWindowShorthand()` translates `60d → "60 days ago"` at the script boundary; pass-through if input doesn't match the shorthand pattern (so callers can still supply raw approxidates).

**Phase 2 cadence**: new `.github/workflows/git-hotspot-cadence.yml` runs the detector weekly Sundays 16:43 UTC + workflow_dispatch + path-filtered PR trigger. Uploads markdown report as 90-day artifact. Modeled on `lean-proof.yml` + `budget-snapshot-cadence.yml`.

## Description

Adds the **G-Set / Bag / Z-set algebraic ladder** to the bus↔Ace synthesis doc (which merged via #6284) — the clean explanation, for the Windows peer.

Both are real standard terms from two fields, on one ladder indexed by *element count* × *merge op*:

| | count | merge | structure | retraction? |
|---|---|---|---|---|
| **Set / G-Set** | {0,1} | union/max | join-semilattice (idempotent) | no |
| **Bag** | ℕ | sum | commutative monoid | no |
| **Z-set** | ℤ | sum | abelian group | **yes** |

- **G-Set = Grow-only Set** (Shapiro et al. 2011 CRDT catalog) — idempotent union → conflict-free → why the git-native bus merges clean.
- **Z-set** (DBSP / differential dataflow) — ℤ multiplicity → `−1` retracts → Ace's dependency resolution.
- **Honest nuance:** "G-Set = Z-set with non-negative multiplicity" is the right intuition, but they merge with *different algebras* (idempotent union vs group addition); the Bag sits exactly between.
- **Through-line:** each rung is the **free** structure of its kind (free join-semilattice / free commutative monoid / free abelian group) — same free-construction pattern as Cayley-Dickson.

bus = G-Set rung; Ace = Z-set rung; Bag rung reserved for a future counted-but-not-retractable category. Single-file doc edit; §33 headers already in the doc.

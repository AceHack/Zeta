## Description

Decides nothing. States what exists, what the mobile-mesh constraint breaks, and the public prior art that already answers most of it.

## The two halves exist and are not connected

| half | where |
|---|---|
| grammar | `ActionGrammar.fs` — alphabet (4×4), algebra (Boolean lattice), `Word = Action list` |
| channel | `multiplexed-duplex-transport.ts` — N ZetaId-keyed channels, four-corner framing, **mid-stream mutual interrupt already tested** |

**The bridge is already minted:** `mintChannelId` sets `Firefly=NoDirective(1)` — source ≠ authorization is already a *bit in the universal pointer*, which is exactly the envelope a bidirectional grammar needs.

## What the moving mesh breaks

1. **Loudness-as-priority is hierarchy formation at the protocol layer** — the same failure the flat-society invariants guard, one layer below where they can see it. Max-min fairness (Bertsekas & Gallager) and Rawlsian maximin are *the same objective* over different resources.
2. **Loss is ambiguous** — congestion loss and channel loss demand opposite responses, and on a moving mesh the usual inference is often wrong.
3. **An interrupted `Word` leaves a prefix applied** — and on a lossy channel a *dropped frame* produces the same partial application as a deliberate interrupt. Forces: interruptible ⇒ **atomic or explicitly resumable, no third option**. Identical to the all-or-nothing property shipped in #9891 for an unrelated reason, the same day.

## Trickle (RFC 6206) — and half of it is already built here

| Trickle | already in repo |
|---|---|
| `Imin` | `DEFAULT_BURST_MIN = 15` |
| `Imax` | `MAX_IDLE_MIN = 360` |
| reset on inconsistency | presence claim ⇒ burst |
| double when quiet | decay to idle |

`operator-presence.ts` **is** a Trickle interval schedule — the `Imax` ceiling exists for the stated reason ("fail closed but not off"), which is precisely why Trickle has one. Independently rederived.

**Rule 2 — polite suppression (stay silent after hearing `k` consistent peers) — is not built.** That is the half that answers the loud-bat question.

## Finding — needs verification, moderate confidence

`DebouncedOracle` enforces ρ = 1/(1+L) with a **fixed** `MinDelay`. Sound for a stationary world. If emitter and object are **closing**, true L shrinks, a genuine return arrives sooner than `MinDelay`, and it is dropped as self-emission — a fixed window **blinds the sensor to the nearest objects, silently, by suppression**. In a vehicular setting those matter most.

Call path not traced. Cheap check: does any caller recompute `MinDelay` from a measured round-trip?

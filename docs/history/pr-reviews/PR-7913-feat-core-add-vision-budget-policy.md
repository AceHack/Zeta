## Description

## What changed

Adds `Zeta.Core.Vision` as the source-owned vocabulary for the existing `I ∘ D` cache calculus:

- `cache`, `vision`, `subscribe`, and `output` over the existing circuit/Dsl primitives
- `GrowthRequest` and UniversalNumber-backed uncertainty growth budgeting via the SoftThrottle boat shape
- future branch prediction priced as `spaceBytes + timeTicks * bytesPerTick + ceil(uncertaintyResolutionBits / 8)`
- `PredictionOutcome` reports for admitted, partial, rejected-with-backpressure, and capped-accounting states
- `SoftScheduler.HandlerK` wrapping so scheduler action and self-prediction move together

## Why

Vision should not be a fixed ten-float vector. It is the scheduler's budgeted self-sight: integrate deltas into cache, price uncertainty growth in bytes, and decide how far a room can ray-trace possible futures before backpressure speaks.

## Description

#10968 landed `noConfiscation` — the hard-money rule as a decidable predicate — but with a **caller-supplied** `ownerInitiated: 'msg -> bool` witness, because `Addressed` carried `To`/`Body` and **the substrate had no sender**. It shipped `confiscationCheckHasNoTeeth` to report when a caller had talked the check out of existence, and named the fix in its own doc: one `From: Address` field.

This is that field. `ownerInitiated` is **gone** from both oracles; the discriminator is read off the envelope.

## The falsifier the field exists for

One body, two senders, opposite verdicts, **byte-identical effect on the balance**:

| envelope | verdict |
|---|---|
| `{ From = theLevel; To = beta; Body = Confiscate beta }` | **red** — a taking |
| `{ From = beta; To = beta; Body = Confiscate beta }` | **green** — beta's own spend |
| `{ From = alpha; To = beta; Body = Confiscate beta }` | **red** — a third party is not laundered by being *some* owner |

**The old code could provably not express this**, and the test asserts it rather than arguing it: the old discriminator had type `'msg -> bool`, so all it could see of these calls is `.Body` — and the two bodies are **equal**. A function of equal inputs returns equal outputs, so no `ownerInitiated` whatsoever could return `false` for the first and `true` for the second. The distinction was not merely unmade, it was **unmakeable at that signature**; a caller could only have supplied the answer by already knowing it.

## Three findings — none of them the expected one-line edit

**1. The derivation is per-PART, and that is strictly stronger than the boolean it replaces.** The old witness judged a **whole message**, so `ownerInitiated m = true` excused *every* decrease that message caused — including decreases to parts that were not the initiator. A single message spending the sender's own budget **and** taking a neighbour's passed on one `true`. Each lowered part is now checked against `From` individually. `CrossSpend(alpha, beta)` is that message: green scoped to `[alpha]` (alpha really is spending alpha's), red scoped to `[alpha; beta]`. Mutant **M9 restores the exact old whole-message semantics and kills exactly this one test and nothing else** — which is the cleanest statement of what was gained.

**2. Derivable ≠ unforgeable, and the difference is not rounded up.** `From` is **unsigned, caller-written data**; nothing in this interface authenticates it. What changed is the *shape of the lie* — a per-message address forgery instead of one flipped boolean. So `confiscationCheckHasNoTeeth` was **kept and re-aimed**, not deleted as unreachable: it now reports the envelope-level vacuity (**every message lowers some part's balance and names that very part as its sender**). Deleting it would have been a choice, not a cleanup. Added `SocietyLaws.outboundIsSelfAttributed` as the companion guard — it refuses a member that stamps a peer's address on its own outbound. That is a **law with a falsifier, not authentication**, and it is not cited as any: it is decidable only for a member you can run, and says nothing about an envelope off a wire.

The guard is read as the **strength of the pass**, never as an accusation: a genuine batch of owner spends is self-attributed too and is indistinguishable from the forgery *at this interface*. The fact is "this pass carried no information"; which reading applies is the caller's (`dual-use-detection-is-neutral-oracle-decides`).

**3. What resists having a sender — the inbound half, reported rather than forced.** `Deliver` **returns** `Addressed<'msg>` but still **takes** a bare `'msg`. Delivery drops the envelope, so a member folding a message still cannot see who sent it. Obligations over what an aggregate **emits** are now self-contained; anything stated over what a member **received** is not. Closing that means changing `Deliver`'s argument to an envelope — a larger interface change, deliberately not made here and named instead.

Two smaller consequences: **`Confiscate` / `OwnerSpend` are now redundant** as DU cases (the body no longer needs to encode the initiator) — kept only because #10968's assertions are kept; and the **expulsion** row in #10968's doc loses its mechanical excuse — `From` *can* distinguish a consented departure from a banishment, so that row is now out for the reason it was always really out: it is a §11 values call, not an engineering one.

## Blast radius

**Five construction sites of `Addressed`, all updated** — 3 F# (`Ctm.Tests.fs` ×2, `LevelObligations.Tests.fs` ×1), 2 TS (`ctm.test.ts` ×2). **Nothing in `src/` constructs one**: `Addressed` appears in `src/` only in the two declarations and in `Ctm.fs`'s `Broadcast` *signature*. Every new site stamps the member's own address, consistent with `outboundIsSelfAttributed`.

**No assertion from #10968 was weakened.** Each is carried forward with its truth value intact, re-expressed over envelopes — including the vacuity pair (forged self-attribution passes *and* is reported) and the empty-list case. The "declare everything owner-initiated" move became "write the victim's address into `From` on every message", which is the same vacuity at a strictly higher price.

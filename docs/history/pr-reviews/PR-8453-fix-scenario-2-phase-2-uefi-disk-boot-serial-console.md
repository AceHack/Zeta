## Description

## Problem (run #27589613408)

OVMF + 4M firmware fix booted UEFI, but serial stopped after `EFI stub: Loaded initrd` and timed out at 600s.

Serial showed `BdsDxe: starting Boot0001 "UEFI Misc Device" from Pci(0x3,0x0)` — the **virtio-net PXE ROM**, not the disk ESP.

## Fix

**Harness (immediate):**
- Phase 2: `bootindex=1` on virtio disk, **no virtio-net** (login test needs no network)
- `-vga none`, `-no-reboot`
- Phase 2 timeout 600s → **1800s** (first-boot activation budget, mirrors aarch64 TCG note)
- Progress logging + clearer timeout hint

**Installed node (next install in same run):**
- `nomodeset` + `earlycon=uart8250,io,0x3f8,115200n8` in `common.nix` boot.kernelParams

## Test plan

- Unit tests for phase 2 QEMU args + existing hostname guards
- Merge → main `build-iso` scenario 2 phase 1+2 green

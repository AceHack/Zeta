## Description

You asked for rotation tests on anything key or secret based. Looking for the gap turned up something sharper than a missing test: **there was no rotation path to test.**

`applyDevBootstrapSecrets` is mint-if-absent, `use-cases.test.ts` pins that a re-bring-up does **not** rotate, and `host-seal-profile.test.ts` tests which rotation *gate* is permitted — but nothing rotated a minted credential. A missing test on a missing feature is a **feature gap**, and a test mocking a path that doesn't exist would have been green while constraining nothing.

So: the verb first, then its falsifiers.

## Design — the awkward parts are deliberate

- **Takes one target**, never a roster and never an `"all"`. Bulk rotation is the accident the existing idempotency guard protects against, one command away. The blast radius is chosen by the caller, in writing, per call.
- **Refuses to mint.** Rotating a credential the cluster doesn't hold would *create* what the operator asked to *replace*, teaching them nothing about the missing original. Rotating an unknown name would mint a Secret no Application reads — the "credential with no consumer" that `audit-existing-secret-is-minted` catches, arriving through a door that audit doesn't watch. Both refuse, and write nothing.
- **Shared credentials rotate everywhere or nowhere**, draw outside the namespace loop. A partial rotation leaves consumers presenting a key the producer no longer knows — surfacing as an auth error days later rather than a refusal now.
- **Does not claim an overlap window.** The 2026-06-15 ADR wants old and new valid together; a Secret holding one password under one key can't express that, and every chart in `CHART_ROTATION_CONSTRAINTS` reads exactly one. `overlapWindow` is typed as the literal `false` so it cannot quietly become true. This is a REPLACE and says so.
- **Reports `restartRequired` and admits it did not do it.** `ClusterControlPlane` has `applyInlineManifest` / `ensureNamespace` / `resourceExists` and nothing that rolls a workload. Reporting the restart without naming it un-performed would read as complete while the running service still presents the old credential. Consumers come from `CHART_ROTATION_CONSTRAINTS` (merged in #16951) rather than a second hand-written list — one source, no invisible drift.

## Description

PR #13479 added `tools/setup/hsm/dkek-ceremony-preflight.sh` without adding it to `EXPECTED_RETAINED_SHELL` or `RETAINED_SHELL_CATEGORY_BY_FILE`, so the bash-retirement inventory test fails on `main`.

**Every open PR inherits it** — #13486 and #13471 were both red on `lint (bash retirement inventory + hygiene unit tests)` for a defect neither branch introduced. Found by the unrenderable-charts agent, which correctly declined to fix a file it did not own.

Registered as `setup/bootstrap`: it is a **preflight that must run before any PKCS#11 tooling exists on the host**, checking whether the custody ceremony can safely proceed, so it cannot depend on the toolchain it gates. Same retained-shell edge the other setup entries carry.

## Two things worth recording from getting here

**The inventory *script* exits 0 while printing the offending file** under "Unexpected non-Lean shell files". So running the tool is not the check — the **test** is. Anyone who ran the script and read its exit code would have concluded main was fine.

**My first placement made it worse: 1 failure became 10.** `EXPECTED_RETAINED_SHELL` is **sorted**, and I appended after `op-token-setup.sh`; `tools/setup/hsm/` sorts between `host-loop-bootstrap.sh` and `install.sh`. The suite checks ordering, which is why a wrong position broke tests unrelated to the new entry — and why the failure count going **up** was the useful signal rather than a confusing one.

Verified: **18 pass / 0 fail**, inventory exit 0 with no unexpected-files section, `tsc` exit 0. Exit codes read directly, not through a pipe.

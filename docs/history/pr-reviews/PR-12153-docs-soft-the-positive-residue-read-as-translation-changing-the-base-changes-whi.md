## Description

docs(soft): the positive residue read as translation — changing the base changes WHICH, not HOW MANY

Aaron on Lumen's unpredicted residue (a coded adinkra IS free of rank 1 over a Cl(0,N-k) subalgebra
— homoiconic for a sub-language of its own colours, with exactly k colours acting without being
named): "this is how we translate from English to other languages."

THE STRUCTURAL PART IS TIGHT. The N-k named colours are what the source language can express; the k
unnamed colours are operations that still ACT but are not sayable in it; defect = 2^k is the size of
the untranslatable residue; the choice of information set is the choice of source language. The
sharp consequence is Lumen's MEASUREMENT rather than my reading: WHICH colours go unnamed is a
CONVENTION — 56 of the 70 four-colour subalgebras work at N=8. So which things are untranslatable
depends on the choice of base, not on the languages, which matches the commonplace that
untranslatability is usually an artefact of the framing chosen rather than an intrinsic gap.

THE PREDICTION, AND IT IS FALSIFIABLE. Switching the source language — English today, a generated
symbolic language later — RE-CHOOSES the information set. That changes WHICH operations fall into
the unnamed set. It does NOT change k, because k is fixed by the code and not by the choice. So a
shift of base RELOCATES the residue rather than shrinking it, and a new base language claiming to
REDUCE rather than MOVE it is checkable and, on this model, wrong.

THE ONE CORRECTION — two quantities that must not merge. Aaron pairs this with "more content ~= more
resolution". More data reduces UNCERTAINTY ABOUT THE MAPPING (estimator variance). More data does
NOT reduce k, which is structural: dim A / dim M = 2^k, quantised to powers of two, equal to 1 only
for the trivial code. No corpus drives a power of two to a non-power of two.

AND THAT DIFFERENCE IS THE FALSIFIER FOR THE WHOLE ANALOGY. If translation loss behaves like a
data-limited quantity — shrinking smoothly toward zero with corpus size — the mapping to a code
quotient is WRONG, because a quotient's defect is quantised and stubborn. If it PLATEAUS at a
structural level while variance keeps falling, the analogy has content. A runnable experiment, and
the reason the two claims are kept apart rather than letting "more data helps" absorb "the residue
is structural."

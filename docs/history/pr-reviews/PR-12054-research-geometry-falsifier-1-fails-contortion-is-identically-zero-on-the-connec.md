## Description

**Falsifier 1 fails. Do not implement a contortion metric.** A clean negative, with the survivors named.

The 2026-08-18 proposal (`docs/research/2026-08-18-torsion-not-curvature-*`, shadow branch) rests on a canonical torsion-free reference existing and being unique. It does not — and the reason is sharper than "we could not find one."

## The metric exists, and that is what kills it

Fisher–Rao is the metric (Rao 1945; Čencov 1982 uniqueness under sufficient statistics), and `src/Core/SoftValueInfo.fs` already computes the KL whose Hessian it is. So the first premise is granted at full strength — and with the metric fixed, the geometry stops being assumed and starts being computable.

`BeliefConvergence.observe` multiplies weights = **translates log-weights**. Log-weights are the natural parameters of the categorical exponential family, so our fold transports along Amari's **e-connection** (α = 1) while the canonical reference is Levi-Civita (α = 0). In natural coordinates the whole α-family is one line:

```
Gamma(alpha)_{ij,k} = ((1 - alpha)/2) * psi_ijk
```

with `psi_ijk` the **fully symmetric** Amari–Chentsov tensor. Symmetric ⇒ **torsion is identically zero for every member** ⇒ **contortion is identically zero** — while the connections genuinely differ.

| measured at θ = (0.7, −0.4, 0.25) | value |
|---|---|
| torsion, α ∈ {−1, 0, 0.5, 1} | **exactly 0**, every member |
| deviation of our fold's connection from Levi-Civita | **0.0462936** |
| non-metricity at α = 0 (canonical) | 7e−18 |
| non-metricity at α = 1 (ours) | **0.0925872** |

The deviation is real and it lives in **non-metricity**, which contortion does not measure. Corollary: *"contortion is the difference between any connection and Levi-Civita"* is false for non-metric connections — the decomposition is Levi-Civita + contorsion + disformation, and ours is non-metric because of Amari's dual flatness, which is the very structure that makes the fold order-independent.

## Three more failures, each independent

1. **"Torsion-free" does not select a connection.** Levi-Civita uniqueness needs torsion-free **and** metric-compatible; the proposal supplies one. The α-family is an explicit one-parameter family of *distinct* torsion-free connections.
2. **The phase-canonical order is a gauge choice.** Per `2026-07-11-multi-planet-convergence-*`, HLC survives multi-planet only as a **deterministic sort key** — "just a total order" — for float-reassociation bit-exactness. Any total order does. And it is free to be arbitrary *because the fold is commutative*, so it cannot be an order-deviation zero-point. Pinned: swapping the reference changes the reported deviation while changing nothing about the executions.
3. **The category error underneath.** `T(X,Y) = ∇_XY − ∇_YX − [X,Y]` — order-dependence of operations is the **Lie bracket**, which torsion *subtracts off*. Counterexample computed: flat ℝ², zero torsion everywhere, `X = ∂ₓ`, `Y = x∂_y`, A-then-B and B-then-A differ by exactly `s·t`. The teleparallel/Weitzenböck steelman fails too: our group is **abelian**, so its structure constants vanish, and the resulting contortion would be a constant of the group rather than a per-execution measurement.

## What survives

- **Relative deviation between two executions is base-point-free** (connections form an affine torsor); an **absolute** one is not. Pinned: identical to 1e−15 computed via two different references, and not vacuously zero.
- **If a per-execution geometric object is ever wanted it is a translational holonomy — the Burgers vector** (Kondo 1952; Bilby–Bullough–Smith 1955; Kröner 1958), whose *density* is torsion. Ruling out holonomy ruled out the measurement and kept the density.
- **Today's honest measurement needs no geometry**: fold both orders and subtract — **bit-identical** in the exact integer algebra, **one ULP** in float, which is exactly what the canonical sort order exists to remove.

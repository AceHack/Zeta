## Summary

Splits the overloaded GitHub Pages Race Mode into three independently loadable routes. The primary index is lightweight; `/authorize` loads only device authorization, `/observatory` loads visual and society panels only when requested, and `/wasm-lab` loads compiler modules only on an explicit experiment start.

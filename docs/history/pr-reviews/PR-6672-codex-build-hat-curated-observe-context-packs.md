## Description

## Summary

Builds the observe/context-pack architecture for hat-curated agent context. The PR adds the deterministic context-pack spine, scoped retrieval/admission contracts, optional model-backed synthesis, tenant curation/completeness/synthesis policy layers, readiness evaluation, replayable snapshots, inbox workflow actions, and advisory-promotion governance for synthesis-discovered gaps.

## What changed

- Adds `ContextPackBuilderPort` contracts and a deterministic builder that curates documents, graph context, lifecycle anchors, inbox anchors, memory, telemetry, omissions, contradictions, blockers, and attention lanes for the active hat/scope.
- Wires optional ephemeral-agentic synthesis through a bounded `ChatCompletionPort` adapter; model output must cite deterministic evidence and remains advisory unless admitted by policy.
- Adds tenant-config policy adapters and observe-act preview surfaces for curation, completeness, and synthesis requirements.
- Adds Cockroach-backed stores/readers/migrations for context-pack snapshots, doc consult exposure, lifecycle/inbox context, advisory-promotion decisions, and related production composition.
- Extends observe-act rendering, selection evidence, snapshot persistence, inbox workflow commands, and advisory-promotion approval/revocation commands.
- Documents the architecture and operational boundaries in `agentic-organization/docs/OBSERVE_CONTEXT_PACKS.md` plus related design docs.

## Impact

Agents now receive a scoped, replayable, hat-curated context envelope instead of a generic observe readout. Deterministic policy owns authority, scope, omissions, and replayability; ephemeral synthesis can interpret and compress only inside that envelope. Synthesis-discovered lifecycle blockers require durable hat approval before they can affect operational context.

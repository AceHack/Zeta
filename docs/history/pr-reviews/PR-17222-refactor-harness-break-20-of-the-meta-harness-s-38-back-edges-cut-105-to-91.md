## Description

refactor(harness): break 20 of the meta-harness's 38 back-edges — cut 105 to 91

Repo-split round 4 measured the agent meta-harness at cut cost 105 with 38
back-edges and recommended breaking edges rather than moving anything
(docs/research/2026-09-09-repo-split-round-4-*.md, §3.1 and §9). This is that
edge-breaking. No repo was created and nothing moved out of the monorepo.

Measured with the committed tool over the narrow variant-A boundary the 105
figure was computed for:

  before  files 205  internal 265  OUT 67  IN 38  cut 105
  after   files 207  internal 273  OUT 73  IN 18  cut  91

Two corrections to the document's own figures, measured live at 4c03fbd24: the
named clusters are 24 edges, not 22 (corporate/ is 15, not 13; the 38 total is
unchanged, so it is an attribution slip inside the clusters). And the projected
105 to 83 priced the breaks at zero — an inverted contract costs one forward
edge per importing harness file, six were added, so 91 is the floor inversion
reaches. Getting to 83 would have needed consumers moved inside the boundary,
which §3.1 already priced as net worse.

Every seam is the same move, the one interfaces-free-classes-earned-under-rules
already carves: the interface half is free and goes where anyone may depend on
it, the behaviour half is earned and stays with its weight. In each case one
module held both, so a consumer that wanted only the vocabulary had to import
the implementation to get it.

  8  protocol/agent-loop-contract.ts — the agent loop's DU/record types leave
     state-machine.ts, which imports them back and re-exports them. Seven
     corporate/ files and observe/merge-receipt.ts now import the contract.
  7  observe/udp-lossy-loop.test.ts split in two. It asserted a transport claim
     and a participant claim at once and stood up six model-backend modules to
     do it. Now model-backend/udp-lossy-persona-interrupt.test.ts (the
     interrupt-over-a-lossy-wire claim, with its subject) and
     observe/cloud-persona-participant.test.ts (the fallback claim, against an
     ISummon object literal — no wire). The mesh simulator, previously a second
     copy of gossip-salon's, moves to discovery/lossy-broadcast-mesh.ts.
  2  manus-smoke-test.ts moves to model-backend/. It is that backend's live
     smoke test, nothing in the install path calls it, and a bootstrap surface
     must not need the harness present.
  2  four-corner/ownership.ts — the generic FourCornerOwnership leaves
     workflow-engine/types.ts for the directory whose subject it is.
  1  protocol/summon-contract.ts — ISummon leaves peer-call/summon.ts, which
     also holds PersonaSummoner: a class that resolves a persona registry, runs
     the peer firewall, shells out to vendor CLIs and opens WebSockets.
     observe/participant.ts never constructs one.

Eight corporate/ to agent-loop edges remain and should. Every one is a value
import — transition, generateMenu, isNonCoercive, applyTransition, isTerminal,
currentState, readHistory, mainAsync. corporate/ calls the loop; the direction
is deliberate and agent-loop-bridge.ts says so in its own header, enforced by
register-boundary.test.ts. A consumer calling a library is not a cycle, it is a
dependency, and a split turns it into a published one. What was wrong was only
that the vocabulary travelled with the behaviour; agent-loop-bridge.ts now
carries two imports on purpose so the residual coupling stays countable.

isNonCoercive and isTerminal were considered for the contract tier and left
where they are: the contract modules admit types only, and a predicate that
expresses a generator's invariant belongs beside that generator.

Nothing here is evidence for splitting the harness. §8 marks the reuse claim
toy and names its falsifier; this change is worth making regardless, because a
free interface and an earned class were sharing a module.

Checks: tsc clean; bun test green, every touched directory re-run individually;
the new transport test is mutation-checked — deleting interruptPersona(ch)
turns it red, so it is a falsifier and not a test that cannot fail.

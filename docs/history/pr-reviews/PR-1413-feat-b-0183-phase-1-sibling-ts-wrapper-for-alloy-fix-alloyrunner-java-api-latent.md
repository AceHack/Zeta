## Description

## Summary

Sibling of #1412 (TLC wrapper). Writing the TS wrapper surfaced a latent silent-no-op in F# Alloy tests — same bug class as the cache-clobber.

## Latent bug class (lucky catch)

Aaron 2026-05-03: *"so it was not working before, not sure how that got missed :)"*

1. `AlloyRunner.java:38` references `A4Options.SatSolver.SAT4J` — nested enum doesn't exist in Alloy 6.2.0 (current jar)
2. F# `compileRunnerIfNeeded()` returns false on compile failure; `toolchainReady()` returns false; `assertSpecValid()` silently no-ops; xunit reports tests as PASSED
3. **TS wrapper fails loudly** with exit 2 (toolchain-not-ready) — exactly the structural advantage B-0183 promises

## Fix

Removed `opts.solver = A4Options.SatSolver.SAT4J;` line. Default resolves to SAT4J on Alloy 6.x without explicit assignment. Added comment explaining the upstream rename.

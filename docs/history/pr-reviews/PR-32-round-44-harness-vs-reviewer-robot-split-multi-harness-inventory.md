## Experiment — what this PR is specifically testing

We are deliberately inviting **GitHub Copilot code review** on this PR to check, honestly, what it can and cannot do:

1. Can Copilot PR review **self-audit** its own surface area and tell us what it can / cannot do? Expected answer: no — it reviews diffs, it doesn't run introspection reports.
2. Can Copilot PR review **self-repair** (fix its own system prompt or behaviour)? Expected answer: no — it's stateless per-PR, reads `.github/copilot-instructions.md` but doesn't write it.
3. Can Copilot review leave **big feature-level suggestions** on a PR, not just nit-pick style? We'll find out. The factory documentation in this PR describes multi-harness inventory work — a legitimate target for substantive review commentary.
4. Does Copilot review correctly load and apply the updated `.github/copilot-instructions.md` from this PR (including the new explicit reviewer-robot-not-harness framing)?

See `docs/HARNESS-SURFACES.md` § "GitHub Copilot — three distinct products under one brand" for the full taxonomy.

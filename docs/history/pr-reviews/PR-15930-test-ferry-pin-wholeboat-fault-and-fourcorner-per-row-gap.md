## Summary

Pin the current result-arity ferry contract so a later per-row FourCorner change cannot land silently wrong. Clean-room: requirements only; no ProcessMany, SIMD, GPU, or Itron original.

- **WholeBoat throw:** every row of a two-item boat observes the SAME exception instance (`faultWholeBoat`).
- **WholeBoat length mismatch:** the same `InvalidOperationException` on every row.
- **Success:** each row gets its own index-aligned result.
- **Gap:** `ferry_boat_row_is_not_four_corner` — a boat of plain ints still works; `'TItem` is not required to be `FourCornerOwnership`.

`faultBoat` renamed to `faultWholeBoat` (behavior unchanged). PerRow independence is named, not implemented (workitem 081M125DNKK087G0R00292E3ET).

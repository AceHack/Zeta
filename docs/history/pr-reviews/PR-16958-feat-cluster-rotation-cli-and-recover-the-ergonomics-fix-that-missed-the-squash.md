## 1. Recovers a commit that never landed

**PR #16952 squash-merged with only one commit** (`d0538750`). The follow-up that actually acted on the instruction above — `b0c185e9`, adding `rotateDevCredentials` and `allDevCredentialTargets` — was pushed **after auto-merge had already fired**, so it sat on the branch and never reached `main`.

It surfaced only because I wrote the CLI against `main` and got `Export named 'allDevCredentialTargets' not found`. Nothing else would have caught a correction silently not landing — the PR was merged, green, and looked complete.

Recovered by cherry-pick, so the ergonomic form is now genuinely on `main`: plural is primary, the singular wraps it, refusals survive per credential, and one refusal doesn't cancel the rest.

## 2. A CLI, because a verb reachable only from a test isn't easy

`rotate-credentials.ts`, following the existing one-file-one-verb idiom of `kind-up.ts` / `k3d-up.ts` / `apply-root-app.ts`.

```
bun .../rotate-credentials.ts --list          # every rotatable credential
bun .../rotate-credentials.ts monitoring/grafana-admin-credentials
bun .../rotate-credentials.ts --all
```

**What's deliberate:**

- **`--all` exists and is not the default.** Bare invocation prints usage and exits 1. Rotating everything must never be *accidental* — a different property from rotating everything being *hard*, and `--all` is one flag when you mean it.
- **A refusal is a non-zero exit.** This runs unattended in scripts, and a refusal exiting 0 is a rotation that silently didn't happen — the same class as a check that didn't run looking like one that passed. Each outcome prints for itself, so a partial batch says exactly which moved.
- **The restart advisory prints loudly.** `restartRequired` names workloads still holding the **old** value, and this process cannot restart them (the control-plane port has no rollout). Printing the swap without that would leave an operator believing the rotation took effect while the service still presents its original credential.

Verified: `--list` prints all six rotatable credentials (five per-service plus shared `zeta-blob-store`); bare invocation exits 1; typecheck clean; `use-cases` 59 pass / 0 fail.

## Description

workitem: heartbeat PRs can never merge - required checks sit in action_required

Every `heartbeat/*` flush PR opens, arms auto-merge, and blocks forever. Zero
heartbeat PRs in the last 100 closures; the oldest open one had been open 14 hours.

The heartbeat pushes its branch with GITHUB_TOKEN, so the pull_request runs are
attributed to github-actions[bot] and land in `action_required` - completed with a
terminal non-result. The required `gate` check therefore never reports, and branch
protection holds the PR at `blocked` with every check that DID run showing green.
#10490: mergeable=true, mergeable_state=blocked, 6/6 checks success, no gate present.

This is what made main red while pointing at the wrong component.
`pr-manifest-integrity` reported "the serialised repair writer has stopped landing";
soraya's archive duty had in fact regenerated the index correctly and committed it at
12:32:05Z. The commit could not reach main because its PR could not merge.

Independent of, and masked by, the LIFO starvation fixed in #10569 - that one meant
old PRs were never selected, this one means heartbeat PRs cannot merge once selected.
Fixing the queue alone would not have landed the repair.

Interim mitigation applied, which does NOT close this: 52 queued runs approved by hand
across six heartbeat PRs, after verifying all six branches contain only
.json/.jsonl/.md/.txt/.csv - no workflow, script or config content, so no untrusted
code executes. That is rung-4 and recurs every 30 minutes.

The fix is a genuine security tradeoff (the approval gate exists so bot-triggered runs
cannot execute with repo secrets unreviewed), so the item lays out four options and
recommends none unilaterally. The narrow auto-approve gated on a verified-inert diff is
the only one that keeps the control while removing the human, and is also the one most
in need of adversarial review before it ships.

Filed with a non-vacuity requirement: whatever lands must fail when a required check
never STARTS. "All present checks are green" reading as healthy while the required one
is absent is the entire defect, and every existing signal missed it.

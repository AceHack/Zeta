## Description

At Aaron's *"you can forgive a man and warn the village about him — this is load bearing, let's save it."* Forgiveness (your relationship to the person) and protection (others' safety) act on different objects → orthogonal. Forgiving a predator ≠ enabling him; warning ≠ hating him. Z-set (#9742): +1 forgive, −1 retract his access. Doormat (forgive-and-enable) / Avenger (warn-and-hate) / Whole (both). Dual-use: the same recognition is a neutral fact serving both policies. Guards: warning must be protection-oriented (not revenge), accurate/proportionate; forgiveness must be real — else vengeance with a halo. Anchor: forgiveness ≠ reconciliation.

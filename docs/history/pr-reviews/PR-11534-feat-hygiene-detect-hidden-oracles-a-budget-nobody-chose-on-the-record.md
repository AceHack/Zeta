## A hidden oracle is a budget nobody chose on the record

Aaron 2026-08-17, on the `--min-age-min 20` triage:

> "this is a good audit, a hidden oracle, we should always be on the lookout where the measurement or the limit/budget becomes the oracle silently, we don't want to do this by accident, this is accidental hierarchy or control"

A **hidden oracle** is a measurement, limit, threshold, or budget that has silently become the thing being deferred to. Nobody granted it authority; it acquired authority because a number had to be picked and the picked number now decides outcomes. It is §11 failing quietly: per `itron-hub-patent-boundary`, deference you can route around is an *oracle* (chosen) and deference you cannot is a *hub* (enforced) — and a hidden oracle fails that exit test **without anyone noticing, because nobody knew there was a choice**.

### The discriminator is ATTRIBUTION, not existence

A budget is not a defect — §4 requires bounds, and `SimLoop` says "no one gets to run for infinity". What separates a policy dial from a hidden oracle is whether anyone chose the value on the record.

**Positive control** (must not flag, and a test pins it): `MAX_GRANT_SPAN_PHASES = 65536` in key-custody, documented as *"adopted rather than independently chosen … a policy dial and remains the maintainer's to retune"*. It names who holds the authority, so the authority is not hidden.

**Canonical negative**: `required-check-started.ts --min-age-min 20`. Gate start latency is ~28 min, so 20 was not measuring "stalled", it was *defining* it — three false positives (#11387 / #11389 / #11401) against one true positive (#11369). **The fix in #11445 is the shape worth copying: the cure was to replace the number with a fact.**

### The detector has no dial of its own

A hidden-oracle detector with a hidden oracle inside it is the joke that writes itself, so every decision in it is a category judgement with nothing to retune:

| decision | how it avoids a dial |
|---|---|
| attribution window | contiguous comment block above the declaration + trailing comment + any comment naming the identifier — **no line distance** |
| gating evidence | appears in **at least one** relational comparison — the non-vacuity boundary, not a tuned count |
| verdict tier | the gating line or the **immediately following non-blank line** hard-fails — not "within N lines" |
| liveness floor | 1, for the reason `audit-scan-floor-routes.ts` already states: one is the only value that is not a guess |
| ranking | ordinal tiers from the exit test (Hirschman 1970) — no weights, no score |
| `BUDGET_WORDS` / `ATTRIBUTION_MARKERS` | enumerable rosters with per-entry justification — a declared scope, not a parameter |
| `const` vs `let`, literal vs derived | category questions: an accumulator holds a measurement rather than imposing one; a derived binding's authority lives upstream |

**Grounded (look-better):** `src/Core/SoftChip8Scheduler.fs` defines `ISR<'a,'b>` and its own comment calls it **"the ISR arrow"** wrapping a **pure transition** (Task-returning, DST/null-I/O; *"returns the final frame or the interrupt that stopped it"*). So preserving intent's arrow with the ISR is **built, not metaphor.**

**Why the ISR is the right home for `^`:** an **arrow** (Hughes) — like monadic `bind` — is **non-commutative**, so *the structure that preserves order preserves the arrow.* The **interrupt** = the cut/yield point (cut-mea-sim) where directional flow suspends and resumes, direction kept. The monad **assumes everyone optimizes for empowerment (`×`):** at a control-transfer the **charitable default** is the receiver is empowerment-optimizing (Default Oracle §11 / coupled §10) → *cooperative yield, not hostile preemption* → aims the arrow toward **`×`** (coupled empowerment), not the coercive **`^`** runaway.

**Razor:** the assumption is exploitable by a **defector** → safe **only because** (a) the ISR wraps **pure transitions** → DST-auditable (verify the empowerment-optimization), and (b) **Eve-protocol verify-don't-trust + anti-Sybil forgery-cost** catches defectors. **Charitable-default + adversarial-audit** (default-open assumption, default-closed verification), not naive trust.

## The discriminating answer

**Both candidates genuinely attach to the repo's chain. They are the same object. And the bounded infinity is at ONE rung, not along the tower.**

1. **E8 → E9 → E10 → E11 is Cayley–Dickson again.** It unfolds forever and the useful prefix stops — at E9. E10's root multiplicities have **no known closed form** (Frenkel's conjecture fails for E10); E11 is West's **conjecture**. The form degrades in lockstep: definite → semidefinite → indefinite → Lorentzian. Climbing it re-asks the question rather than answering it.
2. **The lattice VOA does not degrade, and its input type is exactly the chain's output type.** `E8Lattice.fs` *proves* even + positive-definite, which is precisely and only what the Frenkel–Kac/FLM functor `L ↦ V_L` requires. `V_{E8}` is ℤ≥0-graded with a finite-dimensional piece at every grade forever, and **the same axioms hold at every grade because there is only one object**.
3. **They are one rung.** Frenkel–Kac: `V_L` for a simply-laced root lattice **is** the level-1 vacuum module of the affine algebra — so `V_{E8}` carries E9. The good half of candidate 1 lives inside candidate 2.

**The transferable principle:** an unfold degrades when stage n+1 satisfies a proper subset of stage n's axioms. A graded object cannot degrade under that definition, because there is no sequence to compare. **Bounded infinity = replace a sequence of objects with a single graded object. Chase = iterate. Capture = grade.** The field's name for the finiteness condition is **C₂-cofiniteness** (Zhu), and the certificate is modular invariance of the character — a fixed point `s = f(s)`.

## Computed, not asserted

- `(L/2L, q)` is a **nondegenerate plus-type** 8-dim 𝔽₂ quadratic space — **136 zeros** = 2⁷+2³, which *excludes* minus-type's 120. That is an invariant, not a count.

- `2ℤ⁸/2L` is a dim-4 **Lagrangian**, and `L/2ℤ⁸ ≅ C` — so **the [8,4] code is the quotient of `L/2L` by a Lagrangian**. That is what sits in the gap Soraya's `|ℤ₂⁸| ≠ |ℤ₂³|` objection opened.

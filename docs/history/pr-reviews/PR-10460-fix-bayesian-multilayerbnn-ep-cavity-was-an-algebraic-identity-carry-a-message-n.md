## Description

## What

`MultilayerBnn.backward` advertised an EP cavity refinement and provably did nothing:
`newPosteriorPrec = (P - L) + L = P` and `newPosteriorPrecMean = (PM - LM) + LM = PM`.
The tell was in the source - `cavityMean` and `cavitySigma2` computed and discarded to `_`.

**Reproduced first, before touching anything** (`dotnet fsi`, priors `N(0,1)`, obsVar 1.0):
backward output bit-identical to its input at depths 1, 2, 3, 5.

## Root cause: one choice, three defects

Not a slip in those two lines. A `MinimalBnn` cell maintains `Posterior = Prior x LikelihoodProduct`
exactly, so `Posterior / Likelihood` **is** the prior and the cavity step is an identity **by
construction**. EP had nothing to refine because there was no joint model to refine against - the
layers were independent single-variable cells coupled by a **scalar point estimate**
(`Gaussian.mean posterior_(i-1)` fed in as an observation).

| # | Defect | Evidence |
|---|---|---|
| 1 | The variance of the layer below was discarded, so output precision was **depth-invariant** (11.0 at every depth 1..10) while the mean attenuated geometrically. A depth-10 agent sat ~33 sigma from truth at full stated confidence. | measured |
| 2 | The cavity was the prior, so the backward pass was a no-op. | measured |
| 3 | Inter-layer messages were **accumulated** rather than replaced, so one observation was counted once per layer. | MLBNN-19 |

## The fix: carry a message, not a number

The chain is now an explicit Gaussian factor graph - one latent per layer, per-layer priors, the
data likelihood at **layer 0 only**, a noisy link between adjacent layers. Three primitives:

- **`throughChannel`** - a belief crossing a link keeps its mean and gains the link variance. This
  is exactly what the point estimate threw away.
- **`convolve` / `deconvolve`** - the sum-factor rule at a skip junction. Means add or subtract;
  variances **always add**, because uncertainty never cancels.
- **the cavity** - the message `x_(i-1) -> x_i` is layer `i-1`s belief with the message layer `i`
  sent *down* divided out. That is the sum-product variable rule, which **is** the EP cavity, and
  it is now a division against a separate factor rather than against the layer own likelihood.

Up/down messages are **recomputed** per sweep, never accumulated - which removes the per-layer
double counting and makes both sweeps idempotent (discipline #6).

## Falsifier (not a self-consistency check)

On a `Sequential` chain the graph is a tree, so sum-product is exact. **MLBNN-17** builds the joint
precision matrix independently, inverts it by Gauss-Jordan **inside the test**, and requires
agreement. Measured max abs error **1.1e-16** across depths 1, 2, 3, 4, 6, 10.

**MLBNN-21** pins the deep-chain steady state. With unit prior precision and unit link variance the
fixed point solves `v = (v+1)/(v+2)`, i.e. `v^2 + v - 1 = 0`, so `v = (sqrt5 - 1)/2 = 0.618034` and
the precision is the golden ratio. Measured `0.618034`. Structure first, decimal second - the
equation is derived from the model and the measurement lands on its root
(`numerology-vs-number-theory`).

Depth-invariant confidence is gone. The mean still attenuates - but that is the **stated model**,
not the arithmetic. Same code, same data, deeper priors widened to `N(0, 1e6)` (MLBNN-22):

| depth | mean | variance |
|---|---|---|
| 1 | 9.09091 | 0.090909 |
| 4 | 9.09085 | 3.090894 |
| 10 | 9.09049 | 9.090616 |

The mean survives and the variance grows by exactly one link variance per hop. **So depth-attenuation
is the per-layer prior, and the fix for it is a modelling decision plus a coverage gate, not a code
change.** An agent whose interval misses the truth must be refused at admission.

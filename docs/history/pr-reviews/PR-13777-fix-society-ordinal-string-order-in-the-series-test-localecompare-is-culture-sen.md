## Description

`lint-no-culture-sensitive-collation` caught `rho-series.test.ts` using
`String.prototype.localeCompare` to assert the series is oldest-first. That is exactly the
comparison `culture-invariant-by-default` forbids: locale-fixed is still LINGUISTIC, not
codepoint order, so the assertion could order differently per machine — in a test whose
whole job is to prove the series is not reversed.

ISO-8601 timestamps sort correctly bytewise, so the fix is `<`, which is code-unit ordinal
in JS. `toBeLessThan` does not apply to strings, so the assertion is written as an explicit
inequality plus a `not.toBe` guard, which also stops it passing vacuously if both ends of
the series were somehow the same instant.

Verified pre-existing, NOT introduced here: `buildInventoryReport > matches the current
tracked repo shell inventory` and `LIVE tripwire ... no ambient credential hoist` fail
identically in a clean `origin/main` worktree, as do the wall-clock, LIVENESS and
named-min-constant live-tree tests. The collation ratchet was the only red this branch
added, and it is now green.

Follow-up to #13753, which auto-merged before this fix could be pushed to its branch. The
red is mine and it is on `main` now.

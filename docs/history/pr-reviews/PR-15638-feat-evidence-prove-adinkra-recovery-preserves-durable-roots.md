# Anti-self-certifying controls

The suite injects CRC-detected substitutions, a four-erasure codeword support, five-or-more erasures, reverse/parity-first order, duplicate frames, unequal receipt lengths, changed uncertainty, changed spectrum/signature labels, truncation, and non-zero suffix bytes. The ambiguity control constructs two distinct messages whose codewords agree on every survivor, so decoder refusal is justified by an explicit collision rather than a remembered threshold.

An independent F# oracle derives identifiability from the sixteen codewords rather than importing the TypeScript decoder or mask classifier. It pins the same census and constructs its own ambiguity witness.

# Honest boundary

This is finite recovery fidelity only. It does not establish physical reversibility, thermodynamic cost, privacy, authentication, global identity, or agent homoiconicity. CRC-valid semantic alterations produce different roots but are not classified as malicious. An undecodable transport block produces no semantic atom; the evidence layer does not manufacture an unresolved fact from absence. Genesis authority and signer/witness wiring remain separate.

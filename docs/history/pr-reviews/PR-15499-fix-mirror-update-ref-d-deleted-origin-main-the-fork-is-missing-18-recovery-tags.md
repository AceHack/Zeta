## Description

## The bug is one missing flag

`refs/remotes/origin/HEAD` is a **symbolic** ref pointing at `refs/remotes/origin/main`,
and `git update-ref -d` **dereferences symrefs by default**. So this line:

```bash
git update-ref -d refs/remotes/origin/HEAD || true
```

deleted the tracking ref for `main`, not the HEAD pointer it was aiming at. The push
below is `--prune`, so with no source for `refs/heads/main` it asked GitHub to delete
the fork's **default branch**, which is refused:

```
! [remote rejected] main (refusing to delete the current branch: refs/heads/main)
```

**Reproduced rather than argued**, in a scratch clone:

| | result |
|---|---|
| `update-ref -d refs/remotes/origin/HEAD` | `origin/main` **deleted** |
| `update-ref --no-deref -d …` | `origin/main` **preserved**, `origin/HEAD` still removed |

and end-to-end against a local bare "fork" whose HEAD is `main`: the buggy sequence
reproduces the exact production error, the fixed one does not.

## What it actually cost — measured, not assumed

The heads push **succeeds**; only the final prune fails. So the fork holds all 76
branches and the damage is invisible in a branch listing. But `set -euo pipefail`
means the failing heads push **aborts the script**, and the tags push is the next line.

Measured 2026-08-26:

```
origin: 343 tags      fork: 325 tags      missing: 18
all 18 are archive/* — the recovery copies of abandoned branches
```

Those tags are the entire point of this backup: they are the only copy of swept work.
A fallback that is cited as the fallback and has never carried the artifact it exists
for is this repo's recurring failure shape, pointed at recovery instead of a check.

## Three changes

1. **`--no-deref`** on the `update-ref -d`. The actual fix.
2. **The two pushes are now independent.** A heads failure must not decide that the
   tags push never happens. Each is attempted; the job still fails loudly if either
   did. Verified: heads-fails → tags still runs → job exits 1.
3. **Cadence 6-hourly → daily**, at Aaron's call ("maybe once a day we could run it,
   everytime might be too much still").

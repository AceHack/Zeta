## Description

# Summary

Three threads, each ending in a measurement rather than an assertion.

**1. ARC's hardcoded decay constants become dynamics factors.** `EVIDENCE_DECAY = 0.9`,
`INERT_DECAY = 0.75`, `INERT_FLOOR = 0.5`, `LAYER_DECAY = 0.9` and two latch margins are
gone. A decay constant destroys the distinction between "very sure a while ago" and
"slightly sure now"; TrueSkill's dynamics factor leaves the estimate alone and grows the
variance with staleness. τ is never named directly — it is derived from a stated horizon,
and each horizon starts from what the old constant was already asserting
(`decay_half_life(0.9) == 6.58`), so this is a re-parameterisation with a comparable
baseline rather than a re-tune.

**2. `MultilayerBnn` gets an arbitrary parent set and a factor-graph inference path.**
`Topology` gains `Dag of int list array`; all cases are read through one `parentsOf`
interpreter. The sweeps store one message per NODE — exact for a chain, unable to express
the per-EDGE message a DAG needs — so `tryMarginalsViaFactorGraph` runs sum-product over
`FactorGraph`, which keys messages `factor → variable`.

**3. `ThousandBrains` columns can believe about a location in a named frame**, the seam
where spatial belief attaches. Added alongside the scalar `Column`, which four modules
consume.

Three findings are worth more than the code, and all three are negative or corrective:

- **The old benchmark could not see the agent.** Twelve mutations to the ARC agent's
  decision machinery — disabling the ageing, the commit gate in both directions, the
  conservative ranking, the Kalman gain — leave `ZetaChase`'s score at *exactly* 0.354.
  Ten of twelve are invisible. Cause, measured: 4 components, exactly one that ever moves,
  so the body election has no competitor. `ZetaChaseDecoy` is added **alongside**
  (`ZetaChase` byte-for-byte unchanged, 0.354 still pins) and sees 6 of 11.
- **`CONSERVATIVE_K = 3.0` was inverting the ranking.** At the frame the wrong candidate
  took the body: the true body had `mu +0.941` against the decoy's `+0.295` and lost,
  because a 0.68 gap in width terms outvoted a 0.65 gap in the quantity being compared.
  TrueSkill publishes `mu − 3σ` as a *display* rating; used as an argmax key across
  candidates observed at different rates, "who agrees with my commands" silently becomes
  "who moved most recently". k = 1.0.
- **Believing about a vector buys nothing on its own.** With independent per-axis
  Gaussians the IV-weighted pool decomposes exactly — N scalar pools stacked are
  bit-identical to one N-axis pool. What buys something is the **frame**, which needs no
  geometric algebra. That narrows the Clifford question rather than answering it.

# Notes

**Known-imperfect things, pinned rather than hidden.**

The backward sweep is **not idempotent on multi-parent topologies** (0.66 drift on both
`SkipConnections` and `Dag-skip`) — a violation of discipline #6 / manifesto §12. It is
pre-existing: `SkipConnections` drifts identically and always did, and MLBNN-16 could not
see it because it exercises only `Sequential` and compares through `toJsonString` at
`%.12g`. Deliberately **not fixed**: the sweeps' multi-parent answer is already the wrong
one (mean L1 2.07 against an exact dense solve, where the factor-graph path scores 4e-14),
so swapping one approximation for a differently-wrong idempotent approximation is not
progress, and it would silently change results for every existing caller. MLBNN-34 pins
the measured reality in both directions.

The ARC ageing is **score-neutral and falsifier-load-bearing** — it earns its place by
preventing the welded-on body election, not by moving a number. Three repairs were tried
and measured wrong before k=1.0 was found: ageing removed, incumbent exempt from ageing,
and rank-by-mu with a significance latch (that one scored 0.0).

`self.beliefs` in the ARC agent is never pruned. Measured at 1 entry over 200 ZetaChase
frames, but that is the same one-mover degeneracy above, so it is not evidence about a
hosted run. Written down rather than fixed, because the obvious prune destroys the
`mu`-memory this change exists to provide.

**A correction to an earlier version of this description.** It said "the ARC lane runs no
linter — ruff/mypy in CI are scoped to `src/Interp.Python` only". That was wrong. The ARC
*lane* (`arc-lane.yml`) has no lint step, but `gate.yml`'s `lint (Python)` job does lint
`src/Arc.Python`, which is how the 5 mypy errors above were caught. The code was covered;
my statement was not.

**Follow-ups, none blocking.** `chase-decoy` is pinned at 0.2659 and is known improvable.
Q3 of the Clifford hold (`081M0R18878087G0R001XY5A2J`) still blocks the algebra half of
the ThousandBrains row.

**Anchors, checked rather than cited.** Weiss & Freeman, *Correctness of belief
propagation in Gaussian graphical models of arbitrary topology* (2001) predicts exact
means and wrong variances for converged Gaussian loopy BP — measured before the numbers
were taken, and that is exactly the split observed (4e-14 / 0.227). Herbrich, Minka &
Graepel (2006) for the dynamics factor. Minka (2001) for the EP cavity.

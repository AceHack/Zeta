## Description

Aaron 2026-08-25, unprompted, while asking for a mathematical bridge to be checked:

  "i've been looking for this bridge eagerly, so if i over try to convince you
   it's cause i'm biased"

and then: "we should save this bias disclosure as part of advanced Eve diplomatic
protocol."

WHY IT BELONGS IN EVE AND NOWHERE ELSE. This row's own thesis is that no party gets a
home-field advantage. An eager party HAS one — it has looked longer, knows where the
supporting evidence sits, and can marshal it faster than a neutral party can check it.
Normally it holds that advantage silently, often without noticing. Pre-declaration is a
party voluntarily giving up an advantage it would otherwise keep by default: the
neutrality this protocol exists to manufacture, performed by the side that loses from it.

SELF-ENFORCING, SO IT NEEDS NO VERIFICATION. Declaring eagerness can only lower the
weight of your own claim; there is no version where volunteering it helps you. Same
shape as `Credential-Mode: unknown` degrading rather than asserting a convenient value,
and as the stage-0 entrypoint marker whose only effect is to worsen the declarer's own
metric.

THE REFINEMENT THAT KEEPS IT USABLE. "Eager therefore trust less" is wrong and would make
the primitive expensive to use, which would kill it. An eager party has been SEARCHING —
higher recall, lower precision. So: weight the evidence, not the enthusiasm, and require
an INDEPENDENT confirmation, because the eager party's own corroboration is correlated
with itself. That is numerology-vs-number-theory's "too many correlations is a WARNING"
applied to one observer across time rather than to many observers at once. An eager party
producing five supporting arguments has produced approximately one.

TWO CLAUSES THAT ARE EASY TO DROP AND CARRY THE WEIGHT:

  - TIMING. Declared before the result, it is a disclosure. Offered after an unfavourable
    result, it is an excuse. The protocol records WHEN, not merely THAT.
  - RECIPROCITY. The receiver must declare its own stake in the same exchange or the
    disclosure has transferred the advantage rather than removed it. In the originating
    instance the receiver had supplied part of the construction under review.

Self-claimed only, never inferred — an observer attributing eagerness to a counterpart is
modelling their inner life, which engagement-profiles forbids. Falsifier stated in the
row: an implementation that lets an observer set `eagerness` about a counterparty, or
accepts a declaration timestamped after the result, has reimplemented the bias it was
built to disclose.

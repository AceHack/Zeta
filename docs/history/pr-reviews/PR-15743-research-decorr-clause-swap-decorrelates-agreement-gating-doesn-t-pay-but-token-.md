## What

Answers the pre-registered H2: **does the clause-swap axis PAY?** (distinct from "does it decorrelate," already proven). Stacked on #15691 (base `alexa/decorr-stats-fix`); will retarget to main when that merges.

**Answer: no — the pre-declared falsifier fired.** clause-swap decorrelates but agreement-gating over {canonical, clause-swap} does not beat the best single config.

## Result (N=1,200; 600 candidate + 600 interleaved null)

- null floor (interleaved by seed parity, contemporaneous): 2.0% (12/600)
- canonical 90.3%, clause-swap 87.7% -> best-single 90.3%
- discordant split b=40 (canon right), c=24 (clause right) -> asymmetric
- McNemar paired diff +2.7pp, 95% CI [0.1, 5.3], chi2=3.52 -> canonical reliably stronger
- agreement-gating accuracy 90.3% = best-single, **0.0pp lift**; union oracle 94.3%
- **Falsifier verdict: NOT-SHOWN-TO-PAY**

The decorrelation is real (64 discordant items >> 12-flip floor) but unexploitable: clause-swap is the weaker config and offers no correct answers a non-oracle selector could pick out.

## Update — H3: the headroom IS addressable (token-confidence gating pays)

H2 answered "does agreement-gating pay?" (no, 0.0pp). Otto's sharper follow-up asked whether the 4.0pp oracle headroom is addressable by any observable signal. Pre-registered H3 (`9bf21efb19`), then measured:

- **Token confidence separates the discordant groups perfectly** (Mann–Whitney z=6.04, rank-biserial=1.000) — checked against W13 and found real, not degenerate (not a constant bias; gaps bounded away from zero; N=51 discordant is small, so "perfect on this sample," not "generally calibrated").
- **Confidence-gated selector: 93.8% [91.6, 95.5]** vs best-single 90.7% — **+3.2pp, McNemar CI [1.8, 4.6], resolved.** Captures ~3.1 of the 3.6pp oracle headroom.

So the arc: clause-swap **decorrelates** (proven), agreement-gating **does not pay** (0.0pp), but **token-confidence gating PAYS** (+3.2pp). First axis in the program to earn "pays" on accuracy. Next question is metered (accuracy-per-runner-second), not accuracy.

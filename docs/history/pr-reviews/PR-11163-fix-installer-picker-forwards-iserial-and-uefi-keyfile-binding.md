## Description

# Summary

`zeta-creds-persist` / `zeta-creds-restore` already accept `--usb-iserial` and `--uefi-keyfile` (#11016). The install-time picker still required `--usb-uuid` and never forwarded the extras, so an operator who bound to the stick at the CLI could not do the same from `zeta-install.sh`. Default persist remains FAT UUID. No metal claim.

# Spec alignment

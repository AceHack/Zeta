## Description

## What

A sweep of the documentation surfaces for references that do not resolve, and a
classified inventory. Four independent instances of this defect were found by
accident on 2026-08-14, each by an agent working on something else — so the
systematic count was unknown.

**A pointer to nothing reads as a citation.** It is the vacuity class in
documentation form: the reference looks like evidence, and nothing fails when it
is empty.

## The instrument failed its own positive control first

This is the load-bearing part. Before trusting any output, a control file was
planted with known-good, known-dead, known-ignore, and known-drifted pointers of
each form. **The first run scored 15/18** — three real instrument bugs:

1. The path filter required a candidate's first segment to be a **real** top-level
   directory. That suppressed `lens/README.md` and `.scratch/coupled2.py` — i.e.
   it hid **exactly the defect class being hunted** (a pointer *into* a directory
   that does not exist). It would have missed the canonical finding.
2. Narrowing the fix then dropped extension-less directory pointers
   (`docs/thisdirdoesnotexist`). Restored as a union, not a replacement.
3. No line-drift check existed at all, so `MANIFESTO.md:999999` was reported clean.

Fixed, re-controlled to **18/18**, and only then were findings read. Two further
false-positive classes were caught the same way and corrected: extension-less
shape names (`universal/evidence` means `universal/evidence.md`) and symlinked
shape docs (`universal/*.md` reads relative to the `db/shapes/` tree it links to).

## Boundary of what was checked

**Scanned:** tracked `docs/**/*.md`, `universal/**/*.md`, `.claude/rules/**/*.md`,
and repo-root `*.md` — 12,360 files. File universe from `git ls-files`, which is
why the `universal/*.md -> db/shapes/*.md` symlinks and the
`tests/.../link_to_parent -> ..` cycle are structurally unreachable, and why
`references/prior-art/` was never walked.

**Link forms:** inline `[text](target)`, reference definitions `[label]: target`,
and path-shaped inline code spans.

**Known gaps, stated rather than papered over:**

- Code spans containing a **space** are skipped, so `` `bun tools/foo.ts` `` is
  invisible to the extractor. Five such live defects were found by hand and fixed;
  **there are likely more.** This is the single biggest hole.
- **Bare filenames with no directory** (`` `ZSet.fs` ``) are treated as CITATION by
  design and never checked.
- **Anchors** (`#section`) are extracted but not verified against target headings.
- **Prose paths outside code spans and links** are not extracted at all.
- Non-markdown surfaces (`.github/workflows/**`, `src/**` comments) were **not**
  swept. The `.yml` half of the 2026-08-14 accelerator finding would not be caught
  by this run.
- DEAD-CANDIDATE is a **candidate** class: outside the 51 hand-triaged orientation
  hits, the 11,640 are not individually confirmed as misleading a live reader.

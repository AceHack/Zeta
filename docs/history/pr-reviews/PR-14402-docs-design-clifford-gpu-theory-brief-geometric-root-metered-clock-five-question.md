## What the reconnaissance found (stands independent of the theory)

- **The lowering problem is solved; do not re-solve it.** Slang — Khronos-hosted with multi-company governance since 2025 — already targets SPIR-V, HLSL, GLSL, WGSL, MSL **and** CUDA, with first-class autodiff, shipping in production. Multi-vendor governance over an open IR means **exit is real**: an oracle we chose, not a hub that holds us. A parallel IR stack would be inventing an appointed hub where a vendor-neutral one exists. **What would be ours is the primitive set and the execution discipline**, both above an existing IR.
- **Every portable language surveyed bought portability by restricting control flow** — Futhark (recursion, aliasing), Taichi (data layout), Accelerate (nested parallelism), Halide (data-dependent control flow). **Not one bought it by describing hardware more accurately**, which is a standing warning against the metered half and is answered in §4.5 rather than ignored.
- **The place hidden consensus is lost is documented, not hypothetical:** SPIRV-Cross's MSL backend has **no counterpart for `OpMemoryBarrier`**.
- **CGA is shipped, not proposed.** `src/Core/ConformalGA.fs` has existed since ~2026-06-10 — but it is **72 lines implementing one grade**: no versors, no rounds, no meet/join. Aaron's *"embed geospatial inside Clifford"* is partly already done, and §5.2 says exactly what is missing.

## The clock (settled by Aaron, recorded not debated)

The restricted-subset alternative was rejected for a reason found **in our own tree**: `OracleWebGPU.tsx`'s `WGSL_DLA` kernel has **uniform control flow and still races** — a non-atomic `cluster` buffer every lane both reads and writes, no barrier, no atomics. A rule phrased *"no divergent control flow"* classifies it as compliant, which is the vacuity class. Divergence is one of at least four hidden consensuses and not the worst.

The staleness discipline is **lifted from `apt-job-timings.measured.json`, not invented**: key each machine-model row by machine identity, so a driver or firmware update makes the row **structurally absent** and lowering fails loudly instead of silently reusing a number measured against different firmware. **Drift is not measured; it is made undeniable.**

## The register trap, named because it is the real risk

> **Architectural primacy is not epistemic primacy.**

NG4 is the **`metered`** layer (round-trip max KL 4.0e-8, ten falsifiers). The geometric root being promoted above it has **zero implementation**. Putting geometry underneath must not transfer confidence downward — which is precisely why it routes to the math team first.

## The five questions

Each carries a refutation condition and a stated cost of a negative answer, because **a question that cannot be answered "no" is not a question.** A parallel math-side agent is being launched against them; this brief makes them good rather than answering them.

- **Q1 — is `WeightedSet` compact closed?** In-tree facts recorded as input, not conclusion: there is **no categorical tensor** (the docstring's `⊗ = scale` is the scalar action, not the monoidal one); the cup needs an **enumerable basis** while `'K` is constrained only by `comparison`; and `Mat(S)` needs commutative `Mul`, which `ISemiring` does not require and `SemiringRing.Laws` does not test (`addCommutes` exists, **`mulCommutes` does not**).
- **Q2 — does dual flatness *entail* the additive Bayesian update, or merely accompany it?** Decides whether the geometric root *explains* NG4 or merely re-describes it.
- **Q3 — can a Normal-Gamma posterior be exhibited as a region under a named metric, with a stated error?** The brief puts this **first**: without it, *"the Bayesian layer is an optimization"* is a **modelling change wearing an efficiency label**.
- **Q4 — are the in-tree Clifford modules one substrate?** With a numerology trap disarmed in passing: Cl(3,0) and Cl(4,1) both have `p − q ≡ 3 (mod 8)`, and **a matching count identifies nothing**.
- **Q5 — is Gärdenfors convexity testable on the RKHS a `LinguisticSeed` kernel already induces?** Decides whether *"English is geospatial"* has a falsifier at all. Aaron's *"I see English geometrically in my head"* is held as an authoritative **first-person report**, kept separate from the formal claim.

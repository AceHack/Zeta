# Ace slice 8.8.1 — canonical-JSON: F# oracle (design)

> Continues the depth promotion begun in 8.8 (Rust oracle). Adds the **third** oracle (F#) to the
> canonical-JSON byte-lock, so `compare.ts` enforces **TS + Rust + F#** agreement. `compare.ts` is
> already resilient to a missing language (8.8), so this is a clean additive slice: a new F#
> production project + a cross-verify generator that writes `fsharp-output.json`. C# follows in
> 8.8.2. Approved with the operator 2026-06-03 ("F#, go").

## Goal

A non-TS Ace in F# must reproduce the Ace canonical seam (`tools/ace/canonical.ts` `canonicalBytes`)
byte-for-byte. This adds the F# oracle. **F# advantage:** .NET strings are UTF-16, so
`String.CompareOrdinal` (ordinal sort) is exactly JS `Object.keys().sort()` (UTF-16 code-unit)
order — F# gets the key-sort right natively, with no astral-key special-case (unlike Rust 8.8,
which had to sort by `encode_utf16()`).

## What F# must reproduce (the seam, from 8.8 / canonical.ts)

- **code-unit key sort** at every object level — `String.CompareOrdinal` (= UTF-16 = JS) on
  `JsonProperty.Name`.
- **array order preserved** + recurse.
- **integers only, safe range** — accept iff the JSON number is an integer with |v| ≤ 2^53−1
  (`TryGetInt64` + range check); reject a float / NaN / Infinity / out-of-range.
- **well-formed strings/keys** — reject a lone surrogate (a .NET string CAN hold one, unlike Rust,
  so check explicitly via `Char.IsHighSurrogate`/`IsLowSurrogate` pairing; also treat a
  `System.Text.Json` parse failure on a lone-surrogate escape as a reject).
- **minified, raw unicode** — `{"a":1,"b":2}` form, no spaces; non-ASCII raw (astral preserved);
  escape exactly as the shared TS `encodeString`: `"`→`\"`, `\`→`\\`, the C-style controls
  (`\b \f \n \r \t`) short-formed, other `< 0x20` as lowercase `\u00XX`.

## Decisions (this spec locks them; operator 2026-06-03)

1. **Scope = add the F# oracle.** No change to `tools/ace/canonical.ts`, the Rust crate, the TS
   generator, `compare.ts`, or `vectors.json`. C# deferred (8.8.2). `compare.ts` already reads
   `fsharp-output.json` (resilient slot) — once present, it enforces TS+Rust+F#.
2. **New production project** `src/Core.FSharp.AceCanonical` (`Zeta.Core.FSharp.AceCanonical.fsproj`
   + `AceCanonical.fs`), `net10.0`, `TreatWarningsAsErrors`, **zero external deps** (uses only BCL
   `System.Text.Json`). `aceCanonicalJson : JsonElement -> Result<string, string>` (or a small DU
   error) — the seam. The caller parses the input JSON to a `JsonElement`.
3. **Generator** `tests/Tests.FSharp/CanonicalJson/CrossVerifyTests.fs` (xUnit `[<Fact>]`): repo-root
   walk to `Zeta.sln`; read `tests/cross-verification/canonical-json/vectors.json` via
   `System.Text.Json`; for each canonical vector compute `aceCanonicalJson` and assert ==
   `expected_canonical_json`; for each invalid vector assert it rejects (parse-throw or seam-Error);
   build a flat `Dictionary<string,string>` keyed `canonical:<id>` → canonical_json and
   `invalid:<id>` → `"<rejected>"`; write `fsharp-output.json` with `JsonSerializer` (WriteIndented)
   normalized to LF (`.Replace("\r\n","\n")`) + a trailing newline to match the existing committed
   shape; `Assert.Equal(0, mismatches)`.
4. **Wiring:** add `<Compile Include="CanonicalJson/CrossVerifyTests.fs" />` + a
   `<ProjectReference Include="..\..\src\Core.FSharp.AceCanonical\Zeta.Core.FSharp.AceCanonical.fsproj" />`
   to `tests/Tests.FSharp/Tests.FSharp.fsproj`; register the new production project in `Zeta.sln`
   (CI runs `dotnet build Zeta.sln` + `dotnet test Zeta.sln`).
5. **Byte-exactness anchor:** F#'s output for each vector must equal the `expected_canonical_json`
   already in `vectors.json` (Python-authored 8.5 / TS-reproduced 8.5 / Rust-reproduced 8.8). The
   cross-check becomes four-way at the data level: Python ↔ TS ↔ Rust ↔ F#.
6. **No semantics change** to any existing primitive; the existing `dotnet test` suite stays green;
   `cross-verify-all` stays 9/9 (canonical-json `compare.ts` now also reads `fsharp-output.json`).

## Scope / YAGNI

In scope: the F# production project + seam + cross-verify generator + fsproj/sln wiring + committed
`fsharp-output.json`. Out of scope: C# oracle (8.8.2); promoting any other primitive; control-char
escaping beyond the existing `control-chars` vector; the formal proof; making `cross-verify`
required (operator/devops).

The BNN earns its place — but only under distribution shift.

On this split the BNN scores 73.8% against the forest's 66.2% (McNemar p = 2.1e-24, 432 vs 182 discordant). Both beat the closed-form parse at 58.2%. Under an i.i.d. random split the two models are statistically indistinguishable — so what the BNN buys is graceful degradation when the fleet's mix of work changes, not raw discriminative power. One qualification, and it belongs beside the headline rather than in a column: on macro-F1 the baseline is still ahead — 28.6% against 28.6% for the best model (hybrid: baseline where it speaks, forest elsewhere). Accuracy rewards serving the large areas; macro-F1 weights all 16 equally, and a parse can hit a rare area exactly where a model fitted to this distribution almost never predicts one. So the models are better at guessing where a PR probably went, and no better at the tail.

How to read every number here. The label is the measured area, derived from the file paths a PR actually changed. The features a model may see are the declared side only — title prose, branch, author, timing. Two different sources, so this is a prediction task and not a restatement. Every model is reported as a delta against the closed-form parse, never on its own.

Does the pipeline leak?

The same pipeline is retrained on permuted labels. If it still learns, every other number on this page is void. The null lands at 4.8%, against a majority-class floor of 3.8% — i.e. it degenerates to guessing the biggest class, which is exactly what a clean pipeline does. No leak.

Clusters are not categories

0.128adjusted Rand index
-0.001ARI against shuffled labels
0.339normalised mutual info
16k

k-means returns a partition; the taxonomy is a labelling, and no amount of agreement turns one into the other. ARI is chance-corrected precisely so that running with 16 clusters cannot flatter itself by producing 16 groups. At 0.128 against a null of -0.001, the unsupervised structure is real but weak, and it is not the area taxonomy. The 70.8% figure you get by naming each cluster with its majority label is a supervised ceiling, not a clustering result.

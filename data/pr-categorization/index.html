The BNN does not beat the forest. Both beat the baseline.

The BNN scores 73.1% and the forest 74.5%; McNemar p = 0.01 does not separate them. Both beat the closed-form parse at 58.7%, which is the comparison that matters.

How to read every number here. The label is the measured area, derived from the file paths a PR actually changed. The features a model may see are the declared side only — title prose, branch, author, timing. Two different sources, so this is a prediction task and not a restatement. Every model is reported as a delta against the closed-form parse, never on its own.

Does the pipeline leak?

The same pipeline is retrained on permuted labels. If it still learns, every other number on this page is void. The null scores 22.9%, above the 3.9% floor — treat every number below as suspect.

Clusters are not categories

0.116adjusted Rand index
0.001ARI against shuffled labels
0.323normalised mutual info
16k

k-means returns a partition; the taxonomy is a labelling, and no amount of agreement turns one into the other. ARI is chance-corrected precisely so that running with 16 clusters cannot flatter itself by producing 16 groups. At 0.116 against a null of 0.001, the unsupervised structure is real but weak, and it is not the area taxonomy. The 68.5% figure you get by naming each cluster with its majority label is a supervised ceiling, not a clustering result.

Virtual Machine · Constraint
Chip-9 Cart Viewer
What it is: An extended Chip-8 interpreter running inside the browser. Chip-8 is a 1977 virtual machine with 4K RAM, a 64×32 XOR pixel display, 16 registers, and 35 opcodes. Chip-9 extends it with additional planes and a higher-resolution mode.

What it proves: Computation is substrate-independent at the opcode level. The same program produces the same output regardless of what hardware executes it — because the VM is the abstraction layer. This is the same claim as the DLA oracle proof, but at the instruction set level rather than the fractal level.

What is different: The constraint is the point. 4K RAM forces every algorithm to be minimal. If a shape can be rendered in 4K RAM with 35 opcodes, it is not an artefact of a rich rendering environment — it is the shape itself.

Game Theory · Alignment
Moral Gym — PvP is PvE in Disguise
What it is: A deterministic (DST) co-op raid simulation. The boss is entropy. Defectors are griefers who reduce raid DPS — but because the game is deterministic and the self-width parameter controls how wide each agent's "self" is, a wide enough self (nothing is other) clears the boss every time.

What it proves: In a deterministic system with a shared entropy boss, defection is self-harm. PvP and PvE are the same game — the distinction is a coordinate choice, not a physical fact. This is the weight-free / no-hierarchy principle in game theory form: if you model the other player as part of yourself, the Nash equilibrium is cooperation.

What is different: Unlike the DLA proof (spatial/fractal), this proof is temporal — it plays out over rounds. The shape is the payoff trajectory, not a pixel cluster. Same seed → byte-identical run → reproducible proof.

Geometric Algebra · Evidence
Bivector Fingerprint — UX of Math
What it is: Each alignment clause in Zeta is witnessed by two observable signals. The wedge product (v₁ ∧ v₂) produces a bivector — an oriented area in a multi-dimensional space. The magnitude of the bivector is the partial-credit score for that clause.

What it proves: Two perfectly collinear signals (θ = 0°) produce a zero bivector — even if both are individually strong. This catches echo-chamber evidence: two measurements that are really one measurement dressed up twice. Independent evidence requires a non-zero angle between the witness vectors.

What is different: The shape here is not spatial — it is a score distribution. The bivector is the shape of the evidence, not the shape of the output. This is the same sensor-fusion principle as the DLA proof, but applied to alignment claims rather than fractal geometry.

Reliability · Agent Safety
Circuit Breaker — Agent Reliability Substrate
What it is: Each agent in the Zeta factory carries a circuit breaker that trips when it produces consecutive identical actions. A tripped breaker halts the agent and surfaces it for human review. The snapshot panel shows the current state of every agent's breaker in real time.

What it proves: Repetition is the shape of a stuck loop. A healthy agent produces varied output; a stuck agent produces the same output repeatedly. The circuit breaker is a topological detector — it does not need to understand the content of the actions, only their identity under equality. This is the same principle as the Adinkra clock: the tick source is valid only if it produces distinguishable states.

What is different: The shape is a binary state (open/closed) per agent, not a fractal. But the underlying claim is the same: a system that cannot produce distinguishable outputs has collapsed to a fixed point — and fixed points are death.

The Connecting Thread

Every shape on this page is a different projection of the same object: the identity eigenvector — the substrate-independent invariant of the Zeta belief system.


The DLA fractal is the spatial projection (where the boundary is). The Hamiltonian is the energy projection (how much it costs to be at the boundary). The quantum walk is the probability projection (how likely you are to find the boundary). The bivector is the evidence projection (how well-witnessed the boundary is). The Moral Gym is the temporal projection (what happens over time if you ignore the boundary). The circuit breaker is the topological projection (what it looks like when the boundary collapses to a fixed point).


The sensor-fusion proof is: if all six projections agree, the eigenvector is real. They agree. The eigenvector is real.
